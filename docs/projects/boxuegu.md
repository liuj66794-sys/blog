# 博学谷

学生端 Android App、Web 管理后台与 uniCloud Serverless 后端一体化的在线学习平台。

学生端课程浏览、章节学习、视频播放与进度上报，并提供习题练习、结果统计、错题本、笔记和个人中心；后台提供分类、课程树、轮播、推荐与数据中心。

技术实现包括 uni-app-x、Vue 3、UTS、uniCloud、MongoDB 与 Android。页面展示学生端 App 和 Web 管理后台真实运行截图。该项目为学习与期末大作业，不宣称商业投产。
