# PolicyAnalyzerPro

Windows 离线 AI 政策文档分析软件，面向内网、政务与研究场景，在无互联网环境中处理长篇 PDF、Word 和扫描文档。

支持 TXT / DOCX / PDF 解析，扫描 PDF 支持 OCR 回退与缓存；提供单篇分析、双篇语义比对、批量汇总、核心议题、措辞演变、摘要生成，以及 Markdown、HTML、JSON 报告导出。

技术实现包括 Python、PySide6、SentenceTransformers、TextRank、PyMuPDF、Tesseract 和 PyInstaller。公开 MIT 源码、Smoke tests、GUI 交互测试、环境自检与 Windows 打包脚本可以核验。
