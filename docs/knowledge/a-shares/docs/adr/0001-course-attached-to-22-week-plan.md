# ADR 0001: 课程依附 22 周母计划，不建平行体系

- 状态：已接受
- 日期：2026-08-11

## 背景

知识库已有 `investment-learning-plan-2026-h2.md`（22 周计划），阶段划分、时间分配、铁律、里程碑都已明确。用户提出"制定学习股票知识的课程"时，存在两种解读：为母计划填充内容骨架，或另起一套课程。

## 决策

课程 = 22 周计划的内容骨架。严格按母计划 6 个阶段组织模块，课程只回答母计划没回答的问题：每个概念具体学什么、用什么材料、怎么算"学会"。不新增任何与母计划冲突的阶段、铁律或里程碑。

## 理由

- 母计划铁律 4 是"每阶段只看一个主材料"，两套体系必然打架。
- 母计划的终点（姑婆考核）和证据形式（交易日志、脱稿概念、盈亏归因）已经定义了课程的验收标准。

## 后果

- 课程文件的编号、节奏与母计划周次一一对应；母计划变更时课程必须跟随修订。
- 放弃"更系统、更学院派"的课程结构（如按证券从业教材编排），换取与考核目标的对齐。
