# ADR 0002: 技术分析只教"看得懂"，不教"用得好"

- 状态：已接受
- 日期：2026-08-11

## 背景

A 股入门内容分三层：(A) 交易制度层（T+1、涨跌停、集合竞价、费用、板块门槛）；(B) 分析层（估值、财报，母计划已含）；(C) 技术分析层（K 线形态、均线、量价、短线打法）。市面上大量 A 股入门内容以 (C) 为主，对新手吸引力极大。

## 决策

- (A) 全部纳入，且安排在证券账户开户之前（模块 2 前段）。
- (B) 按母计划推进。
- (C) 只教到"看得懂"级别：知道 K 线/均线/成交量是什么、为什么不能靠它单独决策；明确不教短线打法、不教形态交易。

## 理由

- 短线技术分析与课程的价值投资取向、与姑婆考核的"长期执行、沉下心"标准直接冲突。
- 完全不讲 (C) 会在实盘时看不懂盘面语言，也无法识别"靠 K 线荐股"的骗局；"看得懂"级别是免疫剂量，不是使用剂量（类比知识库中的认知免疫接种框架）。

## 后果

- 课程中技术分析只占模块 1 的一小部分，且每次出现都附"为什么不能靠它决策"的对照说明。
- 若未来用户想深入短线交易，需要重新评审本 ADR 并单独开体系，不在本课程内扩张。
