## 总则

- **考试**：广东省普通专升本 · 计算机科学与技术（政治理论 / 公共英语 / 高等数学 / 计算机基础与程序设计）
- **考试日**：2027-03-27（周六）；W1 从 2026-09-07（周一）起，共 **29 周**
- **目标**：公办本科上岸；阶段量化口径沿用原计划——强化题 ≥75%，真题单科正确率 政治 ≥70% / 英语 ≥65% / 高数 ≥75% / 计算机 ≥80%，总分超公办线 20 分

### 每日节奏与每周轮换

- **19:00-22:10** 黄金时段（每晚固定，不受课表影响），番茄工作法（25+5），**最后一个番茄固定给 DeepTutor** 到期复习；22:10-22:20 每日复盘
- **16:00-18:30 白天机动段**：周二（上午空课）、周三（下午空）、周五（下午多空）可加 1-2 个番茄；周一下午空（11-13 周有劳动教育）；周四全天最满，白天休整
- 每周轮换：周一机动/补弱（上午满课）｜ 周二高数 ｜ 周三计算机 ｜ 周四全科错题复盘（不推新课）｜ 周五英语 ｜ 周六沉浸（上午英语背诵/作文，下午真题限时）｜ 周日政治 + 周复盘
- 英语词汇每日不断线（50 个/天）；错题三色分级：红=每周六复盘（二刷 ≥90%）、黄=半月回看、绿=考前一遍
- 课表依据：2026-2027-1 学期课表——周一 Java Web+机器视觉满上午，周四物联网+软件工程全天最满，周五上午满（3-6 周下午加形势与政策），**周六周日全空**；旧计划"周一全休"相应改为机动/补弱日
