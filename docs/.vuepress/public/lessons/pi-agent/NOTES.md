# NOTES.md — 教学偏好与工作笔记

## 学习者偏好（2026-07-13 确立）

- 语言：全程中文。
- 基础：接近零基础。解释新概念时先用生活类比，再给正式定义；代码示例必须逐行可懂。
- 节奏：每周 8–12 小时，2–3 课；每课 20–40 分钟可完成。
- 环境：Windows + Git Bash。命令示例优先给 PowerShell/Git Bash 通用形式。
- 动机驱动：面试导向。每节课尽量点出"这在面试中怎么考"，但不做题海——理解优先。

## 验收约定（grilling 确认）

- 概念课：HTML 内嵌小测，浏览器自动判分。
- 动手课：课末附验收清单 + 验证命令；学习者把输出贴回，老师审查代码后生成 `learning-records/` 记录。
- learning-record 在每课验收后由老师撰写，记录"做对了什么 / 踩了什么坑 / 下一步难度调整"。

## 课件产出约定（2026-07-24 grilling 确认）

每节新课产出时逐项自查：

1. **温故区**：课首 2–3 道来自前几课的 recall 回忆题（spacing + interleaving；第 1 课除外）。
2. **回忆挑战**：课末 1–2 道 recall 题（`assets/recall.js` 组件），要求默写/复述，不看正文作答。
3. **选择题**：正确答案在 a/b/c/d 间均衡分布；选项字数（尽量字符数）一致，不给任何格式线索；`data-explain` 无多余空白。
4. **导航**：底部双向"上一课/下一课" + 对应速查表 + GLOSSARY + 路线图/资料清单。
5. **速查表**：每课验收后更新或新增 `reference/*.html`（按主题而非按课切分），课件中链接到它。
6. **GLOSSARY**：术语验收通过后才入册 `GLOSSARY.md`；课件措辞以词汇表为准。
