TS 异步与 async/await

这页是"异步"的压缩精华：写异步代码卡住时先查这里，比翻课件快。

两条核心规则

关键字写在哪效果
async函数前面返回值自动包成 Promise（return string → 调用方拿到 Promise<string>）
awaitPromise 前面，且只能在 async 函数内暂停当前函数等结果、取出结果；不冻住整个程序

Promise 三种状态

状态含义
pending等待中，结果还没出来
fulfilled已成功，拿到结果
rejected已失败，拿到错误

最小骨架

// 造一张 ms 毫秒后兑现的小票
function wait(ms: number): Promise<void> {
  return new Promise((resolve) => setTimeout(resolve, ms));
}

async function greet(): Promise<string> {
  await wait(1000);         // 等 1 秒，程序其他部分照常运转
  return "你好，刘杰！";
}

async function main() {     // await 只能在 async 里，入口包一层壳
  console.log(await greet());
}

main();

异步版 Tool 骨架

export interface Tool {
  name: string;
  description: string;
  execute: (args: Record<string, any>) => Promise<string>;
}

async function runTool(name: string, args: Record<string, any>): Promise<string> {
  const tool = toolRegistry[name];
  if (!tool) return `错误：找不到名为 "${name}" 的工具`;
  return await tool.execute(args);
}

常见现象速查

现象 / 报错原因与对策
打印出 Promise { <pending> }忘了写 await——拿到的是小票不是结果
await 报错（不在 async 函数内）外层函数没标 async；文件顶层想用时包一个 async main() 再调用
类型报错：返回 string 赋给 Promise<string>函数忘了标 async；标上后 return string 会自动包成 Promise
一句话记住 Promise 是"未来结果的小票"；await 是"凭票取餐"——当前函数暂停，程序不冻住。
