函数进阶：数组传址、static 与递归

对应笔记 C语言/07-函数 · 教材 P175–223 · 约 15 分钟

学完这节课，你能做到：

① 用数组名作参数修改实参数组，并能说出二维数组形参为什么只能省第一维；② 判断 static 局部变量在多次调用中的取值变化；③ 写出带终止条件的递归函数，并能逐层追踪返回过程。

温故 · 第 9 课「函数基础」：普通变量作实参调用 swap(x, y) 后，x、y 会交换吗？为什么？
不会。传值调用是单向赋值，实参把值复制给形参，形参 a、b 各占独立空间，修改形参不影响实参。
温故 · 第 8 课「数组与字符串」：strlen 与 sizeof 有什么区别？字符串为什么不能直接用 == 比较？
strlen 统计字符个数，不含 '\0'；sizeof 求变量占用的总字节数，含 '\0'。用关系运算符比较字符串实际是在比较两个地址而不是内容，必须用 strcmp。

为什么这节课重要

数组传址、static 生命周期、递归终止条件是填空和程序阅读题的「重灾区」。你已经在基础轮见过它们，这节课把最容易混淆的边界拧清，直接对接阅读题与程序填空。

一、数组名作参数：不是复制，是共享同一片内存

数组元素作实参时，和普通变量一样单向传值；但数组名作实参时，传的是首元素地址，属于传址调用。

实参形式传递方式形参改变是否影响实参典型考点
a[i] 单个元素传值不影响同普通变量
a 数组名传首地址影响（共用内存）形参变，实参也变
&a[2]传某元素地址影响（从该位置开始）形参数组以 a[2] 为首元素

高频陷阱

形参写成 int a[10] 只是「看起来像数组」，编译器仍按指针处理，不会复制整个数组。形参数组的大小在 32 位机是 4 字节、64 位机是 8 字节，等于指针大小。

形参数组可以省略长度，写成 int a[]；二维数组作形参时，可省第一维，不可省第二维：

void f(int a[][3]);   /* 正确：第二维必须写 */
void f(int a[3][]);   /* 错误：第二维不能省 */

二、static 静态局部变量：四句话记牢

在函数内写 static int x = 1;，x 就是静态局部变量。它的行为和普通局部变量完全不同：

特点static 局部变量普通 auto 局部变量
生存期整个程序运行期不释放函数调用结束即释放
赋初值时机编译时只赋一次每次调用重新赋初值
不赋初值时自动为 0 或 '\0'不确定的随机值
作用域仍限于本函数内部限于本函数内部

另记 register（寄存器变量）：建议存放在 CPU 寄存器中（数量有限），不属于静态或动态存储区。

记忆口诀

「整个运行期不释放，编译赋初只一次，不赋初值自动零，仍限本函数引用。」

三、全局变量：默认 0，且会被局部同名变量屏蔽

先回忆局部变量：作用域从定义处开始有效，之前不可用；复合语句像一堵墙，其中定义的变量只在 {} 内有效，有同名变量时就近取用。命题辨析：「一个函数内的局部变量在该函数任何范围都可以引用」是错误说法——定义处之前不能引用。

  • 全局变量定义在所有函数之外，作用域从定义处到文件结束。
  • 不初始化时默认值为 0（局部 auto 变量不初始化才是随机值）。
  • 当全局变量与局部变量同名时，函数内部优先使用局部变量，全局变量被「屏蔽」。

四、递归：必须有终止条件，再逐层返回

递归是函数体内调用自身。写递归时先想终止条件，再想递推关系：

int f(int n) {
    if (n == 1) return 1;      /* 终止条件 */
    return f(n - 1) * n;       /* 递推调用，逐层返回 */
}

不带 return 的递归调用结束后，会回到调用处继续执行后面的语句（例如倒序输出各位数字）。无论哪种形式，缺少终止条件就会无限递归。

五、extern：声明不是定义

  • extern int x; 用来在全局变量定义之前扩展其作用域，是声明不是定义。
  • 声明不分配存储空间，扩展作用域后不可再次初始化。
  • 在函数内声明只在该函数内有效；在函数外声明则扩大到声明处之后。

易错辨析

extern int x; 与 int x = 10; 不同：前者只告诉编译器「别处已定义」，后者才是定义并分配空间。extern 后再次赋值初始化会出错。

六、先回忆，再自测

数组名作实参时，形参改变会影响实参吗？为什么？
会。数组名传的是首元素地址，形参数组与实参数组共用同一片内存单元，所以形参元素变化实参跟着变化。
static 局部变量和普通 auto 局部变量的三个核心区别是什么？
① static 整个运行期不释放，auto 调用结束释放；② static 编译时只赋一次初值，auto 每次调用重新赋；③ static 不赋初值自动为 0/'\0'，auto 不赋初值为不确定值。
递归函数必须满足哪两个条件？
① 必须有终止递归的条件；② 调用自身后必须能逐层返回，不能无限递归。

七、测验（点击选项作答）

1. 下列关于数组名作函数参数的说法，正确的是

  1. 形参会复制整个数组到函数中
  2. 形参与实参数组共用同一内存
  3. 形参数组大小等于数组总字节数
  4. 数组元素作实参也是传址调用

数组名作实参传的是首地址，形参已是指针，二者共用内存；数组元素作实参仍是单向传值。

2. 二维数组作函数形参时，正确的写法是

  1. int a[][3]
  2. int a[3][]
  3. int a[][]
  4. int a[3][3][]

二维数组作形参可省第一维，不可省第二维；第二维决定偏移计算，必须给出。

3. 函数内定义 static int x = 1;，该语句在多次调用中

  1. 每次调用都重新赋值为 1
  2. 只在第一次调用时分配空间
  3. 编译时只赋一次初值
  4. 函数外也能引用变量 x

static 局部变量在编译时赋初值且只赋一次，函数调用结束值仍保留，但作用域仍限于本函数。

4. 全局变量与局部变量同名时，函数内部使用的是

  1. 全局变量，局部被屏蔽
  2. 两个变量同时生效
  3. 编译时报错无法运行
  4. 局部变量，全局被屏蔽

同名时遵循「就近原则」，函数内优先使用局部变量，全局变量在该函数内被屏蔽。

5. 关于 extern int x; 的说法，正确的是

  1. 它定义了一个整型变量 x
  2. 它只是声明，不分配存储空间
  3. 它可以同时为 x 初始化
  4. 它只能在函数内部使用

extern 是声明不是定义，只扩展全局变量作用域，不分配空间，扩展后也不可再初始化。

6. 下列关于递归函数的说法，错误的是

  1. 递归调用必须带有 return 返回值
  2. 递归函数体内调用自身
  3. 递归必须有终止条件
  4. 递归满足条件后逐层返回

递归可以带 return（如阶乘），也可以不带 return（如倒序输出数字），但必须有终止条件并逐层返回。
