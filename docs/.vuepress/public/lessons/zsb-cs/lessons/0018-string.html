串

对应笔记 数据结构/14-串 · 教材 P33–35 · 约 10 分钟

学完这节课，你能做到：

① 说清串名、串值、串长、空串，并一眼分辨空串与空格串；② 背出子串个数公式 n(n+1)/2 + 1，算出任意长度串的子串总数；③ 讲出串与线性表的两点区别（数据对象限定字符集、操作以子串为单位）；④ 列出串的两种存储结构（定长顺序存储、堆分配存储）。

温故 · 第 17 课「数组、矩阵与广义表」：广义表 L=(a,(b,c)) 的表尾 GetTail(L) 是什么？
是 ((b,c)) 而不是 (b,c)。表尾是去掉第一个元素后，剩余元素加括号组成的表，表尾一定是广义表。
温故 · 第 16 课「栈和队列」：栈和队列分别按什么原则插删？位置在哪里？
栈按后进先出 LIFO，只在栈顶插入和删除；队列按先进先出 FIFO，在队尾 rear 插入、队头 front 删除。

为什么现在复习串

串是数据结构里内容最少的一章，但子串计数公式是选择题高频点——2025 年真题第 8 题直接考了「串 'studio' 中以 t 为首的子串个数」。这节课把定义、公式、易混点压成一页速查网，10 分钟拿下这一章的分。

真实缺口：本章是专项复习课浓缩版

串的精讲课件缺失，本章内容来自《专项-第2次课》复习课件中串部分的 8 页有效内容（该课件的其余部分为时间复杂度/二叉树复习，已并入第 14、15 章）。笔记已覆盖专项复习课的全部内容，考点够用，但深度不及其他章的精讲——这是课程的真实缺口，如实告诉你。

一、串的定义与三个基本概念

串（string）：由零个或多个字符组成的有限序列，记作 S = 'a₁,a₂,…,aₙ'（n≥0）。

  • S 是串名；单引号括起的字符序列是串的值；
  • n = 串长；n = 0 时为空串。
概念定义
子串串中任意多个连续的字符组成的子序列（串自身和空串也是串的子串）
串相等长度相等且每个对应位置的字符都相等
空格串由一个或多个空格组成的串——不是空串，长度 = 空格个数

空串 ≠ 空格串

空串长度为 0，里面一个字符都没有；空格串里装的是空格，长度 = 空格的个数。两者的唯一共同点是「都算串」，考试就爱在这里挖坑。

二、子串个数公式

以 S='software'（n=8）归纳：

类型公式说明
子串总数（含空串）n(n+1)/2 + 1加 1 表示空串
非空子串n(n+1)/2不含空串
真子串n(n+1)/2不含自身（若含空串再讨论）

对 n=8：子串总数 = 8×9/2 + 1 = 37；非空子串 = 36。

易错点

① 子串计数别忘 +1（空串也是子串）；② 串自身也是子串——别把它排除掉；③ 真子串、非空子串的口径要在读题时先分清「含不含空串、含不含自身」。

真题印证（2025 年第 8 题）

串 'studio' 中以 t 为首的子串个数为（　）A.2　B.5　C.6　D.7，答案 B。'studio' 长 6，t 是第 2 个字符，以它开头的连续子串一路延伸到串尾：t、tu、tud、tudi、tudio，共 5 个。这正是「连续字符子序列」定义的直接应用。来源：题库/真题-2025年广东省 第 8 题。

三、串的两种存储结构

结构说明
定长顺序存储类似线性表顺序存储——一组地址连续的存储单元存放字符序列
变长（堆）分配存储仍用地址连续的存储单元，但空间在程序执行过程中动态分配

四、串与线性表的区别

  • 逻辑结构极为相似，区别仅在：串的数据对象限定为字符集；
  • 操作层面差别大：线性表以单个元素为操作对象（查/插/删某元素），串通常以子串为操作对象（查找、插入、删除一个子串）——单个字符也属于子串。
易错点正确认识
空串 = 空格串不同——空格串长度 = 空格个数；空串长度 0
子串计数忘了空串总数 = n(n+1)/2 + 1
串的基本操作按单个字符串操作通常以子串为单位
串自身不算子串串自身和空串都是它的子串

五、先回忆，再自测

串、子串、空串、空格串分别怎么定义？
串：零个或多个字符组成的有限序列，n=0 时为空串；子串：串中任意多个连续字符组成的子序列（串自身和空串也是子串）；空格串：由一个或多个空格组成的串，长度 = 空格个数——它不是空串。
长度为 n 的串有多少个子串？非空子串、真子串的口径呢？
子串总数（含空串）n(n+1)/2 + 1；非空子串 n(n+1)/2；真子串 n(n+1)/2，不含自身（若含空串再讨论）。别忘了那个 +1。
串与线性表的区别是什么？
两点：① 数据对象限定为字符集；② 线性表以单个元素为操作对象，串通常以子串为操作对象。
串的两种存储结构？
定长顺序存储；变长（堆）分配存储——空间在程序执行过程中动态分配。

六、测验（点击选项作答）

1. 长度为 8 的串（如 'software'），它的子串总数（含空串）为

  1. 36
  2. 37
  3. 28
  4. 64

子串总数 = n(n+1)/2 + 1 = 8×9/2 + 1 = 37。选 36 是忘了空串那个 +1；64 是 2ⁿ 的干扰项。

2.（2025 真题第 8 题）串 'studio' 中以 t 为首的子串个数为

  1. 2
  2. 5
  3. 6
  4. 7

以 t 为首的连续子串：t、tu、tud、tudi、tudio，共 5 个，选 B。t 是第 2 个字符，从它到串尾共 6−2+1 = 5 个字符，每个结尾对应一个子串。

3. 关于空串与空格串，下列说法正确的是

  1. 空串就是空格串，两者长度都为 0，可互换使用
  2. 空格串的长度规定为 0，不含任何字符
  3. 空格串由一个或多个空格组成，长度等于空格个数
  4. 空串由一个空格组成，长度为 1，也称空白串

空格串不是空串：空格串由一个或多个空格组成，长度 = 空格个数；空串长度为 0，不含任何字符。

4. 串与线性表相比，下列说法正确的是

  1. 串的逻辑结构与线性表完全不同，属于非线性结构
  2. 线性表的操作通常以子串为单位进行插入删除
  3. 串的操作对象只能是单个字符，不能是子串
  4. 串的数据对象限定为字符集，操作通常以子串为单位

两者逻辑结构极为相似，区别仅在于串的数据对象限定为字符集；操作层面线性表按单个元素、串按子串（单个字符也属于子串）。

5. 串的两种存储结构是

  1. 定长顺序与堆分配存储
  2. 顺序存储与索引存储
  3. 链式存储与散列存储
  4. 定长链式存储与堆链式存储

串采用定长顺序存储（类似线性表顺序存储）与变长（堆）分配存储——后者空间在程序执行过程中动态分配。

6. 关于子串，下列说法正确的是

  1. 串自身和空串都是串的子串
  2. 空串不是串的子串
  3. 子串的字符允许不连续
  4. 子串的长度必须小于原串

子串是串中任意多个连续字符组成的子序列，串自身和空串也都算子串；字符必须连续，长度也可以等于原串。
