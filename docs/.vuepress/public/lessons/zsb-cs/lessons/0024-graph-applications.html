图的应用

对应笔记 数据结构/16-图 §4–6 · 约 15 分钟

学完这节课，你能做到：

① 一句话区分 Prim（加点法）与 Kruskal（选边法），并牢记两者都只针对无向图、结果不能有环；② 区分 Dijkstra（单源）与 Floyd（所有顶点对），写出 Floyd 的递推式；③ 按步骤对 AOV 网做拓扑排序，说明序列为什么可能不唯一、输出不完说明什么；④ 用「先求点、再求边」口诀算 ve/vl/e/l，找出 e=l 的关键活动并串出关键路径。

温故 · 第 23 课「图的基础与遍历」：无向完全图和有向完全图的边（弧）数各是多少？
无向完全图 n(n−1)/2 条边；有向完全图 n(n−1) 条弧——有向翻倍，每对顶点要方向相反的两条弧。
温故 · 第 22 课「赫夫曼树与编码」：WPL 的两种算法分别是什么？
算法一：Σ 每个叶子的权值 × 根到该叶子的路径长度（边数）；算法二：所有内部结点权值之和。两个结果应相等，可互相验算。

为什么这一课全是考点

上一课打好了概念与遍历的地基，这一课是图章大题高频区的核心：最小生成树（Prim/Kruskal）、最短路径（Dijkstra/Floyd）、拓扑排序、关键路径（ve/vl/e/l）都可能单独成一道手推大题。每个算法都只需要「几步流程 + 一两句口诀」，练熟两三个完整推演，大题就有底。

一、最小生成树：Prim 加点法与 Kruskal 选边法

⚠️ 课件强调

无论哪种算法，生成树一定不能有环！两种算法都只针对无向图。

算法基本思想记忆
Prim（普里姆）① 题目给定起点加入树；② 从树内所有顶点出发，选连接树内与树外且权值最小的边，把边和新顶点加入树；③ 重复直到全部顶点入树加点法
Kruskal（克鲁斯卡尔）每次从候选边中选权值最小的边并入生成树（不构成环），直到所有边检测完选边法

口诀

Prim「一棵树往外长」——每次一条边、拉进一个点；Kruskal「全局挑便宜边」——先排好序，逐条检查，成环就扔。n 个顶点的生成树恰好 n−1 条边。

二、最短路径：Dijkstra 单源与 Floyd 全对

算法解决问题思想
Dijkstra（迪杰斯特拉）单个源点到其余各顶点的最短路径从源点开始逐步扩展，每轮确定当前已知最短的路径；按路径长度递增次序产生
Floyd（弗洛伊德）所有顶点对之间的最短路径从初始邻接矩阵 D⁻¹ 开始，逐步引入中间结点，递推更新 n 阶矩阵

Floyd 核心递推（k 依次取所有中间点）：

D(A,B) = min( D(A,B), D(A,k)+D(k,B) )

  • Dijkstra 例（课件：以 a 为起点）：第 1 轮确定 (a,b)=2 → 第 2 轮经 b 更新 c=(a,b,c)=3、d=(a,b,d)=5 → 第 3 轮确定 e=(a,b,c,e)=7、f=(a,b,c,f)=4 …… 每轮输出一个「当前最短」的顶点。
  • Floyd 例（课件）：D(A,B)=min(9, 3+3)=6 → 再 min(6, 1+4)=5；矩阵从 D⁻¹→D⁰→D¹→… 逐轮更新，最终矩阵即所有顶点对的最短路径。

三、拓扑排序：AOV 网

AOV 网（活动在顶点上的网）：用有向图表示工程中各活动的先后关系，顶点 = 活动。

拓扑排序（针对有向无环图）的步骤：

  1. 从 AOV 网中选一个没有前驱（入度为 0）的顶点并输出；
  2. 从网中删除该顶点及其所有出边；
  3. 重复①②直到网空（若输出不完所有顶点 → 图中有环）。

拓扑序列可能不唯一。课件例：课程先修关系（C1…C12）有两个合法序列：

(C1, C2, C3, C4, C5, C7, C9, C10, C11, C6, C8, C12)
(C9, C10, C11, C6, C1, C12, C4, C2, C3, C5, C7, C8)

为什么重要

拓扑排序 + 逆拓扑排序是关键路径计算的基础：拓扑序用来求 ve，逆拓扑序用来求 vl，见下一节。

四、AOE 网与关键路径：ve/vl/e/l

AOE 网（边活动网）：顶点 = 事件（旧活动结束、新活动开始），弧 = 活动，弧上权 = 活动持续时间。

关键路径 = 完成整个工程的最耗时路径，其长度 = 最短工期；关键路径上的活动为关键活动：最早开始时间 = 最晚开始时间（e = l），不可拖延。

四个量：

记号含义
ve事件的最早开始时间（earliest）
vl事件的最晚开始时间（latest）
e活动（边）的最早开始时间
l活动（边）的最晚开始时间

计算口诀（课件总结）：

  1. 先求点：拓扑序求 ve（取最大，源点 ve=0）；逆拓扑序求 vl（取最小，汇点 vl=ve）；
  2. 再求边：边最早 e = 出发点的 ve；边最晚 l = 指向点的 vl − 边权；
  3. e == l 的活动是关键活动，串起来即关键路径。

课件例（V1…V6，工程 12 天）：

顶点V1V2V3V4V5V6
ve0258912
vl04581112

关键活动为 e=l 的那些——课件例中为 b、e、i，关键路径为 V1→V3→V4→V6，长 5+3+4=12 天；V2（ve=2、vl=4）与 V5（ve=9、vl=11）各有 2 天余量，不在关键路径上。判断时以 e=l 判据为准——课件流传的「V1→V2→V4→V5→V6」与自身 ve/vl 数据矛盾：关键路径上的事件必须 ve=vl（无余量）。

五、易错点对比（本课范围）

易错点正确认识
Prim/Kruskal 可用于有向图都是无向图的最小生成树算法
最小生成树可以有环生成树边数 = 顶点数 − 1，无环
拓扑序列唯一可能不唯一；且只有有向无环图才有拓扑序列

先回忆，再自测

Prim 和 Kruskal 的思想差别？共同前提是什么？
Prim 是加点法：从起点出发，每次选连接树内与树外且权值最小的边；Kruskal 是选边法：每次从候选边中选权值最小且不成环的边。共同前提：都只针对无向图，结果不能有环。
Dijkstra 与 Floyd 分别解决什么问题？Floyd 的递推式？
Dijkstra 求单个源点到其余各顶点的最短路径（按路径长度递增次序产生）；Floyd 求所有顶点对的最短路径。递推式：D(A,B) = min( D(A,B), D(A,k)+D(k,B) )，矩阵 D⁻¹→D⁰→D¹→…。
拓扑排序的步骤？什么图才有拓扑序列？输出不完说明什么？
每次选入度 0（无前驱）的顶点输出并删除它及其出边，循环到网空。只有有向无环图才有拓扑序列；若输出不完所有顶点，说明图中有环。序列可能不唯一。
ve、vl、e、l 怎么求？关键活动的判据是什么？
先求点：拓扑序求 ve 取最大（源点 ve=0），逆拓扑序求 vl 取最小（汇点 vl=ve）；再求边：e = 出发点的 ve，l = 指向点的 vl − 边权。e == l 的活动是关键活动，串起来即关键路径。

测验（点击选项作答）

1. 关于 Prim 算法求最小生成树，下列说法正确的是

  1. 每次从全部候选边中选权值最小且不成环的边
  2. 每次选入度为 0 的顶点输出并删除其出边
  3. 从起点出发，每次选连接树内与树外权值最小的边
  4. 按路径长度递增次序逐个确定各顶点的最短路径

Prim 是「加点法」：起点入树后，每轮从树内所有顶点出发，选连接树内与树外且权值最小的边，把边和新顶点拉进树。选边不成环是 Kruskal，拓扑排序选入度 0，递增次序产生路径是 Dijkstra。

2. 关于 Prim 与 Kruskal 两种算法，下列说法正确的是

  1. 都只适用于无向图，且生成树不能有环
  2. 都只适用于有向图，且生成树不能有环
  3. Prim 是选边法，Kruskal 是加点法
  4. 两种算法求出的最小生成树一定不同

课件强调：无论哪种算法，生成树一定不能有环，且两种算法都针对无向图。Prim 是加点法、Kruskal 是选边法，说反了就错。

3. Dijkstra 算法解决的问题是

  1. 所有顶点对之间的最短路径
  2. 无向连通图的最小生成树
  3. 有向无环图的拓扑序列
  4. 单个源点到其余各顶点的最短路径

Dijkstra 解决「单个源点到其余各顶点」的最短路径，按路径长度递增次序逐步扩展；「所有顶点对」是 Floyd 的问题。

4. Floyd 算法的核心递推公式是

  1. D(A,B) = max( D(A,B), D(A,k)+D(k,B) )
  2. D(A,B) = min( D(A,B), D(A,k)−D(k,B) )
  3. D(A,B) = D(A,k)+D(k,B)
  4. D(A,B) = min( D(A,B), D(A,k)+D(k,B) )

k 依次取所有中间点，比较「原路径」与「经过 k 的路径」取较小者：min( D(A,B), D(A,k)+D(k,B) )。课件例：D(A,B)=min(9, 3+3)=6 → min(6, 1+4)=5。

5. 做拓扑排序时，每一步应从 AOV 网中选出什么样的顶点输出

  1. 没有前驱（入度为 0）的顶点
  2. 没有后继（出度为 0）的顶点
  3. 入度最大的顶点
  4. 权值最小的顶点

拓扑排序每轮选入度 0（无前驱）的顶点输出，并删除该顶点及其所有出边；若输出不完所有顶点，说明图中有环。出度为 0 的顶点是逆拓扑序处理时先处理的。

6. AOE 网中，某个活动是关键活动的判据是

  1. 活动的 e 与 l 相等
  2. 活动的 e 等于其弧头事件的 ve
  3. 活动的 l 大于 e
  4. 活动所在路径的权值最小

关键活动：最早开始时间 = 最晚开始时间（e = l），一天都不能拖；关键路径是完成整个工程的最耗时路径，其长度等于最短工期。
