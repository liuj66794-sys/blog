查找

对应笔记 数据结构/17-查找 · 教材 P162–168、P175–184 · 约 15 分钟

学完这节课，你能做到：

① 写出 ASL = ΣPᵢCᵢ，并口算顺序查找 ASL成功=(n+1)/2；② 一眼说出折半查找的适用条件，画出判定树并给出树高 ⌊log₂n⌋+1；③ 用除留余数法选质数 p，并手动推演线性/平方探测与拉链法；④ 解释装填因子 α=n/m 与冲突的关系；⑤ 判断 BST 性质（中序递增）并完成双孩子结点的删除；⑥ 识别 AVL 失衡类型，选择 LL/RR/LR/RL 的旋转方式。

温故 · 第 24 课「图的应用」：Prim 和 Kruskal 求最小生成树的思想差别是什么？共同前提是什么？
Prim 是加点法：从起点出发，每次选连接树内与树外且权值最小的边；Kruskal 是选边法：每次从候选边中选权值最小且不成环的边。共同前提：都只针对无向图，结果不能有环。
温故 · 第 23 课「图的基础与遍历」：DFS 与 BFS 分别借助什么辅助结构？两种遍历序列唯一吗？
DFS 借助栈，口诀「不撞南墙不回头」；BFS 借助队列，按层扩展。两种遍历序列都可能不唯一，取决于邻接点的访问次序。

为什么现在复习查找

查找是广东专升本计算机大题高频区：散列表构造过程、ASL 计算、BST/AVL 插入与调整都可能单独成题。你已经学过一轮，这节课把「公式、条件、易混点」压成一张速查网。

一、ASL 与顺序查找

平均查找长度是衡量查找效率的主要指标：

ASL = Σ PᵢCᵢ  （等概率时 Pᵢ = 1/n）

Cᵢ 是找到第 i 个元素所需的比较次数。

方法适用结构ASL成功时间复杂度
顺序查找顺序表、链表(n+1)/2O(n)
折半查找有序的顺序表≈ log₂(n+1)−1O(log₂n)

速记

顺序查找「什么表都能用」，但效率最低；折半查找快，却必须同时满足「有序 + 顺序存储」——链表不支持随机存取，所以不能用折半。

二、折半查找的判定树

折半查找过程可画成一棵判定树：

  • 根 = (第一个序号 + 最后一个序号) / 2，向下取整；
  • 左子树、右子树递归同样画法；
  • 树高 = ⌊log₂n⌋+1；
  • 查找某元素所需的比较次数 = 该结点在判定树上的深度。

例：8 个元素 4,6,9,10,18,19,30,31（下标 1~8）。

  • 根 = (1+8)/2 = 4 → 关键字 10；
  • 左子树根 = (1+3)/2 = 2 → 6；右子树根 = (5+8)/2 = 6 → 19；
  • 找 9：10 → 6 → 9，共 3 次比较。

勘误提醒

课件中另印有算式 "1/11×(1+2×2+3×4+4×1)"，疑似对应 11 个元素的变式题。方法不变：ASL = 所有元素比较次数之和 ÷ 元素个数，不要被 11 这个数字带偏。

三、散列表：构造、冲突与性能

散列函数把关键字直接映射成地址；不同关键字映射到同一地址称为冲突，发生冲突的关键字互称同义词。

3.1 常用散列函数

方法公式要点
直接定址法H(key)=key 或 a×key+b关键字基本连续，否则空间浪费大
除留余数法H(key)=key % pp 取 ≤ 表长 m 的质数

3.2 处理冲突

开放地址法公式：Hᵢ = (H(key) + dᵢ) MOD m。

方法增量序列 dᵢ特点
线性探测1, 2, 3, …, m−1逐个往后找空位，易产生聚集
平方（二次）探测1², −1², 2², −2², …先加后减交替跳跃
拉链法同地址关键字链成链表适合插入/删除频繁的场景

3.3 一道完整推演

关键字 {32,75,63,48,94,25,36,18}，表长 m=11，H(key)=key MOD 11。

key3275634894253618
H(key)109846337
线性探测后位置109846357
比较次数11111131

ASL成功 = (1×7 + 3)/8 = 1.25。若用平方探测处理 36：3→(3+1²)=4 冲突→(3−1²)=2。

易错点

装填因子 α = n/m，α 越大表越满，冲突可能性越大。哈希查找效率同时取决于：哈希函数、处理冲突方法、装填因子。

四、二叉排序树 BST

定义：左子树 < 根 < 右子树；左右子树也必须是 BST。推论：中序遍历 BST 得到递增序列。

删除情况做法
叶子结点直接删除
只有左/右子树用其唯一孩子顶替
左右子树都有用左子树最大或右子树最小替换，再删那个替换结点

五、AVL 平衡二叉树

AVL 是特殊的 BST：每个结点的 |左高 − 右高| ≤ 1，平衡因子只能是 −1、0、1。失衡时旋转调整：

失衡类型插入位置旋转
LL左孩子的左子树右旋
RR右孩子的右子树左旋
LR左孩子的右子树先左旋成 LL，再右旋
RL右孩子的左子树先右旋成 RR，再左旋

口诀

BF 为正（左边高）→ 右旋；BF 为负（右边高）→ 左旋。折线型（LR/RL）先把下面扭成直线型，再按 LL/RR 旋一次。

六、先回忆，再自测

折半查找的判定树怎么画？树高是多少？
根 = (low+high)/2 向下取整，左右递归。树高 = ⌊log₂n⌋+1。想不起来就回头重看 8 个元素的例子。
线性探测与平方探测的增量序列分别是什么？
线性探测：dᵢ = 1,2,3,…,m−1；平方探测：dᵢ = 1²,−1²,2²,−2²,…。平方探测别忘了“先加后减交替”。
AVL 的 LL、RR、LR、RL 分别怎么旋转？
LL 右旋，RR 左旋；LR 先左旋再右旋，RL 先右旋再左旋。本质是把“折线”先扭成“直线”，再旋一次。

七、测验（点击选项作答）

1. 对长度为 11 的顺序表做等概率顺序查找，查找成功时的 ASL 为

  1. 5
  2. 5.5
  3. 11
  4. 6

顺序查找 ASL成功=(n+1)/2，代入 n=11 得 6。注意区分“平均比较次数”与“最多比较次数”。

2. 折半查找能够适用的数据结构必须满足

  1. 关键字有序且顺序存储
  2. 关键字有序且链式存储
  3. 只需顺序存储即可
  4. 只需关键字有序即可

折半查找需要随机存取，因此只适用于有序的顺序表；链表无法直接定位中间元素。

3. 散列表表长 m=15，用除留余数法 H(key)=key%p 时，p 最好取

  1. 15
  2. 14
  3. 12
  4. 13

除留余数法要求 p 取小于等于表长 m 的质数。15 以内最大质数是 13。

4. 关于散列表冲突处理，下列说法正确的是

  1. 平方探测的增量只往一个方向加
  2. 线性探测适合插入删除频繁的场合
  3. 拉链法最容易产生记录堆积
  4. 同义词指映射到同一地址的关键字

平方探测增量为 1²,−1²,2²,−2²…；频繁插删适合拉链法；线性探测易产生聚集。同义词定义正确。

5. 在 BST 中删除一个左右子树都非空的结点，正确的替换做法是

  1. 用左子树最大或右子树最小替换
  2. 用任意叶子结点替换
  3. 用右子树最大结点替换
  4. 直接删除并连接两个孩子

左子树最大（中序前驱）或右子树最小（中序后继）都能保证替换后仍满足左<根<右。

6. AVL 树中某结点的平衡因子为 −2，且失衡由右孩子的右子树插入引起，应执行

  1. 左旋
  2. 右旋
  3. 先左旋再右旋
  4. 先右旋再左旋

右孩子的右子树插入属于 RR 型，RR 型左旋。LL 型右旋，LR/RL 才需要两次旋转。
