指针基础与一维数组

对应笔记 C语言/08-指针 前半 · 教材 P224–P256 · 约 15 分钟

学完这节课，你能做到：

① 正确定义并初始化指针，说出基类型一致、只能赋地址两条硬性规则；② 用指针或数组名遍历一维数组，熟练互译 a+i、&a[i]、*(a+i)、a[i]；③ 写出能真正交换实参的传址版 swap；④ 一眼区分 *p++、*++p、(*p)++ 三者的运算顺序。

温故 · 第 10 课「函数进阶」：static 局部变量与普通 auto 局部变量有哪些核心区别？
static 变量整个程序运行期不释放、编译时只赋一次初值、不赋初值时自动为 0 或 '\0'；auto 变量函数调用结束即释放、每次调用重新赋初值、不赋初值时是不确定的随机值。两者作用域都仍限于本函数内部。
温故 · 第 9 课「函数基础」：执行 return (a, b); 时，函数实际返回几个值？值是什么？
只返回一个值。括号内是逗号表达式，其值等于最右边的操作数 b。

为什么现在巩固这个

指针是 C 语言贯穿数组、函数、字符串、结构体的核心工具，也是专升本选择题和程序阅读题的必考区。你已经学过一轮——这节课把「地址」「基类型」「指针算术」「传址交换」四个最基础的关节重新钉牢。

一、指针变量：存地址的变量

指针就是地址；指针变量是存放地址的变量。变量 p 中如果存了变量 a 的地址，就说 p 指向 a。

int a = 10;
int *p = &a;   /* p 只能存地址；&a 把 a 的地址交给 p */
运算符作用只能跟什么
&取地址变量，如 &a；&5 无意义
*取值地址/指针，如 *p；a 是普通变量时 *a 无意义

两条硬性规则

① 基类型必须一致：int a; float *p = &a; 非法。② 指针变量只能赋地址：int *p = 200; 非法；只有 int *p = 0; 或 int *p = NULL; 合法，表示指向零号地址。

二、指针与一维数组

数组名表示数组首元素地址，因此 int *p = a; 与 int *p = &a[0]; 完全等价。

2.1 地址与元素的等价关系

表达式含义
a + i / &a[i]第 i 个元素的地址
*(a + i) / a[i]第 i 个元素的值
p + i / &p[i]指针 p 后移 i 个元素后的地址
*(p + i) / p[i]该位置的元素值

指针算术不是字节算术

p + 1 不是加 1 字节，而是加 sizeof(基类型) 字节。int 型指针每次移动 4 字节，char 型指针每次移动 1 字节。同数组内两个指针相减得到的是元素个数差，而不是字节差；指针相加、相乘、相除均无意义。

2.2 用指针遍历数组

int a[5] = {1, 3, 5, 7, 9};
int *p = a;
for (int i = 0; i < 5; i++)
    printf("%d ", *(p + i));   /* 等价于 p[i]、a[i] */

也可以用 p++ 逐个移动指针，但注意：数组名 a 是地址常量，a++ 非法；指针变量 p 才可以自增。

指针挪动后「根据地」随之变化：p 后移（如 ++p）后，p[0] 就是原来的 a[1]——下标总是相对当前位置计算的。

三、三种 swap 辨析

写法能否交换 main 里的 a、b原因
void swap(int x, int y){ int t=x; x=y; y=t; }不能传值调用，形参是副本
void swap(int *x, int *y){ int *t=x; x=y; y=t; }不能只交换了形参指针的指向，没改目标值
void swap(int *x, int *y){ int t=*x; *x=*y; *y=t; }能通过 *x、*y 直接修改了实参变量的值

记忆口诀

想改外面的变量，就要拿到它的地址；拿到地址后还要用 * 去改里面的值，而不是把地址本身挪来挪去。

四、*p++ / *++p / (*p)++ 辨析

表达式运算顺序结果
*p++ / *(p++)先取 *p，再 p 后移得到当前值，指针指向下一个元素
*++p / *(++p)先 p 前移，再取 *p得到下一个元素的值
(*p)++先取 *p 参与运算，再把该值自增 1当前元素值加 1，指针不动
++(*p)先把 *p 自增 1，再使用当前元素值加 1，指针不动

五、先回忆，再自测

合上笔记，写出 & 与 * 的运算对象限制，并默写两条指针初始化硬性规则
& 后面只能跟变量；* 后面只能跟地址或指针。基类型必须一致；指针变量只能赋地址（0/NULL 除外）。
用指针 p 遍历 int a[5]，写出两种等价的输出 a[i] 的表达式
*(p + i) 与 p[i] 等价；*(a + i) 与 a[i] 也等价。注意 a 不能自增，p 可以自增。
三种 swap 中，哪种真正能交换 main 里的变量？核心代码是什么？
传址且通过 *x、*y 修改值的版本：void swap(int *x, int *y){ int t=*x; *x=*y; *y=t; }。只传值或只交换形参指向的版本都不行。

六、测验（点击选项作答）

1. 下列指针定义或初始化中，正确的是

  1. int a; float *p = &a;
  2. int *p = 200;
  3. int a; int *p = &a;
  4. int *p; *p = 10;

A 基类型不一致；B 把普通整数赋给指针；D 中 p 未指向具体地址就解引用赋值。C 基类型一致且用 & 取地址。

2. 已知 int a[5], *p = a; 下列代表 a[2] 地址的是

  1. p + 2
  2. *(p + 2)
  3. a[2]
  4. p[2]

p + 2 ≡ &a[2] 是地址；*(p+2)、a[2]、p[2] 都是元素的值。

3. 能真正交换 main 函数中两个 int 变量值的 swap 是

  1. void swap(int x,int y){int t=x;x=y;y=t;}
  2. void swap(int *x,int *y){int *t=x;x=y;y=t;}
  3. void swap(int *x,int *y){int t=*x;*x=*y;*y=t;}
  4. void swap(int x,int y){int *t=&x;*t=y;t=&y;*t=x;}

A 是传值，只改副本；B 只交换形参指针的指向；D 仍是对形参副本操作。C 用 *x、*y 修改了实参地址里的值。

4. 执行 int a[3]={1,3,5},*p=a; printf("%d",*p++); 输出为

  1. 1
  2. 3
  3. 5
  4. 不确定

*p++ 是后置形式：先取当前 *p（即 a[0]=1）输出，然后再把 p 后移一位。

5. 对同一数组内的两个 int* 指针 p1、p2，p2 - p1 的值表示

  1. 两地址的字节差
  2. 两元素的下标差
  3. 两指针占用的字节数
  4. 数组元素的总字节数

指针相减按基类型步长折算，结果是两指针之间相隔的元素个数，不是字节数。

6. 关于数组名作函数参数，下列说法正确的是

  1. 数组名传递的是整个数组的副本
  2. 形参数组名完全等价于同长度数组
  3. 在函数中改 arr[i] 即改 a[i]
  4. 实参只能写数组名不能写指针

数组名作实参传的是首元素地址，形参本质是指针；因此 arr[i] 与 a[i] 是同一单元。实参可以是数组名或指针，四组组合均合法。
