为什么这节课重要

一、存储单位：bit 与 Byte

计算机内部，数据以二进制形式存储和运算。最小单位是 bit（位），数据处理和存储容量的基本单位是 Byte（字节）。

换算说明
1 Byte = 8 bitbit 是最小单位
1 KB = 1024 B = 2¹⁰ B千字节
1 MB = 1024 KB = 2²⁰ B兆字节
1 GB = 1024 MB = 2³⁰ B吉字节
1 TB = 1024 GB = 2⁴⁰ B太字节

二、数制与转换

四个概念：数码、基数、位权、尾符。

进制数码基数尾符
二进制0~12B
八进制0~78O/Q
十进制0~910D
十六进制0~9、A~F16H

转换口诀：

  • 非十进制 → 十进制：乘权求和。例：1101B = 1×2³+1×2²+0×2¹+1×2⁰ = 13D。
  • 十进制 → 非十进制：整数 除 N 取余，倒序输出；小数 乘 N 取整，正序输出。
  • 二进制 ↔ 八进制：每 3 位二进制 = 1 位八进制。
  • 二进制 ↔ 十六进制：每 4 位二进制 = 1 位十六进制。

简答常考

175D = 10101111B = 257Q = AFH。要能写出除基取余的过程。

三、数据类型与原反补码

基本类型中先死记这四个：

类型字节位数范围
char18-128 ~ 127（-2⁷ ~ 2⁷-1）
unsigned char180 ~ 255（0 ~ 2⁸-1）
int / long432-2³¹ ~ 2³¹-1
float432约 6 位有效数字
double864约 15 位有效数字

易错点

实型常量如 3.14 默认按 double 处理，不是 float；写 3.14f 或 3.14F 才是 float。

原码、反码、补码

  • 最高位是符号位：0 正 1 负。
  • 无符号整数：二进制原样存储；有符号整数：补码存储；字符：ASCII存储。
  • 正数：原码 = 反码 = 补码。
  • 负数：反码 = 符号位不变，数值位取反；补码 = 反码 + 1。

例：-11（8 位）

码值
原码10001011
反码11110100
补码11110101

特殊值

8 位有符号数中，-128 只有补码 10000000，没有原码和反码。

char 溢出回绕

char 范围 -128~127，超出后按 ±256 回绕：

  • char c = 128; → 输出 -128（128 - 256 = -128）
  • char c = -129; → 输出 127（-129 + 256 = 127）
  • unsigned char c = -1; → 输出 255（补码 11111111 按无符号读 = 2⁸-1）

四、常量与标识符

整型常量

进制特征合法例非法例
十进制普通数字100、-12—
八进制0 开头，数码 0~7066、023L66（缺 0）、08C2（含 8/C）
十六进制0x/0X 开头0x66、0xACFA8（缺前缀）、0x8CG（含 G）

实型常量

  • 十进制形式：3.14、.2、-9.，口诀是「点的一侧要有数」。
  • 指数形式 aEn：口诀是「e 前 e 后要有数，e 后必须是整数」。如 3.14e2、.7e-2 合法；7e0.0、6e 不合法。

字符与字符串

对比'a'"a"
引号单引号双引号
内存1 字节2 字节（含结束符 '\0'）
含义整型值（ASCII 码）地址值

⚠️ 勘误提醒

'\101' 是字符型，内存占 1 字节；0101 是整型八进制常量，占 4 字节。两者不要混淆。

标识符

用户自定义标识符规则：

  1. 只能由字母、数字、下划线组成。
  2. 数字不能开头。
  3. 不能用关键字。
  4. 区分大小写（Int 合法，int 不合法）。

高频陷阱

9_hool（数字开头）、he.llo（含点）、x￥yz（含￥）、int（关键字）、Text-0（含减号）均不合法。

五、先回忆，再自测

合上笔记默写：十进制转非十进制的口诀、175 的三种进制表示
整数部分「除 N 取余，倒序输出」；小数部分「乘 N 取整，正序输出」。175 = 10101111B = 257Q = AFH。
负数的反码、补码怎么求？-11 的 8 位原码、反码、补码各是什么？
反码：符号位不变，数值位取反；补码：反码 + 1。-11：原码 10001011、反码 11110100、补码 11110101。
用户标识符的三条硬规则是什么？判断 _buy_2、2_buy、Int、char 的合法性
字母/数字/下划线组成、数字不开头、不用关键字（区分大小写）。_buy_2 ✓、2_buy ✗（数字开头）、Int ✓、char ✗（关键字）。

六、测验（点击选项作答）

1. 十进制 175 对应的二进制、八进制、十六进制是

  1. 10101111B、257Q、AFH
  2. 10101111B、267Q、AFH
  3. 10111111B、257Q、AFH
  4. 10101111B、257Q、AEFH

175 除 2 取余得 10101111B；三位一组得 257Q；四位一组得 AFH。

2. 下列整型常量中，合法的是

  1. 08C2
  2. 0x8CG
  3. 066
  4. A8

八进制以 0 开头且只能含 0~7；十六进制以 0x 开头且只能含 0~9/A~F；A8 缺少 0x 前缀。

3. 下列实型常量中，不合法的是

  1. .7e-2
  2. 3.14e2
  3. 7e0.0
  4. -9.

指数形式要求 e 后必须是整数，7e0.0 违反此规则；.7e-2、3.14e2、-9. 均合法。

4. 8 位有符号数 -11 的补码是

  1. 10001011
  2. 11110100
  3. 11110101
  4. 11110110

-11 原码 10001011，数值位取反得反码 11110100，加 1 得补码 11110101。

5. 执行 char c = 128; printf("%d", c); 的输出是

  1. 128
  2. 0
  3. -128
  4. 127

char 上限为 127，128 上溢后按 128 - 256 = -128 回绕。

6. 下列用户标识符中，合法的是

  1. 2_buy
  2. int
  3. _buy_2
  4. Text-0

2_buy 数字开头，int 是关键字，Text-0 含减号，均不合法；_buy_2 符合字母/数字/下划线且非关键字。
