选择结构：条件、短路规则与 if

对应笔记 C语言/04-选择结构程序设计 · 题库 题库/选择结构程序设计-章节练习 · 教材 P87–110 · 约 15 分钟

① 正确计算含 &&、||、++ 副作用的程序阅读题，并判断哪些操作被短路；② 识别 if(x) 与 if(x!=0)、if(!x) 与 if(x==0) 的等价关系；③ 写出用 if-else-if 实现的分段函数，并画出 else 的配对关系。

温故 · 第 3 课「运算符与表达式」：优先级骨架链是什么？哪三档运算符是右结合？
括号/下标 > 单目 > 算术 > 移位 > 关系 > 位（与>异或>或）> 逻辑 > 条件 > 赋值 > 逗号。右结合：单目、?:、赋值（含复合赋值）。

为什么这一课这么关键

选择结构是程序阅读题的三大题源之一（另外两个是循环和 switch）。广东省专升本真题里，短路规则、else 配对、等价形式反复出现，而且 loves 把 ++ 藏在被短路的右侧。

一、关系与逻辑表达式：值只有 0 或 1

关系运算符有 6 个，左结合，分两个优先级：

档次运算符优先级记忆
高> >= < <=6先算大小
低== !=7再算相等

完整优先级链（高 → 低）：

!  →  算术(* / % + -)  →  关系(> >= < <= == !=)  →  &&  →  ||  →  赋值(=)

最高频陷阱

关系/逻辑表达式的值只有 0 或 1，不是 true/false；C 语言里非 0 即真。数学式 10 < a < 15 在 C 中是 (10 < a) < 15，结果恒为 1；判断范围必须写 a > 10 && a < 15。

例（a=10, b=20, c=30）：

  • a < b < c → (a < b) < c → 1 < 30 → 1
  • a + b >= c → 30 >= 30 → 1
  • 'a' == 'b' → 97 == 98 → 0

二、短路规则：右侧可能「白写」

运算符短路条件结果
&&左侧为 0（假）右侧不执行，整体为 0
||左侧非 0（真）右侧不执行，整体为 1

判断口诀

&&「一假俱假」；||「一真皆真」。只要左边已经能决定结果，右边就直接跳过——所以右边的自增、赋值、函数调用可能根本不发生。

例：

  • b && a++（b=0）：值为 0，a++ 不执行。
  • a || b++（a=10）：值为 1，b++ 不执行。
  • !a + 0 && b || c++（a=0, b=1, c=0）：((!a + 0) && b) || c++ → (1 && 1) || c++ → 1 || … → 值 1，c++ 被短路，c 仍为 0。

⚠️ 勘误提醒

部分旧版题库对含短路的答案有误。例如 (m=a==b)||(n=c==d) 在全零变量下，m=1、|| 左真短路，n 保持 0，答案为 1,0。遇到与笔记结论冲突的旧答案，以源笔记为准。

三、if 单分支、双分支与多分支

// 单分支
if (表达式) 语句;

// 双分支
if (表达式) 语句1;
else       语句2;

// 多分支（分段函数常用）
if (表达式1) 语句1;
else if (表达式2) 语句2;
else if (表达式3) 语句3;
else              语句4;

注意：

  • if 的「内嵌语句」只能有一条；多条必须用 { } 包成复合语句。
  • else 前面必须紧邻同一条 if，中间不能隔别的语句，否则报错 else without a previous if。
  • 多分支从上到下匹配，只执行其中一条。

分段函数示例（符号函数）：

if (x > 0)      y = 1;
else if (x == 0) y = 0;
else            y = -1;

四、条件等价与 else 配对

写法等价形式含义
if (x)if (x != 0)x 非零则执行
if (!x)if (x == 0)x 为零则执行

「零值」陷阱表：

表达式逻辑值说明
0、0.0、NULL、'\0'0真正的「零」
'0'、"0"1字符 '0' 的 ASCII 是 48

两个致命混淆

if (a = 0) 是赋值，结果恒为 0，条件恒不成立；if (a = b) 把 b 赋给 a，条件值是 b 的逻辑值。比较必须用 ==。

else 配对规则：C 规定 else 总是与它前面最近的、尚未配对的 if 配对，与缩进无关。花括号可以把内层 if-else 包起来，让外层 else 与更外层的 if 配对。

三、先回忆，再自测

合上笔记默写：优先级链（从 ! 到赋值）和短路规则
优先级：! > 算术 > 关系 > && > || > 赋值。短路：&& 左假右不算；|| 左真右不算。右侧的自增/自减/赋值可能不执行。
if(x) 与 if(!x) 分别等价于什么？写错会发生什么？
if(x) ≡ if(x!=0)；if(!x) ≡ if(x==0)。把 == 写成 = 会变成赋值，导致条件恒真或恒假。
else 配对看缩进还是看语法？如何用花括号改变配对？
else 与前面最近的未配对 if 配对，和缩进无关。用 { } 把内层 if-else 包住，可让外层 else 只能与更外层的 if 配对。

四、测验（点击选项作答）

1. 下列运算符中优先级最低的是

  1. 逻辑与 &&
  2. 等于 ==
  3. 不等于 !=
  4. 逻辑或 ||

优先级：关系（6/7 级）> &&（11 级）> ||（12 级），四者中 || 最低。赋值比 || 还低，但不在选项中。

2. 执行 int a=1,b=2; (a=0)&&(b++); 后，a、b 的值分别是

  1. a=0, b=2
  2. a=0, b=3
  3. a=1, b=2
  4. a=1, b=3

a=0 使 && 左侧为 0，发生短路，右侧 b++ 不执行，故 b 仍为 2。

3. 已知 a=0,b=1,c=0，表达式 !a+0 && b || c++ 的值及 c 的最终值为

  1. 0，c=0
  2. 1，c=0
  3. 1，c=1
  4. 0，c=1

按优先级加括号：((!a+0) && b) || c++ → (1 && 1) || c++ → 1 || …，|| 左真短路，c++ 不执行，表达式值为 1。

4. 下列写法中，与 if(x) 功能不同的是

  1. if(x!=0)
  2. if(!x==0)
  3. if(x==0)
  4. if(x>0||x<0)

if(x) 等价于 if(x!=0)；B 中 !x==0 即 x 非零；D 对整数也等价。C 在 x 为零时才执行，与原式相反。

5. 当 a=1,b=3,c=5,d=4 时，执行下面程序段后 x 的值是

if(a<b)
    if(c<d) x=1;
    else
        if(a<c)
            if(b<d) x=2;
            else x=3;
        else x=6;
else x=7;
  1. 1
  2. 2
  3. 3
  4. 7

a<b 成立 → c<d（5<4）不成立 → 进入 else → a<c（1<5）成立 → b<d（3<4）成立 → x=2。

6. 阅读下列代码，输出结果是

int x=3, y=2;
if(x>y)
    if(x==3) printf("A");
else printf("B");
  1. 输出 A
  2. 输出 B
  3. 输出 AB
  4. 编译错误

else 与最近的未配对 if（即 if(x==3)）配对。x>y 成立且 x==3 成立，执行 printf("A")，else 分支不执行。
