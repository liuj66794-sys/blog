# TypeScript 类型与接口

**阶段 0 · 模块 A（TypeScript 起步）· 第 2 课 ｜ 预计 35 分钟 ｜ 前置：第 1 课**

这节课结束时，你会用 `interface` 定义一个"工具"的形状，并写出一个类型安全的工具注册表——这是 PatchPilot 的 Tool 系统的雏形。

::: info 为什么学这个 · Mission 关联

Agent 的核心能力之一就是**工具调用**：读文件、改代码、跑命令……每个工具都有名字、描述、参数格式、执行函数。TypeScript 的 `interface` 正是描述"一个工具长什么样"的最佳工具。学完这节课，你看 pi 源码里的 `Tool` 定义时就不会懵。

:::

## 1. 从生活中的"形状"说起

想象你要寄一个快递，快递公司规定包裹必须包含：收件人姓名、手机号、地址。如果缺一个，系统就拒收。这个"必须包含哪些字段"的规定，就是包裹的**形状（shape）**。

在 TypeScript 里，`interface` 就是用来描述对象形状的：

```
<code>interface Package {
  receiver: string;
  phone: string;
  address: string;
}</code>
```

一旦有了 `Package`，你就可以规定"这个变量必须是一个 Package"：

```
<code>const pkg: Package = {
  receiver: "刘杰",
  phone: "13800138000",
  address: "火星市软件园"
};</code>
```

如果你漏写 `phone`，TypeScript 会在保存/运行前就告诉你："你的对象不符合 Package 的形状。"这就是类型安全。

## 2. 常用基础类型

这些类型你在写 Agent 代码时会天天见到：

| 类型 | 含义 | 例子 |
| --- | --- | --- |
| `string` | 字符串 | `"hello"` |
| `number` | 数字 | `42`, `3.14` |
| `boolean` | 布尔 | `true`, `false` |
| `string[]` | 字符串数组 | `["a", "b"]` |
| `any` | 任意类型（关闭类型检查） | 尽量少用，作为临时占位 |

## 3. 用 interface 描述一个 Tool

现在我们来定义 PatchPilot 里的一个工具应该长什么样：

```
<code>interface Tool {
  name: string;
  description: string;
  execute: (args: Record<string, any>) => string;
}</code>
```

逐行看懂它：

- `name: string` —— 工具名，字符串。
- `description: string` —— 工具描述，也是字符串。Agent 会把这个描述塞给大模型，告诉它这个工具能干什么。
- `execute: (args: Record<string, any>) => string` —— 工具的执行函数。它接收一个参数对象（`args`），返回一个字符串。`Record<string, any>` 表示"键是字符串、值暂时不限"的参数包；`=> string` 表示函数返回字符串。

注意：这里用 `any` 是临时妥协。后续我们会学到更安全的 `unknown` 和具体参数 schema，现在先用 `any` 把形状搭起来。

## 4. 实现两个工具并放进注册表

有了 `Tool` 形状，我们可以造两个真正的工具：

```
<code>const calculator: Tool = {
  name: "calculator",
  description: "计算两个数的和",
  execute: (args) => {
    const result = Number(args.a) + Number(args.b);
    return `结果是 ${result}`;
  }
};

const greeter: Tool = {
  name: "greeter",
  description: "向指定的人问好",
  execute: (args) => {
    return `你好，${args.name}！`;
  }
};</code>
```

再把它们放进一个**注册表（registry）**里——这是 Agent 查"我有哪些工具"的地方：

```
<code>const toolRegistry: Record<string, Tool> = {
  calculator,
  greeter,
};</code>
```

然后写一个调度函数，按名字找到工具并执行：

```
<code>function runTool(name: string, args: Record<string, any>): string {
  const tool = toolRegistry[name];
  if (!tool) {
    return `错误：找不到名为 "${name}" 的工具`;
  }
  return tool.execute(args);
}

console.log(runTool("calculator", { a: 3, b: 5 }));
console.log(runTool("greeter", { name: "刘杰" }));</code>
```

## 5. 可选属性与 readonly

有些字段不是必须的。比如工具可以有一个 `category` 分类，没有也行：

```
<code>interface ToolV2 {
  name: string;
  description: string;
  category?: string;          // ? 表示可选
  readonly id: string;        // readonly 表示创建后不可修改
  execute: (args: Record<string, any>) => string;
}</code>
```

`readonly` 在 Agent 代码里很重要：比如工具 ID 注册后不应该被中途改掉。TS 会替你守着这条规则。

::: warning 动手任务（验收清单）

1. 在 `ts-playground` 目录下新建 `tools.ts`。
2. 定义一个 `Tool` interface，包含 `name`、`description`、`execute`。
3. 实现至少两个工具：`calculator`（两数相加）和 `greeter`（按名字问好）。
4. 用 `Record<string, Tool>` 把它们放进 `toolRegistry`。
5. 写 `runTool(name, args)`，并调用两次：一次 `calculator`（a=10, b=20），一次 `greeter`（name=你的名字）。
6. 运行 `npx tsx tools.ts`，看到两条输出。
7. **加一个类型错误实验**：把 `runTool("calculator", { a: 10, b: 20 })` 改成 `runTool("calculator", 10)`，运行 `npx tsx tools.ts`，看看报错说了什么，再把代码改回去。

**贴回给我**：① `npx tsx tools.ts` 的正常运行输出（两条）；② 第 7 步的类型报错信息；③ 用一句话解释 `Record<string, Tool>` 是什么意思。

:::

## 小测

**1. TypeScript 中 `interface` 最适合描述什么？**

- A. 任意的类型别名
- B. 对象的结构形状
- C. 函数的异步行为
- D. 代码的执行顺序

::: details 点开核对答案

**答案：B（对象的结构形状）** —— interface 专门描述对象的结构形状，是 Agent Tool 定义的最佳选择。

:::

**2. 下面哪个说法是正确的字符串数组类型？**

- A. 字符串数组用方括号
- B. 字符串数组用小括号
- C. 数组类型必须加逗号
- D. 数组元素不能赋值

::: details 点开核对答案

**答案：A（字符串数组用方括号）** —— string[] 是 TS 中字符串数组的写法，方括号是数组类型标记。

:::

**3. Agent 工具系统里为什么要给 tool schema 做类型标注？**

- A. 运行时让代码更快
- B. 使打包体积更小
- C. 自动生成 API 文档
- D. 编译期发现参数错误

::: details 点开核对答案

**答案：D（编译期发现参数错误）** —— 类型标注在编译期就能发现参数错误，是 Agent 工具系统可靠性的第一道防线。

:::

**4. `function greet(name: string): string` 中第二个 `: string` 表示？**

- A. 参数类型字符串
- B. 函数名是字符串
- C. 函数返回字符串
- D. 调用时才报错

::: details 点开核对答案

**答案：C（函数返回字符串）** —— function greet(name: string): string 中第二个 : string 表示函数返回值的类型。

:::

**2. 面试模拟：用一两句话向面试官解释，什么是对象的"形状"？**

::: details 显示答案

形状是一个对象"必须包含哪些字段、每个字段是什么类型"的整体结构；TypeScript 用 interface 描述形状，不符合形状的对象在运行前就会被拦下。

:::

::: info 面试怎么考

面试里不会直接考 "interface 是什么"，但会考"你怎么保证 Agent 调用工具时参数不报错"——答案之一就是：用 TS interface / schema 在编译期和运行时两层校验参数形状。这节课是你回答这类问题的底层基础。

:::
