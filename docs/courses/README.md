## 学习方式

每门课程遵循三段式学习法：

1. **20 分钟输入**：读讲义，理解核心概念
2. **15 分钟动手**：完成讲义中的练习与随堂测
3. **5 分钟费曼**：脱稿复述，讲不顺的进「未懂清单」回炉

学习记录同步到 [博客](/blog/)，参考资料与总纲沉淀在 [知识库](/knowledge/)。
