# 课程4：军队建设关键事件

**对应错题：第22题 ｜ 预计学习时长：15分钟**

> 本文为站内全文版（已纳入搜索，随堂测为折叠核对）。随堂测可点击作答的交互版：[**打开讲义**](/blog/lessons/policy/lessons/0004-military-building.html){target="_blank"}

## 学习目标

::: info

完成本课后，你将能够：

- 区分"三湾改编"与"古田会议"在军队建设中的不同贡献
- 记住"组织上"= 三湾，"思想上"= 古田
- 理清从南昌起义到古田会议的建军逻辑链

:::

## 核心知识点

### 建军逻辑链（1927-1929）

**1927.8.1 南昌起义** —— 打响第一枪 → 有了军队，但还不懂怎么"管"

**1927.9 秋收起义** —— 毛泽东领导 → 起义失败后向农村转移

**1927.9底 三湾改编 ⭐** —— **组织上**确立党对军队领导 核心措施：**"支部建在连上"** = 建设新型人民军队的**开端**

**1929 古田会议 ⭐** —— **思想上**确立建军原则 核心内容：**思想建党、政治建军** = 解决"军队为谁打仗"的思想问题

### 关键辨析：三湾 vs 古田

::: info

**三湾改编（1927）**

关键词：**组织上**

做了什么：建立党的各级组织，支部建在连上

解决了：党能不能"指挥得动"军队

地位：新型人民军队的**开端**

:::

::: info

**古田会议（1929）**

关键词：**思想上**

做了什么：确立思想建党、政治建军原则

解决了：军队"为什么打仗"的思想问题

地位：建军纲领性文件

:::

::: tip

**审题关键词：**

• 看到"**组织上**" → 三湾改编

• 看到"**思想上/政治建军**" → 古田会议

• 看到"**开端/开始**" + 军队 → 三湾改编

• 看到"**第一枪**" → 南昌起义

:::

### 你的错题复盘

::: danger

**第22题：**从组织上确立党对军队领导，建设新型人民军队开端的是？

你选A（秋收起义），正确B（三湾改编）

**错因：**秋收起义和三湾改编时间太近（只差几天），容易混为一体。但秋收起义是"打仗"，三湾改编是"改编/整顿"——题目问的是"确立领导制度"，不是"打仗"。

**纠正：**秋收起义失败后，部队在三湾村进行改编，**改编**才是制度建设。"起义"是军事行动，"改编"是组织变革。

:::

::: tip 记忆口诀

"南昌第一枪，秋收转农村；

三湾建组织，古田立思想。"


**简化记忆：**"三组古思" —— 三湾=组织，古田=思想

:::

## 即时练习

**1. "支部建在连上"这一制度确立于？**

- A. 南昌起义
- B. 三湾改编
- C. 古田会议
- D. 秋收起义

::: details 点开核对答案

**答案：B（三湾改编）**

:::

**2. 确立"思想建党、政治建军"原则的是？**

- A. 三湾改编
- B. 古田会议
- C. 遵义会议
- D. 八七会议

::: details 点开核对答案

**答案：B（古田会议）**

:::

**3. 打响武装反抗国民党反动派第一枪的是？**

- A. 南昌起义
- B. 秋收起义
- C. 广州起义
- D. 三湾改编

::: details 点开核对答案

**答案：A（南昌起义）**

:::
