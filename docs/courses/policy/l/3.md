# 课程3：党的建设与方针辨析

**对应错题：第24题、第26题、第27题 ｜ 预计学习时长：20分钟**

> 本文为站内全文版（已纳入搜索，随堂测为折叠核对）。随堂测可点击作答的交互版：[**打开讲义**](/blog/lessons/policy/lessons/0003-party-building.html){target="_blank"}

## 学习目标

::: info

完成本课后，你将能够：

- 记住"思想建设"是党的建设的首位/基础
- 准确匹配四大"八字方针"与其适用对象
- 在考试中通过"判断对象"快速选对方针

:::

## 核心知识点

### 知识点一：党的建设首位 = 思想建设

毛泽东建党思想的最大特色：**思想建党**放在首位。

::: info

**为什么是思想建设而非组织建设？**

因为中国革命的特殊性：党员大多来自农民和小资产阶级，他们带着各种非无产阶级思想入党。如果不先解决思想问题，组织再严密也没用。所以毛泽东强调"思想上入党"比"组织上入党"更重要。

:::

::: danger

**❌ 你的直觉**

"有组织才有党" → 组织建设是基础

:::

::: tip

**✅ 正确答案**

思想建设 = 基础性建设 = 首位

（先统一思想，再建组织）

:::

### 知识点二：四大八字方针对照

这是你错得最多的地方（第26、27题都错在这里）。核心方法：**先判断对象，再选方针**。

| 适用对象 | 方针 | 记忆线索 |
| --- | --- | --- |
| **党内**斗争/整风 | 惩前毖后、治病救人 | "治病"= 对同志像对病人 |
| 党与**民主党派** | 长期共存、互相监督 | "共存"= 多个党一起存在 |
| **科学文化**工作 | 百花齐放、百家争鸣 | "百花/百家"= 文艺/学术 |
| **人民内部**矛盾 | 团结—批评—团结 | "团结"= 对人民要团结 |

::: tip

**解题三步法：**

① 看题目问的是谁和谁的关系/矛盾

② 判断对象类别（党内？党外？文化？人民？）

③ 从表格中选对应方针

:::

### 你的错题复盘

::: danger

**第24题：**革命年代党的建设首位？你选A（组织建设），正确B（思想建设）

**纠正：**思想建设 = 基础性建设 = 永远排第一。这是毛泽东建党思想的核心特色。

:::

::: danger

**第26题：**对待党内斗争的方针？你选D（长期共存互相监督），正确B（惩前毖后治病救人）

**纠正：**"长期共存"是党与**民主党派**的关系，不是党内！党内斗争 = 治病救人。

:::

::: danger

**第27题：**处理党与民主党派关系的方针？你选A（百花齐放百家争鸣），正确B（长期共存互相监督）

**纠正：**"百花齐放"是**科学文化**方针！民主党派 = 多党合作 = 长期共存。

:::

## 即时练习

**1. 革命年代，党的建设必须放在首位的是？**

- A. 组织建设
- B. 思想建设
- C. 作风建设
- D. 制度建设

::: details 点开核对答案

**答案：B（思想建设）**

:::

**2. "百花齐放、百家争鸣"方针适用于？**

- A. 党内斗争
- B. 党与民主党派关系
- C. 科学文化工作
- D. 人民内部矛盾

::: details 点开核对答案

**答案：C（科学文化工作）**

:::

**3. 处理人民内部矛盾的公式是？**

- A. 惩前毖后、治病救人
- B. 长期共存、互相监督
- C. 百花齐放、百家争鸣
- D. 团结—批评—团结

::: details 点开核对答案

**答案：D（团结—批评—团结）**

:::

**4. 延安整风运动中对待犯错误同志的方针是？**

- A. 惩前毖后、治病救人
- B. 长期共存、互相监督
- C. 统筹兼顾、适当安排
- D. 团结—批评—团结

::: details 点开核对答案

**答案：A（惩前毖后、治病救人）**

:::

::: tip 记忆口诀

"思想首位不动摇，四大方针记对象：

党内治病党外存，文化百花矛盾团。"

:::

## 阶段检测建议

::: tip

随机抽问以下任一对象，你能在3秒内说出方针即过关：

- 党内斗争 → ？
- 民主党派 → ？
- 科学文化 → ？
- 人民内部矛盾 → ？

:::

::: tip

💬 **有疑问？**方针总是记混？试试"场景联想法"——想象一个具体场景（如整风会议上批评同志），把方针"放进去"感受。

:::
