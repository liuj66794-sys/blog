# 课程2：毛泽东著作与论断对应

**对应错题：第19题、第23题、第39题 ｜ 预计学习时长：25分钟**

## 学习目标

::: info

完成本课后，你将能够：

- 将6部核心著作与其标志性论断一一对应
- 利用"年份排除法"快速锁定答案
- 区分《新民主主义论》与《发刊词》《晋绥讲话》的各自贡献

:::

## 核心知识点

### 六部著作的"签名论断"

每部著作有一个**只属于它**的标志性论断，就像签名一样：

| 著作 | 年份 | 签名论断 |
| --- | --- | --- |
| 《反对本本主义》 | 1930 | "没有调查，没有发言权" |
| 《论新阶段》 | 1938 | "马克思主义中国化" |
| 《〈共产党人〉发刊词》 | 1939 | 三大法宝 + "伟大工程" |
| 《中国革命和中国共产党》 | 1939 | 首次提出"新民主主义革命"概念 |
| 《新民主主义论》 | 1940 | 系统阐述理论体系（政治/经济/文化纲领） |
| 《在晋绥干部会议上的讲话》 | 1948 | 完整概括总路线 |

### 《新民主主义论》的"陷阱"

::: tip

**为什么你总是错选《新民主主义论》？**

因为它的名字太"正"了——看到任何"新民主主义"相关的题目，你的直觉就指向它。但实际上：

- "三大法宝" → 不是它说的，是《发刊词》
- "完整总路线" → 不是它说的，是《晋绥讲话》
- "首次提概念" → 不是它说的，是《中国革命和中国共产党》

**《新民主主义论》真正做的事：**把别人提出的概念、法宝、路线，整合成一个**完整的理论体系**（包括政治纲领、经济纲领、文化纲领）。

:::

### 年份排除法

::: info

当题目给了年份时，**一定要用**！

例：第39题说"1948年" → 《新民主主义论》是1940年的 → 直接排除！

记住年份口诀：**"30-37-38-39-40-48"**

- 30 = 反对本本主义
- 37 = 实践论/矛盾论
- 38 = 论新阶段
- 39 = 发刊词 / 中国革命和中国共产党
- 40 = 新民主主义论
- 48 = 晋绥讲话

:::

### 你的错题复盘

::: danger

**第19题：**"没有调查，没有发言权"出自？你选A《实践论》，正确B《反对本本主义》

**记忆锚点：**《反对本本主义》原名就叫《调查工作》！书名和论断是直接对应的。

:::

::: danger

**第23题：**三大法宝 + 伟大工程出自？你选B《新民主主义论》，正确A《发刊词》

**记忆锚点：**"发刊词" = 创刊号 = 总结过去18年经验 = 提炼出三大法宝。

:::

::: danger

**第39题：**1948年完整概括总路线？你选C《新民主主义论》，正确B《晋绥讲话》

**记忆锚点：**1948 ≠ 1940，年份不对直接排除！

:::

## 即时练习

**1. "没有调查，没有发言权"出自哪部著作？**

- A. 《实践论》
- B. 《反对本本主义》
- C. 《矛盾论》
- D. 《论新阶段》

::: details 点开核对答案

**答案：B（《反对本本主义》）**

:::

**2. 提出"三大法宝"和"党的建设是伟大工程"的著作是？**

- A. 《〈共产党人〉发刊词》
- B. 《新民主主义论》
- C. 《论联合政府》
- D. 《中国革命和中国共产党》

::: details 点开核对答案

**答案：A（《〈共产党人〉发刊词》）**

:::

**3. 1948年完整概括新民主主义革命总路线的是？**

- A. 《新民主主义论》
- B. 《在晋绥干部会议上的讲话》
- C. 《论联合政府》
- D. 《中国革命和中国共产党》

::: details 点开核对答案

**答案：B（《在晋绥干部会议上的讲话》）**

:::

**4. 系统阐述新民主主义政治、经济、文化纲领的著作是？**

- A. 《〈共产党人〉发刊词》
- B. 《新民主主义论》
- C. 《在晋绥干部会议上的讲话》
- D. 《论人民民主专政》

::: details 点开核对答案

**答案：B（《新民主主义论》）**

:::

**5. 首次提出"新民主主义革命"科学概念的著作是？**

- A. 《新民主主义论》
- B. 《〈共产党人〉发刊词》
- C. 《中国革命和中国共产党》
- D. 《论联合政府》

::: details 点开核对答案

**答案：C（《中国革命和中国共产党》）**

:::

::: tip 记忆口诀

"调查反本本，法宝发刊词；

概念中革共，体系新民论；

总线四八晋，提出确立分。"

:::
