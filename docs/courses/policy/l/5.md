# 课程5：新民主主义革命理论

**对应错题：第41题、第42题 ｜ 预计学习时长：20分钟**

> 本文为站内全文版（已纳入搜索，随堂测为折叠核对）。随堂测可点击作答的交互版：[**打开讲义**](/blog/lessons/policy/lessons/0005-new-democracy-theory.html){target="_blank"}

## 学习目标

::: info

完成本课后，你将能够：

- 区分新民主主义经济纲领三项内容，识别"极具特色"的那项

- 理解"特色"="与众不同"的审题逻辑

:::

## 核心知识点

### 知识点一：经济纲领三项及"特色"

| 内容 | 针对对象 | 是否"特色" |
| --- | --- | --- |
| 没收封建地主土地归农民所有 | 封建主义 | ❌ 一般革命都有 |
| 没收官僚资本归国家所有 | 官僚资本主义 | ❌ 社会主义革命也有 |
| **保护民族工商业** | 民族资产阶级 | ✅ **极具特色！** |

::: info

**为什么"保护民族工商业"是特色？**

因为一般的社会主义革命是要**消灭一切私有制**的。但中国新民主主义革命不同——民族资产阶级是革命的**同盟者**（他们也被帝国主义和官僚资本压迫），所以要"保护"而非"消灭"。这就是中国特色！

:::

::: tip

**审题逻辑：**"极具特色" = "与众不同" = "别的革命没有的"

→ "没收"是常规操作（别的革命也没收）

→ "保护"才是特色（别的革命不保护，要消灭）

:::

### 知识点二：主要内容 vs 主要形式

::: info

**主要形式 = 武装斗争**

"形式"= 手段/方式

中国革命靠什么方式推进？→ 打仗

（因为反动派不会自动退出历史舞台）

:::

::: tip

**主要内容 = 土地革命**

"内容"= 解决什么问题

中国革命的核心问题是什么？→ 农民的土地问题

（因为农民占人口绝大多数）

:::

::: info

**逻辑链：**

中国是农业国 → 农民是革命主力 → 农民最关心土地 → 所以革命的**主要内容**是解决土地问题 = 土地革命

但地主不会自愿交出土地 → 所以必须用**武装斗争**（主要形式）来保障土地革命

:::

### 你的错题复盘

::: danger

**第41题：**经济纲领中极具特色的内容？你选B（没收官僚资本），正确C（保护民族工商业）

**错因：**把"特色"理解为"重要"或"革命性强"。但"没收"谁都会，"保护"才是中国独创。

:::

::: info

**第42题：**新民主主义革命主要内容？你选A（武装斗争），正确B（土地革命）

**错因：**混淆了"形式"和"内容"。武装斗争是"怎么打"（形式），土地革命是"打什么/为什么打"（内容）。

:::

::: tip 记忆口诀

"特色看保护，内容看土地；

形式是武装，没收不稀奇。"

:::

## 即时练习

**1. 新民主主义经济纲领中，区别于一般社会主义革命的内容是？**

- A. 没收地主土地
- B. 没收官僚资本
- C. 保护民族工商业
- D. 发展国营经济

::: details 点开核对答案

**答案：C（保护民族工商业）**

:::

**2. 新民主主义革命的主要形式是？**

- A. 武装斗争
- B. 土地革命
- C. 统一战线
- D. 根据地建设

::: details 点开核对答案

**答案：A（武装斗争）**

:::

**3. 中国革命的中心问题是？**

- A. 政权问题
- B. 农民问题
- C. 军队问题
- D. 统一战线问题

::: details 点开核对答案

**答案：B（农民问题）**

:::

**4. 新民主主义革命的主要内容是？**

- A. 武装斗争
- B. 土地革命
- C. 党的建设
- D. 根据地建设

::: details 点开核对答案

**答案：B（土地革命）**

:::
