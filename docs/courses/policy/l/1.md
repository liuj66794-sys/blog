# 课程1：党史重大事件辨析

**对应错题：第1题、第11题 ｜ 预计学习时长：20分钟**

> 本文为站内全文版（已纳入搜索，随堂测为折叠核对）。随堂测可点击作答的交互版：[**打开讲义**](/blog/lessons/policy/lessons/0001-party-history-events.html){target="_blank"}

## 学习目标

::: info

完成本课后，你将能够：

- 准确说出中共一大、遵义会议、六届六中全会、党的七大各自的**唯一核心标签**
- 区分"提出命题"与"确立地位"的不同时间节点
- 在选择题中快速排除干扰项

:::

## 核心知识点

### 四大会议/事件的"唯一标签"

考试中，每个事件只对应**一个最核心的历史意义**。记住这个对应关系，就不会被干扰项迷惑：

| 事件 | 年份 | 唯一核心标签 | 记忆锚点 |
| --- | --- | --- | --- |
| 中共一大 | 1921 | **建党/诞生** | "一"= 第一个 = 诞生 |
| 遵义会议 | 1935 | **转折点** | "遵"= 遵循正确路线 = 转折 |
| 六届六中全会 | 1938 | **提出"中国化"命题** | "六六"= 38 → 提出 |
| 党的七大 | 1945 | **确立指导思想** | "七"= 齐 = 思想统一 |

### 关键辨析："提出" vs "确立"

::: danger

**❌ 常见错误理解**

"马克思主义中国化" = 毛泽东思想 → 所以是七大确立的

:::

::: tip

**✅ 正确理解**

"提出命题"（1938六中全会）≠ "确立为指导思想"（1945七大）

先有人说出来，后来才被写入党章

:::

::: tip

**审题技巧：**看到"正式提出" → 找第一次说出来的时间；看到"确立/写入党章" → 找后来确认的时间。这两个永远不是同一个会议！

:::

### 你的错题复盘

::: danger

**第1题：**"马克思主义中国化"命题正式提出于？

你选了A（七大），正确是B（六届六中全会）。

**错因：**把"确立指导地位"的时间当成了"提出命题"的时间。

**纠正：**1938年毛泽东在六届六中全会上作《论新阶段》报告，**第一次说出**"马克思主义中国化"这句话。

:::

::: danger

**第11题：**中国共产党诞生的标志性事件是？

你选了D（遵义会议），正确是B（中共一大）。

**错因：**遵义会议意义太大（"转折点"），被误当作"诞生"标志。

**纠正：**"诞生/成立/创建" = 1921年一大。遵义会议是1935年的事，党已经存在14年了。

:::

## 即时练习

请尝试回答以下题目，点击选项查看反馈：

**1. 党的历史上"生死攸关的转折点"是？**

- A. 中共一大
- B. 六届六中全会
- C. 遵义会议
- D. 党的七大

::: details 点开核对答案

**答案：C（遵义会议）**

:::

**2. 确立毛泽东思想为党的指导思想的是？**

- A. 六届六中全会
- B. 党的七大
- C. 遵义会议
- D. 十一届六中全会

::: details 点开核对答案

**答案：B（党的七大）**

:::

**3. 1938年毛泽东在《论新阶段》中首次提出的命题是？**

- A. 新民主主义革命
- B. 马克思主义中国化
- C. 人民民主专政
- D. 三大法宝

::: details 点开核对答案

**答案：B（马克思主义中国化）**

:::

**4. 为中国共产党建党奠定思想和干部基础的是？**

- A. 五四运动
- B. 中共一大
- C. 南昌起义
- D. 遵义会议

::: details 点开核对答案

**答案：A（五四运动）**

:::

::: tip 记忆口诀

"一大建党二大纲，遵义转折七大章；

三八提出中国化，命题确立要分清。"

:::
