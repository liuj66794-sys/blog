## 一、凹凸：$f''$ 接管方向盘

::: warning 判定定理（本课程约定）

$f''(x)>0$ ⇒ 图形是**凹**的（碗形，如 $y=x^2$）；$f''(x)<0$ ⇒ 图形是**凸**的（伞形，如 $y=\ln x$——它全程 $y''=-\frac{1}{x^2}<0$）。

**求凹凸区间/拐点四步**：① 定义域 → ② 求 $f''$，找**二阶导零点 + 不可导点** → ③ 分区间 → ④ 逐区间看 $f''$ 符号。

:::

流程与 0024 单调性四步**完全同构**，只是把 $f'$ 换成 $f''$、把"增减"换成"凹凸"——一套脑子两处用。

## 二、拐点：凹凸的换乘站

::: warning 定义与两个"有可能"

**拐点**：曲线两侧**凹凸性改变**的点，写作 $(x_0,\ f(x_0))$——是一个**点（带纵坐标）**，不是横坐标。

① 二阶导零点**有可能**是拐点（要验两侧变号，$f''(x_0)=0$ 但两侧同号就不是，如 $y=x^4$ 的原点）；② 二阶导**不存在的点也有可能**是拐点。

:::

:::: tip 算例

例 1求 $f(x)=x^{4}-6x^{3}+12x^{2}-x+1$ 的凹凸区间与拐点。（夏应用 P52）

::: details 先自己走四步，再展开

$f'(x)=4x^{3}-18x^{2}+24x-1$，$f''(x)=12x^{2}-36x+24=12(x-1)(x-2)$。

$f''$ 零点 $x=1,2$。符号：$x<1$ 时 $+$（凹）；$1<x<2$ 时 $-$（凸）；$x>2$ 时 $+$（凹）。

凹区间 $(-\infty,1)$、$(2,+\infty)$，凸区间 $(1,2)$；两侧变号 ⇒ 拐点 $(1,7)$ 与 $(2,15)$。

:::

## 三、一条龙大题实战

:::: tip 算例

例 2（大题标准形态）求 $f(x)=x^{3}-3x^{2}+1$ 的单调区间、极值、凹凸区间与拐点。（秋应用练习 7(1)）

::: details 先自己全做，再展开

$f'(x)=3x^{2}-6x=3x(x-2)$；$f''(x)=6x-6$。

**单调与极值**：增 $(-\infty,0)$、$(2,+\infty)$，减 $(0,2)$；极大值 $f(0)=1$，极小值 $f(2)=-3$。

**凹凸与拐点**：$f''<0$ 于 $(-\infty,1)$ 凸，$f''>0$ 于 $(1,+\infty)$ 凹；拐点 $(1,-1)$。

考场策略：$f'$、$f''$ 各画一张符号表，两问互不干扰、流水线产出。

:::

::::

## 四、曲率：弯得多厉害

::: warning 三个公式（按曲线形式选）

**直角坐标** $y=f(x)$：$$k=\dfrac{\left|f''(x)\right|}{\left[1+(f'(x))^{2}\right]^{3/2}}$$

**参数方程**：$k=\dfrac{|x'y''-x''y'|}{\left[(x')^{2}+(y')^{2}\right]^{3/2}}$；**极坐标**：$k=\dfrac{|r^{2}+2(r')^{2}-rr''|}{\left[r^{2}+(r')^{2}\right]^{3/2}}$。

结构记忆：分子是"弯曲量"（二阶导为主），分母是"切线倾斜修正"（$1+y'^2$ 的 $\frac32$ 次幂）。

:::

:::: tip 算例

例 3求 $y=x^{2}$ 在 $x=0$ 处与 $y=e^{x}$ 在 $x=0$ 处的曲率。（夏应用 P57）

::: details 先自己代公式，再展开

$y=x^{2}$：$y'(0)=0$，$y''(0)=2$，$k=\dfrac{2}{(1+0)^{3/2}}=2$。

$y=e^{x}$：$y'(0)=y''(0)=1$，$k=\dfrac{1}{(1+1)^{3/2}}=\dfrac{1}{2\sqrt2}=\dfrac{\sqrt2}{4}$。

检查点：抛物线顶点处最弯（切线水平、分母为 1），$k=2$ 正是 $x^2$ 的"曲率半径 $\frac12$"的倒数——公式与直觉吻合。

:::

**随堂测 1：$y=\ln x$ 在 $(0,+\infty)$ 上的凹凸性是（夏应用 P49）**

- A. 凹的
- B. 凸的
- C. 先凸后凹
- D. 无凹凸性

::: details 点开核对答案

**答案：B（凸的）** —— $y'=\frac1x$，$y''=-\frac{1}{x^{2}}&lt;0$ 恒成立 ⇒ 全程凸（伞形，越升越缓）。对数函数"涨得越来越慢"的图像直觉与结论一致。

:::

**随堂测 2：下列关于拐点的说法，正确的是**

- A. $f''(x_0)=0$ 的点 $(x_0,f(x_0))$ 一定是拐点
- B. 拐点就是 $f''(x_0)=0$ 的横坐标 $x_0$
- C. $f''(x_0)=0$ 且两侧 $f''$ 变号，$(x_0,f(x_0))$ 才是拐点
- D. 拐点处函数必不可导

::: details 点开核对答案

**答案：C（$f''(x_0)=0$ 且两侧 $f''$ 变号，$(x_0,f(x_0))$ 才是拐点）** —— A 反例 $y=x^4$：$f''(0)=0$ 但两侧同号，不是拐点；B 丢了纵坐标——拐点是曲线上的&lt;strong&gt;点&lt;/strong&gt;；D 反了：二阶不可导点、二阶为零的点都"有可能"，都要验两侧。

:::

**随堂测 3：$y=x^{3}-\dfrac92x^{2}+6x$ 的拐点是（秋应用练习 7(2)）**

- A. $\left(\dfrac32,\ \dfrac94\right)$
- B. $\dfrac32$
- C. $\left(\dfrac32,\ 0\right)$
- D. $(1,2)$

::: details 点开核对答案

**答案：A（$\left(\dfrac32,\ \dfrac94\right)$）** —— $y''=6x-9$，零点 $x=\frac32$，两侧变号 ✓。代回：$y\left(\frac32\right)=\frac{27}{8}-\frac{81}{8}+9=\frac94$。B 只写了横坐标——拐点要写全点坐标，填空题按"缺纵坐标"扣分。

:::

**随堂测 4：$y=\dfrac{x^{2}}{x-1}$ 的凹凸与拐点情况是（秋应用练习 7(6)）**

- A. 有拐点 $\left(1,\dfrac12\right)$
- B. 全曲线凹，无拐点
- C. 全曲线凸，无拐点
- D. $f''=\dfrac{2}{(x-1)^{3}}$：凹 $(1,+\infty)$、凸 $(-\infty,1)$，无拐点

::: details 点开核对答案

**答案：D（$f''=\dfrac{2}{(x-1)^{3}}$：凹 $(1,+\infty)$、凸 $(-\infty,1)$，无拐点）** —— $f''=\dfrac{2}{(x-1)^3}$ 在 $x=1$ 两侧由负变正——但 $x=1$ 是&lt;strong&gt;间断点&lt;/strong&gt;，函数在那里没有定义，曲线断成两截，两侧"接不上"，故&lt;strong&gt;不是拐点&lt;/strong&gt;。"变号 + 该点有定义且连续"两个条件都要满足。

:::

**随堂测 5：$y=e^{x}$ 在 $x=0$ 处的曲率 $k=$（夏应用 P57）**

- A. $\dfrac{1}{2}$
- B. $\dfrac{\sqrt{2}}{4}$
- C. $1$
- D. $\sqrt2$

::: details 点开核对答案

**答案：B（$\dfrac{\sqrt{2}}{4}$）** —— $y'(0)=y''(0)=1$，$k=\dfrac{|1|}{(1+1^{2})^{3/2}}=\dfrac{1}{2\sqrt2}=\dfrac{\sqrt2}{4}$。分母是 $\frac32$ 次幂不是平方——D 是把 $2^{3/2}=2\sqrt2$ 算成 $\sqrt2$ 的结果。

:::

::: danger 本课易错清单

- 拐点写**全坐标** $(x_0,f(x_0))$；只写 $x_0$ 不完整
- $f''(x_0)=0$ 只是"候选"，**必须验两侧变号**；间断点处变号不算拐点
- 凹凸用 $f''$ 符号判（$>0$ 凹、$<0$ 凸），与单调的 $f'$ 各管各的，别串
- 曲率分母是 $\left[1+(f')^{2}\right]^{\boldsymbol{3/2}}$，不是平方
- 一条龙大题先算 $f'$ 与 $f''$，两张符号表流水线作答

:::

**回忆卡：默写凹凸判定（$f''$ 符号）与拐点定义，并说出拐点的两个"有可能"。**

::: details 先回忆，再揭晓

$f''>0$ 凹（碗）、$f''<0$ 凸（伞）；拐点 = 两侧凹凸性改变的曲线点 $(x_0,f(x_0))$。二阶导零点与二阶不可导点都**有可能**是拐点，都要验变号。

:::

**回忆卡：默写直角坐标曲率公式，并报出 $y=x^2$ 在顶点处的曲率。**

::: details 先回忆，再揭晓

$k=\dfrac{|f''|}{\left[1+(f')^{2}\right]^{3/2}}$；$y=x^2$ 顶点处 $y'=0$、$y''=2$，$k=2$。

:::
