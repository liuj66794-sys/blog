0024 课一元极值的多元升级版：驻点从解一个方程变成解**两个**，判定从看 $f''$ 符号变成算**$AC-B^{2}$**。流程化程度极高，是本章大题的"送分担当"。

## 一、概念与流程

::: warning 驻点与判别

**第一步**：解驻点方程组 $f_{x}(x,y)=0$，$f_{y}(x,y)=0$（偏导存在的极值点必为驻点，反之不然）。

**第二步**：在每个驻点处记 $A=f_{xx}$，$B=f_{xy}$，$C=f_{yy}$，算 $\Delta=AC-B^{2}$。

| 条件 | 结论 |
| --- | --- |
| $\Delta>0$，$A>0$ | **极小值**（碗底） |
| $\Delta>0$，$A<0$ | **极大值**（伞顶） |
| $\Delta<0$ | **不是极值**（鞍点） |
| $\Delta=0$ | **判别失效**，另行分析 |

对照一元版：$A$ 的角色类似 $f''$（凹碗/凸伞）；$AC-B^{2}>0$ 保证两个方向"弯曲一致"，是"真碗/真伞"而非马鞍。

:::

::: tip 算例

例 1（标准件）求 $f(x,y)=x^{3}-y^{3}+3x^{2}+3y^{2}-9x$ 的极值。（练习 25 同族）

::: details 先自己走四步，再展开

**① 驻点**：$f_x=3x^{2}+6x-9=3(x-1)(x+3)=0$，$f_y=-3y^{2}+6y=-3y(y-2)=0$ ⇒ 驻点 $(1,0),(1,2),(-3,0),(-3,2)$。

**② 二阶**：$A=f_{xx}=6x+6$，$B=f_{xy}=0$，$C=f_{yy}=-6y+6$，$\Delta=AC$。

**③④ 判别**：

- $(1,0)$：$A=12>0$，$C=6$，$\Delta=72>0$ ⇒ **极小值** $f(1,0)=-5$；
- $(1,2)$：$A=12$，$C=-6$，$\Delta=-72<0$ ⇒ 非极值；
- $(-3,0)$：$A=-12$，$C=6$，$\Delta=-72<0$ ⇒ 非极值；
- $(-3,2)$：$A=-12$，$C=-6$，$\Delta=72>0$ ⇒ **极大值** $f(-3,2)=31$。

大题答卷就按"①②③④"四段写——步骤分全拿。

:::

:::

::: tip 算例

例 2（$\Delta=0$ 的样子）为什么 $f(x,y)=x^{2}+y^{2}$ 与 $f(x,y)=x^{2}+xy+y^{2}$ 在原点都能过判别、而 $f(x,y)=x^{2}$ 过不了？

::: details 先自己算三个判别式，再展开

$x^{2}+y^{2}$：$A=2,B=0,C=2$，$\Delta=4>0$，$A>0$ ⇒ 极小 ✓。

$x^{2}+xy+y^{2}$：$A=2,B=1,C=2$，$\Delta=3>0$ ⇒ 极小 ✓。

$x^{2}$：$A=2,B=0,C=0$，$\Delta=0$ **失效**——事实上原点确是极小值，但判别法看不见，得回定义：$\forall(x,y)\neq(0,0)$，$f=x^{2}\ge0=f(0,0)$ ✓。

$\Delta=0$ 时**各种结论都有可能**（极值、非极值都行），必须另行分析。

:::

:::

**随堂测 1：驻点 $(x_0,y_0)$ 处 $A=2$，$B=1$，$C=3$，则该点**

- A. 是极大值点
- B. 是极小值点
- C. 是鞍点，不是极值点
- D. 判别法失效

::: details 点开核对答案

**答案：B（是极小值点）** —— $\Delta=AC-B^{2}=2\times3-1=5&gt;0$ 且 $A=2&gt;0$ ⇒ 极小值点。判别两件事分开看：&lt;strong&gt;先看 $\Delta$ 的正负定"是不是"，再看 $A$ 的正负定"极大还是极小"&lt;/strong&gt;。

:::

**随堂测 2：驻点处 $AC-B^{2}<0$，则该点**

- A. 是极小值点
- B. 是极大值点
- C. 一定不是极值点（鞍点）
- D. 可能极大也可能极小

::: details 点开核对答案

**答案：C（一定不是极值点（鞍点））** —— $\Delta&lt;0$ 一票否决：两个主方向弯曲方向相反，是马鞍面形状，无论 $A$ 正负都不是极值。D 是 $\Delta&gt;0$ 时才需要看 $A$ 的情形。

:::

**随堂测 3：$f(x,y)=x^{2}+y^{2}-2x+4y+6$ 的极小值是**

- A. $1$
- B. $6$
- C. $-5$
- D. $2$

::: details 点开核对答案

**答案：A（$1$）** —— 驻点：$f_x=2x-2=0$、$f_y=2y+4=0$ ⇒ $(1,-2)$。$A=2,C=2,B=0$，$\Delta=4&gt;0$，$A&gt;0$ ⇒ 极小。$f(1,-2)=1+4-2-8+6=1$。（或配方 $(x-1)^2+(y+2)^2+1$ 心算验证。）这是练习 25(1) 的同族题。

:::

**随堂测 4：下列说法正确的是**

- A. 驻点必是极值点
- B. 极值点必是驻点
- C. $\Delta=0$ 时必为鞍点
- D. 偏导存在的极值点必是驻点，但驻点未必是极值点

::: details 点开核对答案

**答案：D（偏导存在的极值点必是驻点，但驻点未必是极值点）** —— 与一元版（0024 课费马引理）完全平行：必要条件单向成立。A 反例 $z=xy$ 原点；B 忽略不可导点；C 是 $\Delta&lt;0$ 的结论。$\Delta=0$ 的真正含义是"判别法失效"。

:::

**随堂测 5：求 $f(x,y)=x^{3}+y^{3}-3xy$ 的极值时，驻点是**

- A. $(0,0)$ 与 $(1,1)$
- B. $(1,0)$ 与 $(0,1)$
- C. 只有 $(1,1)$
- D. $(-1,-1)$ 与 $(1,1)$

::: details 点开核对答案

**答案：C（只有 $(1,1)$）** —— $f_x=3x^{2}-3y=0$、$f_y=3y^{2}-3x=0$ ⇒ $y=x^{2}$、$x=y^{2}$ ⇒ $x=x^{4}$ ⇒ $x=0$ 或 $1$：驻点 $(0,0)$ 与 $(1,1)$。判别：$(0,0)$ 处 $A=B=C=0$，$\Delta=0$ 失效（实为鞍点）；$(1,1)$ 处 $A=6,B=-3,C=6$，$\Delta=27&gt;0$，$A&gt;0$ ⇒ 极小值 $-1$。

:::

::: danger 本课易错清单

- 驻点方程组是**两个**方程联立，解出的是**点集**，每个驻点都要分别判别
- $B=f_{xy}$ 别漏算；$\Delta=AC-B^{2}$ 的顺序是"$AC$ 减 $B^{2}$"
- $\Delta<0$ 一票否决（不用看 $A$）；$\Delta=0$ **失效另判**
- 问的是"极值"要代回 $f(x_0,y_0)$ 报数值，只答驻点不得全分
- 应用背景题（实际最值）可由"唯一驻点 = 最值点"直接下结论，但仍要写明理由

:::

**回忆卡：默写 $AC-B^{2}$ 判别表（四种情形四种结论）。**

::: details 先回忆，再揭晓

$\Delta>0$ 且 $A>0$ 极小；$\Delta>0$ 且 $A<0$ 极大；$\Delta<0$ 鞍点非极值；$\Delta=0$ 判别失效另分析。

:::

**回忆卡：二元极值大题四步是什么？$A,B,C$ 各是哪个偏导？**

::: details 先回忆，再揭晓

①解 $f_x=f_y=0$ 定驻点 → ②算 $A=f_{xx}$、$B=f_{xy}$、$C=f_{yy}$ → ③算 $\Delta=AC-B^{2}$ → ④按表下结论并代值。
