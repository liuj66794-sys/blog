## 一、什么是函数：抓住"唯一性"

**定义**：设 $D$ 是非空数集，若对每一个 $x\in D$，按确定的对应法则 $f$，都有**唯一确定**的 $y$ 与之对应，则称 $y=f(x)$ 是 $x$ 的函数。

三个要素：定义域 $D$（$x$ 的取值范围）、对应法则 $f$（怎么算）、值域（算出来的 $y$ 全体）。判断"是不是函数"只看一条：**一个 $x$ 是不是只能对应一个 $y$**。

::: tip 算例

例 1下列各项中，不是函数的是哪一项？

A. $y=2x^2+3x-4$　B. $y^2=x$　C. $y=x^3-4x^2$　D. $y=\sqrt{x}$

::: details 先自己判断，再展开解答（原题见讲义 6·22 例 1）

**答：B**。$y^2=x$ 即 $y=\pm\sqrt{x}$：取 $x=1$，$y$ 可以是 $1$ 也可以是 $-1$，一个 $x$ 对应两个 $y$，违反唯一性。其余三项每个 $x$ 都只算出一个 $y$。

注意 D：$y=\sqrt x$ **是**函数（根号规定取算术平方根，只有非负一个值）；但 $y^2=x$ 不是——方向反了。

:::

:::

## 二、定义域六条限制（必背包）

::: warning 见什么，列什么

| 情形 | 要求 |
| --- | --- |
| 分式 | 分母 $\neq 0$ |
| 偶次根号 $\sqrt{\ \ }$ | 被开方式 $\ge 0$；**在分母里则 $>0$** |
| 对数 $\log_a u$、$\ln u$ | 真数 $u>0$ |
| 零次幂 $u^0$ | $u\neq 0$ |
| $\arcsin u$、$\arccos u$ | $-1\le u\le 1$ |
| $\tan x$、$\cot x$ | $\tan$：$x\neq\dfrac{\pi}{2}+k\pi$；$\cot$：$x\neq k\pi$ |

:::

方法：**一条限制列一个不等式，全部联立，取交集**。最后答案写成**区间或集合**——填空题只写 $x\neq\pm1$ 不写区间符号，阅卷按答案不完整处理。

::: tip 算例

例 2求 $f(x)=\ln\left(1-\sqrt{x}\right)$ 的定义域。

::: details 先自己做，再展开解答（原题见夏讲教材 P8）

两层限制，从外到内：

真数 $>0$：$1-\sqrt x>0\ \Rightarrow\ \sqrt x<1\ \Rightarrow\ 0\le x<1$；根号本身：$x\ge 0$。

联立取交集：$[0,1)$。

技巧：**从最外层往里剥**，每剥一层加一条限制，最后一起解。

:::

:::

::: tip 算例

例 3求 $f(x)=\dfrac{\arcsin(x-2)}{x^2-x-2}$ 的定义域。

::: details 先自己做，再展开解答（原题见夏讲教材 P8）

限制一：$\arcsin$ 的自变量 $-1\le x-2\le 1\Rightarrow 1\le x\le 3$。

限制二：分母 $x^2-x-2=(x-2)(x+1)\neq 0\Rightarrow x\neq 2$ 且 $x\neq -1$。

交集：$[1,2)\cup(2,3]$。

:::

:::

**随堂测 1：$y=\dfrac{1}{\sqrt{4-x^2}}$ 的定义域是**

- A. $[-2,2]$
- B. $(-2,2]$
- C. $[-2,2)$
- D. $(-2,2)$

::: details 点开核对答案

**答案：D（$(-2,2)$）** —— $4-x^2\ge0$ 只给出 $[-2,2]$，但这个根号&lt;strong&gt;在分母里&lt;/strong&gt;，必须严格 $&gt;0$，端点 $x=\pm2$ 使分母为零，必须去掉 → 开区间 $(-2,2)$。"偶次根在分母取 $&gt;0$"是本课第一大易错点。

:::

**随堂测 2：$y=\ln(x+1)+\arctan\dfrac{1}{x}$ 的定义域是**

- A. $(-1,+\infty)$
- B. $(0,+\infty)$
- C. $(-1,0)\cup(0,+\infty)$
- D. $[-1,0)\cup(0,+\infty)$

::: details 点开核对答案

**答案：C（$(-1,0)\cup(0,+\infty)$）** —— $\ln(x+1)$：$x+1&gt;0\Rightarrow x&gt;-1$；$\arctan\dfrac1x$ 本身不限制，但 $\dfrac1x$ 要求 $x\neq0$。交集：$(-1,0)\cup(0,+\infty)$。

:::

## 三、分段函数：各段取并集

分段函数的定义域 = **每一段自变量范围的并集**。另外记住单侧极限伏笔：在分段点处，函数值由"这一点的 $x$ 属于哪一段"决定。

::: tip 算例

例 4$f(x)=\begin{cases}x^2 & x<0\\ \ln(x+1) & 0<x\le 2\\ \dfrac{\sin x}{x} & x>3\end{cases}$，求定义域。

::: details 先自己做，再展开解答（原题见夏讲例题组）

第二段里 $\ln(x+1)$ 还要 $x+1>0$，在 $x>0$ 下自动满足。三段：$(-\infty,0)\cup(0,2]\cup(3,+\infty)$。

注意 $x=0$ 和 $(2,3]$ 这些"缝"：分段函数的定义域完全可以不连续，别想当然补成整个 $\mathbb{R}$。

:::

:::

## 四、易错清单

::: danger 考前再读一遍

- 偶次根号**在分母**里：取 $>0$，不是 $\ge 0$（随堂测 1 就是它）
- 定义域最终要写**区间/集合**，别只写不等式
- $\sqrt{x^2}=|x|$，不等于 $x$——它还会在"相同函数判断"里埋伏你
- $\arcsin$、$\arccos$ 的限制是**双边**的：$-1\le u\le1$，别只写一半

:::

**回忆卡：默写定义域六条限制（分式 / 偶次根 / 对数 / 零次幂 / $\arcsin,\arccos$ / $\tan,\cot$）。**

::: details 先回忆，再揭晓

分母 $\neq0$；被开方式 $\ge0$（分母里 $>0$）；真数 $>0$；底 $\neq0$；$-1\le u\le1$；$\tan$ 排除 $\dfrac{\pi}{2}+k\pi$，$\cot$ 排除 $k\pi$。

:::

**回忆卡：口算：$y=\sqrt{3x+2}$ 与 $y=\arcsin(x-3)$ 的定义域各是什么？**

::: details 先回忆，再揭晓

$$\left[-\dfrac23,+\infty\right)\qquad [2,4]$$

:::
