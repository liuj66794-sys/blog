## 一、定义与前提

::: warning 必背

前提：定义域 $D$ **关于原点对称**（$x\in D\iff -x\in D$）。不对称 → 直接"非奇非偶"，不用再算。

$f(-x)=-f(x)$ 对一切 $x\in D$ 成立 → **奇函数**（图像关于原点对称）；

$f(-x)=f(x)$ 对一切 $x\in D$ 成立 → **偶函数**（图像关于 $y$ 轴对称）。

:::

为什么定义域要对称？因为"$f(-x)$"这个式子本身就要求 $-x$ 也在定义域里，否则连检验都做不了。

**随堂测 1：判断函数奇偶性的第一步是**

- A. 直接计算 $f(-x)$
- B. 检查定义域是否关于原点对称
- C. 画出函数图像
- D. 代入 $x=1$ 试一试

::: details 点开核对答案

**答案：B（检查定义域是否关于原点对称）** —— 定义域不对称就直接"非奇非偶"，连 $f(-x)$ 都不必算。例：$f(x)=x^2$，$x\in[-1,2]$——范围不对称，非奇非偶，虽然式子本身是偶式的。先看定义域是硬流程。

:::

## 二、常见奇偶函数清单

| 奇函数 | 偶函数 |
| --- | --- |
| $x^{2n-1}$（$x,x^3,x^5,\dots$）、$\sin x$、$\tan x$、$\arcsin x$、$\arctan x$、$f(x)-f(-x)$ | $x^{2n}$（$x^2,x^4,\dots$）、常数 $C$、$\|x\|$、$\cos x$、$f(x)+f(-x)$ |

配合 0001 课的三角奇偶（$\sin$ 奇、$\cos$ 偶、$\tan$ 奇）和反三角奇偶（$\arcsin$、$\arctan$ 奇，$\arccos$ 非奇非偶），这份清单覆盖了考题里 90% 的"零件"。

## 三、运算口诀

| 运算 | 结论 |   |   |
| --- | --- | --- | --- |
| 加减 | 奇 $\pm$ 奇 $=$ 奇 | 偶 $\pm$ 偶 $=$ 偶 | 奇 $\pm$ 偶 $=$ 非奇非偶 |
| 乘除 | 奇 $\times$ 奇 $=$ 偶 | 偶 $\times$ 偶 $=$ 偶 | 奇 $\times$ 偶 $=$ 奇 |
| 复合 | **内偶则偶，内奇同外**（内层偶 → 整体偶；内层奇 → 整体随外层） |   |   |

乘除可以记"**同奇偶得偶，异得奇**"；复合记成"跟内层争不过——内层是偶，整体就偶；内层奇，才轮到外层说话"。

::: tip 算例

例 1（口诀速判）用口诀判断下列函数（来自夏讲例题组）：

$y=x^5+x^3$、$y=\sin x^2$、$y=e^x+e^{-x}$、$y=x^3\cos x$、$y=x^2+x^3$、$y=|x|\tan x$、$y=\dfrac{x^3}{1+x^2}$

::: details 先全部判断完，再展开答案

| 函数 | 判断 | 依据 |
| --- | --- | --- |
| $y=x^5+x^3$ | 奇 | 奇＋奇 |
| $y=\sin x^2$ | 偶 | 复合：内层 $x^2$ 偶 → 内偶则偶 |
| $y=e^x+e^{-x}$ | 偶 | $f(-x)=e^{-x}+e^x=f(x)$ |
| $y=x^3\cos x$ | 奇 | 奇 $\times$ 偶 |
| $y=x^2+x^3$ | 非奇非偶 | 奇＋偶 |
| $y=\|x\|\tan x$ | 偶 | 偶 $\times$ 奇 |
| $y=\dfrac{x^3}{1+x^2}$ | 奇 | 奇 $\div$ 偶 |

注意 $y=\sin x^2$ 与 $y=\sin^2 x$ 完全不同：前者"内偶则偶"是偶函数，后者是 $\sin x$ 的平方 = 奇×奇 = 偶函数（结论巧合相同，路径不同）。读题时看清位置！

:::

:::

**随堂测 2：$f(x)=x+\sin x$ 是**

- A. 奇函数
- B. 偶函数
- C. 非奇非偶函数
- D. 既是奇函数又是偶函数

::: details 点开核对答案

**答案：A（奇函数）** —— $x$ 奇，$\sin x$ 奇，奇＋奇＝奇。（这是夏讲的原题，考的就是口诀熟练度。）

:::

**随堂测 3：$y=\tan^3(2x^2+1)$ 的奇偶性是**

- A. 奇函数
- B. 偶函数
- C. 非奇非偶函数
- D. 无法确定

::: details 点开核对答案

**答案：C（非奇非偶函数）** —— 别被三角吓住：最内层是 $2x^2+1$——偶函数（$x^2$ 偶 ＋ 常数偶）。口诀"内偶则偶"：无论外面套 $\tan^3$ 还是别的什么，整体都是偶函数。

:::

## 四、必须先求定义域的类型

::: tip 算例

例 2判断 $f(x)=\ln\dfrac{1+x}{1-x}$ 的奇偶性。

::: details 先自己做，再展开解答（原题见夏讲例题组）

**第一步**：定义域。要 $\dfrac{1+x}{1-x}>0$，即 $-1<x<1$——关于原点对称 ✓（过不了这关就直接写非奇非偶）。

**第二步**：$f(-x)=\ln\dfrac{1-x}{1+x}=\ln\left(\dfrac{1+x}{1-x}\right)^{-1}=-\ln\dfrac{1+x}{1-x}=-f(x)$。

结论：奇函数。

对照清单里"$\log_a\left(\sqrt{1+x^2}\pm x\right)$ 型是奇函数"——这类对数函数是命题常客，套路都是"先验对称，再用倒数关系提负号"。

:::

:::

::: danger 易错

- 先看定义域对称，再验证 $f(-x)=\pm f(x)$——顺序不能反
- 证明奇偶要用**任意** $x$，代入 $x=1$、$x=2$ 验证数值不算证明
- $\sin x^2$（偶）$\neq\sin^2x$（偶，但理由不同）$\neq\sin 2x$（奇）——位置决定一切
- $f(x)+f(-x)$ 必偶、$f(x)-f(-x)$ 必奇——大题证明里直接引用

:::

**回忆卡：默写乘除口诀与复合口诀（奇偶函数的四则与复合结果）。**

::: details 先回忆，再揭晓

加减：同性保持，奇±偶＝非奇非偶。乘除：同得偶，异得奇。复合：内偶则偶，内奇同外。

:::

**回忆卡：快速归类（先全答完再揭晓）：$\arctan x$、$\cos x$、$x^3$、$|x|$、$\arccos x$、$\tan x$、$x^4$ 各是奇还是偶？**

::: details 先回忆，再揭晓

奇：$\arctan x$、$x^3$、$\tan x$；偶：$\cos x$、$|x|$、$x^4$；$\arccos x$：非奇非偶。
