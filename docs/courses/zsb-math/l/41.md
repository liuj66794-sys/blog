正项级数的判别机器已经造好，本课只做两件事：处理"正负相间"的特殊形状，以及给收敛级数**再分一档**（绝对还是条件）——考题最爱问的正是这最后一档。

## 一、交错级数与莱布尼茨判别法

::: warning 判别法（两个条件缺一不可）

形如 $\sum(-1)^{n}b_n$ 或 $\sum(-1)^{n-1}b_n$（$b_n\ge0$）。若 ① $b_n$ 从某项起**单调递减**；② $b_n\to0$ —— 则级数**收敛**。

只验 $b_n\to0$ 不够——**单调递减也要写进答卷**（常"代 $n+1$ 与 $n$ 比较"或看导数）。

:::

## 二、三色标签：绝对收敛 / 条件收敛 / 发散

::: warning 判定流程（固定顺序）

$$\text{先看 } \sum|a_n|:\ \text{收敛}\Rightarrow\textbf{绝对收敛}\qquad \text{发散}\Rightarrow\text{再看 } \sum a_n$$

$$\sum a_n\ \text{收敛}\Rightarrow\textbf{条件收敛}\qquad \sum a_n\ \text{发散}\Rightarrow\textbf{发散}$$

顺序铁律：**先取绝对值用正项级数方法，发散后再回来验原级数**（通常用莱布尼茨）。绝对收敛级数可任意换序且和不变；条件收敛级数不能。

:::

::: tip 算例

例 1（标杆题）判断 $\sum(-1)^{n-1}\dfrac{1}{n}$ 的敛散类型。

::: details 先自己走流程，再展开（练习 9(1)）

**第一步**：取绝对值得调和级数 $\sum\frac1n$——发散（0016 部分和 $\ln(n+1)\to\infty$）。

**第二步**：原级数是交错级数，$b_n=\frac1n$ 单调递减且 $\to0$，莱布尼茨 ⇒ 收敛。

结论：**条件收敛**。这就是著名的**交错调和级数**——绝对值发散、自身收敛的标杆。

:::

:::

::: warning 必背：交错 $p$-级数 $\sum\dfrac{(-1)^{n-1}}{n^{p}}$

| $p$ 的范围 | 结论 |
| --- | --- |
| $p>1$ | **绝对收敛**（绝对值是 $p>1$ 的 $p$-级数） |
| $0<p\le1$ | **条件收敛**（绝对值发散 + 莱布尼茨收敛） |
| $p\le0$ | **发散**（通项 $(-1)^{n-1}n^{-p}$ 不趋零） |

:::

::: tip 算例

例 2（要构造的题型）判断 $\sum(-1)^{n}\dfrac{\ln n}{n}$ 的类型。（练习 9(4)）

::: details 先自己走两步，再展开

**绝对值**：$\sum\dfrac{\ln n}{n}$，因 $\ln n\ge1$（$n\ge3$）时 $\dfrac{\ln n}{n}\ge\dfrac1n$，由比较法（找更小的发散）⇒ 发散。

**原级数**：$b_n=\dfrac{\ln n}{n}$，$n\ge3$ 后单调递减（求导 $(\ln x/x)'=\frac{1-\ln x}{x^{2}}<0$）且 $\to0$，莱布尼茨 ⇒ 收敛。结论：**条件收敛**。

单调性用导数验证是"写答卷"的标准姿势。

:::

:::

**随堂测 1：用莱布尼茨判别法判 $\sum(-1)^{n-1}b_n$ 收敛，需要验证**

- A. $b_n\to0$
- B. $b_n$ 单调递减且 $b_n\to0$
- C. $b_n$ 单调递增且 $b_n\to0$
- D. $\sum b_n$ 收敛

::: details 点开核对答案

**答案：B（$b_n$ 单调递减且 $b_n\to0$）** —— 两个条件缺一不可：趋零 + （最终）单调递减。D 是更强的要求（那叫绝对收敛）——莱布尼茨的价值恰好在 $\sum b_n$ 发散时还能保住收敛。

:::

**随堂测 2：$\sum(-1)^{n-1}\dfrac{1}{n^{p}}$ 当 $p=\dfrac12$ 时的类型是（练习 9(2)）**

- A. 条件收敛
- B. 绝对收敛
- C. 发散
- D. 敛散性无法确定

::: details 点开核对答案

**答案：A（条件收敛）** —— $0&lt;p\le1$ 段位：绝对值是 $p=\frac12\le1$ 的 $p$-级数（发散），自身满足莱布尼茨（收敛）⇒ 条件收敛。B 需要 $p&gt;1$。

:::

**随堂测 3：$\sum(-1)^{n}\dfrac{n}{n+1}$ 的类型是（练习 9(3)）**

- A. 绝对收敛
- B. 条件收敛
- C. 发散
- D. 收敛性与 $n$ 的奇偶有关

::: details 点开核对答案

**答案：C（发散）** —— $b_n=\dfrac{n}{n+1}\to1\neq0$——莱布尼茨第二条件直接失败，且通项不趋零 ⇒ 发散。&lt;strong&gt;判级数永远第一步安检通项&lt;/strong&gt;。

:::

**随堂测 4：$\sum(-1)^{n-1}\dfrac{1}{n^{2}}$ 的类型是（练习 9(6)）**

- A. 条件收敛
- B. 绝对收敛
- C. 发散
- D. 既是绝对收敛又是条件收敛

::: details 点开核对答案

**答案：B（绝对收敛）** —— 绝对值 $\sum\frac{1}{n^{2}}$ 收敛（$p=2&gt;1$）⇒ 绝对收敛。D 自相矛盾：条件收敛的前提恰是"不绝对收敛"——两个标签互斥。

:::

**随堂测 5：判断 $\sum(-1)^{n}\sin\dfrac1n$ 类型的第一步应取**

- A. 绝对值 $\sum\sin\dfrac1n$：因 $\sin\dfrac1n\sim\dfrac1n$，与调和级数同阶 ⇒ 发散，再验原级数
- B. 直接宣布绝对收敛
- C. 通项 $\sin\frac1n\to0$，收敛
- D. 用比值法算 $\rho$

::: details 点开核对答案

**答案：A（绝对值 $\sum\sin\dfrac1n$：因 $\sin\dfrac1n\sim\dfrac1n$，与调和级数同阶 ⇒ 发散，再验原级数）** —— 流程第一步取绝对值：$\sin\frac1n\sim\frac1n$（0013 等价替换），比较判发散。第二步：$b_n=\sin\frac1n$ 单调递减趋零，莱布尼茨收敛 ⇒ &lt;strong&gt;条件收敛&lt;/strong&gt;（练习 9(7)）。C 又是"必要条件当充分"。

:::

::: danger 本课易错清单

- 莱布尼茨两条件都验：**趋零 + 单调递减**（单调性可用导数证）
- 三色标签按固定顺序：**先绝对值、后原级数**，别跳步
- 绝对收敛 ⟹ 收敛（可推）；条件收敛 ⟹ 不绝对收敛（互斥标签）
- 交错 $p$-级数分界：$p>1$ 绝对、$0<p\le1$ 条件、$p\le0$ 发散
- 通项不趋零（如 $\frac{n}{n+1}\to1$）直接判发散，不用莱布尼茨
- 绝对收敛级数可换序、条件收敛不可换序——概念选择题考点

:::
