## 一、基本概念与必要条件

::: warning 部分和定义与必要条件

$\sum a_n$ 的部分和 $S_n=a_1+\cdots+a_n$；$S_n\to S$ 存在则**收敛**（和为 $S$），否则发散。**级数的和 ≠ 通项的极限**。

**必要条件**：$\sum a_n$ 收敛 $\Rightarrow a_n\to0$。**只能用来判发散**：$a_n\not\to0$ ⇒ 必发散；$a_n\to0$ **不保证收敛**——调和级数 $\sum\frac1n$ 通项趋零却发散（部分和 $\ln(n+1)\to\infty$）。

增删改**有限项**不改变敛散性（可能改变和）。

:::

:::: tip 算例

例 1（部分和定义）判断 $\sum\dfrac{1}{n(n+1)}$ 的敛散并求和。（练习 5(1)）

::: details 先自己裂项，再展开

$S_n=\sum\limits_{k=1}^{n}\left(\dfrac1k-\dfrac{1}{k+1}\right)=1-\dfrac{1}{n+1}\to1$，**收敛，和为 1**。

同族：$\sum\ln\left(1+\frac1n\right)$ 的 $S_n=\ln(n+1)\to+\infty$ 发散；$\sum\left(\frac{1}{\sqrt{n+1}+\sqrt n}\right)$ 部分和 $\sqrt{n+1}-1\to\infty$ 发散——**裂项三件套的"判散"用法**。

流程提醒：裂项后要**先写有限和 $S_n$ 再取极限**，不能直接"首减尾"。

:::

::::

## 二、两个基准级数（必背）

::: warning 几何级数与 $p$-级数

$$\sum q^{n}:\ \ |q|<1\ \text{收敛}\ \left(\text{和}\ \tfrac{q}{1-q}\right),\quad |q|\ge1\ \text{发散}$$

$$\sum\frac1{n^{p}}:\ \ p>1\ \text{收敛},\quad p\le1\ \text{发散}$$

一切比较判别的"终点"都是这两个基准——看通项与 $q^n$ 或 $\frac{1}{n^p}$ 谁同阶。

:::

## 三、正项级数四大审敛法

| 方法 | 内容 | 适用长相 |
| --- | --- | --- |
| ① 部分/裂项 | 求 $S_n$ 取极限 | 已知 $S_n$、可拆相邻差 |
| ② 比较法（含极限形式） | $a_n$ 与 $b_n$ 同阶 ⇒ 同敛散 | 有理式、根式、对数（与 $n^{-p}$ 同阶） |
| ③ 比值法 | $\rho=\lim\dfrac{a_{n+1}}{a_n}$：$<1$ 收、$>1$ 散、$=1$ 失效 | 含**阶乘、$c^{n}$** |
| ④ 根值法 | $\rho=\lim\sqrt[n]{a_n}$：结论同上 | 通项整体 $[\,u_n\,]^{n}$ |

::: danger 比较法方向铁律

判**收敛**：找**更大**的收敛级数压住它（$a_n\le Cb_n$，$\sum b_n$ 收 ⇒ 收）；判**发散**：找**更小**的发散级数顶住它。方向用反 = 结论反。

:::

:::: tip 算例

例 2（极限比较）判断 $\sum\dfrac{1}{\sqrt{n(n+1)}}$ 与 $\sum\dfrac{\sqrt n}{n^{2}+1}$。（练习 6(2)(10)）

::: details 先自己找同阶，再展开

第一题：$\dfrac{1}{\sqrt{n(n+1)}}\sim\dfrac1n$（分母 $\sim n$），与调和级数同阶 ⇒ **发散**。

第二题：$\dfrac{\sqrt n}{n^{2}+1}\sim\dfrac{\sqrt n}{n^{2}}=\dfrac{1}{n^{3/2}}$，$p=\frac32>1$ ⇒ **收敛**。

操作：**"抓大头的阶数版"**——只保留 $n$ 的最高次，报出等价于 $\frac{1}{n^{p}}$ 的 $p$，查表。

:::

::::

:::: tip 算例

例 3（比值法）判断 $\sum\dfrac{n!}{n^{n}}$ 与 $\sum\dfrac{3^{n}}{n!}$。（练习 7(1)(2)）

::: details 先自己算 $\rho$，再展开

第一题：$\dfrac{a_{n+1}}{a_n}=\dfrac{(n+1)!}{(n+1)^{n+1}}\cdot\dfrac{n^{n}}{n!}=\left(\dfrac{n}{n+1}\right)^{n}\to\dfrac1e<1$ ⇒ **收敛**。

第二题：$\dfrac{a_{n+1}}{a_n}=\dfrac{3}{n+1}\to0<1$ ⇒ **收敛**。

见阶乘先写 $\dfrac{a_{n+1}}{a_n}$；$\left(\frac{n}{n+1}\right)^{n}\to e^{-1}$ 是 0012 重要极限二的变形。

:::

::::

**随堂测 1：$\sum\dfrac{1}{\sqrt n}$ 的敛散性是**

- A. 收敛（通项趋于 0）
- B. 发散（通项不趋于 0）
- C. 发散（$p=\dfrac12\le1$ 的 $p$-级数）
- D. 收敛（$p$-级数）

::: details 点开核对答案

**答案：C（发散（$p=\dfrac12\le1$ 的 $p$-级数））** —— $\dfrac{1}{\sqrt n}=\dfrac{1}{n^{1/2}}$，$p=\frac12\le1$ ⇒ 发散。A 是"必要条件当充分条件"的经典误判——通项趋零只是入场券，不是通行证。

:::

**随堂测 2：用比较判别法证 $\sum\dfrac{1}{n^{2}+1}$ 收敛，正确的比较对象是**

- A. $\dfrac{1}{n^{2}+1}<\dfrac{1}{n^{2}}$，而 $\sum\dfrac{1}{n^{2}}$ 收敛
- B. $\dfrac{1}{n^{2}+1}>\dfrac{1}{n^{2}}$，而 $\sum\dfrac{1}{n^{2}}$ 发散
- C. $\dfrac{1}{n^{2}+1}<\dfrac{1}{n}$，而 $\sum\dfrac{1}{n}$ 收敛
- D. 与 $n^2$ 直接比较大小

::: details 点开核对答案

**答案：A（$\dfrac{1}{n^{2}+1}&lt;\dfrac{1}{n^{2}}$，而 $\sum\dfrac{1}{n^{2}}$ 收敛）** —— 判收敛要找"&lt;strong&gt;更大的收敛级数&lt;/strong&gt;"：$\frac{1}{n^2+1}&lt;\frac1{n^2}$ 且 $\sum\frac1{n^2}$（$p=2$）收敛。B 把 $\sum\frac1{n^2}$ 说成发散（错），C 把调和级数说成收敛（错）。

:::

**随堂测 3：对 $\sum\dfrac{n^{2}}{2^{n}}$ 用比值判别法，$\rho=$（练习 7(3)）**

- A. $2$
- B. $1$
- C. $4$
- D. $\dfrac{1}{2}$

::: details 点开核对答案

**答案：D（$\dfrac{1}{2}$）** —— $\dfrac{a_{n+1}}{a_n}=\dfrac{(n+1)^{2}}{2^{n+1}}\cdot\dfrac{2^{n}}{n^{2}}=\dfrac12\left(1+\dfrac1n\right)^{2}\to\dfrac12&lt;1$ ⇒ 收敛。含 $2^n$、$n^2$ 混合时比值法比抓大头更系统。

:::

**随堂测 4：$\sum\dfrac{1}{3^{n}+1}$ 的正确判法是（练习 6(12)）**

- A. 比值法，$\rho=1$，失效
- B. 极限比较：$\dfrac{1}{3^{n}+1}\sim\dfrac{1}{3^{n}}$，与收敛的几何级数同阶 ⇒ 收敛
- C. 通项不趋零 ⇒ 发散
- D. 与 $\sum\frac{1}{3^n}$ 逐项比较大小后仍无法判断

::: details 点开核对答案

**答案：B（极限比较：$\dfrac{1}{3^{n}+1}\sim\dfrac{1}{3^{n}}$，与收敛的几何级数同阶 ⇒ 收敛）** —— $3^n+1\sim3^n$，故 $a_n\sim\left(\frac13\right)^{n}$，几何级数 $|q|=\frac13&lt;1$ 收敛 ⇒ 收敛。B 备选：$\frac{1}{3^n+1}&lt;\frac{1}{3^n}$ 直接用比较法也行——两条路都通。

:::

**随堂测 5：对 $\sum\dfrac{(n+1)!}{10^{n}}$ 判敛，正确的是（练习 7(6)）**

- A. 比值法：$\rho=\lim\dfrac{n+2}{10}=+\infty>1$，发散
- B. 比较法：与 $\sum\dfrac{1}{10^{n}}$ 同阶，收敛
- C. 根值法：$\rho=0$，收敛
- D. 通项趋于 0，收敛

::: details 点开核对答案

**答案：A（比值法：$\rho=\lim\dfrac{n+2}{10}=+\infty&gt;1$，发散）** —— 见阶乘上比值法：$\dfrac{a_{n+1}}{a_n}=\dfrac{(n+2)!}{10^{n+1}}\cdot\dfrac{10^{n}}{(n+1)!}=\dfrac{n+2}{10}\to\infty$ ⇒ 发散。B 的"同阶"完全错误（阶乘吊打指数——0011 速度链的级数版）；D 又是必要条件误用。

:::

::: danger 本课易错清单

- **$a_n\to0$ 只是必要条件**：调和级数 $\sum\frac1n$ 是"趋零但发散"的头号反例
- 比较法方向：判收找**大**的收敛、判散找**小**的发散
- 比值 / 根值 $\rho=1$ 时**失效**（如 $\sum\frac1n$ 与 $\sum\frac1{n^2}$ 都是 $\rho=1$）——必须换比较法
- 几何级数看 $|q|$；$p$-级数看 $p>1$——两条分界线别画反
- 裂项判敛先写 $S_n$ 再取极限，别直接"首减尾"

:::

**回忆卡：默写几何级数与 $p$-级数的敛散分界（含几何级数的和）。**

::: details 先回忆，再揭晓

$\sum q^n$：$|q|<1$ 收敛（和 $\frac{q}{1-q}$，从 $n=1$ 起）、$|q|\ge1$ 发散；$\sum\frac1{n^p}$：$p>1$ 收敛、$p\le1$ 发散。

:::
