**混编 1（先认招）：$z=x^{2}y+e^{xy}$，则 $z_{x}=$**

- A. $2xy+e^{xy}$
- B. $2xy+ye^{xy}$
- C. $x^{2}+xe^{xy}$
- D. $2xy-xe^{xy}$

::: details 点开核对答案

**答案：B（$2xy+ye^{xy}$）** —— &lt;strong&gt;认招：多元微分·偏导（冻变量 + 链式）&lt;/strong&gt;。$x^{2}y\to2xy$（$y$ 是常数）；$e^{xy}\to e^{xy}\cdot y$（内层 $xy$ 对 $x$ 导数为 $y$）。A 丢了链式因子 $y$——偏导的链式一步都不能省。

:::

**混编 2：设 $z=f(x^{2}-y^{2},\,xy)$ 可微，则 $z_x=$**

- A. $2xf_1+yf_2$
- B. $-2yf_1+xf_2$
- C. $2xf_1-yf_2$
- D. $f_1+f_2$

::: details 点开核对答案

**答案：A（$2xf_1+yf_2$）** —— &lt;strong&gt;认招：复合求导·树状路径&lt;/strong&gt;。$u=x^{2}-y^{2}$ 对 $x$ 导 $2x$；$v=xy$ 对 $x$ 导 $y$；沿路相乘、同标相加：$z_x=2xf_1+yf_2$。B 是 $z_y$ 的路径——动笔前先画树。

:::

**混编 3：求 $f(x,y)=x^{3}+y^{3}-3xy$ 的极值时，驻点 $(1,1)$ 处的判别结果是**

- A. $AC-B^{2}=27<0$，鞍点
- B. $AC-B^{2}=0$，失效
- C. $AC-B^{2}=27>0$ 且 $A=6>0$，极小值 $-1$
- D. $AC-B^{2}=27>0$ 且 $A<0$，极大值 $1$

::: details 点开核对答案

**答案：C（$AC-B^{2}=27&gt;0$ 且 $A=6&gt;0$，极小值 $-1$）** —— &lt;strong&gt;认招：$AC-B^{2}$ 判别四步&lt;/strong&gt;。$f_x=3x^{2}-3y$、$f_y=3y^{2}-3x$；$(1,1)$ 处 $A=f_{xx}=6$、$B=f_{xy}=-3$、$C=f_{yy}=6$，$\Delta=36-9=27&gt;0$，$A&gt;0$ ⇒ 极小值 $f(1,1)=-1$。$(0,0)$ 驻点才是 $\Delta=0$ 失效的那个。

:::

**混编 4：$\displaystyle\iint_D(x^{2}+y^{2})\,d\sigma$，$D:x^{2}+y^{2}\le4$，等于**

- A. $4\pi$
- B. $8\pi$
- C. $16\pi$
- D. $2\pi$

::: details 点开核对答案

**答案：B（$8\pi$）** —— &lt;strong&gt;认招：二重积分·极坐标（带 $r$！）&lt;/strong&gt;。$\int_0^{2\pi}d\theta\int_0^2r^{3}dr=2\pi\cdot\frac{16}{4}=8\pi$。A 漏了面积元 $r$；被积 $r^2$ + 面积元 $r$ = $r^3$，一环扣一环。

:::

**混编 5：交换 $\displaystyle\int_0^{1}dx\int_0^{x}f(x,y)\,dy$ 的次序，得**

- A. $\displaystyle\int_0^{1}dy\int_0^{y}f(x,y)\,dx$
- B. $\displaystyle\int_0^{1}dy\int_y^{1}f(x,y)\,dx$
- C. $\displaystyle\int_0^{1}dy\int_0^{1}f(x,y)\,dx$
- D. $\displaystyle\int_y^{1}dx\int_0^{1}f(x,y)\,dy$

::: details 点开核对答案

**答案：B（$\displaystyle\int_0^{1}dy\int_y^{1}f(x,y)\,dx$）** —— 区域：$0\le x\le1$、$0\le y\le x$（下三角）。换横条：$0\le y\le1$、$y\le x\le1$，即 B。A 的内层 $[0,y]$ 是另一块三角形（对偶题 $\int_0^1dy\int_0^y$ 对应的区域是上三角）；C 外层限写成了矩形；D 连内外层结构都没换。&lt;strong&gt;交换次序必先画图，"换符号不换区域"等于没换&lt;/strong&gt;。

:::

**混编 6：$\displaystyle\iint_D 1\,d\sigma$（$D$：$0\le x\le1$，$0\le y\le1-x$）等于**

- A. $\dfrac{1}{2}$
- B. $1$
- C. $\dfrac{1}{3}$
- D. $2$

::: details 点开核对答案

**答案：A（$\dfrac{1}{2}$）** —— &lt;strong&gt;认招：被积函数为 1 ⇒ 积分 = 面积&lt;/strong&gt;。直角三角形两直角边为 1，面积 $\frac12$。（这也是冲刺练习 1 的答案来源——先量形状，再决定要不要真算。）

:::

**混编 7：级数 $\sum\dfrac{1}{\sqrt{n}(n+1)}$ 的敛散性是**

- A. 发散（$p=1$）
- B. 收敛（$p=2$）
- C. 收敛（与 $p=\dfrac32$ 的 $p$-级数同阶）
- D. 发散（通项不趋零）

::: details 点开核对答案

**答案：C（收敛（与 $p=\dfrac32$ 的 $p$-级数同阶））** —— &lt;strong&gt;认招：极限比较法&lt;/strong&gt;。$\dfrac{1}{\sqrt n(n+1)}\sim\dfrac{1}{n^{3/2}}$，$p=\frac32&gt;1$ ⇒ 收敛（练习 6(5)）。D 错——通项 $\to0$ 没问题；通项趋零本来就不是收敛的保证，但这里确实收敛。

:::

**混编 8（综合）：级数 $\sum(-1)^{n-1}\dfrac{1}{\sqrt n}$ 的类型是**

- A. 条件收敛
- B. 绝对收敛
- C. 发散
- D. 敛散性取决于 $n$ 的起始值

::: details 点开核对答案

**答案：A（条件收敛）** —— &lt;strong&gt;认招：三色标签流程&lt;/strong&gt;。绝对值 $\sum\frac{1}{\sqrt n}$ 是 $p=\frac12\le1$ 的 $p$-级数，发散；原级数满足莱布尼茨（$\frac{1}{\sqrt n}$ 单调递减趋零）收敛 ⇒ 条件收敛（练习 9(2) 同型）。增删有限项不改变敛散性——D 是干扰项。

:::
