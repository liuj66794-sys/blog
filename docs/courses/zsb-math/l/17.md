## 一、连续：一个极限等式

::: warning 定义与判断三步

**定义二（极限式）**：$f(x)$ 在 $x_0$ 处连续 $\iff\lim\limits_{x\to x_0}f(x)=f(x_0)$。（定义一是增量式 $\lim\limits_{\Delta x\to0}\Delta y=0$，两者等价。）

**判断三步**：① $f(x_0)$ 有定义？② 左右极限存在？③ 都等于 $f(x_0)$？——**三问全"是"才连续**。

左右连续：$\lim\limits_{x\to x_0^-}f=f(x_0)$ 称左连续，右侧同理；连续 ⟺ 既左连续又右连续。

:::

一条"免费定理"：**初等函数在其定义域内处处连续**。它反过来就是 0011 课直接代入法的合法性证明——$\lim\limits_{x\to2}\sqrt{7-x^2}=\sqrt3$、$\lim\limits_{x\to\frac\pi2}\ln(\sin x)=0$ 不需要任何技巧。

概念强弱链（小充分大必要）："有定义"是"连续"的**必要条件**；"连续"是"极限存在"的**充分条件**。即：连续 ⇒ 极限存在 ⇒ 可以没定义（链条单向）。

**随堂测 1："$f(x)$ 在 $x_0$ 处有定义"是"$f(x)$ 在 $x_0$ 处连续"的（夏讲原题）**

- A. 必要条件
- B. 充分条件
- C. 充要条件
- D. 既不充分也不必要

::: details 点开核对答案

**答案：A（必要条件）** —— 连续必先有定义（判断三步第一步），但光有定义不保证连续（如 $\frac{\sin x}{x}$ 补定义 $f(0)=0$ 仍不连续）。有定义 $\Leftarrow$ 连续，故是必要条件。姊妹题："连续"是"极限存在"的&lt;strong&gt;充分&lt;/strong&gt;条件。

:::

## 二、间断点：先找全，再分类

::: warning 四类间断点

| 大类 | 情形 | 名称 |
| --- | --- | --- |
| 第一类（左右极限**都存在**） | 左右极限不相等 | **跳跃** |
| 极限存在但 $\neq f(x_0)$，或该点无定义 | **可去** |   |
| 第二类（左右极限至少一个不存在） | 至少一个为 $\infty$ | **无穷** |
| 至少一个振荡 | **振荡** |   |

**找点清单**：① 分母 / 真数 / arcsin 内部的**无定义点**；② **分段点**。找全后逐点算左右极限，按表归类。

:::

::: tip 算例

例 1（四个代表）判断间断点类型：

(1) $\dfrac{x^{2}-1}{x-1}$ 在 $x=1$；(2) $\dfrac{|x|}{x}$ 在 $x=0$；(3) $\dfrac{1}{x^{2}-4}$ 在 $x=\pm2$；(4) $e^{\frac1x}$ 在 $x=0$

::: details 先逐个左右极限，再展开（秋连续练习 4 精选）

(1) $x=1$ 无定义，但 $\lim\limits_{x\to1}\dfrac{(x+1)(x-1)}{x-1}=2$ **存在** ⇒ **可去**间断点（"约分约掉的点"要单独检查！）。

(2) 左 $=-1$、右 $=1$，都存在不相等 ⇒ **跳跃**。

(3) $x\to\pm2$ 时分母 $\to0$、分子不变 ⇒ **无穷**（两点都是）。

(4) 左：$\frac1x\to-\infty$，$e^{1/x}\to0$；右：$\to+\infty$ ⇒ 右侧无穷 ⇒ **无穷**间断点（0010 课 $e^{1/x}$ 图像的判别版）。

:::

:::

::: tip 算例

例 2（进阶：一函数两类型）讨论 $f(x)=\dfrac{1}{e^{\frac{x}{x-1}}-1}$ 的间断点。

::: details 先找全无定义点，再展开（夏连续教材 P48）

**找点**：指数分母 $x-1=0$ 给 $x=1$；外层 $e^0-1=0$ 给 $x=0$。两个都查。

**$x=1$**：$x\to1^-$ 时 $\frac{x}{x-1}\to-\infty$、$e^{\cdot}\to0$、$f\to\dfrac{1}{0-1}=-1$；$x\to1^+$ 时 $f\to\infty$……都存在？注意左侧 $=-1$、右侧 $\to0^-$ 附近——两侧单侧极限分别为 $-1$ 与 $0$（都存在不相等）⇒ **跳跃**间断点。

**$x=0$**：$\frac{x}{x-1}\to0$，$e^0-1\to0$，$f\to\infty$ ⇒ **无穷**间断点。

一个函数可以同时有不同类型的间断点——逐点独立判。

:::

:::

## 三、由连续逆求参数（高频小题）

::: tip 算例

例 3设 $f(x)=\begin{cases}\dfrac{e^{2x}-1}{x} & x<0\\ 3x^{2}-2x+k & x\ge0\end{cases}$ 在 $x=0$ 处连续，求 $k$。

::: details 先自己算左右，再展开（秋连续练习 3）

左极限：$\dfrac{e^{2x}-1}{x}\sim\dfrac{2x}{x}=2$；右极限：$3(0)-2(0)+k=k$。连续要求左 $=$ 右（$x=0$ 处函数值即 $k$），故 $k=2$。

同款：$f(x)=\dfrac{\sin2x}{x}\ (x\neq0)$，补充定义 $f(0)=k$ 使连续 → $k=\lim\limits_{x\to0}\dfrac{\sin2x}{x}=2$——**可去间断点的"修补"正是逆求参数的来源**。

:::

:::

**随堂测 2：$x=1$ 是 $\dfrac{x^{2}-4x+3}{x^{2}+x-2}$ 的哪类间断点？**

- A. 跳跃间断点
- B. 可去间断点
- C. 无穷间断点
- D. 连续点

::: details 点开核对答案

**答案：B（可去间断点）** —— 分解 $\dfrac{(x-1)(x-3)}{(x+2)(x-1)}$：$x=1$ 无定义但约分后极限 $=-\dfrac23$ 存在 ⇒ 可去。（$x=-2$ 才是无穷间断点。）"无定义但极限存在"= 可去，一条口诀判一半。

:::

**随堂测 3：设 $f(x)=\begin{cases}(1+x)^{\frac3x} & x\neq0\\ a & x=0\end{cases}$ 在 $x=0$ 连续，则 $a=$（夏讲原题）**

- A. $e$
- B. $e^{2}$
- C. $e^{3}$
- D. $1$

::: details 点开核对答案

**答案：C（$e^{3}$）** —— 连续 ⟺ $a=\lim\limits_{x\to0}(1+x)^{\frac3x}$。这是 $1^{\infty}$ 型：$v(u-1)=\dfrac{3x}{x}=3$，极限 $e^3$。（0012 三步法 + 0017 连续条件的组合拳，考试最爱。）

:::

**随堂测 4：$f(x)=\dfrac{\arcsin x}{x(x+3)}$ 的间断点情况是**

- A. $x=0$ 是无穷间断点
- B. $x=0$ 是跳跃间断点
- C. 只有 $x=-3$ 一个间断点
- D. $x=0$ 可去、$x=-3$ 无穷

::: details 点开核对答案

**答案：D（$x=0$ 可去、$x=-3$ 无穷）** —— $x=0$：$\arcsin x\sim x$，极限 $=\dfrac{1}{0+3}=\dfrac13$ 存在但无定义 ⇒ 可去。$x=-3$：分母 $\to0$、分子 $\arcsin(-3)$ 又无意义，属无穷型。两个无定义点，逐点判，别漏。

:::

**随堂测 5："$\lim\limits_{x\to a}f(x)$ 存在"是"$f(x)$ 在 $a$ 处连续"的**

- A. 必要条件
- B. 充分条件
- C. 充要条件
- D. 毫无关系

::: details 点开核对答案

**答案：A（必要条件）** —— 连续 ⇒ 极限存在（且等于函数值）；但极限存在可以没有 $f(a)$（可去间断点）。所以"极限存在"弱一档，是必要条件。与随堂测 1 合起来就是完整的强弱链：连续 &gt; 极限存在 &gt; 有定义。

:::

::: danger 本课易错清单

- 间断点要**找全**：分母零点、真数边界、arcsin 越界、分段点，一个不漏
- **约分约掉的点**是可去间断点，不是"没事了"
- 第一类 vs 第二类的分界：左右极限**是否都存在**（不是是否相等）
- 可去间断点 = "极限存在但不连续"——修补法即逆求参数题
- 分段点连续 ⟺ 左 $=$ 右 $=$ 该点函数值（三量对齐）

:::

**回忆卡：默写连续判断三步，并画出强弱链：有定义 / 极限存在 / 连续，谁推谁？**

::: details 先回忆，再揭晓

①有定义 ②左右极限存在 ③都等于 $f(x_0)$，全"是"才连续。连续 ⇒ 极限存在 ⇒ 可无定义；"有定义"是"连续"的必要条件。

:::

**回忆卡：四类间断点各举一例（可去、跳跃、无穷、振荡），并说出第一类 / 第二类的分界标准。**

::: details 先回忆，再揭晓

可去：$\frac{x^2-1}{x-1}$ 于 $x=1$；跳跃：$\frac{|x|}{x}$ 于 0；无穷：$\frac{1}{x^2-4}$ 于 $\pm2$；振荡：$\sin\frac1x$ 于 0。分界：第一类左右极限**都存在**。

:::
