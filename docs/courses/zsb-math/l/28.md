::: tip 本课结束，你能

- 对 $\sqrt[n]{ax+b}$ 型直接**令根式为 $t$**；双根号并存取**最小公倍根**
- 按根号长相选对三角换元（$\sqrt{a^2-x^2}$ / $\sqrt{x^2+a^2}$ / $\sqrt{x^2-a^2}$ 三选一）
- 换元后**画直角三角形回代**，不把 $t$ 留在答案里

第二换元与凑微分方向相反：凑微分是"**把 $x$ 的函数收进 $d$ 里**"，第二换元是"**把 $x$ 整个换掉**"（$x=\varphi(t)$）。它专治凑微分搞不定的根式。

## 一、流程与根式换元

::: warning 三步流程

令 $x=\varphi(t)$ → 积出关于 $t$ 的结果 $F(t)+C$ → **回代** $t=\varphi^{-1}(x)$。

| 情形 | 换元 |
| --- | --- |
| 含 $\sqrt[n]{ax+b}$ | 令 $t=\sqrt[n]{ax+b}$ |
| 同时含 $\sqrt[n]{x}$、$\sqrt[m]{x}$ | 取最小公倍根 $k$，令 $t=\sqrt[k]{x}$ |
| 分母含 $x$ 高次幂（$\frac{1}{x^{100}+x}$ 型） | 倒代换 $x=\dfrac1t$ |

:::

:::: tip 算例

例 1（标准根式换元）$\displaystyle\int\dfrac{dx}{1+\sqrt x}$。（夏讲 P40 / 秋讲练习 10(1)）

::: details 先自己换元，再展开

令 $t=\sqrt x$，$x=t^{2}$，$dx=2t\,dt$：

$\int\dfrac{2t}{1+t}dt=2\int\left(1-\dfrac{1}{1+t}\right)dt=2t-2\ln(1+t)+C=2\sqrt x-2\ln(1+\sqrt x)+C$。

要点：换元后分子分母**都是 $t$ 的多项式**，"根号消失"是根式换元的胜利标志。

:::

::::

:::: tip 算例

例 2（最小公倍根）$\displaystyle\int\dfrac{dx}{\sqrt x+\sqrt[3]{x}}$。（夏讲 P41）

::: details 先定 $t$，再展开

取 $2,3$ 的最小公倍数 6，令 $t=\sqrt[6]x$，$x=t^{6}$，$dx=6t^{5}dt$：

$\int\dfrac{6t^{5}}{t^{3}+t^{2}}dt=6\int\dfrac{t^{3}}{t+1}dt=6\int\left(t^{2}-t+1-\dfrac{1}{t+1}\right)dt$

$=2\sqrt x-3\sqrt[3]x+6\sqrt[6]x-6\ln(1+\sqrt[6]x)+C$（回代后每个根号都以 $x$ 的幂形式呈现）。

中途那个 $6\int\frac{t^3}{t+1}dt$ 是"假分式长除"（下一课主角）——第二换元常与后续技巧接力。

:::

::::

## 二、三角换元：根号下的二次幂

::: warning 三选一（必背）

| 根式结构 | 换元 | 化简结果 |
| --- | --- | --- |
| $\sqrt{a^{2}-x^{2}}$ | $x=a\sin t$ | $=a\cos t$ |
| $\sqrt{x^{2}+a^{2}}$ | $x=a\tan t$ | $=a\sec t$ |
| $\sqrt{x^{2}-a^{2}}$ | $x=a\sec t$ | $=a\tan t$ |

原理只有一个：**三角平方关系**（$\sin^2+\cos^2=1$、$1+\tan^2=\sec^2$、$\sec^2-1=\tan^2$）吃掉根号。

:::

:::: tip 算例

例 3（经典必会）$\displaystyle\int\sqrt{a^{2}-x^{2}}\,dx\ (a>0)$。（夏讲 P44）

::: details 先自己换元积出 $t$，再展开

令 $x=a\sin t$，$\sqrt{a^{2}-x^{2}}=a\cos t$，$dx=a\cos t\,dt$：

$\int a^{2}\cos^{2}t\,dt=a^{2}\int\dfrac{1+\cos2t}{2}dt=\dfrac{a^{2}}{2}t+\dfrac{a^{2}}{4}\sin2t+C=\dfrac{a^{2}}{2}t+\dfrac{a^{2}}{2}\sin t\cos t+C$。

**画直角三角形回代**：对边 $x$、斜边 $a$ ⇒ 邻边 $\sqrt{a^{2}-x^{2}}$，故 $\sin t=\dfrac xa$、$\cos t=\dfrac{\sqrt{a^{2}-x^{2}}}{a}$。

答案：$\dfrac{a^{2}}{2}\arcsin\dfrac{x}{a}+\dfrac{x\sqrt{a^{2}-x^{2}}}{2}+C$。$a=1$ 时即 $\int\sqrt{1-x^{2}}dx=\dfrac x2\sqrt{1-x^{2}}+\dfrac12\arcsin x+C$（秋讲练习 10(10)）。

:::

::::

::: warning 画三角形回代（三情形对照）

| 换元 | 三角形设边 | 常用回代 |
| --- | --- | --- |
| $x=a\sin t$ | 对边 $x$、斜边 $a$ | $\cos t=\dfrac{\sqrt{a^{2}-x^{2}}}{a}$ |
| $x=a\tan t$ | 对边 $x$、邻边 $a$ | $\sec t=\dfrac{\sqrt{x^{2}+a^{2}}}{a}$ |
| $x=a\sec t$ | 斜边 $x$、邻边 $a$ | $\tan t=\dfrac{\sqrt{x^{2}-a^{2}}}{a}$ |

:::

:::: tip 算例

例 4（倒代换见识）$\displaystyle\int\dfrac{dx}{x^{100}+x}$。（夏讲 P42）

::: details 先自己试 $x=1/t$，再展开

令 $x=\dfrac1t$，$dx=-\dfrac{1}{t^{2}}dt$：$\dfrac{1}{x^{100}+x}=\dfrac{t^{100}}{1+t^{99}}$，

$\int\dfrac{t^{100}}{1+t^{99}}\cdot\left(-\dfrac{1}{t^{2}}\right)dt=-\int\dfrac{t^{98}}{1+t^{99}}dt=-\dfrac{1}{99}\ln\left|1+t^{99}\right|+C$（万能型凑微分！）。

回代：$=\ln|x|-\dfrac{1}{99}\ln(1+x^{99})+C$。倒代换专治"**分母 $x$ 的次数压过分子**"。

:::

::::

**随堂测 1：积分 $\displaystyle\int x\sqrt{x-2}\,dx$ 应令（秋讲练习 10(2)）**

- A. $t=\sqrt{x-2}$
- B. $t=x-2$
- C. $x=2\sin t$
- D. $t=\sqrt x$

::: details 点开核对答案

**答案：A（$t=\sqrt{x-2}$）** —— $\sqrt{x-2}$ 里的 $x-2$ 让平方差失效，直接令 $t=\sqrt{x-2}$：$x=t^{2}+2$、$dx=2t\,dt$，化成 $\int2(t^{2}+2)t^{2}dt$。B 只换掉根号里面的东西，根号还在；C 是三角换元——它只管 $a^2-x^2$ 型。

:::

**随堂测 2：积分 $\displaystyle\int\dfrac{1}{\sqrt x+\sqrt[3]x}dx$ 的正确换元是（夏讲 P41）**

- A. $t=\sqrt x$
- B. $t=\sqrt[3]x$
- C. $t=\sqrt[6]x$（最小公倍根）
- D. $x=\dfrac1t$

::: details 点开核对答案

**答案：C（$t=\sqrt[6]x$（最小公倍根））** —— $\sqrt x=t^{3}$、$\sqrt[3]x=t^{2}$ 同时被 $t=\sqrt[6]x$ 消灭。选 2 或 3 都会留下一个根号——&lt;strong&gt;最小公倍根一次清场&lt;/strong&gt;。

:::

**随堂测 3：积分 $\displaystyle\int\sqrt{x^{2}+4}\,dx$ 应令**

- A. $x=2\sin t$
- B. $x=2\tan t$
- C. $x=2\sec t$
- D. $t=\sqrt{x^{2}+4}$

::: details 点开核对答案

**答案：B（$x=2\tan t$）** —— $x^{2}+4=2^{2}+x^{2}$ 是"$+$"型 → $x=a\tan t$，根号变 $2\sec t$。A 是"$-$"型（$a^{2}-x^{2}$）；C 是 $x^{2}-a^{2}$ 型。对照口诀：&lt;strong&gt;减号正弦、加号正切、反减正割&lt;/strong&gt;。

:::

**随堂测 4：计算 $\displaystyle\int\sqrt{1-x^{2}}\,dx$ 令 $x=\sin t$ 后，最终答案里 $\cos t$ 应回代为（秋讲练习 10(10)）**

- A. $x$
- B. $1-x$
- C. $\dfrac{1}{\sqrt{1-x^{2}}}$
- D. $\sqrt{1-x^{2}}$

::: details 点开核对答案

**答案：D（$\sqrt{1-x^{2}}$）** —— 画三角形：$x=\sin t$ ⇒ 对边 $x$、斜边 1 ⇒ 邻边 $\sqrt{1-x^{2}}$，$\cos t=$ 邻/斜 $=\sqrt{1-x^{2}}$。&lt;strong&gt;画三角形回代&lt;/strong&gt;比背公式可靠——A 是 $\sin t$，C 是 $\sec t$。

:::

**随堂测 5：积分 $\displaystyle\int\dfrac{dx}{x\sqrt{x^{2}-1}}$ 的合适解法是（秋讲练习 10(7)）**

- A. 倒代换 $x=\dfrac1t$，得 $-\arcsin\dfrac1x+C$
- B. 令 $t=\sqrt{x^{2}-1}$，得 $\ln|t|+C$
- C. 分部积分，取 $u=\dfrac{1}{x}$
- D. 直接凑微分得 $\ln\left|x+\sqrt{x^{2}-1}\right|+C$

::: details 点开核对答案

**答案：A（倒代换 $x=\dfrac1t$，得 $-\arcsin\dfrac1x+C$）** —— $x=\dfrac1t$ 后 $\dfrac{1}{x\sqrt{x^{2}-1}}=\dfrac{-t}{\sqrt{1-t^{2}}}$ 型，积出 $-\arcsin t$。D 的形状是 $\int\frac{dx}{x^{2}\pm a^{2}}$ 家族——分母里&lt;strong&gt;没有&lt;/strong&gt;单独的 $x$ 因子，套不上。识别：分母 $x$ 的次数高 → 想倒代换。

:::

::: danger 本课易错清单

- 换元三件套写全：**$x=\varphi(t)$、$dx=\varphi'(t)dt$、回代**——$t$ 不能留在答案里
- 三角换元**三选一**按根号符号走；选错则根号除不掉
- 回代**画直角三角形**，$\cos t$、$\tan t$ 按边比写，不靠记忆硬背
- 第二换元后常接"长除 / 凑微分"接力，一条链算到底
- $\int\sqrt{a^{2}-x^{2}}dx$ 的结论（$\frac{x}{2}\sqrt{\cdot}+\frac{a^2}{2}\arcsin$）在 0034 课算圆面积还回来——记结论也行

:::

**回忆卡：默写三角换元三选一：$\sqrt{a^2-x^2}$、$\sqrt{x^2+a^2}$、$\sqrt{x^2-a^2}$ 各令什么？各化成什么？**

::: details 先回忆，再揭晓

$x=a\sin t\to a\cos t$；$x=a\tan t\to a\sec t$；$x=a\sec t\to a\tan t$。口诀：减号正弦、加号正切、反减正割。

:::

**回忆卡：第二换元三情形（根式、双根号、高次分母）各怎么换元？流程最后一步是什么？**

::: details 先回忆，再揭晓

$t=\sqrt[n]{ax+b}$；取最小公倍根 $t=\sqrt[k]x$；倒代换 $x=\frac1t$。最后一步：回代 $t=\varphi^{-1}(x)$，不留 $t$。

:::
