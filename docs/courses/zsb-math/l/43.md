微分方程章的大题终点站：二阶常系数线性方程 $y''+py'+qy=f(x)$。解法是纯模板：**特征方程 → 齐次通解 → 待定特解 → 相加**。模板熟，这就是全卷最稳的大题。

## 一、三类可降阶方程

| 类型 | 钥匙 | 说明 |
| --- | --- | --- |
| $y^{(n)}=f(x)$ | 连续积分 $n$ 次 | 每次补一个常数 |
| $F(x,y',y'')=0$（缺 $y$） | 令 $p=y'$，$y''=p'$ | 先解 $p(x)$ 的一阶方程，再积 $y'=p$ |
| $F(y,y',y'')=0$（缺 $x$） | 令 $p(y)=y'$，$y''=p\dfrac{dp}{dy}$ | 链式法则；解出 $p(y)$ 后再分离 |

::: tip 算例

例 1（缺 $x$ 型）解 $y''=(y')^{2}+1$。（练习 12(6)）

::: details 先自己降阶，再展开

令 $p=y'$，$y''=p\dfrac{dp}{dy}$：$p\dfrac{dp}{dy}=p^{2}+1$，分离 $\dfrac{p\,dp}{1+p^{2}}=dy$。

积分：$\dfrac12\ln(1+p^{2})=y+C$，取 $p=\tan(x+C_1)$（对应 $p' = p^2+1$ 沿 $x$ 解的另一支——两种降阶路径同果）：

通解 $$y=-\ln\left|\cos(x+C_1)\right|+C_2$$

验算：$y'=\tan(x+C_1)$，$y''=\sec^{2}(x+C_1)=1+\tan^{2}=1+(y')^{2}$ ✓。**缺 $x$ 型的 $y''=p\frac{dp}{dy}$ 不是 $p'$**——链式法则的代价。

:::

:::

## 二、线性方程解的结构（先立规矩）

::: warning 结构定理

齐次解可叠加：$y_1,y_2$ 是齐次解 ⇒ $C_1y_1+C_2y_2$ 仍是（二阶时线性无关的两解即**齐次通解** $y_c$）。

**非齐次通解 = 齐次通解 + 任一特解**：$y=y_c+y_p$（特解不带任意常数）。两个非齐次特解之**差**是齐次解；右端相加时特解可相加。

:::

## 三、二阶常系数齐次：特征方程法

::: warning 必背三模板（$y''+py'+qy=0$，特征方程 $r^{2}+pr+q=0$）

| 根的类型 | 通解 |
| --- | --- |
| 两个不同实根 $r_1\neq r_2$ | $y=C_{1}e^{r_{1}x}+C_{2}e^{r_{2}x}$ |
| 二重根 $r$ | $y=(C_{1}+C_{2}x)e^{rx}$（**补 $x$**） |
| 共轭复根 $\alpha\pm\beta i$ | $y=e^{\alpha x}(C_{1}\cos\beta x+C_{2}\sin\beta x)$ |

:::

::: tip 算例

例 2（三模板各来一道）解 $y''-7y'+12y=0$；$4y''-12y'+9y=0$；$y''+2y'+3y=0$。

::: details 先自己算根，再展开（练习 15 同族）

① $r^{2}-7r+12=(r-3)(r-4)=0$，根 $3,4$：$y=C_1e^{3x}+C_2e^{4x}$。

② $4r^{2}-12r+9=0$，$\Delta=144-144=0$，重根 $r=\dfrac32$：$y=(C_1+C_2x)e^{\frac32x}$。

③ $r^{2}+2r+3=0$，$\Delta<0$，$r=-1\pm\sqrt2 i$：$y=e^{-x}(C_1\cos\sqrt2 x+C_2\sin\sqrt2 x)$。

流程：**写特征方程 → 求根 → 对模板抄答案**，一分钟内收工。

:::

:::

## 四、二阶常系数非齐次：待定特解

::: warning 两类右端的设法（含共振）

**① $f(x)=P_m(x)e^{\lambda x}$**：设 $y_p=x^{k}Q_m(x)e^{\lambda x}$——$\lambda$ 不是根 / 单根 / 二重根时 $k=0/1/2$。

**② $f(x)=e^{\alpha x}[P\cos\beta x+Q\sin\beta x]$**：设 $y_p=x^{k}e^{\alpha x}[R\cos\beta x+S\sin\beta x]$——$\alpha\pm\beta i$ 是特征根时 $k=1$，否则 $k=0$；**只给正弦也要设余弦**（两项成对）。

:::

::: tip 算例

例 3（夏讲 P61 全流程）解 $y''-5y'+6y=xe^{2x}$。

::: details 先自己走四步，再展开

**① 齐次通解**：$r^{2}-5r+6=0$，$r=2,3$：$y_c=C_1e^{2x}+C_2e^{3x}$。

**② 设特解**：$\lambda=2$ 是单根 ⇒ $k=1$：$y_p=xe^{2x}(Ax+B)$。

**③ 代回定系数**：得 $A=-\dfrac12$，$B=-1$。

**④ 相加**：$$y=C_{1}e^{2x}+C_{2}e^{3x}-e^{2x}\left(\frac{x^{2}}{2}+x\right)$$

共振一眼判：右端 $e^{2x}$ 撞上特征根 2 ⇒ 乘 $x$。**"撞根乘 $x$"是本考点全部的灵魂**。

:::

:::

::: tip 算例

例 4（三角右端）解 $y''-y'-2y=\sin3x$。（夏讲 P64）

::: details 先自己设法，再展开

$y_c=C_1e^{2x}+C_2e^{-x}$（根 $2,-1$）。$\pm3i$ 不是特征根 ⇒ $k=0$，且正弦也要配余弦：$y_p=A\cos3x+B\sin3x$。代回解出 $A=\dfrac{3}{130}$，$B=-\dfrac{11}{130}$。

$$y=C_{1}e^{2x}+C_{2}e^{-x}+\frac{3}{130}\cos3x-\frac{11}{130}\sin3x$$

设特解写"两项成对"的理由：对 $\sin$ 单独设常导致系数方程缺行、解不出。

:::

:::

**随堂测 1：方程 $y''+2y'+y=0$ 的通解是（练习 15(7) 同族）**

- A. $C_1e^{x}+C_2e^{-x}$
- B. $C_1\cos x+C_2\sin x$
- C. $(C_1+C_2x)e^{-x}$
- D. $C_1e^{-x}+C_2xe^{x}$

::: details 点开核对答案

**答案：C（$(C_1+C_2x)e^{-x}$）** —— 特征方程 $(r+1)^{2}=0$，二重根 $r=-1$ ⇒ $(C_1+C_2x)e^{-x}$。&lt;strong&gt;重根补 $x$&lt;/strong&gt;——漏 $x$ 项只有一个任意常数，不构成通解。

:::

**随堂测 2：方程 $y''+4y=0$ 的通解是（练习 15(12) 同族）**

- A. $C_1\cos2x+C_2\sin2x$
- B. $(C_1+C_2x)e^{2x}$
- C. $C_1e^{2x}+C_2e^{-2x}$
- D. $e^{2x}(C_1\cos x+C_2\sin x)$

::: details 点开核对答案

**答案：A（$C_1\cos2x+C_2\sin2x$）** —— $r^{2}+4=0$ ⇒ $r=\pm2i$（纯虚根，$\alpha=0,\beta=2$）⇒ $e^{0x}=1$，得 $C_1\cos2x+C_2\sin2x$。C 是 $r=\pm2$ 的样子——虚根与实根差一个 $i$，通解形状完全不同。

:::

**随堂测 3：$y''-5y'+6y=xe^{2x}$ 中，特解应设为**

- A. $y_p=(Ax+B)e^{2x}$
- B. $y_p=x(Ax+B)e^{2x}$
- C. $y_p=Ax^{2}e^{2x}$
- D. $y_p=Axe^{3x}$

::: details 点开核对答案

**答案：B（$y_p=x(Ax+B)e^{2x}$）** —— 右端 $\lambda=2$ 恰为单根 ⇒ 共振乘 $x^{1}$：$x(Ax+B)e^{2x}$。A 没乘 $x$——代回会"两头落空"（左端算出 0）；C 多乘了；D 的指数撞错根。

:::

**随堂测 4：$y''+y' = 0$ 且右端 $f(x)=x$ 时，特解应设为**

- A. $Ax+B$
- B. $Ae^{x}$
- C. $Ax^{3}$
- D. $x(Ax+B)$

::: details 点开核对答案

**答案：D（$x(Ax+B)$）** —— 特征根 $0,-1$：右端 $x=xe^{0x}$ 的 $\lambda=0$ 是单根 ⇒ 共振乘 $x$：$x(Ax+B)=Ax^{2}+Bx$。&lt;strong&gt;常数右端也是 $e^{0x}$&lt;/strong&gt;——$\lambda=0$ 撞根的隐性情形，最易漏。

:::

**随堂测 5：设 $y_1,y_2,y_3$ 是 $L[y]=f(x)$ 的三个特解，则 $L[y]=f(x)$ 的通解可写成**

- A. $C_1y_1+C_2y_2+(1-C_1-C_2)y_3$
- B. $C_1y_1+C_2y_2+C_3y_3$（三个常数）
- C. $y_1+y_2+y_3$
- D. $C(y_1-y_2)+y_3$ 之外无其他形式

::: details 点开核对答案

**答案：A（$C_1y_1+C_2y_2+(1-C_1-C_2)y_3$）** —— $y_1-y_3$、$y_2-y_3$ 都是齐次解，通解 = 齐次通解 + $y_3$，整理即 A（夏讲 P50 选择题）。B 的三个常数不独立（二阶方程只容两个）。

:::

::: danger 本课易错清单

- 特征根三模板：**重根补 $x$**、复根写实函数 $e^{\alpha x}(\cos\beta x,\sin\beta x)$
- 非齐次特解**不带任意常数**；最终通解 $y=y_c+y_p$
- 设特解先查共振：**$\lambda$ 撞特征根就乘 $x^{k}$**（单根 $k=1$、重根 $k=2$）
- 三角右端两项成对设；常数右端视作 $\lambda=0$ 查共振
- 缺 $y$ 型令 $p=y'$、$y''=p'$；缺 $x$ 型令 $p(y)=y'$、$y''=p\dfrac{dp}{dy}$——两把钥匙别插错锁
- 解完**代回原方程**验算（本单元最便宜的满分保险）

:::

**回忆卡：默写特征方程三类根对应的齐次通解模板。**

::: details 先回忆，再揭晓

异根：$C_1e^{r_1x}+C_2e^{r_2x}$；重根：$(C_1+C_2x)e^{rx}$；复根 $\alpha\pm\beta i$：$e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)$。

:::

**回忆卡：非齐次大题四步是什么？两类右端的特解设法与共振规则各是什么？**

::: details 先回忆，再揭晓

①齐次通解 $y_c$ → ②按右端设 $y_p$（$P_me^{\lambda x}$ 型乘 $x^k$，三角型成对设）→ ③代回定系数 → ④$y=y_c+y_p$。共振：$\lambda$（或 $\alpha\pm\beta i$）是单根乘 $x$、重根乘 $x^{2}$。

:::
