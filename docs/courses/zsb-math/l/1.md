## 一、特殊角三角函数值

| $\alpha$ | $0$ | $\dfrac{\pi}{6}$ | $\dfrac{\pi}{4}$ | $\dfrac{\pi}{3}$ | $\dfrac{\pi}{2}$ |
| --- | --- | --- | --- | --- | --- |
| $\sin\alpha$ | $0$ | $\dfrac12$ | $\dfrac{\sqrt2}{2}$ | $\dfrac{\sqrt3}{2}$ | $1$ |
| $\cos\alpha$ | $1$ | $\dfrac{\sqrt3}{2}$ | $\dfrac{\sqrt2}{2}$ | $\dfrac12$ | $0$ |
| $\tan\alpha$ | $0$ | $\dfrac{\sqrt3}{3}$ | $1$ | $\sqrt3$ | 不存在 |

::: warning 必背口诀

**分母一律是 2，分子 $\sqrt{n}$ 从 0 数到 4**：$\sin$ 依次是 $\dfrac{\sqrt0}{2},\dfrac{\sqrt1}{2},\dfrac{\sqrt2}{2},\dfrac{\sqrt3}{2},\dfrac{\sqrt4}{2}$；$\cos$ 倒过来写；$\tan$ 是两者相除。

:::

钝角（第二象限）的值用第一象限推：**符号看象限**。例如 $\sin\dfrac{5\pi}{6}=\sin\left(\pi-\dfrac{\pi}{6}\right)=\sin\dfrac{\pi}{6}=\dfrac12$（第二象限 $\sin$ 为正），而 $\tan\dfrac{2\pi}{3}=-\sqrt3$（第二象限 $\tan$ 为负）。

**随堂测 1：$\sin\dfrac{5\pi}{6}=$**

- A. $\dfrac12$
- B. $-\dfrac12$
- C. $\dfrac{\sqrt3}{2}$
- D. $-\dfrac{\sqrt3}{2}$

::: details 点开核对答案

**答案：A（$\dfrac12$）** —— $5\pi/6 = \pi - \pi/6$，化为第一象限的 $\pi/6$；正弦在第二象限仍为正，故 $\sin\dfrac{5\pi}{6}=\sin\dfrac{\pi}{6}=\dfrac12$。

:::

**随堂测 2：$\tan\dfrac{2\pi}{3}=$**

- A. $\sqrt3$
- B. $\dfrac{\sqrt3}{3}$
- C. $-\sqrt3$
- D. $-\dfrac{\sqrt3}{3}$

::: details 点开核对答案

**答案：C（$-\sqrt3$）** —— $2\pi/3 = \pi - \pi/3$，诱导公式给 $\tan\left(\pi-\alpha\right)=-\tan\alpha$，所以 $=-\tan\dfrac{\pi}{3}=-\sqrt3$。第二象限正切为负——符号看象限。

:::

**回忆卡：不看上面，报出 $\dfrac{\pi}{6}$、$\dfrac{\pi}{4}$、$\dfrac{\pi}{3}$ 三个角的全部 $\sin$、$\cos$、$\tan$ 值。**

::: details 先回忆，再揭晓

$$\sin：\dfrac12,\ \dfrac{\sqrt2}{2},\ \dfrac{\sqrt3}{2}\qquad \cos：\dfrac{\sqrt3}{2},\ \dfrac{\sqrt2}{2},\ \dfrac12\qquad \tan：\dfrac{\sqrt3}{3},\ 1,\ \sqrt3$$

:::

## 二、同角关系：一条平方链

::: warning 必背三条

$$\sin^2\alpha+\cos^2\alpha=1\qquad \tan\alpha=\dfrac{\sin\alpha}{\cos\alpha}\qquad \sec^2\alpha-1=\tan^2\alpha$$

第三条就是常写的 $\tan^2\alpha+1=\sec^2\alpha$；配套的还有 $\csc^2\alpha-1=\cot^2\alpha$，其中 $\sec\alpha=\dfrac1{\cos\alpha}$，$\csc\alpha=\dfrac1{\sin\alpha}$。

:::

:::: tip 算例

例 1已知 $\sin\alpha=\dfrac35$，且 $\alpha\in\left(\dfrac{\pi}{2},\pi\right)$，求 $\cos\alpha$ 与 $\tan\alpha$。

::: details 先自己做，再展开解答（解答为整理时补写）

平方关系：$\cos^2\alpha=1-\sin^2\alpha=1-\dfrac{9}{25}=\dfrac{16}{25}$，所以 $\cos\alpha=\pm\dfrac45$。

**定符号**：$\alpha$ 在第二象限，$\cos$ 为负，故 $\cos\alpha=-\dfrac45$，$\tan\alpha=\dfrac{\sin\alpha}{\cos\alpha}=\dfrac{3/5}{-4/5}=-\dfrac34$。

踩坑提醒：只有给定了象限（或等价的范围）才能去掉"$\pm$"。

:::

::::

**回忆卡：$\sin^2\alpha+\cos^2\alpha=?$　$\tan\alpha=$？　$1+\tan^2\alpha=$？**

::: details 先回忆，再揭晓

$$1\qquad\dfrac{\sin\alpha}{\cos\alpha}\qquad \sec^2\alpha$$

:::

## 三、诱导公式：一句口诀管全部

::: warning 必背口诀：奇变偶不变，符号看象限

- 把角写成 $k\cdot\dfrac{\pi}{2}\pm\alpha$ 的形式（$\alpha$ 是锐角）。
- **$k$ 是奇数**（$\dfrac{\pi}{2}$、$\dfrac{3\pi}{2}$）→ 函数名改变（$\sin\leftrightarrow\cos$，$\tan\leftrightarrow\cot$）；**$k$ 是偶数**（$\pi$、$2\pi$）→ 函数名不变。
- 符号：把 $\alpha$ 当锐角看，原函数在"那个角所在象限"的正负，写在新函数前面。

:::

| 化简式 | 结果 | 化简式 | 结果 |
| --- | --- | --- | --- |
| $\sin(\pi+\alpha)$ | $-\sin\alpha$ | $\cos(\dfrac{\pi}{2}+\alpha)$ | $-\sin\alpha$ |
| $\sin(\dfrac{3\pi}{2}+\alpha)$ | $-\cos\alpha$ | $\cos(\dfrac{3\pi}{2}-\alpha)$ | $-\sin\alpha$ |
| $\tan(\dfrac{\pi}{2}-\alpha)$ | $\cot\alpha$ | $\cot(\pi-\alpha)$ | $-\cot\alpha$ |
| $\sin(\dfrac{\pi}{2}+\alpha)$ | $\cos\alpha$ | $\cos(\dfrac{\pi}{2}-\alpha)$ | $\sin\alpha$ |
| $\cot(2\pi-\alpha)$ | $-\cot\alpha$ | $\tan(\dfrac{3\pi}{2}-\alpha)$ | $\cot\alpha$ |

::: danger 易错

口诀里的"奇偶"指 **$\dfrac{\pi}{2}$ 的倍数**的奇偶，不是 $2\pi$ 的倍数（你的某份讲义原文印错为 $2\pi$，以 $\dfrac{\pi}{2}$ 为准，考试按 $\dfrac{\pi}{2}$ 处理）。

:::

**随堂测 3：$\cos\left(\dfrac{\pi}{2}+\alpha\right)=$**

- A. $\sin\alpha$
- B. $-\sin\alpha$
- C. $\cos\alpha$
- D. $-\cos\alpha$

::: details 点开核对答案

**答案：B（$-\sin\alpha$）** —— $k=1$ 是奇数 → "变"：$\cos$ 变 $\sin$。把 $\alpha$ 当锐角，$\dfrac{\pi}{2}+\alpha$ 在第二象限，原函数 $\cos$ 在第二象限为负 → 符号取 $-$。所以是 $-\sin\alpha$。

:::

:::: tip 算例

例 2化简：$\dfrac{\sin(\pi+\alpha)\cos\left(\dfrac{\pi}{2}+\alpha\right)}{\cos(\pi-\alpha)\sin\left(\dfrac{3\pi}{2}-\alpha\right)}$

::: details 先自己做，再展开解答（解答为整理时补写）

逐个用口诀：$\sin(\pi+\alpha)=-\sin\alpha$，$\cos\left(\dfrac{\pi}{2}+\alpha\right)=-\sin\alpha$，$\cos(\pi-\alpha)=-\cos\alpha$，$\sin\left(\dfrac{3\pi}{2}-\alpha\right)=-\cos\alpha$。

分子 $=(-\sin\alpha)(-\sin\alpha)=\sin^2\alpha$，分母 $=(-\cos\alpha)(-\cos\alpha)=\cos^2\alpha$。

原式 $=\tan^2\alpha$。

:::

::::

## 四、二倍角与降幂（积分预备）

::: warning 必背四条

$$\sin 2\alpha=2\sin\alpha\cos\alpha$$

$$\cos 2\alpha=\cos^2\alpha-\sin^2\alpha=2\cos^2\alpha-1=1-2\sin^2\alpha$$

$$\cos^2\alpha=\dfrac{1+\cos 2\alpha}{2}\qquad \sin^2\alpha=\dfrac{1-\cos 2\alpha}{2}\quad(\text{降幂公式})$$

:::

后两行叫**降幂公式**：把二次降为一次。不定积分里 $\displaystyle\int\sin^2 x\,dx$ 这类题，第一步永远是它。现在就把方向记死：**见到平方，想 $\cos 2\alpha$**。

**随堂测 4：$\cos^2 x$ 降幂后的正确形式是**

- A. $\dfrac{1-\cos 2x}{2}$
- B. $\dfrac{1+\cos 2x}{2}$
- C. $\dfrac{1+\cos x}{2}$
- D. $\dfrac{1-\cos x}{2}$

::: details 点开核对答案

**答案：B（$\dfrac{1+\cos 2x}{2}$）** —— 由 $\cos 2x=2\cos^2x-1$ 移项解出 $\cos^2 x=\dfrac{1+\cos 2x}{2}$。口诀：余弦平方"加"，正弦平方"减"。

:::

**回忆卡：默写 $\cos 2\alpha$ 的全部三种形式，以及 $\sin^2\alpha$ 的降幂形式。**

::: details 先回忆，再揭晓

$$\cos^2\alpha-\sin^2\alpha\qquad 2\cos^2\alpha-1\qquad 1-2\sin^2\alpha\qquad \sin^2\alpha=\dfrac{1-\cos 2\alpha}{2}$$

:::

## 五、反三角速算

反三角就是"问角度"：$\arcsin\dfrac12$ 问的是"哪个角的正弦等于 $\dfrac12$？"——答案必须落在规定的**值域**里，否则会有无穷多解。

| 函数 | 定义域 | 值域（背这个！） | 奇偶性 |
| --- | --- | --- | --- |
| $\arcsin x$ | $[-1,1]$ | $\left[-\dfrac{\pi}{2},\dfrac{\pi}{2}\right]$ | 奇 |
| $\arccos x$ | $[-1,1]$ | $[0,\pi]$ | 非奇非偶 |
| $\arctan x$ | $\mathbb{R}$ | $\left(-\dfrac{\pi}{2},\dfrac{\pi}{2}\right)$ | 奇 |

::: warning 负值恒等式（三条必背）

$$\arcsin(-a)=-\arcsin a\qquad \arctan(-a)=-\arctan a\qquad \boxed{\arccos(-a)=\pi-\arccos a}$$

前两个是奇函数，天然带负号；$\arccos$ **不是**奇函数，负号要变成 $\pi-$。这是函数章明确点名的易错点。

:::

**随堂测 5：$\arccos\left(-\dfrac12\right)=$**

- A. $-\dfrac{\pi}{3}$
- B. $\dfrac{\pi}{3}$
- C. $\dfrac{2\pi}{3}$
- D. $\dfrac{4\pi}{3}$

::: details 点开核对答案

**答案：C（$\dfrac{2\pi}{3}$）** —— $-\dfrac12$ 是负数，必须用 $\arccos(-a)=\pi-\arccos a$：$\arccos\dfrac12=\dfrac{\pi}{3}$，所以答案是 $\pi-\dfrac{\pi}{3}=\dfrac{2\pi}{3}$。选 $-\dfrac{\pi}{3}$ 就是掉进了"负号直接提出来"的坑。

:::

**回忆卡：速算九连（先全部回忆完再揭晓）：$\arcsin\dfrac12$、$\arcsin\dfrac{\sqrt2}{2}$、$\arcsin\left(-\dfrac{\sqrt3}{2}\right)$、$\arccos 0$、$\arccos\left(-\dfrac12\right)$、$\arccos\left(-\dfrac{\sqrt2}{2}\right)$、$\arctan 1$、$\arctan\sqrt3$、$\arctan(-1)$**

::: details 先回忆，再揭晓

$$\dfrac{\pi}{6},\quad \dfrac{\pi}{4},\quad -\dfrac{\pi}{3},\quad \dfrac{\pi}{2},\quad \dfrac{2\pi}{3},\quad \dfrac{3\pi}{4},\quad \dfrac{\pi}{4},\quad \dfrac{\pi}{3},\quad -\dfrac{\pi}{4}$$

:::

:::: tip 算例

例 3（综合）化简：$\sqrt{1-2\sin^2\dfrac{\pi}{12}}$

::: details 先自己做，再展开解答（解答为整理时补写）

$1-2\sin^2\theta=\cos 2\theta$（二倍角第三形式反过来用），所以原式 $=\sqrt{\cos\dfrac{\pi}{6}}=\sqrt{\dfrac{\sqrt3}{2}}$。

套路总结：**看到"$1\pm 2\sin^2$ / $2\cos^2-1$"，立刻拼成 $\cos 2\theta$**。

:::
