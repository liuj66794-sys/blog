微分方程的玩法是"**先认类型，再套模板**"：所有一阶方程最终都化成不定积分。三种类型对应三把钥匙，认对类型就赢了一半。

## 一、基本概念：阶、线性、通解

::: warning 概念速览

**阶** = 最高阶导数的阶数（$(y')^{2}+y=0$ 仍是**一阶**——看导数的阶，不看幂次）；**线性** = $y$ 及各阶导数都只有一次幂、互不相乘、不进非线性函数。

**通解**含独立任意常数（个数 = 阶数）；代入初值条件定常数后得**特解**。如 $y'=2x$ 通解 $y=x^{2}+C$，过 $(1,4)$ 得特解 $y=x^{2}+3$。

:::

## 二、类型一：可分离变量

::: warning 解法

能写成 $g(y)\,dy=f(x)\,dx$ 就**两边积分**：$\displaystyle\int g(y)dy=\int f(x)dx+C$。

**先除后查**：分离时若除了含 $y$ 的因子，回头检查该因子为零是否给出被丢失的常数解。

:::

::: tip 算例

例 1（标准件）解 $y'=2xy$。

::: details 先自己分离，再展开（练习 2(1)）

分离（$y\neq0$）：$\dfrac{dy}{y}=2x\,dx$，积分 $\ln|y|=x^{2}+C_1$，即 $y=Ce^{x^{2}}$。

补查：$y=0$ 恰好对应 $C=0$——没丢。**回代验证**：$y'=2xCe^{x^{2}}=2xy$ ✓。

同族速查：$y'=y\tan x$ 型 ⇒ $y=C\sec x$；$\frac{dy}{dx}=e^{x-y}$ ⇒ $e^{y}=e^{x}+C$。

:::

:::

## 三、类型二：齐次方程 $y'=F\!\left(\dfrac yx\right)$

::: warning 换元降维

令 $v=\dfrac yx$，即 $y=vx$，则 $y'=v+x\dfrac{dv}{dx}$（**乘积求导，$v$ 别丢**），方程化为可分离变量。

辨析：这种"**齐次型**"（右端是 $\frac yx$ 的函数）与"**线性齐次**"$y'+p(x)y=0$ 是两回事，解法完全不同。

:::

::: tip 算例

例 2（代表详解）解 $y'=\dfrac yx+\tan\dfrac yx$。（练习 3(1)）

::: details 先自己换元，再展开

令 $y=vx$：$v+xv'=v+\tan v$ ⇒ $xv'=\tan v$。

分离：$\cot v\,dv=\dfrac{dx}{x}$，积分 $\ln|\sin v|=\ln|x|+C$，即 $\sin v=Cx$。

回代：$$\sin\frac yx=Cx$$

流程四拍：**换元 → 分离 → 积分 → 回代 $v=\frac yx$**。答案保留隐式即可。

:::

:::

## 四、类型三：一阶线性 $y'+p(x)y=q(x)$

::: warning 积分因子法（必背）

积分因子 $\mu(x)=e^{\int p(x)dx}$，则 $(\mu y)'=\mu q$，通解

$$y=e^{-\int p(x)dx}\left[\int q(x)\,e^{\int p(x)dx}dx+C\right]$$

先用必须**化标准形**（$y'$ 系数化为 1）；对数里的绝对值按区间处理。非齐次通解结构：$y=y_c+y_p$（齐次通解 + 一个特解）。

:::

::: tip 算例

例 3（代表详解）解 $y'+2y=e^{x}$。（练习 4(1)）

::: details 先自己算积分因子，再展开

$\mu=e^{\int2dx}=e^{2x}$。方程两边乘 $\mu$：$\left(e^{2x}y\right)'=e^{3x}$，积分：

$e^{2x}y=\dfrac13e^{3x}+C$ ⇒ $y=\dfrac13e^{x}+Ce^{-2x}$。

验算：$y'+2y=\dfrac13e^{x}-2Ce^{-2x}+\dfrac23e^{x}+2Ce^{-2x}=e^{x}$ ✓。**解完代回是免费保险**。

同族速查：$y'+\dfrac1x y=\dfrac{3}{x}$ ⇒ $y=\dfrac{x^{2}}{3}+\dfrac{C}{x}$；$y'+y\cos x=e^{-\cos x}$ ⇒ $y=1+Ce^{\cos x}$（先化标准形再看 $p=\cos x$！）。

:::

:::

**随堂测 1：方程 $(y')^{2}+y=\sin x$ 的类型是（练习 1(2)）**

- A. 一阶非线性
- B. 二阶线性
- C. 一阶线性
- D. 二阶非线性

::: details 点开核对答案

**答案：A（一阶非线性）** —— 最高阶导数是 $y'$ ⇒ 一阶（阶数看导数的阶，不看 $(y')^{2}$ 的幂次）；$y'$ 出现平方 ⇒ 非线性。两个判断互相独立，逐个下。

:::

**随堂测 2：解 $y'=y$，通解是**

- A. $y=x+C$
- B. $y=Ce^{x}$ 之外的 $e^{x}+C$
- C. $y=Ce^{x}$
- D. $y=e^{x}+C$

::: details 点开核对答案

**答案：C（$y=Ce^{x}$）** —— 分离变量 $\frac{dy}{y}=dx$ ⇒ $\ln|y|=x+C_1$ ⇒ $y=Ce^{x}$。D 的形状不对（$e^x+C$ 求导是 $e^x$，代回要求 $C=0$，不是通解）——常数必须"长在"指数因子上。

:::

**随堂测 3：解齐次型方程 $y'=\dfrac yx+\tan\dfrac yx$ 时的正确换元是（练习 3(1)）**

- A. $v=y$，则 $y'=v'$
- B. $v=\dfrac yx$，则 $y'=v+xv'$
- C. $v=\dfrac yx$，则 $y'=v'$
- D. $v=x$，则 $y'=v+\dfrac yv$

::: details 点开核对答案

**答案：B（$v=\dfrac yx$，则 $y'=v+xv'$）** —— $y=vx$ 两边对 $x$ 求导：&lt;strong&gt;乘积法则&lt;/strong&gt; $y'=v+xv'$——漏掉单独的 $v$ 是本型第一大错（那样方程就"解不动"了）。C 忘了 $v$ 本身也随 $x$ 变。

:::

**随堂测 4：$y'+\dfrac{1}{x}y=x$ 的通解是（练习 4(3)）**

- A. $y=3+\dfrac{C}{x}$
- B. $y=\dfrac{3}{x}+C$
- C. $y=\dfrac{C}{x}$
- D. $y=\dfrac{x^{2}}{3}+\dfrac{C}{x}$

::: details 点开核对答案

**答案：D（$y=\dfrac{x^{2}}{3}+\dfrac{C}{x}$）** —— 积分因子 $\mu=e^{\int\frac{dx}{x}}=x$：两边乘 $x$ 得 $(xy)'=x$，积分 $xy=\dfrac{x^{3}}{3}+C_1$，即 $y=\dfrac{x^{2}}{3}+\dfrac{C}{x}$。齐次部分 $y_c=\dfrac{C}{x}$、特解 $y_p=\dfrac{x^{2}}{3}$——结构 $y_c+y_p$ 清晰可见。

:::

**随堂测 5：用积分因子法解 $y'+p(x)y=q(x)$ 时，积分因子 $\mu(x)=$**

- A. $e^{\int p(x)dx}$
- B. $\int p(x)dx$
- C. $e^{p(x)}$
- D. $e^{\int q(x)dx}$

::: details 点开核对答案

**答案：A（$e^{\int p(x)dx}$）** —— $\mu=e^{\int p\,dx}$，作用是把左端打包成 $(\mu y)'=\mu q$。B 少了指数；D 把 $p$、$q$ 用反——$p$ 配 $y$、$q$ 是右端。前置动作：先把 $y'$ 的系数化成 1。

:::

::: danger 本课易错清单

- 阶数看**最高阶导数**；线性看 $y$ 及导数是否"只以一次幂干净出现"
- 分离变量**先除后查**：被除因子的零点可能给出常数解（如 $y=0$）
- 齐次型换元 $y=vx$ ⇒ $y'=v+xv'$，**别丢 $v$**；算完回代 $v=\frac yx$
- 两种"齐次"不是一个东西：$F(y/x)$ 型 vs $y'+py=0$ 型
- 积分因子法先**化标准形**（$y'$ 系数 = 1）；$\mu=e^{\int p dx}$
- 解完**求导代回原方程**验算——微分方程最便宜的满分保险

:::

**回忆卡：三种一阶方程（可分离 / 齐次型 / 一阶线性）各认什么脸、用什么钥匙？**

::: details 先回忆，再揭晓

可分离 $g(y)dy=f(x)dx$ ⇒ 两边积分；齐次型 $y'=F(y/x)$ ⇒ 令 $y=vx$，$y'=v+xv'$；一阶线性 $y'+py=q$ ⇒ 积分因子 $e^{\int p dx}$。

:::

**回忆卡：默写一阶线性方程的通解公式，并说出使用前的两个准备动作。**

::: details 先回忆，再揭晓

$y=e^{-\int p dx}\left[\int q e^{\int p dx}dx+C\right]$。准备：①化标准形（$y'$ 系数为 1）；②认准 $p$ 与 $q$（$p$ 乘 $y$、$q$ 在右端）。

:::
