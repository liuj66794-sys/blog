凑微分是整个积分学的**灵魂方法**：后面的第二换元、分式积分、三角积分，本质上都在"凑"。它的原理只有一行——微分形式不变性 $df(u)=f'(u)du$（0021 课的填空升级成解题主力）。

## 一、方法本体

::: warning 公式与心法

$$\int f\bigl(g(x)\bigr)\,g'(x)\,dx=\int f\bigl(g(x)\bigr)\,dg(x)=F\bigl(g(x)\bigr)+C$$

心法：被积函数拆成"**复合形状 $f(\square)$ × 方框的导数**"两部分，导数部分凑进 $d(\ )$ 里。眼力训练：看见 $\square'$ 就找 $\square$。

:::

## 二、常见凑微分表（要背到 3 秒一填）

| 凑微分 | 凑微分 |
| --- | --- |
| $dx=\dfrac1a\,d(ax+b)$ | $x\,dx=\dfrac12d(x^{2})$ |
| $\dfrac{1}{\sqrt x}dx=2\,d(\sqrt x)$ | $\dfrac{1}{x^{2}}dx=-d\!\left(\dfrac1x\right)$ |
| $x^{\mu-1}dx=\dfrac1\mu d(x^{\mu})$ | $\dfrac{dx}{x}=d(\ln\|x\|)$ |
| $e^{x}dx=d(e^{x})$ | $\sin x\,dx=-d(\cos x)$；$\cos x\,dx=d(\sin x)$ |
| $\sec^{2}x\,dx=d(\tan x)$；$\csc^{2}x\,dx=-d(\cot x)$ | $\sec x\tan x\,dx=d(\sec x)$ |
| $\dfrac{dx}{1+x^{2}}=d(\arctan x)$ | $\dfrac{dx}{\sqrt{1-x^{2}}}=d(\arcsin x)$ |

::: warning 万能型：同底对数

$$\dfrac{f'(x)}{f(x)}dx=d\bigl(\ln|f(x)|\bigr)\quad\Rightarrow\quad\int\dfrac{f'(x)}{f(x)}dx=\ln|f(x)|+C$$

识别信号：**分子恰是分母的导数**（或差个常数倍）。$\int\dfrac{e^{x}}{e^{x}+2}dx$、$\int\dfrac{dx}{x\ln x}$、$\int\tan x\,dx$ 全是它的化身。

:::

:::: tip 算例

例 1（线性整体）$\displaystyle\int e^{2x+1}dx$ 与 $\displaystyle\int(3+2x)^{6}dx$。

::: details 先自己凑，再展开（夏讲 P16、P18）

$\int e^{2x+1}dx=\dfrac12\int e^{2x+1}d(2x+1)=\dfrac12e^{2x+1}+C$。

$\int(3+2x)^{6}dx=\dfrac12\int(3+2x)^{6}d(3+2x)=\dfrac{(3+2x)^{7}}{14}+C$。

**线性整体可以整体搬进 $d(\ )$，但系数要除回来**——漏除系数是本单元第一大错。

:::

::::

:::: tip 算例

例 2（幂型复合）$\displaystyle\int xe^{x^{2}}dx$ 与 $\displaystyle\int\sin^{2}x\cos x\,dx$。

::: details 先自己找方框，再展开（夏讲 P19、P21）

$\int xe^{x^{2}}dx=\dfrac12\int e^{x^{2}}d(x^{2})=\dfrac12e^{x^{2}}+C$（方框 $x^2$，其导数 $2x$）。同款：$\int x\cos x^{2}dx=\dfrac12\sin x^{2}+C$。

$\int\sin^{2}x\cos x\,dx=\int\sin^{2}x\,d(\sin x)=\dfrac{\sin^{3}x}{3}+C$（方框 $\sin x$，$\cos x$ 凑进 $d$）。同款：$\int\cos x\sin^{3}x\,dx=\dfrac{\sin^{4}x}{4}+C$。

套路：**"幂 × 三角"把三角凑进 $d$，剩一个幂当 $f$**；$\sin$、$\cos$ 谁的幂在前面，谁就是方框。

:::

::::

:::: tip 算例

例 3（万能型三连）$\displaystyle\int\tan x\,dx$、$\displaystyle\int\dfrac{dx}{x\ln x}$、$\displaystyle\int\dfrac{e^{x}}{e^{x}+2}dx$。

::: details 先自己识别"分子 = 分母导数"，再展开（夏讲 P20、P21）

$\tan x=\dfrac{\sin x}{\cos x}$，分子是分母导数的相反数：$=-\int\dfrac{d(\cos x)}{\cos x}=-\ln|\cos x|+C$。

$\dfrac{1}{x\ln x}=\dfrac{(\ln x)'}{\ln x}$：$=\int\dfrac{d(\ln x)}{\ln x}=\ln|\ln x|+C$。

分母 $e^x+2$ 的导数是 $e^x$，分子恰是：$=\ln(e^{x}+2)+C$（真数恒正，绝对值可省）。

三道全是同一句：**分子凑成分母的导数，整体 $\ln|\text{分母}|+C$**。

:::

::::

:::: tip 算例

例 4（抽象函数）若 $\int f(x)dx=x^{2}+C$，求 $\int xf(1-x^{2})dx$。（夏讲 P22 选择题）

::: details 先自己换元，再展开

由条件 $f(t)=2t$，故被积函数为 $x\cdot2(1-x^{2})$。令 $u=1-x^{2}$，$du=-2x\,dx$：

$\int xf(1-x^{2})dx=-\dfrac12\int f(u)du=-\dfrac12u^{2}+C=-\dfrac12(1-x^{2})^{2}+C$。

抽象版 = 具体版 + 一次换底，$du$ 的**负号**和**系数**照管不误。

:::

::::

**随堂测 1：$\displaystyle\int\dfrac{1}{3-x}dx=$（夏讲 P17）**

- A. $\ln|3-x|+C$
- B. $-\ln|3-x|+C$
- C. $\ln|3+x|+C$
- D. $\dfrac{-1}{(3-x)^{2}}+C$

::: details 点开核对答案

**答案：B（$-\ln|3-x|+C$）** —— $(3-x)'=-1$，故 $dx=-\,d(3-x)$：$\int\dfrac{-d(3-x)}{3-x}=-\ln|3-x|+C$。A 丢了分母导数的负号——&lt;strong&gt;线性整体的系数（含符号）要除进 $d$&lt;/strong&gt;。D 是求导的答案。

:::

**随堂测 2：$\displaystyle\int\dfrac{\ln x}{x}dx=$（秋讲练习 9(3)）**

- A. $\ln(\ln x)+C$
- B. $x\ln x-x+C$
- C. $\dfrac{(\ln x)^{2}}{2}+C$
- D. $\dfrac{1}{x}+C$

::: details 点开核对答案

**答案：C（$\dfrac{(\ln x)^{2}}{2}+C$）** —— $\dfrac{dx}{x}=d(\ln x)$，故 $\int\ln x\,d(\ln x)=\dfrac{(\ln x)^{2}}{2}+C$——幂函数公式套在方框 $\ln x$ 上。A 是上一课 $\dfrac{1}{x\ln x}$ 的答案，两题只差"谁在分子"，看清再下手。

:::

**随堂测 3：$\displaystyle\int\dfrac{e^{\sqrt x}}{\sqrt x}dx=$（秋讲练习 9(5)）**

- A. $2e^{\sqrt x}+C$
- B. $e^{\sqrt x}+C$
- C. $\dfrac12e^{\sqrt x}+C$
- D. $2e^{\sqrt x}\cdot\dfrac{1}{2\sqrt x}+C$

::: details 点开核对答案

**答案：A（$2e^{\sqrt x}+C$）** —— $\dfrac{dx}{\sqrt x}=2\,d(\sqrt x)$，故 $2\int e^{\sqrt x}d(\sqrt x)=2e^{\sqrt x}+C$。系数 2 别丢；D 是被积函数本身——凑微分不是把式子抄一遍。

:::

**随堂测 4：$\displaystyle\int\sin x\cos^{3}x\,dx=$**

- A. $\dfrac{\sin^{4}x}{4}+C$
- B. $\dfrac{\cos^{4}x}{4}+C$
- C. $-\dfrac{\sin^{4}x}{4}+C$
- D. $-\dfrac{\cos^{4}x}{4}+C$

::: details 点开核对答案

**答案：D（$-\dfrac{\cos^{4}x}{4}+C$）** —— 方框取 $\cos x$（谁的幂乘谁的导数）：$\sin x\,dx=-d(\cos x)$，故 $-\int\cos^{3}x\,d(\cos x)=-\dfrac{\cos^{4}x}{4}+C$。A 把方框错认成 $\sin x$——注意乘的是 $\sin x\,dx$ 不是 $\cos x\,dx$。

:::

**随堂测 5：$\displaystyle\int\dfrac{1}{e^{x}-1}dx=$（秋讲练习 9(7)，进阶）**

- A. $\ln|e^{x}-1|+C$
- B. $\ln|1-e^{-x}|+C$
- C. $e^{x}-x+C$
- D. $-\dfrac{1}{(e^{x}-1)^{2}}+C$

::: details 点开核对答案

**答案：B（$\ln|1-e^{-x}|+C$）** —— 分子不是 $e^x$，先变形：$\dfrac{1}{e^{x}-1}=\dfrac{e^{-x}}{1-e^{-x}}$，而 $(1-e^{-x})'=e^{-x}$ ✓，故 $=\ln|1-e^{-x}|+C$。A 错在分子是 1 不是 $e^x$——万能型要求"分子 = 分母导数"，不满足就先&lt;strong&gt;造&lt;/strong&gt;出来。

:::

::: danger 本课易错清单

- 线性整体凑微分**除以系数**：$\int e^{2x}dx=\frac12e^{2x}+C$，不是 $e^{2x}+C$
- 系数含**符号**：$\int\frac{dx}{3-x}=-\ln|3-x|+C$
- "幂 × 三角"方框认准"**谁的幂配谁的导数**"
- 万能型 $\frac{f'}{f}$ 不满足时先恒等变形（乘 $e^{-x}$、拆项）再造
- 凑完心里默验：$d(\square)$ 的导数是否真等于凑进去的那截

:::

**回忆卡：默写万能型公式 $\int\dfrac{f'(x)}{f(x)}dx$，并用它口算 $\int\tan x\,dx$ 与 $\int\dfrac{dx}{x\ln x}$。**

::: details 先回忆，再揭晓

$=\ln|f(x)|+C$。$\int\tan x\,dx=-\ln|\cos x|+C$；$\int\dfrac{dx}{x\ln x}=\ln|\ln x|+C$。

:::

**回忆卡：默写凑微分表六条：$x\,dx$、$\frac{dx}{\sqrt x}$、$\frac{dx}{x^2}$、$e^xdx$、$\sin x\,dx$、$\sec^2x\,dx$ 各凑成什么。**

::: details 先回忆，再揭晓

$x\,dx=\frac12d(x^2)$；$\frac{dx}{\sqrt x}=2d(\sqrt x)$；$\frac{dx}{x^2}=-d(\frac1x)$；$e^xdx=d(e^x)$；$\sin x\,dx=-d(\cos x)$；$\sec^2x\,dx=d(\tan x)$。

:::
