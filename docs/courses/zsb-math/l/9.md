这两类函数是初中老朋友，但考试换个姿势考：判断"是不是一次函数"、给两个条件立方程、求抛物线顶点与最值。它们还是 0010 课以后"极限的载体"——$x\to\infty$ 时一次函数比阶、抛物线开口，全靠这里的图像直觉。

## 一、一次函数：$k$ 管方向，$b$ 管截距

::: warning 定义与硬条件

$y=kx+b$（$k,b$ 为常数，**$k\neq0$**）。$b=0$ 时 $y=kx$ 叫**正比例函数**。

$k>0$ 增、$k<0$ 减，$|k|$ 越大越陡（$k=\tan\alpha$，倾斜角）；$b$ 是与 $y$ 轴交点的纵坐标。

:::

判断"是不是一次函数"只认 $kx+b\ (k\neq0)$ 这个**结构**：$y=\pi x$ 是（$\pi$ 只是系数）、$y=2^{-1}-3x$ 是；而 $y=\dfrac1x$、$y=x^2-1$ 都不是。6·22 例 2 考的就是这个识别。

|   | $b>0$ | $b=0$ | $b<0$ |
| --- | --- | --- | --- |
| $k>0$（上升） | 过一、二、三象限 | 过原点，过一、三象限 | 过一、三、四象限 |
| $k<0$（下降） | 过一、二、四象限 | 过原点，过二、四象限 | 过二、三、四象限 |

两直线位置关系（设 $y_1=k_1x+b_1$，$y_2=k_2x+b_2$）：

::: warning 必背

平行（不重合）$\iff k_1=k_2$ 且 $b_1\neq b_2$；垂直 $\iff k_1k_2=-1$。

:::

解析式五种形式，按已知条件选最顺手的：

| 形式 | 表达式 | 适用条件 |
| --- | --- | --- |
| 点斜式 | $y-y_1=k(x-x_1)$ | 已知一点 + 斜率 |
| 斜截式 | $y=kx+b$ | 已知斜率 + $y$ 轴截距 |
| 两点式 | $\dfrac{y-y_1}{y_2-y_1}=\dfrac{x-x_1}{x_2-x_1}$ | 已知两点 |
| 截距式 | $\dfrac{x}{a}+\dfrac{y}{b}=1$ | 已知两轴截距 $a,b$（不过原点） |
| 一般式 | $Ax+By+C=0\ (A^2+B^2\neq0)$ | 统一写法 |

:::: tip 算例

例 1（求解析式，6·22 例 5 精选）分别求下列直线的斜截式方程：

(1) $k=3$ 且过 $(2,5)$；(2) 过 $(-2,-7)$ 与 $(-1,-5)$；(3) $x$ 轴截距 $2$、$y$ 轴截距 $-3$

::: details 先自己立方程，再展开答案

- (1) 点斜式直接写：$y=3(x-2)+5=3x-1$
- (2) 先算斜率 $k=\dfrac{-5-(-7)}{-1-(-2)}=2$，再用点斜式：$y=2(x+1)-5=2x-3$
- (3) 截距式一步到位：$\dfrac{x}{2}+\dfrac{y}{-3}=1$，整理得 $y=\dfrac32x-3$

流程固定：选形式 → 代入 → 化成斜截式。两点式先算 $k$ 更不容易错。

:::

::::

**随堂测 1：$y_1=k_1x+b_1$ 与 $y_2=k_2x+b_2$ 垂直的条件是**

- A. $k_1=k_2$ 且 $b_1\neq b_2$
- B. $k_1=k_2$ 且 $b_1=b_2$
- C. $k_1k_2=-1$
- D. $k_1+k_2=0$

::: details 点开核对答案

**答案：C（$k_1k_2=-1$）** —— 垂直斜率互为"负倒数"。A 是平行条件；B 是重合；D 只说明倾斜角互补（对称于 $y$ 轴），不垂直。验证：$y=x$ 与 $y=-x$，$k_1k_2=-1$ ✓ 互相垂直。

:::

**随堂测 2：下列函数中，一次函数共有几个：$y=\pi x$；$y=\dfrac1x$；$y=2x-1$；$y=x^2-1$；$y=2^{-1}-3x$**

- A. 2 个
- B. 3 个
- C. 4 个
- D. 5 个

::: details 点开核对答案

**答案：B（3 个）** —— $y=\pi x$、$y=2x-1$、$y=2^{-1}-3x$ 符合 $kx+b\ (k\neq0)$；$y=\frac1x$（反比例型）与 $y=x^2-1$（二次）不是。（6·22 例 2 原题，答案 B。）

:::

## 二、二次函数：三件套定一切

::: warning 必背三件套：$y=ax^2+bx+c\ (a\neq0)$

开口：$a>0$ 向上，$a<0$ 向下。

对称轴：$x=-\dfrac{b}{2a}$；顶点：$P\left(-\dfrac{b}{2a},\ \dfrac{4ac-b^2}{4a}\right)$——**最值就在顶点取得**（$a>0$ 最小、$a<0$ 最大）。

与 $x$ 轴交点：$\Delta=b^2-4ac$；$\Delta>0$ 两个、$=0$ 一个（相切）、$<0$ 无。零点即方程 $ax^2+bx+c=0$ 的根。

:::

:::: tip 算例

例 2（6·22 例 6）已知 $f(x)=-x^2+4x-3$，求开口方向、零点与顶点。

::: details 先自己做，再展开

① $a=-1<0$，开口向下；

② 零点：$-x^2+4x-3=0$，即 $x^2-4x+3=0$，$(x-1)(x-3)=0$，得 $x=1$ 或 $x=3$；

③ 对称轴 $x=-\dfrac{4}{2\times(-1)}=2$，代回 $f(2)=1$，顶点 $(2,1)$——因为开口向下，这就是**最大值**点。

:::

::::

解析式三种形式，按"已知什么"选（与直线同思路）：

| 形式 | 表达式 | 适用条件 |
| --- | --- | --- |
| 一般式 | $y=ax^2+bx+c$ | 已知三点（或读系数） |
| 顶点式 | $y=a(x-h)^2+k$ | 已知顶点 $(h,k)$ 或最值、对称轴 |
| 交点式 | $y=a(x-x_1)(x-x_2)$ | 已知与 $x$ 轴两交点 $(x_1,0),(x_2,0)$ |

::: danger 易错

- $a$ 定开口、$\Delta$ 定交点个数，**两者独立**：$a>0$ 也可能 $\Delta<0$（整条抛物线悬在 $x$ 轴上方）
- 对称轴公式里的负号：$-x^2+4x-3$ 的对称轴是 $-\dfrac{4}{-2}=2$，不是 $-2$
- 最值只在顶点处取得，且前提是**整个 $R$ 上**；限定区间上的最值要另看端点（0024 课闭区间最值再升级）

:::

**随堂测 3：$y=x^2-5x+6$ 的顶点横坐标是**

- A. $\dfrac{5}{2}$
- B. $-\dfrac{5}{2}$
- C. $\dfrac{5}{6}$
- D. $\dfrac{2}{5}$

::: details 点开核对答案

**答案：A（$\dfrac{5}{2}$）** —— $x=-\dfrac{b}{2a}=-\dfrac{-5}{2}=\dfrac52$。代回 $y=\dfrac52^2-5\cdot\dfrac52+6=-\dfrac14$，顶点 $\left(\frac52,-\frac14\right)$（6·22 例 7(2)）。B 是漏了公式里的负号。

:::

**随堂测 4：若二次函数 $y=ax^2+bx+c$ 满足 $\Delta=b^2-4ac<0$，则其图象与 $x$ 轴**

- A. 有两个交点
- B. 恰有一个交点
- C. 交点个数由 $a$ 的符号决定
- D. 没有交点

::: details 点开核对答案

**答案：D（没有交点）** —— $\Delta$ 专职管交点个数：正二、零一、负零。整条曲线整个悬在 $x$ 轴一侧（$a&gt;0$ 在上方，$a&lt;0$ 在下方）。C 是"独立性"误读——$a$ 只管开口，不管交点个数。

:::

**随堂测 5：过点 $(2,5)$ 且 $k=3$ 的直线方程是**

- A. $y=3x+5$
- B. $y=2x-1$
- C. $y=3x-1$
- D. $y=5x-3$

::: details 点开核对答案

**答案：C（$y=3x-1$）** —— 点斜式：$y-5=3(x-2)$，展开 $y=3x-1$。验算：$x=2$ 时 $y=6-1=5$ ✓。A 直接把点的纵坐标当成了截距。

:::

**回忆卡：默写二次函数对称轴、顶点坐标公式，并说出最值在哪里取得。**

::: details 先回忆，再揭晓

对称轴 $x=-\dfrac{b}{2a}$；顶点 $\left(-\dfrac{b}{2a},\dfrac{4ac-b^2}{4a}\right)$；$a>0$ 顶点处取最小值，$a<0$ 取最大值。

:::

**回忆卡：两直线平行、垂直的条件各是什么？$\Delta$ 的三个取值各对应几个交点？**

::: details 先回忆，再揭晓

平行：$k_1=k_2$ 且 $b_1\neq b_2$；垂直：$k_1k_2=-1$。$\Delta>0$ 两交点、$\Delta=0$ 一点、$\Delta<0$ 无交点。

:::
