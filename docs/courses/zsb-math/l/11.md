## 一、先看两件"不用技巧"的事

::: warning 直接代入法 + 四则法则

初等函数在**连续点**直接代：$\lim\limits_{x\to x_0}f(x)=f(x_0)$。如 $\lim\limits_{x\to3}(3x-2)=7$，$\lim\limits_{x\to e}\ln x=1$。

四则法则：各极限**都存在**时可加减乘除（除法分母非零）。口诀：**极限存在且不为 0 的因子先算掉**，别让它陪着你化简。

:::

代入后发现是 $\dfrac00$、$\dfrac\infty\infty$ 这类"算不出来"的样子，就叫**未定式**，共七种：

::: warning 七种未定式（认脸不认人）

$$\frac00,\quad\frac{\infty}{\infty},\quad\infty-\infty,\quad0\cdot\infty,\quad1^{\infty},\quad0^{0},\quad\infty^{0}$$

这里的 $0,1,\infty$ 指**极限为**该值的式子，不是真常数。反例识破：$\lim\limits_{x\to\infty}1^x=1$——底是真常数 1，不是 $1^{\infty}$ 型。

:::

## 二、方法一：去零因式（$\frac00$ 型）

$x\to x_0$ 时分子分母同时趋于 0，说明**两者都藏着因子 $(x-x_0)$**——因式分解（0002 课十字相乘/立方和差）后约掉：

::: tip 算例

例 1$\lim\limits_{x\to1}\dfrac{x^2+x-2}{x^2-x}$ 与 $\lim\limits_{x\to2}\dfrac{x^3-8}{x^2-4}$。

::: details 先自己分解，再展开

$\lim\limits_{x\to1}\dfrac{(x+2)(x-1)}{x(x-1)}=\lim\limits_{x\to1}\dfrac{x+2}{x}=3$。

$\lim\limits_{x\to2}\dfrac{(x-2)(x^2+2x+4)}{(x-2)(x+2)}=\lim\limits_{x\to2}\dfrac{x^2+2x+4}{x+2}=3$（分子用了**立方差**）。

:::

:::

## 三、方法二：通分再约分（$\infty-\infty$ 型）

两个分式相减都是无穷，先**通分化成一个分式**，通常就变成 $\frac00$ 型，回到方法一：

::: tip 算例

例 2$\lim\limits_{x\to2}\left(\dfrac{1}{x-2}-\dfrac{4}{x^2-4}\right)$。

::: details 先自己通分，再展开

$=\lim\limits_{x\to2}\dfrac{(x+2)-4}{(x-2)(x+2)}=\lim\limits_{x\to2}\dfrac{x-2}{(x-2)(x+2)}=\lim\limits_{x\to2}\dfrac{1}{x+2}=\dfrac14$。

同型（秋讲练习 7(6)）：$\lim\limits_{x\to1}\left(\dfrac{3}{1-x^3}-\dfrac{1}{1-x}\right)=\lim\limits_{x\to1}\dfrac{2+x}{1+x+x^2}=1$。

:::

:::

## 四、方法三：有理化（见到根式差）

分子或分母出现 $\sqrt{\ }-\sqrt{\ }$，**乘共轭根式**（0002 课的有理化因式）：

::: tip 算例

例 3$\lim\limits_{x\to0}\dfrac{\sqrt{1+x}-1}{x}$ 与 $\lim\limits_{x\to1}\dfrac{\sqrt{3-x}-\sqrt{1+x}}{x^2+x-2}$。

::: details 先自己做，再展开

$\lim\limits_{x\to0}\dfrac{(\sqrt{1+x}-1)(\sqrt{1+x}+1)}{x(\sqrt{1+x}+1)}=\lim\limits_{x\to0}\dfrac{x}{x(\sqrt{1+x}+1)}=\dfrac12$。

第二题分母先分解 $x^2+x-2=(x+2)(x-1)$，分子乘共轭：$\dfrac{(3-x)-(1+x)}{(x+2)(x-1)(\sqrt{3-x}+\sqrt{1+x})}=\dfrac{2(1-x)}{(x+2)(x-1)(\cdots)}=\dfrac{-2}{3\times2}=-\dfrac13$。

:::

:::

## 五、方法四：抓大头（$\frac\infty\infty$ 型）

::: warning 必背：多项式比三结论

$$\lim_{x\to\infty}\frac{a_0x^m+\cdots+a_m}{b_0x^n+\cdots+b_n}=\begin{cases}0, & n>m\\ \dfrac{a_0}{b_0}, & n=m\\ \infty, & n<m\end{cases}$$

速度链（$x\to+\infty$ 谁跑得快）：**$\ln x\ll x^a\ll c^x\ll x^x$**。混搭比阶：各自抓最大的头再比。

:::

::: tip 算例

例 4秒答四个（夏讲教材 P32–33）：

::: details 先自己抓头，再展开

$\lim\limits_{x\to\infty}\dfrac{x^2+2x-3}{x^2-1}=1$（同次比系数）；$\lim\limits_{x\to\infty}\dfrac{x^2-5x-1}{x^3-3}=0$（分母次数高）。

$\lim\limits_{x\to+\infty}\dfrac{x^2-1}{e^{2x}}=0$（指数吊打幂）；$\lim\limits_{x\to+\infty}\dfrac{\ln x}{x}=0$（幂吊打对数）。

$\lim\limits_{x\to+\infty}\dfrac{3^x+2}{2^x-4x^2+x}=\infty$：分子抓 $3^x$，分母里 $2^x\gg4x^2$ 抓 $2^x$，比值 $\sim(3/2)^x\to\infty$。

:::

:::

::: danger 负方向陷阱：$x\to-\infty$ 时 $\sqrt{x^2}=|x|=-x$

例（夏讲原题）：$\lim\limits_{x\to-\infty}\dfrac{\sqrt{4x^2+x-1}+x+1}{\sqrt{x^2+\sin x}}$。此时 $\sqrt{4x^2}=|2x|=-2x$、$\sqrt{x^2}=-x$，故分子 $\sim-2x+x=-x$，比值 $=\dfrac{-x}{-x}=1$。

口诀：**偶次根号开出来是非负的**——负方向先提 $|x|$ 再抓大头。

:::

**随堂测 1：$\lim\limits_{x\to3}\dfrac{x^2-5x+6}{x^2-8x+15}=$**

- A. $0$
- B. $-\dfrac{1}{2}$
- C. $\dfrac{1}{2}$
- D. $-\dfrac{2}{5}$

::: details 点开核对答案

**答案：B（$-\dfrac{1}{2}$）** —— 典型 $\frac00$：分子 $=(x-2)(x-3)$，分母 $=(x-3)(x-5)$，约掉 $(x-3)$ 后代入 $x=3$：$\dfrac{3-2}{3-5}=-\dfrac12$。（秋讲练习 7(3) 原题。）

:::

**随堂测 2：$\lim\limits_{x\to\infty}\dfrac{3x^2+2x+1}{5x^2-4x+7}=$**

- A. $0$
- B. $\infty$
- C. $\dfrac{3}{5}$
- D. $\dfrac{5}{3}$

::: details 点开核对答案

**答案：C（$\dfrac{3}{5}$）** —— 同次（$m=n=2$）比最高次项系数：$\dfrac{3}{5}$。D 倒过来了——结论是 $\dfrac{a_0}{b_0}$，分子系数在上。

:::

**随堂测 3：$\lim\limits_{x\to+\infty}\left(\sqrt{x^2+x}-x\right)=$**

- A. $\dfrac{1}{2}$
- B. $0$
- C. $1$
- D. $+\infty$

::: details 点开核对答案

**答案：A（$\dfrac{1}{2}$）** —— "$\infty-\infty$"带根号 → 有理化：$\dfrac{x}{\sqrt{x^2+x}+x}$，再抓大头：分子最高阶 $x$，分母 $\sqrt{x^2+x}+x\sim2x$，得 $\dfrac12$。（秋讲练习 8(3)。）

:::

**随堂测 4：$\lim\limits_{x\to+\infty}\dfrac{(2x-1)^3(3x+1)^2}{(x+1)^5}=$**

- A. $6$
- B. $1$
- C. $36$
- D. $72$

::: details 点开核对答案

**答案：D（$72$）** —— 整体看次数：分子 $x^5$、分母 $x^5$，同次比系数 $\dfrac{2^3\cdot3^2}{1}=8\times9=72$。口诀是"抓大头"，但展开前的系数要抓准：$(2x)^3$ 的头是 $2^3$。（秋讲练习 9(6)。）

:::

**随堂测 5：$\lim\limits_{x\to\infty}\dfrac{x+\sin x}{x-\cos x}=$**

- A. 不存在
- B. $1$ 之外还有别的值
- C. $1$
- D. $0$

::: details 点开核对答案

**答案：C（$1$）** —— 别被 $\sin x$ 吓到：分子分母同除 $x$，得 $\dfrac{1+\frac{\sin x}{x}}{1-\frac{\cos x}{x}}$，其中 $\dfrac{\sin x}{x}\to0$（&lt;strong&gt;有界 × 无穷小&lt;/strong&gt;，0015 课主角），分母 $\to1$，整体 $\to1$。（秋讲练习 9(5)。）

:::

::: danger 方法选择对照表（按长相 30 秒选对）

- $\frac00$ 且是多项式 → **去零因式**（分解 → 约分）
- $\infty-\infty$ 且是分式差 → **通分**后回上一条
- 根式差（$\sqrt{\ }-\sqrt{\ }$ 或 $\sqrt{\ }-a$）→ **有理化**
- $\frac\infty\infty$ 且是多项式 / 混合增长 → **抓大头**（三结论 + 速度链）
- 剩下 $\sin\frac{\square}{\square}$、$1^{\infty}$ → 下一课的两个重要极限

:::

**回忆卡：默写抓大头三结论（多项式比），并排出速度链（$\ln x$、$x^a$、$c^x$、$x^x$）。**

::: details 先回忆，再揭晓

次高得 0、同次比系数 $\frac{a_0}{b_0}$、次低得 $\infty$；$\ln x\ll x^a\ll c^x\ll x^x$。

:::

**回忆卡：七种未定式是哪七种？"假未定式"怎么识破？举一例。**

::: details 先回忆，再揭晓

$\frac00$、$\frac\infty\infty$、$\infty-\infty$、$0\cdot\infty$、$1^\infty$、$0^0$、$\infty^0$。看底/因子是"极限为该值"还是真常数：$\lim\limits_{x\to\infty}1^x=1$ 是真常数底，不算未定式。

:::
