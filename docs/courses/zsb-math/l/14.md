洛必达法则是"万能钥匙"，但万能有条件。考试里它几乎从不单独出场——**先等价替换简化，再洛**才是标准打法；反过来"拿到就洛、洛到底"经常越洛越繁。

## 一、法则本体与三条纪律

::: warning 法则

若 ① $\lim f=\lim g=0$（$\frac00$ 型）**或** $\lim g=\infty$（$\frac\infty\infty$ 型）；② $f,g$ 可导且 $g'(x)\neq0$；③ $\lim\dfrac{f'(x)}{g'(x)}=A$ 存在（或 $\infty$）——

$$\lim\frac{f(x)}{g(x)}=\lim\frac{f'(x)}{g'(x)}=A$$

:::

::: danger 三条纪律

- **先验型再求导**：不是 $\frac00$ / $\frac\infty\infty$ 就不能用。其他五种未定式先化型（取对数、通分、提因子）
- **用一次简化一次**：求导前先约掉非零因子、换掉可替换的等价无穷小，别硬洛出八行
- **失效就换招**：条件③不满足（导数比来回振荡）时结论无效——例如 $\lim\limits_{x\to\infty}\dfrac{\sin x}{x}$ 不能洛（洛完是 $\cos x$ 不存在，但原极限 $=0$），要用"有界 × 无穷小"

:::

## 二、标准 $\frac00$：洛一次或两次

::: tip 算例

例 1求 $\lim\limits_{x\to0}\dfrac{e^{x}-1-x}{x^{2}}$ 与 $\lim\limits_{x\to0}\dfrac{e^{x}+e^{-x}-2}{x^{2}}$。

::: details 先自己洛，再展开（秋讲练习 13(10)(6)）

第一题：$\frac00$ ✓，洛一次 $=\lim\limits_{x\to0}\dfrac{e^x-1}{2x}$，仍是 $\frac00$，再洛 $=\dfrac{e^x}{2}\to\dfrac12$。

第二题：洛一次 $=\lim\dfrac{e^x-e^{-x}}{2x}$，再洛 $=\lim\dfrac{e^x+e^{-x}}{2}=1$。

注意每洛一次都要**重新验型**：第二题洛完一次后分母 $\to0$、分子 $\to0$，才允许再洛。

:::

:::

## 三、先化型：五种间接未定式的处理

| 原 型 | 化型手段 |
| --- | --- |
| $0\cdot\infty$ | 把一个因子移到分母：$0\cdot\infty=\dfrac{0}{1/\infty}=\dfrac00$（通常"丢多项式、留复杂函数"更好洛） |
| $\infty-\infty$ | 通分成一个分式，或提公因式 |
| $1^{\infty}$、$0^{0}$、$\infty^{0}$ | 取对数：$u^v=e^{v\ln u}$，指数 $v\ln u$ 多为 $0\cdot\infty$，化型后再洛 |

::: tip 算例

例 2（$0\cdot\infty$）求 $\lim\limits_{x\to\frac{\pi}{2}}\left(\dfrac{\pi}{2}-x\right)\tan x$。

::: details 先自己化型，再展开（秋讲练习 13）

令 $t=\dfrac{\pi}{2}-x\to0^+$，原式 $=t\cot t=\dfrac{t}{\tan t}\to1$（$\frac00$，或直接用 $\tan t\sim t$）。

换元把"接近 $\frac{\pi}{2}$"化成"接近 $0$"，是三角位置未定式的通用起手。

:::

:::

::: tip 算例

例 3（$\infty-\infty$）求 $\lim\limits_{x\to1}\left(\dfrac{1}{\ln x}-\dfrac{1}{x-1}\right)$。

::: details 先自己通分，再展开（秋讲练习 13）

通分：$\dfrac{(x-1)-\ln x}{(x-1)\ln x}$。令 $t=x-1\to0$：$\dfrac{t-\ln(1+t)}{t\ln(1+t)}$，分母 $\sim t^2$、分子 $\sim\frac12t^2$（三阶差表），得 $\dfrac12$。

也可以洛：$\lim\limits_{t\to0}\dfrac{1-\frac{1}{1+t}}{\ln(1+t)+\frac{t}{1+t}}=\lim\limits_{t\to0}\dfrac{t}{(1+t)t+t}=\dfrac12$。先等价再洛，快得多。

:::

:::

::: tip 算例

例 4（幂指型）求 $\lim\limits_{x\to0}(\cos x)^{\frac{1}{\ln(1+x^{2})}}$。

::: details 先取对数，再展开（秋讲练习 13）

写成 $e^{v\ln u}$：指数 $=\dfrac{\ln\cos x}{\ln(1+x^2)}$。分子 $\sim-\dfrac12x^2$（0013 例 3），分母 $\sim x^2$，指数 $\to-\dfrac12$。

答案 $e^{-\frac12}$。**幂指三兄弟（$1^\infty,0^0,\infty^0$）统一走 $e^{v\ln u}$ 这条路**——若指数恰是 $1^{\infty}$ 型，也可以直接用 0012 三步法。

:::

:::

**随堂测 1：使用洛必达法则前，必须先确认**

- A. 函数处处可导
- B. 是 $\frac00$ 或 $\frac\infty\infty$ 型，且导数比的极限存在（或为 $\infty$）
- C. 分子分母都没有根式
- D. 极限一定存在

::: details 点开核对答案

**答案：B（是 $\frac00$ 或 $\frac\infty\infty$ 型，且导数比的极限存在（或为 $\infty$））** —— 三条件验型 → 可导 → 导数比有结论。D 反了：法则用来&lt;strong&gt;求&lt;/strong&gt;极限，导数比不存在时只是法则失效，不代表原极限不存在。

:::

**随堂测 2：$\lim\limits_{x\to+\infty}\dfrac{\ln x}{x}$ 用洛必达法则得**

- A. 不存在
- B. $1$
- C. $0$
- D. $+\infty$

::: details 点开核对答案

**答案：C（$0$）** —— $\frac\infty\infty$ ✓，洛一次 $=\lim\limits_{x\to+\infty}\dfrac{1/x}{1}=0$。当然抓大头（幂吊打对数）更快——洛必达和抓大头互相印证。

:::

**随堂测 3：求 $\lim\limits_{x\to\infty}\dfrac{x+\sin x}{x}$ 时，下列做法正确的是**

- A. 洛必达两次得 $1$
- B. 洛必达得 $\cos x$，故不存在
- C. 等价替换 $\sin x\sim x$，得 $2$
- D. 不能用洛必达；拆成 $1+\dfrac{\sin x}{x}=1+0=1$

::: details 点开核对答案

**答案：D（不能用洛必达；拆成 $1+\dfrac{\sin x}{x}=1+0=1$）** —— 这是 $\frac\infty\infty$，但洛完 $\dfrac{1+\cos x}{1}$ 极限不存在——条件③不满足，法则失效，&lt;strong&gt;不代表原极限不存在&lt;/strong&gt;。正解：拆项后 $\dfrac{\sin x}{x}\to0$（有界 × 无穷小）。C 还犯了两条错：$\sin x$ 不是无穷小，且这是加减位置。

:::

**随堂测 4：化 $\lim\limits_{x\to0^+}x\ln x$（$0\cdot\infty$ 型）为可直接洛的形式，最好写成**

- A. $\lim\limits_{x\to0^+}\dfrac{\ln x}{1/x}$（$\frac\infty\infty$）
- B. $\lim\limits_{x\to0^+}\dfrac{x}{1/\ln x}$（$\frac00$）
- C. $\lim\limits_{x\to0^+}\dfrac{\ln x}{x}$（$\frac\infty\infty$）
- D. 直接说极限不存在

::: details 点开核对答案

**答案：A（$\lim\limits_{x\to0^+}\dfrac{\ln x}{1/x}$（$\frac\infty\infty$））** —— A 洛一次得 $\dfrac{1/x}{-1/x^2}=-x\to0$。经验法则：&lt;strong&gt;把多项式放到分母，复杂的（对数）留在分子&lt;/strong&gt;——B、C 那样放会越洛越繁。答案：$x\ln x\to0$。

:::

**随堂测 5：$\lim\limits_{x\to\frac{\pi}{2}}(\sec x-\tan x)$（$\infty-\infty$ 型）等于**

- A. 不存在
- B. $0$
- C. $1$
- D. $-1$

::: details 点开核对答案

**答案：B（$0$）** —— 通分：$\dfrac{1-\sin x}{\cos x}=\dfrac{(1-\sin x)(1+\sin x)}{\cos x(1+\sin x)}=\dfrac{\cos^2x}{\cos x(1+\sin x)}=\dfrac{\cos x}{1+\sin x}\to\dfrac01=0$。（秋讲练习 13(9)，恒等变形比洛必达优雅。）

:::

::: danger 本课易错清单

- 不验型就洛 = 白给：$\lim\limits_{x\to\infty}\dfrac{x+\cos x}{x}$ 不是"洛到 $\frac00$"
- 每洛一次**重新验型**，不是一劳永逸
- 洛完不存在 ≠ 原极限不存在（条件③失效，换夹逼 / 有界 × 无穷小 / 抓大头）
- 幂指三兄弟一律 $e^{v\ln u}$ 化型；$1^{\infty}$ 可 shortcut 用三步法
- 优先级：等价替换 / 恒等变形 **先做**，洛必达**殿后**——计算量天差地别

:::

**回忆卡：默写洛必达法则的三个条件，并说出三条纪律。**

::: details 先回忆，再揭晓

①$\frac00$ 或 $\frac\infty\infty$；②$f,g$ 可导且 $g'\neq0$；③导数比的极限存在或为 $\infty$。纪律：先验型、用一次简化一次、失效就换招。

:::

**回忆卡：五种间接未定式（$0\cdot\infty$、$\infty-\infty$、$1^{\infty}$、$0^{0}$、$\infty^{0}$）各怎么化型？**

::: details 先回忆，再揭晓

$0\cdot\infty$：因子下沉到分母；$\infty-\infty$：通分；幂指三兄弟：$u^v=e^{v\ln u}$ 取对数（$1^{\infty}$ 亦可用 $e^{\lim v(u-1)}$）。
