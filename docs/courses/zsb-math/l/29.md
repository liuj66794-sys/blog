::: tip 本课结束，你能

- 用**"反对幂三指"**口诀 3 秒定 $u$ 与 $dv$
- 秒解五类典型：幂×三角、幂×指数、**纯对数、纯反三角**、循环型
- 循环型（$e^{ax}\sin bx$）会**移项解方程**，不丢符号与 $C$

:::

两类"长得不像公式表"的积分：$x\cos x$（两个函数相乘）、$\ln x$（单独一个"积不出"的家伙）。分部积分是它们的专属解法——本质是**乘积求导法则的逆用**。

## 一、公式与选 $u$ 口诀

::: warning 公式

$$\int u\,dv=uv-\int v\,du$$

把被积式拆成 $u$ 和 $dv$ 两半：**$u$ 求导，$dv$ 凑微分后先积分**。成败全在分工。

:::

::: warning 口诀：反 对 幂 三 指

**反**三角、**对**数、**幂**函数、**三**角、**指**数——**排在前面的取作 $u$（求导），排在后面的凑进 $dv$（先积）**。

为什么这样排：反三角、对数"求导变简单"（$\ln x\to\frac1x$、$\arctan x\to\frac{1}{1+x^2}$），让它们当 $u$ 越算越简单；指数、三角"谁都积得出"，当 $dv$ 无所谓。

:::

## 二、五类典型逐个过

:::: tip 算例

例 1（幂 × 三角）$\displaystyle\int x\cos x\,dx$。（夏讲 P47）

::: details 先自己定 $u,dv$，再展开

幂在三角前：$u=x$，$dv=\cos x\,dx$ ⇒ $du=dx$，$v=\sin x$。

$=x\sin x-\int\sin x\,dx=x\sin x+\cos x+C$。

效果：$x$ 从"乘积"变成"单独"，剩下一个基本积分——**幂次数被降了一级**。

:::

::::

:::: tip 算例

例 2（幂 × 指数，连续降幂）$\displaystyle\int x^{2}e^{x}dx$。（夏讲 P47）

::: details 先做一次，再展开

$u=x^{2}$，$dv=e^{x}dx$：$=x^{2}e^{x}-2\int xe^{x}dx$；再对 $\int xe^{x}dx$ 分部一次：

$=x^{2}e^{x}-2(xe^{x}-\int e^{x}dx)=(x^{2}-2x+2)e^{x}+C$。

规律：**幂 × 指数 = 分部 $n$ 次，每降一次幂**。每次都让幂当 $u$，方向别换。

:::

::::

:::: tip 算例

例 3（纯对数 / 纯反三角）$\displaystyle\int\ln x\,dx$ 与 $\displaystyle\int\arctan x\,dx$。

::: details 先想"另一半是谁"，再展开（夏讲 P48）

单独积分时把被积函数当 $u$，$dv=dx$：

$\int\ln x\,dx=x\ln x-\int x\cdot\dfrac1x dx=x\ln x-x+C$。

$\int\arctan x\,dx=x\arctan x-\int\dfrac{x}{1+x^{2}}dx=x\arctan x-\dfrac12\ln(1+x^{2})+C$。

要点：**$dv$ 永远可以填 $dx$**——"没有第二半"不是障碍。$\int\arcsin x\,dx$ 同法。

:::

::::

:::: tip 算例

例 4（循环型）$\displaystyle I=\int e^{x}\sin x\,dx$。（夏讲 P49）

::: details 先分部两次，再展开

第一次（三角当 $u$）：$I=e^{x}\sin x-\int e^{x}\cos x\,dx$。

第二次（**仍让三角当 $u$**，类型不能换）：$I=e^{x}\sin x-\left[e^{x}\cos x-\int e^{x}(-\sin x)dx\right]=e^{x}\sin x-e^{x}\cos x-I$。

循环出现 ⇒ 移项解方程：$2I=e^{x}(\sin x-\cos x)$，$I=\dfrac{e^{x}}{2}(\sin x-\cos x)+C$。

两个陷阱：第二次 $u$ **必须同类型**（否则转一圈又回原点）；移项后**除以 2**，$C$ 不能丢。

:::

::::

**随堂测 1：$\displaystyle\int x\sin x\,dx=$（秋讲练习 11(1)）**

- A. $-x\cos x+\sin x+C$
- B. $x\cos x-\sin x+C$
- C. $-x\cos x-\sin x+C$
- D. $x\sin x+\cos x+C$

::: details 点开核对答案

**答案：A（$-x\cos x+\sin x+C$）** —— $u=x$、$dv=\sin x\,dx$（$v=-\cos x$）：$-x\cos x+\int\cos x\,dx=-x\cos x+\sin x+C$。D 是 $\int x\cos x$ 的答案——两题互为"正负镜像"，动笔前先写 $v$。

:::

**随堂测 2：$\displaystyle\int xe^{-x}dx=$（秋讲练习 11(3)）**

- A. $(x-1)e^{-x}+C$
- B. $-(x+1)e^{-x}+C$
- C. $\dfrac{x^{2}}{2}e^{-x}+C$
- D. $-(x-1)e^{-x}+C$

::: details 点开核对答案

**答案：B（$-(x+1)e^{-x}+C$）** —— $u=x$、$dv=e^{-x}dx$（$v=-e^{-x}$）：$-xe^{-x}+\int e^{-x}dx=-xe^{-x}-e^{-x}+C=-(x+1)e^{-x}+C$。$v$ 里的负号是本题唯一的坑——写 $dv$ 时顺手标 $v$。

:::

**随堂测 3：$\displaystyle\int x^{3}\ln x\,dx=$（秋讲练习 11(5)）**

- A. $\dfrac{x^{4}}{4}\ln x+\dfrac{x^{4}}{16}+C$
- B. $\dfrac{x^{4}}{4}\ln x-\dfrac{x^{4}}{4}+C$
- C. $\dfrac{x^{4}}{4}\ln x-\dfrac{x^{4}}{16}+C$
- D. $x^{2}\ln x-\dfrac{x^{2}}{2}+C$

::: details 点开核对答案

**答案：C（$\dfrac{x^{4}}{4}\ln x-\dfrac{x^{4}}{16}+C$）** —— 对数在前当 $u$：$=\dfrac{x^{4}}{4}\ln x-\int\dfrac{x^{4}}{4}\cdot\dfrac1xdx=\dfrac{x^{4}}{4}\ln x-\dfrac{x^{4}}{16}+C$。A 符号反了；B 忘了 $\int x^3dx$ 有 $\frac14$（系数 $\frac14\cdot\frac14=\frac1{16}$）。

:::

**随堂测 4：计算 $\displaystyle\int x\arctan x\,dx$ 时，$u$ 与 $dv$ 应取（秋讲练习 11(4)）**

- A. $u=\arctan x$，$dv=x\,dx$
- B. $u=x$，$dv=\arctan x\,dx$
- C. $u=\arctan x$，$dv=dx$
- D. $u=1$，$dv=x\arctan x\,dx$

::: details 点开核对答案

**答案：A（$u=\arctan x$，$dv=x\,dx$）** —— 反三角排在幂前面 ⇒ 反三角当 $u$、幂凑进 $dv$（$v=\frac{x^{2}}{2}$）。得 $\dfrac{x^{2}}{2}\arctan x-\dfrac12\int\dfrac{x^{2}}{1+x^{2}}dx=\dfrac{x^{2}+1}{2}\arctan x-\dfrac x2+C$。B 让 $x$ 当 $u$ 会越算越繁——口诀的排序就是"谁求导更划算"。

:::

**随堂测 5：循环型 $\displaystyle\int e^{x}\cos x\,dx$ 第二次分部时，$u$ 应选**

- A. $u=e^{x}$（与第一次交替）
- B. $u=\cos x$ 的导数整体
- C. $u=1$，凑 $dv$ 为全部
- D. $u=\cos x$（与第一次同类型）

::: details 点开核对答案

**答案：D（$u=\cos x$（与第一次同类型））** —— 两次分部 $u$ 必须&lt;strong&gt;同类&lt;/strong&gt;（都选三角或都选指数），否则第二次循环回来方向相反，抵消成一圈空转（$0=0$）。选对后移项：$\int e^x\cos x\,dx=\dfrac{e^{x}}{2}(\sin x+\cos x)+C$。

:::

::: danger 本课易错清单

- 口诀顺序：**反、对、幂、三、指**，前者当 $u$ 求导，后者当 $dv$ 先积
- 纯对数 / 纯反三角：**$dv=dx$** 照样分部
- $v$ 带负号时（$dv=\sin x\,dx$）全程跟踪，最后别丢
- 循环型：第二次 $u$ **同类型**；移项后除系数、补 $C$
- 结果不唯一是常态：差个常数都正确（如 $\frac12\sin^2x$ 与 $-\frac12\cos^2x$ 同为 $\int\sin x\cos x\,dx$ 的原函数），**求导验算是终极裁判**

:::

**回忆卡：默写分部积分公式与"反对幂三指"分工规则。**

::: details 先回忆，再揭晓

$\int u\,dv=uv-\int v\,du$；反三角、对数排前当 $u$（求导），幂、三角、指数排后当 $dv$（先积）。

:::

**回忆卡：秒答三个结果：$\int\ln x\,dx$、$\int x e^{x}dx$、$\int e^{x}\sin x\,dx$。**

::: details 先回忆，再揭晓

$x\ln x-x+C$；$(x-1)e^{x}+C$；$\dfrac{e^{x}}{2}(\sin x-\cos x)+C$。

:::
