0006 课用定义判断单调性的伏笔，在本课兑现：**$f'$ 的符号就是单调性的判据**。这课是大题高频区——单调区间、极值、最值常常合成一道大题连问。

## 一、单调性：$f'$ 的符号说了算

::: warning 判定定理与四步法

区间 $I$ 上：$f'(x)\ge0$ ⇔ 单调增；$f'(x)\le0$ ⇔ 单调减。**$f'>0$（或除去有限个零点外 $>0$）⇒ 严格增**（$y=x-\sin x$ 在 $(0,2\pi)$ 全程 $y'\ge0$ 只在端点为零，仍严格增）。

**四步**：① 定定义域 → ② 求 $f'$，找**驻点 + 不可导点** → ③ 分区间 → ④ 逐区间看 $f'$ 符号。

:::

::: tip 算例

例 1求 $y=2x^{3}-9x^{2}+12x-3$ 的单调区间。（夏应用 P28）

::: details 先自己走四步，再展开

$y'=6x^{2}-18x+12=6(x-1)(x-2)$，驻点 $x=1,2$（无不可导点）。

符号表：$x<1$ 时 $+$（增）；$1<x<2$ 时 $-$（减）；$x>2$ 时 $+$（增）。

增区间 $(-\infty,1)$、$(2,+\infty)$，减区间 $(1,2)$。

:::

:::

## 二、极值：两个判定定理

::: warning 概念先行

**驻点**：$f'(x_0)=0$ 的点。**费马引理**：可导的极值点必是驻点。

关系三句：驻点**未必**是极值点（$y=x^3$ 的 $x=0$）；极值点**未必**是驻点（$y=|x|$ 的 $x=0$，不可导）；极值只比"邻居"，**极小值可以大于极大值**。

:::

::: warning 判定定理一 / 二

**定理一（看两侧）**：$f'$ 在 $x_0$ 两侧**左正右负** ⇒ 极大；**左负右正** ⇒ 极小。（对驻点和不可导点都适用——首选。）

**定理二（看二阶）**：$f'(x_0)=0$ 且 $f''(x_0)<0$ ⇒ 极大；$f''(x_0)>0$ ⇒ 极小；$f''(x_0)=0$ ⇒ **失效**，退回定理一。

:::

::: tip 算例

例 2（含不可导点）求 $f(x)=\dfrac23x-(x-1)^{2/3}$ 的极值。（夏应用 P42）

::: details 先找全候选点，再展开

$f'(x)=\dfrac23-\dfrac{2}{3}(x-1)^{1/3}$。驻点：$(x-1)^{1/3}=1$，$x=2$；**不可导点 $x=1$**。

符号：$x<1$ 时 $f'>0$；$1<x<2$ 时 $f'<0$；$x>2$ 时 $f'>0$。

极大值 $f(1)=\dfrac23$（不可导点！），极小值 $f(2)=\dfrac13$。

警示：**候选点 = 驻点 + 不可导点**，漏掉后者是本考点最常见丢分。

:::

:::

## 三、闭区间最值：别忘了端点

::: warning 最值四步

① 定义域；② 求驻点与不可导点；③ 算**驻点、不可导点、区间端点**的函数值；④ 比大小。

极值是"局部冠军"，最值是"全场冠军"——**全场冠军可以在端点产生**，所以端点必比。

:::

::: tip 算例

例 3求 $f(x)=2x^{3}+3x^{2}-12x+14$ 在 $[-1,2]$ 上的最值。（夏应用 P47）

::: details 先自己列表，再展开

$f'(x)=6(x+2)(x-1)$，区间内驻点 $x=1$（$x=-2$ 在区间外，舍）。

比较：$f(-1)=27$，$f(1)=7$，$f(2)=18$。

最大值 $27$（在端点 $-1$ 取得！），最小值 $7$。

如果只比驻点就答错了最大值——**端点必比**，这道题就是来抓这个的。

:::

:::

## 四、两个应用套路

### 1. 单调性证不等式

::: tip 算例

例 4证明 $x>1$ 时 $2\sqrt{x}>3-\dfrac1x$。（夏应用 P30）

::: details 先自己设 $F$，再展开

设 $F(x)=2\sqrt x-3+\dfrac1x$，则 $F(1)=0$。

$F'(x)=\dfrac{1}{\sqrt x}-\dfrac{1}{x^{2}}=\dfrac{x^{3/2}-1}{x^{2}}>0$（$x>1$），故 $F$ 严格增，$F(x)>F(1)=0$，即 $2\sqrt x>3-\frac1x$。∎

固定套路：**移项设 $F=$ 右 $-$ 左（或左 $-$ 右）→ 算 $F$ 在起点的值（常为 0）→ 证 $F'$ 定号 → 得 $F$ 的符号**。秋应用练习 11–16 全部同型（$e^x>1+x$、$\ln x<x-1$ 等）。

:::

:::

### 2. 方程根的个数（最值分析）

::: tip 算例

例 5$a$ 为何值时，$\ln x-ax+1=0$ 在 $(0,+\infty)$ 有两个实根？（秋应用练习 17）

::: details 先自己分析最值，再展开

设 $f(x)=\ln x-ax+1$：$f'(x)=\dfrac1x-a$。

$a\le0$：$f$ 递增，至多 1 个根。$a>0$：$f$ 在 $x=\dfrac1a$ 取最大值 $f\left(\dfrac1a\right)=-\ln a$；两端 $x\to0^+$、$x\to+\infty$ 时 $f\to-\infty$。

两个根 ⟺ 最大值 $>0$ ⟺ $-\ln a>0$ ⟺ $0<a<1$。

方法论：**单调性 → 最值位置与符号 → 数形结合数交点**。"先存在后唯一"的证明（练习 18）是它的姊妹题型。

:::

:::

**随堂测 1：$y=e^{x}-ex-1$ 的单调性是（夏应用 P29）**

- A. 在 $R$ 上单调递增
- B. 在 $(-\infty,1)$ 减、$(1,+\infty)$ 增
- C. 在 $(-\infty,1)$ 增、$(1,+\infty)$ 减
- D. 在 $R$ 上单调递减

::: details 点开核对答案

**答案：B（在 $(-\infty,1)$ 减、$(1,+\infty)$ 增）** —— $y'=e^{x}-e$：$x&lt;1$ 时负（减），$x&gt;1$ 时正（增）。驻点 $x=1$ 同时是极小值点。先解 $f'=0$ 定分界，再逐段报符号。

:::

**随堂测 2：关于驻点与极值点，正确的是（夏应用概念题）**

- A. 驻点必是极值点
- B. 极值点必是驻点
- C. 可导函数的极值点必是驻点
- D. 极值点既不是驻点也不可导

::: details 点开核对答案

**答案：C（可导函数的极值点必是驻点）** —— A 反例 $y=x^3$（$x=0$ 是驻点但两侧同号不极值）；B 反例 $y=|x|$（极值点但不可导）；C 正是费马引理；D 自相矛盾。&lt;strong&gt;"可导的极值点必是驻点，反之不然"&lt;/strong&gt;。

:::

**随堂测 3：$y=\dfrac13x^{3}-4x+4$ 的极大值是（夏应用 P41）**

- A. $\dfrac{28}{3}$
- B. $-\dfrac{4}{3}$
- C. $4$
- D. $\dfrac{4}{3}$

::: details 点开核对答案

**答案：A（$\dfrac{28}{3}$）** —— $y'=x^{2}-4$，驻点 $\pm2$。$x=-2$ 两侧左正右负 ⇒ 极大，$y(-2)=-\frac83+8+4=\dfrac{28}{3}$；$x=2$ 极小 $-\dfrac43$。B 是极小值——看准问的哪个。

:::

**随堂测 4：求 $f(x)=\sin x+\cos x$ 在 $[0,\pi]$ 上的最小值，答案是（秋应用练习 8）**

- A. $\sqrt2$
- B. $0$
- C. $1$
- D. $-1$

::: details 点开核对答案

**答案：D（$-1$）** —— 驻点 $x=\frac\pi4$：$f=\sqrt2$（最大）。但端点 $f(0)=1$、$f(\pi)=-1$——最小值 $-1$ 在端点取得。只比驻点的人会答 $\sqrt2$ 或 1：&lt;strong&gt;端点必比&lt;/strong&gt;。

:::

**随堂测 5：证明 $x>0$ 时 $e^{x}>1+x$，设 $F(x)=e^{x}-1-x$，关键一步是**

- A. $F(0)=0$，且 $F$ 在 $x=0$ 处取极大值
- B. $F'(x)=e^{x}-1$，在 $x>0$ 时可能为负
- C. $F(0)=0$，且 $x>0$ 时 $F'(x)=e^{x}-1>0$，故 $F$ 严格增
- D. $F''(x)=e^{x}>0$ 直接得结论

::: details 点开核对答案

**答案：C（$F(0)=0$，且 $x&gt;0$ 时 $F'(x)=e^{x}-1&gt;0$，故 $F$ 严格增）** —— C 完整：起点值 $F(0)=0$ + 区间上严格增 ⇒ $F(x)&gt;0$。A 方向反了（是增不是极大）；B 符号判断错（$x&gt;0$ 时 $e^x&gt;1$）；D 只说凸性不够——凹函数可以取负值。（秋应用练习 11。）

:::

::: danger 本课易错清单

- 候选点 = **驻点 + 不可导点**（$|x|$ 型、分数幂型都藏不可导点）
- 判定定理二 $f''(x_0)=0$ 时**失效**，回判定定理一
- 闭区间最值**必比端点**；开区间可能无最值
- 单调区间要与**定义域**取交（$\ln$ 型先挖掉无定义段）
- 证不等式三件套：移项设 $F$ → 起点值 → $F'$ 定号
- 极小值可以大于极大值——别按"大小"排序极值

:::

**回忆卡：默写极值两个判定定理，并说出各自适用场景。**

::: details 先回忆，再揭晓

定理一：$f'$ 左正右负极大、左负右正极小（适用一切候选点，含不可导点）。定理二：$f''(x_0)<0$ 极大、$>0$ 极小、$=0$ 失效（仅在 $f''$ 好算时用）。

:::

**回忆卡：闭区间最值四步是什么？"驻点、极值点、最值点"三者的包含关系怎么说？**

::: details 先回忆，再揭晓

①定义域 ②驻点+不可导点 ③算候选点与端点值 ④比大小。可导极值点 ⊂ 驻点；最值在驻点/不可导点/端点中产生；极值是局部，最值是全局。

:::
