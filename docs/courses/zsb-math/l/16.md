数列极限 = 函数极限的离散版，前面六课的方法几乎全部平移过来；真正新的只有三样：$q^n$ 的讨论、$n$ 项和的夹逼、以及几个数列专属公式。本课以练带讲。

## 一、必背：$q^{n}$ 的四情形

::: warning 必背（$q=-1$ 是最常挖的坑）

$$\lim_{n\to\infty}q^{n}=\begin{cases}0, & |q|<1\\ +\infty, & q>1\\ 1, & q=1\\ \text{不存在}, & q\le-1\end{cases}$$

$q=-1$：$-1,1,-1,\dots$ **振荡发散**。$q=-\frac15$ 则 $|q|<1$，收敛于 0（秋数列练习 1）。

:::

## 二、四件套逐个过

### 1. 裂项（望远镜求和）

:::: tip 算例

例 1求 $\lim\limits_{n\to\infty}\left(\dfrac{1}{1\times2}+\dfrac{1}{2\times3}+\cdots+\dfrac{1}{n\times(n+1)}\right)$。

::: details 先自己裂，再展开（夏数列 P30）

$S_n=\left(1-\dfrac12\right)+\left(\dfrac12-\dfrac13\right)+\cdots+\left(\dfrac1n-\dfrac{1}{n+1}\right)=1-\dfrac{1}{n+1}\to1$。

0002 课的裂项三件套在这里全面服役：$1/\sqrt{n+1}+\sqrt n$ 型、$\ln(1+\frac1n)$ 型同法。

:::

::::

### 2. 根式有理化

:::: tip 算例

例 2求 $\lim\limits_{n\to\infty}\left(\sqrt{n^{2}+n}-n\right)$ 与 $\lim\limits_{n\to\infty}\left(\sqrt{4n^{2}+n}-2n\right)$。

::: details 先自己乘共轭，再展开（秋数列练习 6）

$\sqrt{n^2+n}-n=\dfrac{n}{\sqrt{n^2+n}+n}$，抓大头分母 $\sim2n$，答案 $\dfrac12$。

$\sqrt{4n^2+n}-2n=\dfrac{n}{\sqrt{4n^2+n}+2n}\to\dfrac{n}{4n}=\dfrac14$。

系数进根号要还原：$2n=\sqrt{4n^2}$，这是容易错的一步。

:::

::::

### 3. $e$ 定义式

:::: tip 算例

例 3秒答（秋数列练习 7）：

::: details 先全部心算，再展开核对

$\lim\limits_{n\to\infty}\left(1+\dfrac2n\right)^{n}=e^{2}$；$\lim\limits_{n\to\infty}\left(1-\dfrac1n\right)^{n}=e^{-1}$；

$\lim\limits_{n\to\infty}\left(1+\dfrac{3}{2n}\right)^{2n}=e^{3}$（指数与"分母配对"：$2n$ 正好吃掉 $\frac{3}{2n}$ 的分母）；$\lim\limits_{n\to\infty}\left(1+\dfrac{1}{2n}\right)^{3n}=e^{\frac32}$；

$\lim\limits_{n\to\infty}\left(\dfrac{3n-1}{3n+2}\right)^{n}=\left(1-\dfrac{3}{3n+2}\right)^{n}\to e^{-1}$。

统一公式：$\lim\left(1+\dfrac{k}{n}\right)^{cn}=e^{ck}$——先化成标准脸，再看指数吃进什么。

:::

::::

### 4. 求和公式（先求和再取极限）

:::: tip 算例

例 4求 $\lim\limits_{n\to\infty}\left(\dfrac{1}{n^{2}}+\dfrac{2}{n^{2}}+\cdots+\dfrac{n}{n^{2}}\right)$ 与 $\lim\limits_{n\to\infty}\dfrac{1+3+5+\cdots+(2n-1)}{n^{2}}$。

::: details 先自己求和，再展开（夏数列 P15、P17）

第一题分子是 $1+2+\cdots+n=\dfrac{n(n+1)}{2}$，整体 $=\dfrac{n(n+1)}{2n^2}\to\dfrac12$。

第二题奇数和 $=n^2$，整体 $\dfrac{n^2}{n^2}\to1$。

信号词：分子是**规整求和**（等差/等比）→ 先闭式求和再除。

:::

::::

## 三、夹逼定理：$n$ 项和的杀手锏

::: warning 夹逼定理与操作流程

若 $a_n\le b_n\le c_n$（$n$ 足够大）且 $\lim a_n=\lim c_n=k$，则 $\lim b_n=k$。

$n$ 项和三步：**每项换成最大 → 每项换成最小 → 两端算极限**。两端相等才收网，不等则此路不通。

:::

:::: tip 算例

例 5求 $\lim\limits_{n\to\infty}\left(\dfrac{n}{n^{2}+1}+\dfrac{n}{n^{2}+2}+\cdots+\dfrac{n}{n^{2}+n}\right)$。

::: details 先自己放大缩小，再展开（夏数列 P32）

共 $n$ 项，分母 $n^2+1$ 最小、$n^2+n$ 最大：

$\dfrac{n\cdot n}{n^{2}+n}\le S_n\le\dfrac{n\cdot n}{n^{2}+1}$，即 $\dfrac{n^{2}}{n^{2}+n}\le S_n\le\dfrac{n^{2}}{n^{2}+1}$。

两端抓大头都 $\to1$，故极限 $=1$。同型：$\sum\limits_{k=1}^{n}\dfrac{1}{\sqrt{n^{2}+k}}$，夹出 $1$。

:::

::::

## 四、海涅定理：数列 ↔ 函数的桥

数列是"$x$ 取正整数"的函数，所以 $\lim\limits_{n\to\infty}f(n)=\lim\limits_{x\to+\infty}f(x)$。数列题卡住时，**化成 $x\to+\infty$ 的函数极限**，把 0011–0015 的全部武器搬过来用。例：$\lim\limits_{n\to\infty}\dfrac{n^{2}+2n+3}{3n^{2}-2}\xlongequal{转函数}\lim\limits_{x\to+\infty}\dfrac{x^{2}+2x+3}{3x^{2}-2}=\dfrac13$（抓大头）。反向也成立：函数极限存在 ⇒ 任何子列极限相同（可用于**证伪**：奇偶子列极限不同 ⇒ 原极限不存在，如 $(-1)^n$）。

**随堂测 1：$\lim\limits_{n\to\infty}\left(-\dfrac15\right)^{n}=$**

- A. 不存在
- B. $-1$
- C. $0$
- D. $1$

::: details 点开核对答案

**答案：C（$0$）** —— $|q|=\frac15&lt;1$，按第一情形收敛于 0（正负交替只是让它"摆动着"归零，不影响极限值）。别和 $q=-1$ 的振荡发散搞混。

:::

**随堂测 2：$\lim\limits_{n\to\infty}\left(\dfrac{2n+3}{2n}\right)^{n}=$**

- A. $e^{\frac{3}{2}}$
- B. $e^{3}$
- C. $e^{\frac{2}{3}}$
- D. $e^{6}$

::: details 点开核对答案

**答案：A（$e^{\frac{3}{2}}$）** —— 化标准脸 $=\left(1+\dfrac{3}{2n}\right)^{n}$，指数 $v(u-1)=\dfrac{3n}{2n}=\dfrac32$，答案 $e^{3/2}$。（秋数列练习 7(5)。）

:::

**随堂测 3：$\lim\limits_{n\to\infty}\left(\sqrt{9n^{2}+2n}-3n\right)=$**

- A. $3$
- B. $\dfrac{1}{3}$
- C. $0$
- D. $+\infty$

::: details 点开核对答案

**答案：B（$\dfrac{1}{3}$）** —— 乘共轭：$\dfrac{2n}{\sqrt{9n^2+2n}+3n}$，分母抓大头 $\sim6n$，答案 $\dfrac{2n}{6n}=\dfrac13$。（秋数列练习 6(4) 改编——先有理化，再抓头，两步不能省。）

:::

**随堂测 4：用夹逼定理求 $\lim\limits_{n\to\infty}\sum\limits_{k=1}^{n}\dfrac{1}{\sqrt{n^{2}+k}}$ 时，正确的放缩是**

- A. $\dfrac{n}{\sqrt{n^{2}+n^{2}}}\le S_n\le\dfrac{n}{\sqrt{n^{2}+1}}$，极限 $\dfrac{1}{\sqrt2}$
- B. 每项放成 $\dfrac{1}{n}$，极限 $1$；不用夹逼
- C. $\dfrac{1}{\sqrt{n^{2}+n}}\le S_n\le1$，两端不等，夹不出来
- D. $\dfrac{n}{\sqrt{n^{2}+n}}\le S_n\le\dfrac{n}{\sqrt{n^{2}+1}}$，两端均 $\to1$

::: details 点开核对答案

**答案：D（$\dfrac{n}{\sqrt{n^{2}+n}}\le S_n\le\dfrac{n}{\sqrt{n^{2}+1}}$，两端均 $\to1$）** —— 放缩用"每项同换最值"：最小值 $\frac{1}{\sqrt{n^2+n}}$ 乘 $n$ 项、最大值 $\frac{1}{\sqrt{n^2+1}}$ 乘 $n$ 项，两端抓大头都 $\to1$。A 的下界放太狠（把 $k$ 也换成 $n$），夹出了错误值。

:::

**随堂测 5：若 $\{a_n\}$ 的奇数项子列 $\to1$、偶数项子列 $\to-1$，则 $\{a_n\}$**

- A. 发散（子列极限不同）
- B. 收敛于 0
- C. 收敛，但极限未知
- D. 收敛于 1 或 $-1$ 之一

::: details 点开核对答案

**答案：A（发散（子列极限不同））** —— 收敛数列的&lt;strong&gt;任何子列&lt;/strong&gt;都收敛于同一极限（海涅定理思想）。两支子列分道扬镳，原数列必发散——典型如 $(-1)^n$。这是"证发散"的标准话术。

:::

::: danger 本课易错清单

- $q^{n}$ 四情形背全：$q\le-1$ 不存在，$q=-1$ 是**振荡**不是 0
- 有理化后别忘了分母抓大头：$\sqrt{n^2+n}+n\sim2n$（系数 2 别丢）
- $e$ 定义式先化"$1+\frac{k}{\text{指数的底}}$"标准脸，再看指数
- $n$ 项和：规整求和先闭式（例 4），乱和无规则用夹逼（例 5）——先判断再动笔
- 夹逼的放缩是"**每项**换成最值 × 项数"，别只放一两端

:::

**回忆卡：默写 $q^n$ 四情形，并举一个振荡发散的具体数列。**

::: details 先回忆，再揭晓

$|q|<1\to0$；$q>1\to+\infty$；$q=1\to1$；$q\le-1$ 不存在。例：$(-1)^n$（$q=-1$，振荡发散）。

:::

**回忆卡：数列极限四件套是哪四样？各自对付什么长相的题？**

::: details 先回忆，再揭晓

裂项（$\sum$ 分式相消）；根式有理化（$\sqrt{n^2+an}-bn$）；$e$ 定义式（$1^{\infty}$ 型）；等差等比求和（分子规整求和）。再外加夹逼（乱和无规则）。

:::
