定积分应用题的本质是"**总量 = 微元的累积**"。公式不用硬背一堆——每个公式都是一条微元加个积分号。本课把四组公式搭好架子，配讲义标准例题。

## 一、元素法三步

::: warning 通用流程

① **画图像**（求交点、看区域）→ ② **写微元**（$dS$、$dV$、$dl$）→ ③ **补积分区间**（积分限 = 交点 / 端点）。

:::

## 二、平面图形的面积

::: warning 两组公式

**X 型**（竖条微元 $[f-g]\,dx$）：$S=\displaystyle\int_a^{b}\left[f(x)-g(x)\right]dx$

**Y 型**（横条微元 $[\varphi-\psi]\,dy$）：$S=\displaystyle\int_c^{d}\left[\varphi(y)-\psi(y)\right]dy$

被减数永远是**"上减下"或"右减左"**——先画图再定，别死记谁减谁。

:::

::: tip 算例

例 1（必会标准件）求 $y=\sqrt x$ 与 $y=x^{2}$ 围成图形的面积。（夏讲 P61）

::: details 先自己三步走，再展开

交点：$\sqrt x=x^{2}\Rightarrow x=0,1$；$[0,1]$ 上 $\sqrt x\ge x^{2}$（上减下）。

$S=\displaystyle\int_0^{1}\left(\sqrt x-x^{2}\right)dx=\left[\frac23x^{\frac32}-\frac{x^{3}}{3}\right]_0^1=\frac23-\frac13=\frac13$。

同款：$y=e^{x}$ 与 $y=e^{-x}$ 在 $[0,1]$：$S=e+\dfrac1e-2$（夏讲 P60）。

:::

:::

## 三、旋转体的体积

::: warning 两组公式（圆盘法）

**绕 $x$ 轴**：$V=\pi\displaystyle\int_a^{b}f^{2}(x)\,dx$（竖条转出薄圆盘 $\pi y^{2}dx$）

**绕 $y$ 轴**：换写成 $x=\varphi(y)$ 后 $V=\pi\displaystyle\int_c^{d}\varphi^{2}(y)\,dy$（横条转盘）

两个自带项：**$\pi$ 与平方**——漏 $\pi$ 或忘平方是本考点两大失分源。

:::

::: tip 算例

例 2（球的体积是怎么来的）半圆 $y=\sqrt{r^{2}-x^{2}}$ 绕 $x$ 轴一周。（夏讲 P66）

::: details 先自己积分，再展开

$V=\pi\displaystyle\int_{-r}^{r}\left(r^{2}-x^{2}\right)dx=\pi\left[r^{2}x-\frac{x^{3}}{3}\right]_{-r}^{r}=\frac43\pi r^{3}$。

初中背的球体积公式，用定积分三行推出——旋转体公式的"验明正身"。

:::

:::

::: tip 算例

例 3（绕 $x$ 轴标准件）$y=\sqrt x$、$x=2$ 与 $x$ 轴围成的图形绕 $x$ 轴。（夏讲 P67）

::: details 先自己列式，再展开

$V=\pi\displaystyle\int_0^{2}\left(\sqrt x\right)^{2}dx=\pi\int_0^{2}x\,dx=2\pi$。

看点：$\left(\sqrt x\right)^2=x$——先平方后积分，很多"吓人"的根号自己就消失了。

:::

:::

::: tip 算例

例 4（绕 $y$ 轴）$y=e^{x}$、$y=e^{3}$ 与 $y$ 轴围成的图形绕 $y$ 轴。（夏讲 P68）

::: details 先换成 $x=\varphi(y)$，再展开

区域：$1\le y\le e^{3}$，$0\le x\le\ln y$。换底：$x=\varphi(y)=\ln y$。

$V=\pi\displaystyle\int_1^{e^{3}}(\ln y)^{2}dy=\pi\left[y(\ln y)^{2}-2y\ln y+2y\right]_1^{e^{3}}=\pi\left(5e^{3}-2\right)$（分部积分两次）。

要点：**绕 $y$ 轴就"横过来"对 $y$ 积分**，积分限换成 $y$ 的范围。

:::

:::

## 四、弧长

::: warning 两组公式

**直角坐标**：$l=\displaystyle\int_a^{b}\sqrt{1+\left(f'(x)\right)^{2}}\,dx$

**参数式**：$l=\displaystyle\int_{\alpha}^{\beta}\sqrt{\left(x'(t)\right)^{2}+\left(y'(t)\right)^{2}}\,dt$

记忆：微元是"斜的小段"$dl=\sqrt{dx^{2}+dy^{2}}$。根号别丢。

:::

::: tip 算例

例 5（参数式 = 圆弧）$\begin{cases}x=3\sin t\\ y=3\cos t\end{cases}$，$t\in\left[0,\frac\pi2\right]$。（秋讲练习 23）

::: details 先自己套公式，再展开

$l=\displaystyle\int_0^{\frac\pi2}\sqrt{9\cos^{2}t+9\sin^{2}t}\,dt=\int_0^{\frac\pi2}3\,dt=\dfrac{3\pi}{2}$——半径 3 的四分之一圆周，公式结果与几何常识互相印证。

:::

:::

## 五、物理应用：总量 = 变化率的积分

产量 = $\int_{t_1}^{t_2}f(t)\,dt$；细棒质量 = $\int_0^{L}\rho(x)\,A\,dx$。例（夏讲 P70）：$A=2$、$L=4$、$\rho(x)=2x^{2}+3x+6$ 的细棒，$m=2\int_0^4(2x^{2}+3x+6)dx=\dfrac{544}{3}$。**"变化率累积成总量"是定积分最朴素的应用观**。

**随堂测 1：曲线 $y=x^{2}$ 与 $y=2x$ 围成图形的面积是**

- A. $\dfrac{4}{3}$
- B. $\dfrac{1}{3}$
- C. $\dfrac{4}{3}$ 之外的 $\dfrac{8}{3}$
- D. $\dfrac{2}{3}$

::: details 点开核对答案

**答案：C（$\dfrac{4}{3}$ 之外的 $\dfrac{8}{3}$）** —— 交点：$x^2=2x\Rightarrow x=0,2$；$[0,2]$ 上 $2x\ge x^{2}$。$S=\displaystyle\int_0^2(2x-x^{2})dx=4-\dfrac83=\dfrac43$。D 忘了幂函数系数（$\int2x=x^2$，$\int x^2=\frac{x^3}3$）——老老实实两步积分。

:::

**随堂测 2：$y=\dfrac1x$、$y=0$、$x=1$ 与 $x=2$ 围成的图形绕 $x$ 轴一周的体积是**

- A. $\pi\ln2$
- B. $\dfrac{\pi}{2}$
- C. $\pi$
- D. $\dfrac12$

::: details 点开核对答案

**答案：B（$\dfrac{\pi}{2}$）** —— $V=\pi\displaystyle\int_1^{2}\frac{1}{x^{2}}dx=\pi\left[-\frac1x\right]_1^2=\frac{\pi}{2}$。A 把 $\frac1{x^2}$ 积成了 $\ln$——$\frac1{x^2}$ 是幂函数（$p=2$），$\frac1x$ 才是对数。&lt;strong&gt;先平方，再认形状&lt;/strong&gt;。

:::

**随堂测 3：用圆盘法求绕 $y$ 轴的旋转体体积时，正确的做法是**

- A. 仍对 $x$ 积分，公式不变
- B. 把 $f(x)$ 直接平方对 $y$ 积分
- C. 用弧长公式替代
- D. 把曲线写成 $x=\varphi(y)$，$V=\pi\int_c^d\varphi^{2}(y)\,dy$，限用 $y$ 的范围

::: details 点开核对答案

**答案：D（把曲线写成 $x=\varphi(y)$，$V=\pi\int_c^d\varphi^{2}(y)\,dy$，限用 $y$ 的范围）** —— 绕谁转就"垂直于谁"切微元：绕 $y$ 轴用横条，曲线反解成 $x=\varphi(y)$，$y$ 从 $c$ 到 $d$。例 4 的 $y=e^x$ 换成 $\ln y$ 就是标准动作。

:::

**随堂测 4：$y=\dfrac23x^{\frac32}$ 从 $x=0$ 到 $x=3$ 的弧长被积函数是**

- A. $\sqrt{1+x}\,dx$
- B. $\sqrt{1+x^{3}}\,dx$
- C. $\sqrt{1+\dfrac23x}\,dx$
- D. $\dfrac23x^{\frac32}\,dx$

::: details 点开核对答案

**答案：A（$\sqrt{1+x}\,dx$）** —— $y'=x^{\frac12}=\sqrt x$，弧长 $=\int_0^3\sqrt{1+(\sqrt x)^{2}}dx=\int_0^3\sqrt{1+x}\,dx=\dfrac23\left(4^{\frac32}-1\right)=\dfrac{14}{3}$。D 是面积微元——弧长的根号 + 平方导数结构别丢。

:::

**随堂测 5：某产品总量的变化率 $f(t)=100+12t-0.6t^{2}$，则 $t=2$ 到 $t=4$ 的产量为（夏讲 P69）**

- A. $f(4)-f(2)$
- B. $f(4)$
- C. $\displaystyle\int_2^{4}f(t)\,dt=260.8$
- D. $\displaystyle\int_0^{4}f(t)\,dt$

::: details 点开核对答案

**答案：C（$\displaystyle\int_2^{4}f(t)\,dt=260.8$）** —— 总量 = 变化率的定积分：$\left[100t+6t^{2}-0.2t^{3}\right]_2^4=483.2-222.4=260.8$。A 是"变化率的变化"，不是产量——总量对变化率&lt;strong&gt;积分&lt;/strong&gt;，不是代入相减。

:::

::: danger 本课易错清单

- 应用题**先画图求交点**：交点就是积分限；"上减下 / 右减左"看图定
- 旋转体公式自带 $\pi$ 与**平方**：$V=\pi\int f^{2}$；绕 $y$ 轴换 $x=\varphi(y)$
- 弧长公式 $\sqrt{1+(f')^{2}}$：**根号别丢**、导数先平方
- 几何面积 vs 代数值：跨 $x$ 轴的图形要分段取 $|f|$
- 物理题："总量 = 变化率的积分"，区间看题目给的时间段

:::
