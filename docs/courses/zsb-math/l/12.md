## 一、第一个重要极限：小角正弦

::: warning 必背与推广

$$\lim_{x\to0}\frac{\sin x}{x}=1\qquad\text{推广：}\lim_{\square\to0}\frac{\sin\square}{\square}=1$$

推论：$\lim\limits_{x\to0}\dfrac{\tan x}{x}=1$；$\lim\limits_{x\to0}\dfrac{1-\cos x}{x^2}=\dfrac12$（用 $\cos$ 半角或乘共轭推出来）。

使用心法：**方框里必须一模一样**，且方框 $\to0$。凑方框是全部技巧。

:::

::: tip 算例

例 1求 $\lim\limits_{x\to0}\dfrac{\sin 2x}{x}$ 与 $\lim\limits_{x\to0}\dfrac{1-\cos x}{\frac12x^2}$。

::: details 先自己凑，再展开

$\lim\limits_{x\to0}\dfrac{\sin2x}{x}=\lim\limits_{x\to0}2\cdot\dfrac{\sin2x}{2x}=2\times1=2$（凑 $2x$ 方框）。

$1-\cos x=2\sin^2\dfrac x2$，故 $\lim\limits_{x\to0}\dfrac{2\sin^2\frac x2}{\frac12x^2}=\lim\limits_{x\to0}\left(\dfrac{\sin\frac x2}{\frac x2}\right)^2=1$，即 $\dfrac{1-\cos x}{x^2}\to\dfrac12$。

:::

:::

::: danger 同式不同命：先看过程再动笔

| 式子 | $x\to0$ | $x\to\infty$ |
| --- | --- | --- |
| $\dfrac{\sin 2x}{x}$ | $2$（重要极限一） | $0$（有界 × 无穷小） |
| $x\sin\dfrac{2}{x}$ | $0$（无穷小 × 有界） | $2$（令 $t=\frac2x\to0$） |
| $\dfrac{\arctan x}{x}$ | $1$ | $0$（有界 × 无穷小） |

三行全对 = 本课一半的分数。做题**第一眼先圈趋向**，再套公式。（秋讲练习 10 原题组。）

:::

## 二、第二个重要极限：$1^{\infty}$ 型

::: warning 必背与三步法

$$\lim_{x\to\infty}\left(1+\frac1x\right)^{x}=e\qquad\text{等价形式：}\lim_{\alpha\to0}\left(1+\alpha\right)^{\frac1\alpha}=e$$

**$1^{\infty}$ 三步法**：确认 $u\to1$、$v\to\infty$ 后，$$\lim u^{v}=e^{\lim v(u-1)}$$

指数 $\lim v(u-1)$ 用普通方法（抓大头/等价）算出 $k$，答案就是 $e^k$。

:::

::: tip 算例

例 2求 $\lim\limits_{x\to\infty}\left(1-\dfrac1x\right)^{4x+3}$ 与 $\lim\limits_{x\to\infty}\left(\dfrac{x+3}{x-5}\right)^{x}$。

::: details 先自己算指数，再展开

第一题：$u=1-\frac1x\to1$，$v=4x+3\to\infty$ ✓。$v(u-1)=(4x+3)\left(-\dfrac1x\right)\to-4$，答案 $e^{-4}$。

第二题：先改写成标准脸 $u=\dfrac{x+3}{x-5}=1+\dfrac{8}{x-5}$，则 $v(u-1)=\dfrac{8x}{x-5}\to8$，答案 $e^{8}$。

流程固定：**化成 $1+$ 无穷小 → 算 $v(u-1)$ → 写 $e^k$**。

:::

:::

::: tip 算例

例 3（逆求参数）若 $\lim\limits_{x\to\infty}\left(\dfrac{x+2a}{x-a}\right)^{x}=8$，求 $a$。

::: details 先自己列方程，再展开（秋讲练习 16 同型）

$u=1+\dfrac{3a}{x-a}$，$v(u-1)=\dfrac{3ax}{x-a}\to3a$。所以 $e^{3a}=8$，$3a=\ln8$，$a=\ln2$。

逆求题全是这个闭环：**算出指数表达式 → 令 $e^{指数}=$ 已知值 → 解参数**。再练一道：$\lim\limits_{x\to0}(1+ax)^{\frac1x}=e^2$，指数 $\dfrac{ax}{x}=a$，故 $a=2$（秋讲练习 17）。

:::

:::

**随堂测 1：$\lim\limits_{x\to\infty}x\sin\dfrac{2}{x}=$**

- A. $0$
- B. $2$
- C. $1$
- D. 不存在

::: details 点开核对答案

**答案：B（$2$）** —— $x\to\infty$ 时 $\frac2x\to0$，改写 $2\cdot\dfrac{\sin\frac2x}{\frac2x}\to2\times1=2$。方框是 $\frac2x$，整体一样就能套。A 是"$x\to0$"的答案——又是同式不同命。

:::

**随堂测 2：$\lim\limits_{x\to0}\left(\dfrac{\tan x}{x}\right)^{\frac{1}{x^2}}$ 属于哪种未定式？**

- A. $\frac00$ 型
- B. $0\cdot\infty$ 型
- C. $1^{\infty}$ 型
- D. 不是未定式

::: details 点开核对答案

**答案：C（$1^{\infty}$ 型）** —— 底 $\dfrac{\tan x}{x}\to1$，指数 $\dfrac1{x^2}\to\infty$，标准 $1^{\infty}$。（顺手算：指数 $v(u-1)=\dfrac{\tan x-x}{x^3}\to\dfrac13$，答案 $e^{1/3}$——用了三阶差关系 $\tan x-x\sim\frac13x^3$，0013 课细讲。）

:::

**随堂测 3：$\lim\limits_{x\to0}(1-2x)^{\frac1x}=$**

- A. $e^{-2}$
- B. $e^{2}$
- C. $e^{-\frac12}$
- D. $e$

::: details 点开核对答案

**答案：A（$e^{-2}$）** —— 三步法：$u=1-2x\to1$，$v=\frac1x\to\infty$；$v(u-1)=\dfrac{-2x}{x}=-2$，答案 $e^{-2}$。（秋讲练习 11(1)。）B 忘了负号；C 把"每次除 2"和"乘 $-2$"搞混了。

:::

**随堂测 4：$\lim\limits_{x\to0}\left(1+\dfrac ax\right)^{bx}$（$a\neq0$）的值是（易错题）**

- A. $e^{ab}$
- B. $e^{a}$
- C. $e^{b}$
- D. $1$

::: details 点开核对答案

**答案：D（$1$）** —— 这不是 $1^{\infty}$！底 $1+\frac ax\to\infty$，属 $\infty^{0}$ 型。取对数：$\dfrac{\ln(1+\frac ax)}{bx}\cdot b\to\dfrac{\ln(+\infty)}{\infty}=0$ 型 → 极限 $e^0=1$。先验底再套公式——三步法的第一步是"确认 $u\to1$"。（秋讲练习 11(4) 原题陷阱。）

:::

**随堂测 5：若 $\lim\limits_{x\to\infty}\left(\dfrac{x+a}{x-a}\right)^{x}=4$，则 $a=$**

- A. $\ln 4$
- B. $\ln 2$
- C. $\dfrac{\ln 4}{4}$
- D. $2\ln 2$ 之外再无解

::: details 点开核对答案

**答案：B（$\ln 2$）** —— $v(u-1)=\dfrac{2ax}{x-a}\to2a$，故 $e^{2a}=4$，$a=\ln2$。A 把 $2a$ 当成了 $a$。逆求三步：算指数 → $e^{指数}=$ 已知 → 两边取对数。（秋讲练习 16 原题。）

:::

::: danger 本课易错清单

- 动笔前先圈趋向：$\dfrac{\sin2x}{x}$ 在 $x\to0$ 与 $x\to\infty$ 答案差一个世界
- 重要极限一要求**方框一致**：$\dfrac{\sin 3x}{2x}= \dfrac32\cdot\dfrac{\sin3x}{3x}\to\dfrac32$，别直接写 1
- $1^{\infty}$ 三步法第一步是**验底 $\to1$**；底 $\to\infty$ 或 $\to0$ 时要取对数另算
- 推论 $\dfrac{1-\cos x}{x^2}\to\dfrac12$ 考场直接用，等价于 $1-\cos x\sim\dfrac12x^2$（0013 课正式入表）

:::

**回忆卡：默写两个重要极限（含方框推广形式），并写出 $1^{\infty}$ 三步法公式。**

::: details 先回忆，再揭晓

$\lim\limits_{\square\to0}\frac{\sin\square}{\square}=1$；$\lim\limits_{x\to\infty}\left(1+\frac1x\right)^x=e$，即 $\lim\limits_{\alpha\to0}(1+\alpha)^{\frac1\alpha}=e$；$1^{\infty}$ 型：$\lim u^v=e^{\lim v(u-1)}$（先验 $u\to1,v\to\infty$）。

:::

**回忆卡：秒答四题：$\lim\limits_{x\to0}\dfrac{\sin2x}{x}$、$\lim\limits_{x\to\infty}\dfrac{\sin2x}{x}$、$\lim\limits_{x\to0}x\sin\dfrac2x$、$\lim\limits_{x\to0}(1+\tan x)^{\cot x}$。**

::: details 先回忆，再揭晓

$2$；$0$（有界 × 无穷小）；$0$（无穷小 × 有界）；$e$（$1^{\infty}$，指数 $v(u-1)=\cot x\cdot\tan x=1$）。

:::
