不定积分是求导的**逆运算**：求导表倒过来背，就是积分表。这单元方法最多（凑微分、换元、分部、分式、三角五套），但入口只有两个概念 + 一张表——本课把地基打平。

## 一、原函数与不定积分

::: warning 定义与两条性质

区间 $I$ 上 $F'(x)=f(x)$，则 $F(x)$ 是 $f(x)$ 的一个**原函数**；原函数全体 $F(x)+C$ 记作 $\int f(x)dx$，称**不定积分**。

① $F(x)+C$ 就是**所有的**原函数（$(x^2)'=(x^2+2)'=(x^2-1000)'=2x$）；② 任意两个原函数**仅相差一个常数**。

:::

::: warning 互逆关系与 $C$ 规则（概念题年年考）

| 运算 | 结果 | $C$？ |
| --- | --- | --- |
| 先积后导 $\left[\int f(x)dx\right]'$ / 先积后微 $d\int f(x)dx$ | $f(x)$ / $f(x)dx$ | **无 $C$** |
| 先导后积 $\int F'(x)dx$ / $\int dF(x)$ | $F(x)$ | **有 $C$** |

口诀：**"积出去要补 $C$，导回来不用"**。另外 $d\int f\,dx=f(x)\,dx$——别把 $dx$ 弄丢。

:::

::: tip 算例

例 1$f'(x)=3x^{2}+2e^{x}$ 且 $f(0)=1$，求 $f(x)$。（秋讲练习 3）

::: details 先自己积一次，再展开

$f(x)=\int(3x^{2}+2e^{x})dx=x^{3}+2e^{x}+C$；由 $f(0)=2+C=1$ 得 $C=-1$。

答案 $f(x)=x^{3}+2e^{x}-1$——**"积分 + 定常数"两步**，这类"由 $f'$ 求 $f$"是原函数概念题的标准考法。

:::

:::

**随堂测 1：$\ln x$ 的一个原函数是（秋讲练习同型）**

- A. $x\ln x$
- B. $\dfrac{1}{x}$
- C. $x\ln x-x$
- D. $\dfrac{(\ln x)^{2}}{2}$

::: details 点开核对答案

**答案：C（$x\ln x-x$）** —— 验证导数：$(x\ln x-x)'=\ln x+x\cdot\frac1x-1=\ln x$ ✓。A 求导多出 $\ln x+1$ 的"1"；B 是 $\ln x$ 的导数不是原函数；D 求导得 $\frac{\ln x}{x}$。"谁是原函数"永远用&lt;strong&gt;求导验证&lt;/strong&gt;，不用积分。

:::

**随堂测 2：下列等式正确的是（夏讲 P7 原题）**

- A. $\int df(x)=f(x)$
- B. $d\int f(x)dx=f(x)$
- C. $\int f'(x)dx=f(x)$
- D. $\dfrac{d}{dx}\int f(x)dx=f(x)$

::: details 点开核对答案

**答案：D（$\dfrac{d}{dx}\int f(x)dx=f(x)$）** —— D 是"先积后导"，无 $C$ 恰好还原 ✓。A 应为 $f(x)+C$（先导后积要补 $C$）；B 丢了 $dx$（应为 $f(x)dx$）；C 应为 $f(x)+C$。三错一对比着记。

:::

## 二、基本积分公式表（必背）

| 公式 | 公式 |
| --- | --- |
| $\int k\,dx=kx+C$ | $\int x^{\mu}dx=\dfrac{x^{\mu+1}}{\mu+1}+C\ (\mu\neq-1)$ |
| $\int\dfrac{1}{x}dx=\ln\|x\|+C$ | $\int\dfrac{1}{\sqrt x}dx=2\sqrt x+C$；$\int\dfrac{dx}{x^{2}}=-\dfrac1x+C$ |
| $\int e^{x}dx=e^{x}+C$ | $\int a^{x}dx=\dfrac{a^{x}}{\ln a}+C$ |
| $\int\sin x\,dx=-\cos x+C$ | $\int\cos x\,dx=\sin x+C$ |
| $\int\sec^{2}x\,dx=\tan x+C$ | $\int\csc^{2}x\,dx=-\cot x+C$ |
| $\int\sec x\tan x\,dx=\sec x+C$ | $\int\csc x\cot x\,dx=-\csc x+C$ |
| $\int\dfrac{dx}{1+x^{2}}=\arctan x+C$ | $\int\dfrac{dx}{\sqrt{1-x^{2}}}=\arcsin x+C$ |
| $\int\dfrac{dx}{\sqrt{x^{2}+a}}=\ln\left\|x+\sqrt{x^{2}+a}\right\|+C$（补充公式，0028 课会"再发现"它） | $\int\dfrac{dx}{\sqrt{x^{2}+a}}=\ln\left\|x+\sqrt{x^{2}+a}\right\|+C$（补充公式，0028 课会"再发现"它） |

::: danger 两个高频坑

- $\mu=-1$ 是幂函数公式的**例外**：$\int\frac{dx}{x}=\ln|x|+C$——**绝对值不可丢**
- 三角公式**符号与求导表"同步反向"**：$\int\sin x\,dx=-\cos x+C$（因为 $(\cos x)'=-\sin x$）

:::

## 三、直接积分法：化幂 + 加减一项

::: tip 算例

例 2（化幂）$\displaystyle\int\frac{(1+\sqrt x)^{2}}{\sqrt[3]{x}}\,dx$。（夏讲 P13）

::: details 先自己展开，再对照

展开为幂和：$x^{-\frac13}+2x^{\frac16}+x^{\frac23}$，逐项套幂函数公式：

$\dfrac32x^{\frac23}+\dfrac{12}{7}x^{\frac76}+\dfrac35x^{\frac53}+C$。

流程：**根式化分数指数 → 逐项积分**；除法（如 $\sqrt x(x^2-1)$）先乘开。

:::

:::

::: tip 算例

例 3（加一项减一项）$\displaystyle\int\frac{x^{2}-1}{x^{2}+1}dx$ 与 $\displaystyle\int\tan^{2}x\,dx$。（夏讲 P14）

::: details 先自己"造出公式长相"，再展开

$\dfrac{x^{2}-1}{x^{2}+1}=\dfrac{(x^{2}+1)-2}{x^{2}+1}=1-\dfrac{2}{x^{2}+1}$，积分 $=x-2\arctan x+C$。

$\tan^{2}x=\sec^{2}x-1$，积分 $=\tan x-x+C$。

"加一项减一项"的本质：**把不认识的形状改造回公式表里的形状**。同款：$\int\dfrac{x^{2}}{x^{2}+1}dx=x-\arctan x+C$。

:::

:::

**随堂测 3：$\displaystyle\int\dfrac{1}{x^{2}}dx=$**

- A. $-\dfrac{2}{x^{3}}+C$
- B. $-\dfrac{1}{x}+C$
- C. $\dfrac{1}{x}+C$
- D. $\ln|x^{2}|+C$

::: details 点开核对答案

**答案：B（$-\dfrac{1}{x}+C$）** —— $\frac{1}{x^2}=x^{-2}$，幂函数公式：$\dfrac{x^{-2+1}}{-2+1}=-x^{-1}=-\dfrac1x$。A 是求导的答案（方向反了）；D 是 $\frac1x$ 的积分——三条路线别串。

:::

**随堂测 4：$\displaystyle\int(2^{x}-3\sin x)\,dx=$（夏讲 P11）**

- A. $2^{x}\ln2+3\cos x+C$
- B. $\dfrac{2^{x}}{\ln2}-3\cos x+C$
- C. $\dfrac{2^{x}}{\ln2}+3\cos x+C$
- D. $\dfrac{2^{x+1}}{2}-3\cos x+C$

::: details 点开核对答案

**答案：C（$\dfrac{2^{x}}{\ln2}+3\cos x+C$）** —— $\int a^xdx=\dfrac{a^x}{\ln a}+C$；$\int(-3\sin x)dx=-3\cdot(-\cos x)=+3\cos x$。A 是求导的形状；负负得正是 C 的关键一步。

:::

**随堂测 5：$\displaystyle\int\dfrac{x-1}{\sqrt x-1}dx=$（秋讲练习 8(7)）**

- A. $\dfrac{2}{3}x^{\frac32}+x+C$
- B. $\dfrac{2}{3}x^{\frac32}-x+C$
- C. $\ln|\sqrt x-1|+C$
- D. $\dfrac12x^{2}-x+C$

::: details 点开核对答案

**答案：A（$\dfrac{2}{3}x^{\frac32}+x+C$）** —— 分子平方差：$x-1=(\sqrt x-1)(\sqrt x+1)$，约分后剩 $\sqrt x+1$，积分 $\dfrac23x^{\frac32}+x+C$。"因式分解消因子"和 0011 课极限的去零因式是同一招的前后半场。

:::

::: danger 本课易错清单

- $\int\frac{dx}{x}=\ln\boldsymbol{|x|}+C$——绝对值丢一个，全题重做
- 幂函数公式 $\mu\neq-1$ 才能用；$\int\frac{dx}{x^2}$、$\int\frac{dx}{\sqrt x}$ 是"负指数/分数指数"幂
- "谁是原函数"用**求导验证**；"由 $f'$ 求 $f$" = 积分 + 边界条件定 $C$
- 先积后导无 $C$、先导后积有 $C$；$d\int f\,dx$ 别丢 $dx$
- 三角、反三角积分符号逐一对照求导表，别凭感觉写

:::

**回忆卡：默写互逆关系四条，并标注哪两条带 $C$。**

::: details 先回忆，再揭晓

$[\int f\,dx]'=f(x)$（无 $C$）；$d\int f\,dx=f(x)dx$（无 $C$）；$\int F'(x)dx=F(x)+C$（有 $C$）；$\int dF(x)=F(x)+C$（有 $C$）。

:::

**回忆卡：默写三条幂系公式：$\int x^{\mu}dx$（注明例外）、$\int\frac{dx}{x}$、$\int\frac{dx}{\sqrt x}$。**

::: details 先回忆，再揭晓

$\int x^{\mu}dx=\frac{x^{\mu+1}}{\mu+1}+C$（$\mu\neq-1$）；$\int\frac{dx}{x}=\ln|x|+C$；$\int\frac{dx}{\sqrt x}=2\sqrt x+C$。

:::
