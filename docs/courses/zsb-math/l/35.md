## 一、二元函数、二重极限与连续

::: warning 定义域与二重极限

定义域把一元函数的限制**逐项联立**（分母、偶次根、真数、反三角）。如 $z=\ln(1-x^{2}-y^{2})$ 的定义域为 $x^{2}+y^{2}<1$（圆内）。

二重极限 $\lim\limits_{(x,y)\to(x_0,y_0)}f=A$ 要求**沿任意路径**都趋于 $A$：**两条路径结果不同 ⇒ 极限不存在**；但两条路径相同**不能证明**存在。

连续：极限值 = 函数值；初等函数在有定义的区域内连续。累次极限（先 $y$ 后 $x$）与二重极限是两回事，存在时相等、反向不成立。

:::

## 二、偏导数：轮流"冻结"变量

::: warning 定义与求法

$$f_x(x_0,y_0)=\lim_{\Delta x\to0}\dfrac{f(x_0+\Delta x,\,y_0)-f(x_0,y_0)}{\Delta x}$$

对 $x$ 求偏导时**把 $y$ 当常数**，反之亦然——第 3 单元全部求导法则照用。分段函数在分界点求偏导**必须回定义**（固定另一变量后作差商）。

:::

::: tip 算例

例 1（一阶 + 特定点值）$f(x,y)=x^{3}y^{2}+2xy^{4}+\sin(xy)$，求 $f_x,\ f_y$ 与 $f_y(1,2)$ 型计算。

::: details 先自己冻变量，再展开（练习 4–5 同族）

$f_x=3x^{2}y^{2}+2y^{4}+y\cos(xy)$（对 $x$：$y$ 全程当常数）；$f_y=2x^{3}y+8xy^{3}+x\cos(xy)$。

定点型：$f(x,y)=x^{2}e^{x^{2}y}+\ln(x+y^{2})$，$f_y=x^{2}e^{x^{2}y}\cdot x^{2}+\dfrac{2y}{x+y^{2}}$，代 $(1,2)$：$f_y(1,2)=e^{2}+\dfrac45$。

偏导数也是（二元）函数——先求通式再代点，与一元"求 $f'$ 再代值"完全同构。

:::

:::

## 三、全微分与二阶偏导

::: warning 公式

$$dz=f_{x}\,dx+f_{y}\,dy$$

如 $z=x^{y}$（$x>0$）：$dz=yx^{y-1}dx+x^{y}\ln x\,dy$（对 $y$ 求导时 $x^y$ 是"指数函数"，冒出 $\ln x$）。

二阶偏导四种：$f_{xx},\ f_{xy},\ f_{yx},\ f_{yy}$；混合偏导连续时 $f_{xy}=f_{yx}$（先对谁后对谁看下标顺序）。

:::

::: tip 算例

例 2（二阶全套）$z=x^{3}+x^{2}y-3y^{3}$，求四个二阶偏导。

::: details 先自己求两轮，再展开（练习 10 同族）

$z_x=3x^{2}+2xy$，$z_y=x^{2}-9y^{2}$。

$z_{xx}=6x+2y$，$z_{yy}=-18y$，$z_{xy}=z_{yx}=2x$。

操作节奏：**先求两个一阶，再各再导一次**；$z_{xy}$ 是"先对 $x$、再对 $y$"。

:::

:::

::: warning 概念关系图（选择题高发区）

$$f_x,f_y\ \text{在邻域内连续}\ \Longrightarrow\ f\ \text{可微}\ \Longrightarrow\ f\ \text{连续且偏导存在}$$

箭头**不可逆**；"连续"与"偏导存在"互相推不出；**偏导存在 ⇏ 可微**（与一元"可导 ⇏ 连续？不，一元可导必连续"不同，多元的坑在"偏导存在但连续/可微都保不住"）。

:::

**随堂测 1：$z=x^{2}y+\sin(xy)$，则 $z_x=$**

- A. $2xy+\cos(xy)$
- B. $x^{2}+y\cos(xy)$
- C. $2xy+y\cos(xy)$
- D. $2xy-y\cos(xy)$

::: details 点开核对答案

**答案：C（$2xy+y\cos(xy)$）** —— 对 $x$ 求导，$y$ 是常数：$x^{2}y\to2xy$；$\sin(xy)\to\cos(xy)\cdot y$（链式，内层 $xy$ 对 $x$ 的导数是 $y$）。A 丢了链式的 $y$；B 把第一项求导错了对象。

:::

**随堂测 2："$f_x$、$f_y$ 在点 $(x_0,y_0)$ 的邻域内连续"是"$f$ 在该点可微"的**

- A. 必要条件
- B. 充分条件
- C. 充要条件
- D. 毫无关系

::: details 点开核对答案

**答案：B（充分条件）** —— 偏导连续 ⇒ 可微（充分），但可微&lt;strong&gt;不必&lt;/strong&gt;偏导连续——"可微但偏导不连续"的反例存在（超出讲义范围，不要求会构造），记住这条单向箭头即可。关系图单向记忆：&lt;strong&gt;偏导连续是最强条件&lt;/strong&gt;。

:::

**随堂测 3：要证明 $\lim\limits_{(x,y)\to(0,0)}f(x,y)$ 不存在，有效的做法是**

- A. 找两条路径趋近，极限值不同
- B. 沿 $x$ 轴与 $y$ 轴极限相同
- C. 两个累次极限相等
- D. 沿 $y=kx$ 极限都相同

::: details 点开核对答案

**答案：A（找两条路径趋近，极限值不同）** —— 二重极限要求&lt;strong&gt;任意路径&lt;/strong&gt;一致，两径不同即否决。B、D 是"部分路径相同"——不能证明存在；C 累次极限与二重极限是两回事。&lt;strong&gt;路径法只能证伪，不能证实&lt;/strong&gt;。

:::

**随堂测 4：$z=x^{y}$（$x>0$），则 $z_y=$**

- A. $yx^{y-1}$
- B. $x^{y}$
- C. $x^{y}\ln y$
- D. $x^{y}\ln x$

::: details 点开核对答案

**答案：D（$x^{y}\ln x$）** —— 对 $y$ 求导时 $x^{y}$ 是"指数函数"：$(a^{y})'=a^{y}\ln a$，底是 $x$ ⇒ $x^{y}\ln x$。A 是 $z_x$——这对函数是"幂函数 / 指数函数"的双面人，看清对谁求导。

:::

**随堂测 5：$z=e^{xy}$，则 $z_{xy}=$**

- A. $e^{xy}$
- B. $(1+xy)e^{xy}$
- C. $xye^{xy}$
- D. $y^{2}e^{xy}$

::: details 点开核对答案

**答案：B（$(1+xy)e^{xy}$）** —— $z_x=ye^{xy}$；再对 $y$：$e^{xy}+y\cdot xe^{xy}=(1+xy)e^{xy}$（乘积 + 链式）。两次混合偏导连续时相等，验算可换序：$z_y=xe^{xy}$ 再对 $x$ 同样得 $(1+xy)e^{xy}$ ✓。

:::

::: danger 本课易错清单

- 偏导口诀：**对谁求导，另一个变量全是常数**；复合内层（$xy$）要链式
- $x^{y}$ 型：对 $x$ 是幂（$yx^{y-1}$）、对 $y$ 是指数（$x^{y}\ln x$）——双面人函数
- 关系链单向：偏导连续 ⇒ 可微 ⇒ 连续 + 偏导存在；**偏导存在 ⇏ 可微、⇏ 连续**
- 二重极限：路径法**只能否定**；累次极限 ≠ 二重极限
- 分段点偏导**必须用定义**（固定另一变量作差商）

:::

**回忆卡：默写全微分公式，并画出"偏导连续 / 可微 / 连续 / 偏导存在"的推出关系。**

::: details 先回忆，再揭晓

$dz=f_xdx+f_ydy$。偏导连续 ⇒ 可微 ⇒ 连续且偏导存在；单向，且"连续"与"偏导存在"互不推出。

:::

**回忆卡：写出 $z=x^{y}$ 的两个一阶偏导，并说出各自把 $x^{y}$ 当成什么函数。**

::: details 先回忆，再揭晓

$z_x=yx^{y-1}$（幂函数视角）；$z_y=x^{y}\ln x$（指数函数视角）。
