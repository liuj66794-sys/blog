## 一、四大定理（都要求"闭区间上连续"）

::: warning 必背

**① 有界性定理**：$f(x)$ 在 $[a,b]$ 上连续 ⇒ 必有界。

**② 最值定理**：$f(x)$ 在 $[a,b]$ 上连续 ⇒ 必取得最大值 $M$ 与最小值 $m$。

**③ 介值定理**：对任意 $\mu\in[m,M]$，存在 $\xi\in[a,b]$ 使 $f(\xi)=\mu$——曲线从最低爬到最高，中间每个高度都要路过。

**④ 零点定理**：若 $f(a)\cdot f(b)<0$（端点异号），则存在 $\xi\in(a,b)$ 使 $f(\xi)=0$。

:::

注意前提都是"**闭区间 + 连续**"，缺一不可：开区间内 $f(x)=\frac1x$ 连续但无界；不连续（如取整函数）可能跳过某些值。零点定理是介值定理取 $\mu=0$ 的特例——前提是 $0$ 夹在 $m,M$ 之间，端点异号正好保证这点。

## 二、零点定理证根五步（秋讲总结的满分模板）

::: warning 五步：构造 → 连续 → 端点值 → 异号 → 套定理

① **构造** $F(x)$：把方程一边移成 $F(x)=0$；

② 说明 $F$ 在闭区间 $[a,b]$ 上**连续**（初等函数一句话）；

③ 计算 $F(a)$、$F(b)$ 的值；

④ 验证 $F(a)\cdot F(b)<0$（**端点异号**）；

⑤ 引用零点定理下结论：存在 $\xi\in(a,b)$ 使 $F(\xi)=0$，即方程在 $(a,b)$ 内至少有一个实根。∎

:::

::: tip 算例

例 1（标准示范）证明方程 $x^{3}-4x^{2}+1=0$ 在 $(0,1)$ 内至少有一个实根。（夏连续教材 P49）

::: details 先自己按五步写，再对照

令 $F(x)=x^{3}-4x^{2}+1$，$F(x)$ 在 $[0,1]$ 上连续；

$F(0)=1>0$，$F(1)=1-4+1=-2<0$，端点异号。

由零点定理，存在 $\xi\in(0,1)$ 使 $F(\xi)=0$，即方程在 $(0,1)$ 内至少有一个实根。∎

:::

:::

::: tip 算例

例 2（移项构造）证明 $e^{x}=3x$ 在 $(0,1)$ 内至少有一个实根。（秋连续练习 6）

::: details 先自己构造，再展开

移项：令 $F(x)=e^{x}-3x$，在 $[0,1]$ 上连续；

$F(0)=1>0$，$F(1)=e-3\approx-0.28<0$，异号 ✓。

由零点定理，存在 $\xi\in(0,1)$ 使 $e^{\xi}=3\xi$。∎

估值小技巧：$e\approx2.718<3$，能直接断负号；实在不好估就说"$F(1)=e-3<0$"（$e<3$ 是常识）。

:::

:::

## 三、两个变式

::: tip 算例

例 3（不动点问题）$f(x)$ 在 $[a,b]$ 上连续，$f(a)<a$，$f(b)>b$。证明存在 $c\in(a,b)$ 使 $f(c)=c$。（秋连续练习 9）

::: details 先想"怎么造出=0 的式子"，再展开

"$f(c)=c$"即"$f(c)-c=0$"——构造 $F(x)=f(x)-x$。

$F$ 在 $[a,b]$ 上连续；$F(a)=f(a)-a<0$，$F(b)=f(b)-b>0$，异号。

由零点定理，存在 $c\in(a,b)$ 使 $F(c)=0$，即 $f(c)=c$。∎

口诀：**结论里要什么等式，就把等式一边移过来构造 $F$**。"方程 $g(x)=h(x)$ 有根" ⟺ "$F=g-h$ 有零点"。

:::

:::

::: tip 算例

例 4（介值定理推论）$f(x)$ 在 $[a,b]$ 上连续，$x_1,x_2,x_3\in[a,b]$。证明存在 $\xi\in[a,b]$ 使 $f(\xi)=\dfrac{f(x_1)+f(x_2)+f(x_3)}{3}$。（夏连续教材 P49）

::: details 先自己串最值+介值，再展开

由最值定理，$f$ 取到最小值 $m$、最大值 $M$。对 $i=1,2,3$：$m\le f(x_i)\le M$，三式相加：

$m\le\dfrac{f(x_1)+f(x_2)+f(x_3)}{3}\le M$——平均值也夹在 $[m,M]$ 内。

由介值定理，存在 $\xi\in[a,b]$ 使 $f(\xi)$ 等于这个平均值。∎

套路：**"平均值/中间值"结论 = 最值定理夹出范围 + 介值定理命中**。

:::

:::

**随堂测 1：零点定理的条件是**

- A. $f(x)$ 在 $(a,b)$ 内连续，且 $f(a)=f(b)$
- B. $f(x)$ 在 $[a,b]$ 上连续，且 $f(a)+f(b)<0$
- C. $f(x)$ 在 $[a,b]$ 上连续，且 $f(a)\cdot f(b)<0$
- D. $f(x)$ 在 $[a,b]$ 上可导，且 $f(a)\cdot f(b)>0$

::: details 点开核对答案

**答案：C（$f(x)$ 在 $[a,b]$ 上连续，且 $f(a)\cdot f(b)&lt;0$）** —— 两个条件缺一不可：&lt;strong&gt;闭区间连续 + 端点异号（积为负）&lt;/strong&gt;。B 的"和为负"不代表异号（$-2+1=-1&lt;0$ 但同号）；D 的前提和符号全不对。

:::

**随堂测 2：证明"$x^{3}-3x+1=0$ 在 $(1,2)$ 内有根"的正确构造是**

- A. $F(x)=x^{3}-3x+1$，$F(1)=-1<0$，$F(2)=3>0$
- B. $F(x)=x^{3}-3x$，$F(1)=-2$，$F(2)=2$
- C. $F(x)=x^{3}+1$，$F(1)=2$，$F(2)=9$
- D. $F(x)=x^{3}-3x+1$ 在开区间 $(1,2)$ 内看连续性

::: details 点开核对答案

**答案：A（$F(x)=x^{3}-3x+1$，$F(1)=-1&lt;0$，$F(2)=3&gt;0$）** —— 方程已经是"左边 $=0$"，构造就是它自己（A）；B 丢掉了常数项 1，$F(1)=-2,F(2)=2$ 虽异号但零点不再对应原方程——构造必须与方程等价。D 的错误：零点定理要&lt;strong&gt;闭区间&lt;/strong&gt;连续。

:::

**随堂测 3：证明"$\ln x=x-2$ 在 $(3,4)$ 内有根"，应构造并计算**

- A. $F=\ln x+x-2$，$F(3)>0$，$F(4)>0$
- B. $F=\ln x-x+2$，$F(3)=\ln3-1>0$，$F(4)=\ln4-2<0$
- C. $F=\ln x-2$，$F(3)<0$，$F(4)>0$
- D. $F=x-2-\ln x$，$F(3)=1-\ln3>0$，$F(4)=2-\ln4>0$

::: details 点开核对答案

**答案：B（$F=\ln x-x+2$，$F(3)=\ln3-1&gt;0$，$F(4)=\ln4-2&lt;0$）** —— 移项成 $\ln x-x+2=0$（B）。A 是"同边相加"，造不出零点等式；D 构造等价但端点算错号（$1-\ln3\approx-0.10&lt;0$，$\ln3\approx1.10$）。注意 $\ln3&gt;1$（$e&lt;3$）、$\ln4&lt;2$（$e^2&gt;4$）这两个估值锚点。

:::

**随堂测 4：四大定理共同的前提是**

- A. $f(x)$ 在 $(a,b)$ 内连续
- B. $f(x)$ 在 $[a,b]$ 上可导
- C. $f(x)$ 在 $(-\infty,+\infty)$ 连续
- D. $f(x)$ 在闭区间 $[a,b]$ 上连续

::: details 点开核对答案

**答案：D（$f(x)$ 在闭区间 $[a,b]$ 上连续）** —— 四个定理全部建在"&lt;strong&gt;闭区间 + 连续&lt;/strong&gt;"上。A 开区间不够（$1/x$ 在 $(0,1)$ 连续但无界、无最值）；B 的可导太强也没必要。写证明时这句前提要&lt;strong&gt;原样写进卷面&lt;/strong&gt;，阅卷按步给分。

:::

**随堂测 5：证明不动点问题（$f(a)<a$，$f(b)>b$ ⇒ 存在 $c$ 使 $f(c)=c$）的构造是**

- A. $F(x)=f(x)$
- B. $F(x)=f(x)+x$
- C. $F(x)=f(x)-x$
- D. $F(x)=f(x)\cdot x$

::: details 点开核对答案

**答案：C（$F(x)=f(x)-x$）** —— 目标等式 $f(c)=c$ 移项得 $f(c)-c=0$，零点就属于 $F(x)=f(x)-x$。构造心法：&lt;strong&gt;见到"相等的两样东西"，相减构造&lt;/strong&gt;。此时 $F(a)&lt;0$、$F(b)&gt;0$，恰好异号。

:::

::: danger 本课易错清单

- 五步一步不能省：**尤其"闭区间上连续"这句前提话**——阅卷按步给分
- 结论写"存在 $\xi\in\boldsymbol{(a,b)}$"（开区间），条件里 $f(a)\cdot f(b)<0$ 用的是端点值
- 构造必须与方程**等价**：移项后一边为 0，另一边整体就是 $F(x)$
- 端点值估号常用锚点：$\ln2\approx0.69$、$\ln3\approx1.10$、$e\approx2.72$、$\pi\approx3.14$
- "平均值"型结论走**最值定理 + 介值定理**组合，不走零点定理

:::

**回忆卡：默写四大定理（名称 + 条件 + 结论各一句）。**

::: details 先回忆，再揭晓

$[a,b]$ 上连续 ⇒ ①有界；②取到最大值 $M$、最小值 $m$；③对任意 $\mu\in[m,M]$ 存在 $\xi$ 使 $f(\xi)=\mu$（介值）；④若 $f(a)f(b)<0$，则存在 $\xi\in(a,b)$ 使 $f(\xi)=0$（零点）。

:::

**回忆卡：默写零点定理证根五步，并说出"平均值型"证明用哪两个定理组合。**

::: details 先回忆，再揭晓

构造 $F$ → 闭区间连续 → 算端点值 → 验异号 → 引零点定理下结论。平均值型：最值定理夹范围 + 介值定理命中。

:::
