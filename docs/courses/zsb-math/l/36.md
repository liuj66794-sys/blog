一元链式法则的多元版：从 $z$ 到 $x$ 可能有多条"路"，每条路**沿路相乘**，到同一个目标的各条路**相加**。0008 课的拆层能力在这里升级成画树状图。

## 一、复合函数：树状路径法

::: warning 链式公式

$z=f(u,v)$，$u=u(x,y)$，$v=v(x,y)$：

$$z_{x}=f_{u}\,u_{x}+f_{v}\,v_{x}\qquad\qquad z_{y}=f_{u}\,u_{y}+f_{v}\,v_{y}$$

画法：$z$ 在树根，分叉到 $u,v$，再各自分叉到 $x,y$。求 $z_x$：找所有**从 $z$ 到 $x$ 的路径**，每条路径上偏导相乘，路径间相加。

:::

::: tip 算例

例 1（具体复合）$z=e^{uv}$，$u=x+y$，$v=x^{2}+y$，求 $z_x,\ z_y$。

::: details 先自己画树，再展开（练习 17 同型）

$z_u=e^{uv}\cdot v=z\cdot v$（先对 $u$：指数函数），$z_v=e^{uv}\cdot u$。

$z_x=z_u\cdot u_x+z_v\cdot v_x=e^{uv}v+e^{uv}u\cdot2x=e^{uv}(v+2xu)$。

$z_y=e^{uv}(v+u)$。

结构化输出：**先写 $u,v$，再写路径和**——阅卷按路径给分，树状图写草稿上。

:::

:::

::: tip 算例

例 2（抽象复合：$f_1,f_2$ 记号）$z=f\bigl(x^{2}-y^{2},\ e^{xy}\bigr)$，求 $z_x,\ z_y$。

::: details 先自己设记号，再展开（练习 19）

令 $u=x^{2}-y^{2}$，$v=e^{xy}$，记 $f_1=f_u$、$f_2=f_v$：

$z_x=2x\,f_1+ye^{xy}f_2$；$z_y=-2y\,f_1+xe^{xy}f_2$。

要点：**$f_1,f_2$ 不许再动**（它们就是"答案的零件"）；严格场合注明取值点 $\bigl(u,v\bigr)$。漏路径、丢 $f_2$ 是本型最大扣分点。

:::

:::

## 二、隐函数求导：两条路

::: warning 公式法（先把三个变量当独立）

一元 $F(x,y)=0$：$y'=-\dfrac{F_x}{F_y}$；二元 $F(x,y,z)=0$ 确定 $z(x,y)$：

$$z_{x}=-\frac{F_{x}}{F_{z}},\qquad z_{y}=-\frac{F_{y}}{F_{z}}\qquad(F_{z}\neq0)$$

注意与"两边直接求导法"的区别：公式法里 $F_x$ 对 $x$ 求导时 $y,z$ **都当常数**；直接法里 $z$ 是 $x$ 的函数。两条路答案一致，公式法快。

:::

::: tip 算例

例 3（公式法）$e^{z}=xyz$，求 $z_x,\ z_y$。

::: details 先自己算 $F$ 的三个偏导，再展开（练习 22 同型）

令 $F=e^{z}-xyz$：$F_x=-yz$，$F_y=-xz$，$F_z=e^{z}-xy$。

$z_x=-\dfrac{F_x}{F_z}=\dfrac{yz}{e^{z}-xy}$；$z_y=\dfrac{xz}{e^{z}-xy}$。

易错警示：**$F_x$ 里不要再对 $z$ 链式**——公式法的 $F_x,F_y,F_z$ 各自独立求偏导，这是它比直接法省心的全部原因。

:::

:::

::: tip 算例

例 4（直接法对照）$x^{2}+y^{2}+z^{2}=4z$，求 $z_x$。

::: details 两种方法都走一遍

**公式法**：$F=x^{2}+y^{2}+z^{2}-4z$，$F_x=2x$，$F_z=2z-4$，$z_x=-\dfrac{2x}{2z-4}=\dfrac{x}{2-z}$。

**直接法**：两边对 $x$ 求导（$z$ 是 $x$ 的函数，$y$ 是常数）：$2x+2zz_x=4z_x$，解出 $z_x=\dfrac{x}{2-z}$ ✓。

两法同果。直接法的口诀：**含 $z$ 项全带 $z'$，最后解方程**（0017 课一元隐函数的老套路）。

:::

:::

**随堂测 1：$z=u^{2}v$，$u=x+y$，$v=xy$，则 $z_x=$**

- A. $2uv+u^{2}y$
- B. $2uv+u^{2}y$ 之外的 $\dfrac{2uv}{x}$
- C. $2uv\cdot y$
- D. $u^{2}y$

::: details 点开核对答案

**答案：B（$2uv+u^{2}y$ 之外的 $\dfrac{2uv}{x}$）** —— 两条路：经 $u$：$2uv\cdot u_x=2uv\cdot1$；经 $v$：$u^{2}\cdot v_x=u^{2}y$。相加 $2uv+u^{2}y$。&lt;strong&gt;"沿路相乘、同标相加"&lt;/strong&gt;八个字就是全部。

:::

**随堂测 2：$z=f(x+y,\ xy)$，则 $z_y=$（练习 20 同型）**

- A. $xf_{1}+yf_{2}$
- B. $f_{1}+yf_{2}$
- C. $f_{1}+xf_{2}$
- D. $f_{2}$

::: details 点开核对答案

**答案：C（$f_{1}+xf_{2}$）** —— $u=x+y$ 对 $y$ 导数 1；$v=xy$ 对 $y$ 导数 $x$：$z_y=f_1\cdot1+f_2\cdot x$。A 是 $z_x$（把 $x,y$ 角色互换）——抽象复合题先写清 $u,v$ 再落笔，防串线。

:::

**随堂测 3：设 $F(x,y,z)=0$ 确定 $z=z(x,y)$，则 $z_x=$**

- A. $-\dfrac{F_x}{F_z}$
- B. $\dfrac{F_x}{F_z}$
- C. $-\dfrac{F_z}{F_x}$
- D. $F_x-F_z$

::: details 点开核对答案

**答案：A（$-\dfrac{F_x}{F_z}$）** —— 负号别丢、分子分母别倒：$F_x$ 在上、$F_z$ 在下、整体添负。记忆：$z$ 的偏导 = "$-x$ 方向比上 $z$ 方向"。

:::

**随堂测 4：$x^{2}+y^{2}+z^{2}=4z$ 中用公式法求 $F_x$ 时，正确的是**

- A. $2x+2z\dfrac{\partial z}{\partial x}$
- B. $2x+2zz_x$
- C. $2x+2y$
- D. $2x$

::: details 点开核对答案

**答案：D（$2x$）** —— 公式法中 $F_x$ 是"$x,y,z$ 视为独立变量"时对 $x$ 的偏导：$z^{2}$ 项与 $x$ 无关，导数为 0，得 $2x$。A、B 是直接法的动作——&lt;strong&gt;两套规则不可混用&lt;/strong&gt;，混用就重复计算。

:::

**随堂测 5：$x+y+z=\ln z$（即 $F=x+y+z-\ln z$）确定 $z(x,y)$，则 $z_x=$**

- A. $1+z$
- B. $\dfrac{z}{1-z}$
- C. $\dfrac{1-z}{z}$
- D. $-\dfrac{z}{1-z}$

::: details 点开核对答案

**答案：B（$\dfrac{z}{1-z}$）** —— $F_x=1$，$F_z=1-\dfrac1z=\dfrac{z-1}{z}$，$z_x=-\dfrac{1}{(z-1)/z}=\dfrac{z}{1-z}$。D 丢了整体负号。验算（直接法）：$1+z_x=\dfrac{z_x}{z}$ ⇒ $z(1+z_x)=z_x$ ⇒ 同样得 $\dfrac{z}{1-z}$ ✓。

:::

::: danger 本课易错清单

- 链式树状图：**漏路径 = 丢分**；抽象复合 $f_1,f_2$ 不许再求导，需注明取值点
- 幂指型 $z=u^{v}$ 优先取对数 $\ln z=v\ln u$ 再求导（0020 课口诀的多元版）
- 公式法 $F_x,F_y,F_z$：**三变量当独立**；直接法：$z$ 当函数——两条路别串规则
- 隐函数公式自带**负号**：$z_x=-\dfrac{F_x}{F_z}$
- 答案里允许含 $z$（隐函数导数本来就带位置信息），但 $F_z=0$ 的点要排除

:::

**回忆卡：默写复合链式公式（$z=f(u,v)$）与隐函数公式（$F(x,y,z)=0$）。**

::: details 先回忆，再揭晓

$z_x=f_uu_x+f_vv_x$，$z_y=f_uu_y+f_vv_y$（沿路相乘、同标相加）；$z_x=-\dfrac{F_x}{F_z}$，$z_y=-\dfrac{F_y}{F_z}$。

:::

**回忆卡：公式法与直接法对 $z$ 的"身份"各怎么处理？各自的口诀是什么？**

::: details 先回忆，再揭晓

公式法：$x,y,z$ 全当独立变量，各自求偏导再套 $-\frac{F_x}{F_z}$；直接法：$z$ 是 $x,y$ 的函数，含 $z$ 项全带 $z'$，最后解方程。

:::
