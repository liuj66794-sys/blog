复合函数的拆解是下一章"复合函数求极限 / 链式求导"的预备动作——到时候要一层一层穿进去算，所以现在就要练成"一眼看穿层数"的本事。反函数则是 0007 课指数↔对数关系的正式化。

## 一、复合函数：由外向内剥洋葱

::: warning 结构与可复合条件

外层 $y=f(u)$，内层 $u=g(x)$，复合成 $y=f[g(x)]$。能复合的条件：$f$ 的定义域与 $g$ 的值域**交集非空**——内层的输出要接得住外层的输入。

拆解口诀：**由外向内，逐层设变量**；每层都必须是 0007 课的基本初等函数，拆到拆不动为止。

:::

:::: tip 算例

例 1（四连拆，讲义原题）写出下列函数的复合过程：

$y=2^{\sin x}$；$y=\lg(1-x)$；$y=\tan^3(2x^2+1)$；$y=\sqrt{\ln(a^x+3)}$

::: details 先自己全部拆完，再展开答案

| 函数 | 复合过程（由外向内） |
| --- | --- |
| $y=2^{\sin x}$ | $y=2^u$，$u=\sin x$（两层） |
| $y=\lg(1-x)$ | $y=\lg u$，$u=1-x$（两层） |
| $y=\tan^3(2x^2+1)$ | $y=u^3$，$u=\tan v$，$v=2x^2+1$（三层） |
| $y=\sqrt{\ln(a^x+3)}$ | $y=\sqrt u$，$u=\ln v$，$v=a^x+3$（三层） |

两个细节：$\tan^3(\cdot)$ 的外层是 $u^3$ 不是 $\tan u$——三次方套在外面；$\lg(1-x)$ 的内层 $1-x$ 不必再拆，它已是一次函数。

:::

::::

**随堂测 1：$y=\tan^3(2x^2+1)$ 的复合过程（由外向内）是**

- A. $y=\tan u$，$u=v^3$，$v=2x^2+1$
- B. $y=u^3$，$u=\tan v$，$v=2x^2+1$
- C. $y=u^3$，$u=2v+1$，$v=\tan x^2$
- D. $y=\tan^3 u$，$u=2x^2+1$

::: details 点开核对答案

**答案：B（$y=u^3$，$u=\tan v$，$v=2x^2+1$）** —— 最外层是"三次方"，其次是 $\tan$，最内是二次式。A 把前两层顺序穿反了；D 的"$\tan^3 u$"只是原式换了个写法，没有拆开——每一层都得是基本初等函数才算拆到位。

:::

**随堂测 2：$y=2^{\sin^2 x}$ 应拆成几层？正确第一层（最外层）是**

- A. 两层，$y=2^u$，$u=\sin x$
- B. 两层，$y=\sin^2 u$，$u=2x$
- C. 三层，$y=2^u$，$u=v^2$，$v=\sin x$
- D. 三层，$y=u^2$，$u=2^v$，$v=\sin x$

::: details 点开核对答案

**答案：C（三层，$y=2^u$，$u=v^2$，$v=\sin x$）** —— 从外读：指数位置上坐着一个 $\sin^2x$，所以最外层是 $2^u$；$\sin^2x=\left(\sin x\right)^2$ 再拆出平方层；最后是 $\sin x$。层数 = 从外到内遇到的运算次数，先在草稿上标出来再设变量。

:::

## 二、反函数：三步法，最后一步必标定义域

::: warning 定义与性质

$y=f(x)$ 若对其值域内每个 $y$ 都能**唯一**解出 $x$，就得到反函数 $x=f^{-1}(y)$，习惯上写成 $y=f^{-1}(x)$。

三条性质：① $x=f^{-1}[f(x)]=f[f^{-1}(x)]$（互相抵消）；② 图象关于直线 $y=x$ 对称；③ **单调性与原函数一致**。

:::

::: warning 三步法

**反解**（把 $x$ 用 $y$ 表示）→ **互换**（$x,y$ 换位置）→ **标定义域**（= 原函数的值域，不是想当然的"全体实数"）。

:::

:::: tip 算例

例 2（夏讲教材 P24）求 $y=\sqrt{x+1}$ 的反函数。

::: details 先自己求，再展开

反解：$x+1=y^2$，$x=y^2-1$（$y\ge0$，因为原函数是算术根）；互换：$y=x^2-1$；标定义域：原函数值域是 $[0,+\infty)$，所以

$$y=x^2-1\quad(x\ge0)$$

不写 $(x\ge0)$ 就错了：抛物线 $y=x^2-1$ 整条有左半支，而反函数只要右半支。同法可得 $y=e^{x+1}$ 的反函数为 $y=\ln x-1\ (x>0)$。

:::

::::

:::: tip 算例

例 3（秋讲练习 10）求 $y=2\sin 3x$，$x\in\left[-\dfrac{\pi}{6},\dfrac{\pi}{6}\right]$ 的反函数。

::: details 先自己求，再展开

反解：$\sin3x=\dfrac y2$，$3x=\arcsin\dfrac y2$，$x=\dfrac13\arcsin\dfrac y2$；互换并标定义域：原函数值域 $y\in[-2,2]$，故

$$y=\dfrac13\arcsin\dfrac x2,\quad x\in[-2,2]$$

注意题目给的 $x\in\left[-\frac{\pi}{6},\frac{\pi}{6}\right]$ 不是装饰：它让 $3x\in\left[-\frac{\pi}{2},\frac{\pi}{2}\right]$，正好落在 $\sin$ 的一一对应区间上，反函数才存在。**先有限制区间，才有反函数**——这正是 0007 课反三角函数表里值域受限的原因。

:::

::::

| 原函数 | 反函数 | 限制条件 |
| --- | --- | --- |
| $y=x^n$ | $y=\sqrt[n]{x}$ | $x>0$ |
| $y=e^x$ | $y=\ln x$ | — |
| $y=\sin x$ | $y=\arcsin x$ | $x\in\left[-\frac{\pi}{2},\frac{\pi}{2}\right]$ |
| $y=\cos x$ | $y=\arccos x$ | $x\in[0,\pi]$ |
| $y=\tan x$ | $y=\arctan x$ | $x\in\left(-\frac{\pi}{2},\frac{\pi}{2}\right)$ |
| $y=\cot x$ | $y=\operatorname{arccot} x$ | $x\in(0,\pi)$ |

**随堂测 3：$y=1+\ln(x+2)$ 的反函数是（秋讲练习 10）**

- A. $y=e^{x-1}-2\ (x\in R)$
- B. $y=e^{x+1}-2\ (x\in R)$
- C. $y=e^{x-1}+2\ (x\in R)$
- D. $y=\ln(x-1)+2\ (x>1)$

::: details 点开核对答案

**答案：A（$y=e^{x-1}-2\ (x\in R)$）** —— 反解：$y-1=\ln(x+2)$ → $x=e^{y-1}-2$；互换得 $y=e^{x-1}-2$。原函数值域是 $R$，所以定义域 $x\in R$。指数、对数互化时"常数搬家"最容易错位——用 $x=0$ 代回验算：原函数 $f(0)=1+\ln2$；反函数带 $x=1+\ln2$ 进去应得 0：$e^{\ln2}-2=0$ ✓。

:::

**随堂测 4：$y=\sqrt{x+1}$ 的反函数写成下列哪种形式才完整？**

- A. $y=x^2-1$
- B. $y=x^2-1\ (x\le0)$
- C. $y=-x^2+1\ (x\ge0)$
- D. $y=x^2-1\ (x\ge0)$

::: details 点开核对答案

**答案：D（$y=x^2-1\ (x\ge0)$）** —— 三步法的第三步不可省：定义域 $=$ 原函数值域 $=[0,+\infty)$。A 没标——按定义不完整，考试要扣分；B、C 的方向或符号反了。

:::

**随堂测 5：一个函数与其反函数的图象，关于下列哪条直线对称？**

- A. $y$ 轴
- B. $y=x$
- C. $x$ 轴
- D. $y=-x$

::: details 点开核对答案

**答案：B（$y=x$）** —— "$x,y$ 互换"在图象上就是把每个点 $(a,b)$ 翻到 $(b,a)$——关于直线 $y=x$ 的镜面反射。例如 $y=e^x$ 与 $y=\ln x$ 互为镜像；顺带还有个有趣特例：$y=\dfrac{1-x}{1+x}$ 的反函数是它自己（秋讲练习 10）。

:::

::: danger 本课易错清单

- 反函数**最后一步必标定义域**（= 原函数值域）——阅卷看到 $y=x^2-1\ (x\ge0)$ 给满分，不标扣分
- $\tan^3(\cdot)$ 外层是 $u^3$；$\sin^2(\cdot)$ 外层是 $u^2$——幂在三角**外面**
- 不是所有函数都有反函数：要先一一对应（$\sin x$ 全域无反函数，限定区间后才有）
- 反函数单调性与原函数一致（增的反还是增），但定义域、值域**互换**

:::

**回忆卡：默写反函数三步法，并说出第三步的定义域等于什么。**

::: details 先回忆，再揭晓

反解 → 互换 → 标定义域；定义域 = 原函数的值域。

:::

**回忆卡：从外向内拆：$y=\sqrt{\ln(a^x+3)}$。每层各是什么？**

::: details 先回忆，再揭晓

$y=\sqrt u$，$u=\ln v$，$v=a^x+3$（三层：算术根、对数、指数）。

:::

**回忆卡：默写三组最常用反函数对及其限制区间：$e^x$、$\sin x$、$\tan x$ 的反函数。**

::: details 先回忆，再揭晓

$y=e^x\leftrightarrow y=\ln x$（无需限制）；$y=\sin x\leftrightarrow y=\arcsin x$（限 $x\in\left[-\frac{\pi}{2},\frac{\pi}{2}\right]$）；$y=\tan x\leftrightarrow y=\arctan x$（限 $x\in\left(-\frac{\pi}{2},\frac{\pi}{2}\right)$）。

:::
