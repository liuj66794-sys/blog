## 一、分式积分四策略

::: warning 判型流程（先看分子分母次数！）

| 类型 | 策略 |
| --- | --- |
| **假分式**（分子次数 ≥ 分母） | **长除法**拆成"多项式 + 真分式"，或加一项减一项 |
| 真分式，分母**能**因式分解 | **裂项**（待定系数：单因式 $\frac{A}{x+a}$；重根多设几层；二次因式设 $\frac{Ax+B}{\cdot}$） |
| 真分式，分母**不能**分解，分子含变量 | 分子凑**分母的导数**（剩常数部分配 $\arctan$） |
| 真分式，分子是常数 | 分母配方，**凑 $\arctan$** 或基本公式 |

:::

::: tip 算例

例 1（长除）$\displaystyle\int\dfrac{4x^{3}+8x^{2}+5x+5}{2x+3}dx$。（夏讲 P25）

::: details 先自己长除，再展开

长除：商 $2x^{2}+x+1$、余 2？——逐步除：$4x^3\div2x=2x^2$，乘回减去后剩 $2x^2+5x+5$；$2x^2\div2x=x$，剩 $3x+5$；$3x\div2x=\frac32$，余 $\frac12$。即原式 $=2x^{2}+x+\dfrac32+\dfrac{\frac12}{2x+3}$。

积分：$\dfrac{2x^{3}}{3}+\dfrac{x^{2}}{2}+\dfrac{3x}{2}+\dfrac14\ln|2x+3|+C$。

要点：**假分式不拆直接裂项 = 白给**；长除慢就慢工细算，或用"加一项减一项"绕行。

:::

:::

::: tip 算例

例 2（裂项标准版）$\displaystyle\int\dfrac{x+1}{x^{2}-2x-15}dx$。（夏讲 P33）

::: details 先分解、设项、定系数，再展开

分母 $=(x-5)(x+3)$。设 $\dfrac{x+1}{(x-5)(x+3)}=\dfrac{A}{x-5}+\dfrac{B}{x+3}$，通分比对：$x+1=A(x+3)+B(x-5)$。

代 $x=5$：$6=8A$，$A=\dfrac34$；代 $x=-3$：$-2=-8B$，$B=\dfrac14$。

积分 $=\dfrac34\ln|x-5|+\dfrac14\ln|x+3|+C$。

技巧：**代根定系数**比解方程组快；求完代一个特殊值回验。同款：$\dfrac{3x+1}{x^{2}-x-6}=\dfrac{2}{x-3}+\dfrac{1}{x+2}$（练习 12(5)）。

:::

:::

::: tip 算例

例 3（分母不可分解）$\displaystyle\int\dfrac{x+3}{x^{2}+2x+2}dx$。（夏讲 P35–P36）

::: details 先自己拆分子，再展开

分母导数 $2x+2$。把分子写成"$\dfrac12(2x+2)+2$"：

$=\dfrac12\displaystyle\int\dfrac{2x+2}{x^{2}+2x+2}dx+2\int\dfrac{d(x+1)}{(x+1)^{2}+1}=\dfrac12\ln(x^{2}+2x+2)+2\arctan(x+1)+C$。

两段流水线：**凑分母导数段 → $\ln$；常数段 → 配方后 $\arctan$**。同款速查：$\int\dfrac{dx}{x^{2}+2x+2}=\arctan(x+1)+C$、$\int\dfrac{dx}{4x^{2}+4x+5}=\dfrac14\arctan\dfrac{2x+1}{2}+C$。

:::

:::

## 二、三角积分五技巧

| 技巧 | 适用长相 | 动作 |
| --- | --- | --- |
| ① 凑微分 + 降幂 | 幂 × 三角、纯 $\cos^{2}x$ | $\sin x\,dx=-d(\cos x)$；$\sin^{2}x=\dfrac{1-\cos2x}{2}$ 降幂 |
| ② 齐次化（乘共轭） | 分母 $1\pm\sin x$ 型 | 乘 $1\mp\sin x$，用 $\cos^{2}x=1-\sin^{2}x$ 打开 |
| ③ 弦割化切 | 正弦余弦**对称**出现 | 分子分母同除 $\cos^{n}x$，化成 $\tan x$ |
| ④ 一次项重组 | $\dfrac{a\sin x+b\cos x}{c\sin x+d\cos x}$ | 分子 = $A\times$(分母) + $B\times$(分母导数) |
| ⑤ 万能公式 | 以上全失效 | $t=\tan\dfrac x2$ 全部有理化（兜底，计算量大） |

::: tip 算例

例 4（②齐次化）$\displaystyle\int\dfrac{dx}{1-\sin x}$。（夏讲 P53）

::: details 先自己乘共轭，再展开

乘 $\dfrac{1+\sin x}{1+\sin x}$：$=\displaystyle\int\dfrac{1+\sin x}{\cos^{2}x}dx=\int(\sec^{2}x+\sec x\tan x)dx=\tan x+\sec x+C$。

同款：$\int\dfrac{dx}{1+\sin x}=\tan x-\sec x+C$（练习 13(8)）——共轭方向反、结果符号反。

:::

:::

::: tip 算例

例 5（③弦割化切）$\displaystyle\int\dfrac{dx}{\sin x\cos x}$。（夏讲 P54）

::: details 先自己除以 $\cos^2x$，再展开

分子分母同除 $\cos^{2}x$：$=\displaystyle\int\dfrac{\sec^{2}x}{\tan x}dx=\int\dfrac{d(\tan x)}{\tan x}=\ln|\tan x|+C$。

同款：$\int\dfrac{dx}{4\sin^{2}x+\cos^{2}x}=\int\dfrac{\sec^{2}x}{4\tan^{2}x+1}dx=\dfrac12\arctan(2\tan x)+C$。**上下齐除 $\cos^2x$，世界变成 $\tan$ 的**。

:::

:::

::: tip 算例

例 6（④重组）$\displaystyle\int\dfrac{\sin x+8\cos x}{2\sin x+3\cos x}dx$。（夏讲 P55）

::: details 先自己待定系数，再展开

分母导数 $=2\cos x-3\sin x$。设分子 $=A(2\sin x+3\cos x)+B(2\cos x-3\sin x)$，比对系数：$\sin$：$1=2A-3B$；$\cos$：$8=3A+2B$。解得 $A=2$，$B=1$。

$=\displaystyle\int\left[2+\dfrac{2\cos x-3\sin x}{2\sin x+3\cos x}\right]dx=2x+\ln|2\sin x+3\cos x|+C$。

同款：$\int\dfrac{\sin x}{\sin x+\cos x}dx=\dfrac x2-\dfrac12\ln|\sin x+\cos x|+C$（练习 13(10)）。**"分母 + 分母导数"两件套拆分子**。

:::

:::

## 三、复杂函数积分表（10 条，直接引用）

::: warning 高频四条（全表见速查 004）

$\int\dfrac{dx}{a^{2}+x^{2}}=\dfrac1a\arctan\dfrac xa+C$　　$\int\dfrac{dx}{x^{2}-a^{2}}=\dfrac{1}{2a}\ln\left|\dfrac{x-a}{x+a}\right|+C$

$\int\sec x\,dx=\ln|\sec x+\tan x|+C$　　$\int\sqrt{a^{2}-x^{2}}\,dx=\dfrac x2\sqrt{a^{2}-x^{2}}+\dfrac{a^{2}}{2}\arcsin\dfrac xa+C$

警示：$\int\dfrac{dx}{x^{2}-a^{2}}$ 与 $\int\dfrac{dx}{a^{2}-x^{2}}=\dfrac{1}{2a}\ln\left|\dfrac{a+x}{a-x}\right|+C$ **分子分母互为倒序**，别混。9、10 号（$e^{ax}\sin bx$ 型）就是 0029 循环型的现成答案。

:::

**随堂测 1：$\displaystyle\int\dfrac{x^{2}}{x^{2}+1}dx=$（夏讲 P27）**

- A. $\ln(x^{2}+1)+C$
- B. $x-\arctan x+C$
- C. $x+\arctan x+C$
- D. $1-\arctan x+C$

::: details 点开核对答案

**答案：B（$x-\arctan x+C$）** —— 假分式（分子分母同次）：$\dfrac{x^{2}}{x^{2}+1}=1-\dfrac{1}{x^{2}+1}$（加一项减一项），积分 $x-\arctan x+C$。A 是 $\frac{x}{x^2+1}$ 的答案——那是"凑分母导数"型，先辨型！

:::

**随堂测 2：$\displaystyle\int\dfrac{2x+1}{x^{2}+3x+2}dx=$（秋讲练习 12(4)）**

- A. $2\ln|x+1|+\ln|x+2|+C$
- B. $-\ln|x+1|+3\ln|x+2|+C$
- C. $-\ln|x+1|+3\ln|x+2|+C$ 与 $2\ln|x+2|-\ln|x+1|+C$ 之外的另一答案
- D. $\ln(x^{2}+3x+2)+C$

::: details 点开核对答案

**答案：C（$-\ln|x+1|+3\ln|x+2|+C$ 与 $2\ln|x+2|-\ln|x+1|+C$ 之外的另一答案）** —— 分母 $=(x+1)(x+2)$，分子 $=-(x+2)+3(x+1)$，裂项 $\dfrac{-1}{x+1}+\dfrac{3}{x+2}$，答案 $-\ln|x+1|+3\ln|x+2|+C$。D 是"分子 = 分母导数"的形状——这里分子是 $2x+1$ 而导数是 $2x+3$，差一点就换招。B 与 C 重复是干扰：真正答案只有一个，B、C 同式（认真算到底，别被选项唬住）。

:::

**随堂测 3：$\displaystyle\int\dfrac{dx}{4x^{2}+4x+5}=$（秋讲练习 12(10)）**

- A. $\dfrac14\arctan\dfrac{2x+1}{2}+C$
- B. $\arctan(2x+1)+C$
- C. $\dfrac12\arctan\dfrac{2x+1}{2}+C$
- D. $2\arctan\dfrac{2x+1}{2}+C$

::: details 点开核对答案

**答案：A（$\dfrac14\arctan\dfrac{2x+1}{2}+C$）** —— 配方：$4x^{2}+4x+5=(2x+1)^{2}+4$，$dx=\frac12d(2x+1)$：$\dfrac12\int\dfrac{d(2x+1)}{(2x+1)^{2}+2^{2}}=\dfrac12\cdot\dfrac12\arctan\dfrac{2x+1}{2}$。系数 $\frac14$ 是"换元 $\frac12$ × 公式 $\frac1a=\frac12$"的乘积，两层都别丢。

:::

**随堂测 4：$\displaystyle\int\cos^{2}x\,dx=$**

- A. $\dfrac{\sin^{3}x}{3\cos x}+C$
- B. $2\sin x\cos x+C$
- C. $x-\dfrac{\sin2x}{2}+C$
- D. $\dfrac x2+\dfrac{\sin2x}{4}+C$

::: details 点开核对答案

**答案：D（$\dfrac x2+\dfrac{\sin2x}{4}+C$）** —— 降幂：$\cos^{2}x=\dfrac{1+\cos2x}{2}$，积分 $=\dfrac x2+\dfrac{\sin2x}{4}+C$。C 是 $\sin^2x$ 的答案——$1-\cos2x$ 与 $1+\cos2x$ 一字之差，结果差一个符号。&lt;strong&gt;降幂公式两兄弟成对记&lt;/strong&gt;。

:::

**随堂测 5：$\displaystyle\int\dfrac{dx}{1+\sin x}=$（秋讲练习 13(8)）**

- A. $\tan x+\sec x+C$
- B. $\tan x-\sec x+C$
- C. $\ln|1+\sin x|+C$
- D. $-\cot x+\csc x+C$

::: details 点开核对答案

**答案：B（$\tan x-\sec x+C$）** —— 乘共轭 $\dfrac{1-\sin x}{1-\sin x}$：$=\displaystyle\int\dfrac{1-\sin x}{\cos^{2}x}dx=\tan x-\sec x+C$。A 是 $\frac{1}{1-\sin x}$ 的答案——共轭方向对应符号方向。C 又是"万能型"误判：分子 1 不是分母导数 $\cos x$。

:::

::: danger 本课易错清单

- 分式先辨型：**假分式必先长除**；分母可分解走裂项、不可分解走"凑导数 + $\arctan$"
- 裂项用"代根定系数"，求完**代值回验**
- $\int\frac{dx}{x^{2}-a^{2}}$ 与 $\int\frac{dx}{a^{2}-x^{2}}$ **ln 里分子分母倒序**
- 三角降幂两公式成对用；$\int\cos^2$ 与 $\int\sin^2$ 差一个符号
- 弦割化切的前提：$\sin$、$\cos$ **整体对称**出现
- 万能公式是兜底：算完**必须回代 $t=\tan\frac x2$**

:::

**回忆卡：默写分式积分四策略（按判型顺序）。**

::: details 先回忆，再揭晓

假分式 → 长除；真分式分母可分解 → 裂项；不可分解、分子含变量 → 凑分母导数；分子是常数 → 配方凑 $\arctan$。

:::

**回忆卡：报出三角积分五技巧，并默写降幂公式两条。**

::: details 先回忆，再揭晓

凑微分降幂 / 齐次化乘共轭 / 弦割化切 / 一次项重组 / 万能公式。$\sin^{2}x=\frac{1-\cos2x}{2}$，$\cos^{2}x=\frac{1+\cos2x}{2}$。
