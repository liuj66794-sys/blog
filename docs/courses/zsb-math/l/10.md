## 一、六种极限过程与两大充要条件

| 过程 | 含义 | 记法 |
| --- | --- | --- |
| $x\to+\infty$ / $x\to-\infty$ | 沿正 / 负方向无限远离原点 | $\lim\limits_{x\to\pm\infty}f(x)=a$ |
| $x\to\infty$ | $\|x\|\to+\infty$（两侧一起） | $\lim\limits_{x\to\infty}f(x)=a$ |
| $x\to x_0^-$ / $x\to x_0^+$ | 从 $x_0$ 左 / 右侧接近（左 / 右极限） | $\lim\limits_{x\to x_0^\pm}f(x)=a$ |
| $x\to x_0$ | 在 $x_0$ 的**去心邻域**内接近 | $\lim\limits_{x\to x_0}f(x)=a$ |

::: warning 必背：两大充要条件

$$\lim_{x\to\infty}f(x)=a\iff\lim_{x\to-\infty}f(x)=\lim_{x\to+\infty}f(x)=a$$

$$\lim_{x\to x_0}f(x)=a\iff\lim_{x\to x_0^-}f(x)=\lim_{x\to x_0^+}f(x)=a$$

一句话：**整体极限存在 ⟺ 两侧都存在且相等**。极限存在叫**收敛**，不存在叫**发散**——发散分两种：**无穷**与**振荡**。

:::

注意"$x\to x_0$"关心的是 $x_0$ **附近**的行为，与 $f(x_0)$ 处有没有定义、等于几**完全无关**（去心邻域的含义）。这个观念后面"可去间断点"全靠它。

## 二、必背走向表：这些极限要形成条件反射

| 极限 | 结果 | 理由 |
| --- | --- | --- |
| $\lim\limits_{x\to+\infty}\dfrac1x$ 与 $\lim\limits_{x\to\infty}\dfrac1x$ | $0$、$0$ | 倒数趋势，两侧同为 0 |
| $\lim\limits_{x\to-\infty}e^{x}$ | $0$ | 图象左端贴死 $x$ 轴 |
| $\lim\limits_{x\to+\infty}e^{x}$ | $+\infty$（发散·无穷） | 指数爆炸 |
| **$\lim\limits_{x\to\infty}e^{x}$** | **不存在** | 左 $\to0$、右 $\to+\infty$，两侧不等 |
| $\lim\limits_{x\to-\infty}\arctan x$ / $+\infty$ 方向 | $-\dfrac{\pi}{2}$ / $\dfrac{\pi}{2}$ | 两条水平渐近线 |
| **$\lim\limits_{x\to\infty}\arctan x$** | **不存在** | $-\frac{\pi}{2}\neq\frac{\pi}{2}$ |
| $\lim\limits_{x\to+\infty}\sin x$ | **不存在**（发散·振荡） | 永远在 $[-1,1]$ 里晃 |
| $\lim\limits_{x\to-\infty}\dfrac{\|x\|}{x}$ | $-1$ | $x<0$ 时 $\|x\|=-x$ |

## 三、必须分左右极限的两类情形（高频考点）

::: warning 见到就拆左右

① **分段函数的分段点**：左、右各代所在段的表达式，算完再比较；

② **$e^{1/x}$ 与 $\arctan\dfrac1x$ 在 $x\to0$**：因为 $\dfrac1x$ 在 $0$ 两侧分别 $\to\mp\infty$，而 $e^u$、$\arctan u$ 的两侧行为天差地别。

:::

::: tip 算例

例 1（分段点）$f(x)=\begin{cases}3x+2 & x\le0\\ x^2+1 & 0<x\le1\\ \dfrac2x & x>1\end{cases}$，讨论 $x\to0$ 与 $x\to1$ 处的极限。（秋讲练习 1）

::: details 先左右各算一次，再展开

**$x\to0$**：左 $=3(0)+2=2$，右 $=0^2+1=1$，$2\neq1$ ⇒ 极限**不存在**。

**$x\to1$**：左 $=1^2+1=2$，右 $=\dfrac21=2$，相等 ⇒ $\lim\limits_{x\to1}f(x)=2$。

口诀：**分段点处，左算一次右算一次，相等才存在**。

:::

:::

::: tip 算例

例 2（$e^{1/x}$ 型）求 $\lim\limits_{x\to0}\dfrac{e^{1/x}-1}{e^{1/x}+2}$。（秋讲练习 2）

::: details 先分左右，再展开

**$x\to0^-$**：$\dfrac1x\to-\infty$，$e^{1/x}\to0$，极限 $=\dfrac{0-1}{0+2}=-\dfrac12$。

**$x\to0^+$**：$\dfrac1x\to+\infty$，$e^{1/x}\to+\infty$，分子分母同除 $e^{1/x}$：$\dfrac{1-e^{-1/x}}{1+2e^{-1/x}}\to\dfrac{1-0}{1+0}=1$。

左右不等 ⇒ $x\to0$ 时极限**不存在**（但单侧极限都算得出来——考试常只要单侧）。

:::

:::

**随堂测 1："$\lim\limits_{x\to x_0}f(x)=a$"成立的充要条件是**

- A. $f(x_0)=a$
- B. $f(x)$ 在 $x_0$ 处有定义
- C. 左右极限都存在且都等于 $a$
- D. $f(x)$ 在 $x_0$ 处连续

::: details 点开核对答案

**答案：C（左右极限都存在且都等于 $a$）** —— 左 $=$ 右 $=a$ 才行。A、B 混进了"该点的值"——极限用&lt;strong&gt;去心&lt;/strong&gt;邻域，与 $f(x_0)$ 无关（后面可去间断点就靠这一点）；D 的条件比"极限存在"强得多。

:::

**随堂测 2：$\lim\limits_{x\to\infty}e^{x}$ 的结论是**

- A. 等于 $0$
- B. 等于 $+\infty$
- C. 等于 $1$
- D. 不存在

::: details 点开核对答案

**答案：D（不存在）** —— $x\to-\infty$ 时 $e^x\to0$，$x\to+\infty$ 时 $e^x\to+\infty$，两侧不等 ⇒ 不存在。单侧看答案分别是 A 和 B——"两侧一起问"的题必须先想充要条件。

:::

**随堂测 3：$\lim\limits_{x\to0}\dfrac{\sin x}{|x|}$ 等于**

- A. $1$
- B. 不存在
- C. $-1$
- D. $0$

::: details 点开核对答案

**答案：B（不存在）** —— $|x|$ 逼你分左右：右侧 $\dfrac{\sin x}{x}\to1$，左侧 $\dfrac{\sin x}{-x}\to-1$（秋讲练习 4），$1\neq-1$ ⇒ 不存在。看到 $|x|$、$e^{1/x}$、$\arctan\frac1x$、分段点——四类信号，先拆左右。

:::

**随堂测 4：$\lim\limits_{x\to2^-}[x]$（取整函数）等于**

- A. $1$
- B. $2$
- C. $0$
- D. 不存在

::: details 点开核对答案

**答案：A（$1$）** —— $x\to2^-$ 时 $x\in[1,2)$，不超过 $x$ 的最大整数是 $1$。（夏讲教材 P28 原题；取整函数图像是台阶，每级左闭右开，所以左极限踩在下一级上。）

:::

::: danger 本课易错清单

- 极限存在与 $f(x_0)$ **无关**：$\lim\limits_{x\to2}\dfrac{x^2-4}{x-2}=4$，哪怕函数在 $x=2$ 根本没定义
- $x\to\infty$ 的题先自问：**两侧走向一样吗**？（$e^x$、$\arctan x$、$2^x$、$\frac{|x|}{x}$ 都不一样）
- 发散两种：无穷（如 $\lim\limits_{x\to+\infty}e^x$）≠ 振荡（如 $\lim\limits_{x\to+\infty}\sin x$），但都"不存在"
- 分段点求极限只看左右两侧，**不用管分段点上的函数值**

:::

**回忆卡：默写两大充要条件（$x\to\infty$ 与 $x\to x_0$ 两式），并说出"发散"的两种方式。**

::: details 先回忆，再揭晓

整体存在 ⟺ 两侧存在且相等（$\lim_{x\to\infty}$：$-\infty$ 侧 $=$ $+\infty$ 侧；$\lim_{x\to x_0}$：左 $=$ 右）。发散分：无穷、振荡。

:::

**回忆卡：秒答：$\lim\limits_{x\to\infty}e^x$、$\lim\limits_{x\to-\infty}e^x$、$\lim\limits_{x\to\infty}\arctan x$、$\lim\limits_{x\to0}e^{1/x}$（分左右）。**

::: details 先回忆，再揭晓

不存在；$0$；不存在（左右 $=\pm\frac{\pi}{2}$）；$x\to0^-$ 时 $\to0$、$x\to0^+$ 时 $\to+\infty$，整体不存在。

:::
