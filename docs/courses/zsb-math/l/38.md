二重积分 = 定积分的"平面版"：定义同为分割–求和–取极限，计算则"**化两层定积分**"。本章考试重心极其固定：**画区域**。图一画对，题就做对了一大半。

## 一、定义与几何意义

::: warning 概念三句话

$\displaystyle\iint_D f\,d\sigma$ 是一个**数**；$f\ge0$ 时是**曲顶柱体体积**；特别地 $\displaystyle\iint_D 1\,d\sigma=S_D$（区域的面积）、$\displaystyle\iint_D k\,d\sigma=kS_D$。

线性、可加、保序、中值定理与定积分性质平行（0031 课的平面版）。

:::

## 二、直角坐标：X 型与 Y 型

::: warning 化累次积分

**X 型**（竖条扫描）：$a\le x\le b$，$\varphi_1(x)\le y\le\varphi_2(x)$

$$\iint_D f\,d\sigma=\int_a^{b}dx\int_{\varphi_1(x)}^{\varphi_2(x)}f(x,y)\,dy$$

**Y 型**（横条扫描）：$c\le y\le d$，$\psi_1(y)\le x\le\psi_2(y)$，先对 $x$ 积分。

内层限可以是外层变量的函数；外层限必须是常数。

:::

::: tip 算例

例 1（X 型标准件）$D$ 由 $y=x$、$y=0$、$x=1$ 围成，求 $\displaystyle\iint_D xy\,d\sigma$。

::: details 先自己画图定限，再展开（冲刺练习 2 同族）

X 型：$0\le x\le1$，$0\le y\le x$：

$\displaystyle\int_0^1x\,dx\int_0^{x}y\,dy=\int_0^1x\cdot\frac{x^{2}}{2}dx=\frac12\cdot\frac14=\frac18$。

流程：**画图 → 竖条上下沿 → 先积 $y$（把 $x$ 当常数）→ 再积 $x$**。

:::

:::

::: tip 算例

例 2（对称性秒杀）$D$ 为 $x^{2}+y^{2}\le1$，求 $\displaystyle\iint_D x^{2}y^{2}\,d\sigma$ 的化简思路。

::: details 先看对称，再展开（冲刺练习 9）

$D$ 关于两轴、对角线都对称，$x^{2}y^{2}$ 恒非负：取第一象限的四分之一，乘 4：

$\displaystyle\iint_D x^{2}y^{2}\,d\sigma=4\int_0^1dx\int_0^{1-x}x^{2}y^{2}dy=\frac43\int_0^1x^{2}(1-x)^{3}dx=\frac1{45}$。

对称性规则（对照 0031 性质 6）：$D$ 关于 $y$ 轴对称时，被积函数对 $x$ 为**奇 ⇒ 0**、**偶 ⇒ 半域 × 2**；对原点、$y=x$ 对称各有版本。**先看对称再硬算**，常省一半工。

:::

:::

## 三、极坐标：圆域杀手

::: warning 换元三件套与必带因子

$x=r\cos\theta$，$y=r\sin\theta$，且**面积元必须乘 $r$**：

$$\iint_D f\,d\sigma=\int_{\alpha}^{\beta}d\theta\int_{r_1(\theta)}^{r_{2}(\theta)}f(r\cos\theta,\,r\sin\theta)\,\boldsymbol{r}\,dr$$

信号：区域是**圆 / 圆环 / 扇形**，或被积函数含 $x^{2}+y^{2}$（换成 $r^{2}$）。圆心在原点半径 $R$：$0\le\theta\le2\pi$，$0\le r\le R$。

:::

::: tip 算例

例 3（极坐标标准件）$D:x^{2}+y^{2}\le4$，求 $\displaystyle\iint_D(x^{2}+y^{2})\,d\sigma$。

::: details 先自己换极坐标，再展开（冲刺练习 3 同族）

$=\displaystyle\int_0^{2\pi}d\theta\int_0^{2}r^{2}\cdot r\,dr=2\pi\cdot\frac{r^{4}}{4}\Big|_0^2=2\pi\cdot4=8\pi$。

别忘那个 $r$：$\int r^{3}dr=\frac{r^{4}}4$ 里的三次方，来自"被积 $r^2$ + 面积元 $r$"。**漏 $r$ 是本章第一大错误**。

:::

:::

## 四、交换积分次序

::: warning 可靠三步

① 由给定限**写出区域不等式并画图**；② 换扫描方向（X ↔ Y）重新描述区域；③ 必要时**分段**。口诀：**先还原区域，再重新描述**——只把 $dx\,dy$ 换个位置 = 白改。

:::

::: tip 算例

例 4交换 $\displaystyle\int_0^{1}dx\int_x^{1}f(x,y)\,dy$ 的次序。（冲刺练习 12(1)）

::: details 先自己画图，再展开

区域：$0\le x\le1$，$x\le y\le1$——即直线 $y=x$ 上方的三角形。

换横条：$0\le y\le1$，$0\le x\le y$ ⇒ $\displaystyle\int_0^{1}dy\int_0^{y}f(x,y)\,dx$。

动机预告：有时"先 $y$ 后 $x$"积不动（如出现 $e^{y^{2}}$、$\frac{\sin y}{y}$ 原函数积不出），交换次序后立刻可积——**交换次序是解题手段，不是题目刁难**。

:::

:::

**随堂测 1：$\displaystyle\iint_D d\sigma$（$D$：$0\le x\le1$，$0\le y\le2$）等于**

- A. $1$
- B. $2$
- C. $4$
- D. $0$

::: details 点开核对答案

**答案：B（$2$）** —— 被积函数为 1 时二重积分 = 区域面积 $=1\times2=2$。这是"先量形状再积分"的免费捷径，判断题、填空题常客。

:::

**随堂测 2：$D$ 关于 $y$ 轴对称，被积函数关于 $x$ 为奇函数，则积分值**

- A. $=0$
- B. = 半区域积分的 2 倍
- C. 无法确定
- D. = 半区域积分

::: details 点开核对答案

**答案：A（$=0$）** —— 左右两半正负抵消（0031 奇偶性质的平面版）。B 是"偶函数"的待遇——先判奇偶再动手，能省整段计算。

:::

**随堂测 3：极坐标下 $\displaystyle\iint_D(x^{2}+y^{2})\,d\sigma$（$D:x^{2}+y^{2}\le1$）的被积式是**

- A. $\displaystyle\int_0^{2\pi}d\theta\int_0^{1}r^{2}\,dr$
- B. $\displaystyle\int_0^{2\pi}d\theta\int_0^{1}r^{4}\,dr$
- C. $\displaystyle\int_0^{2\pi}d\theta\int_0^{1}r^{3}\,dr$
- D. $\displaystyle\int_0^{2\pi}d\theta\int_0^{1}r\,dr$

::: details 点开核对答案

**答案：C（$\displaystyle\int_0^{2\pi}d\theta\int_0^{1}r^{3}\,dr$）** —— 被积函数 $r^{2}$ + 面积元 $r$ = $r^{3}$，积分 $2\pi\cdot\frac14=\frac\pi2$。A 漏面积元；C 的被积式正确（积出 $\frac\pi2$ ✓）——审题：问的是"被积式"，$r^{2}\cdot r=r^{3}$。

:::

**随堂测 4：下列信号中，最应该考虑换极坐标的是**

- A. 区域是矩形 $[0,1]\times[0,2]$
- B. 被积函数是 $x+y$，区域是三角形
- C. 被积函数是 $xy$，区域是正方形
- D. 区域是圆环 $1\le x^{2}+y^{2}\le4$，被积函数含 $x^{2}+y^{2}$

::: details 点开核对答案

**答案：D（区域是圆环 $1\le x^{2}+y^{2}\le4$，被积函数含 $x^{2}+y^{2}$）** —— 极坐标的双信号：&lt;strong&gt;圆 / 圆环 / 扇形区域&lt;/strong&gt; + &lt;strong&gt;$x^{2}+y^{2}$ 结构&lt;/strong&gt;。矩形、三角形在直角坐标里限更好写——换极坐标反而自找麻烦。

:::

**随堂测 5：交换 $\displaystyle\int_0^{1}dy\int_y^{1}f(x,y)\,dx$ 的次序，结果是**

- A. $\displaystyle\int_0^{1}dx\int_0^{x}f(x,y)\,dy$
- B. $\displaystyle\int_0^{1}dx\int_x^{1}f(x,y)\,dy$（原样对调符号）
- C. $\displaystyle\int_0^{1}dx\int_1^{x}f(x,y)\,dy$
- D. $\displaystyle\int_0^{1}dx\int_0^{1}f(x,y)\,dy$

::: details 点开核对答案

**答案：A（$\displaystyle\int_0^{1}dx\int_0^{x}f(x,y)\,dy$）** —— 原区域：$0\le y\le1$，$y\le x\le1$（$y=x$ 下方三角形）。换竖条：$0\le x\le1$，$0\le y\le x$。B 只是换了字母位置——&lt;strong&gt;交换次序必须重新描述区域&lt;/strong&gt;，画图是唯一可靠路径。

:::

::: danger 本课易错清单

- 极坐标**必乘 $r$**：$d\sigma=r\,dr\,d\theta$——本章第一大失分点
- 外层限必须常数、内层限可以是函数；累次积分**由内向外**算
- 交换次序先**画图还原区域**，再重新描述（必要时分段），不是换符号
- 对称性使用前提：**区域对称 + 被积函数相应奇偶**，两者缺一不可
- 内层积不动（$e^{y^2}$、$\frac{\sin y}{y}$）是"该换次序"的信号

:::

**回忆卡：默写 X 型区域的二重积分化累次公式，并写出极坐标面积元。**

::: details 先回忆，再揭晓

$\displaystyle\iint_D f\,d\sigma=\int_a^bdx\int_{\varphi_1(x)}^{\varphi_2(x)}f\,dy$；$d\sigma=r\,dr\,d\theta$。

:::

**回忆卡：对称性四条规则各一句话：$D$ 关于 $y$ 轴对称（对 $x$ 奇/偶）？关于原点？关于 $y=x$？**

::: details 先回忆，再揭晓

对 $x$ 奇 → 0，偶 → 半域×2；原点对称且 $f(-x,-y)=-f$ → 0；$y=x$ 对称可交换 $x,y$（$\iint f(x,y)=\iint f(y,x)$）。

:::
