## 一、无穷小与无穷大：一对倒数

::: warning 定义与关系

**无穷小**：以 0 为极限的**变量**（$x\to\infty$ 时 $\frac1x$；$x\to-\infty$ 时 $e^x$）。**无穷大**：以 $\infty$ 为极限的变量。两者互为倒数（无穷小不取零值时）。

辨析：无穷小 ≠ 很小的常数；$0$ 是唯一的常量无穷小。

:::

::: warning 四条性质（第四条是求极限利器）

有限个无穷小的**和**、**积**仍是无穷小；常数 × 无穷小仍是无穷小；**有界函数 × 无穷小仍是无穷小**。

代表作：$\lim\limits_{x\to\infty}\dfrac{\sin x}{x}=0$（$\sin x$ 有界、$\frac1x$ 无穷小）；$\lim\limits_{x\to1}\cos\dfrac{1}{x-1}\cdot\ln x=0$（$\ln x\to0$，余弦有界）。

:::

## 二、阶的比较：一张表 + 一个方向警示

| 设 $\alpha,\beta$ 是同过程无穷小，$\lim\dfrac{\alpha}{\beta}=$ | 结论 | 记号 |
| --- | --- | --- |
| $0$ | $\alpha$ 是 $\beta$ 的**高阶**无穷小 | $\alpha=o(\beta)$ |
| $\infty$ | $\alpha$ 是 $\beta$ 的**低阶**无穷小 | — |
| $C\neq0$ | **同阶**无穷小 | — |
| $1$ | **等价**无穷小 | $\alpha\sim\beta$ |
| $f$ 与 $x^{k}$ 同阶 | $f$ 是 $k$ **阶**无穷小 | — |

::: danger 方向相反的两个"只看一项"

两个**多项式比阶**（$x\to0$）：只看**幂次最低**的项——$x\to0$ 时 $x^2-x^3\sim x^2$。而**抓大头**（$x\to\infty$）看**最高次**。两个"只看一项"方向相反，先看趋向再选武器！

例（夏讲 P35）：$x\to0$ 时 $x^2-x^3$ 与 $2x-x^2$ 相比，$\lim\dfrac{x^2-x^3}{2x-x^2}=\lim\dfrac{x(1-x)}{2-x}=0$，故 $x^2-x^3$ 是**高阶**。

:::

**随堂测 1：当 $x\to0$ 时，比 $x$ 高阶的无穷小是（夏讲选择题）**

- A. $\sqrt[3]{x}$
- B. $1-\cos x$
- C. $e^{x}-1$
- D. $\ln\left(1+\dfrac12x\right)$

::: details 点开核对答案

**答案：B（$1-\cos x$）** —— $1-\cos x\sim\frac12x^2$ 是二阶，比 $x$ 高阶 ✓。A 是 $\frac13$ 阶（低阶）；C、D 都 $\sim x$（同阶）。各选项往等价表里一放，秒出。

:::

**随堂测 2：当 $x\to0$ 时，下列无穷小中阶数最高的是（秋讲练习 22）**

- A. $1-\cos 2x$
- B. $x-\sin 2x$
- C. $2x+x^{3}$
- D. $\sqrt{1+x}-\sqrt{1-x}$

::: details 点开核对答案

**答案：A（$1-\cos 2x$）** —— A：$1-\cos2x\sim\frac12(2x)^2=2x^2$（二阶）；B：$x-2\sin x\sim-x$（一阶）；C 一阶；D：乘共轭 $\sim\dfrac{2x}{2}=x$（一阶）。最高阶 = A。方法：每项报阶数，取最大。

:::

## 三、三类渐近线：曲线的"边界"

| 类型 | 定义 | 求法 |
| --- | --- | --- |
| 水平 $y=A$ | $\lim\limits_{x\to\pm\infty}f(x)=A$ | $x\to+\infty$ 与 $-\infty$ **分别看**，最多两条 |
| 垂直 $x=x_0$ | $\lim\limits_{x\to x_0^{\pm}}f(x)=\infty$ | 在**无定义点**逐个查单侧极限；约分约掉的点只是可去间断点，**不是**渐近线 |
| 斜 $y=kx+b$ | $k=\lim\limits_{x\to\pm\infty}\dfrac{f(x)}{x}\neq0$，$b=\lim[f(x)-kx]$ | $\pm\infty$ 各可有一条；$x\to-\infty$ 时 $\dfrac{\sqrt{x^2}}{x}=-1$ |

::: tip 算例

例 1（斜渐近线全流程）求 $y=\sqrt{x^{2}+x+1}$ 的斜渐近线。

::: details 先自己算 $k,b$，再展开（夏讲教材 P37）

**$x\to+\infty$**：$k=\lim\dfrac{f(x)}{x}=1$；$b=\lim\left(\sqrt{x^2+x+1}-x\right)=\lim\dfrac{x+1}{\sqrt{x^2+x+1}+x}=\dfrac12$ ⇒ $y=x+\dfrac12$。

**$x\to-\infty$**：$k=\lim\dfrac{\sqrt{x^2+x+1}}{x}=-1$（$\sqrt{x^2}=-x$！）；$b=\lim\left(\sqrt{x^2+x+1}+x\right)=\lim\dfrac{x+1}{\sqrt{x^2+x+1}-x}=-1$ ⇒ $y=-x-1$。

两条都要算——右渐近线不能想当然推广到左边。

:::

:::

::: tip 算例

例 2（逆求 $a,b$）已知 $\lim\limits_{x\to\infty}\left(\dfrac{x^{2}+3}{x-1}-ax-b\right)=0$，求 $a,b$。

::: details 先自己带除，再展开（夏讲教材 P38）

带除法：$\dfrac{x^2+3}{x-1}=x+1+\dfrac{4}{x-1}$，代回：$(1-a)x+(1-b)+\dfrac{4}{x-1}\to0$。

逐层归零：$1-a=0$，$1-b=0$ ⇒ $a=1,\ b=1$。本质：**$\frac{x^2+3}{x-1}$ 的斜渐近线就是 $y=x+1$，$a,b$ 就是渐近线的斜率与截距**。

:::

:::

**随堂测 3：曲线 $y=\dfrac{3x+1}{2x-1}$ 的水平渐近线是（秋讲练习 25(1)）**

- A. $y=1$
- B. $y=\dfrac{2}{3}$
- C. $y=\dfrac{3}{2}$
- D. $x=\dfrac{1}{2}$

::: details 点开核对答案

**答案：C（$y=\dfrac{3}{2}$）** —— $\lim\limits_{x\to\infty}$ 抓大头：同次比系数 $\dfrac32$，即 $y=\dfrac32$。（D 是垂直渐近线——题目问的水平，看清问什么。）

:::

**随堂测 4：曲线 $y=\dfrac{x^{2}-4x+3}{x^{2}+x-2}$ 的渐近线情况是（秋讲练习 26(3)）**

- A. 仅垂直渐近线 $x=-2$；$x=1$ 处极限存在，不是渐近线
- B. 垂直渐近线 $x=-2$ 与 $x=1$
- C. 没有渐近线
- D. 仅有水平渐近线

::: details 点开核对答案

**答案：A（仅垂直渐近线 $x=-2$；$x=1$ 处极限存在，不是渐近线）** —— 因式分解 $\dfrac{(x-1)(x-3)}{(x+2)(x-1)}$：$x=-2$ 处分母 $\to0$ ⇒ 垂直渐近线；$x=1$ 被约分&lt;strong&gt;约掉了&lt;/strong&gt;，极限 $=\dfrac{1-3}{1+2}=-\dfrac23$ 存在——只是可去间断点，不是渐近线。另有水平渐近线 $y=1$，但 A 对"垂直渐近线部分"的描述是本课考点。

:::

**随堂测 5：$y=\dfrac{2^{x}}{1+2^{x}}$ 的水平渐近线共有（秋讲练习 25(4)）**

- A. 0 条
- B. 1 条
- C. 3 条
- D. 2 条

::: details 点开核对答案

**答案：D（2 条）** —— $x\to+\infty$：分子吃掉分母，$\to1$；$x\to-\infty$：$2^x\to0$，$\to0$。两条水平渐近线 $y=1$、$y=0$——"分别看两侧"的典型回报。

:::

::: danger 本课易错清单

- 比阶看最低次、抓大头看最高次——先圈趋向再动笔
- 有界 × 无穷小 = 0：$\dfrac{\sin x}{x}$（$x\to\infty$）、$\dfrac{\arctan x}{x}$（$x\to\infty$）都是 0
- 垂直渐近线只认"单侧极限为 $\infty$"的点；约分约掉的点是可去间断点
- 水平渐近线两侧各看，最多 2 条（$\arctan$、$\frac{2^x}{1+2^x}$ 型）
- $x\to-\infty$ 求 $k$：$\dfrac{\sqrt{x^2+\cdots}}{x}=-1$

:::

**回忆卡：默写阶比较五分类（$\lim\frac{\alpha}{\beta}$ 的五种取值对应什么），并说出"两个只看一项"的方向。**

::: details 先回忆，再揭晓

$0$ 高阶 $o(\beta)$；$\infty$ 低阶；$C\neq0$ 同阶；$1$ 等价 $\sim$；与 $x^k$ 同阶即 $k$ 阶。抓大头看最高次，比阶（$x\to0$）看最低次。

:::

**回忆卡：三类渐近线的定义式各是什么？各最多几条？垂直渐近线去哪里找？**

::: details 先回忆，再揭晓

水平 $\lim_{x\to\pm\infty}f=A$（≤2 条）；垂直 $\lim_{x\to x_0^\pm}f=\infty$（找无定义点）；斜 $k=\lim\frac f x\neq0$、$b=\lim(f-kx)$（$\pm\infty$ 各一条）。

:::
