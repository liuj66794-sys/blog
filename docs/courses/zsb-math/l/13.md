# 等价无穷小替换

等价替换是求极限的"快刀"：把复杂的无穷小换成最简单的 $x$ 的幂，$\frac00$ 型瞬间变四则运算。它是选择题与计算题的核心手法，也是**错得最集中**的地方——军规先立好。

## 一、基础八条（$x\to0$，必背）

::: warning 基础八条（方框替换后仍然成立）

$$\sin x\sim x,\qquad \tan x\sim x,\qquad \arcsin x\sim x,\qquad \arctan x\sim x$$

$$e^{x}-1\sim x,\qquad \ln(1+x)\sim x,\qquad 1-\cos x\sim\frac12x^{2},\qquad (1+x)^{\alpha}-1\sim\alpha x$$

前四条是 0012 重要极限一的化身；后四条请各自配套记忆：指数、对数、"幂减一"都是一阶，余弦补角是二阶。

:::

::: tip 算例

例 1（方框替换）求 $\lim\limits_{x\to0}\dfrac{\ln(1+2x)}{x}$ 与 $\lim\limits_{x\to0}\dfrac{(1+x)^{n}-1}{x}$。

::: details 先自己换，再展开（秋讲练习 12(3)(4)）

$\ln(1+2x)\sim2x$（方框是 $2x$），故极限 $=2$。

$(1+x)^n-1\sim nx$（第八条 $\alpha=n$），故极限 $=n$。同法 $\dfrac{e^x-1}{x}\to1$、$\dfrac{\arcsin x}{x}\to1$。

:::

:::

## 二、进阶六条：三阶差关系（加减题的钥匙）

::: warning 进阶六条（比基础条高两个数量级，必背）

$$\tan x-x\sim\frac13x^{3},\qquad x-\sin x\sim\frac16x^{3},\qquad \tan x-\sin x\sim\frac12x^{3}$$

$$x-\arctan x\sim\frac13x^{3},\qquad \arcsin x-x\sim\frac16x^{3},\qquad x-\ln(1+x)\sim\frac12x^{2}$$

记忆：六个都是"$f(x)-x$"或"$x-f(x)$"的差，一阶项抵掉后暴露出更高阶的主部。

:::

::: tip 算例

例 2（三阶差的典型战场）求 $\lim\limits_{x\to0}\dfrac{\tan x-\sin x}{x^{3}}$ 与 $\lim\limits_{x\to0}\dfrac{\tan x-x}{x^{2}\sin x}$。

::: details 先自己算，再展开（秋讲练习 12(6)）

$\tan x-\sin x=\tan x(1-\cos x)\sim x\cdot\dfrac12x^2=\dfrac12x^3$（用乘法自己合成，正好等于进阶第三条），故第一题 $=\dfrac12$。

第二题：分子 $\tan x-x\sim\dfrac13x^3$，分母 $x^2\sin x\sim x^3$，答案 $\dfrac13$。

:::

:::

## 三、军规：哪里能换、哪里不能换

::: warning 唯一军规

**乘除因子：可以整体替换。**加减运算：**不能随意替换**——两个一阶项相减可能暴露高阶主部，你把每个都换成 $x$ 就把主部抹没了（$x-x=0$ 的假象）。

正确姿势：加减结构优先套**进阶六条**的整体结论，或先恒等变形（提取公因式、乘共轭）化成乘除再换。

:::

::: tip 算例

例 3（变形后再替换）求 $\lim\limits_{x\to0}\dfrac{\ln\cos x}{x^{2}}$。

::: details 先自己找方框，再展开（夏讲教材 P35）

$\ln$ 的真数不是 $1+x$ 的样子？其实是：$\ln\cos x=\ln\left[1+(\cos x-1)\right]$，方框是 $\cos x-1\to0$ ✓。用第七条：$\ln[1+(\cos x-1)]\sim\cos x-1\sim-\dfrac12x^2$。

所以极限 $=\lim\limits_{x\to0}\dfrac{-\frac12x^2}{x^2}=-\dfrac12$。**"凑方框"是等价替换的灵魂技巧**。

:::

:::

::: tip 算例

例 4（乘除混合 + 提常数）求 $\lim\limits_{x\to0}\dfrac{e-e^{\cos x}}{\sqrt[3]{1+x^{2}}-1}$。

::: details 先自己变形，再展开（夏讲教材 P35）

分子提 $e$：$e\left(1-e^{\cos x-1}\right)=e\left[-\left(e^{\cos x-1}-1\right)\right]$，用 $e^u-1\sim u$（$u=\cos x-1\sim-\frac12x^2$）→ 分子 $\sim e\cdot\dfrac{x^2}{2}$。

分母用幂式：$\sqrt[3]{1+x^2}-1\sim\dfrac13x^2$。答案 $=\dfrac{e/2}{1/3}=\dfrac{3e}{2}$。

:::

:::

**随堂测 1：当 $x\to0$ 时，$1-\cos 2x$ 等价于**

- A. $2x^{2}$ 的一半即 $x^{2}$
- B. $x^{2}$
- C. $2x^{2}$
- D. $\dfrac{1}{2}x^{2}$

::: details 点开核对答案

**答案：C（$2x^{2}$）** —— 方框替换：$1-\cos\square\sim\dfrac12\square^2$，方框是 $2x$ → $\dfrac12(2x)^2=2x^2$。D 忘了给方框平方。两步都走稳：先平方、再乘半。（秋讲练习 22 用到。）

:::

**随堂测 2：$\lim\limits_{x\to0}\dfrac{1-\cos x}{2\tan x^{2}}=$**

- A. $\dfrac{1}{4}$
- B. $\dfrac{1}{2}$
- C. $\dfrac{1}{8}$
- D. $2$

::: details 点开核对答案

**答案：A（$\dfrac{1}{4}$）** —— 乘除各自替换：分子 $\sim\dfrac12x^2$，分母 $2\tan x^2\sim2x^2$，答案 $\dfrac14$。（夏讲教材 P35 原题。）

:::

**随堂测 3：$\lim\limits_{x\to0}\dfrac{\sqrt[3]{1+x^{2}}-1}{1-\cos 2x}=$**

- A. $\dfrac{1}{3}$
- B. $\dfrac{1}{6}$
- C. $\dfrac{1}{12}$
- D. $1$

::: details 点开核对答案

**答案：B（$\dfrac{1}{6}$）** —— 分子：$(1+x^2)^{1/3}-1\sim\dfrac13x^2$；分母：$1-\cos2x\sim\dfrac12(2x)^2=2x^2$。比值 $\dfrac{1/3}{2}=\dfrac16$。（夏讲教材 P35 原题。）

:::

**随堂测 4：直接把 $\tan x$、$\sin x$ 都换成 $x$ 来算 $\lim\limits_{x\to0}\dfrac{\tan x-\sin x}{x^3}$，会得到**

- A. 正确答案 $\dfrac{1}{2}$
- B. 正确答案 $\dfrac{1}{6}$
- C. 正确答案 $1$
- D. 错误答案 $0$

::: details 点开核对答案

**答案：D（错误答案 $0$）** —— $x-x=0$——加减中乱替换把三阶主部抹掉了。正解：$\tan x-\sin x\sim\dfrac12x^3$（乘法合成或进阶第三条）。这就是军规存在的意义。

:::

**随堂测 5：$\lim\limits_{x\to0}\dfrac{\left(\sqrt{1+2x}-1\right)\arcsin x}{\tan x^{2}}=$**

- A. $1$
- B. $\dfrac{1}{2}$
- C. $2$
- D. $4$

::: details 点开核对答案

**答案：A（$1$）** —— 三个乘除因子各换各的：$\sqrt{1+2x}-1\sim\dfrac12\cdot2x=x$，$\arcsin x\sim x$，$\tan x^2\sim x^2$ → $\dfrac{x\cdot x}{x^2}=1$。（秋讲练习 12(7) 原题——乘除结构放心换。）

:::

::: danger 本课易错清单

- 方框替换必须**整体一致**：$\sin 2x\sim2x$，不是 $\sim x$
- 加减优先用**进阶六条**整体结论；乱换一阶会抹掉主部
- 真数不是 $1+\square$ 时先**凑方框**（$\ln\cos x=\ln[1+(\cos x-1)]$）
- 带系数的幂式：$(1+\square)^\alpha-1\sim\alpha\cdot\square$，系数别丢
- 等价替换前后极限过程必须一致（都是 $x\to0$）

:::

**回忆卡：默写等价替换军规，并举一个"乱换会错"的例子。**

::: details 先回忆，再揭晓

乘除因子可整体替换；加减中不能随意替换。例：$\dfrac{\tan x-\sin x}{x^3}$ 乱换成 $\dfrac{x-x}{x^3}=0$，正解 $\dfrac12$。

:::

**回忆卡：默写基础八条（$x\to0$）。**

::: details 先回忆，再揭晓

$\sin x\sim x$，$\tan x\sim x$，$\arcsin x\sim x$，$\arctan x\sim x$，$e^x-1\sim x$，$\ln(1+x)\sim x$，$1-\cos x\sim\frac12x^2$，$(1+x)^\alpha-1\sim\alpha x$。

:::

**回忆卡：默写三阶差关系六条（进阶）。**

::: details 先回忆，再揭晓

$\tan x-x\sim\frac13x^3$；$x-\sin x\sim\frac16x^3$；$\tan x-\sin x\sim\frac12x^3$；$x-\arctan x\sim\frac13x^3$；$\arcsin x-x\sim\frac16x^3$；$x-\ln(1+x)\sim\frac12x^2$。

:::
