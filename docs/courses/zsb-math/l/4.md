::: tip 本课结束，你能

- 掌握抽象函数定义域的**三个方向**：$f\to f[g]$、$f[g]\to f$、$f[g]\to f[h]$（考试填空高频）
- 用**换元法**和**恒等变形**从 $f[g(x)]$ 反求 $f(x)$
- 用"定义域 + 对应法则"两把尺子判断两个函数是否相同

:::

核心思想一句话：**$f$ 括号里的量，永远在同一个范围内活动。**$f$ 的"输入"无论是 $x$、$x+1$ 还是 $\sin x$，都必须落进同一个集合。想通这句，三个方向全是水到渠成。

## 一、整体代换：三个方向

| 方向 | 已知 | 做法 |
| --- | --- | --- |
| ① $f\to f[g]$ | $f(x)$ 定义域为 $D$，求 $f[g(x)]$ 的定义域 | 解不等式 $g(x)\in D$ |
| ② $f[g]\to f$ | $f[g(x)]$ 定义域为 $D$，求 $f(x)$ 的定义域 | 算出 $g(x)$ 在 $D$ 上的**值域** |
| ③ $f[g]\to f[h]$ | $f[g(x)]$ 定义域已知，求 $f[h(x)]$ | 先用②得 $f$ 的定义域，再按①解 $h(x)$ 落入其中 |

:::: tip 算例

例 1（方向①）$f(x)$ 定义域为 $(-1,1]$，求 $f(x+1)$ 的定义域。

::: details 先自己做，再展开解答（原题见夏讲教材 P9）

括号里的 $x+1$ 必须还在 $(-1,1]$ 里：$-1<x+1\le1\Rightarrow -2<x\le0$，即 $(-2,0]$。

注意：变的是 $x$ 的范围，$f$ 的"胃口"从没变过。

:::

::::

:::: tip 算例

例 2（方向②）$f(3x-1)$ 的定义域为 $[0,1]$，求 $f(x)$ 的定义域。

::: details 先自己做，再展开解答（原题见夏讲教材 P9）

$x\in[0,1]$ 时，$3x-1\in[-1,2]$——这就是 $f$ 的输入范围。所以 $f(x)$ 的定义域为 $[-1,2]$。

方向②求的是 $f$ 本身的胃口，答案与 $x$ 无关，由内层函数的**值域**决定。

:::

::::

**随堂测 1：$f(x)$ 的定义域为 $[0,4]$，则 $f(4-3x)$ 的定义域是**

- A. $\left[-\dfrac43,0\right]$
- B. $\left[0,\dfrac43\right]$
- C. $[0,4]$
- D. $\left[-4,\dfrac43\right]$

::: details 点开核对答案

**答案：B（$\left[0,\dfrac43\right]$）** —— 方向①：$0\le4-3x\le4$。先解 $4-3x\ge0\Rightarrow x\le\dfrac43$，再解 $4-3x\le4\Rightarrow -3x\le0\Rightarrow x\ge0$（除以负数不等号反向！）。交集 $\left[0,\dfrac43\right]$。

:::

:::: tip 算例

例 3（方向③）$f(2x+3)$ 的定义域为 $[1,3)$，求 $f(1-x)$ 的定义域。

::: details 先自己做，再展开解答（原题见夏讲教材 P9）

第一步（②）：$x\in[1,3)$ 时 $2x+3\in[5,9)$，故 $f$ 的定义域是 $[5,9)$。

第二步（①）：令 $5\le1-x<9$，各边减 1：$4\le-x<8$，除以 $-1$ 变号：$-8<x\le-4$，即 $(-8,-4]$。

方向③永远两步走，**先求 $f$ 的胃，再喂 $h(x)$**。

:::

::::

## 二、求函数表达式：换元与恒等变形

两类任务：（1）已知 $f(x)$，求 $f[g(x)]$——**直接代入**；（2）已知 $f[g(x)]$，反求 $f(x)$——**换元法**（令 $t=g(x)$ 反解出 $x$）或**恒等变形**（把右边凑成"括号量"的结构）。

:::: tip 算例

例 4（换元法）$f(x+1)=x^2-3x$，求 $f(x)$。

::: details 先自己做，再展开解答（原题见夏讲教材 P10）

令 $t=x+1$，则 $x=t-1$，代入右边：

$f(t)=(t-1)^2-3(t-1)=t^2-2t+1-3t+3=t^2-5t+4$。

把记号换回 $x$：$f(x)=x^2-5x+4$。

检验：$f(2)=4-10+4=-2$；用原式算 $f(2)$ 即 $x+1=2\Rightarrow x=1$，$1-3=-2$ ✓。

:::

::::

:::: tip 算例

例 5（恒等变形）$f\left(x+\dfrac1x\right)=x^2+\dfrac{1}{x^2}$，求 $f(x)$。

::: details 先自己做，再展开解答（原题见夏讲教材 P10）

换元要反解 $x+\dfrac1x$ 太麻烦；观察右边：$x^2+\dfrac{1}{x^2}=\left(x+\dfrac1x\right)^2-2$。

所以 $f(\ \cdot\ )=(\ \cdot\ )^2-2$，即 $f(x)=x^2-2$。别忘了定义域：括号量 $x+\dfrac1x$ 满足 $|x+\dfrac1x|\ge2$，严格写为 $f(x)=x^2-2\ (|x|\ge2)$。

标志词：看到 $x+\dfrac1x$、$x-\dfrac1x$，立刻想 **$(x\pm\dfrac1x)^2=x^2+\dfrac{1}{x^2}\pm2$**。

:::

::::

:::: tip 算例

例 6（连锁）$f(x-2)=x^2-x$，求 $f\left(\sqrt x\right)$。

::: details 先自己做，再展开解答（原题见夏讲教材 P10–11）

先求 $f$：令 $t=x-2$，$x=t+2$，$f(t)=(t+2)^2-(t+2)=t^2+3t+2$。

再代入 $\sqrt x$：$f\left(\sqrt x\right)=x+3\sqrt x+2$，定义域 $x\ge0$。

$f[g]\to f[h]$ 的"求表达式"版本，同样是两步。

:::

::::

## 三、相同函数：两把尺子

::: warning 必背

两个函数相同 $\iff$ **定义域相同** 且 **对应法则相同**。与变量字母（$x$ 还是 $t$）、表达形式（化简前后）**无关**。

:::

| 函数对 | 相同？ | 原因 |
| --- | --- | --- |
| $\dfrac{x^2}{x}$ 与 $x$ | 否 | 前者定义域 $x\neq0$——约分偷走了定义域 |
| $x$ 与 $\sqrt{x^2}$ | 否 | $\sqrt{x^2}=\|x\|$，$x<0$ 时法则不同 |
| $x$ 与 $x(\sin^2x+\cos^2x)$ | **是** | $\sin^2x+\cos^2x=1$ 恒成立，定义域法则都同 |
| $y=f(x)$ 与 $u=f(t)$ | **是** | 字母只是名字 |

**随堂测 2：下列哪一对是相同的函数？**

- A. $y=x$ 与 $y=\sqrt{x^2}$
- B. $y=\dfrac{x^2}{x}$ 与 $y=x$
- C. $y=x$ 与 $y=x(\sin^2x+\cos^2x)$
- D. $y=\lg x^2$ 与 $y=2\lg x$

::: details 点开核对答案

**答案：C（$y=x$ 与 $y=x(\sin^2x+\cos^2x)$）** —— A：$\sqrt{x^2}=|x|\neq x$；B：定义域不同（$x\neq0$）；D：$\lg x^2$ 定义域为 $x\neq0$，而 $2\lg x$ 要求 $x&gt;0$。C：$\sin^2x+\cos^2x=1$ 对一切实数成立，两把尺子都过 → 相同。

:::

::: danger 易错

$f[g(x)]$ 的定义域是"使 $g(x)$ 落入 $f$ 的定义域"的 $x$ 范围，**不是把 $g$ 的定义域直接搬过来**。解含 $g(x)$ 的不等式时，除以负数记得变号（随堂测 1 的 $\left[0,\dfrac43\right]$ 就藏在一次变号里）。

:::

**回忆卡：抽象函数定义域三个方向各自怎么做？（$f\to f[g]$、$f[g]\to f$、$f[g]\to f[h]$）**

::: details 先回忆，再揭晓

① 解 $g(x)\in D$；② 取 $g$ 在已知定义域上的**值域**；③ 先用②求出 $f$ 的定义域，再按①解 $h(x)$ 落入其中。

:::

**回忆卡：判断相同函数的两把尺子是什么？哪三个"干扰项"可以无视？**

::: details 先回忆，再揭晓

定义域相同 + 对应法则相同。变量字母、表达形式、写法都不是判断依据。

:::
