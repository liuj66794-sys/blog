## 卡 1 · 预备与函数（0001–0009）

**必背包卡 1：①特殊角三角函数值（$0,\frac\pi6,\frac\pi4,\frac\pi3,\frac\pi2$）；②奇偶运算口诀；③有界函数清单；④三类定点（幂/指数/对数）；⑤反函数三步法；⑥二次函数顶点。**

::: details 先回忆，再揭晓

①$\sin$：$0,\frac12,\frac{\sqrt2}2,\frac{\sqrt3}2,1$（余弦倒序）；②同性保持、奇偶相乘得奇、乘除同得偶异得奇、**内偶则偶内奇同外**；③$\sin,\cos,\arcsin,\arccos,\arctan,\frac{1}{1+x^{2}}$；④$(1,1)/(0,1)/(1,0)$；⑤反解→互换→**标定义域**；⑥$(-\frac{b}{2a},\frac{4ac-b^{2}}{4a})$。

:::

## 卡 2 · 极限与连续（0010–0018）

**必背包卡 2：①两大充要条件；②必分左右的信号；③等价无穷小基础八条；④三阶差六条；⑤$1^{\infty}$ 三步法；⑥抓大头三结论 + 速度链；⑦$q^{n}$ 四情形；⑧四类间断点；⑨零点定理条件。**

::: details 先回忆，再揭晓

①两侧存在且相等；②分段点、$e^{1/x}$、$\arctan\frac1x$；③$\sin x,\tan x,\arcsin x,\arctan x,e^{x}-1,\ln(1+x)\sim x$、$1-\cos x\sim\frac{x^{2}}2$、$(1+x)^{\alpha}-1\sim\alpha x$；④$\tan x-x\sim\frac{x^{3}}3$、$x-\sin x\sim\frac{x^{3}}6$、$\tan x-\sin x\sim\frac{x^{3}}2$ 等；⑤$u^{v}=e^{v(u-1)}$（先验 $u\to1$）；⑥次高 0 / 同次 $\frac{a_0}{b_0}$ / 次低 $\infty$，$\ln x\ll x^{a}\ll c^{x}\ll x^{x}$；⑦$|q|<1$ 收 0、$q>1$ 散、$q=1$ 为 1、$q\le-1$ 不存在；⑧可去/跳跃/无穷/振荡；⑨闭区间连续 + 端点异号。

:::

## 卡 3 · 导数与微分（0019–0025）

**必背包卡 3：①定义式变形公式；②可导与连续关系及反例；③六类求导法各一句；④$n$ 阶导四公式；⑤切线法线公式；⑥三中值定理；⑦极值两判定；⑧拐点条件。**

::: details 先回忆，再揭晓

①$(\alpha-\beta)f'(x_0)$；②可导 ⇒ 连续，反例 $|x|$、$x^{1/3}$；③分段用定义 / 两边导 / 参数 $\frac{dy/dt}{dx/dt}$（二阶再除一次）/ 幂指取对数 / 反函数取倒数 / 复杂取对数；④$e^{x}\to e^{x}$、$a^{x}\to a^{x}\ln^{n}a$、$\sin\to\sin(x+\frac{n\pi}{2})$、$\ln(1+x)\to(-1)^{n-1}\frac{(n-1)!}{(1+x)^{n}}$；⑤$y-y_0=f'(x_0)(x-x_0)$、法线斜率 $-\frac{1}{f'(x_0)}$；⑥罗尔（端点等值）/ 拉格朗日 / 柯西；⑦左正右负极大、左负右正极小；$f''<0$ 极大、$>0$ 极小、$=0$ 失效；⑧两侧凹凸改变的全坐标点（$f''=0$ 需验变号）。

:::

## 卡 4 · 积分（0026–0034）

**必背包卡 4：①互逆 $C$ 规则；②凑微分万能型；③换元三选一；④"反对幂三指"；⑤分式四策略；⑥点火公式两种结尾；⑦变限求导口诀；⑧面积/体积/弧长公式；⑨牛顿–莱布尼茨。**

::: details 先回忆，再揭晓

①先导后积补 $C$、先积后导不补；②$\int\frac{f'}{f}dx=\ln|f|+C$；③减号正弦、加号正切、反减正割（画三角形回代）；④反、对、幂、三、指——前者当 $u$；⑤长除 / 裂项 / 凑分母导数 / 凑 $\arctan$；⑥奇串到 1、偶串到 $\frac\pi2$；⑦代上限函数先代后乘导、下限变量添负；⑧$S=\int[f-g]$、$V=\pi\int f^{2}$、$l=\int\sqrt{1+f'^{2}}$；⑨$F(b)-F(a)$。

:::

## 卡 5 · 多元 + 级数 + 方程（0035–0043）

**必背包卡 5：①全微分与关系链；②复合链式与隐函数公式；③$AC-B^{2}$ 判别表；④极坐标面积元；⑤格林公式；⑥$p$-级数与几何级数分界；⑦三色标签流程；⑧一阶线性通解公式；⑨特征根三模板与共振。**

::: details 先回忆，再揭晓

①$dz=f_xdx+f_ydy$；偏导连续 ⇒ 可微 ⇒ 连续 + 偏导存在（单向）；②$z_x=f_uu_x+f_vv_x$；$z_x=-\frac{F_x}{F_z}$；③$\Delta>0$ 且 $A>0$ 极小、$A<0$ 极大、$\Delta<0$ 鞍点、$=0$ 失效；④$d\sigma=r\,dr\,d\theta$；⑤$\oint Pdx+Qdy=\iint(Q_x-P_y)d\sigma$（正向 = 区域在左）；⑥$|q|<1$ 收、$p>1$ 收；⑦先 $\sum|a_n|$ 后 $\sum a_n$；⑧$y=e^{-\int p}\left[\int qe^{\int p}dx+C\right]$；⑨异根 / 重根补 $x$ / 复根 $e^{\alpha x}(\cos,\sin)$；撞根乘 $x^{k}$。

:::

**终检 1（混章）：下列四个结论中，错误的是**

- A. 可导必连续，$|x|$ 在 0 连续不可导
- B. $a_n\to0$ 不能保证 $\sum a_n$ 收敛
- C. 偏导存在则二元函数必连续
- D. $1^{\infty}$ 型可用 $e^{\lim v(u-1)}$

::: details 点开核对答案

**答案：C（偏导存在则二元函数必连续）** —— C 错——"偏导存在 ⇏ 连续"正是多元与一元的关键差异（关系链单向）。A、B、D 都是全程反复强调的正确结论。混章辨错题考的就是"相似结论不串门"。

:::

**终检 2（混章）：四个"负号 / 系数易错点"中，写法正确的是**

- A. $\displaystyle\int\tan x\,dx=-\ln|\cos x|+C$；隐函数 $z_x=-\dfrac{F_x}{F_z}$；法线斜率 $=-\dfrac{1}{f'(x_0)}$；比较法判收敛找更大的收敛级数
- B. $\displaystyle\int\tan x\,dx=\ln|\cos x|+C$；其余三项同 A
- C. 隐函数 $z_x=\dfrac{F_x}{F_z}$；其余三项同 A
- D. 法线斜率 $=\dfrac{1}{f'(x_0)}$；其余三项同 A

::: details 点开核对答案

**答案：A（$\displaystyle\int\tan x\,dx=-\ln|\cos x|+C$；隐函数 $z_x=-\dfrac{F_x}{F_z}$；法线斜率 $=-\dfrac{1}{f'(x_0)}$；比较法判收敛找更大的收敛级数）** —— 四个负号/方向高发点一次打包：积分符号、隐函数负号、法线负倒数、比较法方向。考场上遇到"带符号的公式"就默念一遍这四项——全部出自你的错题高发区。

:::
