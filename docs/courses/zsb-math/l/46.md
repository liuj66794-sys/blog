从本课起进入"整卷模式"。你有 8 套模拟 + 4 套押题卷（含题解）——数量足够，缺的是**消化流程**。刷十套不复盘，不如按本课五步吃透三套。

## 一、限时实战五步

::: warning 每套卷的标准流程

- **① 限时**：按正式考试时间一气呵成，题间不看答案（手表放卷侧，不设手机）
- **② 对答**：对照题解批改；每道错题当场标类别：**知识缺口 / 方法选择 / 运算 / 审题 / 时间分配**
- **③ 归因**：只摘录自己的"错误触发条件"，不抄整段答案
- **④ 还原**：把错题压缩成"触发词 → 方法 → 一步关键式"三件套
- **⑤ 回测**：**24 小时后**重做错题，**7 天后**再测一次；两次都独立正确才移出错题队列

:::

:::: tip 算例

例（三件套长什么样）某次模拟中，你在"判 $\sum\frac{1}{\sqrt n(n+1)}$ 敛散"时答了"发散"。

::: details 展开看它压缩成三件套后的样子

| 项 | 内容 |
| --- | --- |
| 触发词 | 通项是"根号乘多项式的分式" → 想到**阶数比较** |
| 方法 | 极限比较法：与 $\frac{1}{n^{3/2}}$ 同阶 → 查 $p$-级数表（$p>1$ 收敛） |
| 一步关键式 | $\dfrac{1}{\sqrt n(n+1)}\sim\dfrac{1}{n^{3/2}}$ |

归因：方法选择错（当时想成了"分母含根号 = 发散"）。补救：0040 课选法速查表抄 3 遍 + 重做练习 6 全组。

:::

::::

## 二、五类错因的对应补救

| 类别 | 典型表现 | 补救动作 |
| --- | --- | --- |
| 知识缺口 | 公式想不起来、定义说不出 | 回对应知识课**重测回忆卡**（不是重读正文） |
| 方法选择 | 方向对但招错了、绕远路 | 练"认脸"：把同类题打混限时 30 秒/题说招 |
| 运算 | 思路对、算错（符号/系数/漏项） | 限时基础题；**关键步骤回代验算** |
| 审题 | 看错问法（求切线看成法线、面积看成积分值） | 动笔前**圈画题目关键词**；错题本记"我当时看成什么" |
| 时间分配 | 会做但没做完、难题恋战 | 掐表单项训练；单题超时 5 分钟先跳过打标记 |

::: warning 勘误与"原页疑点"

你的资料里有一份《随堂练习册勘误》；部分题解里标了"原页疑点"（题面与常识冲突）。规则：**遇到对不上的题，先查勘误与题解说明，别硬猜图**——把疑问记下来问老师，比自己耗 20 分钟值。

:::

## 三、错题队列的运转

::: warning 队列规则

入场：整卷批改后，所有非"粗心看错"的错题入队。出场：**24 小时重做 + 7 天再测，两次都独立正确**才退役。中间：每次模拟卷前，先扫一遍队列里的"三件套"，只看触发词、遮住方法与关键式。

:::

**随堂测 1：一道题你思路完全正确但最后一步把 $-\frac{2}{3}$ 算成 $\frac{2}{3}$，这属于哪类错因？对应补救是？**

- A. 知识缺口——回看知识点正文
- B. 运算——限时基础题 + 关键步骤回代验算
- C. 审题——圈画题目关键词
- D. 时间分配——整卷提速

::: details 点开核对答案

**答案：B（运算——限时基础题 + 关键步骤回代验算）** —— 符号丢 = 运算类。补救不是"多刷整卷"，而是&lt;strong&gt;定点&lt;/strong&gt;：限时做 5 道同长度计算，并养成"末步代回验算"的肌肉记忆（微分方程、积分求导都适用）。

:::

**随堂测 2：错题"退役"的标准是**

- A. 24 小时后与 7 天后两次重做都独立做对
- B. 看懂题解后立即退役
- C. 抄写三遍后退役
- D. 错题本记满一页后统一处理

::: details 点开核对答案

**答案：A（24 小时后与 7 天后两次重做都独立做对）** —— "看懂"只说明题解写得好（流畅性错觉）；&lt;strong&gt;间隔双测独立做对&lt;/strong&gt;才是存储强度的证据。B 是错题复发的第一原因。

:::

**随堂测 3：模拟卷遇到一道题面疑似有误（条件矛盾），正确做法是**

- A. 按自己猜测的条件强行做下去
- B. 直接跳过，永不回头
- C. 先查勘误与题解的"原页疑点"说明，得出条件化结论，仍有疑问就问老师
- D. 认定一定是自己的错，反复重算到考时结束

::: details 点开核对答案

**答案：C（先查勘误与题解的"原页疑点"说明，得出条件化结论，仍有疑问就问老师）** —— 你的题解体系已明确标注"题面矛盾时不修改转录，在题解中说明"——先查勘误（如《随堂练习册勘误》已公布的更正），再决策。考场上同款策略：标记跳过，最后回头。

:::

**随堂测 4："三件套"中"一步关键式"的作用是**

- A. 让错题本看起来更完整
- B. 替代整段抄答案，方便背诵
- C. 给老师检查作业用
- D. 重做时只看触发词回忆方法和关键一步，检验是"想起来了"还是"看懂了"

::: details 点开核对答案

**答案：D（重做时只看触发词回忆方法和关键一步，检验是"想起来了"还是"看懂了"）** —— 三件套的设计目标就是&lt;strong&gt;检索练习&lt;/strong&gt;：遮住后两栏，只读触发词——能自己复原方法与关键式才算过，否则题还没"长"在脑子里。

:::

::: danger 本课易错清单（流程层面的）

- 刷卷不计时 = 只练了"会"，没练"快"——**限时是一切的前提**
- 对答案即退役——**双测标准**（24h + 7d）才是退役线
- 抄整段答案不写三件套——错题本不是笔记本
- 只刷新卷不复古老错——**队列扫描**排在每场模拟之前
- 题面矛盾硬猜——查勘误、标疑点、问老师

:::

**回忆卡：默写限时实战五步与错题五分类。**

::: details 先回忆，再揭晓

限时 → 对答 → 归因 → 还原 → 回测；五分类：知识缺口 / 方法选择 / 运算 / 审题 / 时间分配。

:::

**回忆卡：错题三件套是哪三件？退役标准是什么？**

::: details 先回忆，再揭晓

触发词 → 方法 → 一步关键式；24 小时 + 7 天两次独立正确才退役。

:::
