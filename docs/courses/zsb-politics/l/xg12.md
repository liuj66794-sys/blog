## 03正文精讲

## 第一节 坚持人与自然和谐共生

总起：大自然是人类赖以生存发展的基本条件，**尊重自然、顺应自然、保护自然**是全面建设社会主义现代化国家的**内在要求**；"要像保护眼睛一样保护生态环境，像对待生命一样对待生态环境"⭐⭐。

### 一、生态兴则文明兴

自然是生命之母，**人与自然是生命共同体**。当人类友好保护自然时，自然的回报是慷慨的；当人类粗暴掠夺自然时，自然的惩罚也是无情的。**保护自然就是保护人类，建设生态文明就是造福人类**。

**1. 生态环境变化直接影响文明的兴衰演替**⭐⭐
- ⭐ 名句："**生态兴则文明兴，生态衰则文明衰**。"
- 古代埃及、古代巴比伦、古代印度、古代中国四大文明古国均发源于森林茂密、水量丰沛、田野肥沃的地区；生态环境衰退特别是**严重的土地荒漠化**导致古代埃及、古代巴比伦衰落。
- 恩格斯《自然辩证法》：美索不达米亚、希腊、小亚细亚等地居民为得到耕地毁灭森林，"这些地方今天竟因此而成为不毛之地"。
- 我国教训：河西走廊、黄土高原曾水丰草茂，毁林开荒、乱砍滥伐使生态破坏加剧经济衰落；唐代中叶以来经济中心逐步向东、向南转移，很大程度上同西部地区生态环境变迁有关。

**2. 生态文明是人类文明发展的历史趋势**⭐
- 人类经历**原始文明、农业文明、工业文明**；工业文明在创造巨大物质财富的同时加速了对自然资源的攫取，打破了地球生态系统原有的循环和平衡。
- ⭐ 生态文明是**工业文明发展到一定阶段的产物**，是人类社会进步的重大成果；它强调协调人与自然关系，把人类活动限制在生态环境能够承受的限度内，昭示着人类文明发展的未来。
- 拓展案例：《寂静的春天》（卡逊，1962 年出版）揭露以 DDT 为代表的杀虫剂对生存环境难以逆转的危害。

**3. 中华文明孕育着丰富的生态文化**
- 绵延 5000 多年的中华文明孕育丰富生态文化："天地与我并生，而万物与我为一"的**"天人合一"思想**是中华文明的鲜明特色和独特标识。
- 现实紧迫性：我国环境容量有限、生态系统脆弱，资源环境约束趋紧、生态系统退化问题突出，各类环境污染、生态破坏呈高发态势。
- 必须坚定不移走**生产发展、生活富裕、生态良好**的文明发展道路，守牢美丽中国建设安全底线。

### 二、绿水青山就是金山银山

**1. 理念定位与内涵**⭐⭐⭐
- 生态环境问题归根到底是**经济发展方式和生活方式问题**。
- 两山理念是重要的**发展理念**，也是推进现代化建设的**重大原则**；它阐明经济发展与生态环境保护的关系，揭示了**保护生态环境就是保护生产力、改善生态环境就是发展生产力**，指明实现发展和保护协同共生的新路径。
- 辩证关系：表面上是鱼和熊掌不可兼得的两难选择，根本上是**辩证统一、相辅相成**——坚持**在发展中保护、在保护中发展**。
- 原文金句："我们既要绿水青山，也要金山银山。宁要绿水青山，不要金山银山，而且绿水青山就是金山银山。"

**2. 理念的提出与丰富完善（时间线必背）**⭐⭐⭐

| 时间 | 事件 |
| --- | --- |
| 2005.8.15 | 习近平在浙江安吉**余村**考察，**首次提出**"绿水青山就是金山银山"（肯定余村关停矿山搞生态旅游） |
| 2005.8.24 | 在《浙江日报》发表《绿水青山也是金山银山》，阐述两者辩证统一关系 |
| 2006.3 | 《从"两座山"看生态环境》提出对两山关系认识的**"三个阶段"论** |
| 党的十八大以来 | 生态文明建设纳入"五位一体"总体布局，理念在理论内涵和实践应用上不断丰富完善 |
| 党的十九大 | **首次**将"必须树立和践行绿水青山就是金山银山的理念"写入大会报告（作为基本方略之一的主要内容）；"增强绿水青山就是金山银山的意识"**写入党章** |
| 2018.5 | 全国生态环境保护大会召开，**正式确立习近平生态文明思想**；系统阐释"六项原则"，两山理念为其一 |
| 2021.11 | "必须坚持绿水青山就是金山银山的理念"写入《中共中央关于党的百年奋斗重大成就和历史经验的决议》 |

**3. 两山关系的三个层次**⭐
- 财富论：绿水青山既是**自然财富、生态财富**，又是**社会财富、经济财富**（"草木植成，国之富也"）；绿水青山可带来金山银山，但**金山银山却买不到绿水青山**。
- 转化论：坚持生态优先、绿色发展，把生态环境优势转化为**生态农业、生态工业、生态旅游**等生态经济优势，绿水青山就变成了金山银山。
- 方法论：处理好两山关系**关键在人、关键在思路**；要处理好**高质量发展和高水平保护**的关系；不简单以国内生产总值增长率论英雄，但不是不要发展，不能动以牺牲环境换取经济增长的念头。

### 三、把生态文明建设摆在全局工作的突出位置

**1. 三个"重大问题"定位**⭐⭐
- 生态文明建设是**重大经济问题**，也是关系党的使命宗旨的重大**政治问题**、关系民生福祉的重大**社会问题**。
- ⭐ "良好的生态环境是**最公平的公共产品**，是**最普惠的民生福祉**。"

**2. 四个重大转变**⭐⭐⭐

| 序号 | 重大转变 |
| --- | --- |
| ① | 由**重点整治**到**系统治理** |
| ② | 由**被动应对**到**主动作为** |
| ③ | 由全球环境治理**参与者**到**引领者** |
| ④ | 由**实践探索**到**科学理论指导**（形成习近平生态文明思想） |

**3. 战略地位更加凸显（八个"纳入/写入"）**⭐⭐

| 纳入对象 | 内容 |
| --- | --- |
| "五位一体"总体布局 | 生态文明建设 |
| 新时代坚持和发展中国特色社会主义基本方略 | 坚持人与自然和谐共生 |
| 中国式现代化的本质要求 | 促进人与自然和谐共生 |
| 社会主义现代化强国目标 | 美丽中国 |
| 新发展理念 | 绿色 |
| 决胜全面建成小康社会三大攻坚战 | 污染防治 |
| 党章（十九大） | 增强绿水青山就是金山银山的意识等 |
| **宪法**（2018.3 十三届全国人大一次会议宪法修正案） | 生态文明 |

**4. 制度体系与治理成效**
- 制度：出台《中共中央国务院关于加快推进生态文明建设的意见》《生态文明体制改革总体方案》等纲领性文件，生态文明"**四梁八柱**"性质的制度体系基本形成；制定修订环境保护法、环境保护税法等 **30 多部**生态环境领域法律和行政法规；开展**中央生态环境保护督察**。
- 治理：深入实施大气、水、土壤污染防治三大行动计划，打好**蓝天、碧水、净土保卫战**；我国成为**全球大气环境质量改善速度最快的国家**；严守**生态保护红线、环境质量底线、资源利用上线**三条红线。
- 总体评价：绿色成为新时代中国的**鲜明底色**；新时代生态文明建设的成就举世瞩目，成为新时代党和国家事业取得历史性成就、发生历史性变革的**显著标志**。

## 第二节 建设美丽中国

总起：建设美丽中国，是**全面建设社会主义现代化国家的重要目标**，也是满足人民日益增长的优美生态环境需要的必然要求；要实现到**本世纪中叶建成美丽中国**的战略目标⭐⭐。

### 一、加快形成绿色生产方式和生活方式

绿色发展是新发展理念的重要内容，是**发展观的一场深刻革命**；"绿色发展，就其要义来讲，是要解决好**人与自然和谐共生**问题"；坚持把绿色低碳发展作为解决生态环境问题的**治本之策**⭐⭐。

**1. 加快推动产业结构、能源结构、交通运输结构等调整优化**
- 抓住**产业结构调整**这个关键，促进产业结构变"轻"、发展模式变"绿"。
- 两手抓：运用绿色低碳技术改造升级传统产业（推进能源革命、发展非化石能源）+ 以绿色低碳技术创新应用推动战略性新兴产业、高技术产业、现代服务业发展。

**2. 推进各类资源节约集约利用**
- ⭐ 生态环境问题，归根到底是**资源过度开发、粗放利用、奢侈消费**造成的。
- 树立节约集约循环利用的资源观，实行最严格的耕地保护、水资源管理制度；形成节约适度、绿色低碳、文明健康的生活方式和消费模式。

**3. 积极稳妥推进碳达峰碳中和**⭐⭐⭐

| 概念 | 含义 | 关键点 |
| --- | --- | --- |
| 碳达峰 | 某一时点二氧化碳排放不再增长达到峰值，之后逐步回落 | 排放**由增转降的历史拐点**，标志碳排放与经济发展实现脱钩 |
| 碳中和 | 通过植树造林、节能减排等形式抵消直接或间接产生的二氧化碳或温室气体排放总量 | 正负抵消，达到相对"**零排放**" |
| 碳排放权交易 | 以市场机制控制排放的环境经济政策 | 全国碳排放权交易市场 **2021.7.16** 上线开市 |

- 目标：力争 **2030 年前实现碳达峰，努力争取 2060 年前实现碳中和**；到 2030 年单位 GDP 二氧化排放比 2005 年下降 **65% 以上**、非化石能源占一次能源消费比重达 **25% 左右**。
- ⭐ 金句："实现'双碳'目标，**不是别人让我们做，而是我们自己必须要做**"——破解资源环境约束突出问题、实现可持续发展的迫切需要，是一场广泛而深刻的经济社会系统性变革。
- 注重处理好四对关系：**发展和减排、整体和局部、长远目标和短期目标、政府和市场**。
- 处理好"双碳"承诺和自主行动的关系：目标确定不移，但路径方式、节奏力度**由我们自己作主，决不受他人左右**。

**4. 健全绿色发展的保障体系**
- 统筹打好**法治、市场、科技、政策"组合拳"**，推动有效市场和有为政府更好结合。
- 推进绿色低碳科技自立自强；深化人工智能等数字技术应用，构建美丽中国数字化治理体系，建设绿色智慧的**数字生态文明**。

**5. 坚持把建设美丽中国转化为全体人民自觉行动**
- 生态文明是人民群众**共同参与共同建设共同享有**的事业；每个人都是生态环境的**保护者、建设者、受益者**。
- 增强全民节约意识、环保意识、生态意识，开展全民绿色行动。

### 二、坚持山水林田湖草沙一体化保护和系统治理

**1. 理论依据：生命共同体**⭐⭐
- "山水林田湖草沙是一个生命共同体，是不可分割的生态系统"；⭐ 原文："人的命脉在田，田的命脉在水，水的命脉在山，山的命脉在土，土的命脉在林和草，这个生命共同体是人类生存发展的物质基础。"
- 坚持系统观念，统筹考虑自然生态各要素、山上山下、地上地下、岸上水里、城市农村、陆地海洋以及流域上下游，进行**整体保护、系统修复、综合治理**。

**2. 五大举措**⭐⭐

| 举措 | 核心要点 |
| --- | --- |
| ① 加快实施重要生态系统保护和修复重大工程 | 划定落实**生态保护红线、永久基本农田、城镇开发边界**三条控制线；推进青藏高原生态屏障区、黄河重点生态区、长江重点生态区和东北森林带、北方防沙带、南方丘陵山地带、海岸带等"**三区四带**"生态屏障建设；处理好自然恢复和人工修复的关系 |
| ② 推进自然保护地体系建设 | 构建以**国家公园为主体、自然保护区为基础、各类自然公园为补充**的自然保护地体系；建设好三江源、大熊猫、东北虎豹、海南热带雨林、武夷山等国家公园 |
| ③ 科学推进荒漠化、石漠化、水土流失综合治理 | 坚持乔灌草相结合；**森林既是水库、钱库、粮库，也是碳库**；开展全民义务植树 |
| ④ 实施生物多样性保护重大工程 | 优化就地保护体系、完善迁地保护体系；加强生物安全管理，防治外来物种侵害 |
| ⑤ 推行草原森林河流湖泊湿地休养生息 | 落实禁牧、休牧和草畜平衡制度；统筹水资源、水环境、水生态、水安全 |

- 案例：2024.11.28 全长 **3046 公里**的塔克拉玛干绿色阻沙防护带实现全面锁边"合龙"，是**世界上最长的环沙漠绿色生态屏障**。

### 三、用最严格制度最严密法治保护生态环境

**1. 总要求**⭐⭐
- "只有实行**最严格的制度、最严密的法治**，才能为生态文明建设提供可靠保障。"
- 把**制度建设**作为生态文明建设的**重中之重**，构建产权清晰、多元参与、激励约束并重、系统完整的生态文明制度体系。

**2. 三大制度 + 执行保障**⭐⭐

| 制度 | 核心内容 |
| --- | --- |
| 最严格的生态环境保护制度 | 健全**源头预防、过程控制、损害赔偿、责任追究**的生态环境保护体系；构建以排污许可制为核心的固定污染源监管制度体系；健全党委领导、政府主导、企业主体、社会组织和公众共同参与的现代环境治理体系 |
| 资源高效利用制度 | 自然资源统一确权登记、资源有偿使用、资源总量管理和全面节约；普遍实行垃圾分类和资源化利用制度；构建清洁低碳、安全高效的能源体系 |
| 生态环境保护责任制度 | 生态文明建设目标评价考核；**领导干部自然资源资产离任审计**；落实中央生态环境保护督察制度；实行生态环境损害责任**终身追究制**；健全河湖长制、林长制 |
| 执行保障 | ⭐ "**制度的生命力在于执行，关键在真抓，靠的是严管**"；不得作选择、搞变通、打折扣 |

## 第三节 共谋全球生态文明建设之路

总起：建设绿色家园是人类的共同梦想；中国致力于推动**共建地球生命共同体**，积极参与全球环境治理，是**全球生态文明建设的重要参与者、贡献者、引领者**⭐⭐。

### 一、保护人类共同家园

- 地球是全人类赖以生存的**唯一家园**，珍爱和呵护地球是人类的唯一选择。"人类只有一个地球，保护生态环境、推动可持续发展是各国的共同责任。"
- 人类可以利用自然、改造自然，但归根结底是**自然的一部分**，必须呵护自然，不能凌驾于自然之上（习近平在第七十届联合国大会一般性辩论时的讲话，2015.9.28）。
- 面对生态环境挑战，人类是**一荣俱荣、一损俱损的命运共同体**，任何一国想单打独斗都无法解决；应秉持地球生命共同体理念，开展全球行动、全球应对、全球合作⭐。
- ⭐ 五个"追求"：追求**人与自然和谐**、追求**绿色发展繁荣**、追求**热爱自然情怀**、追求**科学治理精神**、追求**携手合作应对**；秉持**共商共建共享**的全球治理观，实现联合国 2030 年可持续发展目标。

### 二、共建清洁美丽世界（四点主张）⭐⭐

| 主张 | 核心要点 |
| --- | --- |
| 坚持以人为本 | 把全球生态治理同促进各国可持续发展结合；采取绿色基建、绿色能源、绿色交通、绿色金融等举措；增进世界各国人民特别是**发展中国家人民**的福祉 |
| 坚持科学治理 | 加深对自然规律、生物多样性等科学规律的认识；依靠**科技创新**破解绿色发展难题 |
| 坚持多边主义 | 摒弃"单边主义""极端利己主义""甩锅推责"；以**国际法为基础、以公平正义为要旨、以有效行动为导向**，维护以联合国为核心的国际体系，消除绿色贸易壁垒 |
| 坚持共同但有区别的责任原则 | 发达国家和发展中国家历史责任和现实能力存在差异：发展中国家大多是"**生存型**"排放，发达国家早已是"**奢侈型**"或"浪费型"排放；发达国家应主动承担历史责任，为发展中国家提供**资金、技术、能力建设**支持 |

### 三、积极推动全球可持续发展

**1. 积极参与全球气候治理**⭐
- 中国作为**世界上最大的发展中国家**，重信守诺，已将应对气候变化全面融入国家经济社会发展战略。
- 成绩：提前完成 2020 年应对气候变化和设立自然保护区相关目标；**人工林面积居全球第一**；是**对全球臭氧层保护贡献最大的国家**。
- 承诺：力争 2030 年前实现碳达峰、努力争取 2060 年前实现碳中和（同第二节"双碳"目标）。

**2. 积极推进全球生物多样性治理**⭐⭐
- "万物各得其和以生，各得其养以成。"生物多样性使地球充满生机，是人类生存和发展的基础。
- 中国成功承办联合国《生物多样性公约》**第十五次缔约方大会**，推动达成"**昆明—蒙特利尔全球生物多样性框架**"等具有里程碑意义的成果；积极落实联合国生态系统恢复十年行动计划。

**3. 积极打造绿色"一带一路"**
- "一带一路"是一条绿色发展之路：携手打造"**绿色丝绸之路**"；完善"一带一路"绿色发展国际联盟；共建生态环保大数据服务平台，实施绿色丝路使者计划。
- 让**绿色切实成为共建"一带一路"的底色**；以绿色转型为驱动、以人民福祉为中心、以国际法为基础，共建地球生命共同体、共建清洁美丽世界。

## 05易错点辨析

1. **"三条红线"≠"三条控制线"**——三条红线指**生态保护红线、环境质量底线、资源利用上线**；三条控制线指**生态保护红线、耕地和永久基本农田、城镇开发边界**（2019.11《关于在国土空间规划中统筹划定落实三条控制线的指导意见》）。两者名称相近、内容不同，选择极易混。
2. **碳达峰 ≠ 碳中和**——碳达峰是二氧化碳排放由增转降的**历史拐点**（2030 年前）；碳中和是通过植树造林、节能减排等实现排放正负抵消的相对"零排放"（2060 年前）。先达峰、后中和，顺序和时间不能颠倒。
3. **两山金句是三层递进，不能断章取义**——"既要绿水青山，也要金山银山→宁要绿水青山，不要金山银山→绿水青山就是金山银山"；保护生态不是**舍弃经济发展**，而是坚持在发展中保护、在保护中发展。
4. **习近平生态文明思想正式确立于 2018.5 全国生态环境保护大会**——不是十九大；十九大的动作是两山理念写入大会报告并写入党章；2021.11 才写入党的百年奋斗历史决议。三个节点别对调。
5. **两山理念首次提出是 2005 年在浙江安吉余村考察时**——先有考察时的首次提出（2005.8.15），再有《浙江日报》撰文阐述（2005.8.24）、"三个阶段"论（2006.3），时间线由口头到文字逐步展开。
6. **"最公平的公共产品"与"最普惠的民生福祉"是同一句话**——"良好的生态环境是最公平的公共产品，是最普惠的民生福祉"，选择题常拆开冒充两个出处。
7. **"四梁八柱"是形容制度体系基本形成**，不是"四项制度+八项制度"的实指；其依据是纲领性文件＋数十项改革方案。
8. **两个"生命共同体"语境不同**——"人与自然是生命共同体"讲人与自然的关系；"山水林田湖草沙是一个生命共同体"讲生态系统内部各要素不可分割，配套记忆命脉链"人→田→水→山→土→林和草"。
9. **八个"纳入"要一一对应**——"美丽中国"纳入的是**强国目标**，"绿色"纳入**新发展理念**，"促进人与自然和谐共生"纳入**中国式现代化的本质要求**，"污染防治"纳入**三大攻坚战**，不能张冠李戴。
10. **中国是全球治理的"参与者、贡献者、引领者"**——由"参与者到引领者"是四个重大转变之一；对外表述是"重要参与者、贡献者、引领者"，不使用"领导者""主导者"等提法。
11. **"共同但有区别的责任"的论据口径**——发展中国家多为"生存型"排放，发达国家是"奢侈型/浪费型"排放；发达国家应主动承担历史责任并提供资金、技术、能力建设支持，而非让各国承担同等责任。
