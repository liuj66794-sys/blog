:::: details 一、党的二十届四中全会与"十五五"规划

::: details 答案

- **二十届四中全会**：**2025年10月20日至23日**在北京举行，最重要的成果是审议通过**《中共中央关于制定国民经济和社会发展第十五个五年规划的建议》**。
- 二十届历次中全会：一中（**2022年10月**，选举产生新一届中央领导机构）；二中（**2023年2月**，审议通过《党和国家机构改革方案》）；三中（**2024年7月**，审议通过《关于进一步全面深化改革、推进中国式现代化的决定》）。
- **"十五五"时期定位**：**基本实现社会主义现代化夯实基础、全面发力的关键时期**，在基本实现社会主义现代化进程中具有**承前启后**的重要地位。
- 我国长期向好四大优势：**中国特色社会主义制度优势、超大规模市场优势、完整产业体系优势、丰富人才资源优势**。
- **"十五五"六大原则**：坚持**党的全面领导、人民至上、高质量发展、全面深化改革、有效市场和有为政府相结合、统筹发展和安全**。
- **"十五五"经济社会发展的主题**：推动**高质量发展**。
- **2035年目标**：经济实力、科技实力、国防实力、综合国力和国际影响力大幅跃升，**人均国内生产总值达到中等发达国家水平**，基本实现社会主义现代化。
- **12项重大部署之首**：建设**现代化产业体系**——把发展经济的着力点放在**实体经济**上，坚持**智能化、绿色化、融合化**方向；现代化产业体系是**中国式现代化的物质技术基础**。
- 科技部署：**加快高水平科技自立自强，引领发展新质生产力**；建设强大国内市场要坚持**扩大内需**这个**战略基点**。
- 人事：全会决定增补**张升民**为中共中央军事委员会副主席。

::: details 答案

- **弹性退休制度**：《实施弹性退休制度暂行办法》自**2025年1月1日**起施行；可自愿弹性提前退休，提前最长不超过**3年**，且不得低于原法定退休年龄（女**50、55周岁**，男**60周岁**）。
- 习近平参加**江苏代表团**审议（3月5日）：圆满实现"十四五"发展目标，**经济大省要挑大梁**。
- 中央政治局**第二十次集体学习**（4月25日，主题：加强人工智能发展和监管）：发挥**新型举国体制**优势，推动人工智能朝着**有益、安全、公平**方向健康有序发展。
- **中华全国总工会成立100周年**（4月28日表彰大会）：我国工人阶级是——中国共产党**最坚实最可靠的阶级基础**、社会主义国家的**领导阶级**、先进生产力和生产关系的代表、坚持和发展中国特色社会主义的**主力军**。
- **故宫博物院建院100周年**（10月27日参观展览）：故宫博物院承载着中华民族的**文化基因**，是**中华文明的一个重要标识**。

- **双拥工作**：拥军优属、拥政爱民是我党我军我国人民优良传统和**特有政治优势**。
