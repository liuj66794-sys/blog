## 03正文精讲

## 第一节 首要的基本的理论问题和精髓

::: info 本节指引 · 第一节 首要的基本的理论问题和精髓

- **目标**：背出社会主义本质论断的原文与两方面理解，说清“什么是社会主义、怎样建设社会主义”为什么是首要的基本的理论问题，并说明解放思想、实事求是为什么是邓小平理论的精髓。
- **建议用时**：13 分钟
- **知识点**：`邓小平理论首要的基本的理论问题与社会主义本质论` `邓小平理论的精髓：解放思想、实事求是`

:::

::: info 社会主义本质论

- **白话**：先问：社会主义到底是什么？邓小平用五句话回答——解放生产力、发展生产力、消灭剥削、消除两极分化、最终达到共同富裕。前两句讲生产力，后三句讲生产关系与目标。
- **教材表述**：首要的基本的理论问题是在中国这样一个经济文化比较落后的国家“建设什么样的社会主义、怎样建设社会主义”，搞清楚这一问题的关键是在坚持社会主义基本制度的基础上进一步认清社会主义的本质。认识过程：1980.5 邓小平第一次提出“社会主义的本质”这个概念；1985.8 讲对内搞活经济是活了社会主义、没有伤害社会主义的本质；1986.9 讲社会主义原则第一是发展生产、第二是共同致富；1988.5 讲社会主义的特点不是穷而是富、但这种富是人民共同富裕；1990.12 讲社会主义最大的优越性就是共同富裕；1992 年初南方谈话作出总结性的理论概括。本质论断（原文背诵）：“社会主义的本质，是解放生产力，发展生产力，消灭剥削，消除两极分化，最终达到共同富裕。”两方面理解：从生产力角度，突出强调解放和发展生产力的重要地位，纠正了过去关于发展生产力的错误观念，明确社会主义基本制度建立后还要通过改革进一步解放生产力（“应该把解放生产力和发展生产力两个讲全了”）；从生产关系与发展目标角度，突出强调消灭剥削、消除两极分化、最终达到共同富裕，只有在坚持公有制和按劳分配为主体的条件下才能实现，体现社会主义发展的价值目标，是发展手段和发展目的的统一。两条根本原则：一是以社会主义公有制经济为主体，一是共同富裕。
- **情境**：用它解释“为什么不能离开生产力抽象地谈论社会主义”：过去把许多束缚生产力发展、并不具有社会主义本质属性的东西当作“社会主义原则”加以固守，把许多在社会主义条件下有利于生产力发展的东西当作“资本主义复辟”加以反对——本质论断正是针对这一历史教训，把生产力与共同富裕统一起来，为改革开放扫清了思想障碍。
- **易混区别**：①“社会主义的本质”这一概念 1980 年 5 月第一次提出，而本质论断的完整概括在 1992 年南方谈话，两个时间不能互换；②本质论包含生产力与生产关系、目标两方面，只答“解放和发展生产力”不完整；③精髓（解放思想、实事求是）与首要的基本的理论问题（什么是社会主义、怎样建设社会主义）常被互换设错。
- **答题关键词**：1980.5 首次提出“社会主义的本质”概念、1992 南方谈话的总结性概括、解放生产力、发展生产力、消灭剥削、消除两极分化、最终达到共同富裕、手段与目的的统一、两条根本原则：公有制为主体、共同富裕

:::

::: info 从“名词”到“本质”：对社会主义本质的认识过程

1. **1980 年 5 月** 第一次提出“社会主义的本质”这个概念：“社会主义是一个很好的名词，但是如果搞不好，不能正确理解，不能采取正确的政策，那就体现不出社会主义的本质。”
2. **1985 年 8 月** “对内搞活经济，是活了社会主义，没有伤害社会主义的本质。”
3. **1986 年 9 月** “社会主义原则，第一是发展生产，第二是共同致富。”
4. **1988 年 5 月** “社会主义的特点不是穷，而是富，但这种富是人民共同富裕。”
5. **1990 年 12 月** 社会主义最大的优越性就是共同富裕，这是体现社会主义本质的一个东西。
6. **1992 年初 南方谈话** 作出总结性的理论概括：解放生产力，发展生产力，消灭剥削，消除两极分化，最终达到共同富裕。

:::

::: info 解放思想、实事求是（邓小平理论的精髓）

- **白话**：精髓就是那条贯穿始终、最能体现理论本质的东西：先解开思想的扣子（解放思想），再按实际情况办事（实事求是）。
- **教材表述**：精髓指能使理论得以形成和发展并贯穿始终、同时又体现在理论中最本质的东西——解放思想、实事求是是邓小平理论的精髓。背景是破除“两个凡是”（“凡是毛主席作出的决策，我们都坚决维护；凡是毛主席的指示，我们都始终不渝地遵循”），邓小平支持和领导真理标准问题讨论，指出“是个思想路线问题，是个政治问题，是个关系到党和国家的前途和命运的问题”。思想路线重新确立解决了四个问题：①有力推动和保证了拨乱反正——十一届三中全会批评“两个凡是”，作出把工作重点转移到社会主义现代化建设上来的战略决策，邓小平《解放思想，实事求是，团结一致向前看》实际上是三中全会的主题报告，是开辟新时期新道路的宣言书；②破除僵化的社会主义模式观念，坚持走自己的路；③一切从社会主义初级阶段的实际出发；④坚持“三个有利于”作为检验一切工作是非得失的根本标准。解放思想与实事求是辩证统一：只有解放思想才能达到实事求是，只有实事求是才是真正的解放思想；解放思想就是在马克思主义指导下打破习惯势力和主观偏见的束缚，研究新情况、解决新问题。
- **情境**：用它的实践成果检验理解：科学评价毛泽东、维护毛泽东思想的历史地位；从初级阶段实际出发确立基本路线、开创中国特色社会主义；在家庭联产承包责任制、发展乡镇企业、创办经济特区、引进外资、提出社会主义市场经济理论等问题上实现思想解放——改革开放的每一步都是“解放思想、实事求是”的产物。
- **易混区别**：①邓小平理论的形成过程节点（十一届三中全会、十二大、十三大、南方谈话、十五大）与精髓解决的四个问题是两组内容，别混答；②“两个凡是”是要破除的对象，不要写成党的主张；③解放思想的两种情况（对原先认识进行再认识；在研究新情况、解决新问题、总结新经验的基础上形成新的正确认识）是理解其含义的抓手。
- **答题关键词**：精髓、破除“两个凡是”、真理标准问题讨论、《解放思想，实事求是，团结一致向前看》是开辟新时期新道路的宣言书、四个问题、辩证统一

:::

::: tip 解放思想与实事求是像“先解开绳结，再照着尺子量”

| 本概念 | 类比为 |
| --- | --- |
| 解放思想 | 先把捆在身上的旧绳子解开——打破习惯势力和主观偏见的束缚 |
| 实事求是 | 再拿尺子按实际情况量——一切从实际出发，按规律办事 |
| 二者辩证统一 | 不解开绳子量不了；不照着量，解开绳子也没用 |
| 四个问题的解决 | 绳结解开后办成的四件事：拨乱反正、走自己的路、从初级阶段出发、用三个有利于作标准 |

**局限**：类比只能帮你记住“先破束缚、再按实际”的先后与统一关系；考试要写的是精髓的标准表述、思想路线重新确立解决的四个问题与相关文献名，不能写“解绳子”“量尺子”。

:::

### 一、邓小平理论首要的基本的理论问题

**1. 问题是什么**⭐⭐⭐

- 在中国这样一个经济文化比较落后的国家，**建设什么样的社会主义、怎样建设社会主义**——这是首要的基本的理论问题。"老祖宗"没有讲过，马克思、恩格斯没有提供现成的答案；列宁探索过但苏联模式出现很多弊端；毛泽东的探索既有巨大成就也出现不少失误。
- 邓小平："我们建设社会主义的方向是完全正确的，但什么叫社会主义，怎样建设社会主义，还在摸索之中"，并反复强调必须首先搞清楚这个问题。
- 搞清楚这一问题的**关键**：在坚持社会主义基本制度的基础上**进一步认清社会主义的本质**。
- 历史教训：不能离开生产力抽象地谈论社会主义——把许多束缚生产力发展、并不具有社会主义本质属性的东西当作"社会主义原则"加以固守，把许多在社会主义条件下有利于生产力发展的东西当作"资本主义复辟"加以反对。

**2. 对社会主义本质的认识过程**⭐⭐

| 时间 | 邓小平的推进 |
| --- | --- |
| **1980.5** | **第一次提出"社会主义的本质"这个概念**："社会主义是一个很好的名词，但是如果搞不好，不能正确理解，不能采取正确的政策，那就体现不出社会主义的本质" |
| 1985.8 | "对内搞活经济，是活了社会主义，没有伤害社会主义的本质" |
| 1986.9 | "社会主义原则，第一是发展生产，第二是共同致富" |
| 1988.5 | "社会主义的特点不是穷，而是富，但这种富是人民共同富裕" |
| 1990.12 | 社会主义**最大的优越性就是共同富裕**，这是体现社会主义本质的一个东西 |
| **1992 年初南方谈话** | 作出**总结性的理论概括**（见下） |

**3. 社会主义本质论断（原文背诵）**⭐⭐⭐

> &lt;p&gt;"社会主义的本质，是解放生产力，发展生产力，消灭剥削，消除两极分化，最终达到共同富裕。"&lt;/p&gt;

**4. 两方面理解（必背）**⭐⭐⭐

| 角度 | 内容 | 要点 |
| --- | --- | --- |
| 生产力 | 突出强调**解放和发展生产力**的重要地位 | 纠正了过去关于发展生产力的错误观念；明确了社会主义基本制度建立后**还要通过改革进一步解放生产力**——"应该把解放生产力和发展生产力两个讲全了"，这是对社会主义的新认识 |
| 生产关系+目标 | 突出强调"**消灭剥削，消除两极分化，最终达到共同富裕**" | 消灭剥削、消除两极分化只有在坚持**公有制和按劳分配为主体**的条件下才能实现；发展成果由全体社会成员共享而非少数人享有；体现社会主义发展的价值目标，是**发展手段和发展目的的统一**；为坚持和完善公有制指明方向 |

- 两条根本原则："在改革中，我们始终坚持两条根本原则，一是以社会主义公有制经济为主体，一是共同富裕。"
- 意义（4 句）：**继承了**科学社会主义的基本原则，**反映了**人民的利益和时代的要求，**深化了**对科学社会主义的认识，**推进了**改革开放的伟大实践。

### 二、邓小平理论的精髓：解放思想、实事求是

**1. 为什么是精髓**⭐⭐

- 精髓指能使理论得以形成和发展并贯穿始终、同时又体现在理论中最本质的东西。**解放思想、实事求是，是邓小平理论的精髓**。
- 毛泽东在新民主主义革命时期确立了实事求是的思想路线，保证了革命和改造的胜利；但党没能始终如一坚持，社会主义建设探索出现曲折。邓小平："一个党，一个国家，一个民族，如果一切从本本出发，思想僵化，迷信盛行，那它就不能前进，它的生机就停止了，就要亡党亡国。"
- 背景：破除"**两个凡是**"（"凡是毛主席作出的决策，我们都坚决维护；凡是毛主席的指示，我们都始终不渝地遵循"）；邓小平支持和领导**真理标准问题讨论**——"是个思想路线问题，是个政治问题，是个关系到党和国家的前途和命运的问题"。

**2. 思想路线重新确立解决的四个问题**⭐⭐⭐

| 序号 | 解决的问题 | 关键点 |
| --- | --- | --- |
| ① | 有力推动和保证了**拨乱反正** | 十一届三中全会批评"两个凡是"，作出把工作重点转移到社会主义现代化建设上来的战略决策；邓小平《解放思想，实事求是，团结一致向前看》（1978.12 中央工作会议闭幕会讲话）**实际上是三中全会的主题报告**，是开辟新时期新道路的**宣言书** |
| ② | 破除僵化的社会主义模式观念，坚持**走自己的路** | "把马克思主义的普遍真理同我国的具体实际结合起来，走自己的道路，建设有中国特色的社会主义"——总结长期历史经验得出的基本结论 |
| ③ | 一切从**社会主义初级阶段**的实际出发 | 我国处于并将长期处于社会主义初级阶段，"一切都要从这个实际出发，根据这个实际来制订规划" |
| ④ | 坚持**"三个有利于"**作为检验一切工作是非得失的根本标准 | 破除了离开发展生产力抽象谈论姓"社"姓"资"的思维定势 |

**3. 解放思想与实事求是的辩证统一**⭐

- 只有解放思想才能达到实事求是，只有实事求是才是真正的解放思想。
- 解放思想的定义："在马克思主义指导下打破习惯势力和主观偏见的束缚，研究新情况，解决新问题"；"就是使思想和实际相符合，使主观和客观相符合，就是实事求是"。
- 解放思想的两种情况：一是对原先认识进行**再认识**（坚持正确部分+纠正错误部分）；二是在研究新情况、解决新问题、总结新经验的基础上**形成新的正确认识**。
- 实践成果：科学评价毛泽东、维护毛泽东思想的历史地位；从初级阶段实际出发确立基本路线、开创中国特色社会主义；在家庭联产承包责任制、发展乡镇企业、创办经济特区、引进外资、提出社会主义市场经济理论等问题上实现思想解放。

## 第二节 邓小平理论的主要内容

::: info 社会主义初级阶段理论与党的基本路线

- **白话**：初级阶段有两层意思：我们已经是社会主义（不能离开），但还处在初级阶段（不能超越）。基本路线就是在这个判断上定下来的总方向：一个中心、两个基本点。
- **教材表述**：初级阶段理论提出过程：1981.6 十一届六中全会《历史决议》提出“我们的社会主义制度还是处于初级的阶段”；1982.9 十二大、1986.9 十二届六中全会作进一步分析；十三大前夕邓小平讲初级阶段就是“不发达的阶段”，“一切都要从这个实际出发”——第一次把社会主义初级阶段作为事关全局的基本国情加以把握；党的十三大系统阐述社会主义初级阶段的科学内涵；1997.9 党的十五大进一步概括初级阶段九个方面的特征，强调这是中国最大的实际。两层含义：第一，我国社会已经是社会主义社会，必须坚持而不能离开社会主义（阐明社会性质）；第二，我国的社会主义社会还处在初级阶段，必须从这个实际出发而不能超越这个阶段（阐明发展程度）。基本路线（党的十三大提出，原文背诵）：“领导和团结全国各族人民，以经济建设为中心，坚持四项基本原则，坚持改革开放，自力更生，艰苦创业，为把我国建设成为富强、民主、文明的社会主义现代化国家而奋斗。”要素拆解：奋斗目标是建设富强、民主、文明的社会主义现代化国家；基本途径是“一个中心、两个基本点”（最主要内容）——以经济建设为中心回答根本任务问题，四项基本原则回答政治保证问题，改革开放回答发展动力和外部条件问题；领导力量和依靠力量是领导和团结全国各族人民；根本立足点是自力更生、艰苦创业。三句话定位：以经济建设为中心是兴国之要，四项基本原则是立国之本、党和国家生存发展的政治基石，改革开放是强国之路、发展进步的活力源泉；党的基本路线是国家的生命线、人民的幸福线。
- **情境**：用它辨析“兴国之要／立国之本／强国之路”这组固定搭配：以经济建设为中心是兴国之要（党在新时期实现的最根本的拨乱反正）；四项基本原则（1979.3《坚持四项基本原则》讲话提出：坚持社会主义道路、人民民主专政、共产党的领导、马列主义毛泽东思想）是立国之本；改革开放是强国之路。三句话互换就是对经典的破坏。
- **易混区别**：①初级阶段两层含义缺一不可，“离开社会主义”与“超越阶段”都是错误倾向；②首次提出初级阶段论断是 1981.6 十一届六中全会《历史决议》，系统阐述科学内涵是十三大，两者不是同一次会议；③四项基本原则提出于 1979 年 3 月，不要与十一届三中全会（1978.12）混。
- **答题关键词**：两层含义（社会性质／发展程度）、十三大系统阐述、基本路线原文、一个中心、两个基本点是基本途径、兴国之要／立国之本／强国之路

:::

::: info 根本任务与发展战略（三步走、科学技术是第一生产力）

- **白话**：根本任务就一句话：发展生产力。怎么发展？靠科技（第一生产力），按三步走（温饱→小康→基本实现现代化），先让一部分地区一部分人富起来，最终走向共同富裕。
- **教材表述**：根本任务是发展生产力：生产力是社会发展的最根本的决定性因素，社会主义制度优越性的根本表现就是能够允许社会生产力以旧社会所没有的速度迅速发展；“发展才是硬道理”体现在维护世界和平、振兴中华、坚持和完善社会主义制度、保持稳定、发展民主法制、加强精神文明、和平统一祖国等方面。科学技术是第一生产力：1978.3 全国科学大会讲“四个现代化，关键是科学技术的现代化”；1988.9 提出“马克思讲过科学技术是生产力，这是非常正确的，现在看来这样说可能不够，恐怕是第一生产力”；南方谈话再次明确。三步走战略：第一步到 1990 年国民生产总值比 1980 年翻一番、解决人民温饱问题；第二步到 2000 年再翻一番、人民生活达到小康水平；第三步到 21 世纪中叶达到中等发达国家水平、人民生活比较富裕、基本实现现代化。“小康”概念来自 1979.12 邓小平会见日本首相大平正芳时用“小康之家”阐释“中国式的现代化”，党的十三大把“小康社会”思想和“三步走”发展战略确定下来。三个战略重点（1982.9）：农业、能源和交通、教育和科学。“先富”带“共富”的出发点和落脚点是共同富裕；“两个大局”指沿海先发展起来带动内地发展、发展到一定时候沿海拿出更多力量帮助内地发展。
- **情境**：用它辨析两个“第一”：科学技术是第一生产力（1988.9 提出）、发展是党执政兴国的第一要务（“三个代表”重要思想中提出）——前者讲生产力要素，后者讲党执政的任务，别把两个“第一”串在一起。
- **易混区别**：①“科学技术是第一生产力”的提出时间是 1988 年 9 月，1978 年全国科学大会讲的是“科学技术是生产力”和“四个现代化关键是科学技术的现代化”，别把 1978 年当成“第一生产力”的提出时间；②共同富裕不等于同步富裕、平均富裕；③三步走是“解决温饱→达到小康→基本实现现代化”，第三、四步（十六大以后的“新三步走”）不是邓小平理论里的表述。
- **答题关键词**：发展才是硬道理、1988.9“恐怕是第一生产力”、三步走（1990 温饱→2000 小康→21 世纪中叶基本实现现代化）、小康之家（1979.12 大平正芳）、三个战略重点、两个大局

:::

::: info 改革开放与社会主义市场经济理论

- **白话**：改革是“第二次革命”，但改的是体制、不是制度——是社会主义制度的自我完善。市场经济不是资本主义的专利，计划和市场都是手段；市场化改革的目标在十四大正式确立。
- **教材表述**：改革是一场深刻的社会变革，是中国的第二次革命，但不是一个阶级推翻另一个阶级那种原来意义上的革命，不是也不允许否定和抛弃社会主义基本制度，而是社会主义制度的自我完善和发展；改革是社会主义社会发展的直接动力。“三个有利于”标准：是否有利于发展社会主义社会的生产力（首要的也是最根本的一条）、是否有利于增强社会主义国家的综合国力、是否有利于提高人民的生活水平。对外开放：开放也是改革，对外开放是建设中国特色社会主义的一项基本国策；1980.12 邓小平使用“对外开放”表述，1984.10 党的十二届三中全会把实行对外开放作为基本国策；依据是“现在的世界是开放的世界，中国的发展离不开世界”。社会主义市场经济理论的形成过程：1981 十一届六中全会提出“计划经济为主、市场调节为辅”；1984 十二届三中全会《中共中央关于经济体制改革的决定》提出社会主义经济是“公有制基础上的有计划的商品经济”；1987 十三大提出“计划与市场内在统一的体制”“国家调节市场，市场引导企业”；1992 南方谈话提出“计划经济不等于社会主义，资本主义也有计划；市场经济不等于资本主义，社会主义也有市场。计划和市场都是经济手段”，标志着理论的形成；党的十四大明确把建立社会主义市场经济体制作为我国经济体制改革的目标。三点内涵：计划经济和市场经济不是划分社会制度的标志；计划和市场都是经济手段，各有优劣，要把两者优势结合起来；市场经济作为资源配置手段本身不具有制度属性，可以和不同的社会制度结合。
- **情境**：用它区分两个易混提法：1984 年十二届三中全会提出的是“公有制基础上的有计划的商品经济”（不再把计划经济同商品经济对立起来，是社会主义经济理论的重大突破）；1992 年党的十四大明确的是把“建立社会主义市场经济体制”作为经济体制改革的目标——前者讲商品经济的性质，后者讲体制改革的目标。
- **易混区别**：①“三个有利于”的第一条是“发展社会主义社会的生产力”，不是综合国力或生活水平；②改革是第二次革命，但绝不能说改革要否定社会主义基本制度；③基本路线的原文与市场经济理论的节点（1981／1984／1987／1992／十四大）是两套内容，答题别混。
- **答题关键词**：第二次革命＝社会主义制度的自我完善和发展、三个有利于（生产力是首要的最根本的）、1984 有计划的商品经济、1992 南方谈话＝理论形成、十四大确立经济体制改革目标、市场经济不具有制度属性

:::

::: info “和平统一、一国两制”的基本内容

- **白话**：五条要点，核心只有一条：坚持一个中国。其他四条（两制并存、高度自治、争取和平但不承诺放弃使用武力、寄希望于台湾人民）都建立在这条之上。
- **教材表述**：一个中国是核心问题，是发展两岸关系和实现和平统一的基础；两制并存指国家的主体部分实行社会主义制度，港澳台保持原有的社会制度和生活方式长期不变；高度自治指特别行政区享有不同于中国其他省、市、自治区的高度自治权；尽最大努力争取和平统一，但不承诺放弃使用武力（“不放弃使用武力，有利于促进和平解决”）；解决台湾问题、实现祖国完全统一寄希望于台湾人民。构想的形成过程：1979.1.1 全国人大常委会发表《告台湾同胞书》，宣示争取祖国和平统一的大政方针；1979.1 邓小平访美时表示“我们不再用‘解放台湾’这个提法了”；1981.9.30 叶剑英发表谈话阐明九条方针；1982.1 邓小平指出“九条方针实际上就是一个国家两种制度”，构想内容开始明晰化；1983.6 邓小平提出六条方针；1984.12 与 1987.4 中英、中葡分别签署关于香港、澳门问题的联合声明；1990.4 与 1993.3 全国人大分别通过香港、澳门特别行政区基本法。意义：把和平共处原则用于解决一个国家的统一问题；既体现坚持祖国统一、维护国家主权的原则性，又体现照顾历史实际和现实可能的灵活性；是对马克思主义国家学说的创造性发展。
- **情境**：用它辨析台湾问题与港澳问题的性质：台湾问题是国内战争遗留问题、属于中国内政不容许外国干涉；港澳问题是历史上殖民主义侵略遗留的问题——性质不同，但解决方式上都适用“一国两制”，且政策上台湾还可以更宽。
- **易混区别**：①“一国两制”的核心是坚持一个中国，不是两制并存或高度自治；②“不承诺放弃使用武力”不等于放弃和平统一，恰恰是为了促进和平解决；③《告台湾同胞书》（1979.1.1）与叶剑英九条方针（1981.9.30）是两个文件，别混。
- **答题关键词**：坚持一个中国（核心）、两制并存、高度自治、不承诺放弃使用武力、寄希望于台湾人民、台湾问题＝内政，港澳问题＝殖民主义侵略遗留

:::

::: info 外交国际战略与党的建设

- **白话**：对外：时代主题是和平与发展，外交独立自主、真正不结盟，党际关系四条原则。对内：中国问题的关键在于党，思想、组织、作风、制度建设一起抓。
- **教材表述**：时代主题新判断：1985 年邓小平指出世界上真正大的问题、带全球性的战略问题，一个是和平问题，一个是经济问题或者说发展问题；和平问题是东西问题，发展问题是南北问题，南北问题是核心问题；1987 年党的十三大确认和平与发展是当今世界的两大主题；成为时代主题并不意味着这两个问题已经解决。外交政策的基本目标是维护我国的独立和主权、促进世界的和平与发展；中国的对外政策是独立自主的，是真正的不结盟；坚持在和平共处五项原则基础上建立和平、稳定、公正、合理的国际政治经济新秩序；党际关系四项原则是独立自主、完全平等、互相尊重、互不干涉内部事务；1989 年后确定“冷静观察、稳住阵脚、沉着应付、韬光养晦、有所作为、善于守拙、决不当头”的方针。党的建设：建设中国特色社会主义关键在于坚持、加强和改善党的领导；思想建设重视马克思主义理论学习，增强工作中的原则性、系统性、预见性和创造性；组织建设以民主集中制为根本组织制度和领导制度（最重要的是全党服从中央），干部队伍坚持“革命化、年轻化、知识化、专业化”方针；作风建设强调执政党的党风关系党的生死存亡，坚持反腐败斗争；制度建设强调领导制度、组织制度问题更带有根本性、全局性、稳定性和长期性，党必须在宪法和法律范围内活动。
- **情境**：用它辨析“时代主题”的两句判断：和平与发展是当今世界的两大主题，其中南北问题（发展问题）是核心问题；判断的四个基本点还包括“世界大战在一个相当长的时期内可以避免，有可能争取较长时期的和平环境”“成为时代主题并不意味着这两个问题已经解决”。
- **易混区别**：①时代主题是邓小平 1985 年提出、1987 年十三大确认，别写成“一直就是”；②党际关系四项原则（独立自主、完全平等、互相尊重、互不干涉内部事务）与和平共处五项原则是两组内容；③党的建设四个方面（思想、组织、作风、制度）要与“三个代表”重要思想里的党建内容区分开。
- **答题关键词**：和平与发展是当今世界的两大主题（1985 提出、1987 十三大确认）、南北问题是核心问题、真正的不结盟、和平共处五项原则、党际关系四项原则、关键在于党·四个建设

:::

主要内容七个方面：①社会主义初级阶段理论和党的基本路线；②社会主义根本任务和发展战略理论；③社会主义改革开放和社会主义市场经济理论；④"两手抓，两手都要硬"；⑤"一国两制"与祖国统一；⑥中国特色社会主义外交和国际战略；⑦中国问题的关键在于党。

### 一、社会主义初级阶段理论和党的基本路线⭐⭐⭐

**1. 初级阶段理论的提出过程**

| 时间/会议 | 进展 |

| 1981.6 十一届六中全会《历史决议》 | 提出"**我们的社会主义制度还是处于初级的阶段**" |
| 1982.9 十二大、1986.9 十二届六中全会 | 对这一阶段的内容作进一步分析 |
| 十三大前夕 | 邓小平：初级阶段就是"不发达的阶段"，"一切都要从这个实际出发"——**第一次把社会主义初级阶段作为事关全局的基本国情加以把握** |
| **党的十三大** | **系统阐述**社会主义初级阶段的科学内涵 |
| 1997.9 党的十五大 | 进一步概括初级阶段的特征（九个方面），强调这是中国**最大的实际** |

**2. 两层含义与长期性（必背）**⭐⭐⭐

- 第一，我国社会**已经是社会主义社会**——必须坚持而不能离开社会主义（阐明初级阶段的**社会性质**）；
- 第二，我国的社会主义社会**还处在初级阶段**——必须从这个实际出发，而不能超越这个阶段（阐明**发展程度**）。两层含义不可分割，必须全面把握。
- 长期性：不是泛指任何国家进入社会主义都会经历的起始阶段，而是**特指我国在生产力落后、商品经济不发达条件下建设社会主义必然要经历的特定阶段**；南方谈话："巩固和发展社会主义制度，还需要一个很长的历史阶段，需要我们几代人、十几代人，甚至几十代人坚持不懈地努力奋斗。"
- 意义⭐⭐：基于对中国国情的准确把握，揭示了当代中国的历史方位，是建设中国特色社会主义的**总依据**，是对马克思主义关于社会主义发展阶段理论的重大发展和重大突破。

**3. 党的基本路线（原文背诵）**⭐⭐⭐

> &lt;p&gt;"领导和团结全国各族人民，以经济建设为中心，坚持四项基本原则，坚持改革开放，自力更生，艰苦创业，为把我国建设成为富强、民主、文明的社会主义现代化国家而奋斗。"（党的十三大提出）&lt;/p&gt;

**4. 要素拆解**⭐⭐⭐

| 要素 | 内容 | 地位 |
| --- | --- | --- |
| 奋斗目标 | 建设"富强、民主、文明的社会主义现代化国家" | 富强/民主/文明分别是经济、政治、思想文化领域的目标和要求 |
| 基本途径 | "一个中心、两个基本点"（**最主要内容**） | 以经济建设为中心回答**根本任务**问题；四项基本原则回答**政治保证**问题；改革开放回答**发展动力和外部条件**问题 |
| 领导力量和依靠力量 | 领导和团结全国各族人民 | 中国共产党是领导核心 |
| 根本立足点 | 自力更生，艰苦创业 | 体现社会主义的奋斗精神 |

- 三句话定位：以经济建设为中心是**兴国之要**（党在新时期实现的最根本的拨乱反正）；四项基本原则是**立国之本**、党和国家生存发展的**政治基石**（1979.3《坚持四项基本原则》讲话提出：坚持社会主义道路、人民民主专政、共产党的领导、马列主义毛泽东思想，是"实现四个现代化的根本前提"）；改革开放是**强国之路**、发展进步的**活力源泉**。党的基本路线是**国家的生命线、人民的幸福线**。
- 充实完善：十七大把"和谐"写入基本路线；十九大提出"为把我国建设成为富强民主文明和谐美丽的社会主义现代化强国而奋斗"。

### 二、社会主义根本任务和发展战略理论

**1. 根本任务：发展生产力**⭐⭐

- 依据：生产力是社会发展的最根本的决定性因素；1979.3 邓小平指出"我们的生产力发展水平很低，远远不能满足人民和国家的需要，这就是我们目前时期的主要矛盾"；1981.6《历史决议》明确主要矛盾是**人民日益增长的物质文化需要同落后的社会生产之间的矛盾**。
- 社会主义制度优越性的**根本表现**，就是能够允许社会生产力以旧社会所没有的速度迅速发展，使人民不断增长的物质文化生活需要能够逐步得到满足。
- **"发展才是硬道理"**：维护世界和平、振兴中华、坚持和完善社会主义制度、保持稳定、发展民主法制、加强精神文明、和平统一祖国——都离不开发展。

**2. 科学技术是第一生产力**⭐⭐⭐

- 1978.3 全国科学大会："四个现代化，关键是科学技术的现代化"；
- 1988.9："马克思讲过科学技术是生产力，这是非常正确的，现在看来这样说可能不够，恐怕是**第一生产力**"；南方谈话再次明确。
- 1986.3 王大珩、王淦昌、杨嘉墀、陈芳允四位科学家建议，邓小平批示、国务院批准《高技术研究发展计划（"863 计划"）纲要》。

**3. 分三步走基本实现现代化的发展战略**⭐⭐⭐

| 步骤 | 时间 | 目标 |
| --- | --- | --- |
| 第一步 | 到 1990 年 | 国民生产总值比 1980 年**翻一番**，解决人民的**温饱**问题 |
| 第二步 | 到 2000 年 | 国民生产总值**再翻一番**，人民生活达到**小康**水平 |
| 第三步 | 到 21 世纪中叶 | 达到**中等发达国家**水平，人民生活比较富裕，**基本实现现代化** |

- "小康"的提出：1979.12 邓小平会见日本首相大平正芳，用"小康之家"阐释"中国式的现代化"；党的十三大把"小康社会"思想和"三步走"发展战略确定下来。
- 三个战略重点（1982.9）：**农业、能源和交通、教育和科学**；农业"两个飞跃"——第一飞跃废除人民公社、实行家庭联产承包为主的责任制，第二飞跃适应科学种田和生产社会化需要、发展适度规模经营和集体经济。
- "台阶式"发展思想：抓住机遇，争取隔几年使国民经济上一个新台阶，讲求效益、稳步协调地发展。
- "先富"带"共富"：1978.12 把允许一部分地区、一部分人通过诚实劳动、合法经营先富起来作为大政策提出，**出发点和落脚点是共同富裕**；共同富裕决不等于完全平均，决不等于所有社会成员在同一时间以同等速度富裕起来。
- **"两个大局"**：沿海先发展起来带动内地发展（内地要顾全这个大局）；发展到一定时候沿海拿出更多力量帮助内地发展（沿海也要服从这个大局）。

### 三、社会主义改革开放和社会主义市场经济理论

**1. 改革开放理论**⭐⭐⭐

- 性质：改革是一场深刻的社会变革，是**中国的第二次革命**，"也是为了扫除发展社会生产力的障碍，使中国摆脱贫穷落后的状态"；但**不是一个阶级推翻另一个阶级那种原来意义上的革命**，不是也不允许否定和抛弃我们建立起来的社会主义基本制度，而是**社会主义制度的自我完善和发展**。
- 实质和目标：从根本上改变束缚我国生产力发展的经济体制，建立充满生机和活力的社会主义新经济体制，同时相应地改革政治体制和其他方面的体制。
- 改革是社会主义社会发展的**直接动力**（社会主义社会基本矛盾仍然是生产关系和生产力、上层建筑和经济基础之间的矛盾）；"要发展生产力，经济体制改革是必由之路"。
- **"三个有利于"标准**⭐⭐⭐：是否有利于发展社会主义社会的**生产力**（首要的也是最根本的一条）、是否有利于增强社会主义国家的**综合国力**、是否有利于提高人民**生活水平**。
- 对外开放：**开放也是改革**，对外开放是建设中国特色社会主义的一项**基本国策**，和改革一起成为新时期最鲜明的特征；1980.12 邓小平使用"对外开放"表述，1984.10 党的十二届三中全会把实行对外开放作为基本国策。
- 依据："现在的世界是开放的世界，中国的发展离不开世界"；两点强调：①大胆吸收和借鉴人类社会创造的一切文明成果，为我所用；②高度珍惜并坚决维护独立自主权利，始终把国家的主权和安全放在第一位。
- 评价：改革开放是决定中国命运的**关键一招**，也是实现中华民族伟大复兴的关键一招；改革开放只有进行时，没有完成时。

**2. 社会主义市场经济理论**⭐⭐⭐

| 时间/会议 | 认识推进 |
| --- | --- |
| 1981 十一届六中全会 | "计划经济为主、市场调节为辅"，为形成市场经济理论开辟道路 |
| 1984 十二届三中全会《中共中央关于经济体制改革的决定》 | 提出社会主义经济是"**公有制基础上的有计划的商品经济**"——不再把计划经济同商品经济对立起来，是社会主义经济理论的重大突破；邓小平称其是"马克思主义基本原理和中国社会主义实践相结合的政治经济学" |
| 1987 十三大 | "计划与市场内在统一的体制"，"国家调节市场，市场引导企业" |
| **1992 南方谈话** | "计划经济不等于社会主义，资本主义也有计划；市场经济不等于资本主义，社会主义也有市场。计划和市场都是经济手段。"——**标志着邓小平社会主义市场经济理论的形成** |
| 党的十四大 | 明确把**建立社会主义市场经济体制**作为我国经济体制改革的目标 |

- 三点内涵⭐⭐：①计划经济和市场经济**不是划分社会制度的标志**；②计划和市场都是**经济手段**，对经济活动的调节各有优劣，要把两者优势结合起来；③市场经济作为资源配置手段**本身不具有制度属性**，可以和不同的社会制度结合——坚持社会主义制度与市场经济的结合，是社会主义市场经济的特色所在、优势所在。
- 意义：实现了马克思主义政治经济学的重大创新；社会主义市场经济是**中国共产党的一个伟大创举**，是我国经济体制改革在实践和理论上的重大突破。

### 四、"两手抓，两手都要硬"⭐⭐

- **社会主义精神文明是社会主义社会的重要特征**；针对"一手硬、一手软"的倾向，强调**两个文明都搞好才是有中国特色的社会主义**。
- 精神文明的内涵：不但指教育、科学、文化，而且指共产主义的思想、理想、信念、道德、纪律，革命的立场和原则，人与人的同志式关系等。
- 三层强调：①不但要有高度的物质文明，而且要有高度的精神文明（不建设精神文明同样会葬送社会主义）；②两个文明建设**相辅相成、相互促进**（"风气如果坏下去，经济搞成功又有什么意义"）；③精神文明**重在建设**，不但要"抓"并且要"硬"。
- 1986.9 党的十二届六中全会：以经济建设为中心，坚定不移地进行经济体制改革、政治体制改革，坚定不移地加强精神文明建设——初步形成社会主义现代化建设"**三位一体**"的总体布局。
- 系列两手抓：①"**一手抓建设，一手抓法制**"——发展社会主义民主必须同健全社会主义法制紧密结合，做到有法可依、有法必依、执法必严、违法必究；②"**一手抓改革开放，一手抓惩治腐败**"——"在整个改革开放过程中都要反对腐败""还是要靠法制，搞法制靠得住些"。
- 意义：坚持了辩证法的全面性，坚持了**两点论和重点论的统一**，为党的领导方法和工作方法充实了新的内容。

### 五、"一国两制"与祖国统一⭐⭐⭐

**1. 构想的形成过程**

| 时间 | 事件 |
| --- | --- |
| 1979.1.1 | 全国人大常委会发表《**告台湾同胞书**》，宣示争取祖国和平统一的大政方针；解放军停止对金门等岛屿炮击 |
| 1979.1 | 邓小平访美："我们不再用'解放台湾'这个提法了" |
| 1981.9.30 | 叶剑英发表谈话，阐明台湾回归祖国、实现和平统一的**九条方针** |
| 1982.1 | 邓小平："九条方针实际上就是一个国家两种制度"——"一国两制"构想内容**开始明晰化** |
| 1983.6 | 邓小平提出祖国统一的**六条方针** |
| 1984.12 / 1987.4 | 中英、中葡两国政府分别签署关于香港、澳门问题的联合声明 |
| 1990.4 / 1993.3 | 全国人大分别通过《香港特别行政区基本法》《澳门特别行政区基本法》 |

- 构想从解决**台湾问题**开始，进而扩展到解决香港、澳门问题；台湾问题是**国内战争遗留**问题、属于中国内政不容许外国干涉；港澳问题是**历史上殖民主义侵略遗留**的问题。

**2. "和平统一、一国两制"的基本内容（5 条必背）**⭐⭐⭐

1. **坚持一个中国**——这是核心，是发展两岸关系和实现和平统一的基础；
2. **两制并存**——国家的主体部分实行社会主义制度，港澳台保持原有的社会制度和生活方式长期不变；
3. **高度自治**——特别行政区享有不同于中国其他省、市、自治区的高度自治权；
4. **尽最大努力争取和平统一，但不承诺放弃使用武力**——"不放弃使用武力，有利于促进和平解决"；
5. 解决台湾问题、实现祖国完全统一，**寄希望于台湾人民**。

**3. 意义**⭐：把和平共处原则用于解决一个国家的统一问题；既体现坚持祖国统一、维护国家主权的**原则性**，又体现照顾历史实际和现实可能的**灵活性**；是**对马克思主义国家学说的创造性发展**；港澳回归洗雪了中华民族百年屈辱。

### 六、中国特色社会主义外交和国际战略⭐⭐

- **时代主题新判断**：1985 年邓小平指出："现在世界上真正大的问题，带全球性的战略问题，一个是和平问题，一个是经济问题或者说发展问题。和平问题是东西问题，发展问题是南北问题。概括起来，就是东西南北四个字。**南北问题是核心问题**。"1987 年党的十三大确认**和平与发展是当今世界的两大主题**。
- 判断的四个基本点：①世界大战在一个相当长的时期内可以避免，有可能争取较长时期的和平环境；②和平与发展是两大带有全球性的战略问题，是东西方、南北矛盾全局的集中体现；③两者相辅相成；④成为时代主题**并不意味着这两个问题已经解决**。
- 外交政策的基本目标：**维护我国的独立和主权，促进世界的和平与发展**；中国的对外政策是独立自主的，是**真正的不结盟**；"谁搞霸权就反对谁，谁搞战争就反对谁"。
- 坚持在**和平共处五项原则**（互相尊重主权和领土完整、互不侵犯、互不干涉内政、平等互利、和平共处）基础上，建立和平、稳定、公正、合理的国际政治经济新秩序。
- 党际关系"四项原则"：**独立自主、完全平等、互相尊重、互不干涉内部事务**。
- 1989 年后国际局势风云变幻，确定"**冷静观察、稳住阵脚、沉着应付、韬光养晦、有所作为、善于守拙、决不当头**"的方针。

### 七、中国问题的关键在于党（党的建设理论）⭐

- "没有中国共产党，就没有社会主义的新中国"；建设中国特色社会主义，关键在于坚持、加强和**改善**党的领导；把党建设成为"有战斗力的马克思主义政党"，成为领导全国人民进行社会主义物质文明和精神文明建设的坚强核心。

| 建设 | 要点 |
| --- | --- |
| 思想建设 | 重视马克思主义理论学习，增强工作中的**原则性、系统性、预见性和创造性** |
| 组织建设 | **民主集中制**是党的根本组织制度和领导制度（最重要的是**全党服从中央**）；干部队伍"**革命化、年轻化、知识化、专业化**"方针 |
| 作风建设 | 执政党的党风**关系党的生死存亡**；坚持反腐败斗争，把它摆在党风建设的突出位置 |
| 制度建设 | 领导制度、组织制度问题**更带有根本性、全局性、稳定性和长期性**；废除实际存在的干部领导职务终身制；党必须在宪法和法律范围内活动 |

- 其他思想：依靠力量——广大工人、农民、知识分子，全体社会主义劳动者、拥护社会主义的爱国者和拥护祖国统一的爱国者的最广泛的统一战线；人民军队——坚持**党对军队的绝对领导**。

## 05易错点辨析

1. **精髓 ≠ 首要的基本的理论问题**——精髓是"解放思想、实事求是"；首要的基本的理论问题是"什么是社会主义、怎样建设社会主义"，两者常被互换设错。
2. **社会主义本质 ≠ 根本任务**——本质是五句完整表述（含生产关系与发展目标）；根本任务是发展生产力。答本质只写"解放和发展生产力"不完整。
3. **"科学技术是第一生产力"的提出时间**——1978 全国科学大会讲的是"科学技术是生产力""四个现代化关键是科学技术现代化"；1988.9 才提出"恐怕是第一生产力"，南方谈话再次明确，别把 1978 年当成"第一生产力"的提出时间。
4. **初级阶段两层含义缺一不可**——只答"已经是社会主义社会"或只答"还处在初级阶段"都错；前者阐明社会性质、后者阐明发展程度；"离开社会主义"与"超越阶段"都是错误倾向。
5. **改革 ≠ 原来意义上的革命**——"第二次革命"是从扫除生产力障碍、根本变革体制的意义上讲的；改革不是也不允许否定和抛弃社会主义基本制度，而是社会主义制度的**自我完善和发展**。
6. **计划/市场 ≠ 社会制度属性**——计划经济不等于社会主义，市场经济不等于资本主义，两者都是经济手段；市场经济作为资源配置手段本身不具有制度属性，可以和不同社会制度结合。
7. **共同富裕 ≠ 同步、平均富裕**——先富是手段、共富是大原则；共同富裕决不等于也不可能是完全平均，决不等于所有社会成员在同一时间以同等速度富裕起来。
8. **台湾问题与港澳问题性质不同**——台湾问题是国内战争遗留下来的问题、属于中国内政不容外国干涉；港澳问题是历史上殖民主义侵略遗留的问题；在香港澳门实行的政策原则上适用于台湾，且政策还可以更宽。
9. **"不承诺放弃使用武力" ≠ 放弃和平统一**——要尽一切力量争取用和平方式解决台湾问题；"不放弃使用武力，有利于促进和平解决"。
10. **和平与发展成为主题 ≠ 这两个问题已经解决**——"当今世界和平与发展这两大问题一个都没有得到解决，还需要各国人民长期不懈地共同努力"。

**答案：B**

**逐选项解析**

- A ❌ 两制并存是国家主体部分实行社会主义制度、港澳台保持原有社会制度和生活方式长期不变——它是重要内容，但前提是“一个中国”；离开一个中国，“两制”就无从谈起。
- B ✅ 坚持一个中国是“和平统一、一国两制”的核心，是发展两岸关系和实现和平统一的基础。来源：课件正文·第二节“和平统一、一国两制的基本内容”。
- C ❌ 高度自治指特别行政区享有不同于中国其他省、市、自治区的高度自治权——自治权来自中央授权，同样以“一个中国”为前提，不是核心。
- D ❌ 不承诺放弃使用武力是针对外国干涉和“台独”分裂势力的必要安排（“不放弃使用武力，有利于促进和平解决”），它是内容之一而非核心。

**对比自测**：做完后对照 mcq:3，比较两题的判断依据

**原文定位**（课件正文·第二节 一国两制基本内容）：坚持一个中国——这是核心，是发展两岸关系和实现和平统一的基础。

## 主观题支架

### qa:1

**要点**

- 本质论断原文（背诵）：“社会主义的本质，是解放生产力，发展生产力，消灭剥削，消除两极分化，最终达到共同富裕。”出自 1992 年初南方谈话。
- 生产力角度的理解：突出强调解放和发展生产力的重要地位，纠正了过去关于发展生产力的错误观念，明确社会主义基本制度建立后还要通过改革进一步解放生产力，把解放生产力和发展生产力“两个讲全了”。
- 生产关系与目标角度的理解：突出强调消灭剥削、消除两极分化、最终达到共同富裕；只有在坚持公有制和按劳分配为主体的条件下才能实现，体现了社会主义发展的价值目标，是发展手段和发展目的的统一。
- 两条根本原则：在改革中始终坚持两条根本原则——一是以社会主义公有制经济为主体，一是共同富裕。
- 理论意义（四句）：继承了科学社会主义的基本原则，反映了人民的利益和时代的要求，深化了对科学社会主义的认识，推进了改革开放的伟大实践。
- 可补充认识过程：1980.5 第一次提出“社会主义的本质”概念，1986.9 讲“第一是发展生产，第二是共同致富”，1990.12 讲共同富裕是社会主义最大的优越性，1992 年初作出总结性概括。

**推导**：先给原文，再分两个角度解释（生产力／生产关系与目标），最后落到意义四句。解释部分要写出“两个讲全了”“手段与目的的统一”“坚持公有制和按劳分配为主体”这些关键句，不要只把原文复述一遍。若题目问“理论意义”，四句要逐句写；若问“内容”，重点放在两方面理解。

**自评标准**

- [ ] 能一字不差地背出本质论断的五句原文并注明出自 1992 年南方谈话；
- [ ] 能从生产力与生产关系、目标两个角度分别解释，并写出“两个讲全了”；
- [ ] 能写出两条根本原则与“继承／反映／深化／推进”四句理论意义。

### qa:2

**要点**

- 精髓的含义：精髓指能使理论得以形成和发展并贯穿始终、同时又体现在理论中最本质的东西——解放思想、实事求是正是邓小平理论的精髓。
- 历史背景：破除“两个凡是”，邓小平支持和领导真理标准问题讨论，指出这是思想路线问题、政治问题，是关系到党和国家前途命运的问题。
- 解决的第一、二个问题：有力推动和保证了拨乱反正（十一届三中全会批评“两个凡是”，作出工作重点转移的战略决策，《解放思想，实事求是，团结一致向前看》实际上是三中全会的主题报告、是开辟新时期新道路的宣言书）；破除僵化的社会主义模式观念，坚持走自己的路。
- 解决的第三、四个问题：一切从社会主义初级阶段的实际出发；坚持“三个有利于”作为检验一切工作是非得失的根本标准。
- 辩证统一关系：只有解放思想才能达到实事求是，只有实事求是才是真正的解放思想；解放思想就是在马克思主义指导下打破习惯势力和主观偏见的束缚，研究新情况、解决新问题。
- 实践成果举例：科学评价毛泽东、维护毛泽东思想的历史地位；从初级阶段实际出发确立基本路线、开创中国特色社会主义；在家庭联产承包责任制、发展乡镇企业、创办经济特区、引进外资、社会主义市场经济理论等问题上实现思想解放。

**推导**：先答“精髓是什么”（含义＋判断），再答“为什么是精髓”（贯穿理论形成发展的始终、体现在理论最本质的地方），然后按四个问题展开思想路线重新确立的意义，最后用辩证统一关系与实践成果收尾。四个问题的表述要具体（拨乱反正、走自己的路、从初级阶段出发、三个有利于），不要只写编号。

**自评标准**

- [ ] 能写出精髓的含义（形成发展并贯穿始终、最本质的东西）；
- [ ] 四个问题能逐一写清，并知道《解放思想，实事求是，团结一致向前看》是开辟新时期新道路的宣言书；
- [ ] 能说明解放思想与实事求是的辩证统一关系，并至少举一个实践成果。

### qa:3

**要点**

- 基本路线原文（十三大提出，背诵）：“领导和团结全国各族人民，以经济建设为中心，坚持四项基本原则，坚持改革开放，自力更生，艰苦创业，为把我国建设成为富强、民主、文明的社会主义现代化国家而奋斗。”
- 奋斗目标：建设富强、民主、文明的社会主义现代化国家（富强／民主／文明分别是经济、政治、思想文化领域的目标和要求）。
- 基本途径：“一个中心、两个基本点”（最主要内容）——以经济建设为中心回答根本任务问题，四项基本原则回答政治保证问题，改革开放回答发展动力和外部条件问题。
- 领导力量和依靠力量：领导和团结全国各族人民，中国共产党是领导核心；根本立足点是自力更生、艰苦创业。
- 三句话定位：以经济建设为中心是兴国之要；四项基本原则是立国之本、党和国家生存发展的政治基石（1979.3《坚持四项基本原则》讲话提出）；改革开放是强国之路、发展进步的活力源泉。
- 党的基本路线是国家的生命线、人民的幸福线；十七大把“和谐”写入基本路线，十九大提出“为把我国建设成为富强民主文明和谐美丽的社会主义现代化强国而奋斗”。

**推导**：先背原文，再按四个要素拆解（奋斗目标／基本途径／领导力量和依靠力量／根本立足点），最后补三句话定位。原文是本问的采分主体，必须一字不错；拆解部分重点写“一个中心、两个基本点”各自回答什么问题，并带上兴国之要、立国之本、强国之路的固定搭配。

**自评标准**

- [ ] 能一字不差地背出基本路线原文；
- [ ] 四个要素齐全，且“一个中心、两个基本点”能各自对应根本任务、政治保证、发展动力与外部条件；
- [ ] 能准确写出兴国之要（以经济建设为中心）、立国之本（四项基本原则）、强国之路（改革开放）并注明四项基本原则提出于 1979 年 3 月。

### qa:4

**要点**

- 第一条：坚持一个中国——这是核心，是发展两岸关系和实现和平统一的基础。
- 第二条：两制并存——国家的主体部分实行社会主义制度，港澳台保持原有的社会制度和生活方式长期不变。
- 第三条：高度自治——特别行政区享有不同于中国其他省、市、自治区的高度自治权。
- 第四条：尽最大努力争取和平统一，但不承诺放弃使用武力（“不放弃使用武力，有利于促进和平解决”）。
- 第五条：解决台湾问题、实现祖国完全统一，寄希望于台湾人民。

**推导**：五条内容逐条写，第一条要点明“核心”与“基础”两个定位；第四、五条容易被漏掉，答题时按顺序清点一遍即可。若分值较高，最后补一句意义（原则性与灵活性的统一、对马克思主义国家学说的创造性发展）。

### qa:5

**要点**

- 形成过程：1981 十一届六中全会提出“计划经济为主、市场调节为辅”，为形成市场经济理论开辟道路；1984 十二届三中全会《关于经济体制改革的决定》提出社会主义经济是“公有制基础上的有计划的商品经济”，是社会主义经济理论的重大突破；1987 十三大提出“计划与市场内在统一的体制”“国家调节市场，市场引导企业”；1992 南方谈话提出“计划经济不等于社会主义……市场经济不等于资本主义……计划和市场都是经济手段”，标志着理论的形成；党的十四大明确把建立社会主义市场经济体制作为我国经济体制改革的目标。
- 内涵一：计划经济和市场经济不是划分社会制度的标志。
- 内涵二：计划和市场都是经济手段，对经济活动的调节各有优劣，要把两者的优势结合起来。
- 内涵三：市场经济作为资源配置手段本身不具有制度属性，可以和不同的社会制度结合——坚持社会主义制度与市场经济的结合，是社会主义市场经济的特色所在、优势所在。
- 意义：实现了马克思主义政治经济学的重大创新；社会主义市场经济是中国共产党的一个伟大创举，是我国经济体制改革在实践和理论上的重大突破。
- 可补充：邓小平称 1984 年十二届三中全会的《决定》是“马克思主义基本原理和中国社会主义实践相结合的政治经济学”。

**推导**：按“过程→内涵→意义”三段写。过程部分要给足五个节点（1981／1984／1987／1992 南方谈话／十四大），并注明 1984 年的提法是“公有制基础上的有计划的商品经济”；内涵部分三点要把“不是标志”“都是手段”“不具有制度属性”写准；意义部分用“重大创新”“伟大创举”“重大突破”三个关键词收尾。

**自评标准**

- [ ] 能按时间顺序写出四个以上节点，且 1984 与 1992 的提法不混；
- [ ] 三点内涵齐全，能写出“市场经济作为资源配置手段本身不具有制度属性”；
- [ ] 知道十四大确立体制改革目标，并能说出“伟大创举”这一评价。

### qa:6

**要点**

- 第一重地位：马克思列宁主义、毛泽东思想的继承和发展——邓小平理论是马克思列宁主义基本原理同当代中国实际和时代特征相结合的产物，是对马克思列宁主义、毛泽东思想的继承和发展，是全党全国人民集体智慧的结晶；既继承前人又突破陈规，开拓了马克思主义的新境界。
- 第二重地位：中国特色社会主义理论体系的开篇之作——紧紧抓住“什么是社会主义，怎样建设社会主义”这个基本问题，响亮提出“走自己的道路，建设有中国特色的社会主义”。
- 第二重地位的深化：开创性地提出社会主义本质、社会主义初级阶段、党的基本路线、改革开放、“一国两制”等一系列新概念新范畴，建构了中国特色社会主义理论的基本框架。
- 第二重地位的落脚点：第一次比较系统地初步回答了建设中国特色社会主义的一系列基本问题（发展道路、发展阶段、根本任务、发展动力、外部条件、政治保证、战略步骤、党的领导和依靠力量、祖国统一等），形成了比较完备的科学体系。
- 第三重地位：改革开放和社会主义现代化建设的科学指南——指导了制定初级阶段基本路线、制定“三步走”发展战略、强调“改革是中国的第二次革命”、反复强调“两手抓，两手都要硬”、创造性提出“一国两制”、明确提出和平与发展是当代世界两大主题、聚精会神抓党的建设；在邓小平理论指导下，我国社会生产力、综合国力和人民生活都上了一个大台阶。

- [ ] 第二重能写出“第一次比较系统地初步回答”这一完整表述；
