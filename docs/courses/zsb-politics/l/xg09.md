## 03正文精讲

## 第一节 坚持中国特色社会主义法治道路

"奉法者强则国强，奉法者弱则国弱。"法治是我们党矢志不渝的追求；全面依法治国，必须始终坚持正确方向，坚定不移走中国特色社会主义法治道路。

### 一、全面依法治国是国家治理的一场深刻革命

**1. 革命性定位**⭐⭐

- 法律是治国之重器，法治是国家治理体系和治理能力的重要依托。党的十八届四中全会通过《中共中央关于全面推进依法治国若干重大问题的决定》，规划了全面依法治国的**总蓝图、路线图、施工图**。
- ⭐⭐ 习近平指出："全面依法治国是国家治理的一场深刻革命，**关系党执政兴国，关系人民幸福安康，关系党和国家长治久安**。"（三个"关系"必背）

**2. 历史与现实证据：法治兴则国兴**⭐

- 什么时候重视法治、法治昌明，什么时候就国泰民安；什么时候忽视法治、法治松弛，什么时候就国乱民怨。
- 从我国古代看，凡属盛世都是法制相对健全的时期；从世界历史看，国家强盛往往同法治相伴而生；近代以来一些国家虽一度快速发展却没有顺利迈进现代化门槛，很大程度上与法治不彰有关。

**3. 认识深化的三组变化**
新中国成立以来：从"五四宪法"到 2018 年新修订的宪法；从"社会主义法制"到"社会主义法治"；从"有法可依、有法必依、执法必严、违法必究"到"科学立法、严格执法、公正司法、全民守法"——我们党越来越深刻认识到，法治是治国理政不可或缺的重要手段。

**4. 地位与保障作用**

- 全面依法治国是完善和发展中国特色社会主义制度、推进国家治理体系和治理能力现代化的**重要方面**，是坚持和发展中国特色社会主义的**本质要求和重要保障**。
- 法律是治国理政最大最重要的规矩；治理一个国家、一个社会，关键是要立规矩、讲规矩、守规矩。
- ⭐ 全面依法治国为制度之治提供**最基本最稳定最可靠的保障**：通过宪法法律确认和巩固国家根本制度、基本制度、重要制度，并运用国家强制力保证实施，保障了国家治理体系的系统性、规范性、协调性、稳定性。

**5. 十八大以来的历史性成就（7 条）**⭐

党的十八大以来，党中央从坚持和发展中国特色社会主义的全局和战略高度定位法治、布局法治、厉行法治，把全面依法治国纳入"四个全面"战略布局：

| 领域 | 成就 |
| --- | --- |
| 党的领导 | 加强党对全面依法治国集中统一领导，完善顶层设计，总体格局基本形成 |
| 依宪治国 | 与时俱进修改宪法，设立国家宪法日，建立宪法宣誓制度，推进合宪性审查，宪法实施和监督全面加强 |
| 立法 | 完善立法体制，加强重点领域立法，中国特色社会主义法律体系日趋完善 |
| 执法 | 推进法治政府建设，深化行政执法体制改革，执法更加严格规范公正文明 |
| 司法 | 深化司法体制改革，坚决维护社会公平正义，司法质量、效率、公信力显著提高 |
| 普法 | 实行"谁执法谁普法"普法责任制，将法治教育纳入国民教育体系，全社会法治观念明显增强 |
| 依规治党 | 深入推进依规治党，加强党内法规制度建设，形成比较完善的党内法规体系 |

- 法治中国建设迈出坚实步伐，法治**固根本、稳预期、利长远**的保障作用进一步发挥。

### 二、全面依法治国的唯一正确道路

**1. 必须走对路**⭐⭐

- "全面推进依法治国，必须走对路。如果路走错了，南辕北辙了，那再提什么要求和举措也都没有意义了。"
- 中国特色社会主义法治道路是全面依法治国的**唯一正确道路**：由我国社会主义国家性质所决定，本质上是中国特色社会主义道路在法治领域的具体体现；我国法治建设的成就可以列举十几条、几十条，但归结起来就是**开辟了中国特色社会主义法治道路这一条**。

**2. 核心要义（3 条）**⭐⭐⭐

| 核心要义 | 地位作用 |
| --- | --- |
| 坚持党的领导 | 党的领导是中国特色社会主义**最本质的特征**，是社会主义法治**最根本的保证** |
| 坚持中国特色社会主义制度 | 是中国特色社会主义法治体系的**根本制度基础**，是全面推进依法治国的**根本制度保障** |
| 贯彻中国特色社会主义法治理论 | 是中国特色社会主义法治体系的**理论指导和学理支撑**，是全面推进依法治国的**行动指南** |

这三个方面规定和确保了中国特色社会主义法治体系的制度属性和前进方向。

**3. 必须毫不动摇坚持的五个原则**⭐⭐⭐

| 原则 | 核心要点 |
| --- | --- |
| ①坚持中国共产党的领导 | ⭐党的领导是中国特色社会主义**法治之魂**，是我们的法治同西方资本主义国家的法治**最大的区别** |
| ②坚持以人民为中心 | 全面依法治国**最广泛、最深厚的基础是人民**；坚持法治为了人民、依靠人民、造福人民、保护人民；根本目的是依法保障人民权益 |
| ③坚持法律面前人人平等 | 平等是社会主义法律的**基本属性**；都不得有超越宪法法律的特权；有权必有责、用权受监督、违法必追究 |
| ④坚持依法治国和以德治国相结合 | 法安天下，德润人心；一手抓法治、一手抓德治，实现法律和道德相辅相成、法治和德治相得益彰 |
| ⑤坚持从中国实际出发 | 突出法治的**中国特色、实践特色、时代特色**；传承中华优秀传统法律文化；学习借鉴世界优秀法治文明成果，以我为主、为我所用 |

要点补充：

- 坚持党的领导：把依法治国、依法执政、依法行政**统一起来**，把党总揽全局、协调各方同人大、政府、政协、监察机关、审判机关、检察机关依法依章程履行职能**统一起来**，把党领导人民制定和实施宪法法律同党坚持在宪法法律范围内活动**统一起来**；善于使党的主张通过法定程序成为国家意志。
- 坚持以人民为中心：加强人权法治保障，实现尊重和保障人权在立法、执法、司法、守法**全链条、全过程、全方位**覆盖，让人民群众在每一项法律制度、每一个执法决定、每一宗司法案件中都感受到公平正义。
- 从中国实际出发：中华法系在世界几大法系中独树一帜——出礼入刑、隆礼重法的治国策略，民惟邦本、本固邦宁的民本理念，天下无讼、以和为贵的价值追求，德主刑辅、明德慎罚的慎刑思想，援法断罪、罚当其罪的平等观念，保护鳏寡孤独、老幼妇残的恤刑原则。

### 三、统筹处理全面依法治国的重大关系

⭐⭐ "全面依法治国必须正确处理**政治和法治、改革和法治、依法治国和以德治国、依法治国和依规治党**的关系。"

| 重大关系 | 核心论断 | 处理要点 |
| --- | --- | --- |
| ①政治和法治 | 法治当中有政治，没有脱离政治的法治 | ⭐⭐党和法的关系是政治和法治关系的**集中反映**，是全面依法治国的**一个根本问题**：处理得好，则法治兴、党兴、国家兴。党的领导和社会主义法治是**一致的**——社会主义法治必须坚持党的领导，党的领导必须依靠社会主义法治；全面依法治国绝不是要虚化、弱化甚至动摇、否定党的领导 |
| ②改革和法治 | 相辅相成、相伴而生；**在法治下推进改革，在改革中完善法治** | 重大改革**于法有据**；成熟的改革经验和行之有效的举措尽快上升为法律；先行先试的按法定程序作出授权——既不允许随意突破法律红线，也不允许简单以现行法律没有依据为由迟滞改革；及时修改或废止不适应改革的法律法规，不让过时条款成为改革的"绊马索" |
| ③依法治国和以德治国 | 法安天下，德润人心；**法律是成文的道德，道德是内心的法律** | 法治和德治不可分离、不可偏废，国家治理需要法律和道德协同发力；在道德体系中体现法治要求，在道德教育中突出法治内涵 |
| ④依法治国和依规治党 | ⭐**依规治党深入党心，依法治国才能深入民心** | 坚持依法治国与制度治党、依规治党**统筹推进、一体建设**；确保党既依据宪法法律治国理政，又依据党内法规管党治党、从严治党 |

**党的政策和国家法律的关系**⭐

- 两者都是人民根本意志的反映，**在本质上是一致的**。
- 党的政策是国家法律的**先导和指引**，是立法的依据和执法司法的重要指导；党的政策成为国家法律后，实施法律就是贯彻党的意志，依法办事就是执行党的政策，**不能把两者对立起来、割裂开来**。

## 第二节 建设中国特色社会主义法治体系

中国特色社会主义法治体系是由**法律规范体系、法治实施体系、法治监督体系、法治保障体系和党内法规体系**构成的统一体，涵盖立法、执法、司法、守法各个环节，对推进全面依法治国具有**纲举目张**的重要意义。

### 一、全面推进依法治国的总抓手

**1. 总抓手的提出与认识深化**⭐⭐⭐

- "在实际工作中必须有一个总揽全局、牵引各方的总抓手，这个总抓手就是**建设中国特色社会主义法治体系**。依法治国各项工作都要围绕这个总抓手来谋划、来推进。"
- 认识深化过程：党的**十五大**明确提出形成**中国特色社会主义法律体系**的重大任务 → 进入新时代，党的**十八届四中全会**将建设中国特色社会主义法治体系、建设社会主义法治国家确定为全面推进依法治国的**总目标**，将建设中国特色社会主义法治体系确定为**总抓手**。

**2. 本质与意义**⭐

- 中国特色社会主义法治体系，本质上是中国特色社会主义制度的**法律表现形式**。
- 建设法治体系是实现国家治理体系和治理能力现代化的必然要求，也是全面深化改革的必然要求；**三个"有利于"**：有利于在法治轨道上推进国家治理体系和治理能力现代化，有利于在全面深化改革总体框架内推进全面依法治国各项工作，有利于在法治轨道上不断深化改革。

### 二、坚持依宪治国、依宪执政

**1. 宪法的地位**⭐⭐⭐

| 维度 | 表述 |
| --- | --- |
| 根本法 | 国家的根本法，治国安邦的**总章程** |
| 意志体现 | 党和人民意志的集中体现 |
| 总依据 | 国家各种制度和法律法规的**总依据** |
| 效力 | 具有**最高的法律地位、法律权威、法律效力** |

- ⭐⭐ "坚持依法治国首先要坚持依宪治国，坚持依法执政首先要坚持依宪执政。"建设社会主义法治国家，必须把**全面贯彻实施宪法**作为首要任务。
- 维护宪法权威，就是维护党和人民共同意志的权威；捍卫宪法尊严，就是捍卫党和人民共同意志的尊严；保证宪法实施，就是保证人民根本利益的实现。

**2. 两个"不动摇"**⭐⭐

- "我们讲依宪治国、依宪执政，**同西方所谓'宪政'有着本质区别**，不能把二者混为一谈。"
- 必须坚持宪法确定的**中国共产党领导地位**不动摇，坚持宪法确定的**人民民主专政的国体和人民代表大会制度的政体**不动摇。

**3. 全面贯彻实施宪法（5 条）**

- ⭐ **宪法的生命在于实施，宪法的权威也在于实施。**
- ①坚持和加强党对宪法工作的全面领导；②把宪法实施贯穿到治国理政各方面全过程；③加快完善以宪法为核心的中国特色社会主义法律体系；④健全保证宪法全面实施的制度体系；⑤加强宪法理论研究和宣传教育。

### 三、更好推进中国特色社会主义法治体系建设

⭐⭐⭐ 法治体系是**国家治理体系的骨干工程**。五大体系对比记忆：

| 体系 | 定位/重点 | 关键举措 |
| --- | --- | --- |
| ①完备的**法律规范体系** | 以宪法为核心的有机整体 | 抓住**立法质量**这个关键，科学立法、民主立法、依法立法，统筹**立改废释纂**；总结编纂民法典的经验，适时推动条件成熟的立法领域**法典编纂**；推进合宪性审查；地方立法要有地方特色 |
| ②高效的**法治实施体系** | 执法、司法、守法等各个环节协调高效运转 | 有了法律而不实施、束之高阁，制定再多法律也无济于事；执法者必须**忠实于法律**；依法平等保护各类市场主体产权和合法权益 |
| ③严密的**法治监督体系** | 以**规范和约束公权力的运行**为重点 | 有权必有责、用权受监督、违法必追究；"只要公权力存在，就必须有制约和监督。不关进笼子，公权力就会被滥用"；构建党统一领导、全面覆盖、权威高效的法治监督体系 |
| ④有力的**法治保障体系** | 包括政治、思想、组织、制度、队伍、科技等保障条件 | 建设忠于党、忠于国家、忠于人民、忠于法律的社会主义法治工作队伍；充分运用大数据、云计算、人工智能等现代科技手段，全面建设"智慧法治" |
| ⑤完善的**党内法规体系** | ⭐⭐纳入法治体系是**我国法治区别于其他国家法治的鲜明特征** | 以**党章为根本**、以**民主集中制为核心**、以准则条例等**中央党内法规为主干**、以部委党内法规和地方党内法规为重要组成部分；构建内容科学、程序严密、配套完备、运行有效的党内法规体系 |

- 监督格局细节：坚持以**党内监督为主导**，推动人大监督、民主监督、行政监督、司法监督、审计监督、财会监督、统计监督、群众监督、舆论监督有机贯通、相互协调。
- 党内法规执行细节：把提高党内法规执行力摆在更加突出位置，把抓"关键少数"和管"绝大多数"统一起来。

## 第三节 加快建设法治中国

建设法治中国，是全面建设社会主义现代化国家的重要组成部分；加快建设法治中国，必须围绕**保障和促进社会公平正义**，坚持依法治国、依法执政、依法行政共同推进，坚持法治国家、法治政府、法治社会一体建设，全面推进国家各方面工作法治化。

### 一、法治中国建设的总体目标

- 法治既是实现国家现代化的基本保障，也是国家现代化的重要内容；"**一个现代化国家必然是法治国家**"。
- 党的**十八届三中全会**首次提出"**推进法治中国建设**"的目标并作出重大任务部署⭐
- 2020 年，中共中央印发《法治中国建设规划(2020—2025 年)》，从全局和战略高度对法治中国建设作出系统部署，在党和国家法治建设史上具有重大意义。

⭐⭐⭐ 总体目标与两个时间节点：

| 节点 | 目标表述 |
| --- | --- |
| 总体目标 | 法律规范科学完备统一，执法司法公正高效权威，权力运行受到有效制约监督，人民合法权益得到充分尊重保障，法治信仰普遍确立，**法治国家、法治政府、法治社会全面建成** |
| 到 2025 年 | 党领导全面依法治国体制机制更加健全，以宪法为核心的中国特色社会主义法律体系更加完备，依法行政的政府治理体系日益健全，法治社会建设取得重大进展，党内法规体系更加完善，中国特色社会主义法治体系**初步形成** |
| 到 2035 年 | **法治国家、法治政府、法治社会基本建成**，中国特色社会主义法治体系**基本形成**，人民平等参与、平等发展权利得到充分保障，国家治理体系和治理能力现代化**基本实现** |

### 二、法治中国建设的工作布局

**1. 坚持依法治国、依法执政、依法行政共同推进**⭐⭐⭐

| 三者 | 定位 |
| --- | --- |
| 依法治国 | 党领导人民治理国家的**基本方式** |
| 依法执政 | 新的历史条件下我们党执政的**基本方式**：通过法定程序将党的主张上升为国家意志，领导立法、保证执法、支持司法、带头守法 |
| 依法行政 | 法治状态下政府行为的**基本原则和基本方式**：合法行政，法定职责必须为、法无授权不可为，严格规范公正文明执法 |

三者具有内涵的统一性、目标的一致性、成效的相关性，必须彼此协调、形成合力。

**2. 坚持法治国家、法治政府、法治社会一体建设**⭐⭐⭐

| 三者 | 地位 |
| --- | --- |
| 法治国家 | 法治建设的**目标** |
| 法治政府 | 全面依法治国的**重点任务和主体工程**（职能科学、权责法定、执法严明、公开公正、智能高效、廉洁诚信、人民满意的法治政府） |
| 法治社会 | 构筑法治国家的**基础**（信仰法治、公平正义、保障权利、守法诚信、充满活力、和谐有序的社会主义法治社会） |

三者相互联系、内在统一，是法治中国建设的**三大支柱**，必须同步规划、同步实施、一体建设。

**3. 坚持统筹推进国内法治和涉外法治**⭐

- 加快涉外法治工作战略布局，协调推进国内治理和国际治理，加快形成系统完备的涉外法律法规体系，提升涉外执法司法效能；
- 善于运用法治思维和法治方式有效应对挑战、防范风险，综合利用立法、执法、司法等手段开展国际斗争，坚决维护国家核心利益；
- 坚定维护以联合国为核心的国际体系，坚定维护以国际法为基础的国际秩序，坚定维护以联合国宪章宗旨和原则为基础的国际法基本原则和国际关系基本准则。

### 三、建设更高水平的法治中国

⭐ 坚持系统观念，全面推进**科学立法、严格执法、公正司法、全民守法**。

**1. 完善以宪法为核心的中国特色社会主义法律体系（科学立法）**

**2. 扎实推进依法行政（严格执法）**

**3. 严格公正司法**⭐⭐

- ⭐⭐ 公正司法是维护社会公平正义的**最后一道防线**。
- 深化司法体制综合配套改革，全面准确落实**司法责任制**，加快建设公正高效权威的社会主义司法制度；强化对司法活动的制约监督；加强检察机关法律监督工作，完善**公益诉讼**制度。

## 05易错点辨析

1. **"法制" ≠ "法治"**——从"社会主义法制"到"社会主义法治"是认识深化的体现；新十六字方针是"科学立法、严格执法、公正司法、全民守法"，与历史上"有法可依、有法必依、执法必严、违法必究"的表述相区别。
2. **法律体系 ≠ 法治体系**——十五大提出形成"中国特色社会主义**法律**体系"（立法成果）；十八届四中全会确定建设"中国特色社会主义**法治**体系"（含实施、监督、保障、党内法规的统一体）为总目标、总抓手，两者不能混同。
3. **依宪治国、依宪执政 ≠ 西方"宪政"**——两者有着本质区别；必须坚持宪法确定的中国共产党领导地位、人民民主专政的国体和人民代表大会制度的政体不动摇。
4. **全面依法治国 ≠ 削弱党的领导**——党的领导和社会主义法治是一致的；全面依法治国绝不是要虚化、弱化甚至动摇、否定党的领导，而是为了巩固党的执政地位、改善党的执政方式、提高党的执政能力。
5. **党的政策 ≠ 与国家法律对立**——两者都是人民根本意志的反映，本质上一致；党的政策是国家法律的先导和指引，依法办事就是执行党的政策，不能把两者对立起来、割裂开来。
6. **改革和法治 ≠ 二者取一**——既不允许随意突破法律红线，也不允许简单以现行法律没有依据为由迟滞改革；过时的法律条款要及时修改或废止，不能成为改革的"绊马索"。
7. **法治监督体系的重点 ≠ 监督一切**——其重点是**规范和约束公权力的运行**；监督格局是"党内监督为主导+各类监督有机贯通"，答题别漏掉"党内监督主导"。
8. **党内法规体系是法治体系的组成部分**——把党内法规体系纳入中国特色社会主义法治体系，恰恰是我国法治区别于其他国家法治的鲜明特征，不要把它排除在法治体系之外。
9. **2025"初步形成" vs 2035"基本建成/基本形成"**——程度词不同：2025 年中国特色社会主义法治体系"初步形成"；2035 年法治国家、法治政府、法治社会"基本建成"、法治体系"基本形成"，两个节点不能互换。
10. **"共同推进"与"一体建设"是两组概念**——依法治国、依法执政、依法行政"共同推进"；法治国家、法治政府、法治社会"一体建设"；且法治政府是"重点任务和主体工程"、法治社会是"基础"、法治国家是"目标"，定位不可互换。
11. **宪法地位表述要写全**——宪法是国家的根本法、治国安邦的总章程、党和人民意志的集中体现、国家各种制度和法律法规的总依据，并具有最高的法律地位、法律权威、法律效力，答题别只写一半。
