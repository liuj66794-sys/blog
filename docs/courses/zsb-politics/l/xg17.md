## 03正文精讲

## 第一节 全面从严治党是新时代党的建设的鲜明主题

党要管党、从严治党，是党的建设的一贯要求和根本方针。全面从严治党是党永葆生机活力、走好新的赶考之路的必由之路，是**新时代党的建设的鲜明主题**⭐

### 一、打铁必须自身硬

**1. 提出过程**⭐

| 时间 | 场合 | 表述 |
| --- | --- | --- |
| 2012 年 11 月 | 十八届中共中央政治局常委同中外记者见面 | "**打铁还需自身硬**"，必须从严治党，不躺在过去的功劳簿上 |
| 2017 年 10 月 | 党的十九大报告 | "**打铁必须自身硬**"，表明党坚持**刀刃向内**的非凡勇气和高度清醒 |

**2. 依据一：加强党的自身建设是新形势下推进伟大事业、进行伟大斗争、实现伟大梦想的必然要求**

- ①党领导的**伟大事业**涵盖领域极其广泛，发展中的问题和发展后的问题、一般矛盾和深层次矛盾交织叠加；
- ②进行的**伟大斗争**极其尖锐复杂，国际形势波谲云诡、周边环境复杂敏感；
- ③实现**伟大梦想**（脱贫攻坚、全面小康、以中国式现代化全面推进中华民族伟大复兴）既无比光荣又困难重重。
- 结论：必须把党建设得更加坚强有力，使党始终走在时代前列、始终成为全国人民的主心骨、始终成为坚强领导核心。

**3. 依据二：是把党锻造成为坚强有力的马克思主义执政党的迫切需要**⭐⭐

- "我们党作为世界第一大党，没有什么外力能够打倒我们，**能够打倒我们的只有我们自己**"；成立以来面临的最大风险是**内部变质、变色、变味**，失去最广大人民的支持和拥护。
- **四大考验、四种危险将长期存在**：

| 四大考验 | 四种危险 |
| --- | --- |
| 执政考验 | 精神懈怠危险 |
| 改革开放考验 | 能力不足危险 |
| 市场经济考验 | 脱离群众危险 |
| 外部环境考验 | 消极腐败危险 |

- 如果管党不力、治党不严，党内突出问题得不到解决，"那我们党迟早会失去执政资格，不可避免被历史淘汰"。

**4. 百年大党的根本性问题**：如何**永葆先进性和纯洁性**、永葆青春活力，如何**永远得到人民拥护和支持**，如何**实现长期执政**——必须回答好、解决好。

### 二、坚定不移全面从严治党

**1. 科学内涵（必背定位）**⭐⭐⭐

- 一些问题屡禁不绝，"**根子就在从严治党没有做到位**……没有管到位上，没有严到份上"，必须在"全面从严"上下功夫。

| 定位 | 内涵 |
| --- | --- |
| **核心是加强党的领导** | 党的领导是中国特色社会主义制度的最大优势、根本政治保证；克服软弱涣散特别是腐败问题，保持先进性纯洁性，提高领导水平和执政能力 |
| **基础在全面** | 落实到每个党组织、每名党员，体现到政治、思想、组织、作风、纪律、制度建设、反腐败斗争各个领域 |
| **关键在严** | 严字当头、贯穿全过程，真管真严、敢管敢严、长管长严，不降标准、不图形式、不走过场 |
| **要害在治** | 真正解决问题、切实担起责任：各级党委担负**主体责任**、各级纪委担负**监督责任**；标本兼治，拔"烂树"、治"病树"、正"歪树"，从宽松软走向严紧硬 |

**2. 全面从严治党体系：把全的要求、严的基调、治的理念落实到全过程**⭐⭐

| "四个全" | 要点 |
| --- | --- |
| 内容上**全涵盖** | 党的建设推进到哪里，全面从严治党体系就要构建到哪里 |
| 对象上**全覆盖** | 面向党的各级组织和全体党员，管全党、治全党，不留死角和空白 |
| 责任上**全链条** | 每名党员干部行使应有权利、履行应尽责任，全党动手一起抓 |
| 制度上**全贯通** | 制度建设要求体现到全过程、各方面、各层级，实现制度治党、依规治党 |

**3. 新时代党的建设总要求**⭐⭐⭐

| 要素 | 内容 |
| --- | --- |
| 方针 | 坚持和加强党的**全面领导**；坚持党要管党、**全面从严治党** |
| 主线 | 加强党的**长期执政能力建设、先进性和纯洁性建设** |
| 统领 | 以党的**政治建设**为统领 |
| 根基 | 以坚定**理想信念宗旨**为根基 |
| 着力点 | 以调动全党**积极性、主动性、创造性**为着力点 |
| 总体布局 | 全面推进政治、思想、组织、作风、纪律建设，把**制度建设贯穿其中**，深入推进**反腐败斗争**，不断提高党的建设质量 |
| 目标 | 把党建设成为始终走在时代前列、**人民衷心拥护、勇于自我革命**、经得起各种风浪考验、朝气蓬勃的**马克思主义执政党** |

### 三、全面从严治党取得历史性开创性成就

**1. 九条举措与成就**⭐

| 序号 | 成就要点 |
| --- | --- |
| ① | 从**中央八项规定**制定落实**开局破题**，抓住"关键少数"，以上率下 |
| ② | **政治建设放在首位**，出台加强和维护党中央集中统一领导的若干规定 |
| ③ | 全党开展**集中学习教育**：党的群众路线教育实践活动、"三严三实"专题教育、"两学一做"学习教育、"不忘初心、牢记使命"主题教育、党史学习教育、学习贯彻习近平新时代中国特色社会主义思想主题教育 |
| ④ | 提出和贯彻**新时代党的组织路线**，突出政治标准选贤任能 |
| ⑤ | 把**巡视**作为全面从严治党的战略性制度安排，建立巡视巡察上下联动格局 |
| ⑥ | 以钉钉子精神纠治"**四风**"（形式主义、官僚主义、享乐主义、奢靡之风），反对特权 |
| ⑦ | 把**纪律**挺在前面，纪严于法、执纪执法贯通，使铁的纪律成为带电的高压线 |
| ⑧ | 制度建设贯穿各方面，形成**比较完善的党内法规体系** |
| ⑨ | 以"**得罪千百人、不负十四亿**"的决心开展史无前例的**反腐败斗争**：不敢腐的目标初步实现、不能腐的笼子越扎越紧、不想腐的堤坝正在构筑，反腐败斗争取得**压倒性胜利并全面巩固** |

- 总体结论：管党治党**宽松软**状况得到根本扭转，风清气正的党内政治生态不断形成和发展；成就具有**历史性、开创性**，影响**全方位、深层次**。

**2. 重要经验："六个相统一"**⭐⭐

| 相统一 | 要点 |
| --- | --- |
| 思想建党 和 制度治党 | 解决思想问题+解决制度问题，坚定理想信念是根本任务 |
| 使命引领 和 问题导向 | 立足当前解决群众最不满意的问题+着眼未来强化顶层设计 |
| 抓"关键少数" 和 管"绝大多数" | 对高级干部提出更高更严标准 |
| 行使权力 和 担当责任 | 咬住"责任"二字，抓住"问责"这个要害 |
| 严格管理 和 关心信任 | 惩前毖后、治病救人，抓早抓小、防微杜渐 |
| 党内监督 和 群众监督 | 以党内监督带动其他监督，发挥群众监督、舆论监督作用 |

**3. 长期战略、永恒课题**：成就来之不易，"还远未到大功告成的时候"；"党和人民事业发展到什么阶段，全面从严治党就要跟进到什么阶段"；决不能有松劲歇脚、疲劳厌战的情绪。

## 第二节 以政治建设为统领深入推进党的建设

把党的建设作为一项**伟大工程**来推进，是我们党的一大创举，是领导人民进行伟大社会革命的**重要法宝**；必须注重系统性、整体性、协同性。

### 一、把党的政治建设摆在首位

**1. 为什么**：党的政治建设是党的**根本性建设**；把政治建设纳入总体布局并**摆在首位**，是对马克思主义党建理论的重大创新⭐⭐

- ①旗帜鲜明讲政治是我们党作为马克思主义政党的**根本要求**——政治上的先进性丧失了，党的先进性和纯洁性就无从谈起；
- 党的政治建设**决定党的建设方向和效果**，党内很多问题都同政治问题相关联。

**2. 首要任务**⭐⭐⭐：**保证全党服从中央，维护党中央权威和集中统一领导**。

- 团结统一是党的生命；坚持党中央权威和集中统一领导，才能使全党团结成"**一块坚硬的钢铁**"；
- 坚决维护习近平同志党中央的核心、全党的核心地位，坚决维护党中央权威和集中统一领导；
- 坚持民主集中制，坚决防止和反对个人主义、分散主义、自由主义，宗派主义、圈子文化、码头文化，反对搞两面派、做两面人。

**3. 发挥统领性作用的四个着力点**⭐⭐

| 着力点 | 要点 |
| --- | --- |
| 把准**政治方向** | 党生存发展第一位的问题，发挥政治指南针作用 |
| 站稳**政治立场** | 坚定马克思主义立场，坚决站稳党性立场和人民立场 |
| 营造良好**政治生态** | 基础性、经常性工作；增强党内政治生活的政治性、时代性、原则性、战斗性 |
| 提高**政治能力** | 领导干部所有能力中**第一位**的；增强政治判断力、政治领悟力、政治执行力 |

### 二、思想建设是党的基础性建设

坚持**思想建党、理论强党**，用习近平新时代中国特色社会主义思想**凝心铸魂**。三条意义⭐：

1. **前提**：加强思想建设是坚守理想信念、坚定革命意志的前提——解决世界观、人生观、价值观这个"**总开关**"问题；弘扬以**伟大建党精神**为源头的中国共产党人精神谱系；
2. **要求**：保持政治上清醒坚定、行动上团结统一——"'欲事立，须是心立。'加强思想教育和理论武装，是党内政治生活的**首要任务**"；转化为增强"四个意识"、坚定"四个自信"、做到"两个维护"的政治自觉；
3. **保障**：是贯彻党的理论和路线方针政策、推进党和国家事业发展的重要保障——坚持学思用贯通、知信行统一，在学懂弄通做实上下功夫。

### 三、贯彻新时代党的组织路线

党的力量来自组织，党的全面领导、党的全部工作要靠党的坚强**组织体系**去实现。

**1. 严密党的组织体系是重点**⭐⭐

| 层级 | 定位 | 要求 |
| --- | --- | --- |
| 中央和国家机关 | "最初一公里" | 建设讲政治、守纪律、负责任、有效率的**模范机关** |
| 地方党委 | "中间段" | 建设坚决听从党中央指挥、管理严格、监督有力、班子团结、风气纯正的**坚强组织** |
| 基层党组织 | "最后一公里" | 坚持大抓基层导向，建设宣传党的主张、贯彻党的决定、领导基层治理、团结动员群众、推动改革发展的**坚强战斗堡垒** |
| 党员 | 党的活动的主体 | 提高党员发展质量，发挥**先锋模范作用** |

**2. 建设高素质专业化干部队伍是关键**⭐⭐

- **忠诚**（忠于党、同党中央保持高度一致、立志为民、襟怀坦白）、**干净**（克己奉公、以俭修身、清正廉洁）、**担当**（为党分忧、为国尽责、为民奉献，敢于斗争、善于斗争）；
- 新时代好干部标准："**信念坚定、为民服务、勤政务实、敢于担当、清正廉洁**"；

## 05易错点辨析

1. **"还需"≠"必须"**——2012 年十八届常委见面会讲"打铁**还需**自身硬"，2017 年十九大报告升级为"打铁**必须**自身硬"，选择题爱考年份与措辞对应。
2. **四大考验 ≠ 四种危险**——"考验"是执政、改革开放、市场经济、外部环境；"危险"是精神懈怠、能力不足、脱离群众、消极腐败。别把"市场经济"答进危险、把"脱离群众"答进考验。
3. **全面从严治党定位顺序不能换**——是"**核心**是加强党的领导"，不是"核心在严"；"基础在全面、关键在严、要害在治"三句对应关系固定。
4. **建设定位搭配**——政治建设是**根本性**建设（摆在首位）；思想建设是**基础性**建设；纪律建设是**治本之策**；靠制度是**长远之策、根本之策**——四个形容词不能互换。
5. **政治建设的首要任务不是"讲政治"**——首要任务是**保证全党服从中央，维护党中央权威和集中统一领导**；"旗帜鲜明讲政治"是党的根本要求。
6. **"三不腐"定位顺序**——"**不敢**"是前提、"**不能**"是关键、"**不想**"是根本；别把"不想"当前提、"不敢"当根本。
7. **两个答案的归属**——第一个答案是"**让人民来监督政府**"（毛泽东、延安窑洞），第二个答案才是"**自我革命**"；别颠倒，也别答成"民主"或"监督"。
8. **巡视的定位表述**——巡视是"**党内监督的战略性制度安排**"（也是全面从严治党的战略性制度安排）；派驻监督只是监督体系的"重要组成部分"，两者层级表述不同。
9. **党内监督地位最高**——在党和国家各种监督形式中"最根本、第一位"的是**党内监督**，不是国家监察、群众监督或舆论监督（后两者是"以党内监督带动"的对象）。
10. **党性党风党纪关系不可倒置**——党性是**根本**、党风是**表现**、党纪是**保障**。
11. **反腐败三句状态表述**——不敢腐的目标"**初步实现**"、不能腐的笼子"**越扎越紧**"、不想腐的堤坝"**正在构筑**"，整体已达"压倒性胜利并全面巩固"，三句一一对应别混。
12. **"十三个坚持"的归属**——概括的是**习近平关于党的建设的重要思想**（2023 年 6 月全国组织工作会议），不是概括"习近平新时代中国特色社会主义思想"本身。
13. **大党独有难题的数量**——独有难题是**五个"如何始终"**，破解路径是**六条"必须"**，另记"三个务必"，三组数字别混。
