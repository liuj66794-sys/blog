## 03正文精讲

## 第一节 从新民主主义到社会主义的转变

### 一、新民主主义社会是一个过渡性的社会

**1. 时间与性质**

- 从中华人民共和国成立（1949）到社会主义改造基本完成（1956），是**从新民主主义到社会主义的过渡时期**，社会性质是新民主主义社会。
- ⭐⭐ 新民主主义社会**不是一个独立的社会形态**，而是由新民主主义向社会主义转变的**过渡性社会形态**，属于社会主义体系。

**2. 五种经济成分 → 三种主要经济成分**⭐⭐

| 五种经济成分 | 性质 | 演变方向 |
| --- | --- | --- |
| 国营经济 | 社会主义性质 | 领导地位，不断扩大 |
| 合作社经济 | **半**社会主义性质 | 个体经济向集体经济过渡的**形式** |
| 个体经济（农民和手工业者） | 私有 | 主要成分之一 |
| 私人资本主义经济 | 私有 | 主要成分之一 |
| 国家资本主义经济 | — | 私人资本主义向国营经济过渡的**形式** |

- 主要经济成分是**三种**：**社会主义经济、个体经济、资本主义经济**。
- 1952 年结构：个体经济 71.8%、国营经济 19.1%、资本主义经济 6.9%、合作社 1.5%、公私合营 0.7%。

**3. 阶级构成与主要矛盾**⭐⭐

- 三种经济成分对应三种基本阶级力量：**工人阶级 / 农民阶级和其他小资产阶级 / 民族资产阶级**。
- 随着土地改革基本完成，**工人阶级和资产阶级的矛盾逐步成为我国社会的主要矛盾**（社会主义 vs 资本主义两条道路）。只有解决这一矛盾，中国才能实现向社会主义的转变。

**4. 民族资产阶级的两面性**⭐

- 既有**剥削工人**的一面，又有**接受工人阶级及其政党领导**的一面；
- 其与工人阶级的矛盾也具有两重性：对抗性（剥削与被剥削）+ 非对抗性（可以合作）；
- 因此民族资产阶级既是**被消灭的对象**（作为剥削阶级），又是**可以团结和改造的对象**（作为社会力量）。

**5. 为什么社会主义因素会取得最终胜利**

- 经济上：社会主义经济不断发展（国营工业占全国工业比重 1949 年 34.2% → 1952 年 52.8%）；
- 政治上：工人阶级领导的人民民主专政国家，马克思主义居于指导地位；
- 国际上：二战后社会主义形成强大阵营。
- 三年间还完成了没收官僚资本（确立国营经济领导地位）、土地改革（1950.6《土地改革法》，1952 年基本完成，3 亿多农民分得土地）、互助合作运动、初级形式国家资本主义等铺垫。

### 二、党在过渡时期的总路线及其依据

**1. 提出过程时间线**⭐⭐

| 时间 | 事件 |
| --- | --- |
| 1949.3 七届二中全会 | 提出"两个转变"同时并举（农业国→工业国，新民主主义国家→社会主义国家） |
| 1951 年前后 | 党内共识：先用三个五年计划搞工业化，**再**过渡（约 15-20 年） |
| 1952.9 | 毛泽东：**现在就**开始用 10-15 年基本完成过渡（酝酿开始） |
| **1953.6** | 毛泽东在中央政治局会议**正式提出**过渡时期总路线和总任务 |
| **1953.12** | 形成总路线的**完整表述** |
| 1954.2 七届四中全会 | 正式批准这条总路线；1954.9 一届全国人大写入宪法 |

**2. 总路线完整表述（原文背诵）**⭐⭐⭐

> &lt;p&gt;"从中华人民共和国成立，到社会主义改造基本完成，这是一个过渡时期。党在这个过渡时期的总路线和总任务，是要在一个相当长的时期内，逐步实现国家的**社会主义工业化**，并逐步实现国家对**农业**、对**手工业**和对**资本主义工商业**的社会主义改造。"&lt;/p&gt;

**3. "一化三改"："主体"与"两翼"**⭐⭐⭐

- **一化** = 社会主义工业化 → **主体**
- **三改** = 对个体农业、手工业和资本主义工商业的社会主义改造 → **两翼**
- 两者相辅相成、相互促进；这是**社会主义建设和社会主义改造同时并举**的路线，体现了解放生产力与发展生产力、变革生产关系与发展生产力的有机统一。
- 工业化为何必须走社会主义道路：毛泽东"现在我们能造什么？……一辆汽车、一架飞机、一辆坦克、一辆拖拉机都不能造"；"资本主义道路，也可增产，但时间要长，而且是痛苦的道路"。

**4. 理论依据**⭐

- **马恩**：提出从资本主义到社会主义需要经历过渡时期（不可逾越）；曾设想**暴力没收与和平赎买**两种变革所有制方式，认为赎买"最便宜不过"。
- **列宁**：进一步发展革命转变思想；过渡时期根本任务是把剥削阶级的生产资料转为公有财产，通过合作社使农民集体化；也曾设想通过国家资本主义和平赎买（未实现）。
- **毛泽东为代表的中国共产党人**：将马列过渡时期理论**中国化**，依据中国具体情况制定总路线（1953.12 宣传提纲：过渡之所以必要且需相当长时间，一因经济文化落后，二因个体农业手工业和资本主义工商业比重大、需要时间改造）。

**5. 现实依据（4 条）**⭐⭐

1. **相对强大和迅速发展的社会主义国营经济**——提供了**物质基础**（1952 年国营工业产值占全国工业总产值 56%）；
2. 土改后**农民有走互助合作道路的要求**——避免两极分化、互助合作明显增产；
3. 合理调整工商业中出现的**加工订货、经销代销、统购包销、公私合营**等一系列国家资本主义形式——积累了改造资本主义工商业的最初经验；
4. **国际形势有利**——苏联社会主义显示优越性、朝鲜战争停战缓和，提供了有利的国际环境。

## 第二节 社会主义改造道路和历史经验

### 一、适合中国特点的社会主义改造道路

#### 1. 农业（三大改造中**首先进行**）⭐⭐⭐

**四条经验：**

1. **积极引导农民组织起来，走互助合作道路**（农民有两种积极性：个体经济的积极性 + 互助合作的积极性）；
2. **遵循自愿互利、典型示范和国家帮助的原则**——农民既是私有者又是劳动者，不能剥夺，只能引导说服教育（1953.2《关于农业生产互助合作的决议》确立自愿+互利两条必须绝对遵守的原则）；
3. **正确分析农村阶级和阶层状况，制定正确的阶级政策**——毛泽东把中农分为上中农和下中农，**依靠贫下中农**（贫农+下中农占农村人口 60%-70%），发展互助合作，由逐步限制到最后消灭富农剥削；
4. **坚持积极领导、稳步前进的方针，采取循序渐进的步骤**。

**三步骤（性质演变必背）**⭐⭐⭐

| 步骤 | 组织形式 | 生产资料归属 | 分配方式 | 性质 |
| --- | --- | --- | --- | --- |
| 第一阶段 | **互助组**（临时/常年） | 农民**个人所有** | — | **社会主义萌芽性质** |
| 第二阶段 | **初级农业生产合作社** | **土地入股**、耕畜农具作价入社，统一经营 | **按劳分配 + 土地分红**相结合 | **半社会主义性质** |
| 第三阶段 | **高级农业生产合作社** | **集体所有**，取消土地报酬 | **按劳分配** | **社会主义性质（完全）** |

- 1956 年 90% 的农户加入合作社；到 1956 年底农业社会主义改造基本完成。

#### 2. 手工业⭐⭐

- 方针："积极领导、稳步前进"；方法：从**供销合作**入手，逐步发展到**生产合作**；手段：说服教育、典型示范、国家帮助。
- **三步骤**（对比记忆）：**供销小组**（未改变私有制，脱离资本主义工商业供销轨道 → 社会主义萌芽性质）→ **供销合作社**（统一供销业务，部分生产资料公有 → 半社会主义性质）→ **生产合作社**（生产资料集体所有、集体劳动、按劳分配 → 社会主义性质）。
- 到 1956 年底基本完成（生产合作社占全部手工业合作组织 70.5%，产值占 87.8%）。

#### 3. 资本主义工商业⭐⭐⭐

**第一，用和平赎买的方法改造。**

- 赎买 = 国家**有偿**地将私营企业改变为国营企业；**不是由国家支付一笔巨额补偿资金，而是让资本家在一定年限内从企业经营所得中获取一部分利润**。
- 能够和平赎买的原因（3 条）⭐⭐：
  1. **民族资产阶级具有两面性**（剥削工人 / 拥护党的领导、愿意接受改造），矛盾处理得当可转为非对抗性；
  2. **中国共产党与民族资产阶级长期保持统一战线关系**；
  3. **人民民主专政国家政权 + 强大的社会主义国营经济掌握经济命脉**，加上粮棉统购统销、工人监督，使私人资本主义只能接受改造。

**第二，采取从低级到高级的国家资本主义过渡形式。**

- 国家资本主义 = 在人民政府管理之下、用各种形式和国营社会主义经济联系着、并受工人监督的资本主义经济；"带着很大的社会主义性质"。
- **初级形式**：委托加工、计划订货、统购包销、经销代销（企业**外部**合作）；
- **高级形式**：公私合营（个别企业公私合营 → 全行业公私合营，企业**内部**合作）。

**三个步骤**⭐⭐⭐

| 步骤 | 形式 | 利润分配 | 性质 |
| --- | --- | --- | --- |
| 第1步 | 初级形式的国家资本主义 | **"四马分肥"**：国家所得税、企业公积金、工人福利费、资方红利（约 1/4） | 具有社会主义因素 |
| 第2步 | **个别企业**公私合营（国家入股、公方代表居领导地位） | 仍"四马分肥" | **半社会主义性质** |
| 第3步 | **全行业**公私合营（1956 年高潮） | 清产核资、**定股定息**，生产资料归国家所有 | 基本成为**社会主义国营性质** |

- 1956 年底：全国私营工业户数的 **99%**、私营商业户数的 **82%** 纳入公私合营或合作社轨道 → 对资本主义工商业改造**基本完成**。

**第三，把资本主义工商业者改造成为自食其力的社会主义劳动者。**

- 对资方在职人员和资方代理人采取"**包下来**"政策，"量才使用，适当照顾"；改造企业同改造人相结合。
- 案例：荣毅仁 1956 年率先将全部企业交给国家合营。

### 二、社会主义改造的历史经验⭐⭐⭐

1. **坚持社会主义工业化建设与社会主义改造同时并举**——围绕工业化中心任务变革生产关系，"一五"计划主要指标 1956 年提前完成、1957 年超额完成，改造未破坏生产力反而促进发展；
2. **积极采取引导、逐步过渡的方式**——区别对象、创造从低级到高级的过渡形式（互助组→初级社→高级社；初级→高级国家资本主义），符合农民特点与生产力状况；
3. **用和平方法进行改造**——说服教育的方法，既保证改造顺利进行，又维护了社会稳定。

**失误与偏差**（辩证评价必背）⭐

- "1955 年夏季以后，农业合作化以及对手工业和个体商业的改造**要求过急，工作过粗，改变过快，形式也过于简单划一**"；1956 年后"对一部分原工商业者的使用和处理也不很适当"（《关于建国以来党的若干历史问题的决议》）。
- 认识根源：经济模式选择过于单一、公有制实现形式理解简单化，缺乏公有制与非公有制**共同发展**的认识；对社会主义发展阶段未形成科学理论。
- ⭐ 但**不能因失误偏差否定社会主义改造的伟大意义**——两个世界罕见的事实：①几亿人口的大国实现复杂深刻的社会变革，未破坏生产力反而促进发展；②未引起巨大社会动荡，反而加强人民团结、在人民普遍拥护下完成。邓小平："我们的社会主义改造是搞得成功的，很了不起。这是毛泽东同志对马克思列宁主义的一个重大贡献。"

## 第三节 社会主义基本制度在中国的确立

### 一、确立标志及其理论根据

**1. 经济标志**⭐⭐

- 1956 年底三大改造基本完成 → 农业手工业个体所有制变为**劳动群众集体所有制**，资本主义私有制变为**全民所有制**；公有制占绝对优势，成为社会经济的**基础**。
- ⭐ 标志着**中国历史上长达数千年的阶级剥削制度的结束**和**社会主义基本制度的确立**。
- 数据：1956 年国营+合作社+公私合营经济占国民收入 **92.9%**；全国 96.3% 的农户加入农业生产合作社。

**2. 政治标志**⭐⭐

- 1954 年 9 月，**第一届全国人民代表大会**召开和**《中华人民共和国宪法》**颁布施行——社会主义民主政治建设的里程碑。
- 宪法明确规定：国体 = **人民民主专政**；政体 = **人民代表大会制度**。
- 制度体系：**人民代表大会制度**（根本政治制度）+ **中国共产党领导的多党合作和政治协商制度** + **民族区域自治制度**（基本政治制度）。

**3. 阶级关系的根本变化（7 条）**
帝国主义侵略势力被清除；官僚资产阶级被消灭；地主富农、民族资产阶级被改造成自食其力的劳动者；工人阶级成为领导阶级；农民和个体劳动者成为集体劳动者；知识界成为为社会主义服务的队伍。

**4. 理论根据：反对"庸俗生产力论"**⭐

- 第二国际机会主义者以"没有经济前提"否定落后国家可以走向社会主义；
- **列宁**批评这是"庸俗生产力论"："为什么不能首先用革命手段取得达到这个一定水平的前提，然后在工农政权和苏维埃制度的基础上赶上别国人民呢？"
- **毛泽东**："生产关系的革命，是生产力的一定发展所引起的。但是，生产力的大发展，总是在生产关系改变以后。"
- **邓小平**："我们也是反对庸俗的生产力论……在一个很不发达的中国能搞社会主义。"
- 结论：中国可以在未工业化的情况下进入社会主义；但也因经济文化落后，只能是**社会主义初级阶段**。

### 二、确立社会主义基本制度的重大意义（4 条）⭐⭐

1. **极大地促进了我国社会生产力的发展**——为当代中国一切发展进步奠定了**制度基础**（两大优势：与社会化大生产的一致性；经济落后条件下集中力量办大事）；
2. **实现了中华民族有史以来最为广泛而深刻的社会变革**——使广大劳动人民真正成为国家的主人，是中国几千年来阶级关系的最根本变革；
3. **使占世界人口 1/4 的东方大国进入社会主义社会**——世界社会主义发展史上又一个历史性的伟大胜利，改变世界政治经济格局，增强社会主义力量；
4. **是马克思列宁主义关于社会主义革命理论在中国的正确运用和创造性发展**——对脱胎于半殖民地半封建的东方大国如何进行社会主义革命的系统回答。

## 05易错点辨析

1. **新民主主义社会 ≠ 独立的社会形态**——它是过渡性的、属于社会主义体系的社会；1949 年建国时**尚未进入**社会主义社会。
2. **五种经济成分 vs 三种主要经济成分**——答题先写五种（国营/合作社/个体/私人资本主义/国家资本主义），再指出主要的是三种；合作社经济是**半**社会主义性质，国家资本主义是过渡**形式**，两者都不能直接归为社会主义经济。
3. **互助组（萌芽）≠ 初级社（半社会主义）≠ 高级社（社会主义）**——区分标志看两点：生产资料归谁所有 + 是否取消土地分红。初级社"土地入股、按劳分配与土地分红相结合"是半社会主义；高级社取消土地报酬才是完全社会主义性质。
4. **手工业改造第二步是"供销合作社"（半社会主义），第三步"生产合作社"才是社会主义性质**——别与农业的"初级社/高级社"混淆。
5. **和平赎买 ≠ 国家支付巨额补偿**——是让资本家在一定年限内从企业经营所得中获取一部分利润。
6. **"四马分肥"只用于初级形式和个别企业公私合营阶段**；全行业公私合营后实行**定股定息**，企业已是社会主义国营性质。
7. **"一化"与"三改"不是并列关系**——一化是"主体"、三改是"两翼"，相辅相成；总路线是建设与改造**同时并举**的路线。
8. **时间线易混**：正式提出总路线是 1953.6；完整表述是 1953.12；批准并写入宪法是 1954。三大改造基本完成（1956 年底）才标志社会主义基本制度确立，**不是 1949 年建国**。
9. **资本主义工商业改造三步骤的性质递进**：初级国家资本主义（有社会主义因素）→ 个别企业公私合营（半社会主义）→ 全行业公私合营（基本社会主义国营性质）。
10. **失误偏差的评价口径**——"要求过急、工作过粗、改变过快、形式过于简单划一"四个短语是固定表述（引《决议》原文），但不能据此否定改造的伟大意义。
