## 03正文精讲

## 第一节 坚定中国特色社会主义政治制度自信

::: info 本节指引 · 第一节 坚定中国特色社会主义政治制度自信

- **目标**：记住人民民主的地位表述、根本政治制度与三项基本政治制度，以及党的领导、人民当家作主、依法治国三者有机统一中各自的定位。
- **建议用时**：15 分钟
- **知识点**：`人民民主是社会主义的生命与政治制度自信`

:::

::: info 人民民主是社会主义的生命

- **白话**：民主不是装饰：没有民主，就没有社会主义，也谈不上现代化和民族复兴。
- **教材表述**：人民民主是社会主义的生命；没有民主就没有社会主义，就没有社会主义的现代化，就没有中华民族伟大复兴（课1 p4/p9）。
- **情境**：回答「为什么说民主是社会主义的生命」：把三个「没有」连成一条逻辑链——性质（社会主义）、目标（现代化）、使命（民族复兴）都离不开民主。
- **易混区别**：三个「没有」的宾语不能漏项或换序：社会主义、社会主义现代化、中华民族伟大复兴；答题只写「没有民主就没有社会主义」会丢分。
- **答题关键词**：人民民主是社会主义的生命、没有民主就没有社会主义、没有社会主义现代化、没有中华民族伟大复兴

:::

::: info 根本政治制度与基本政治制度

- **白话**：一个人大制度是根本，三项基本制度是配套——一名三配，不能混。
- **教材表述**：根本政治制度：人民代表大会制度；基本政治制度：中国共产党领导的多党合作和政治协商制度、民族区域自治制度、基层群众自治制度（课1 p10）。
- **情境**：题干问「我国的根本政治制度是」：只能答人民代表大会制度；若问「基本政治制度」则要写全三项。
- **易混区别**：「根本」只有一项（人民代表大会制度），「基本」有三项；把多党合作和政治协商制度说成根本政治制度是最常见错误。
- **答题关键词**：根本政治制度：人民代表大会制度、中国共产党领导的多党合作和政治协商制度、民族区域自治制度、基层群众自治制度

:::

::: info 三者有机统一

- **白话**：党是保证、人民是本质、法治是方式；最根本的是坚持党的领导。
- **教材表述**：坚持党的领导、人民当家作主、依法治国有机统一：党的领导是根本保证，人民当家作主是本质特征，依法治国是基本方式；三者统一于我国社会主义民主政治伟大实践，最根本的是坚持党的领导（课1 p15）。
- **情境**：辨析「人民当家作主最重要还是党的领导最重要」：三者有机统一，但「最根本」的定位落在坚持党的领导上。
- **易混区别**：三个定位词必须一对一：根本保证＝党的领导、本质特征＝人民当家作主、基本方式＝依法治国；尤其不要把「本质特征」配给依法治国。
- **答题关键词**：根本保证、本质特征、基本方式、最根本的是坚持党的领导

:::

::: info 八个能否

- **白话**：评价一个国家的政治制度民不民主、有没有效，看八个方面能不能做到。
- **教材表述**：「八个能否」是评价一个国家政治制度是不是民主的、有效的标准（课1 p13）。
- **情境**：面对「用西方标准评价中国政治制度」的设问：用「八个能否」说明评价标准应看实践成效，而非照搬他国尺度。
- **易混区别**：「八个能否」是评价标准，不是政治制度的构成；不要与根本政治制度、基本政治制度的清单混答。
- **答题关键词**：八个能否、评价政治制度是不是民主的、有效的标准

:::

导语：制度优势是一个政党、一个国家的最大优势。中国特色社会主义政治制度是扎根中国大地、保证人民当家作主的好制度；坚定中国特色社会主义制度自信，首先要坚定对中国特色社会主义政治制度的自信⭐。

### 一、人民民主是社会主义的生命⭐⭐

**1. 民主是全人类共同价值；民主是历史的、具体的、不断发展的**

- 民主制度植根于本国的历史文化传统，必须与本国国情相适应；实现民主的道路并非只有一条；**民主没有最好，只有更好**，人类对民主的探索和实践永无止境。

| 时期 | 民主发展成就 |
| --- | --- |
| 新民主主义革命时期 | 成立新中国，实现中国从几千年封建专制政治向人民民主的**伟大飞跃**，人民当家作主从梦想变为现实 |
| 社会主义革命和建设时期 | 人民当家作主的**政治架构、经济基础、法律原则、制度框架**基本确立并不断发展 |
| 改革开放和社会主义现代化建设新时期 | 民主发展的**政治制度保障和社会物质基础**更加坚实 |
| 中国特色社会主义新时代 | 团结带领人民**发展全过程人民民主**，健全人民当家作主制度体系，取得新的历史性成就 |

**2. 人民民主是一种新型的社会主义民主**⭐⭐

- 人民民主建立在**社会主义经济基础**之上，体现了社会主义国家的性质，反映了社会主义制度的本质要求。
- 国体体现：**工人阶级领导的、以工农联盟为基础的人民民主专政**的社会主义国家；政体体现：人民通过**各级人民代表大会**行使国家权力。
- 五点具体体现：①国家一切权力属于人民；②保证人民依法通过各种途径和形式管理国家事务、管理经济和文化事业、管理社会事务；③一切国家机关和工作人员依靠人民、倾听人民意见建议、接受人民监督、为人民服务；④法律法规和方针政策体现人民意志、维护最广大人民根本利益；⑤坚持以人民为中心的发展思想，不断满足人民日益增长的美好生活需要，促进人的全面发展。

**3. 人民民主是全面建设社会主义现代化国家的应有之义**⭐

- ①社会主义现代化是**全体人民的现代化**，以实现好、维护好、发展好最广大人民根本利益为出发点和落脚点；②全面建成社会主义现代化强国，**人民是决定性力量**；③民主的发展与国家治理的现代化**相伴相生、相互作用、相互促进**，为现代化建设提供坚强的制度保障。

**4. 结论（原文背诵）**⭐⭐

> &lt;p&gt;**没有民主就没有社会主义，就没有社会主义的现代化，就没有中华民族伟大复兴。社会主义愈发展，民主也愈发展。**&lt;/p&gt;

### 二、中国特色社会主义政治制度行得通、有生命力、有效率⭐⭐

**1. 制度体系构成（"四梁八柱"）**⭐⭐⭐

- 马克思主义认为，**民主首先而且主要是一种国家制度**。

| 层级 | 制度 | 定位 |
| --- | --- | --- |
| **根本政治制度** | 人民代表大会制度 | 坚持党的领导、人民当家作主、依法治国有机统一的**根本政治制度安排** |
| **基本政治制度** | 中国共产党领导的多党合作和政治协商制度、民族区域自治制度、基层群众自治制度 | 三项，构成我国的基本政治制度 |
| **重要政治制度** | 在根本、基本政治制度基础上形成的一系列具有中国特色的制度 | 制度体系的重要组成部分 |

**2. 为什么行得通、有生命力、有效率**

- 习近平："中国特色社会主义政治制度之所以行得通、有生命力、有效率，就是因为它是**从中国的社会土壤中生长起来的**"——是长期发展、渐进改进、**内生性演化**的结果，具有鲜明的中国特色、民族特色、时代特色⭐。
- 实践中的四大优势⭐⭐：①有效保证人民享有更加广泛、更加充实的权利和自由，保证人民广泛参加国家治理和社会治理；②有效调节国家政治关系，发展充满活力的**政党关系、民族关系、宗教关系、阶层关系、海内外同胞关系**，形成安定团结的政治局面；③能够**集中力量办大事**，有效促进社会生产力解放和发展；④有效维护国家独立自主，有力维护国家主权、安全、发展利益。

**3. 评价标准："八个能否"**⭐⭐（习近平在庆祝全国人民代表大会成立60周年大会上的讲话，2014年9月5日）

> &lt;p&gt;①国家领导层能否依法有序更替；②全体人民能否依法管理国家事务和社会事务、管理经济和文化事业；③人民群众能否畅通表达利益要求；④社会各方面能否有效参与国家政治生活；⑤国家决策能否实现科学化、民主化；⑥各方面人才能否通过公平竞争进入国家领导和管理体系；⑦执政党能否依照宪法法律规定实现对国家事务的领导；⑧权力运用能否得到有效制约和监督。&lt;/p&gt;

**4. 党的十八大以来的实践成就**（要点）：全面发展全过程人民民主，推进协商民主广泛多层制度化发展；全面深化党和国家机构改革；完善大统战工作格局；把**铸牢中华民族共同体意识**作为党的民族工作主线；全面贯彻党的宗教工作基本方针；以保障人民**生存权、发展权**为首要推进人权事业全面发展；社会主义民主政治制度化、规范化、程序化全面推进。

### 三、坚定不移走中国特色社会主义政治发展道路⭐⭐

- 中国特色社会主义政治发展道路，是近代以来中国人民长期奋斗**历史逻辑、理论逻辑、实践逻辑**的必然结果，是坚持党的本质属性、践行党的根本宗旨的必然要求。

**三条要求（必背）**⭐⭐⭐

| 要求 | 核心内容 |
| --- | --- |
| ①必须坚持党的领导、人民当家作主、依法治国有机统一 | **党的领导**是人民当家作主和依法治国的**根本保证**；**人民当家作主**是社会主义民主政治的**本质特征**；**依法治国**是党领导人民治理国家的**基本方式**；三者统一于我国社会主义民主政治伟大实践，**最根本的是坚持党的领导** |
| ②必须积极稳妥推进政治体制改革 | 中国特色社会主义民主是个新事物，也是个好事物，但制度并非完美无缺；要在坚持根本政治制度、基本政治制度的基础上不断深化政治体制改革，持续推进制度化、规范化、程序化 |
| ③必须始终保持政治定力 | 世界上不存在完全相同的政治制度，也不存在适用于一切国家的政治制度模式；两种简单化观点（别国有我们没有就搬过来、我们有别国没有就去掉）都是不正确的；不能割断历史、想象突然搬来政治制度上的**"飞来峰"** |

## 第二节 全过程人民民主是社会主义民主政治的本质属性

::: info 本节指引 · 第二节 全过程人民民主是社会主义民主政治的本质属性

- **目标**：按时间线说清全过程人民民主的提出与定性过程，记住「四个统一」「全链条五环节」与三个「最」。
- **建议用时**：14 分钟
- **知识点**：`全过程人民民主：本质属性、四个统一与三个「最」`

:::

::: info 全过程人民民主的「四个统一」

- **白话**：民主不是只看投票那一刻：过程与成果、程序与实质、直接与间接、民意与国家意志都要统一。
- **教材表述**：「四个统一」：过程民主和成果民主、程序民主和实质民主、直接民主和间接民主、人民民主和国家意志（课2 p4）。
- **情境**：批驳「中国只有形式民主」：用「过程民主和成果民主」「程序民主和实质民主」两组统一说明民主既看过程也看结果。
- **易混区别**：四组统一中的配对不能错搭：过程—成果、程序—实质、直接—间接、人民民主—国家意志。
- **答题关键词**：过程民主和成果民主、程序民主和实质民主、直接民主和间接民主、人民民主和国家意志

:::

::: info 全链条、全方位、全覆盖

- **白话**：五个环节连成链、五级人大覆盖到底、国家政治生活与社会生活都贯通。
- **教材表述**：全链条指民主选举、民主协商、民主决策、民主管理、民主监督五个环节贯通；全方位指贯通国家政治生活和社会生活各层面各维度；五级人大包括全国、省级、设区的市级、县级、乡镇级人民代表大会（课2 p7-8）。全过程人民民主是最广泛、最真实、最管用的民主（课2 p10-12）。
- **情境**：论述「全过程人民民主好在哪里」：按「最广泛（主体与范围）—最真实（制度与程序保障）—最管用（解决实际问题）」三层展开。
- **易混区别**：「三个最」的顺序与对应不要错：最广泛、最真实、最管用；不要把「最管用」写成「最有效」或与「四个统一」混答。
- **答题关键词**：民主选举、民主协商、民主决策、民主管理、民主监督、五级人大、最广泛、最真实、最管用

:::

## 第三节 健全人民当家作主的制度体系

::: info 人民代表大会制度

- **教材表述**：人民代表大会制度是我国的根本政治制度，也是实现全过程人民民主的重要制度载体（课3 p4/p5）；加强人民当家作主制度保障，要支持和保证人民通过人民代表大会行使国家权力。
- **情境**：回答「人大制度与全过程人民民主是什么关系」：双重定位——根本政治制度（地位）＋重要制度载体（功能）。

- **答题关键词**：有事好商量，众人的事情由众人商量、最大公约数、独特、独有、独到的优势、专门协商机构、七种协商渠道

- **答题关键词**：全过程人民民主的重要体现、社会主义民主最广泛的实践、自我管理、自我服务、自我教育、自我监督

### 二、全面发展协商民主⭐⭐

- 定义：在中国共产党领导下，人民内部各方面围绕改革发展稳定重大问题和涉及群众切身利益的实际问题，在**决策之前和决策实施之中**开展广泛协商、努力形成共识的重要民主形式。
- 五个"源自"：①中华民族长期形成的天下为公、兼容并蓄、求同存异等优秀政治文化；②近代以后中国政治发展的现实进程；③党领导人民进行革命、建设、改革的长期实践；④新中国成立后各党派、各团体、各民族、各阶层、各界人士在政治制度上的共同创造；⑤改革开放以来政治体制上的不断创新——具有深厚的**文化基础、理论基础、实践基础、制度基础**。

### 一、统一战线是凝聚人心、汇聚力量的强大法宝⭐⭐

**1. 地位**：统一战线是中国共产党夺取革命、建设、改革事业胜利的**重要法宝**，也是实现中华民族伟大复兴的重要法宝；新时代在维护国家主权、安全、发展利益，围绕中心、服务大局，增强党的阶级基础、扩大党的群众基础上的作用**更加重要**。

## 05易错点辨析

1. **"人民民主是社会主义的生命" ≠ "全过程人民民主是社会主义民主政治的本质属性"**——前者讲人民民主的地位，后者是党的二十大对全过程人民民主的定性表述，答题不能混搭。
2. **提出时间线别错置**——2019.11 上海虹桥首次提出"人民民主是一种全过程的民主"；2021.7 建党百年讲话提出"发展全过程人民民主"；2021.10 中央人大工作会议才"系统阐述"；"本质属性"的定性出自**党的二十大**而非十九届六中全会。
3. **根本政治制度只有一个，基本政治制度有三项**——人大制度是唯一的根本政治制度；多党合作和政治协商、民族区域自治、基层群众自治三项是基本政治制度；重要政治制度是"派生"的，别与基本政治制度混淆。
4. **三者有机统一的定位词不能互换**——党的领导是"根本保证"、人民当家作主是"本质特征"、依法治国是"基本方式"，且"最根本的是坚持党的领导"。
5. **五个民主环节的顺序与协商的时点**——民主选举、民主协商、民主决策、民主管理、民主监督；协商发生在"重大决策**之前和决策实施之中**"，不是决策之后。
6. **"最管用"的六个切实防止要与举措对应**——防"群龙无首、一盘散沙"对应党的领导下有效治理国家；防"选举时漫天许诺、选举后无人过问"对应人民依法行使权利；防"形式上有权、实际上无权"对应发展基层民主，别张冠李戴。
7. **选举民主与协商民主的关系**——不是相互替代、相互否定，而是相互补充、相得益彰；人民政协是"**专门协商机构**"、实行多党合作和政治协商制度的重要机构，不是国家权力机关。
8. **基层相关三个定位短语对象不同**——基层群众自治制度是"社会主义民主政治建设的**基础**"；基层民主是"全过程人民民主的**重要体现**"和"社会主义民主**最广泛的实践**"，三者不能互换。
9. **统战工作的"对象"与两个"最"表述**——工作对象是**党外人士**（重点是代表人士），不是全体国民；"本质要求是大团结大联合"与"党的领导是统一战线最鲜明的特征"是两个不同维度的表述，别混。
10. **"生命线"与"之本"主宾固定**——民族团结是我国各族人民的生命线；中华民族共同体意识是民族团结之本，两句不能颠倒。

- B ✅ 这句话是人民民主的真谛，落点在「商量」，对应协商民主——实践全过程人民民主的重要形式（课3 p9）。（来源：课件附答案但未附解析，本条依据本课正文补充。）
- C ❌ 基层民主是全过程人民民主的重要体现与最广泛的实践，但本句并不限于基层。干扰点：把「众人商量」直接联想到基层议事。
- D ❌ 党内民主范围在党内，本句讲的是「全社会意愿和要求」。干扰点：把党内民主与全社会民主混同。

**整句翻译**：题干问的是：「有事好商量，众人的事情由众人商量，找到全社会意愿和要求的最大公约数」这句话强调的是哪种民主形式。

**词组**：`人民民主的真谛` 有事好商量，众人的事情由众人商量，找到全社会意愿和要求的最大公约数（课3 p9）；`协商民主` 实践全过程人民民主的重要形式，与选举民主相互补充、相得益彰

**对比自测**：做完后对照 mcq:5，比较两题的判断依据

:::

**5. 统一战线工作的本质要求是（ ） 。**

- A. 一致性和多样性相统一
- B. 求同存异
- C. 大团结大联合
- D. 铸牢中华民族共同体意识

::: details 点开核对答案

**答案：C**

**逐选项解析**

- A ❌ 一致性和多样性相统一是统一战线要处理好的基本关系，不是本质要求。干扰点：把处理关系当成本质要求。
- B ❌ 求同存异是方式方法，不是本质要求。干扰点：把做法当成要求。
- C ✅ 统一战线工作的本质要求是大团结大联合，解决的是人心和力量问题（课4 p5）。（来源：课件附答案但未附解析，本条依据本课正文补充。）
- D ❌ 铸牢中华民族共同体意识是民族团结之本（民族工作主线），不是统一战线的本质要求。干扰点：把民族工作定位当成统战本质要求。

**整句翻译**：题干问的是：统一战线工作的本质要求是什么。

**词组**：`本质要求` 大团结大联合，解决的是人心和力量问题（课4 p5）；`一致性和多样性相统一` 统一战线处理的基本关系，不是「本质要求」的提法

**对比自测**：做完后对照 mcq:6，比较两题的判断依据

:::

**6. 铸牢中华民族共同体意识，就是要引导各族人民牢固树立的共同体理念是（ ） 。**

- A. 平等团结互助和谐
- B. 休戚与共、荣辱与共、生死与共、命运与共
- C. 自由平等公正法治
- D. 团结—批评—团结

::: details 点开核对答案

**答案：B**

**逐选项解析**

- A ❌ 「平等团结互助和谐」是社会主义新型民族关系的表述。干扰点：把民族关系表述与共同体理念混同。
- B ✅ 铸牢中华民族共同体意识要引导各族人民牢固树立休戚与共、荣辱与共、生死与共、命运与共的共同体理念（课4 p8-9）。（来源：课件附答案但未附解析，本条依据本课正文补充。）
- C ❌ 「自由平等公正法治」属社会主义核心价值观社会层面的内容。干扰点：把价值观内容当成共同体理念。
- D ❌ 「团结—批评—团结」是解决人民内部矛盾的方针方法。干扰点：把方针方法与共同体理念混答。

**整句翻译**：题干问的是：铸牢中华民族共同体意识要引导各族人民牢固树立的共同体理念是哪一句。

**词组**：`四个与共` 休戚与共、荣辱与共、生死与共、命运与共；`民族团结之本` 铸牢中华民族共同体意识的定位（课4 p8-9）

**对比自测**：做完后对照 mcq:5，比较两题的判断依据

## 主观题支架

### qa:1

**要点**

- 根本政治制度：人民代表大会制度。
- 基本政治制度（三项）：中国共产党领导的多党合作和政治协商制度、民族区域自治制度、基层群众自治制度。
- 在根本政治制度和基本政治制度基础上，形成中国特色社会主义政治制度体系（含经济、政治、文化、社会、生态文明等领域的具体制度）。

**推导**：先答「一根本」，再答「三基本」，最后用「在二者基础上形成的制度体系」收束。

**自评标准**

- [ ] 根本与基本是否分清（一根本、三基本）。
- [ ] 三项基本政治制度是否写全。
- [ ] 是否点出「在二者基础上形成制度体系」。

### qa:2

**要点**

- 党的领导是人民当家作主和依法治国的根本保证。
- 人民当家作主是社会主义民主政治的本质特征。
- 依法治国是党领导人民治理国家的基本方式。
- 三者统一于我国社会主义民主政治伟大实践，最根本的是坚持党的领导。

**推导**：三个定位词一一对应写出，再补「统一于伟大实践」与「最根本的是坚持党的领导」两句收束。

**自评标准**

- [ ] 三顶帽子是否与三者一一对应。
- [ ] 是否写出「统一于社会主义民主政治伟大实践」。
- [ ] 是否点出「最根本的是坚持党的领导」。

### qa:3

**要点**

- 全过程人民民主既是完整的制度程序，也是完整的参与实践。
- 全链条：民主选举、民主协商、民主决策、民主管理、民主监督五个环节贯通。
- 全方位：贯通国家政治生活和社会生活各层面各维度；五级人大（全国、省级、设区的市级、县级、乡镇级）。
- 全覆盖：涵盖全体人民、覆盖国家治理各领域各方面各环节。

**推导**：先总起「完整制度程序＋完整参与实践」，再按「全链条（五环节）—全方位（五级人大）—全覆盖」逐条展开。

**自评标准**

- [ ] 五环节是否写全且顺序正确。
- [ ] 是否答出五级人大。
- [ ] 是否点出「完整制度程序＋完整参与实践」。

### qa:4

**要点**

- 定位：协商民主是实践全过程人民民主的重要形式，是我国社会主义民主政治的特有形式。
- 优势：具有独特、独有、独到的优势，与选举民主相互补充、相得益彰，可以有效克服选举民主的一些弊端。
- 渠道：统筹推进政党协商、人大协商、政府协商、政协协商、人民团体协商、基层协商、社会组织协商七种渠道。
- 专门机构：人民政协作为专门协商机构，发挥重要平台作用。

**推导**：按「定位—优势—渠道—专门机构」四层写，优势一层要点出「三个独」与「与选举民主相补充」。

**自评标准**

- [ ] 是否答出「重要形式」与「特有形式」的定位。
- [ ] 是否写出七种协商渠道。
- [ ] 是否点出人民政协的专门协商机构作用。

### qa:5

**要点**

- 构成：新时代爱国统一战线是中国共产党领导的、以工农联盟为基础的，包括全体社会主义劳动者、社会主义事业的建设者、拥护社会主义的爱国者、拥护祖国统一和致力于中华民族伟大复兴的爱国者的联盟。
- 本质要求：大团结大联合，解决的是人心和力量问题。
- 定位：统一战线是凝聚人心、汇聚力量的强大法宝。
- 工作格局：党委统一领导、统战部门牵头协调、有关方面各负其责。

**推导**：先按「领导力量＋基础＋四类人士」写构成，再答本质要求与法宝定位，最后补大统战工作格局。

**自评标准**

- [ ] 四类人士是否齐全（劳动者、建设者、拥护社会主义的爱国者、拥护祖国统一和致力于民族复兴的爱国者）。
- [ ] 是否答出本质要求「大团结大联合」。
- [ ] 是否写出大统战工作格局的三个环节。

### qa:6

**要点**

- 提出过程：2019 年 11 月在上海虹桥街道基层立法联系点首次提出；2021 年 7 月进一步阐述；2021 年 10 月中央人大工作会议系统阐述；十九届六中全会写入党的重要文献；党的二十大明确其是社会主义民主政治的本质属性。
- 「四个统一」：过程民主和成果民主、程序民主和实质民主、直接民主和间接民主、人民民主和国家意志。
- 判断：全过程人民民主是党领导人民发展社会主义民主政治的伟大创造，是重大理念创新与标志性成果，最能体现社会主义民主政治的质的规定性。
- 落脚：全过程人民民主是最广泛、最真实、最管用的民主。

**推导**：先按时间线五节点说明提出与定性过程，再用「四个统一」论证其质的规定性，最后以「三个最」收束。

**自评标准**

- [ ] 时间线五节点是否齐全。
- [ ] 「四个统一」四组配对是否准确。
- [ ] 是否点出「本质属性」与「三个最」。

### qa:7

**要点**

- 坚持和完善人民代表大会制度：发挥其根本政治制度与重要制度载体作用，支持和保证人民通过人大行使国家权力。
- 坚持和完善三项基本政治制度：中国共产党领导的多党合作和政治协商制度（新型政党制度）、民族区域自治制度、基层群众自治制度。
- 全面发展协商民主：统筹推进七种协商渠道，发挥人民政协专门协商机构作用。
- 积极发展基层民主：实现自我管理、自我服务、自我教育、自我监督。
- 总要求：把人民当家作主具体地、现实地体现到国家政治生活和社会生活之中。

**推导**：按「人大制度—基本政治制度—协商民主—基层民主」四条主线写，每条给定位与做法，最后落到「具体地、现实地体现」的总要求。

**自评标准**

- [ ] 人大制度的双重定位是否写出。
- [ ] 三项基本政治制度与七种协商渠道是否提及。
- [ ] 是否以「具体地、现实地体现」收束。
