## 03正文精讲

## 第一节 教育、科技、人才是全面建设社会主义现代化国家的基础性、战略性支撑

::: info 本节指引 · 第一节 教育、科技、人才是全面建设社会主义现代化国家的基础性、战略性支撑

- **目标**：背出三者定位（教育是根本、科技是关键、人才是基础）与「三个第一」「三个坚持」，说清三大战略的内涵与「四个面向」「双轮驱动」。
- **建议用时**：15 分钟
- **知识点**：`教育、科技、人才的基础性战略性支撑与三个战略、三个坚持`

:::

::: info 三者总定位

- **白话**：教育打地基、科技当引擎、人才做根本；三者是一体的支撑，不是三条并列的事。
- **教材表述**：教育、科技、人才是全面建设社会主义现代化国家的基础性、战略性支撑：教育是根本、科技是关键、人才是基础（课1 p4）。
- **情境**：回答「为什么把三者放在一起部署」：一体推进的逻辑是教育培养人才、人才支撑科技、科技引领发展，任何一环脱节都会断链。
- **易混区别**：「根本—关键—基础」三顶帽子不能错位：教育是根本、科技是关键、人才是基础。这与「科技是第一生产力、人才是第一资源、创新是第一动力」是两组不同的固定搭配，答题时不要串。
- **答题关键词**：基础性、战略性支撑、教育是根本、科技是关键、人才是基础

:::

::: info 三个第一与三个坚持

- **白话**：三句「第一」讲作用，三句「坚持」讲做法。
- **教材表述**：「三个第一」：科技是第一生产力、人才是第一资源、创新是第一动力；「三个坚持」：坚持教育优先发展、坚持科技自立自强、坚持人才引领驱动（课1 p4）。
- **情境**：综合题要求「说明教育、科技、人才的战略地位」：先给总定位，再补「三个第一」与「三个坚持」，层次最完整。
- **易混区别**：「三个第一」与「三个坚持」内容不同但句式相近，最容易混写；记忆时前组记「生产力／资源／动力」，后组记「优先发展／自立自强／引领驱动」。
- **答题关键词**：科技是第一生产力、人才是第一资源、创新是第一动力、教育优先发展、科技自立自强、人才引领驱动

:::

::: info 三大战略与双轮驱动

- **白话**：科教兴国、人才强国、创新驱动三根梁；创新还要配上体制机制的改进才能跑起来。
- **教材表述**：深入实施科教兴国战略、人才强国战略、创新驱动发展战略；科教兴国是作为基本国策提出的（课1 p9）；创新驱动发展战略要「四个面向」——面向世界科技前沿、面向经济主战场、面向国家重大需求、面向人民生命健康，并坚持「双轮驱动」＝科技创新＋体制机制创新（课1 p10）；创新在国家发展全局中居于核心位置（课1 p11-12）。
- **情境**：分析「为什么光投钱搞研发不够」：用「双轮驱动」解释——科技创新的轮子要靠体制机制创新带动，否则成果难以转化。
- **易混区别**：「基本国策」是科教兴国；「居于核心位置」是创新。两者题干若混着问，要按题干关键词分别作答。
- **答题关键词**：科教兴国战略、人才强国战略、创新驱动发展战略、基本国策、四个面向、双轮驱动、创新居于核心位置

:::

### 一、坚持教育发展、科技创新、人才培养一体推进

**1. 总定位（本章总纲，必背）**⭐⭐⭐

- 教育、科技、人才是全面建设社会主义现代化国家的**基础性、战略性支撑**。
- 全面建设社会主义现代化国家，**教育是根本，科技是关键，人才是基础**。
- ⭐⭐⭐ "三个第一"：**科技是第一生产力、人才是第一资源、创新是第一动力**；"三个坚持"：坚持**教育优先发展、科技自立自强、人才引领驱动**，加快教育强国、科技强国、人才强国建设。
- ⭐ 现代化强国，必定是教育强国、科技强国、人才强国。坚持教育发展、科技创新、人才培养**良性循环**，坚持科教兴国战略、人才强国战略、创新驱动发展战略**有效联动**，坚持教育强国、科技强国、人才强国**一体推进**，就能为全面推进中国式现代化开辟发展新领域新赛道、塑造发展新动能新优势。

**2. 党重视教育、科技、人才事业的历史脉络**⭐⭐

| 时期 | 主要举措与论断 |
| --- | --- |
| 革命战争年代 | 在根据地开展文化教育；"没有知识分子参加的革命是不可能胜利的"；提出建立民族的、科学的、人民大众的新文化和新教育 |
| 新中国成立后 | 发出"向科学进军"号召；提出科学文化现代化、科学技术现代化等奋斗目标；"两弹一星"等国防尖端科技不断突破 |
| 改革开放以后 | 坚持教育为本；提出"科学技术是第一生产力"论断；实施知识创新工程、科教兴国战略、人才强国战略，建设创新型国家 |
| 进入新时代 | 提出"创新是第一动力"，全面实施创新驱动发展战略；召开全国教育大会、全国科技创新大会、中央人才工作会议；制定《中国教育现代化2035》等文件 |

**3. 新时代历史性成就（三领域对应记忆）**⭐

- 教育：建成**世界上规模最大的教育体系**，教育现代化发展总体水平跨入**世界中上国家行列**，教育普及水平实现历史性跨越；
- 科技：进入**创新型国家行列**，一些关键核心技术实现突破，科技事业实现历史性、整体性、格局性重大变化；
- 人才：发展成为全球**规模最宏大、门类最齐全**的人才资源大国，世界重要人才中心和创新高地建设步伐加快。

**4. 为什么必须一体推进（背景与紧迫性）**

- 全球科技创新进入空前密集活跃期，新一轮科技革命和产业变革正在重构全球创新版图、重塑全球经济结构，教育、科技、人才在综合国力竞争中的关键地位更加凸显；
- 我国正进入高质量发展阶段，面临**质量变革、效率变革、动力变革**的繁重任务，迫切需要教育、科技、人才提供新的动能；
- 同党和国家事业发展要求、人民群众期待、国际先进水平相比，我国教育、科技、人才发展水平**还有差距**。
- 习近平："时代越是向前，知识和人才的重要性就愈发突出，教育的地位和作用就愈发凸显。""谁牵住了科技创新这个'牛鼻子'，谁走好了科技创新这步先手棋，谁就能占领先机、赢得优势。"

### 二、深入实施科教兴国战略、人才强国战略、创新驱动发展战略⭐⭐⭐

三者**既相互融合又各有侧重**，要加强统筹、有效联动、系统集成，更好塑造我国发展新优势。

| 战略 | 核心内涵 | 实施要求 |
| --- | --- | --- |
| 科教兴国战略 | 全面落实**科学技术是第一生产力**的思想，坚持教育优先发展，把科技和教育作为经济社会发展的**重中之重** | 把教育摆在**优先发展**的战略地位；把科技创新作为提高社会生产力和综合国力的**战略支撑**；深化科教体制改革，促进科技和教育成果向现实生产力转化。⭐科教兴国是我国的**基本国策** |
| 人才强国战略 | 牢固树立**人才资源是第一资源**的理念，把我国由**人口大国**转化为**人才资源强国** | ⭐坚持**党管人才**原则，坚持尊重劳动、尊重知识、尊重人才、尊重创造；实施更加积极、更加开放、更加有效的人才政策。人才强国战略是国家和民族**长远发展大计** |
| 创新驱动发展战略 | 坚持**创新是第一动力**，把创新发展主动权牢牢掌握在自己手中 | ⭐创新在国家发展全局中居于**核心位置**；坚持"四个面向"；坚持**科技创新和体制机制创新双轮驱动**；坚决打赢关键核心技术攻坚战 |

- ⭐⭐ **"四个面向"**：面向**世界科技前沿**、面向**经济主战场**、面向**国家重大需求**、面向**人民生命健康**。

### 三、坚持教育优先发展、科技自立自强、人才引领驱动⭐⭐

总原则：紧紧围绕全面建设社会主义现代化国家战略需求，尊重教育、科技、人才事业发展客观规律。**教育优先发展重在夯实人力资源深度开发基础，科技自立自强重在坚持独立自主开拓创新，人才引领驱动重在巩固发展优势赢得竞争主动**。

| 要求 | 定位 | 要点 |
| --- | --- | --- |
| 教育优先发展 | 推动党和国家各项事业发展的**重要先手棋** | "抓教育就是抓发展、谋教育就是谋未来"；⭐"三个优先"：经济社会发展规划**优先安排教育发展**、财政资金投入**优先保障教育投入**、公共资源配置**优先满足教育和人力资源开发需要** |
| 科技自立自强 | 决定我国生存和发展的**基础能力** | 把科技自立自强作为**国家发展的战略支撑**；坚决攻克重要领域"卡脖子"技术；⭐**不等于自我封闭、自我隔绝**，要以更加开放的思维和举措推进国际科技交流合作 |
| 人才引领驱动 | 经济社会发展和国家现代化的**基本规律** | 把人才资源开发放在**最优先位置**；按照创新规律培养和吸引人才、按照市场规律让人才自由流动；发挥重大人才工程牵引作用，建设**全球人才高地** |

## 第二节 加快建设教育强国

::: info 本节指引 · 第二节 加快建设教育强国

- **目标**：记住教育的基础性、先导性、全局性地位与「四个服务」，说清立德树人的关键课程与「三问」，并掌握办好人民满意教育的着力点。
- **建议用时**：15 分钟
- **知识点**：`教育强国：立德树人与办好人民满意的教育`

:::

::: info 教育的地位与四个服务

- **白话**：教育是国家的大计：既是基础，也管方向。
- **教材表述**：教育具有基础性、先导性、全局性地位；坚持「四个服务」：为人民服务、为党治国理政服务、为巩固和发展中国特色社会主义制度服务、为改革开放和社会主义现代化建设服务；教育是国之大计、党之大计（课2 p4）。
- **情境**：分析「双减」等教育政策：从「为人民服务」与「办好人民满意的教育」切入，说明政策的价值取向。
- **易混区别**：「四个服务」中的第三项是「为巩固和发展中国特色社会主义制度服务」，不要与「为改革开放服务」混淆——四项的顺序与内容都要准确。
- **答题关键词**：基础性、先导性、全局性、四个服务、国之大计、党之大计

:::

::: info 立德树人与教育三问

- **白话**：先问培养什么人、怎么培养、为谁培养，再谈课程与方法。
- **教材表述**：教育的根本任务是立德树人；根本问题是培养什么人、怎样培养人、为谁培养人，这是建设教育强国的核心课题（课2 p7）；落实立德树人根本任务的关键课程是思想政治理论课（课2 p9）。
- **情境**：论述「怎样落实立德树人」：按「培养什么人（明白定位）→ 怎样培养人（三全育人、思政课、家校社协同）→ 为谁培养人（为党育人、为国育才）」三问作答。
- **易混区别**：「根本任务」是立德树人，「关键课程」是思想政治理论课，「根本问题」是培养什么人、怎样培养人、为谁培养人——三者提问角度不同，不能互换。
- **答题关键词**：立德树人、培养什么人、怎样培养人、为谁培养人、思想政治理论课、为党育人、为国育才

:::

::: info 办好人民满意的教育

- **白话**：基础教育打底、高等教育带头，教师是关键。
- **教材表述**：基础教育是基点、高等教育是龙头（课2 p12）；办好人民满意的教育要促进教育公平、建设高质量教育体系、增强服务发展能力；教师队伍建设是教育强国最重要的基础工作——教育大计，教师为本（课2 p15）。
- **情境**：材料题出现「乡村教师支持计划」：用「教师队伍建设是最重要的基础工作」与「促进教育公平」两条回应。
- **易混区别**：「基点」与「龙头」对应基础教育与高等教育，位置不能颠倒；「最重要的基础工作」指教师队伍建设，不是经费投入。

## 04考点闪卡 · 先回忆再翻面

## 05易错点辨析

1. **"教育是根本，科技是关键，人才是基础" ≠ "三个第一"**——前者是三者对全面建设社会主义现代化国家的定位分工，后者是科技第一生产力、人才第一资源、创新第一动力；两组表述都要背，不能交叉混搭。
2. **科教兴国是"基本国策"，人才强国战略是"国家和民族长远发展大计"**——两个定位表述各有归属，不能互换。
3. **科技自立自强 ≠ 自我封闭、自我隔绝**——要以更加开放的思维和举措推进国际科技交流合作，在开放合作中提升自身科技创新能力。
4. **"四个服务"（教育）≠ "四个面向"（科技创新）**——"四个服务"是对办好中国特色社会主义教育的要求；"四个面向"是实施创新驱动发展战略的要求，张冠李戴是常见命题陷阱。
5. **教育的根本任务是"立德树人"，教育的根本问题是"培养什么人、怎样培养人、为谁培养人"**——一个是"任务"、一个是"问题"（也是建设教育强国的核心课题），问什么答什么。
6. **基点、龙头、关键课程、基础工作四个喻指不能混**——基础教育是"基点"、高等教育是"龙头"（顺序固定不能颠倒）；思政课是立德树人的"关键课程"；教师队伍建设是建设教育强国"最重要的基础工作"。
7. **"卡脖子"技术问题的"根子"在基础理论研究跟不上**——基础研究处于科研链条**起始端**（源头），应用研究是**桥梁**，层次不能乱。
8. **四支国家战略科技力量定位各异**——"引领作用"是国家实验室、"建制化组织作用"是国家科研机构、"主力军和生力军"是高水平研究型大学、"主体"是企业；尤其不能把高校的"主力军"（基础研究）说成企业。
9. **人才引领驱动的"最优先位置"**——是"把**人才资源开发**放在最优先位置"，不要与"把教育摆在优先发展的战略地位"混淆；前者属人才工作、后者属教育优先发展。
10. **聚才三条路径的定位对应**——党的全面领导是"根本保证"（"纲"和"本"），体制机制改革是"重要保障"，营造环境是"社会条件"，三者的定位词对应固定。
11. **人才大国 ≠ 人才强国**——我国已是全球规模最宏大、门类最齐全的人才资源大国，但目标是由人才大国迈向人才强国、建设世界重要人才中心和创新高地。

**整句翻译**：题干问的是：在国家战略科技力量中发挥「建制化组织作用」的是哪一类机构。

**词组**：`四支战略科技力量` 国家实验室（引领）、国家科研机构（建制化组织）、高水平研究型大学（基础研究主力军）、科技领军企业（创新主体）

**对比自测**：做完后对照 mcq:6，比较两题的判断依据

:::

**8. 党中央战略谋划明确：到（ ） 年，形成我国在诸多领域人才竞争比较优势，国家战略科技力量和高水平人才队伍位居世界前列。**

- A. 2025
- B. 2030
- C. 2035
- D. 本世纪中叶

::: details 点开核对答案

**答案：C**

**逐选项解析**

- A ❌ 2025 年的节点是研发投入大幅增长，不是「位居世界前列」。干扰点：把三节点中最靠前的年份当答案。
- B ❌ 2030 年的节点是人才制度体系基本形成。干扰点：把制度节点与「位居世界前列」互换。
- C ✅ 到 2035 年，形成我国在诸多领域人才竞争比较优势，国家战略科技力量和高水平人才队伍位居世界前列（课4 p10）。（来源：课件附答案但未附解析，本条依据本课正文补充。）
- D ❌ 「本世纪中叶」是建设社会主义现代化强国的长远目标节点，与人才节点不同。干扰点：把长远目标当人才节点。

**整句翻译**：题干问的是：到哪一年形成我国在诸多领域人才竞争比较优势，国家战略科技力量和高水平人才队伍位居世界前列。

**词组**：`人才中心和高地三节点` 2025 年研发投入大幅增长、2030 年人才制度体系基本形成、2035 年位居世界前列

**对比自测**：做完后对照 mcq:2，比较两题的判断依据

## 主观题支架

### qa:1

**要点**

- 总定位：教育、科技、人才是全面建设社会主义现代化国家的基础性、战略性支撑。
- 三顶帽子：教育是根本、科技是关键、人才是基础。
- 「三个第一」：科技是第一生产力、人才是第一资源、创新是第一动力。
- 「三个坚持」：坚持教育优先发展、坚持科技自立自强、坚持人才引领驱动。

**推导**：先答共同定位（基础性、战略性支撑），再写三顶帽子，最后补「三个第一」与「三个坚持」两组固定表述。

**自评标准**

- [ ] 三顶帽子是否与教育／科技／人才一一对应。
- [ ] 「三个第一」与「三个坚持」是否写全且不串行。
- [ ] 是否写出共同定位「基础性、战略性支撑」。

### qa:2

**要点**

- 科教兴国战略：基于科技是第一生产力的思想，坚持教育优先发展，把科技和教育摆在经济社会发展的重要位置。
- 人才强国战略：基于人才是第一资源的思想，坚持党管人才，培养造就高素质人才队伍。
- 创新驱动发展战略：基于创新是第一动力的思想，坚持「四个面向」「双轮驱动」，把创新摆在国家发展全局的核心位置。
- 三者关系：既相互融合又各有侧重，要加强统筹、有效衔接，形成合力。

**推导**：三段式作答：先逐个战略写「思想基础 + 核心做法」，再写三者「相互融合、各有侧重、统筹衔接」的关系。

**自评标准**

- [ ] 三个战略是否各有「思想基础 + 做法」。
- [ ] 是否写出三者的关系（融合、侧重、统筹）。
- [ ] 是否点出创新居核心位置、教育优先发展等关键提法。

### qa:3

**要点**

- 培养什么人：社会主义教育要培养社会主义建设者和接班人，「定语就是社会主义」，做到拥护党的领导和社会主义制度、立志为中国特色社会主义事业奋斗终身等要求。
- 怎样培养人：坚持全员育人、全程育人、全方位育人（三全育人）；发挥思想政治理论课的关键课程作用；学校、家庭、社会协同育人。
- 为谁培养人：坚持为党育人、为国育才，教育要为人民服务、为中国共产党治国理政服务、为巩固和发展中国特色社会主义制度服务、为改革开放和社会主义现代化建设服务。

**推导**：按「培养什么人—怎样培养人—为谁培养人」三问逐条作答，每问先给判断再给要点；结尾可落到「立德树人是根本任务」。

**自评标准**

- [ ] 三问是否完整（三顶帽子齐全）。
- [ ] 「怎样培养人」是否包含三全育人、思政课、家校社协同。
- [ ] 「为谁培养人」是否答出为党育人、为国育才。

### qa:4

**要点**

- 关键核心技术是国之重器，要不来、买不来、讨不来。
- 核心技术受制于人是最大的隐患，必须把主动权掌握在自己手中。
- 从根本上保障国家经济安全、国防安全和其他安全，避免在关键领域被「卡脖子」。
- 掌握国际竞争主动权与产业发展主导权，为高质量发展提供支撑。

**推导**：先用「国之重器、三不」定性，再答受制于人的风险，最后从「安全」与「竞争主动权」两方面说清为什么必须自己掌握。

**自评标准**

- [ ] 是否写出「要不来、买不来、讨不来」。
- [ ] 是否点出「最大隐患」与安全意义。
- [ ] 是否落到竞争主动权与发展支撑。

### qa:5

**要点**

- 坚持党对人才工作的全面领导：这是集聚优秀人才的根本保证。
- 深化人才发展体制机制改革：这是重要保障，要破除「四唯」（唯论文、唯职称、唯学历、唯奖项），做到以用为本。
- 营造识才爱才敬才用才的环境：这是社会条件，让人才安心安身安业。

**推导**：三条路径按「根本保证—重要保障—社会条件」三顶帽子写，每条补一句做法；机制改革一条要写出「四唯」。

**自评标准**

- [ ] 三条路径是否齐全且定位词正确。
- [ ] 是否写出「四唯」的具体内容。
- [ ] 是否点出「以用为本」等方针要点。

### qa:6

**要点**

- 教育的四重定位：基础性、先导性、全局性地位，是国之大计、党之大计。
- 坚持「四个服务」：为人民服务、为党治国理政服务、为巩固和发展中国特色社会主义制度服务、为改革开放和社会主义现代化建设服务。
- 落实立德树人根本任务：解决好培养什么人、怎样培养人、为谁培养人的根本问题，发挥思政课的关键课程作用。
- 办好人民满意的教育：促进教育公平、建设高质量教育体系、增强服务发展能力，基础教育是基点、高等教育是龙头。
- 加强教师队伍建设：教育大计、教师为本，这是教育强国最重要的基础工作。

**推导**：按「定位（三性＋两个大计）→ 四个服务 → 立德树人（三问＋关键课程）→ 办好人民满意的教育（公平、质量、服务）→ 教师队伍」五层展开。

**自评标准**

- [ ] 是否写出教育的三性与「四个服务」。
- [ ] 是否答出立德树人的三问与思政课的关键作用。
- [ ] 是否提到基础教育基点、高等教育龙头与教师队伍建设。

### qa:7

**要点**

- 战略意义：科技自立自强是国家强盛之基、安全之要，是国家发展的战略支撑。
- 打赢关键核心技术攻坚战：发挥新型举国体制优势，推进科技体制改革（如「揭榜挂帅」等机制），把关键核心技术掌握在自己手中。
- 增强自主创新能力：推进原始创新、集成创新、开放创新，加强基础研究这一自主创新的源头。
- 强化战略科技力量：国家实验室引领、国家科研机构发挥建制化组织作用、高水平研究型大学成为基础研究主力军、科技领军企业成为创新主体。
- 深化人才与教育支撑：坚持教育优先发展、人才引领驱动，为科技强国提供人才基础。

**推导**：先答科技自立自强的定位（强盛之基、安全之要、战略支撑），再按「攻坚战（体制与举国体制）—自主创新（基础研究）—战略科技力量—人才教育支撑」四层展开。

**自评标准**

- [ ] 是否答出科技自立自强的定位表述。
- [ ] 是否写出新型举国体制与科技体制改革举措。
- [ ] 是否答出四支战略科技力量的各自定位。
