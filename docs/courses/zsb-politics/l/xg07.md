## 03正文精讲

## 第一节 教育、科技、人才是全面建设社会主义现代化国家的基础性、战略性支撑

### 一、坚持教育发展、科技创新、人才培养一体推进

**1. 总定位（本章总纲，必背）**⭐⭐⭐
- 教育、科技、人才是全面建设社会主义现代化国家的**基础性、战略性支撑**。
- 全面建设社会主义现代化国家，**教育是根本，科技是关键，人才是基础**。
- ⭐⭐⭐ "三个第一"：**科技是第一生产力、人才是第一资源、创新是第一动力**；"三个坚持"：坚持**教育优先发展、科技自立自强、人才引领驱动**，加快教育强国、科技强国、人才强国建设。
- ⭐ 现代化强国，必定是教育强国、科技强国、人才强国。坚持教育发展、科技创新、人才培养**良性循环**，坚持科教兴国战略、人才强国战略、创新驱动发展战略**有效联动**，坚持教育强国、科技强国、人才强国**一体推进**，就能为全面推进中国式现代化开辟发展新领域新赛道、塑造发展新动能新优势。

**2. 党重视教育、科技、人才事业的历史脉络**⭐⭐

| 时期 | 主要举措与论断 |
| --- | --- |
| 革命战争年代 | 在根据地开展文化教育；"没有知识分子参加的革命是不可能胜利的"；提出建立民族的、科学的、人民大众的新文化和新教育 |
| 新中国成立后 | 发出"向科学进军"号召；提出科学文化现代化、科学技术现代化等奋斗目标；"两弹一星"等国防尖端科技不断突破 |
| 改革开放以后 | 坚持教育为本；提出"科学技术是第一生产力"论断；实施知识创新工程、科教兴国战略、人才强国战略，建设创新型国家 |
| 进入新时代 | 提出"创新是第一动力"，全面实施创新驱动发展战略；召开全国教育大会、全国科技创新大会、中央人才工作会议；制定《中国教育现代化2035》等文件 |

**3. 新时代历史性成就（三领域对应记忆）**⭐
- 教育：建成**世界上规模最大的教育体系**，教育现代化发展总体水平跨入**世界中上国家行列**，教育普及水平实现历史性跨越；
- 科技：进入**创新型国家行列**，一些关键核心技术实现突破，科技事业实现历史性、整体性、格局性重大变化；
- 人才：发展成为全球**规模最宏大、门类最齐全**的人才资源大国，世界重要人才中心和创新高地建设步伐加快。

**4. 为什么必须一体推进（背景与紧迫性）**
- 全球科技创新进入空前密集活跃期，新一轮科技革命和产业变革正在重构全球创新版图、重塑全球经济结构，教育、科技、人才在综合国力竞争中的关键地位更加凸显；
- 我国正进入高质量发展阶段，面临**质量变革、效率变革、动力变革**的繁重任务，迫切需要教育、科技、人才提供新的动能；
- 同党和国家事业发展要求、人民群众期待、国际先进水平相比，我国教育、科技、人才发展水平**还有差距**。
- 习近平："时代越是向前，知识和人才的重要性就愈发突出，教育的地位和作用就愈发凸显。""谁牵住了科技创新这个'牛鼻子'，谁走好了科技创新这步先手棋，谁就能占领先机、赢得优势。"

### 二、深入实施科教兴国战略、人才强国战略、创新驱动发展战略⭐⭐⭐

三者**既相互融合又各有侧重**，要加强统筹、有效联动、系统集成，更好塑造我国发展新优势。

| 战略 | 核心内涵 | 实施要求 |
| --- | --- | --- |
| 科教兴国战略 | 全面落实**科学技术是第一生产力**的思想，坚持教育优先发展，把科技和教育作为经济社会发展的**重中之重** | 把教育摆在**优先发展**的战略地位；把科技创新作为提高社会生产力和综合国力的**战略支撑**；深化科教体制改革，促进科技和教育成果向现实生产力转化。⭐科教兴国是我国的**基本国策** |
| 人才强国战略 | 牢固树立**人才资源是第一资源**的理念，把我国由**人口大国**转化为**人才资源强国** | ⭐坚持**党管人才**原则，坚持尊重劳动、尊重知识、尊重人才、尊重创造；实施更加积极、更加开放、更加有效的人才政策。人才强国战略是国家和民族**长远发展大计** |
| 创新驱动发展战略 | 坚持**创新是第一动力**，把创新发展主动权牢牢掌握在自己手中 | ⭐创新在国家发展全局中居于**核心位置**；坚持"四个面向"；坚持**科技创新和体制机制创新双轮驱动**；坚决打赢关键核心技术攻坚战 |

- ⭐⭐ **"四个面向"**：面向**世界科技前沿**、面向**经济主战场**、面向**国家重大需求**、面向**人民生命健康**。

### 三、坚持教育优先发展、科技自立自强、人才引领驱动⭐⭐

总原则：紧紧围绕全面建设社会主义现代化国家战略需求，尊重教育、科技、人才事业发展客观规律。**教育优先发展重在夯实人力资源深度开发基础，科技自立自强重在坚持独立自主开拓创新，人才引领驱动重在巩固发展优势赢得竞争主动**。

| 要求 | 定位 | 要点 |
| --- | --- | --- |
| 教育优先发展 | 推动党和国家各项事业发展的**重要先手棋** | "抓教育就是抓发展、谋教育就是谋未来"；⭐"三个优先"：经济社会发展规划**优先安排教育发展**、财政资金投入**优先保障教育投入**、公共资源配置**优先满足教育和人力资源开发需要** |
| 科技自立自强 | 决定我国生存和发展的**基础能力** | 把科技自立自强作为**国家发展的战略支撑**；坚决攻克重要领域"卡脖子"技术；⭐**不等于自我封闭、自我隔绝**，要以更加开放的思维和举措推进国际科技交流合作 |
| 人才引领驱动 | 经济社会发展和国家现代化的**基本规律** | 把人才资源开发放在**最优先位置**；按照创新规律培养和吸引人才、按照市场规律让人才自由流动；发挥重大人才工程牵引作用，建设**全球人才高地** |

## 第二节 加快建设教育强国

教育强国四重定位⭐⭐：全面建成社会主义现代化强国的**战略先导**、实现高水平科技自立自强的**重要支撑**、促进全体人民共同富裕的**有效途径**、以中国式现代化全面推进中华民族伟大复兴的**基础工程**。必须把教育事业放在**优先发展**的战略位置，把**立德树人**作为教育的根本任务。

### 一、教育是民族振兴、社会进步的基石

**1. 教育的战略地位**⭐⭐
- 教育是**国之大计、党之大计**，是功在当代、利在千秋的**德政工程**，对提高人民综合素质、促进人的全面发展、增强中华民族创新创造活力、实现中华民族伟大复兴具有**决定性意义**。
- 教育在国家发展中始终具有**基础性、先导性、全局性**地位。"教育兴则国家兴，教育强则国家强。"
- ⭐⭐ **"四个服务"**：坚持教育**为人民服务，为中国共产党治国理政服务，为巩固和发展中国特色社会主义制度服务，为改革开放和社会主义现代化建设服务**。

**2. 办好中国特色社会主义教育的政治要求**⭐⭐

| 要求 | 要点 |
| --- | --- |
| 坚持党对教育工作的全面领导 | 办好教育的**根本保证**；建立健全党委统一领导、党政齐抓共管、部门各负其责的教育领导体制 |
| 坚持党的教育方针 | 教育事业发展的**根本遵循**：教育必须为社会主义现代化建设服务、为人民服务，必须与生产劳动和社会实践相结合，培养**德智体美劳全面发展的社会主义建设者和接班人** |
| 坚持社会主义办学方向 | 始终坚持**马克思主义指导地位**，把立德树人作为教育的根本任务，牢牢掌握思想政治工作主导权 |
| 坚持扎根中国大地办教育 | 我国独特的历史、独特的文化、独特的国情决定**不能简单以国外教育作为标准和模式**；走扎根中国、融通中外，立足时代、面向未来的发展道路 |

### 二、落实立德树人根本任务⭐⭐⭐

- 育人的根本在于**立德**。⭐⭐⭐ **培养什么人、怎样培养人、为谁培养人**是教育的**根本问题**，也是建设教育强国的**核心课题**。
- 建设教育强国的目的：培养一代又一代德智体美劳全面发展的社会主义建设者和接班人，确保党的事业和社会主义现代化强国建设**后继有人**。

| 根本问题 | 要点 |
| --- | --- |
| 培养什么人 | 习近平："社会主义建设者和接班人，定语就是'社会主义'，这是我们对培养什么人的本质规定。"四个要求：①坚定**共产主义远大理想和中国特色社会主义共同理想**，永远听党话、跟党走；②有高尚**道德品质**，厚植爱国主义情怀，践行社会主义核心价值观；③养成刻苦学习习惯，增长知识见识、练就过硬本领、培养**创新思维**；④积极投身**社会实践**，掌握真才实学 |
| 怎样培养人 | 坚持系统思维，发挥家庭、学校、社会协同育人机制作用，实现**全员育人、全过程育人、全方位育人**；把立德树人融入各环节、贯穿各领域、体现到各方面，推进**大中小学思想政治教育一体化**建设；⭐**思想政治理论课是落实立德树人根本任务的关键课程**；家庭是人生的第一所学校，家长是孩子的第一任老师，扣好人生第一粒扣子 |
| 为谁培养人 | 每个国家都是按照**自己的政治要求**来培养人的；必须坚持**为党育人、为国育才**，把立德树人内化到教育各领域各方面各环节，作为检验教育工作的**根本标准** |

### 三、办好人民满意的教育⭐⭐

人民满意是发展教育的**根本尺度**。五条举措：

| 举措 | 要点 |
| --- | --- |
| 1 大力促进教育公平 | 教育公平是**社会公平的重要基础**，是国家**基本教育政策**；推动义务教育优质均衡发展和城乡一体化；缩小城乡、区域、校际、群体差距，满足群众"上好学"需要 |
| 2 加快建设高质量教育体系 | ⭐**基础教育是基点，高等教育是龙头**（把建设中国特色、世界一流的大学和优势学科作为重中之重）；扭转教育功利化倾向；建设全民终身学习的**学习型社会、学习型大国** |
| 3 提升教育服务经济社会发展能力 | 加强科学教育、工程教育和拔尖创新人才**自主培养**；动态调整优化高校学科专业设置；推进**职普融通、产教融合、科教融汇**，培养大国工匠 |
| 4 坚持深化教育改革创新 | 深化新时代**教育评价改革**；推进**数字教育**；扩大教育对外开放，使我国成为具有强大影响力的**世界重要教育中心** |
| 5 坚持把教师队伍建设作为基础工作 | "教育大计，**教师为本**"，**强教必先强师**；使教师成为最受社会尊重的职业之一；加强**师德师风**建设，做学生健康成长的指导者和引路人 |

## 第三节 加快建设科技强国

总纲：科技自立自强是**国家强盛之基、安全之要**。必须坚持走**中国特色自主创新道路**，发挥**新型举国体制**优势，完善国家创新体系，加快关键核心技术攻关，实现**高水平科技自立自强**。

### 一、科技强则国家强⭐⭐

"科技兴则民族兴，科技强则国家强。"实现高水平科技自立自强的三层意义：

| 意义 | 要点 |
| --- | --- |
| 1 国家强盛和民族复兴的**战略基石** | 百年未有之大变局中，科技创新是**关键变量**；全面建成社会主义现代化强国**关键看科技自立自强**，必须把科技的命脉牢牢掌握在自己手中 |
| 2 应对风险挑战和维护国家利益的**必然选择** | 提升我国发展的**独立性、自主性、安全性**，增强抗压能力、应变能力、对冲能力和反制能力；我国科技发展正处在**将强未强、不进则退**的关键阶段 |
| 3 构建新发展格局、推动高质量发展、满足人民美好生活需要的**内在要求** | ①构建新发展格局：保障产业链供应链安全稳定；②高质量发展：推动质量变革、效率变革、动力变革；③人民高品质生活：把**惠民、利民、富民、改善民生**作为科技创新的重要方向 |

- "科技是国之利器，国家赖之以强，企业赖之以赢，人民生活赖之以好。"

### 二、打赢关键核心技术攻坚战⭐⭐⭐

## 04考点闪卡 · 先回忆再翻面

## 05易错点辨析

1. **"教育是根本，科技是关键，人才是基础" ≠ "三个第一"**——前者是三者对全面建设社会主义现代化国家的定位分工，后者是科技第一生产力、人才第一资源、创新第一动力；两组表述都要背，不能交叉混搭。
2. **科教兴国是"基本国策"，人才强国战略是"国家和民族长远发展大计"**——两个定位表述各有归属，不能互换。
3. **科技自立自强 ≠ 自我封闭、自我隔绝**——要以更加开放的思维和举措推进国际科技交流合作，在开放合作中提升自身科技创新能力。
4. **"四个服务"（教育）≠ "四个面向"（科技创新）**——"四个服务"是对办好中国特色社会主义教育的要求；"四个面向"是实施创新驱动发展战略的要求，张冠李戴是常见命题陷阱。
5. **教育的根本任务是"立德树人"，教育的根本问题是"培养什么人、怎样培养人、为谁培养人"**——一个是"任务"、一个是"问题"（也是建设教育强国的核心课题），问什么答什么。
6. **基点、龙头、关键课程、基础工作四个喻指不能混**——基础教育是"基点"、高等教育是"龙头"（顺序固定不能颠倒）；思政课是立德树人的"关键课程"；教师队伍建设是建设教育强国"最重要的基础工作"。
7. **"卡脖子"技术问题的"根子"在基础理论研究跟不上**——基础研究处于科研链条**起始端**（源头），应用研究是**桥梁**，层次不能乱。
8. **四支国家战略科技力量定位各异**——"引领作用"是国家实验室、"建制化组织作用"是国家科研机构、"主力军和生力军"是高水平研究型大学、"主体"是企业；尤其不能把高校的"主力军"（基础研究）说成企业。
9. **人才引领驱动的"最优先位置"**——是"把**人才资源开发**放在最优先位置"，不要与"把教育摆在优先发展的战略地位"混淆；前者属人才工作、后者属教育优先发展。
10. **聚才三条路径的定位对应**——党的全面领导是"根本保证"（"纲"和"本"），体制机制改革是"重要保障"，营造环境是"社会条件"，三者的定位词对应固定。
11. **人才大国 ≠ 人才强国**——我国已是全球规模最宏大、门类最齐全的人才资源大国，但目标是由人才大国迈向人才强国、建设世界重要人才中心和创新高地。
