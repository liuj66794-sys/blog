## 章导言 · 习近平外交思想

**1. 外交工作的地位**

- 外交工作是党和国家工作全局的**重要组成部分**，在为国家发展和民族复兴**营造良好外部环境**、促进世界和平发展和人类共同进步中具有十分重要的作用。党的十八大以来，习近平外交思想指引外交工作取得**全方位、开创性历史成就**。

**2. 习近平外交思想的主要内容："十个坚持"**⭐⭐⭐

| 条目 | 以……为 | 落脚点 |
| --- | --- | --- |
| 1 | 维护党中央权威为统领 | 加强党对对外工作的集中统一领导 |
| 2 | 实现中华民族伟大复兴为使命 | 推进中国特色大国外交 |
| 3 | 维护世界和平、促进共同发展为宗旨 | 推动构建人类命运共同体 |

| 6 | 相互尊重、合作共赢为基础 | 走和平发展道路 |
| 7 | 深化外交布局为依托 | 打造全球伙伴关系 |
| 8 | 公平正义为理念 | 引领全球治理体系改革 |

- **教材表述**：大变局三大表现：国际力量对比深刻变化、新一轮科技革命和产业变革、国际体系和国际秩序深度调整；最具革命性的变化是新兴市场国家和发展中国家群体性崛起（「东升西降」「中治西乱」）；世界面临和平赤字、发展赤字、安全赤字、治理赤字（课1 p6-16）。

- **易混区别**：「四个赤字」是和平、发展、安全、治理，不要漏掉或改写；「最具革命性的变化」特指发展中国家群体性崛起。
- **答题关键词**：国际力量对比深刻变化、新一轮科技革命和产业变革、国际体系和国际秩序深度调整、和平、发展、安全、治理赤字、历史观、大局观、角色观

:::

::: info 习近平外交思想「十个坚持」

- **白话**：十个坚持里：党领导是统领，和平发展与人类命运共同体是宗旨，核心利益是底线。
- **教材表述**：习近平外交思想的主要内容集中体现为「十个坚持」：党的集中统一领导处于统领地位，坚持走和平发展道路、推动构建人类命运共同体体现宗旨，维护国家核心利益是底线（课1 p6-16）。

### 一、当今世界正经历百年未有之大变局⭐⭐

**1. 总判断（一体两面）**

- 一方面：**世界多极化、经济全球化、社会信息化、文化多样化**深入发展，**和平、发展、合作、共赢**的历史潮流不可阻挡；
- 另一方面：不稳定性不确定性突出，全球性问题加剧，人类处在危机交织叠加、风险日益增多的时代，世界又一次站在**历史的十字路口**。

**2. 大变局的三大表现**⭐⭐

| 表现 | 要点 | 关键提法 |
| --- | --- | --- |
| 1. 国际力量对比深刻变化 | 新兴市场国家和发展中国家**群体性崛起**、加速走向现代化，多个发展中心在各地区逐渐形成；发达国家内部矛盾重重、实力相对下降 | "东升西降""中治西乱"更加鲜明——近代以来国际力量对比中**最具革命性的变化** |
| 2. 新一轮科技革命和产业变革深入发展 | 人工智能、大数据、量子技术、基因工程等前沿科技不断突破，催生新产业、新业态、新模式，社会生产和消费从工业化向自动化、智能化转变，学科交叉融合 | 科学技术从来没有像今天这样深刻影响各国前途命运、改变人类生产生活方式和思维方式 |
| 3. 国际体系和国际秩序深度调整 | 二战后建立的国际秩序和全球治理体系不适应的地方越来越多，西方主导的国际政治经济秩序难以为继 | 发展中国家代表性和发言权不断扩大，**国际关系民主化**不可阻挡 |

**3. 动荡变革期与"四个赤字"**⭐⭐

- 世界之变、时代之变、历史之变正以前所未有的方式展开，大变局加速演进，世界进入**新的动荡变革期**：世纪疫情影响深远，局部冲突硝烟又起，冷战思维和集团政治回潮，单边主义、保护主义抬头，经济全球化遭遇逆流，世界经济复苏步履维艰。
- **和平赤字、发展赤字、安全赤字、治理赤字**有增无减；公共卫生、恐怖主义、气候变化、网络安全等**非传统安全威胁**持续蔓延。

**4. 时代之问与中国立场**⭐

- 世界向何处去？**和平还是战争？发展还是衰退？开放还是封闭？合作还是对抗？**——关乎各国利益、关乎人类前途命运。
- 中国：从人类发展大潮流、世界变化大格局、中国发展大历史正确认识和处理同外部世界的关系，**站在历史正确的一边，站在人类进步的一边**。

### 二、中国必须有自己特色的大国外交

**1. "三观"基础**⭐⭐ 习近平："把握国际形势要树立正确的历史观、大局观、角色观。"

| 观点 | 内涵 |
| --- | --- |
| 历史观 | 不仅看现在国际形势什么样，更要端起**历史望远镜**回顾过去、总结历史规律，展望未来、把握历史前进大势 |
| 大局观 | 不仅看现象和细节，更要**把握本质和全局**，抓住主要矛盾和矛盾的主要方面，避免迷失方向、舍本逐末 |
| 角色观 | 不仅冷静分析国际现象，还要**把自己摆进去**，在中国同世界的关系中看问题，弄清中国的地位和作用 |

**2. 主线与总目标**⭐⭐⭐

- 主线：牢牢把握**服务民族复兴、促进人类进步**（为中国人民谋幸福、为中华民族谋复兴，同时为人类谋进步、为世界谋大同）。
- 总目标：**推动构建人类命运共同体**，始终坚持维护世界和平、促进共同发展的宗旨。
- 服务民族复兴要营造**五个环境**：和平安宁的国际环境、睦邻友好的周边环境、开放包容的合作环境、稳定有序的安全环境、客观友善的舆论环境。

**3. 坚持正确的原则要求（5 条）**⭐⭐

1. **坚持和加强党对对外工作的集中统一领导**——外交大权在党中央，改革完善对外工作体制机制；
2. **以中国特色社会主义为根本增强战略自信**——更自信地提出中国主张、中国智慧、中国方案；
3. **以相互尊重、合作共赢为基础走和平发展道路**——坚持独立自主的和平外交政策，以共商共建共享为原则推动"一带一路"建设，始终做世界和平的建设者、全球发展的贡献者、国际秩序的维护者；
4. **以公平正义为理念引领全球治理体系改革**——打造全球伙伴关系、维护多边主义，做全球治理变革进程的参与者、推动者、引领者；
5. **以国家核心利益为底线维护国家主权、安全、发展利益**——为改革发展和民族复兴保驾护航。

**4. 展现独特风范（4 个）**⭐

- **守正创新的大国气派**（坚持马克思主义立场观点方法，从中华优秀传统文化中汲取智慧，推进理论创新和实践创新）；
- **立己达人的世界情怀**（爱国主义同国际主义相结合：政治上主持公道、伸张正义，经济上合作共赢、共同发展，安全上守望相助、相互支持）；
- **开放包容的宽广胸襟**（倡导不同文明互学互鉴、不同社会制度和发展道路相互包容）；
- **重情尚义的崇高品格**（诚信为本、恪守政治承诺、重视民间友好和民心相通）。

### 三、我国国际影响力、感召力、塑造力显著提升

**1. 外交成就的五个方面**⭐

1. 成立**中央外事工作委员会**，巩固党总揽全局、协调各方的对外工作大协同局面；提出构建人类命运共同体重大理念、共建"一带一路"倡议和**全球发展倡议、全球安全倡议、全球文明倡议**，深刻回答"世界怎么了、我们怎么办"的时代课题；
2. 在**和平共处五项原则**基础上发展全球伙伴关系，以**元首外交**为外交全局提供战略引领，构建和平共处、总体稳定、均衡发展的大国关系格局，深入推进周边命运共同体建设，打造遍布全球的朋友圈；
3. 倡导**共商共建共享的全球治理观**，坚持真正的多边主义，开展南南合作，坚定维护发展中国家的正当权益和发展空间；
4. 服务发展全面深化，以共建"一带一路"推动建设合作共赢的开放体系，通过主场外交、国际展会、全球推介等平台支持地方开放发展；
5. 面对无理讹诈和极限施压**保持战略定力**，在原则问题上寸步不让，连续挫败利用**台湾、涉疆、涉港、涉藏、涉疫、人权**等问题发动的攻击抹黑。

**2. 标志性数据（选择常考）**⭐⭐

- 构建人类命运共同体倡议**已被多次写入联合国文件**，正从理念转化为行动；
- 中国已同 **180 多个国家**建立外交关系，与 **110 多个国家和地区组织**建立不同形式的伙伴关系，缔结 **2 万多项双边条约**，加入几乎所有普遍性政府间国际组织和 **600 多项国际公约**；
- 在联合国、世界贸易组织、二十国集团、金砖国家、亚太经合组织、上海合作组织等多边机制中发挥越来越重要的作用。

## 第二节 全面推进中国特色大国外交

::: info 本节指引 · 第二节 全面推进中国特色大国外交

- **目标**：记住大国外交的主线与总目标、走和平发展道路的三条依据、新型国际关系与主要外交布局（中美、中欧、周边、发展中国家、政党）。
- **建议用时**：15 分钟
- **知识点**：`中国特色大国外交（主线、和平发展、新型国际关系）`

:::

::: info 大国外交主线、总目标与和平发展依据

- **白话**：主线是服务民族复兴、促进人类进步；总目标是构建人类命运共同体。
- **教材表述**：中国特色大国外交的主线是服务民族复兴、促进人类进步，总目标是推动构建人类命运共同体；走和平发展道路的三条依据：党的性质宗旨和社会主义制度、中国历史文化传统、符合历史潮流顺应世界大势（课2 p4-15）。
- **情境**：论述「为什么中国坚持走和平发展道路」：三条依据逐条展开，缺一不可。
- **易混区别**：「主线」与「总目标」不能互换：服务民族复兴促进人类进步是主线，构建人类命运共同体是总目标。
- **答题关键词**：服务民族复兴、促进人类进步、推动构建人类命运共同体、三条依据

:::

::: info 新型国际关系与主要布局

- **白话**：对话不对抗、结伴不结盟；对不同对象用不同方针。
- **教材表述**：推动构建新型国际关系：相互尊重、公平正义、合作共赢，做到对话不对抗、结伴不结盟；中美关系三原则：相互尊重、和平共处、合作共赢；中欧四大伙伴关系：和平、增长、改革、文明；周边外交方针与理念：与邻为善、以邻为伴＋亲诚惠容，亚洲安全观为共同、综合、合作、可持续；对发展中国家：真实亲诚＋正确义利观，金砖「三轮驱动」；新型政党关系：求同存异、相互尊重、互学互鉴（课2 p4-15）。
- **情境**：考「周边外交理念」：答「亲诚惠容」；考「对发展中国家」：答「真实亲诚」——两组方针最易互换。
- **易混区别**：「亲诚惠容」属周边外交，「真实亲诚」属对发展中国家；「相互尊重、公平正义、合作共赢」是新型国际关系的内容，「相互尊重、和平共处、合作共赢」是中美关系三原则。
- **答题关键词**：相互尊重、公平正义、合作共赢、对话不对抗、结伴不结盟、亲诚惠容、真实亲诚、正确义利观

:::

::: info 维护国家核心利益

导言：进入新时代，必须**坚定奉行独立自主的和平外交政策，坚持走和平发展道路，推动构建新型国际关系，坚决维护国家主权、安全、发展利益，彰显外交为民宗旨**，走出一条中国特色大国外交新路。

### 一、坚持走和平发展道路⭐⭐

**1. 定位与依据**

- 定位：根据**时代发展潮流和我国根本利益**作出的**战略抉择**，是**新时代中国外交的基本原则**。习近平："中国走和平发展道路，不是权宜之计，更不是外交辞令，而是从历史、现实、未来的客观判断中得出的结论，是思想自信和实践自觉的有机统一。"

| 依据 | 要点 |
| --- | --- |
| 由党的性质宗旨和社会主义制度决定 | 社会主义国家**决不以损害别国利益来实现自己的发展**；始终倡导和坚持和平共处五项原则，一贯坚持独立自主的和平外交政策 |
| 基于中国历史文化传统的必然选择 | 中华文明具有**突出的和平性**；"国虽大，好战必亡"的箴言，"以和为贵""和而不同""睦邻友邦""天下大同"等理念世代相传 |
| 符合历史潮流、顺应世界大势 | "殖民主义、霸权主义的老路还能走得通吗？答案是否定的……只有和平发展道路可以走得通。"和平发展道路对中国有利、对世界有利 |

**2. 坚定奉行独立自主的和平外交政策**⭐⭐

- 根据**事情本身的是非曲直**决定自己的立场和政策；坚持国家不分大小、强弱、贫富**一律平等**，尊重各国人民自主选择的发展道路和社会制度；
- 坚决反对**一切形式的霸权主义和强权政治**，反对冷战思维、干涉别国内政、搞双重标准；
- 奉行**防御性的国防政策**；中国的发展是世界和平力量的增长，无论发展到什么程度，中国**永远不称霸、永远不搞扩张**。

**3. 和平与发展的辩证关系**

- 既要通过**维护世界和平**发展自己，又要通过**自身发展**维护世界和平——没有和平，中国和世界都不可能顺利发展；没有发展，中国和世界也不可能有持久和平；
- 共谋和平、共护和平、共享和平，始终做国际和地区安全的**维护者、建设者、贡献者**。

### 二、推动构建新型国际关系⭐⭐⭐

**内涵**：秉持**相互尊重、公平正义、合作共赢**原则，走出一条**对话而不对抗、结伴而不结盟**的国与国交往新路；在和平共处五项原则基础上深化拓展**平等、开放、合作**的全球伙伴关系——这是新时代中国外交理论和实践的**重要创新**。布局四条线：

**1. 推进大国协调合作**⭐⭐

- 大国是"重要内容"：大国之间**和睦才有世界和平，大国相互合作才有全球发展**；构建**和平共处、总体稳定、均衡发展**的大国关系格局。

| 大国关系 | 定位与提法 |
| --- | --- |
| 中俄 | 新时代全面战略协作伙伴关系**成熟、稳定、自主、坚韧**；以**互信为基石**，深化利益交融、促进民心相通 |
| 中美 | 当今世界**最重要的双边关系之一**，正处于重要关口；坚持**相互尊重、和平共处、合作共赢**三原则，在互惠互利基础上拓展合作、在相互尊重基础上管控分歧 |
| 中欧 | 同为世界多极化、经济全球化的重要参与者和塑造者；从战略高度和长远角度发展，推进**和平、增长、改革、文明四大伙伴关系** |

**2. 周边外交**⭐⭐⭐

- 方针：坚持**亲诚惠容**和**与邻为善、以邻为伴**；周边是我国**安身立命之所、发展繁荣之基**，要始终将周边置于外交全局的**首要位置**；
- 安全：坚持**共同、综合、合作、可持续的亚洲安全观**，主动参与区域和次区域安全合作；同时深化区域金融合作、加强公共外交和人文交流。

**3. 加强同发展中国家团结合作**⭐⭐⭐

- 中国是**世界上最大的发展中国家**，广大发展中国家是我国在国际事务中的**天然同盟军**；
- 理念：**真实亲诚** + **正确义利观**（对发展中国家政策理念的重大创新）——讲信义、重情义、扬正义、树道义，做到**义利兼顾、义利平衡**；
- 金砖国家：国际事务中积极、稳定、建设性的重要力量，巩固**经贸财金、政治安全、人文交流"三轮驱动"**合作架构。

**4. 构建新型政党关系**

- 在**独立自主、完全平等、互相尊重、互不干涉内部事务**原则基础上，探索建立**求同存异、相互尊重、互学互鉴**的新型政党关系；
- 五个责任：引领方向、凝聚共识（坚守和弘扬全人类共同价值）、促进发展、加强合作、完善治理；以新型政党关系助力构建新型国际关系。

### 三、坚决维护国家主权、安全、发展利益⭐⭐

- 地位：是我国对外工作的**出发点和落脚点**，是中国外交的**神圣使命**。习近平："决不能放弃我们的正当权益，决不能牺牲国家核心利益。任何外国不要指望我们会拿自己的核心利益做交易，不要指望我们会吞下损害我国主权、安全、发展利益的苦果。"
- 在涉及国家核心利益的问题上**亮明原则立场、划出红线、捍卫底线**；维护国家利益这一对外工作的**根本任务**没有变、也不能变。
- **敢于斗争、善于斗争**⭐："我们不惹事，但也不怕事"；在涉及党的领导地位、社会主义制度、国家根本利益和重大关切问题上**敢于亮剑**；把**斗争精神和斗争艺术**结合起来，坚持**有理有利有节**，在斗争中争取团结、谋求合作、争取共赢。

### 四、坚持外交为民⭐

- 中国外交是**人民的外交**；**人民外交是中国共产党的一个创举，也是中国外交的力量源泉**；把为民服务、为民解忧作为重要职责，把**人民的满意度作为重要标尺**。
- 坚定维护**海外公民和法人正当权益**：打造**海外民生工程**；遍布全球的驻外使领馆是亲民网点——"同胞在海外走到哪里，领事保护和服务就跟随到哪里"。
- 积极开展**民间外交**（中国外交的优良传统和鲜明特色）："**国之交在于民相亲**"，人民的深厚友谊是国家关系发展的力量源泉；多领域、多渠道、多层次开展，坚持以诚感人、以心暖人、以情动人。

### 二、推动构建人类命运共同体的价值基础和重要依托

**1. 弘扬全人类共同价值**⭐⭐⭐

## 04考点闪卡 · 先回忆再翻面

## 05易错点辨析

1. **走和平发展道路 ≠ 权宜之计、外交辞令**——它是从历史、现实、未来的客观判断中得出的结论，是思想自信和实践自觉的有机统一，政策、制度、实践上一以贯之。
2. **"亲诚惠容"与"真实亲诚"对象不同**——亲诚惠容（+与邻为善、以邻为伴）是**周边**外交方针理念；真实亲诚（+正确义利观）是对**发展中国家**的理念，两者不可混用。
3. **新型政党关系四原则 ≠ 和平共处五项原则**——党际交往原则是独立自主、完全平等、互相尊重、互不干涉内部事务；和平共处五项原则处理的是**国家间**关系（发展全球伙伴关系的基础）。
4. **全人类共同价值 ≠ 西方"普世价值"**——前者反映全人类共同利益、体现不同文明价值共识、以联合国宪章为基础，是最大公约数；后者仅代表部分西方国家利益、依靠霸权强行输出。
5. **三大全球倡议的时间场合易混**——全球发展倡议：2021.9 第七十六届联大；全球安全倡议：2022.4 博鳌亚洲论坛年会；全球文明倡议：2023.3 中国共产党与世界政党高层对话会（顺序：发展→安全→文明）。
6. **全球治理体系改革 ≠ 推倒重来、另起炉灶**——而是与时俱进、创新完善；同时要坚定维护**以联合国为核心的国际体系、以国际法为基础的国际秩序**，并非抛弃现行秩序。
7. **"一带一路"的三个"不是"**——不是地缘政治联盟或军事同盟、不是封闭小圈子或"中国俱乐部"、不是所谓"陷阱"；它是经济合作倡议、开放包容进程、阳光大道。
8. **"五通""六路""三个联通"三组提法别混**——五通：政策/设施/贸易/资金/民心相通；六路：和平/繁荣/开放/绿色/创新/文明之路；硬联通（方向）、软联通（支撑）、心联通（基础）。
9. **主线与总目标层次不同**——中国特色大国外交的**主线**是服务民族复兴、促进人类进步，**总目标**是推动构建人类命运共同体；后者同时是新时代对外工作的总目标。
10. **"真正的多边主义"的反面**——不能以多边主义之名行单边主义之实，不能搞"有选择的多边主义"；其四个坚持是开放包容/以国际法则为基础/协商合作/与时俱进，各自对应"不搞"封闭排他/唯我独尊/冲突对抗/故步自封。
