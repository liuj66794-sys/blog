## 03正文精讲

## 第一节 科学发展观的科学内涵

### 一、形成背景与总体表述

**1. 形成背景**
进入新世纪，以**胡锦涛**同志为主要代表的中国共产党人，紧紧抓住我国发展的**重要战略机遇期**，在全面建设小康社会进程中推进实践创新、理论创新、制度创新，坚持以人为本、全面协调可持续发展，**形成了科学发展观**，成功在新的历史起点上坚持和发展了中国特色社会主义。

**2. 科学内涵总表述（一字不能错）**⭐⭐⭐

> &lt;p&gt;科学发展观，**第一要义是发展**，**核心立场是以人为本**，**基本要求是全面协调可持续**，**根本方法是统筹兼顾**。&lt;/p&gt;

**3. 四要素分别回答的问题**⭐⭐

| 要素 | 回答的问题 |
| --- | --- |
| 第一要义：发展 | "为什么发展" |
| 核心立场：以人为本 | "发展为了谁和依靠谁" |
| 基本要求：全面协调可持续 | "实现什么样的发展" |
| 根本方法：统筹兼顾 | "怎样发展" |

**4. 名家引言**：胡锦涛《把科学发展观贯穿于发展的整个过程和各个方面》（2004年5月5日）："科学发展观总结了二十多年来我国改革开放和现代化建设的成功经验，揭示了经济社会发展的客观规律，反映了我们党对发展问题的新认识。"

### 二、第一要义：推动经济社会发展 ⭐⭐

**1. 为什么发展是第一要义**

- 发展是人类文明进步的基础，也是**马克思主义最基本的范畴之一**；党执政的首要任务就是带领人民推动经济社会发展。
- 胡锦涛：**发展是解决中国一切问题的"总钥匙"**。
- 在当代中国，**坚持发展是硬道理的本质要求就是坚持科学发展**。

**2. 科学发展"五个既要……又要……"**
①发展规模速度 ↔ 质量效益；②社会财富创造涌流 ↔ 利益分配调整；③经济实力增长 ↔ 经济政治文化社会生态均衡发展；④开发利用自然造福人类 ↔ 人与自然和谐发展；⑤满足群众基本需求 ↔ 生活质量提高和人的全面发展。

**3. 坚持科学发展的五条要求**

| 要求 | 核心内容 |
| --- | --- |
| ①加快转变经济发展方式 | 主攻方向=**经济结构战略性调整**；重要支撑=**科技进步和创新**；出发点和落脚点=**保障和改善民生**；重要着力点=**建设资源节约型、环境友好型社会**；强大动力=**改革开放**；正确处理"好"与"快"的辩证关系，实现三个"转变"（消费投资出口协调拉动、一二三产业协同带动、科技进步+劳动者素质提高+管理创新） |
| ②推动科学技术的跨越式发展 | 科技是**第一生产力**；胡锦涛提出**建设创新型国家**的重大战略思想——**是国家发展战略的核心，是提高综合国力的关键**；实施科教兴国战略，坚持"自主创新、重点跨越、支撑发展、引领未来"方针 |
| ③培养高素质创新型人才 | "国以才立，政以才治，业以才兴"；实施**人才强国战略**，坚持尊重劳动、尊重知识、尊重人才、尊重创造，推动由人力资源大国向**人才强国**迈进 |
| ④善于抓住和用好机遇 | 党的**十六大**作出重大判断：**21世纪头二十年**是必须紧紧抓住并且可以大有作为的**重要战略机遇期**；胡锦涛"综观国际国内大势，我国发展仍处于可以大有作为的重要战略机遇期" |
| ⑤全面建成小康社会 | 党对人民的庄严承诺：十六大提出头二十年**全面建设**惠及十几亿人口的更高水平的小康社会 → 十七大提出新要求 → **十八大**明确提出**到2020年全面建成**小康社会的新要求（经济持续健康发展、人民民主不断扩大、文化软实力显著增强、人民生活水平全面提高、两型社会建设取得重大进展） |

**4. 理念变化**：20世纪90年代初以来长期提"又快又好发展"；**2006年**胡锦涛在党外人士座谈会上强调"**又好又快**发展"，"好"字排到"快"之前，体现发展理念的重大变化；党的十六届六中全会进一步提出"促进经济又好又快发展"方针（好中求快、优化结构、提高质量和效益）。

### 三、核心立场：以人为本 ⭐⭐⭐

**1. 内涵**

- **"人"**：指**人民群众**，即以**工人、农民、知识分子等劳动者为主体，包括社会各阶层人民在内的中国最广大人民**；**"本"**：就是**根本**，就是**出发点和落脚点**。
- 胡锦涛论根本含义：坚持全心全意为人民服务，**立党为公、执政为民**，始终把最广大人民根本利益作为党和国家工作的根本出发点和落脚点，坚持**发展为了人民、发展依靠人民、发展成果由人民共享**。

**2. 三个"区别"（对比必背）**

| 思想 | 积极面 | 本质局限 |
| --- | --- | --- |
| 中国古代民本思想 | 朴素的重民价值取向，缓和阶级矛盾、减轻人民负担 | 本质是为**维护封建统治者统治地位**服务 |
| 近代西方人本主义 | 反对封建主义、推进人的解放 | 离开具体历史条件和人的社会性，以抽象永恒不变的人性说明历史，为**资产阶级**取得和维护统治地位服务 |
| **以人为本** | 坚持**历史唯物主义**基本立场观点，人民利益放在首位，体现人民当家作主和立党为公、执政为民 | —— |

- 根本区别：以人为本站在历史唯物主义立场，民本思想与人本主义站在**唯心史观**立场。

**3. 理论基石**

- 人民群众是历史的创造者，是推动社会发展的决定性力量。
- ⭐ 胡锦涛："相信谁、依靠谁、为了谁，是否始终站在最广大人民的立场上，是**区分唯物史观和唯心史观的分水岭**，也是**判断马克思主义政党的试金石**。"

**4. 坚持以人为本的四条要求**⭐⭐
①坚持**发展为了人民**，始终把最广大人民的根本利益放在第一位——真正做到**权为民所用、情为民所系、利为民所谋**；
②坚持**发展依靠人民**，从人民群众的伟大创造中汲取智慧和力量——做到**问政于民、问需于民、问计于民**；
③坚持**发展成果由人民共享**，着力提高人民物质文化生活水平——把维护社会公平放到更加突出的位置，朝着**共同富裕**方向稳步前进；
④最终是为了**实现人的全面发展**。

**5. 标志性事件**：2005年12月29日，**十届全国人大常委会第十九次会议**决定自**2006年1月1日**起废止**《中华人民共和国农业税条例》**，在我国延续**2600年**的农业税退出历史舞台（与1999年相比人均减负约140元），给亿万农民带来实惠。

### 四、基本要求：全面协调可持续 ⭐⭐

**1. 三个概念的界定（背诵）**

- **全面**：发展要有**全面性、整体性**，不仅经济要发展，而且各个方面都要发展；
- **协调**：发展要有**协调性、均衡性**，各个方面、各个环节的发展要相互适应、相互促进；
- **可持续**：发展要有**持久性、连续性**，不仅当前要发展，而且要保证长远发展。

**2. 坚持全面发展：五位一体各项定位**⭐⭐⭐

| 建设 | 定位 |
| --- | --- |
| 经济建设 | **中心和基础** |
| 政治建设 | **方向和保障** |
| 文化建设 | **灵魂和血脉** |
| 社会建设 | **支撑和归宿** |
| 生态文明建设 | **根基和条件** |

**3. 坚持协调发展**：协调好消费与投资、供给与需求、发展的速度和结构质量效益、科技进步与人力资源优势的发挥、市场机制与宏观调控等经济发展重大问题；正确处理经济与社会、城市与农村、东中西部、人与自然、国内发展和对外开放、改革发展稳定等现代化建设重大关系。

**4. 坚持可持续发展**：坚定走**生产发展、生活富裕、生态良好**的文明发展道路——**以生产发展为基础，以生活富裕为目的，以生态良好为条件**；还必须**建设生态文明**，把生态文明建设放在突出地位。

### 五、根本方法：统筹兼顾 ⭐⭐

**1. 定位四句话**：统筹兼顾是科学发展观的**根本方法**；是**唯物辩证法**在发展问题上的科学运用；是**实现科学发展、促进社会和谐的基本途径**；是**正确处理经济社会发展中重大关系的方针原则**。

**2. "五个统筹"及其扩展**⭐⭐⭐

- **党的十六届三中全会**提出：统筹**城乡发展、区域发展、经济社会发展、人与自然和谐发展、国内发展和对外开放**（五个统筹）；
- **党的十七大**在坚持"五个统筹"的同时进一步强调：统筹**中央和地方关系**，统筹**个人利益和集体利益、局部利益和整体利益、当前利益和长远利益**，统筹**国内国际两个大局**。

**3. 坚持统筹兼顾的四条要求**
①正确认识和妥善处理中国特色社会主义事业中的**重大关系**（城乡、区域、经济社会、人与自然、国内发展与对外开放、国内产业和国际产业分工等）；
②认真考虑和对待各方面的发展需要，正确反映和兼顾**各阶层各群体的利益要求**；
③牢牢掌握统筹兼顾的**科学思想方法**，提高**战略思维、创新思维、辩证思维**能力，正确处理重点和一般的关系；
④既**立足当前，又着眼长远**，做到兼顾各方、综合平衡。

## 第二节 科学发展观的主要内容

总览：科学发展观的主要内容展开为**经济、政治、文化、社会、生态、党建**六大方面。

### 一、加快转变经济发展方式 ⭐⭐⭐

**1. 主题主线与背景**

- 推动经济持续健康发展，必须**以科学发展为主题、以加快转变经济发展方式为主线**。
- 2008年由**美国次贷危机**引发的波及全球的**国际金融危机**，使内需外需不平衡、投资消费不协调、产业结构不合理、发展方式不可持续的问题更加凸显。胡锦涛："国际金融危机对我国经济的冲击，表面上是对经济增长速度的冲击，**实质上是对经济发展方式的冲击**……转变经济发展方式已**刻不容缓**。"
- 路径："四个着力"（激发各类市场主体发展新活力、增强创新驱动发展新动力、构建现代产业发展新体系、培育开放型经济发展新优势）+"五个更多依靠"（内需特别是消费需求拉动、现代服务业和战略性新兴产业带动、科技进步劳动者素质提高管理创新驱动、节约资源和循环经济推动、城乡区域发展协调互动）。

**2. 七个定位词（选择高频）**⭐⭐⭐

| 定位 | 内容 |
| --- | --- |
| **关键** | 全面深化经济体制改革（核心问题是**处理好政府和市场的关系**：更加尊重市场规律，充分发挥市场在资源配置中的**基础性**作用；更好发挥政府作用） |
| **重大战略决策** | 实施**创新驱动**发展战略（把科技创新摆在国家发展全局的核心位置） |
| **主攻方向** | 推动经济结构**战略性调整**（扩大内需是基本立足点和长期战略方针、调整经济结构的首要任务） |
| **重大战略** | 促进**区域协调发展**（实施西部大开发、振兴东北地区等老工业基地、促进中部地区崛起、鼓励东部地区率先发展→区域发展总体战略） |
| **重要措施** | 积极稳妥推进**城镇化** |
| **根本途径** | 推动**城乡发展一体化**——解决"三农"问题的根本途径；坚持工业反哺农业、城市支持农村和**多予少取放活**方针，形成以工促农、以城带乡、工农互惠、城乡一体的新型工农、城乡关系 |
| **重要动力** | 实现**工业化、信息化、城镇化、农业现代化**同步发展 |

### 二、发展社会主义民主政治 ⭐⭐

**1. 总论**

- **人民民主是社会主义的生命**；发展社会主义民主政治是党始终不渝的奋斗目标。
- **社会主义民主政治的本质和核心是人民当家作主**。
- 最根本的是坚持**党的领导、人民当家作主、依法治国有机统一**：党的领导是人民当家作主和依法治国的**根本保证**，人民当家作主是社会主义民主政治的**本质和核心**，依法治国是党领导人民治理国家的**基本方略**。

**2. 五项部署**

| 部署 | 要点 |
| --- | --- |
| ①坚持和完善社会主义政治制度 | **人民代表大会制度**＝根本政治制度、人民当家作主的根本途径和最高实现形式；**多党合作和政治协商制度**＝社会主义新型政党制度；**民族区域自治制度**＝解决民族问题的重大创造；**基层群众自治制度**＝社会主义民主政治建设的基础 |
| ②健全社会主义协商民主制度 | 社会主义协商民主是中国共产党和中国人民的**伟大创造**；**选举民主与协商民主相结合**是中国社会主义民主的一大特点 |
| ③坚定不移推进依法治国基本方略 | 前提是**有法可依**，基础是提高全社会法律意识和法制观念，关键是**依法执政、依法行政、依法办事、公正司法**；**依法治国首先要依宪治国，依法执政首先要依宪执政** |

## 05易错点辨析

1. **第一要义是"发展"，但本质要求是"科学发展"**——发展是解决中国一切问题的"总钥匙"，但不是单纯追求速度：2006年起"**又好又快**"取代"又快又好"，"好"字排在"快"之前。
2. **四要素的定位词不能互换**：第一要义（发展）—核心立场（以人为本）—基本要求（全面协调可持续）—根本方法（统筹兼顾）；对应回答"为什么发展／为谁依靠谁／实现什么样的发展／怎样发展"。
3. **以人为本的"人"≠抽象的人，"本"≠"以人为本"这个口号本身**——"人"指中国最广大人民，"本"指根本、出发点和落脚点。
4. **以人为本≠中国古代民本思想≠西方人本主义**——根本区别在于以人为本坚持**历史唯物主义**，而民本思想为维护封建统治服务、人本主义为资产阶级服务，二者站在**唯心史观**立场。
5. **"五个统筹"提出于党的十六届三中全会**，不是十七大；十七大是"在坚持'五个统筹'的同时"新增统筹中央和地方关系、个人／集体／局部／整体／当前／长远利益、国内国际两个大局。
6. **三个"性"别混**：全面=全面性整体性；协调=协调性均衡性；可持续=持久性连续性。另注意五位一体定位中**社会建设是"支撑和归宿"**（不是"保障"）、**生态文明建设是"根基和条件"**。
7. **市场作用表述**——本阶段原文表述为"充分发挥市场在资源配置中的**基础性**作用"，与"更好发挥政府作用"并举；作答以教材表述为准，勿凭印象换词。
8. **民主政治三个短语各就各位**：人民民主是社会主义的**生命**；人民当家作主是民主政治的**本质和核心**；党的领导是**根本保证**；依法治国是**基本方略**——四句不能互相串用。
9. **社会主义核心价值体系≠社会主义核心价值观**——"体系"是**兴国之魂**，四项内容（马克思主义指导思想、共同理想、民族精神时代精神、荣辱观）；三个倡导 12 词是培育和践行**核心价值观**的要求。
10. **和谐社会"总要求"六条≠民生"五有"**——总要求是民主法治、公平正义、诚信友爱、充满活力、安定有序、人与自然和谐相处；学有所教等五项是保障和改善民生的目标。
11. **党建三个定位别混**：执政能力建设是党执政后的**一项根本建设**；先进性建设是**根本任务和永恒课题**；**纯洁性是先进性的重要体现**（不是并列的另一种"属性"）；主线是"执政能力建设+先进性和纯洁性建设"。
12. **历史地位只有两条定位**：一是**接续发展**（理论层面），二是**根本指针**（实践层面）；"精神实质"四词（解放思想、实事求是、与时俱进、求真务实）单独立点，别与"内涵""路线"混淆。
