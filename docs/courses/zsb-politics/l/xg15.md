## 03正文精讲

## 第一节 全面准确理解和贯彻“一国两制”方针

### 一、“一国两制”是中国特色社会主义的伟大创举

**1. 地位与定义**⭐⭐⭐
- “一国两制”是党领导人民实现祖国和平统一的一项**重要制度**，是**国家的一项基本国策**。
- 定义（原文背诵）：作为一项基本国策，“一国两制”是指**在统一的国家之内，国家主体实行社会主义制度，个别地区依法实行资本主义制度**。
- 制度设计：以**宪法和基本法**为基础，保持香港、澳门原有的资本主义制度和生活方式不变、法律基本不变；作为直辖于中央人民政府的特别行政区，享有**高度自治权**，包括**行政管理权、立法权、独立的司法权和终审权**。
- 特点：立足中国国情，顺应时代潮流，观照人民福祉，把**原则性和灵活性、现实性和长远性、一致性和差异性**统一起来，凝结了中国共产党人解决国家统一问题的超凡勇气和卓越智慧，是**前无古人的伟大创举**。

**2. 三个定位（多维意义）**⭐⭐

| 定位 | 核心内容 |
| --- | --- |
| 中国特色社会主义**制度创新**的重要成果 | 统一国家内两种制度并存；以宪法和基本法为基础；高度自治权四项内容 |
| 党领导人民实现祖国和平统一的**伟大构想** | 维护国家主权和领土完整、绝不容忍国家分裂的历史悲剧重演，是党对历史和人民的庄严承诺；**最早针对台湾问题提出，首先运用于解决香港和澳门问题**；实现港澳平稳过渡、和平回归，洗刷了民族百年耻辱，完成了实现祖国完全统一的重要一步 |
| 为国际社会解决类似问题提供的**新思路新方案** | 包含中华文化的**和合理念**，体现尊重差异、求同存异；坚守“一国”之本、善用“两制”之利；是解决类似历史遗留问题、促进世界和平与发展的好制度，是对**人类政治文明**作出的一大贡献 |

**3. 港澳问题的由来与回归时间线**⭐⭐
- 香港、澳门问题是**历史上殖民主义侵略中国遗留下来的问题**。

| 时间 | 事件 |
| --- | --- |
| 1982.9—1984.9 | 中英两国政府就解决香港问题进行**两个阶段**的艰苦谈判，最终达成协议 |
| 1984.12.19 | 中英两国政府领导人在北京正式签署关于香港问题的**联合声明及三个附件** |
| **1997.7.1** | 中国政府恢复对香港行使主权，香港回到祖国怀抱 |
| 1985.5 | 中葡就举行谈判解决澳门问题达成协议 |
| 1986.6—1987.3 | 中葡两国先后举行**四轮会谈** |
| 1987.4.13 | 中葡关于澳门问题的联合声明在北京正式签署 |
| **1999.12.20** | 澳门回到祖国怀抱 |

### 二、准确把握“一国两制”的科学内涵⭐⭐⭐

党的十八大以来，以习近平同志为核心的党中央继承发展党的“一国两制”科学理论，系统阐发新时代坚持和完善“一国两制”的基本立场和重大原则，对马克思主义国家学说作出了新贡献。**五个要点：**

| 要点 | 核心内容 | 关键表述（考点原话） |
| --- | --- | --- |
| 1 牢牢把握**根本宗旨** | 维护国家主权、安全、发展利益，保持香港、澳门长期繁荣稳定 | 贯彻方针坚持两点：一是**坚定不移**，确保不会变、不动摇；二是**全面准确**，确保不走样、不变形 |
| 2 准确把握**“一国”和“两制”的关系** | “一国”是实行“两制”的**前提和基础**，“两制”从属和派生于“一国”，并统一于“一国”之内 | 维护国家主权、安全、发展利益是**最高原则**；“一国”是根是本；“两制”并非等量齐观、比肩并列，国家主体必须实行社会主义制度 |
| 3 坚持**中央全面管治权**和保障特区**高度自治权**相统一 | 我国是单一制国家，中央对所有地方行政区域拥有全面管治权；全面管治权是授权高度自治的**前提和基础**，高度自治权是中央行使全面管治权的**体现** | 二者是**源与流、本与末**的关系；高度自治**不是完全自治，也不是分权**；不存在“剩余权力” |
| 4 坚定落实**“爱国者治港”“爱国者治澳”** | 政权必须掌握在爱国者手中，这是**世界通行的政治法则** | 爱国者标准：尊重自己民族 + 诚心诚意拥护祖国恢复行使对港澳的主权 + 不损害港澳的繁荣和稳定 |
| 5 坚持**依法治港治澳** | 依法治理是**最可靠、最稳定的治理**；是全面依法治国的应有之义 | **宪法和基本法共同构成**特别行政区的宪制基础；宪法是根本大法、特区制度的法律渊源；基本法是“一国两制”方针的法律化、制度化；特区**不存在一个脱离国家宪法的“宪制”和“法治”** |

- “一国”与“两制”关系金句（引述题）：习近平：“‘一国’是根，根深才能叶茂；‘一国’是本，本固才能枝荣。”“‘一国’原则愈坚固，‘两制’优势就愈彰显；‘一国’底线越牢，‘两制’空间就越大。”
- 补充：社会主义制度是中华人民共和国的根本制度，中国共产党领导是中国特色社会主义最本质的特征；中央授予多少权力，特区就享有多少权力，中央有权监督高度自治权行使情况、有权依法纠正违反“一国两制”和基本法的行为；任何港澳居民只要秉持爱国爱港爱澳立场、不从事危害活动，都可依法参与港澳的选举和治理。

### 三、坚持和完善“一国两制”制度体系⭐

“一国两制”必须通过具体的制度体系、制度安排、制度规则呈现出来、落到实处。三个方面：

| 方面 | 主要内容 |
| --- | --- |
| 1 加强**依法治理**相关制度和机制建设 | 巩固宪法和基本法共同构成的特区宪制基础，维护宪制秩序；完善与基本法实施相配套的制度和法律体系，夯实依法治港治澳的制度基础 |
| 2 健全**中央行使全面管治权**的制度 | 依法行使宪法和基本法赋予中央的各项权力；建立健全特区维护国家安全的法律制度和执行机制；健全行政长官对中央政府负责的制度；完善港澳融入国家发展大局、同内地优势互补协同发展机制；完善防范遏制外部势力干预港澳事务和进行分裂、颠覆、渗透、破坏活动的体制机制 |
| 3 为落实**爱国者治理**提供制度保障 | 完善有关选举制度，确保特区行政、立法、司法机构组成人员及重要法定机构负责人由真正的爱国者担任；发展壮大爱国爱港爱澳力量，在爱国爱港爱澳旗帜下**画出最大同心圆** |

## 第二节 保持香港、澳门长期繁荣稳定

### 一、香港、澳门保持长期稳定发展良好态势

- 实践证明⭐：“一国两制”实践取得**举世公认的成功**；它是**保持港澳长期繁荣稳定的好制度，是保障港澳居民根本利益和福祉的好制度**。
- “三个不会变”（2012.12 习近平会见香港特区行政长官）：中央贯彻落实“一国两制”、严格按照基本法办事的**方针**不会变；支持行政长官和特区政府依法施政、履行职责的**决心**不会变；支持港澳发展经济、改善民生、推进民主、促进和谐的**政策**不会变。
- 2022.7 庆祝香港回归祖国 25 周年大会：中央全力支持香港主动对接“十四五”规划、**粤港澳大湾区**建设和“一带一路”高质量发展等国家战略，支持香港积极稳妥推进改革、破除利益固化藩篱。
- 港澳成就对比：

| 香港 | 澳门 |
| --- | --- |
| 抵御国际金融危机、新冠疫情等冲击；国际金融、航运、贸易中心地位稳固；创新科技产业迅速兴起；**连续多次被评为全球最自由经济体第一位**，世界竞争力排名长期位居前列；“东方之珠”“活力之都”魅力更胜往昔 | 走出一条**具有澳门特色**的“一国两制”成功实践道路；以宪法和澳门基本法为基础的宪制秩序牢固确立；经济跨越式发展，**人均收入水平稳居世界前列**；多元文化交相辉映，国际影响力不断提升 |

- ⭐ **青少年是港澳长期繁荣稳定的希望和未来**：加强对青少年的宪法和基本法教育、国情教育、中国历史和中华文化教育，增强国家意识和爱国精神，使爱国爱港爱澳光荣传统薪火相传。

### 二、推动香港进入由乱到治走向由治及兴的新阶段⭐⭐⭐

- **三条底线（绝不能允许）**：“一国两制”的提出首先是为了实现和维护国家统一；任何**危害国家主权安全**、**挑战中央权力和香港特区基本法权威**、**利用香港对内地进行渗透破坏**的活动，都是对底线的触碰。
- 一个时期以来反中乱港活动猖獗，香港局势一度出现严峻局面；党中央**审时度势、标本兼治**，三大举措：

| 举措 | 关键文件与事件 | 意义定位 |
| --- | --- | --- |
| 1 建立健全香港特区**维护国家安全的法律制度和执行机制** | 2020.5 十三届全国人大三次会议通过《全国人民代表大会关于建立健全香港特别行政区维护国家安全的法律制度和执行机制的决定》；**2020.6** 十三届全国人大常委会第二十次会议通过**《中华人民共和国香港特别行政区维护国家安全法》**；随后中央设驻港国家安全公署、特区设维护国家安全委员会；2022.12 全国人大常委会通过国安法第十四条和第四十七条的解释 | 为防范、制止和惩治危害国家安全的行为提供有力制度保障，成为维护香港稳定的**“定海神针”** |
| 2 完善**香港特区选举制度** | 2021.3 十三届全国人大四次会议通过《关于完善香港特别行政区选举制度的决定》；全国人大常委会修订基本法附件一、附件二；2021.5 立法会通过《2021 年完善选举制度（综合修订）条例草案》；2023.7《2023 年区议会（修订）条例》刊宪实施 | **“爱国者治港”原则的新选举制度全面确立和实行**；2023 区议会修订是全面落实“爱国者治港”的重要举措 |
| 3 坚持**以行政长官为核心的行政主导体制** | 行政长官和特别行政区政府是**香港的当家人，也是治理香港的第一责任人** | 中央坚定支持依法施政、积极作为，防范遏制外部势力干预，着力破解深层次矛盾，实现**良政善治** |

- 结论：香港已实现**由乱到治的重大转折，正处在由治及兴的关键时期**；一个政治民主、法治健全、自由开放、包容和谐、繁荣稳定、胸怀祖国、面向世界的香港必将更好呈现于世人面前。

### 三、支持香港、澳门融入国家发展大局⭐⭐

- **背靠祖国、联通世界**，是港澳得天独厚的显著优势：香港是我国内地**最大的外资来源地、对外投资最大目的地、对外贸易最大转口地**；澳门是我国双向开放特别是与**葡语国家**经贸往来的重要平台。
- 三个“最”（背诵）⭐：对港澳来说，“一国两制”是**最大的优势**，国家改革开放是**最大的舞台**，共建“一带一路”、粤港澳大湾区建设等国家战略实施是**新的重大机遇**。
- **四个“积极主动”**：

| 积极主动 | 要点 |
| --- | --- |
| 1 助力国家**全面开放** | 以“**港澳所长**”对接“**国家所需**”；把港澳国际联系广泛、专业服务发达优势同内地市场广阔、产业体系完整、科技实力较强优势结合起来，努力把港澳打造成**国家双向开放的重要桥头堡** |
| 2 参与**粤港澳大湾区**建设 | 在**一个国家、两种制度、三个关税区、三种货币**条件下建设，国际上没有先例；广深港高铁、港珠澳大桥建成开通，前海、横琴、南沙、河套深港等平台加快推进；打造**国际一流湾区和世界级城市群**，使大湾区成为**中国式现代化的引领地** |
| 3 参与**国家治理**实践 | 完善特区同宪法和基本法实施相关的制度和机制，引导特区政府转变治理理念、提高治理能力，展现**良政善治**新气象；自觉维护国家安全 |
| 4 促进**国际人文**交流 | 港澳是中西文化交流的重要纽带；传播中华优秀文化，宣介国家方针政策，讲好当代中国故事、讲好“一国两制”成功实践的香港故事、澳门故事 |

## 第三节 推进祖国完全统一

### 一、实现祖国完全统一是中华民族伟大复兴的必然要求⭐⭐

- **三重定位（原文背诵）**：解决台湾问题、实现祖国完全统一，是党**矢志不渝的历史任务**，是全体中华儿女的**共同愿望**，是实现中华民族伟大复兴的**必然要求**。
- 统一由民族复兴的**时和势**决定，是**不可阻挡的历史潮流**；习近平：“实现祖国完全统一是全体中华儿女的共同愿望，是民族复兴的题中之义。”

## 05易错点辨析

1. **构想的“提出对象”≠“首先运用对象”**——“一国两制”最早是针对**台湾问题**提出来的，**首先运用于解决香港和澳门问题**，别答反。
2. **“一国”与“两制”不是并列关系**——“一国”是前提和基础，“两制”从属、派生于“一国”；“两制”并非等量齐观、比肩并列，**国家的主体必须实行社会主义制度**。
3. **高度自治 ≠ 完全自治 ≠ 分权**——高度自治是**中央授予的地方事务管理权**，中央授予多少权力特区就享有多少权力，**不存在“剩余权力”**。
4. **全面管治权与高度自治权不对立**——二者本质统一，是源与流、本与末；任何时候都不能把两者对立起来，更不能以高度自治权**对抗**全面管治权。
5. **特区宪制基础不能只答基本法**——是宪法和基本法**共同构成、共同实施**；特别行政区不存在一个脱离国家宪法的“宪制”和“法治”。
6. **2020 年 5 月的《决定》≠ 6 月的《香港国安法》**——5 月全国人大通过的是《关于建立健全香港特别行政区维护国家安全的法律制度和执行机制的决定》；《中华人民共和国香港特别行政区维护国家安全法》是同年 **6 月由全国人大常委会**通过的。
7. **“定海神针”指香港国安法，不是选举制度**——落实“爱国者治港”、实现由乱到治的选举制度完善是另一项举措，两个定位不能互换。
8. **香港的“当家人”“第一责任人”**——行政长官和特别行政区政府是香港的当家人、治理香港的**第一责任人**；答题别写成中央政府。
9. **台湾问题的产生与解决**——台湾问题**因民族弱乱而产生，必将随着民族复兴而解决**；两岸同属一个中国的事实和现状清清楚楚，主权和领土完整从未分割。
10. **“最大现实威胁”“最大障碍”的搭配**——对两岸关系和平发展的**最大现实威胁**是“台独”势力及其分裂活动；“台独”分裂是祖国统一的**最大障碍**、民族复兴的**严重隐患**。
11. **总体方略十个坚持与定位一一对应**——政治基础 = 一个中国原则和“九二共识”（不是“九二共识”单独）；根本保证 = 党中央集中统一领导；战略支撑 = 决不承诺放弃使用武力；不能错位搭配。
12. **决不承诺放弃使用武力 ≠ 针对台湾同胞**——针对的是外部势力干涉和极少数“台独”分裂分子及其分裂活动，**绝非针对广大台湾同胞**。
