## 一、习近平新时代中国特色社会主义思想创立的时代背景

**总起**⭐⭐
- 一个民族要走在时代前列就不能没有**理论思维**，一个国家要实现繁荣富强、人民幸福就不能没有**科学理论指引**。
- 党的十八大以来，中国特色社会主义进入**新时代**，以习近平同志为主要代表的中国共产党人，坚持把马克思主义基本原理同中国具体实际相结合、同中华优秀传统文化相结合，创立了习近平新时代中国特色社会主义思想，**实现了马克思主义中国化时代化新的飞跃**。

**1. 时代是思想之母，实践是理论之源**⭐
- 当代中国正经历我国历史上最为广泛而深刻的社会变革，正在进行人类历史上最为宏大而独特的实践创新——这是一个需要思想理论、产生思想理论、并在伟大变革中不断推动思想理论向前发展的时代。

**2. 五方面时代背景**⭐⭐

| 时代背景 | 核心内容 | 溯源 |
| --- | --- | --- |
| **世界百年未有之大变局加速演进** | 世界之变、时代之变、历史之变前所未有；"东升西降"日益显著；和平赤字、发展赤字、安全赤字、治理赤字加重；深刻回答"人类社会何去何从"的历史之问 | ⭐ |
| **中华民族伟大复兴进入关键时期** | 社会主要矛盾发生历史性变化；"船到中流浪更急、人到半山路更陡"；牢牢立足社会主义初级阶段这个基本国情、最大实际；如期全面建成小康社会，迎来从站起来、富起来到强起来的伟大飞跃，进入不可逆转的历史进程 | ⭐ |
| **中国式现代化全面推进拓展** | 独特的文化传统、历史命运、基本国情决定必然走适合自己特点的现代化道路；用几十年时间走完了发达国家几百年走过的工业化历程；丰富和发展了人类文明新形态 | ⭐ |
| **科学社会主义在21世纪的中国焕发新的蓬勃生机** | 创立170多年来深刻改变世界历史进程；20世纪80年代末90年代初世界社会主义遭受严重曲折；中国特色社会主义正成为21世纪科学社会主义发展的旗帜，成为振兴世界社会主义的中流砥柱 | ⭐ |
| **中国共产党自我革命开辟新的境界** | 找到**自我革命**这个跳出治乱兴衰历史周期率的**第二个答案**；管党治党宽松软状况得到根本扭转；不断实现自我净化、自我完善、自我革新、自我提高 | ⭐ |

**3. 主要创立者**⭐
- 这一思想是**党和人民实践经验和集体智慧的结晶**，**主要创立者是习近平**。
- 习近平以马克思主义政治家、思想家、战略家的历史主动精神、非凡理论勇气、卓越政治智慧、强烈使命担当，应时代之变迁、立时代之潮头、发时代之先声，提出一系列治国理政**新理念新思想新战略**，为这一思想的创立和发展发挥了**决定性作用**、作出了**决定性贡献**。

## 二、习近平新时代中国特色社会主义思想是"两个结合"的重大成果

**1. "两个结合"的定位**⭐⭐
- 内容：马克思主义基本原理**同中国具体实际相结合**、**同中华优秀传统文化相结合**。
- "两个结合"是我们党在探索中国特色社会主义道路中得出的**规律性认识**，是我们取得成功的**最大法宝**。

**2. "两个结合"的提出脉络**⭐
- **毛泽东**：第一次系统阐述马克思主义基本原理同中国具体实际相结合的一系列重大问题，并提出要使马克思主义具有**民族形式**（第一个结合）。
- **习近平**：总结党百年来的理论创新经验，在强调坚持"第一个结合"的基础上，明确提出把马克思主义基本原理同中华优秀传统文化相结合的重大命题——这是**又一次的思想解放**。
- 三个"新高度"：对中国道路、理论、制度的认识达到新高度；党的历史自信、文化自信达到新高度；在传承中华优秀传统文化中推进理论创新的自觉性达到新高度。

**3. 两个结合各自要义对比**⭐⭐

|   | 第一个结合：同中国具体实际相结合 | 第二个结合：同中华优秀传统文化相结合 |
| --- | --- | --- |
| 形象说法 | 用马克思主义之"矢"去射新时代中国之"的" | 植根本国、本民族历史文化沃土，马克思主义真理之树才能根深叶茂 |
| 关键要求 | 推进实践基础上的理论创新，解放思想、实事求是、与时俱进、求真务实 | 坚持古为今用、推陈出新，坚定历史自信、文化自信 |
| 逻辑前提 | 马克思主义不是教条，而是行动指南；关键在于同中国实际和时代特征相结合 | 中华优秀传统文化是中华文明的智慧结晶，同马克思主义具有**高度契合性** |
| 具体做法 | 不断回答**中国之问、世界之问、人民之问、时代之问**，作出符合中国实际和时代要求的正确回答 | 把马克思主义思想精髓同中华优秀传统文化精华**贯通起来**、同人民群众日用而不觉的共同价值观念**融通起来** |

## 05易错点辨析

1. **"十个明确" ≠ "十四个坚持"的定位**——"十个明确"是**主体内容**（四梁八柱、统摄作用），"十四个坚持"是**基本方略**（理论分析和政策指导），两者不能互换。
2. **"六个必须坚持"是党的二十大提出的**——不是党的十九大或十九届六中全会；它体现的是**世界观、方法论和立场观点方法**，不是"主要内容"。
3. **"两个结合"的提出主体**——毛泽东是第一次系统阐述"第一个结合"；"第二个结合"（同中华优秀传统文化相结合）是**习近平明确提出**的重大命题，被称为"又一次的思想解放"。
4. **"两个确立" ≠ "两个维护"**——"两个确立"是确立核心地位与指导思想地位（重大政治成果），"两个维护"是政治要求（增强"四个意识"、坚定"四个自信"、做到"两个维护"）；选择题常把两组搭配互换设错。
5. **写入党章与载入宪法的时间、会议、载体对应**——2017.10 党的十九大写入党章（党的指导思想）；2018.3 十三届全国人大一次会议载入宪法（国家指导思想），三者任一错位即为错误选项。
6. **"新的飞跃"表述要完整**——是"实现了马克思主义中国化**时代化**新的飞跃"，不能漏掉"时代化"，也不能写成其他思想的飞跃。
7. **"六个必须坚持"的定位一一对应**——人民至上是**根本价值立场**、自信自立是内在精神特质、守正创新是鲜明理论品格、问题导向是重要实践要求、系统观念是基本思想和工作方法、胸怀天下是境界格局；"定位与内容"错配是常见干扰项。
8. **主要创立者的表述口径**——这一思想是"党和人民**实践经验和集体智慧的结晶**，主要创立者是习近平"，答题既要写集体结晶又要写习近平的决定性作用、决定性贡献，不能只写其一。
9. **两组"最大"别混淆**——"两个结合"是我们取得成功的**最大法宝**；"两个确立"是应对一切不确定性的**最大确定性、最大底气、最大保证**。
10. **教材结构数字**——本教材由**导论、结语和 17 章**内容组成，不是 16 章或 18 章。
