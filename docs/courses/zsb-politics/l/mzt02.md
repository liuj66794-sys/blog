## 03正文精讲

## 第一节 新民主主义革命理论形成的依据

::: info 本节指引 · 第一节 新民主主义革命理论形成的依据

- **目标**：说清近代中国的国情（半殖民地半封建社会）、两对主要矛盾与革命根本任务，并说明十月革命、五四运动怎样把中国革命推进到新民主主义革命阶段。
- **建议用时**：14 分钟
- **知识点**：`新民主主义革命理论形成的依据`

:::

::: info 半殖民地半封建社会

- **白话**：近代中国既不是完整的殖民地，也不是完整的封建社会：一面被帝国主义操纵着财政经济命脉和政治军事力量，一面又保留着地主阶级对农民的封建剥削——这两面合起来，就是近代中国最基本的国情。
- **教材表述**：毛泽东：“认清中国社会的性质，就是说，认清中国的国情，乃是认清一切革命问题的基本的根据。”半封建性：经济上封建剥削制度依旧占优势、民族资本主义先天不足未成为社会经济主要形式，政治上先是地主阶级军阀官僚的统治、接着是地主阶级和大资产阶级联盟的专政。半殖民地性：帝国主义通过政治、经济、文化侵略操纵中国的财政经济命脉和政治军事力量，破坏领土完整、勒索战争赔款、驻兵、攫取领事裁判权、控制海关和划分势力范围。中国经济、政治和文化的发展表现出极端的不平衡性，人民的贫困和不自由程度是当时世界少有的（课件正文·第一节）。
- **情境**：用它解释“为什么中国革命不能照搬西方”：西方资产阶级民主革命是在独立国家内部、由资产阶级领导、走合法斗争到武装起义的道路；近代中国内无民主制度、外无民族独立，又被帝国主义分割统治、发展极端不平衡——正是这样的国情决定了中国革命的对象、动力、道路都必须是另一套答案，所以毛泽东说认清国情是认清一切革命问题的基本根据。
- **易混区别**：三组易混：①“半殖民地”说的是主权被侵犯、被帝国主义间接支配，不是“完全殖民地”（名义上仍是独立国家，清政府和后来的北洋、国民党政权都还在）；②“半封建”说的是封建剥削制度仍占优势，不是“完全封建”（已有资本主义经济和无产阶级）；③国情里“极端不平衡”是经济政治文化发展的不平衡，别与“两对主要矛盾”或“革命道路走通的条件”里的“政治经济发展不平衡”写混——后者正是从这条国情里长出来的。
- **答题关键词**：半殖民地半封建社会、认清国情是认清一切革命问题的基本根据、帝国主义操纵财政经济命脉、封建剥削制度占优势、极端的不平衡性

:::

::: info 两对主要矛盾与革命根本任务

- **白话**：近代中国社会有两对主要矛盾：帝国主义和中华民族的矛盾、封建主义和人民大众的矛盾；其中第一对是最主要的。矛盾决定任务，革命的根本任务就是推翻帝国主义、封建主义和官僚资本主义的统治。
- **教材表述**：两对主要矛盾＝帝国主义和中华民族的矛盾（各种矛盾中最主要）＋封建主义和人民大众的矛盾；革命根本任务＝推翻帝国主义、封建主义和官僚资本主义的统治，推翻反动腐朽的政治上层建筑，变革阻碍生产力发展的生产关系（课件正文·第一节“主要矛盾与根本任务”）。对外推翻帝国主义压迫的是民族革命，对内推翻封建地主压迫的是民主革命，两个基本任务既相互区别又相互统一，其中最主要的任务是对外的民族革命。
- **情境**：用它解释“为什么首要对象是帝国主义”：帝国主义是社会进步和发展的最大障碍，是近代中国贫困落后和一切灾难祸害的总根源——它既直接压迫中国人民，又通过支持封建势力维持其统治，所以反对帝国主义是民族革命的任务，也就成了各类矛盾中最主要的那一对。不同历史阶段革命的主要对象随主要矛盾变化而不同：大革命时期是北洋军阀，土地革命战争时期是国民党新军阀，抗日战争时期是日本帝国主义，解放战争时期是美帝国主义支持下的国民党反动派。
- **易混区别**：①“最主要”只给帝国主义和中华民族的矛盾，别把封建主义和人民大众的矛盾也写成“最主要”；②“无产阶级和资产阶级的矛盾”不是近代中国的主要矛盾，它是社会主义改造时期（第三章）逐步上升的主要矛盾，属时间错位；③“地主阶级和农民阶级的矛盾”只是封建主义和人民大众矛盾的一个具体表现，层级更低。
- **答题关键词**：帝国主义和中华民族的矛盾（最主要）、封建主义和人民大众的矛盾、推翻三座大山、一切灾难祸害的总根源、民族革命与民主革命相统一

:::

::: info 从国情到理论：新民主主义革命理论形成的时代条件与实践基础

1. **1840 年鸦片战争以后** 中国逐步沦为半殖民地半封建社会——近代中国最基本的国情，也是两对主要矛盾与革命任务的来源。
2. **1917 年** 俄国十月革命开辟世界无产阶级社会主义革命的新时代，中国资产阶级民主革命的时代背景发生根本转换：从旧的世界资产阶级民主主义革命范畴，转变为世界无产阶级社会主义革命的一部分。
3. **1919 年 5 月 4 日** 五四运动爆发（直接导火索是巴黎和会把德国在山东的特权让予日本）：中国无产阶级作为独立的政治力量登上历史舞台成为领导力量，马克思列宁主义逐步成为指导思想——五四运动是从旧民主主义革命走向新民主主义革命的转折点。
4. **1921 年以后** 中国共产党成立并领导人民进行革命和建设。旧民主主义革命接连失败（太平天国、洋务运动、戊戌变法、义和团、辛亥革命都未能改变半殖民地半封建的社会性质），证明不触动封建根基的各种方案都不能完成反帝反封建任务——呼唤新的革命理论。
5. **大革命失败及井冈山斗争后** 党认识到“没有革命的武装就无法战胜武装的反革命”，提出“须知政权是由枪杆子中取得的”论断和工农武装割据思想，探索出农村包围城市、武装夺取政权的革命道路（土地革命＋武装斗争＋革命根据地建设），遵义会议后确立毛泽东在党中央和红军的领导地位。
6. **抗日战争时期** 中日民族矛盾上升为主要矛盾，党成为全民族抗战的中流砥柱，对中国革命规律性的认识趋于成熟，逐步形成系统化的新民主主义革命理论——实践与理论一一对应：两次国共合作→统一战线理论，农村根据地实践→农村包围城市道路理论，革命战争实践→人民军队和革命战争理论，党由小到大由弱到强→党的建设理论。

:::

| 本概念 | 类比为 |

### 一、近代中国国情和中国革命的时代特征

**1. 认清国情是基本前提**

- 毛泽东："认清中国社会的性质，就是说，认清中国的国情，乃是认清一切革命问题的基本的根据。"不了解近代中国国情和时代特征，便不可能提出符合中国实际的革命理论。

**2. 半殖民地半封建社会 = 近代中国最基本的国情**⭐⭐

- **半封建性**（一方面）：①经济上封建根基——地主阶级对农民的剥削依旧存在，并与买办资本、高利贷资本的剥削结合，占明显优势；②民族资本主义先天不足，未成为社会经济主要形式；③政治上辛亥革命后先是地主阶级军阀官僚的统治，接着是地主阶级和大资产阶级联盟的专政。
- **半殖民地性**（另一方面）：帝国主义通过政治、经济、文化侵略，操纵中国的财政经济命脉和政治军事力量——破坏领土完整、勒索"战争赔款"、驻兵、领事裁判权、控制海关和划分势力范围。
- 中国经济、政治和文化的发展表现出**极端的不平衡性**；中国人民的贫困和不自由程度，是当时世界少有的。

**3. 主要矛盾与根本任务**⭐⭐⭐

| 项目 | 内容 |
| --- | --- |
| 两对主要矛盾 | **帝国主义和中华民族的矛盾**（各种矛盾中**最主要**）＋**封建主义和人民大众的矛盾** |
| 革命根本任务 | 推翻**帝国主义、封建主义和官僚资本主义**的统治，推翻反动腐朽的政治上层建筑，变革阻碍生产力发展的生产关系 |

**4. 时代特征：从旧民主主义革命到新民主主义革命**⭐⭐

- **十月革命**（划时代意义）→ 中国资产阶级民主革命的**时代背景发生根本转换**：从旧的世界资产阶级民主主义革命范畴，转变为**世界无产阶级社会主义革命的一部分**。
- **五四运动** → 中国无产阶级开始作为**独立的政治力量登上历史舞台**成为领导力量，马克思列宁主义逐步成为指导思想，中国进入**新民主主义革命阶段**。直接导火索：1919 年巴黎和会把德国在山东的特权让予日本。
- 五四是**从旧民主主义革命走向新民主主义革命的转折点**：此前反帝反封建革命由农民阶级和民族资产阶级领导，此后领导者变成无产阶级；带着辛亥革命还不曾有的姿态——**彻底地不妥协地反帝国主义和彻底地不妥协地反封建主义**。
- 新民主主义革命**不同于**欧美各国民主革命（不建立资产阶级共和国，而造成各革命阶级在无产阶级领导下的联合专政），**也不同于**社会主义革命（不破坏参加反帝反封建的资本主义成分）。
- ⭐⭐ **革命两步走**：第一步完成反帝反封建的新民主主义革命任务，第二步完成社会主义革命任务——**性质不同但又相互联系**的两个革命过程。

### 二、新民主主义革命理论的实践基础

**1. 旧民主主义革命的失败呼唤新的革命理论**⭐

- 太平天国运动、洋务运动、戊戌变法、义和团运动接连而起，孙中山领导的辛亥革命推翻君主专制制度，但都未能改变半殖民地半封建的社会性质。
- 事实证明：**不触动封建根基的自强运动和改良主义、旧式的农民战争、资产阶级革命派领导的民主革命、照搬西方资本主义的种种方案**，都不能完成反帝反封建的革命任务（根源：不适合近代中国国情）。

**2. 新民主主义革命的艰辛探索奠定实践基础**

- 幼年时期：在领导权、武装斗争、革命道路等问题上没有科学认识，**遭受大革命失败的严重损失**。
- 大革命失败及井冈山斗争后：认识到"没有革命的武装就无法战胜武装的反革命"；毛泽东提出"**须知政权是由枪杆子中取得的**"论断和"**工农武装割据**"思想，探索出农村包围城市、武装夺取政权的革命道路；遵义会议后确立毛泽东在党中央和红军的领导地位。
- ⭐ **工农武装割据**三要素：**土地革命**（主要内容）＋**武装斗争**（主要形式）＋**革命根据地建设**（重要依托），三者有机统一。
- 抗日战争时期：中日民族矛盾上升为主要矛盾，党成为全民族抗战的中流砥柱，对中国革命的规律性认识趋于成熟，**逐步形成系统化的新民主主义革命理论**。
- ⭐ 实践与理论一一对应：两次国共合作 → 统一战线理论；农村根据地实践 → 农村包围城市道路理论；革命战争实践 → 人民军队和革命战争理论；党由小到大由弱到强 → 党的建设理论。**新民主主义革命实践是理论得以形成的基础和源泉**。

## 第二节 新民主主义革命的总路线和基本纲领

::: info 本节指引 · 第二节 新民主主义革命的总路线和基本纲领

- **目标**：背出总路线的完整表述，分别说清对象、动力、领导力量、性质和前途；背出政治、经济、文化三大纲领，并指出经济纲领三条各自的地位。
- **建议用时**：15 分钟
- **知识点**：`新民主主义革命总路线` `新民主主义的基本纲领`

:::

::: info 新民主主义革命总路线

- **白话**：一句话：无产阶级领导的、人民大众的、反对帝国主义封建主义和官僚资本主义的革命。它把“谁来领导、靠谁干、打谁、革命是什么性质、将来往哪走”五个问题一次说清。
- **教材表述**：1948 年《在晋绥干部会议上的讲话》完整表述：“新民主主义的革命，它只能是和必须是无产阶级领导的，人民大众的，反对帝国主义、封建主义和官僚资本主义的革命。”总路线指明了中国革命的对象、动力、领导力量、性质和前途（课件正文·第二节）。对象：帝国主义是首要对象、是近代中国贫困落后和一切灾难祸害的总根源；封建主义是帝国主义统治中国的社会基础；官僚资本主义是依靠帝国主义、勾结封建势力、利用国家政权发展起来的买办的封建的国家垄断资本主义。动力：无产阶级是最基本的动力和领导力量，农民是主力军（占全国人口 80% 以上，农民问题是中国革命的基本问题），城市小资产阶级是可靠同盟者，民族资产阶级是动力之一但带两面性。领导：无产阶级的领导权是中国革命的中心问题，也是新民主主义革命理论的核心问题。性质前途：新式的特殊的资产阶级民主主义革命，前途是社会主义。
- **情境**：用它分析“为什么民族资产阶级不能当领导”：民族资产阶级既受帝国主义压迫、封建主义束缚而有革命要求，又与二者有千丝万缕的联系，关键时刻动摇妥协——既不能充当革命的主要力量，更不可能是领导力量，所以政策是又联合又斗争。领导权历史地落到无产阶级及其政党手里有三个原因：帝国主义不允许中国建立独立的资产阶级共和国；民族资产阶级的软弱性和妥协性，不愿意也不能够彻底反帝反封建；中国无产阶级的强大和革命的彻底性。
- **易混区别**：①领导权属于无产阶级＝“中心问题／核心问题”，实现领导权的四个条件是另一组考点，别与“三大法宝”混；②性质是“资产阶级民主主义革命”而不是社会主义革命，只是“新式的特殊的”；③农民是主力军但从来不是领导力量——工人阶级对农民的领导是实现革命领导权的基础；④“革命的首要问题”是分清敌友（对象问题），与“中心问题”（领导权）不是一回事。
- **答题关键词**：无产阶级领导的、人民大众的、反帝反封建反官僚资本主义、首要对象＝帝国主义、农民是主力军、领导权是中心问题和核心问题、新式的特殊的资产阶级民主主义革命、前途社会主义

:::

::: info 总路线的文献时间线：1939 提概念 → 1940 系统论述 → 1948 完整表述

1. **1939 年** 《中国革命和中国共产党》第一次提出“新民主主义的革命”这一科学概念。
2. **1940 年** 《新民主主义论》系统论述新民主主义理论（政治、经济、文化三纲领在这一年展开），是毛泽东思想成熟的主要标志。
3. **1948 年** 《在晋绥干部会议上的讲话》完整地表述了新民主主义革命的总路线。
4. **1949 年** 《论人民民主专政》对新民主主义革命的基本经验作出集中概括，为新中国成立作理论准备。

::: info 新民主主义的基本纲领（政治·经济·文化）

- **白话**：基本纲领是总路线展开成的一张“施工图”：政治上建什么国、经济上动谁的财产、文化上提倡什么，三件事各有原文。
- **教材表述**：政治纲领：推翻帝国主义和封建主义的统治，建立无产阶级领导的、以工农联盟为基础的、各革命阶级联合专政的新民主主义共和国——国体是各革命阶级联合专政，政体是民主集中制的人民代表大会制度。经济纲领三条：①没收封建地主阶级的土地归农民所有，是新民主主义革命的主要内容（实行耕者有其田，土地革命路线是依靠贫雇农，团结中农，有步骤、有分别地消灭封建剥削制度，发展农业生产）；②没收官僚资本归新民主主义国家所有，是题中应有之义，包含新民主主义革命和社会主义革命的双重性质；③保护民族工商业，是经济纲领中极具特色的内容。文化纲领：无产阶级领导的、人民大众的、反帝反封建的文化，即民族的、科学的、大众的文化。
- **情境**：用“三条经济纲领各自的地位”分析选择题：题干问“极具特色”只能选保护民族工商业（由中国落后的生产力和新民主主义革命的性质决定，不是一般地消灭资本主义）；问“主要内容”选没收封建地主阶级的土地归农民所有；问“题中应有之义”或“双重性质”选没收官僚资本。反过来看，“没收一切私人资本主义”既不是三条中的任何一条，也与“保护民族工商业”直接矛盾。
- **易混区别**：①反对官僚资本主义并不是因为“它是资本主义”，而是因为它同帝国主义、封建势力结合成买办的封建的国家垄断资本主义、是国民党统治的经济基础；②保护民族工商业不等于无限制发展资本主义，是让私人资本主义在不能操纵国计民生的范围内获得发展便利；③新民主主义共和国既不是欧美式资产阶级专政共和国，也不是苏联式无产阶级专政共和国，而是几个革命阶级联合专政的过渡形式。
- **答题关键词**：国体＝各革命阶级联合专政、政体＝民主集中制的人民代表大会制度、没收土地归农民＝主要内容、没收官僚资本＝题中应有之义·双重性质、保护民族工商业＝极具特色、民族的科学的大众的文化

:::

::: info 无产阶级的领导权

- **白话**：中国革命由谁领头？答案是工人阶级（通过中国共产党）。这一点决定了这场革命是“新”的还是“旧”的。
- **教材表述**：无产阶级的领导权是中国革命的中心问题，也是新民主主义革命理论的核心问题；区别新旧两种不同范畴民主主义革命的根本标志，是革命的领导权掌握在无产阶级手中还是资产阶级手中。实现领导权要有四个条件：建立以工农联盟为基础的广泛的统一战线是实现领导权的关键；坚持独立自主原则、保持思想上政治上组织上的独立性、实行又联合又斗争是坚持领导权的基本策略；建立和发展人民的革命武装力量是保证领导权的坚强支柱；加强无产阶级政党的建设是实现领导权的根本保证。
- **情境**：用它比较两次国共合作：第一次国共合作中党没有坚持独立自主，大革命失败；抗日战争时期坚持统一战线中的独立自主原则，实行又团结又斗争，党反而在抗战中壮大——同一个“统一战线”摆在面前，能不能实现领导权，取决于四个条件是否落实。
- **易混区别**：①“中心问题／核心问题”＝无产阶级的领导权，不要写成“农民问题”（农民问题是中国革命的基本问题，两者提法不同）；②“根本标志”只指领导权归属，别选成革命对象、动力或武装斗争形式；③实现领导权的“关键”是统一战线、“坚强支柱”是革命武装、“根本保证”是党的建设——三个定位别互换。
- **答题关键词**：中心问题与核心问题、根本标志＝领导权在无产阶级还是资产阶级手中、统一战线是关键、革命武装是坚强支柱、党的建设是根本保证

:::

### 一、新民主主义革命的总路线

**0. 总路线的提出（文献时间线）**⭐⭐

| 时间 | 文献 | 贡献 |
| --- | --- | --- |
| 1939 | 《中国革命和中国共产党》 | **第一次提出"新民主主义的革命"的科学概念** |
| 1940 | 《新民主主义论》 | 系统论述新民主主义理论，**毛泽东思想成熟的主要标志** |
| 1948 | 《在晋绥干部会议上的讲话》 | **完整地表述总路线** |

- ⭐⭐⭐ 总路线原文背诵："新民主主义的革命，它只能是和必须是**无产阶级领导的**，**人民大众的**，**反对帝国主义、封建主义和官僚资本主义**的革命。"总路线指明了中国革命的**对象、动力、领导力量、性质和前途**。

**1. 革命对象**⭐⭐⭐

- 分清敌友，是**革命的首要问题**（"谁是我们的敌人？谁是我们的朋友？"）。

| 对象 | 地位 | 要点 |
| --- | --- | --- |
| 帝国主义 | **首要对象** | 近代中国最大的压迫是民族压迫；帝国主义是社会进步和发展的最大障碍，是近代中国贫困落后和一切灾难祸害的**总根源** |
| 封建主义 | 帝国主义统治的社会基础 | 地主阶级是帝国主义统治中国和封建军阀专制统治的**社会基础**；反封建 = 经济上消灭封建土地所有制、政治上消灭官僚军阀专制统治、解放生产力 |
| 官僚资本主义 | 基本对象之一 | 依靠帝国主义、勾结封建势力、利用国家政权力量发展起来的**买办的、封建的国家垄断资本主义**（背靠帝国主义、充当买办、垄断金融、压迫兼并民族工商业） |

- ⭐ 对外推翻帝国主义压迫的**民族革命**＋对内推翻封建地主压迫的**民主革命**，两个基本任务**既相互区别，又相互统一**；"最主要的任务是推翻帝国主义的民族革命"。
- ⭐ 不同历史阶段主要对象不同：大革命时期→北洋军阀；土地革命战争时期→国民党新军阀；抗日战争时期→日本帝国主义；解放战争时期→美帝国主义支持下的国民党反动派。

**2. 革命动力**⭐⭐⭐

| 阶级 | 地位 | 要点 |
| --- | --- | --- |
| 无产阶级 | **最基本的动力**、领导力量 | 新的社会生产力的代表，近代中国**最进步的阶级**；伴随民族工业和外国资本在华直接经营企业而产生 |
| 农民阶级 | **主力军** | 占全国人口 **80%以上**；农民问题是中国革命的**基本问题**；新民主主义革命实质上就是党领导下的**农民革命**，革命战争实质上是**农民战争**；工农阶级的联盟是形成强大力量、实现领导权的基础 |
| 城市小资产阶级 | 无产阶级的**可靠同盟者** | 包括广大知识分子、小商人、手工业者和自由职业者 |
| 民族资产阶级 | 动力之一 | **带两面性的阶级**：既受帝国主义压迫、封建主义束缚而有革命要求，又与之有千丝万缕的联系而在关键时刻**动摇妥协**；既不可能充当革命的主要力量，更不可能是领导力量；政策是**又联合又斗争** |

- ⭐ 动力是工人、农民、城市小资产阶级和民族资产阶级，而**根本动力是工人和农民**。

**3. 领导力量**⭐⭐⭐

- ⭐⭐ **无产阶级的领导权是中国革命的中心问题，也是新民主主义革命理论的核心问题**；区别新旧两种不同范畴民主主义革命的**根本标志**，是革命的领导权掌握在**无产阶级**手中还是**资产阶级**手中。
- 领导权历史地落到无产阶级及其政党的 3 个原因：①帝国主义不允许中国建立独立的资产阶级共和国；②民族资产阶级的软弱性和妥协性，不愿意也不能够彻底反帝反封建；③中国无产阶级的强大和革命的彻底性。
- 中国无产阶级自身的特点和优点（3 条）：①身受外国资本主义、本国封建势力和资产阶级**三重压迫**，革命最坚决最彻底；②**集中**在大城市大企业，利于组织团结和革命思想传播；③大部分出身破产农民，与农民有**天然联系**，便于结成联盟。
- ⭐⭐ 实现领导权的 4 个条件：

| 条件 | 定位 |
| --- | --- |
| 建立以工农联盟为基础的广泛统一战线 | 实现领导权的**关键** |
| 坚持独立自主原则，保持思想上政治上组织上的独立性，实行又联合又斗争 | 坚持领导权的**基本策略** |
| 建立和发展人民的革命武装力量 | 保证领导权的**坚强支柱** |
| 加强无产阶级政党的建设 | 实现领导权的**根本保证** |

**4. 性质和前途**⭐⭐⭐

- 性质：不是无产阶级社会主义革命，而是**资产阶级民主主义革命**——但是"**新式的特殊的**资产阶级民主主义的革命"。
- 与旧民主主义革命相比"新"在 4 点：

| 方面 | 新的内容和特点 |
| --- | --- |
| 时代 | 处于世界无产阶级社会主义革命的时代，是其**一部分** |
| 领导力量 | 中国无产阶级及其先锋队——**中国共产党** |
| 指导思想 | **马克思列宁主义** |
| 前途 | **社会主义**而不是资本主义 |

- 与社会主义革命的**区别**：新民主主义革命只推翻三座大山的反动统治，政治上建立**各革命阶级的联合专政**而不是无产阶级专政，经济上**保护民族工商业**、容许有利于国计民生的私人资本主义发展；社会主义革命则是无产阶级性质的革命，目标是消灭资本主义剥削制度和改造小生产的私有制。
- 与社会主义革命的**联系**：互相联系、紧密衔接，**中间不容横插一个资产阶级专政**；毛泽东以"文章的上篇与下篇"作喻——"**民主主义革命是社会主义革命的必要准备，社会主义革命是民主主义革命的必然趋势**"。

### 二、新民主主义的基本纲领

**提出过程**：1940 年《新民主主义论》阐述新民主主义的政治、经济和文化；1945 年党的七大《论联合政府》进一步与党的基本纲领联系起来具体阐述，形成新民主主义的基本纲领——它是**总路线的进一步展开和体现**。

**1. 政治纲领**⭐⭐⭐

- 内容：推翻帝国主义和封建主义的统治，建立**无产阶级领导的、以工农联盟为基础的、各革命阶级联合专政**的新民主主义共和国。
- ⭐ 国体 = **各革命阶级联合专政**；政体 = **民主集中制的人民代表大会制度**（国体决定人民当家作主，政体最直接最全面地体现这一核心内容和准则）。
- 国家体制三种（毛泽东按政权阶级性质划分）：甲 资产阶级专政的共和国；乙 无产阶级专政的共和国；丙 几个革命阶级联合专政的共和国。新民主主义共和国属丙种，是**一定历史时期的过渡形式**，既不同于欧美式资产阶级专政共和国，又区别于苏联式无产阶级专政社会主义共和国。

**2. 经济纲领**⭐⭐⭐

| 纲领 | 地位 | 要点 |
| --- | --- | --- |
| **没收封建地主阶级的土地归农民所有** | 新民主主义革命的**主要内容** | 废除封建地主土地所有制，进行土地革命，实行"**耕者有其田**"；土地革命路线：**依靠贫雇农，团结中农，有步骤、有分别地消灭封建剥削制度，发展农业生产**（贫雇农约占农村人口 70%左右） |
| **没收官僚资本归新民主主义国家所有** | 新民主主义革命的**题中应有之义** | 反对它并非因为它是资本主义，而因其是买办的封建的国家垄断资本主义、是国民党统治的经济基础、严重阻碍经济发展和社会进步；⭐没收官僚资本**包含新民主主义革命和社会主义革命的双重性质**，由此建立的社会主义性质国营经济在新民主主义社会经济中**居领导地位** |
| **保护民族工商业** | 经济纲领中**极具特色**的内容 | 由中国落后的生产力和新民主主义革命的性质决定；不是一般地消灭资本主义和资产阶级，让私人资本主义经济在**不能操纵国计民生的范围内**获得发展的便利，有益于社会向前发展 |

**3. 文化纲领**⭐⭐

- 定性：**无产阶级领导的、人民大众的、反帝反封建的文化**，即**民族的、科学的、大众的**文化。

| 特性 | 内涵 |
| --- | --- |
| 民族的 | 内容上反对帝国主义压迫、主张中华民族的尊严和独立；形式上具有鲜明的民族风格、民族形式和民族特色，要有**中国作风和中国气派**，同时大量吸收外国进步文化 |
| 科学的 | 反对一切封建思想和迷信思想，主张实事求是、客观真理及理论和实践的一致性；剔除封建性**糟粕**、吸收民主性**精华**，反对民族虚无主义 |
| 大众的 | 为全民族中绝大多数工人阶级和劳动群众服务，文化**普及于大众又提高大众**，因而也是民主的 |

- 地位：革命前是革命的**思想准备**，革命过程中是革命总战线中的一条**必要和重要的战线**。新民主主义的政治＋经济＋文化相结合，就是**新民主主义共和国**。

## 第三节 新民主主义革命的道路和基本经验

::: info 本节指引 · 第三节 新民主主义革命的道路和基本经验

- **目标**：论证农村包围城市、武装夺取政权道路的必然性，记住道路三内容与三大法宝的出处、內容和相互关系。
- **建议用时**：15 分钟
- **知识点**：`农村包围城市、武装夺取政权的革命道路` `新民主主义革命的三大法宝` `新民主主义革命理论的意义`

:::

::: info 农村包围城市、武装夺取政权

- **白话**：不是先占城市再取乡村，而是反过来：到农村去建立根据地、开展武装斗争和土地革命，用农村包围城市，最后夺取全国胜利。
- **教材表述**：1938 年 11 月六届六中全会明确指出：“共产党的任务，基本地不是经过长期合法斗争以进入起义和战争，也不是先占城市后取乡村，而是走相反的道路。”必要性两条：半殖民地半封建的中国内无民主制度而受封建主义压迫、外无民族独立而受帝国主义压迫，不可能像资本主义国家那样经长期合法斗争再武装起义，主要斗争形式只能是武装斗争；近代中国是农业大国，农民占绝大多数、是无产阶级可靠同盟军和革命主力军，必须深入农村，从解决农民土地问题入手，组织、发动和武装农民。能走通的五个条件：近代中国社会政治经济发展极端不平衡、军阀割据、存在统治薄弱环节（缝隙和可能）；广大农村深受多重压迫剥削、革命愿望强烈、又经大革命洗礼（群众基础好）；全国革命形势继续向前发展（客观条件）；相当力量正式红军的存在（坚强后盾）；党的领导有力量及其政策不错误（主观条件）。道路内容：土地革命是中国革命的基本内容，武装斗争是中国革命的主要形式、是农村根据地建设和土地革命的强有力保证，农村革命根据地是中国革命的战略阵地、是进行武装斗争和开展土地革命的依托。
- **情境**：用它分析“工农武装割据”：毛泽东提出这一思想时，强调的是土地革命、武装斗争、根据地建设三者的有机结合——只有土地革命把农民发动起来，根据地才有群众基础；只有武装斗争，根据地才能存在；只有根据地，武装斗争才有依托。所以三者的地位不能互换，1938 年六届六中全会才把这条道路完整表述出来。
- **易混区别**：①“初步形成”与“确立”：井冈山时期的文章提出工农武装割据，只是初步形成道路理论；先占乡村、后取城市、最后夺取全国胜利的完整表述是 1938 年六届六中全会确立的；②“为什么必须走”与“为什么能走通”是两组要点，答题要分开写；③道路三内容的定位不能互换：土地革命是基本内容、武装斗争是主要形式、根据地是战略阵地（依托）。
- **答题关键词**：先占乡村、后取城市、最后夺取全国胜利、内无民主制度、外无民族独立、农业大国与农民主力军、政治经济发展极端不平衡、土地革命·武装斗争·根据地建设

:::

::: info 道路的探索：从城市到农村的七个节点

1. **党成立初期** 工作重心放在城市、领导工人运动，对发动农民、建立农村根据地的重要性缺乏足够认识。
2. **1927 年大革命失败后** 八七会议提出“枪杆子里面出政权”；秋收起义受挫后毛泽东率队开赴井冈山，创建井冈山革命根据地，把武装斗争的主攻方向首先指向农村。
3. **农村根据地斗争时期** 写下《中国的红色政权为什么能够存在》《井冈山的斗争》《星星之火，可以燎原》，提出工农武装割据思想，初步形成农村包围城市的革命道路理论。
4. **红军长征到达陕北后** 分析时代特点和国情，论述中国革命的长期性和不平衡性，进一步丰富整体战略思想。
5. **1938 年 11 月六届六中全会** 确立“先占乡村，后取城市，最后夺取全国胜利”的革命道路——道路理论从初步形成走向完整确立。

:::

::: info 三大法宝（统一战线·武装斗争·党的建设）

- **白话**：党打败敌人的三件利器：把朋友拉得多多的统一战线、手里有枪的武装斗争、把党自己建设好。其中党的建设是核心。
- **教材表述**：出处：毛泽东在《〈共产党人〉发刊词》（1939 年 10 月）中总结中国革命两次胜利和两次失败的经验教训，提出统一战线、武装斗争、党的建设是党在中国革命中战胜敌人的三个主要的法宝——“正确地理解了这三个问题及其相互关系，就等于正确地领导了全部中国革命。”统一战线：由半殖民地半封建社会的阶级状况（中国社会是两头小中间大的社会）和革命的长期性、残酷性及其发展的不平衡性决定其必要性，两个联盟中工农联盟是基础、基本的和主要的，同民族资产阶级的联盟是非基本的、辅助性的但不可缺少；实践经验四条：巩固工农联盟、正确对待资产阶级（既联合又斗争）、区别对待（发展进步势力、争取中间势力、孤立顽固势力）、坚持独立自主原则。武装斗争：中国革命的特点和优点之一；建设人民军队的经验四条：坚持党对军队的绝对领导（根本原则、毛泽东建军思想的核心）、全心全意为人民服务（唯一宗旨）、开展革命的政治工作（官兵一致、军民一致、瓦解敌军和优待俘虏）、坚持正确的战略战术原则。党的建设：把思想建设始终放在首位（以无产阶级思想克服和改造各种非无产阶级思想）、重视组织建设（贯彻民主集中制）、重视作风建设（理论联系实际、密切联系群众、批评与自我批评三大优良作风，是党区别于其他任何政党的显著标志）、联系党的政治路线加强党的建设；延安整风确立了实事求是的思想路线。相互关系：统一战线和武装斗争是中国革命的两个基本特点、是战胜敌人的两个基本武器，统一战线是实行武装斗争的统一战线，武装斗争是统一战线的中心支柱，党的组织则是掌握这两个武器以实行对敌冲锋陷阵的英勇战士；党的建设是三大法宝的核心。
- **情境**：用它解释“为什么党的建设是核心”：统一战线能不能守住，取决于党在政治上、组织上、思想上有没有独立性；武装斗争能不能坚持，取决于党对军队的绝对领导——两件武器都握在党的手里，党自身建设不好，武器就握不住。1949 年毛泽东在《论人民民主专政》中对新民主主义革命的基本经验作出集中概括，正是建立在这三者之上。
- **易混区别**：①出处是 1939 年 10 月《〈共产党人〉发刊词》，别记成《论联合政府》或《新民主主义论》；②两个联盟的地位别记反：工农联盟是基础的、基本的主要的，与民族资产阶级的联盟是非基本的辅助性的；③“三大优良作风”是理论联系实际、密切联系群众、批评与自我批评，与“三大法宝”“三大作风”属不同考点，不要串；④“核心是党的建设”不要写成“核心是统一战线”。
- **答题关键词**：《〈共产党人〉发刊词》（1939.10）、统一战线两个联盟、党对军队的绝对领导、思想建设放在首位、三大优良作风、党的建设是核心

:::

::: tip 三大法宝像打仗时的三件事：拉盟友、握枪杆、练内功

| 本概念 | 类比为 |
| --- | --- |
| 统一战线 | 把能团结的人都团结过来，朋友越多越好，把主要敌人孤立起来 |
| 武装斗争 | 手里得有枪，而且是听自己指挥的枪（党对军队的绝对领导） |
| 党的建设 | 练内功：思想、组织、作风都过硬，队伍才不会散了架 |

**局限**：类比只能帮你记住“三件武器＋党是核心”这个结构；考试要写的是各自的具体经验条目（如两个联盟、官兵一致军民一致、三大优良作风）和固定搭配（武装斗争是统一战线的中心支柱、党的组织是英勇战士），不能写“拉盟友、握枪杆、练内功”。

### 一、新民主主义革命的道路

**1. 道路的提出（探索时间线）**⭐⭐

| 阶段 | 进展 |
| --- | --- |
| 党成立初期 | 工作重心放在城市、领导工人运动；对发动农民、建立农村根据地的重要性**缺乏足够认识** |
| 1927 大革命失败后 | 八七会议提出"枪杆子里面出政权"；秋收起义失败后毛泽东率队开赴井冈山，**创建井冈山革命根据地**，把武装斗争的主攻方向首先指向农村 |
| 农村根据地斗争实践 | 写下《中国的红色政权为什么能够存在》《井冈山的斗争》《星星之火，可以燎原》，提出"**工农武装割据**"思想，**初步形成**农村包围城市的革命道路理论 |
| 红军长征到达陕北后 | 分析时代特点和国情，论述中国革命的**长期性和不平衡性**，进一步丰富整体战略思想 |
| **1938.11 六届六中全会** | 明确指出："共产党的任务，基本地不是经过长期合法斗争以进入起义和战争，也不是先占城市后取乡村，**而是走相反的道路**"——确立经过长期武装斗争，**先占乡村，后取城市，最后夺取全国胜利**的革命道路 |

**2. 道路形成的必然性**⭐⭐⭐

- ⭐ **为什么要走**（由时代特点和具体国情决定的两方面）：
  1. 半殖民地半封建中国**内无民主制度**而受封建主义压迫、**外无民族独立**而受帝国主义压迫——不可能像资本主义国家那样经长期合法斗争再武装起义，**主要斗争形式只能是武装斗争**，主要组织形式必然是军队；
  2. 近代中国是**农业大国**，农民占绝大多数，是无产阶级可靠同盟军和革命主力军——必须**深入农村，从解决农民土地问题入手**，组织、发动和武装农民。
- ⭐ **为什么能走通**（5 条）：

| 条件 | 作用 |
| --- | --- |
| 近代中国社会政治经济发展**极端不平衡**、军阀割据，存在统治薄弱环节 | 提供了**缝隙和可能** |
| 广大农村深受多重压迫剥削、革命愿望强烈，又经大革命洗礼 | **群众基础**好 |
| 全国革命形势的继续向前发展 | **客观条件** |
| 相当力量**正式红军**的存在 | **坚强后盾** |
| 党的领导有力量及其政策的不错误 | **主观条件** |

**3. 道路的内容及意义**⭐⭐⭐

- 走这条道路，**根本在于处理好土地革命、武装斗争、农村革命根据地建设三者之间的关系**：

| 内容 | 地位 |
| --- | --- |
| 土地革命 | 中国革命的**基本内容** |
| 武装斗争 | 中国革命的**主要形式**，是农村根据地建设和土地革命的强有力保证 |
| 农村革命根据地 | 中国革命的**战略阵地**，是进行武装斗争和开展土地革命的依托 |

- 意义（3 条）：①不是照抄照搬俄国十月革命经验，而是**从中国实际出发**开辟正确道路；②是党运用马克思主义立场观点方法解决中国革命具体问题的**光辉典范**，反映了半殖民地半封建社会民主革命发展的客观规律，**独创性地发展了马克思列宁主义**；③对推进**马克思主义中国化时代化**具有重要的方法论意义。

### 二、新民主主义革命的三大法宝

**出处**：毛泽东在《〈共产党人〉发刊词》（1939 年 10 月）中，总结中国革命两次胜利和两次失败的经验教训，提出**统一战线、武装斗争、党的建设**是党在中国革命中战胜敌人的三个主要的法宝。"正确地理解了这三个问题及其相互关系，就等于正确地领导了全部中国革命。"（"三样法宝"的最早由来：1939.7.7 毛泽东在华北联合大学开学典礼以姜子牙三样法宝作喻）

**1. 统一战线**⭐⭐

- 建立最广泛统一战线的必要性（3 条）：①由中国半殖民地半封建社会的**阶级状况**决定——"中国社会是一个**两头小中间大**的社会"，无产阶级和地主大资产阶级都只占少数，必须团结最广大的人民；②由中国革命的**长期性、残酷性及其发展的不平衡性**决定；③近代中国社会**诸多矛盾交织**，提供了利用矛盾建立和发展统一战线的可能性。
- 发展历程：第一次国共合作的统一战线 → 工农民主统一战线 → 抗日民族统一战线 → 人民民主统一战线。
- ⭐⭐ 革命统一战线的**两个联盟**：

| 联盟 | 内容 | 地位 |
| --- | --- | --- |
| 第一个 | 工人阶级同农民阶级、广大知识分子及其他劳动者的联盟（主要是**工农联盟**） | 统一战线的**基础**，是**基本的、主要的**；只有巩固它才能实现党对统一战线的领导权 |
| 第二个 | 工人阶级和非劳动人民的联盟（主要是与**民族资产阶级**的联盟） | **非基本的、辅助性的**，但又是重要的不可缺少的；联合一切可联合的力量，孤立主要敌人 |

- 建立、巩固和发展统一战线的实践经验（4 条）：①建立巩固的**工农联盟**；②正确对待资产阶级尤其是民族资产阶级，实行**既联合又斗争**；③采取**区别对待**的方针——发展进步势力、争取中间势力、孤立顽固势力；④坚持**独立自主**原则，保持党在政治上、组织上和思想上的独立性。

**2. 武装斗争**⭐⭐

- 武装斗争是**中国革命的特点和优点之一**："在中国，离开了武装斗争，就没有无产阶级的地位，就没有人民的地位，就没有共产党的地位，就没有革命的胜利。"没有一支人民的军队，便没有人民的一切。
- 建设人民军队的经验（4 条）：

| 经验 | 要点 |
| --- | --- |
| 坚持党对军队的**绝对领导** | 建设新型人民军队的**根本原则**，也是毛泽东建军思想的**核心** |
| 建设全心全意为人民服务的人民军队 | **唯一宗旨**；人民军队要担负打仗、做群众工作、生产等任务 |
| 开展革命的政治工作 | 基本原则：**官兵一致、军民一致、瓦解敌军和优待俘虏** |
| 坚持正确的战略战术原则 | 以少胜多、以弱胜强的**人民战争**理论和一系列战略战术原则 |

**3. 党的建设**⭐⭐

- 特殊困难：半殖民地半封建的中国，**无产阶级人数很少，农民和其他小资产阶级出身的党员占多数**，各种非无产阶级思想必然反映到党内；"有许多党员，在组织上入了党，思想上并没有完全入党，甚至完全没有入党"——建设一个广大群众性的、马克思主义的无产阶级政党是一项**伟大的工程**。
- 党的自身建设经验（4 条）：

| 经验 | 要点 |
| --- | --- |
| 把**思想建设**始终放在首位 | 关键是以**无产阶级思想克服和改造各种非无产阶级思想** |
| 任何时候都重视**组织建设** | 根本的是贯彻**民主集中制**：个人服从组织、少数服从多数、下级服从上级、全党服从中央 |
| 重视**作风建设** | 逐步形成**理论联系实际、密切联系群众、批评与自我批评**三大优良作风——这是中国共产党**区别于其他任何政党的显著标志** |
| 联系党的**政治路线**加强党的建设 | 政治路线为全党的团结统一奠定政治基础 |

## 05易错点辨析

1. **新民主主义革命 ≠ 社会主义革命**——新民主主义革命仍属于**资产阶级民主主义革命的范畴**（新式的特殊的），只是领导权、指导思想、前途"新"；它建立各革命阶级联合专政、保护民族工商业，而非直接消灭资本主义。
2. **两步走之间不容"横插"**——民主主义革命是社会主义革命的必要准备，社会主义革命是民主主义革命的必然趋势，中间**不容横插一个资产阶级专政**；但两者性质不同，也不能"一次毕其功"。
3. **反对官僚资本主义 ≠ 反对一般资本主义**——并非因为它"是资本主义"，而是因为它同帝国主义、封建势力结合，是买办的封建的国家垄断资本主义，是国民党统治的经济基础。
4. **农民是主力军 ≠ 领导力量**——领导力量始终是无产阶级；工人阶级对农民的领导，是**实现革命领导权的基础**；农民革命实质是党领导下的农民革命。
5. **民族资产阶级是动力，但既不能充当主要力量更不能当领导力量**——因其两面性（革命要求＋动摇妥协），对其政策是又联合又斗争，别与"小资产阶级是可靠同盟者"混淆。
6. **新民主主义共和国 ≠ 欧美式共和国，也 ≠ 苏联式共和国**——它是**几个革命阶级联合专政**的共和国，是一定历史时期的**过渡形式**。
7. **没收官僚资本具有双重性质**——既含新民主主义革命性质，又含社会主义革命性质；由此建立的国营经济在新民主主义社会多种经济成分中**居领导地位**。
8. **保护民族工商业 ≠ 无限制发展资本主义**——是让私人资本主义在**不能操纵国计民生的范围内**获得发展的便利。
9. **道路三内容的地位不能互换**——土地革命是**基本内容**、武装斗争是**主要形式**、农村革命根据地是**战略阵地（依托）**；"工农武装割据"思想只是**初步形成**道路理论，1938 年六届六中全会才**确立**完整道路表述。
10. **两个联盟的地位**——工农联盟（第一个联盟）是基础、基本的主要的；与民族资产阶级的联盟（第二个联盟）是非基本的辅助性的，但**不可缺少**，别记反。
11. **三大法宝的出处与核心**——出自《〈共产党人〉发刊词》（1939）；核心是**党的建设**；另记固定搭配：武装斗争是统一战线的**中心支柱**，党的组织是掌握两个武器的**英勇战士**。
12. **延安整风的时间与内容**——1941.5《改造我们的学习》开始，1945.4.20 六届七中全会《关于若干历史问题的决议》结束；"三反对"对应"三整顿"（主观主义—学风、宗派主义—党风、党八股—文风），方针是"惩前毖后，治病救人"。

### qa:2

**要点**

- 总起：基本纲领是总路线的进一步展开和体现，分政治、经济、文化三个方面。
- 政治纲领：推翻帝国主义和封建主义的统治，建立无产阶级领导的、以工农联盟为基础的、各革命阶级联合专政的新民主主义共和国。
- 国体与政体：国体是各革命阶级联合专政；政体是民主集中制的人民代表大会制度。
- 经济纲领第一条：没收封建地主阶级的土地归农民所有——新民主主义革命的主要内容（实行耕者有其田；土地革命路线是依靠贫雇农，团结中农，有步骤、有分别地消灭封建剥削制度，发展农业生产）。
- 经济纲领第二条：没收官僚资本归新民主主义国家所有——题中应有之义，包含新民主主义革命和社会主义革命的双重性质，由此建立的国营经济居领导地位。
- 经济纲领第三条：保护民族工商业——经济纲领中极具特色的内容，让私人资本主义在不能操纵国计民生的范围内获得发展便利。
- 文化纲领：无产阶级领导的、人民大众的、反帝反封建的文化，即民族的、科学的、大众的文化（民族的＝反对帝国主义压迫、有中国作风中国气派；科学的＝反对封建迷信、主张实事求是；大众的＝为全民族中绝大多数劳动群众服务）。

**推导**：先答“基本纲领是什么”（总路线展开为政治、经济、文化三方面），再逐方面写：政治纲领抓“国体＋政体”两句；经济纲领必须三条齐写并各带定位词（主要内容／题中应有之义·双重性质／极具特色）；文化纲领写全“无产阶级领导的人民大众的反帝反封建的文化＝民族的科学的大众的文化”并简单解释三个特征。三条经济纲领是本问采分重点，缺一条或错位一个定位词都会失分。

**自评标准**

- [ ] 政治、经济、文化三方面齐全，经济纲领三条一条不漏；
- [ ] 三个定位词对号入座：主要内容＝没收土地归农民、题中应有之义＝没收官僚资本、极具特色＝保护民族工商业；
- [ ] 文化纲领能写出“无产阶级领导的人民大众的反帝反封建的文化”与“民族的、科学的、大众的”两层表述。

### qa:3

**要点**

- 总起：道路即农村包围城市、武装夺取政权，1938 年 11 月六届六中全会确立“先占乡村，后取城市，最后夺取全国胜利”的完整表述。
- 为什么必须走之一：半殖民地半封建的中国内无民主制度而受封建主义压迫、外无民族独立而受帝国主义压迫，不可能像资本主义国家那样经过长期合法斗争再进入武装起义，主要斗争形式只能是武装斗争，主要组织形式必然是军队。
- 为什么必须走之二：近代中国是农业大国，农民占绝大多数，是无产阶级可靠同盟军和革命主力军，必须深入农村，从解决农民土地问题入手，组织、发动和武装农民。
- 为什么能走通（五条）：政治经济发展极端不平衡、军阀割据、存在统治薄弱环节（缝隙和可能）；农村群众基础好；全国革命形势继续向前发展（客观条件）；相当力量正式红军的存在（坚强后盾）；党的领导有力量及其政策不错误（主观条件）。
- 道路内容与三者关系：土地革命是中国革命的基本内容、武装斗争是主要形式、农村革命根据地是战略阵地（依托），三者有机结合，即工农武装割据思想。
- 收尾：这条道路不是照抄照搬俄国十月革命经验，而是从中国实际出发开辟的正确道路，独创性地发展了马克思列宁主义，对推进马克思主义中国化时代化具有方法论意义。

**推导**：按“为什么必须走→为什么能走通→道路是什么→意义”四段推进：第一段从国情里两条现实（内无民主外无独立、农业大国农民占多数）分别推出“只能武装斗争”和“必须深入农村”；第二段列五条条件，注意客观与主观分开；第三段写道路三内容并强调地位不能互换；最后用一句意义收尾，避免只答原因不答内容。

**自评标准**

- [ ] 能分开写“必须走”的两条原因与“能走通”的五条条件，而不是混成一堆；
- [ ] 道路三内容及其定位（基本内容／主要形式／战略阵地）能准确对应；
- [ ] 能点出道路的确立时间（1938 年六届六中全会）与“从中国实际出发、独创性地发展了马克思列宁主义”的评价句。

### qa:4

**要点**

- 总起：统一战线的必要性和经验出自半殖民地半封建社会的阶级状况与革命的长期性、残酷性及其发展的不平衡性。
- 经验一：建立巩固的工农联盟——工人阶级同农民阶级、广大知识分子及其他劳动者的联盟是统一战线的基础，是基本的、主要的。
- 经验二：正确对待资产阶级尤其是民族资产阶级，实行既联合又斗争的政策。
- 经验三：采取区别对待的方针——发展进步势力、争取中间势力、孤立顽固势力。
- 经验四：坚持独立自主原则，保持党在政治上、组织上和思想上的独立性。
- 补充（两个联盟的地位）：工人阶级同民族资产阶级等非劳动人民的联盟是非基本的、辅助性的，但又是不可缺少的，用来联合一切可联合的力量、孤立主要敌人；只有巩固工农联盟才能实现党对统一战线的领导权。

**推导**：先一句说必要性（阶级状况决定必须团结最广大人民；革命长期残酷且不平衡；诸多矛盾交织提供利用矛盾的可能性），再按四条经验展开，最后补上两个联盟的地位对比，答案就从“有几点”变成“有层次”。答题时注意“建立巩固的工农联盟”要写出“基础、基本的和主要的”这一限定。

**自评标准**

- [ ] 四条经验齐全，并能写出“工农联盟是统一战线的基础”这一限定；
- [ ] 能区分两个联盟的地位（基础的、基本的和主要的／非基本的、辅助性的但不可缺少）；
- [ ] 不会把统一战线的经验与三大法宝的其他两件（武装斗争、党的建设）条目写混。

### qa:5

**要点**

- 与旧民主主义革命相比的“新”之一（时代）：处于世界无产阶级社会主义革命的时代，是世界无产阶级社会主义革命的一部分。
- 与旧民主主义革命相比的“新”之二（领导力量）：由中国无产阶级及其先锋队——中国共产党领导。
- 与旧民主主义革命相比的“新”之三（指导思想）：以马克思列宁主义为指导。
- 与旧民主主义革命相比的“新”之四（前途）：前途是社会主义而不是资本主义。
- 与社会主义革命的区别：新民主主义革命只推翻三座大山的反动统治，政治上建立各革命阶级的联合专政而不是无产阶级专政，经济上保护民族工商业、容许有利于国计民生的私人资本主义发展；社会主义革命则是无产阶级性质的革命，目标是消灭资本主义剥削制度和改造小生产的私有制。
- 与社会主义革命的联系：两者互相联系、紧密衔接，中间不容横插一个资产阶级专政；毛泽东以“文章的上篇与下篇”作喻——“民主主义革命是社会主义革命的必要准备，社会主义革命是民主主义革命的必然趋势”。

**推导**：分三块作答：第一块用“时代、领导力量、指导思想、前途”四点回答“新”在哪里——这是最常考的四点；第二块写区别，抓住“联合专政 vs 无产阶级专政”“保护民族工商业 vs 消灭剥削制度”两组对照；第三块写联系，必写“上篇与下篇”“必要准备与必然趋势”“中间不容横插一个资产阶级专政”三句固定表述。最后可用一句总结收束：新民主主义革命属于资产阶级民主主义革命范畴，但又不同于旧式民主革命，也不同于社会主义革命。

**自评标准**

- [ ] “新”的四点（时代、领导力量、指导思想、前途）齐全且表述规范；
- [ ] 区别部分能写出“各革命阶级的联合专政而非无产阶级专政、保护民族工商业”两个要点；
- [ ] 联系部分能写出“必要准备与必然趋势”“中间不容横插一个资产阶级专政”的固定表述。

### qa:6

**要点**

- 出处与总述：毛泽东在《〈共产党人〉发刊词》（1939 年 10 月）中提出统一战线、武装斗争、党的建设是党在中国革命中战胜敌人的三个主要的法宝。
- 统一战线：两个联盟——工农联盟（同农民阶级、广大知识分子及其他劳动者的联盟）是基础、基本的和主要的；同民族资产阶级等非劳动人民的联盟是非基本的、辅助性的但不可缺少。
- 武装斗争：中国革命的特点和优点之一；建设人民军队的根本原则是坚持党对军队的绝对领导，唯一宗旨是全心全意为人民服务，政治工作基本原则是官兵一致、军民一致、瓦解敌军和优待俘虏。
- 党的建设：把思想建设放在首位，重视组织建设（民主集中制）和作风建设（理论联系实际、密切联系群众、批评与自我批评三大优良作风），延安整风确立实事求是的思想路线。
- 相互关系（必背）：统一战线和武装斗争是中国革命的两个基本特点、是战胜敌人的两个基本武器；统一战线是实行武装斗争的统一战线，武装斗争是统一战线的中心支柱，党的组织则是掌握这两个武器以实行对敌冲锋陷阵的英勇战士。
- 核心与收尾：党的建设是三大法宝的核心；1949 年毛泽东在《论人民民主专政》中对新民主主义革命的基本经验作了集中概括。

**推导**：先答出处（1939.10《〈共产党人〉发刊词》）与总述，再按“统一战线→武装斗争→党的建设”三件武器各写要点（每件抓两个抓手：统一战线的两个联盟、武装斗争的党对军队绝对领导、党的建设的思想建设首位和三大优良作风），最后用相互关系句收尾并点明“党的建设是核心”。三件武器与相互关系都要写，只写三件武器会丢掉“相互关系”的采分点。

**自评标准**

- [ ] 出处、总述、三件武器、相互关系、核心五部分齐全；
- [ ] 能准确写出“武装斗争是统一战线的中心支柱、党的组织是英勇战士”这一固定搭配；
- [ ] 知道三大法宝的核心是党的建设，并能在结尾带上 1949 年《论人民民主专政》的集中概括。
