## 03正文精讲

## 第一节 让人民生活幸福是"国之大者"

> &lt;p&gt;带领人民创造美好生活，是我们党始终不渝的奋斗目标。党的十八大以来，党中央坚持以人民为中心的发展思想，在发展中保障和改善民生，加强和创新社会治理，人民生活全方位改善。全面建设社会主义现代化国家，**出发点和落脚点是让人民生活越过越好**；以人民为中心是我们党的根本执政理念，**让人民生活幸福是"国之大者"**，要把增进民生福祉作为发展的根本目的⭐⭐。&lt;/p&gt;

### 一、民生是人民幸福之基

**总述**："治国有常，利民为本。"民生是老百姓最关心的问题，涉及**分配、就业、教育、医疗、住房、社会保障**等方面；民生事关人民的生存生活生计，事关民心所向、民情所系、民意所指，**决定党的事业成败和国家命运兴衰**⭐。

**增进民生福祉的三个定位（必背）**⭐⭐⭐

| 定位 | 要点 |
| --- | --- |
| ①坚持**立党为公、执政为民**的本质要求 | 中国共产党是人民的党，任何时候都把**群众利益放在第一位**；始终坚守为中国人民谋幸福、为中华民族谋复兴的初心使命，实现好、维护好、发展好最广大人民根本利益 |
| ②**社会主义生产**的根本目的 | "努力办好各项民生事业，让老百姓的日子越过越好，是社会主义生产的根本目的"；关注人本身的发展，是**社会主义和资本主义的根本区别之一** |
| ③全面建设社会主义现代化国家的**应有之义** | 中国式现代化是**造福人民的现代化**；人民期盼更好的教育、更稳定的工作、更满意的收入、更可靠的社会保障、更高水平的医疗卫生服务、更舒适的居住条件、更优美的环境 |

### 二、人民获得感幸福感安全感更加充实、更有保障、更可持续

**1. 打赢脱贫攻坚战**⭐⭐⭐

- 打赢脱贫攻坚战、消除绝对贫困，是**全面建成小康社会的底线任务**，是必须抓紧抓好的**第一民生工程**。"小康不小康，关键看老乡，关键在贫困的老乡能不能脱贫"；组织实施了**人类历史上规模最大、力度最强**的脱贫攻坚战。
- 注重加强**普惠性、基础性、兜底性**民生建设，着力解决人民群众急难愁盼问题，扎实推进共同富裕。

| 方略 | 内容 |
| --- | --- |
| **六个精准** | 扶持对象、项目安排、资金使用、措施到户、因村派人、脱贫成效精准 |
| **五个一批** | 发展生产、易地搬迁、生态补偿、发展教育、社会保障兜底（脱贫）一批 |
| **两不愁三保障** | 不愁吃、不愁穿；**义务教育、基本医疗、住房安全**有保障 |
| 责任机制 | 省、市、县、乡、村**五级书记**抓扶贫，层层压实责任 |

- 成就：全国 **832** 个贫困县全部摘帽，**12.8 万**个贫困村全部出列，现行标准下**近 1 亿**农村贫困人口实现脱贫，历史性地解决了绝对贫困问题；脱贫摘帽不是终点，而是新生活、新奋斗的起点，把巩固拓展脱贫攻坚成果同**乡村振兴**有效衔接。

**2. 聚焦民生重点领域，推动人民生活全方位改善**⭐⭐

| 领域 | 重大举措 |
| --- | --- |
| 收入分配 | 更合理、更有序，推动形成**橄榄型分配格局** |
| 就业 | 作为**最大的民生工程**，实现更加充分更高质量就业 |
| 教育 | 办好人民满意的教育，建成**世界上规模最大的教育体系** |
| 社会保障 | 建成**世界上规模最大的社会保障体系** |
| 医疗卫生 | 全面推进健康中国建设，建成**世界上规模最大的医疗卫生体系** |
| 疫情防控 | 坚持人民至上、生命至上，取得疫情防控重大决定性胜利 |
| 住房 | 坚持**房子是用来住的、不是用来炒的**定位，多主体供给、多渠道保障、**租购并举** |

- "七有"得到更好实现：**幼有所育、学有所教、劳有所得、病有所医、老有所养、住有所居、弱有所扶**。

**3. 新时代十年社会建设主要成就（数据）**：城镇新增就业年均超 **1300 万**人；约 **1.8 亿**农村人口进城成为城镇常住人口；居民人均可支配收入超 **3.5 万元**、中等收入群体超 **4 亿**人；劳动年龄人口平均受教育年限 **10.9 年**；人均预期寿命 **78.2 岁**；基本养老、失业、工伤、基本医疗保险参保人数分别为 **10.3 亿、2.3 亿、2.8 亿、13.6 亿**。

### 三、坚持在发展中增进民生福祉⭐⭐⭐

- 发展是解决民生问题的"**总钥匙**"，民生是发展的"**指南针**"。

| 定位 | 内容要点 |
| --- | --- |
| **重要前提**：正确把握民生和发展的关系 | 发展是改善民生的**物质基础**，离开发展谈改善民生是无源之水、无本之木；民生连着内需、连着发展，**抓民生也是抓发展**；使民生改善和经济发展有效对接、相得益彰 |
| **工作思路**：坚守底线、突出重点、完善制度、引导预期 | 坚守底线=织牢民生安全网"网底"，对困难群众**应保尽保**；突出重点=加大对革命老区、民族地区、边疆地区、相对贫困地区基本公共服务支持；完善制度=公平、普惠、可持续；引导预期=民生保障水平与经济社会发展水平相适应 |
| **重中之重**：解决人民群众最关心最直接最现实的利益问题 | "把人民群众安危冷暖放在心上，雪中送炭，纾难解困"；完善制度机制同解决群众急难愁盼问题相结合，实现工作常态化、长效化 |
| **重要方针**：尽力而为、量力而行 | 承诺了就要兑现，不能裹足不前、铢施两较、该花的钱也不花；又不提出超越阶段的过高标准，不能好高骛远、寅吃卯粮 |
| **重要原则**：人人尽责、人人享有 | 对美好生活的向往只有通过**劳动**才能实现；鼓励辛勤劳动、诚实劳动、创造性劳动，依靠共同奋斗创造美好生活 |

## 第二节 不断提高人民生活品质

> &lt;p&gt;保障和改善民生**没有终点，只有连续不断的新起点**。要采取更多惠民生、暖民心举措，健全基本公共服务体系，提高公共服务水平，增强**均衡性和可及性**，不断满足人民日益增长的美好生活需要。&lt;/p&gt;

### 一、完善分配制度⭐⭐⭐

- **收入分配是民生之源**，是改善民生、实现发展成果由人民共享最重要最直接的方式；**分配制度是促进共同富裕的基础性制度**；分配是联结生产与消费的重要纽带。既要把"蛋糕"做大做好，又要把"蛋糕"切好分好。
- 数据：居民人均可支配收入从 2012 年 **1.65 万元**增加到 2021 年 **3.51 万元**；2013-2021 年农村居民年均收入增速比城镇快 **1.7 个百分点**；东部、中部、西部、东北年均增速分别为 8.6%、8.9%、9.3%、7.4%；中等收入群体超 **4 亿**人，形成世界上规模最大的中等收入群体。

**构建三次分配协调配套的制度体系**⭐⭐⭐

| 层次 | 作用 | 举措要点 |
| --- | --- | --- |
| **初次分配** | 发挥**基础性作用** | 提高劳动报酬在初次分配中的比重，健全工资合理增长机制；通过土地、资本等要素使用权、收益权增加中低收入群体要素收入；不断壮大中等收入群体 |
| **再分配** | 发挥**调节作用** | 加大**税收、社保、转移支付**等的调节力度，提高精准性 |
| **第三次分配** | 建立健全机制 | 引导、支持有意愿有能力的企业、社会组织和个人积极参与**公益慈善事业** |

### 二、实施就业优先战略⭐⭐

- **就业是最基本的民生**，是民生改善的"温度计"。习近平："**就业是最大的民生工程、民心工程、根基工程，必须抓紧抓实抓好。**"充分就业则民心安、社会稳；劳动者只有拥有一份职业、一份工作，才能平等融入社会生活，也才更有尊严。
- 形势：2012-2021 年城镇新增就业年均超 **1300 万**人，城镇就业人数增长至 **4.7 亿**；同时就业总量压力依然存在，**结构性就业矛盾凸显**。
- 举措（7 条）：①把**稳就业**提高到战略高度通盘考虑；②强化**就业优先政策**，健全就业促进机制，促进高质量充分就业；③健全就业公共服务体系，完善**重点群体**就业支持体系（高校毕业生扩渠道、农民工稳就业、困难群体兜底帮扶）；④统筹城乡就业政策体系，消除影响平等就业的不合理限制和**就业歧视**；⑤健全**终身职业技能培训制度**，推动解决结构性就业矛盾；⑥完善促进**创业带动就业**的保障制度，支持和规范发展**新就业形态**；⑦健全劳动法律法规，加强**灵活就业和新就业形态劳动者权益保障**。

### 三、健全社会保障体系⭐⭐

- **含义与范围**：社会保障体系由国家立法规定并以国家作为给付义务主体，为保障社会成员的基本生活和福利、对生活困难社会成员给予物质或服务帮助的各项措施的统称，主要涉及**社会保险、社会救助、社会福利、社会优抚**等方面。
- **定位**（习近平）：社会保障是保障和改善民生、维护社会公平、增进人民福祉的**基本制度保障**，发挥着**民生保障安全网、收入分配调节器、经济运行减震器**的作用，是治国安邦的大问题⭐⭐。
- **现状与目标**：坚持以**增强公平性、适应流动性、保证可持续性**为重点；截至 2022 年底，基本养老保险参保人数达 **10.5 亿**，基本医疗保险参保率稳定在 **95%** 以上，织就世界上规模最大的社会保障安全网；完善**覆盖全民、统筹城乡、公平统一、安全规范、可持续**的多层次社会保障体系。
- **具体举措**：完善基本养老保险**全国统筹**；加快发展多层次、多支柱养老保险体系，扩大年金制度覆盖范围，规范发展第三支柱养老保险，积极发展商业医疗保险；推动基本医疗保险、失业保险、工伤保险**省级统筹**；健全农民工、灵活就业人员、新业态就业人员参加社会保险制度；健全退役军人保障制度、老年人关爱服务体系，完善帮扶残疾人、孤儿等社会福利制度。

### 四、推进健康中国建设⭐⭐

- **地位**：人民健康是**社会文明进步的基础**，是**民族昌盛和国家富强的重要标志**；习近平指出，**人民健康是社会主义现代化的重要标志**；卫生健康事业在经济社会发展中处于**基础性地位**。
- **成就**：人均预期寿命从 2012 年的 **74.8 岁**增长到 2021 年的 **78.2 岁**，主要健康指标居于中高收入国家前列。
- **举措（9 条）**：
  1. 把保障人民健康放在**优先发展的战略位置**，坚持**大卫生大健康**理念，全方位、全周期保障人民健康；
  2. 优化人口发展战略，建立**生育支持政策体系**；
  3. 实施积极应对**人口老龄化**国家战略，发展养老事业和养老产业；
  4. 深化医药卫生体制改革，促进**医保、医疗、医药**协同发展和治理；
  5. 坚持基本医疗卫生事业**公益属性**，支持社会力量举办非营利性医疗机构；
  6. 改革完善疾病预防控制体系，健全重大疫情救治体系，构建强大的公共卫生体系；
  7. 重视**心理健康和精神卫生**，推动防治体系建设；
  8. 大力发展**中医药**事业，推动中医药和西医药相互补充、协调发展；
  9. 深入开展健康中国行动和**爱国卫生运动**，倡导文明健康生活方式。

## 第三节 在共建共治共享中推进社会治理现代化

> &lt;p&gt;社会治理是**国家治理的重要领域**，推进社会治理现代化是推进国家治理体系和治理能力现代化的重要内容；要打造共建共治共享的社会治理新格局，坚定不移走中国特色社会主义社会治理之路。&lt;/p&gt;

### 一、加强和创新社会治理

**1. 内涵**⭐⭐：加强和创新社会治理，就是要在**党的领导下，以政府为主导，以社会多元主体参与为基础，以维护人民群众根本利益为核心**，通过合作、对话、协商、沟通等方式，依法对社会事务、社会组织和社会生活进行引导和规范，协调社会利益，化解社会矛盾，促进社会公平，推动社会稳定有序发展。

**2. 理念演进（三个会议三个提法）**⭐⭐⭐

| 会议 | 提法 |
| --- | --- |
| 党的**十八届三中全会** | 提出**创新社会治理体制**；从"社会管理"到"社会治理"，一字之差意味着社会建设理念、体制和方式的重大变革 |
| 党的**十九大** | 提出打造**共建共治共享的社会治理格局** |
| 党的**十九届四中全会** | 提出坚持和完善**共建共治共享的社会治理制度** |

**3. "四个治理"**⭐⭐⭐

| 原则 | 要点 |
| --- | --- |
| **系统治理** | 把社会治理置于经济社会发展全局、国家治理现代化大局、法治中国建设战略布局中思考谋划推进 |
| **依法治理** | 以法治精神引领、用法治思维谋划、用法治方式破解难题，把社会治理纳入法治轨道 |
| **综合治理** | 坚持党委领导核心作用、政府主导作用，发挥相关部门职能作用、社会各方面协同作用、广大群众主体作用，形成整体合力 |
| **源头治理** | 标本兼治、重在治本，推动社会治理向前端、向基层延伸，从源头解决深层次问题 |

- 成就与挑战：社会治理**社会化、法治化、智能化、专业化**水平大幅提升；同时社会利益关系日趋复杂、互联网深刻改变生产生活方式，要切实把党的领导和我国社会主义制度优势**转化为社会治理优势**。

### 二、完善社会治理体系

- **总要求**：党的十九届四中全会提出，完善**党委领导、政府负责、民主协商、社会协同、公众参与、法治保障、科技支撑**的社会治理体系（七要素）⭐⭐⭐。

**1. 理念是先导：坚持共建共治共享**⭐⭐⭐

| 理念 | 内涵 | 定位 |
| --- | --- | --- |
| **共建** | 共同参与社会建设 | 社会治理的**基础** |
| **共治** | 共同参与社会治理 | 社会治理的**关键** |
| **共享** | 共同享有社会治理成果 | 社会治理的**目标** |

- 坚持问题导向，把专项治理和系统治理、依法治理、综合治理、源头治理结合起来，建设**人人有责、人人尽责、人人享有的社会治理共同体**，确保社会治理过程人民参与、成效人民评判、成果人民共享。

**2. 制度是保障：健全社会治理制度**：①构建源头防控、排查梳理、纠纷化解、应急处置的**社会矛盾综合治理机制**；②坚持生命至上、安全第一，健全公共安全体制机制，编织全方位、立体化**公共安全网**；③完善社会治安综合治理体制机制，加快建设立体化、信息化**社会治安防控体系**；④健全**社会心理服务体系**和疏导机制、危机干预机制，塑造自尊自信、理性平和、亲善友爱的社会心态。

**3. 方式方法是重要内容：不断创新治理方式**：习近平："**社会治理是一门科学**，管得太死，一潭死水不行；管得太松，波涛汹涌也不行。"⭐ ①讲究辩证法，正确处理**维稳与维权、活力与秩序**的关系；②运用**法治思维和法治方式**统筹力量、平衡利益、化解矛盾；③强化**互联网思维**，推进政府决策科学化、社会治理精准化、公共服务高效化；④坚持**系统思维**，综合运用专业化方法，提高预测预警预防各类风险能力。

### 三、加强城乡社区治理

- **总述**："基础不牢，地动山摇。"习近平指出，**基层强则国家强，基层安则天下安**。**基层治理是国家治理的基石**，城乡社区是**社会治理最基本的单元**，是党和政府联系、服务居民群众的"**最后一公里**"；社会治理的重心必须向基层下移⭐⭐。

**1. 健全党组织领导的城乡基层治理体系**：充分发挥**基层党组织领导核心作用**，把党的领导贯穿社会治理全过程各环节；有效发挥**基层政府主导作用**，健全社区管理和服务机制；注重发挥**基层群众性自治组织基础作用**，促进基层群众自治与网格化服务管理有效衔接。发挥自治章程、村规民约、居民公约重要作用，促进**法治、德治、自治**有机融合；统筹发挥社会力量协同作用，形成人人参与、人人尽责的良好局面。

**2. 坚持和发展新时代"枫桥经验""浦江经验"**⭐⭐

- 把**干部主动下沉服务**和激发**群众自治活力**结合起来，探索社会矛盾纠纷多元预防调处化解综合机制，畅通群众诉求表达、利益协调、权益保障通道，及时把矛盾纠纷**化解在基层、化解在萌芽状态**。
- "**浦江经验**"：2003 年，时任浙江省委书记习近平到浦江下访接待群众，变"坐堂等访"为"主动下访"，开创"省级领导下访接访"先河；主要内容是"**变群众上访为领导下访，深入基层，联系群众，真下真访民情，实心实意办事**"。

**3. 加快推进市域社会治理现代化**

- 市域是将风险隐患解决在基层、化解在萌芽状态的**最直接、最有效力**的治理层级，处于推进基层治理现代化的前线位置。
- ①适应共建共治共享新格局要求，完善市域社会治理的**组织架构和组织方式**；②适应社会主要矛盾变化要求，尊重民意、汇聚民智、凝聚民力；③适应把**重大风险防控化解在市域**的要求，增强统筹力、执行力和实效性。

## 05易错点辨析

1. **三个"最"别串位**——"收入分配是民生之源"、"就业是最基本的民生"、习近平称就业是"最大的民生工程、民心工程、根基工程"；三者搭配各不相同，互相张冠李戴即错。
2. **"六个精准"≠"五个一批"**——六个精准全部以"精准"收尾；五个一批全部以"脱贫一批"收尾（发展生产、易地搬迁、生态补偿、发展教育、社会保障兜底），别把"生态补偿"写成"生态扶贫"或混入精准清单。
3. **两不愁三保障不含"饮水安全"**——"三保障"是义务教育、基本医疗、住房安全有保障，答题按原文写全。
4. **三次分配的作用定位不同**——初次分配强调**基础性作用**（提高劳动报酬比重），再分配是**调节作用**（税收、社保、转移支付），第三次分配是**公益慈善**；把税收调节安到第三次分配头上即错。
5. **共建、共治、共享定位顺序固定**——共建是基础、共治是关键、共享是目标，写成"共治是基础""共享是关键"均错。
6. **三个会议三个提法别混**——十八届三中全会"创新社会治理体制"（社会管理→社会治理）；十九大"打造共建共治共享的治理**格局**"；十九届四中全会"坚持和完善共建共治共享的治理**制度**"。
7. **七要素易漏"科技支撑"**——社会治理体系=党委领导、政府负责、民主协商、社会协同、公众参与、法治保障、科技支撑；漏写或把"科技支撑"写成"科技保障"均错。
8. **"基石"的表述对象**——原文是"**基层治理**是国家治理的**基石**"，不是"社会治理的基石"；"社会治理最基本的单元"是**城乡社区**。
9. **尽力而为与量力而行是统一体**——既要兑现承诺、该花的钱要花（反对裹足不前、铢施两较），又不提超越阶段的过高标准（反对好高骛远、寅吃卯粮），只答一面不完整。
10. **社保数据口径不同**——"中国这十年"发布会口径基本养老保险参保 10.3 亿；"截至 2022 年底"为 10.5 亿、基本医疗保险参保率 95% 以上；两组数字出处时间不同，答题按题干给的口径取用。
11. **住房制度关键词**——定位是"房子是用来住的、不是用来炒的"，制度是"多主体供给、多渠道保障、**租购并举**"，不是"以购为主"。
12. **"基层"与"市域"层级关系**——城乡社区是社会治理最基本的单元（末梢），市域则是把风险隐患化解在基层的最直接、最有效力的**治理层级**（前线），两者不是同一层级概念。
