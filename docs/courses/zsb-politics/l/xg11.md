## 03正文精讲

## 第一节 让人民生活幸福是"国之大者"

::: info 本节指引 · 第一节 让人民生活幸福是"国之大者"

- **目标**：增进民生福祉有哪三个定位？脱贫攻坚战的关键表述和十年成就是什么？坚持在发展中增进民生福祉的五条要求怎么配对？
- **建议用时**：15 分钟
- **知识点**：`增进民生福祉的三个定位与“国之大者”` `脱贫攻坚战与人民生活全方位改善` `坚持在发展中增进民生福祉`

:::

::: info 增进民生福祉的三个定位

- **白话**：为什么必须抓好民生：因为党是人民的党、社会主义生产就是为了让人过得好、现代化本来就要造福人民。
- **教材表述**：①坚持立党为公、执政为民的本质要求——中国共产党是人民的党，任何时候都把群众利益放在第一位，始终坚守为中国人民谋幸福、为中华民族谋复兴的初心使命；②社会主义生产的根本目的——“努力办好各项民生事业，让老百姓的日子越过越好，是社会主义生产的根本目的”，关注人本身的发展是社会主义和资本主义的根本区别之一；③全面建设社会主义现代化国家的应有之义——中国式现代化是造福人民的现代化（本课正文第一节一）。
- **情境**：用它回答“为什么说让人民生活幸福是‘国之大者’”：以人民为中心是我们党的根本执政理念，全面建设社会主义现代化国家的出发点和落脚点是让人民生活越过越好，所以要把增进民生福祉作为发展的根本目的；民生事关人民的生存生活生计，事关民心所向、民情所系、民意所指，决定党的事业成败和国家命运兴衰。
- **易混区别**：三个定位与要点必须配对：本质要求对应“群众利益放在第一位”，根本目的对应“社会主义和资本主义的根本区别之一”，应有之义对应“中国式现代化是造福人民的现代化”——互换即错。
- **答题关键词**：立党为公、执政为民的本质要求、社会主义生产的根本目的、应有之义、造福人民的现代化、国之大者

:::

::: info 打赢脱贫攻坚战

- **白话**：全面建成小康社会的底线任务、第一民生工程：用最严格的精准办法把人找出来、把办法配上，最后历史性地解决了绝对贫困问题。
- **教材表述**：打赢脱贫攻坚战、消除绝对贫困，是全面建成小康社会的底线任务，是必须抓紧抓好的第一民生工程；组织实施了人类历史上规模最大、力度最强的脱贫攻坚战；方略是六个精准（扶持对象、项目安排、资金使用、措施到户、因村派人、脱贫成效精准）、五个一批（发展生产、易地搬迁、生态补偿、发展教育、社会保障兜底一批）、两不愁三保障（不愁吃、不愁穿；义务教育、基本医疗、住房安全有保障）；责任机制是省、市、县、乡、村五级书记抓扶贫（本课正文第一节二）。
- **情境**：用它答“人民生活如何全方位改善”的成就部分：全国 832 个贫困县全部摘帽，12.8 万个贫困村全部出列，现行标准下近 1 亿农村贫困人口实现脱贫；脱贫摘帽不是终点，而是新生活、新奋斗的起点，要把巩固拓展脱贫攻坚成果同乡村振兴有效衔接。
- **易混区别**：“六个精准”与“五个一批”不能混：六个精准全部以“精准”收尾，五个一批全部是“脱贫一批”；“三保障”是义务教育、基本医疗、住房安全有保障，不含饮水安全。
- **答题关键词**：底线任务、第一民生工程、六个精准、五个一批、两不愁三保障、五级书记

:::

::: info 坚持在发展中增进民生福祉

- **白话**：先发展再改善、在不断做大蛋糕的过程中改善民生：发展是解决民生问题的“总钥匙”，民生是发展的“指南针”。
- **教材表述**：五条要求：①重要前提——正确把握民生和发展的关系（发展是改善民生的物质基础，离开发展谈改善民生是无源之水、无本之木；民生连着内需、连着发展，抓民生也是抓发展）；②工作思路——坚守底线、突出重点、完善制度、引导预期；③重中之重——解决人民群众最关心最直接最现实的利益问题；④重要方针——尽力而为、量力而行；⑤重要原则——人人尽责、人人享有（本课正文第一节三）。
- **情境**：用它判断具体做法的归属：对困难群众应保尽保属于“坚守底线”；加大对革命老区、民族地区、边疆地区支持属于“突出重点”；民生保障水平与经济社会发展水平相适应属于“引导预期”；不提出超越阶段的过高标准、不好高骛远属于“量力而行”。
- **易混区别**：“尽力而为”与“量力而行”是统一体：既要兑现承诺、该花的钱要花（反对裹足不前、铢施两较），又不提超越阶段的过高标准（反对好高骛远、寅吃卯粮）——只答一面不完整。
- **答题关键词**：总钥匙、指南针、坚守底线、突出重点、完善制度、引导预期、尽力而为、量力而行、人人尽责、人人享有

:::

::: info 人民生活全方位改善的推进线（原因 → 结果）

1. **脱贫攻坚阶段** 以六个精准、五个一批、两不愁三保障为抓手，五级书记抓扶贫 → 832 个贫困县全部摘帽、12.8 万个贫困村全部出列、近 1 亿农村贫困人口脱贫，历史性地解决了绝对贫困问题
2. **民生重点领域** 收入分配更合理有序（推动形成橄榄型分配格局）、就业作为最大的民生工程、教育（世界上规模最大的教育体系）、社会保障（世界上规模最大的社会保障体系）、医疗卫生（世界上规模最大的医疗卫生体系）、疫情防控、住房坚持“房子是用来住的、不是用来炒的” → “七有”得到更好实现

4. **下一阶段** 把巩固拓展脱贫攻坚成果同乡村振兴有效衔接，扎实推进共同富裕 → 脱贫摘帽不是终点，而是新生活、新奋斗的起点

> &lt;p&gt;带领人民创造美好生活，是我们党始终不渝的奋斗目标。党的十八大以来，党中央坚持以人民为中心的发展思想，在发展中保障和改善民生，加强和创新社会治理，人民生活全方位改善。全面建设社会主义现代化国家，**出发点和落脚点是让人民生活越过越好**；以人民为中心是我们党的根本执政理念，**让人民生活幸福是"国之大者"**，要把增进民生福祉作为发展的根本目的⭐⭐。&lt;/p&gt;

### 一、民生是人民幸福之基

**总述**："治国有常，利民为本。"民生是老百姓最关心的问题，涉及**分配、就业、教育、医疗、住房、社会保障**等方面；民生事关人民的生存生活生计，事关民心所向、民情所系、民意所指，**决定党的事业成败和国家命运兴衰**⭐。

**增进民生福祉的三个定位（必背）**⭐⭐⭐

| 定位 | 要点 |
| --- | --- |
| ①坚持**立党为公、执政为民**的本质要求 | 中国共产党是人民的党，任何时候都把**群众利益放在第一位**；始终坚守为中国人民谋幸福、为中华民族谋复兴的初心使命，实现好、维护好、发展好最广大人民根本利益 |
| ②**社会主义生产**的根本目的 | "努力办好各项民生事业，让老百姓的日子越过越好，是社会主义生产的根本目的"；关注人本身的发展，是**社会主义和资本主义的根本区别之一** |
| ③全面建设社会主义现代化国家的**应有之义** | 中国式现代化是**造福人民的现代化**；人民期盼更好的教育、更稳定的工作、更满意的收入、更可靠的社会保障、更高水平的医疗卫生服务、更舒适的居住条件、更优美的环境 |

### 二、人民获得感幸福感安全感更加充实、更有保障、更可持续

**1. 打赢脱贫攻坚战**⭐⭐⭐

- 打赢脱贫攻坚战、消除绝对贫困，是**全面建成小康社会的底线任务**，是必须抓紧抓好的**第一民生工程**。"小康不小康，关键看老乡，关键在贫困的老乡能不能脱贫"；组织实施了**人类历史上规模最大、力度最强**的脱贫攻坚战。
- 注重加强**普惠性、基础性、兜底性**民生建设，着力解决人民群众急难愁盼问题，扎实推进共同富裕。

| 方略 | 内容 |
| --- | --- |
| **六个精准** | 扶持对象、项目安排、资金使用、措施到户、因村派人、脱贫成效精准 |
| **五个一批** | 发展生产、易地搬迁、生态补偿、发展教育、社会保障兜底（脱贫）一批 |
| **两不愁三保障** | 不愁吃、不愁穿；**义务教育、基本医疗、住房安全**有保障 |
| 责任机制 | 省、市、县、乡、村**五级书记**抓扶贫，层层压实责任 |

- 成就：全国 **832** 个贫困县全部摘帽，**12.8 万**个贫困村全部出列，现行标准下**近 1 亿**农村贫困人口实现脱贫，历史性地解决了绝对贫困问题；脱贫摘帽不是终点，而是新生活、新奋斗的起点，把巩固拓展脱贫攻坚成果同**乡村振兴**有效衔接。

### 三、坚持在发展中增进民生福祉⭐⭐⭐

- 发展是解决民生问题的"**总钥匙**"，民生是发展的"**指南针**"。

| 定位 | 内容要点 |

| **重要原则**：人人尽责、人人享有 | 对美好生活的向往只有通过**劳动**才能实现；鼓励辛勤劳动、诚实劳动、创造性劳动，依靠共同奋斗创造美好生活 |

## 第二节 不断提高人民生活品质

::: info 本节指引 · 第二节 不断提高人民生活品质

- **目标**：三次分配各自发挥什么作用？就业优先战略和健康中国建设的核心定位与举措有哪些？社会保障体系为什么被称作安全网、调节器、减震器？
- **建议用时**：14 分钟
- **知识点**：`完善分配制度与三次分配` `实施就业优先战略与推进健康中国建设` `健全社会保障体系`

:::

::: info 三次分配协调配套的制度体系

- **白话**：第一次按劳动和市场分配（做大工资蛋糕），第二次靠税收社保转移支付来调节，第三次靠自愿的公益慈善来补充。
- **教材表述**：收入分配是民生之源，是改善民生、实现发展成果由人民共享最重要最直接的方式；分配制度是促进共同富裕的基础性制度；构建初次分配、再分配、第三次分配协调配套的制度体系：初次分配发挥基础性作用（提高劳动报酬在初次分配中的比重，健全工资合理增长机制，通过土地、资本等要素使用权收益权增加中低收入群体要素收入，不断壮大中等收入群体）；再分配发挥调节作用（加大税收、社保、转移支付等的调节力度，提高精准性）；第三次分配建立健全机制（引导、支持有意愿有能力的企业、社会组织和个人积极参与公益慈善事业）（本课正文第二节一）。
- **情境**：用它判断一项政策属于哪一次分配：提高最低工资标准、健全工资合理增长机制属于初次分配；提高个人所得税的调节力度、完善转移支付属于再分配；企业设立慈善基金、个人参与公益捐赠属于第三次分配。
- **易混区别**：三次分配的作用定位不同：初次分配是“基础性作用”，再分配是“调节作用”，第三次分配是“公益慈善”机制——把税收调节安到第三次分配头上即错。
- **答题关键词**：民生之源、基础性制度、基础性作用、调节作用、公益慈善

::: info “四个治理”

- **白话**：社会治理的四条原则：站位要高（系统）、手段要依法、力量要合力、治理要往前端和源头走。
- **教材表述**：系统治理——把社会治理置于经济社会发展全局、国家治理现代化大局、法治中国建设战略布局中思考谋划推进；依法治理——以法治精神引领、用法治思维谋划、用法治方式破解难题，把社会治理纳入法治轨道；综合治理——坚持党委领导核心作用、政府主导作用，发挥相关部门职能作用、社会各方面协同作用、广大群众主体作用，形成整体合力；源头治理——标本兼治、重在治本，推动社会治理向前端、向基层延伸，从源头解决深层次问题（本课正文第三节一）。
- **情境**：用它解释“为什么社会治理要向前端延伸”：源头治理强调标本兼治、重在治本，把矛盾纠纷化解在基层、化解在萌芽状态，与“枫桥经验”“浦江经验”里干部下沉、群众自治的做法是同一逻辑；同时社会治理社会化、法治化、智能化、专业化水平大幅提升，要把党的领导和我国社会主义制度优势转化为社会治理优势。
- **易混区别**：“四个治理”的原则名称与要点必须配套：系统治理讲全局布局，依法治理讲法治轨道，综合治理讲多元主体合力，源头治理讲标本兼治——写成“综合治理重在治本”即错。
- **答题关键词**：系统治理、依法治理、综合治理、源头治理、标本兼治、重在治本

:::

::: info 共建共治共享的社会治理制度

- **白话**：大家一起建设、一起治理、一起享成果；其中“共治”最关键，因为治理不能只靠政府一头。
- **教材表述**：党的十九届四中全会提出，完善党委领导、政府负责、民主协商、社会协同、公众参与、法治保障、科技支撑的社会治理体系（七要素）；理念是先导：共建＝共同参与社会建设（社会治理的基础），共治＝共同参与社会治理（社会治理的关键），共享＝共同享有社会治理成果（社会治理的目标）；坚持问题导向，把专项治理和系统治理、依法治理、综合治理、源头治理结合起来，建设人人有责、人人尽责、人人享有的社会治理共同体（本课正文第三节二）。
- **情境**：用它区分三个会议的提法：党的十八届三中全会提出创新社会治理体制，从“社会管理”到“社会治理”一字之差意味着社会建设理念、体制和方式的重大变革；党的十九大提出打造共建共治共享的社会治理格局；党的十九届四中全会提出坚持和完善共建共治共享的社会治理制度——格局与制度不能互换。
- **易混区别**：共建、共治、共享的定位顺序固定为“基础—关键—目标”；七要素不能漏“科技支撑”，也不能把“科技支撑”写成“科技保障”。
- **答题关键词**：党委领导、政府负责、民主协商、社会协同、公众参与、法治保障、科技支撑、共建是基础、共治是关键、共享是目标、社会治理共同体

### 一、加强和创新社会治理

**1. 内涵**⭐⭐：加强和创新社会治理，就是要在**党的领导下，以政府为主导，以社会多元主体参与为基础，以维护人民群众根本利益为核心**，通过合作、对话、协商、沟通等方式，依法对社会事务、社会组织和社会生活进行引导和规范，协调社会利益，化解社会矛盾，促进社会公平，推动社会稳定有序发展。

| 党的**十九届四中全会** | 提出坚持和完善**共建共治共享的社会治理制度** |

**3. "四个治理"**⭐⭐⭐

| 原则 | 要点 |
| --- | --- |
| **系统治理** | 把社会治理置于经济社会发展全局、国家治理现代化大局、法治中国建设战略布局中思考谋划推进 |
| **依法治理** | 以法治精神引领、用法治思维谋划、用法治方式破解难题，把社会治理纳入法治轨道 |

| **源头治理** | 标本兼治、重在治本，推动社会治理向前端、向基层延伸，从源头解决深层次问题 |

- 成就与挑战：社会治理**社会化、法治化、智能化、专业化**水平大幅提升；同时社会利益关系日趋复杂、互联网深刻改变生产生活方式，要切实把党的领导和我国社会主义制度优势**转化为社会治理优势**。

### 二、完善社会治理体系

- **总要求**：党的十九届四中全会提出，完善**党委领导、政府负责、民主协商、社会协同、公众参与、法治保障、科技支撑**的社会治理体系（七要素）⭐⭐⭐。

- ①适应共建共治共享新格局要求，完善市域社会治理的**组织架构和组织方式**；②适应社会主要矛盾变化要求，尊重民意、汇聚民智、凝聚民力；③适应把**重大风险防控化解在市域**的要求，增强统筹力、执行力和实效性。

## 05易错点辨析

1. **三个"最"别串位**——"收入分配是民生之源"、"就业是最基本的民生"、习近平称就业是"最大的民生工程、民心工程、根基工程"；三者搭配各不相同，互相张冠李戴即错。
2. **"六个精准"≠"五个一批"**——六个精准全部以"精准"收尾；五个一批全部以"脱贫一批"收尾（发展生产、易地搬迁、生态补偿、发展教育、社会保障兜底），别把"生态补偿"写成"生态扶贫"或混入精准清单。
3. **两不愁三保障不含"饮水安全"**——"三保障"是义务教育、基本医疗、住房安全有保障，答题按原文写全。
4. **三次分配的作用定位不同**——初次分配强调**基础性作用**（提高劳动报酬比重），再分配是**调节作用**（税收、社保、转移支付），第三次分配是**公益慈善**；把税收调节安到第三次分配头上即错。
5. **共建、共治、共享定位顺序固定**——共建是基础、共治是关键、共享是目标，写成"共治是基础""共享是关键"均错。
6. **三个会议三个提法别混**——十八届三中全会"创新社会治理体制"（社会管理→社会治理）；十九大"打造共建共治共享的治理**格局**"；十九届四中全会"坚持和完善共建共治共享的治理**制度**"。
7. **七要素易漏"科技支撑"**——社会治理体系=党委领导、政府负责、民主协商、社会协同、公众参与、法治保障、科技支撑；漏写或把"科技支撑"写成"科技保障"均错。
8. **"基石"的表述对象**——原文是"**基层治理**是国家治理的**基石**"，不是"社会治理的基石"；"社会治理最基本的单元"是**城乡社区**。
9. **尽力而为与量力而行是统一体**——既要兑现承诺、该花的钱要花（反对裹足不前、铢施两较），又不提超越阶段的过高标准（反对好高骛远、寅吃卯粮），只答一面不完整。
10. **社保数据口径不同**——"中国这十年"发布会口径基本养老保险参保 10.3 亿；"截至 2022 年底"为 10.5 亿、基本医疗保险参保率 95% 以上；两组数字出处时间不同，答题按题干给的口径取用。
11. **住房制度关键词**——定位是"房子是用来住的、不是用来炒的"，制度是"多主体供给、多渠道保障、**租购并举**"，不是"以购为主"。
12. **"基层"与"市域"层级关系**——城乡社区是社会治理最基本的单元（末梢），市域则是把风险隐患化解在基层的最直接、最有效力的**治理层级**（前线），两者不是同一层级概念。

- C. 经济运行减震器
- D. 治国安邦大问题

::: details 点开核对答案

**答案：B**

**逐选项解析**

- A ❌ 同一句的另一个定位：民生保障安全网讲的是保障基本生活、兜住底线，不是“调节器”所指的内容。
- B ✅ 课件原话：社会保障“发挥着民生保障安全网、收入分配调节器、经济运行减震器的作用”；其中“调节器”对应的是收入分配调节。（依据本课正文第二节三）
- C ❌ 同一句的另一个定位：经济运行减震器讲的是在经济波动中的缓冲作用，不是“调节器”。
- D ❌ 不同层级：治国安邦的大问题是关于社会保障总体重要性的判断句，不是“调节器”的具体内容。

**对比自测**：做完后对照 mcq:1，比较两题的判断依据

**原文定位**（课件正文·第二节 三、健全社会保障体系）：社会保障是保障和改善民生、维护社会公平、增进人民福祉的基本制度保障，发挥着民生保障安全网、收入分配调节器、经济运行减震器的作用，是治国安邦的大问题。

:::

## 主观题支架

### qa:1

**要点**

- ①坚持立党为公、执政为民的本质要求：中国共产党是人民的党，任何时候都把群众利益放在第一位，始终坚守为中国人民谋幸福、为中华民族谋复兴的初心使命，实现好、维护好、发展好最广大人民根本利益。
- ②社会主义生产的根本目的：“努力办好各项民生事业，让老百姓的日子越过越好，是社会主义生产的根本目的”；关注人本身的发展，是社会主义和资本主义的根本区别之一。
- ③全面建设社会主义现代化国家的应有之义：中国式现代化是造福人民的现代化；人民期盼更好的教育、更稳定的工作、更满意的收入、更可靠的社会保障、更高水平的医疗卫生服务、更舒适的居住条件、更优美的环境。
- 总述（可选）：民生是人民幸福之基，事关人民的生存生活生计，事关民心所向、民情所系、民意所指，决定党的事业成败和国家命运兴衰；让人民生活幸福是“国之大者”，要把增进民生福祉作为发展的根本目的。

**推导**：先总述民生与“国之大者”的关系，再按三个定位逐条作答，每条写“定位名称＋支撑要点”。三个定位的配对话（本质要求→群众利益第一位；根本目的→社会主义与资本主义的根本区别之一；应有之义→造福人民的现代化）是踩分点，不能只写名称。

**自评标准**

- [ ] 三个定位名称完整（立党为公执政为民的本质要求／社会主义生产的根本目的／全面建设社会主义现代化国家的应有之义）；
- [ ] 至少两个定位能补出支撑要点（群众利益第一位、社会主义和资本主义的根本区别之一、造福人民的现代化）；
- [ ] 开头或结尾能写出“让人民生活幸福是‘国之大者’”“增进民生福祉是发展的根本目的”等判断句。

### qa:2

**要点**

- 总述：发展是解决民生问题的“总钥匙”，民生是发展的“指南针”，要坚持在发展中增进民生福祉，五条要求一环扣一环。
- 重要前提——正确把握民生和发展的关系：发展是改善民生的物质基础，离开发展谈改善民生是无源之水、无本之木；民生连着内需、连着发展，抓民生也是抓发展，要使民生改善和经济发展有效对接、相得益彰。
- 工作思路——坚守底线、突出重点、完善制度、引导预期：坚守底线是织牢民生安全网“网底”、对困难群众应保尽保；突出重点是加大对革命老区、民族地区、边疆地区、相对贫困地区基本公共服务支持；完善制度要求公平、普惠、可持续；引导预期要求民生保障水平与经济社会发展水平相适应。
- 重中之重——解决人民群众最关心最直接最现实的利益问题：把人民群众安危冷暖放在心上，雪中送炭、纾难解困，把完善制度机制同解决群众急难愁盼问题相结合，实现工作常态化、长效化。
- 重要方针——尽力而为、量力而行：承诺了就要兑现，不能裹足不前、铢施两较、该花的钱也不花；又不提出超越阶段的过高标准，不能好高骛远、寅吃卯粮。
- 重要原则——人人尽责、人人享有：对美好生活的向往只有通过劳动才能实现，鼓励辛勤劳动、诚实劳动、创造性劳动，依靠共同奋斗创造美好生活。

**推导**：按五条要求逐条作答，每条先写定位（重要前提／工作思路／重中之重／重要方针／重要原则），再写内容要点。定位词与内容必须一一配对，尤其“工作思路”四个短语的顺序不要打乱；“尽力而为、量力而行”要答出正反两面（该花的钱要花＋不提超越阶段的标准）。

**自评标准**

- [ ] 五个定位词齐全（重要前提、工作思路、重中之重、重要方针、重要原则）且顺序不错；
- [ ] 工作思路四条短句能完整写出（坚守底线、突出重点、完善制度、引导预期）；
- [ ] “尽力而为、量力而行”答出正反两面，并提到“人人尽责、人人享有”与劳动创造的关系。

### qa:3

**要点**

- 总述：收入分配是民生之源，分配制度是促进共同富裕的基础性制度；要构建初次分配、再分配、第三次分配协调配套的制度体系，既把“蛋糕”做大做好，又把“蛋糕”切好分好。
- 初次分配发挥基础性作用：提高劳动报酬在初次分配中的比重，健全工资合理增长机制；通过土地、资本等要素使用权、收益权增加中低收入群体要素收入；不断壮大中等收入群体。
- 再分配发挥调节作用：加大税收、社保、转移支付等的调节力度，提高精准性。
- 第三次分配建立健全机制：引导、支持有意愿有能力的企业、社会组织和个人积极参与公益慈善事业。
- 成效数据（可选）：居民人均可支配收入从 2012 年 1.65 万元增加到 2021 年 3.51 万元，中等收入群体超 4 亿人，形成世界上规模最大的中等收入群体。

**推导**：先写总述（民生之源＋基础性制度＋协调配套），再按三次分配逐条写“作用定位＋具体举措”。作用定位最容易出错：初次＝基础性作用，再分配＝调节作用，第三次＝公益慈善机制；举措要与层次对应（税收、社保、转移支付只能写在再分配里）。

**自评标准**

- [ ] 三次分配的顺序、作用定位与举措一一对应（初次基础性作用、再分配调节作用、第三次分配公益慈善机制）；
- [ ] 初次分配写出“提高劳动报酬比重”“壮大中等收入群体”；再分配写出“税收、社保、转移支付”；
- [ ] 开头写出“收入分配是民生之源”“分配制度是促进共同富裕的基础性制度”。

### qa:4

**要点**

- 总述：加强和创新社会治理，要在党的领导下，以政府为主导，以社会多元主体参与为基础，以维护人民群众根本利益为核心；“四个治理”是新时代加强和创新社会治理的基本原则。
- 系统治理：把社会治理置于经济社会发展全局、国家治理现代化大局、法治中国建设战略布局中思考谋划推进。
- 依法治理：以法治精神引领、用法治思维谋划、用法治方式破解难题，把社会治理纳入法治轨道。
- 综合治理：坚持党委领导核心作用、政府主导作用，发挥相关部门职能作用、社会各方面协同作用、广大群众主体作用，形成整体合力。
- 源头治理：标本兼治、重在治本，推动社会治理向前端、向基层延伸，从源头解决深层次问题。
- 实践要求（可选）：社会治理社会化、法治化、智能化、专业化水平大幅提升，要把党的领导和我国社会主义制度优势转化为社会治理优势。

**推导**：先写社会治理的内涵（党的领导下、政府主导、多元主体参与、维护群众根本利益），再按“四个治理”逐条作答：每条写“原则名称＋核心要点”，系统治理讲全局、依法治理讲法治轨道、综合治理讲合力、源头治理讲治本。最后可加一句“把制度优势转化为社会治理优势”。

**自评标准**

- [ ] “四个治理”名称齐全、顺序正确（系统、依法、综合、源头）；
- [ ] 每条能补出核心要点（全局布局／法治轨道／多元合力／标本兼治）；
- [ ] 开头写出社会治理的内涵，包含“党的领导”“政府主导”“多元主体参与”“群众根本利益”等关键词。

### qa:5

**要点**

- 三个定位（理论依据）：坚持立党为公、执政为民的本质要求；社会主义生产的根本目的（关注人本身的发展是社会主义和资本主义的根本区别之一）；全面建设社会主义现代化国家的应有之义（中国式现代化是造福人民的现代化）。
- 逻辑支点：以人民为中心是我们党的根本执政理念，全面建设社会主义现代化国家的出发点和落脚点是让人民生活越过越好，所以要让人民生活幸福是“国之大者”，把增进民生福祉作为发展的根本目的。
- 实践成就一（脱贫攻坚）：打赢脱贫攻坚战、消除绝对贫困是全面建成小康社会的底线任务、第一民生工程；用六个精准、五个一批、两不愁三保障和五级书记抓扶贫，全国 832 个贫困县全部摘帽、12.8 万个贫困村全部出列、近 1 亿农村贫困人口脱贫，历史性地解决了绝对贫困问题。
- 实践成就二（七大领域）：收入分配更合理有序，就业作为最大的民生工程，教育、社会保障、医疗卫生建成世界上规模最大的三大体系，疫情防控坚持人民至上、生命至上，住房坚持“房子是用来住的、不是用来炒的”定位、多主体供给、多渠道保障、租购并举——“七有”得到更好实现。
- 实践成就三（数据）：城镇新增就业年均超 1300 万人，约 1.8 亿农村人口进城成为城镇常住人口，居民人均可支配收入超 3.5 万元、中等收入群体超 4 亿人，人均预期寿命 78.2 岁，基本养老、失业、工伤、基本医疗保险参保人数分别达 10.3 亿、2.3 亿、2.8 亿、13.6 亿。
- 要求（可选）：坚持在发展中增进民生福祉——重要前提、工作思路、重中之重、重要方针、重要原则，把巩固拓展脱贫攻坚成果同乡村振兴有效衔接。

**推导**：两问两答。第一问用三个定位＋一句逻辑（以人民为中心、出发点和落脚点）作答；第二问按“脱贫攻坚—七大领域—数据”三层展开，每层至少给两个具体举措或数字。整题要体现“理论定位在前、实践证据在后”的结构，数字不必全背，但 832／12.8 万／近 1 亿、三大体系、78.2 岁要能说出来。

**自评标准**

- [ ] 三个定位齐全，并写出“以人民为中心”“出发点和落脚点是让人民生活越过越好”等逻辑句；
- [ ] 脱贫攻坚部分能写出六个精准、五个一批、两不愁三保障中的两组以上，并给出 832／12.8 万／近 1 亿等关键数字；
- [ ] 七大领域至少写出四项举措（就业、教育、社保、医疗、住房等），并能点出“七有”。

### qa:6

**要点**

- 总要求：党的十九届四中全会提出，完善党委领导、政府负责、民主协商、社会协同、公众参与、法治保障、科技支撑的社会治理体系（七要素）。
- 理念是先导：坚持共建共治共享——共建是社会治理的基础、共治是社会治理的关键、共享是社会治理的目标；建设人人有责、人人尽责、人人享有的社会治理共同体，确保社会治理过程人民参与、成效人民评判、成果人民共享。
- 制度是保障：构建源头防控、排查梳理、纠纷化解、应急处置的社会矛盾综合治理机制；健全公共安全体制机制、编织全方位立体化公共安全网；完善社会治安综合治理体制机制、加快建设立体化信息化社会治安防控体系；健全社会心理服务体系和疏导机制、危机干预机制。
- 方式方法是重要内容：讲究辩证法，正确处理维稳与维权、活力与秩序的关系；运用法治思维和法治方式统筹力量、平衡利益、化解矛盾；强化互联网思维，推进政府决策科学化、社会治理精准化、公共服务高效化；坚持系统思维，提高预测预警预防各类风险能力。
- 城乡社区治理三路径之一：健全党组织领导的城乡基层治理体系——基层治理是国家治理的基石，城乡社区是社会治理最基本的单元、是党和政府联系服务居民群众的“最后一公里”，社会治理重心必须向基层下移。
- 城乡社区治理三路径之二、之三：坚持和发展新时代“枫桥经验”“浦江经验”，把干部主动下沉服务和激发群众自治活力结合起来，及时把矛盾纠纷化解在基层、化解在萌芽状态；加快推进市域社会治理现代化，市域是把风险隐患解决在基层最直接、最有效力的治理层级。

**推导**：按“总要求（七要素）→ 理念先导（共建共治共享及其定位、社会治理共同体）→ 制度保障（四类机制）→ 方式方法（辩证法、法治、互联网、系统思维）→ 城乡社区治理（基层体系、枫桥浦江经验、市域现代化）”五段作答。七要素和三个定位（基础／关键／目标）是硬得分点；社区治理部分要突出“基层治理是国家治理的基石、城乡社区是社会治理最基本的单元、市域是最直接最有效力的治理层级”这组层级判断。

**自评标准**

- [ ] 七要素完整写出（党委领导、政府负责、民主协商、社会协同、公众参与、法治保障、科技支撑），不漏“科技支撑”；
- [ ] 写出共建（基础）、共治（关键）、共享（目标）的定位并提到“社会治理共同体”；
- [ ] 城乡社区治理写出三条路径中的至少两条（基层治理体系／枫桥浦江经验／市域社会治理现代化）。
