## 03正文精讲

## 第一节 以新发展理念引领高质量发展

### 一、我国进入新发展阶段

**1. 从新常态到高质量发展阶段**⭐⭐

- 针对国际金融危机后世界经济低迷、我国经济下行压力加大，党提出我国经济发展正处在**增长速度换挡期、结构调整阵痛期、前期刺激政策消化期**的"**三期叠加**"阶段，进入了**新常态**。
- 习近平：新常态**没有改变**我国发展仍处于可以大有作为的**重要战略机遇期**的判断，改变的是重要战略机遇期的**内涵和条件**；**没有改变**经济发展**总体向好的基本面**，改变的是**经济发展方式和经济结构**。

**2. 新常态带来的六大变化**

| 维度 | 变化方向 |
| --- | --- |
| 增长速度 | 高速 → **中高速** |
| 发展方式 | 规模速度型 → **质量效率型** |
| 经济结构调整 | 增量扩能为主 → 调整存量、做优增量并举 |
| 发展动力 | 主要依靠资源和低成本劳动力等要素投入 → **创新驱动** |
| 演进趋势 | 向形态更高级、分工更优化、结构更合理的阶段演进 |
| 总体判断 | 我国经济已**由高速增长阶段转向高质量发展阶段** |

**3. 新发展阶段的内涵**⭐⭐

- 全面建成小康社会、实现第一个百年奋斗目标之后，乘势而上开启全面建设社会主义现代化国家新征程、向第二个百年奋斗目标进军，标志着我国进入**新发展阶段**。
- 三重定位：是我国**社会主义初级阶段历史进程中的一个重要阶段**；是迎来从**站起来、富起来到强起来**历史性跨越的新阶段；是全面建设社会主义现代化国家、向第二个百年奋斗目标进军的重要阶段。
- 机遇判断："机遇和挑战都有新的发展变化，机遇和挑战之大都前所未有，**总体上机遇大于挑战**"。
- 主线：以**深化供给侧结构性改革**为主线，加快经济结构优化升级、提升科技创新能力、深化改革开放、加快绿色发展、参与全球经济治理体系变革。

### 二、贯彻新发展理念是关系我国发展全局的一场深刻变革

**1. 发展理念的地位**⭐

- 贯彻新发展理念是新时代我国发展壮大的**必由之路**；发展理念是发展行动的**先导**，是**管全局、管根本、管方向、管长远**的东西，是发展思路、发展方式、发展着力点的集中体现，**从根本上决定着发展成效乃至成败**。
- 党的十八大以来提出的重大理论和战略中，**新发展理念是最重要、最主要的**。

**2. 五大理念的科学内涵（必背表）**⭐⭐⭐

| 理念 | 地位定位 | 解决的问题 |
| --- | --- | --- |
| 创新 | 引领发展的**第一动力** | 发展**动力**问题 |
| 协调 | 持续健康发展的**内在要求** | 发展**不平衡**问题 |
| 绿色 | 永续发展的**必要条件**、人民对美好生活追求的重要体现 | **人与自然和谐共生**问题 |
| 开放 | 国家繁荣发展的**必由之路** | 发展**内外联动**问题 |
| 共享 | 中国特色社会主义的**本质要求** | **社会公平正义**问题（全民共享、全面共享、共建共享、渐进共享） |

- 新发展理念是一个**系统的理论体系**，回答了关于发展的**目的、动力、方式、路径**等一系列理论和实践问题，阐明了我们党关于发展的**政治立场、价值导向、发展模式、发展道路**等重大政治问题，开拓了**中国特色社会主义政治经济学新境界**。

**3. 把握新发展理念的三个维度**⭐⭐

- 新发展理念是**指挥棒、红绿灯**，必须完整、准确、全面地理解和把握：①从**根本宗旨**上把握——坚持以人民为中心的发展思想，让现代化建设成果更多更公平惠及全体人民；②从**问题导向**上把握——切实解决发展不平衡不充分问题；③从**忧患意识**上把握——下好先手棋、打好主动仗，敢于斗争、善于斗争，牢牢守住**安全发展**的底线。

### 三、以新发展理念引领高质量发展

**1. 高质量发展的内涵**⭐⭐⭐

- 定义：能够很好满足人民日益增长的**美好生活需要**的发展，是**体现新发展理念**的发展，是**创新成为第一动力、协调成为内生特点、绿色成为普遍形态、开放成为必由之路、共享成为根本目的**的发展。
- 五个角度看高质量发展：

| 角度 | 要求 |
| --- | --- |
| 供给 | 产业体系比较完整，生产组织方式网络化、智能化，创新力、需求捕捉力、品牌影响力、核心竞争力强，产品和服务质量高 |
| 需求 | 不断满足人民群众个性化、多样化、不断升级的需求，引领供给体系和结构变化，不断催生新的需求 |
| 投入产出 | 提高劳动、资本、土地、资源、环境效率，提升科技进步贡献率，不断提高**全要素生产率** |
| 分配 | 实现投资有回报、企业有利润、员工有收入、政府有税收 |
| 宏观经济循环 | 生产、分配、流通、消费**循环通畅**，国民经济重大比例关系和空间布局比较合理，不出现大的起落 |

- 一句话：高质量发展，就是从"**有没有**"转向"**好不好**"。

**2. 三大战略意义**⭐⭐
①高质量发展为全面建设社会主义现代化国家提供更为**坚实的物质基础**；②是不断满足人民对美好生活需要的**重要保证**（增进人民福祉、促进共同富裕取得更为扎实的进展）；③是维护国家**长治久安**的必然要求（确保关键领域安全可控、有效防范化解重大风险）。

**3. 怎样推动高质量发展**⭐
①更好统筹**质的有效提升和量的合理增长**，坚持**质量第一、效益优先**，以效率变革、动力变革促进**质量变革**，增强经济竞争力、创新力、抗风险能力；②坚持**稳中求进**工作总基调，实行"宏观政策要稳、产业政策要准、微观政策要活、改革政策要实、社会政策要托底"的政策框架，以深化供给侧结构性改革为主线，把**实施扩大内需战略**同深化供给侧结构性改革**有机结合起来**，加快构建新发展格局。

**4. 理论概括与实践成效**

- **习近平经济思想**：2017 年 12 月召开的**中央经济工作会议**对其**首次作出概括**，以新发展理念为主要内容，共 7 条"坚持"：党对经济工作的集中统一领导 / 以人民为中心的发展思想 / 适应把握引领经济发展新常态 / 市场在资源配置中起决定性作用、更好发挥政府作用 / 适应我国经济发展主要矛盾变化完善宏观调控 / 问题导向部署经济发展新战略 / 正确工作策略和方法。
- **历史性成就**：国内生产总值突破**百万亿元**大关，人均国内生产总值超过 1 万美元，对世界经济增长的贡献率稳居首位；世界第二大经济体、第二大消费市场、制造业第一大国、货物贸易第一大国、外汇储备第一大国的地位进一步巩固；进入**创新型国家行列**。

## 第二节 坚持和完善社会主义基本经济制度

### 一、坚持和完善社会主义基本经济制度是实现高质量发展的保障

- 社会主义基本经济制度是中国特色社会主义制度的**重要支柱**，是新时代推动实现高质量发展的**制度基础**。
- 它是我国**生产关系在制度上的体现**，在经济制度体系中具有**基础性决定性地位**；规定了我国经济关系的基本原则，明确人们在**生产、分配、交换、消费**中的地位及相互关系，是解放和发展社会生产力、改善人民生活、维护社会公平正义、推进**共同富裕**的制度基础⭐。

**新概括及其内在关系**⭐⭐⭐

| 方面 | 内容 | 关系 |
| --- | --- | --- |
| 所有制结构 | **公有制为主体、多种所有制经济共同发展** | 是基本经济制度的**基础**，决定分配方式和资源配置方式 |
| 分配制度 | **按劳分配为主体、多种分配方式并存** | 合理有效的分配方式有利于进一步完善所有制结构 |
| 资源配置体制机制 | **社会主义市场经济体制** | 合理有效的资源配置方式有利于进一步完善所有制结构 |

- 三者相互联系、相互支持、相互促进，是**内在统一整体**；是经济制度体系中具有**长期性和稳定性**的部分，起着规范方向的作用，对经济制度属性和经济发展方式有决定性影响，是新时代推动经济高质量发展的**制度支撑**。
- 将按劳分配为主体、多种分配方式并存和社会主义市场经济体制**上升为基本经济制度**，是着眼于新的实践和发展需要作出的概括，具有科学的理论基础、广泛的实践基础和深厚的群众基础。

### 二、坚持"两个毫不动摇"

**1. 总要求**⭐⭐⭐：毫不动摇**巩固和发展**公有制经济，毫不动摇**鼓励、支持、引导**非公有制经济发展。公有制经济和非公有制经济都是**社会主义市场经济的重要组成部分**，都是我国经济社会发展的重要基础。

**2. 公有制经济**

- 构成：**国有经济和集体经济**，还包括**混合所有制经济中的国有成分和集体成分**。
- 公有制**主体地位**不能动摇，国有经济**主导作用**不能动摇——这是我国各族人民共享发展成果的**制度性保证**，也是巩固党的执政地位、坚持我国社会主义制度的重要保证。
- 要求：探索公有制多种实现形式，发挥国有经济**战略支撑作用**，推进国有经济布局优化和结构调整，增强国有经济**竞争力、创新力、控制力、影响力、抗风险能力**。
- 国有企业是中国特色社会主义的**重要物质基础和政治基础**，是我们党**执政兴国的重要支柱和依靠力量**；坚持党对国有企业的领导不动摇，把加强党的领导和完善公司治理统一起来，建设**中国特色现代国有企业制度**。

**3. 非公有制经济**

- 构成：**个体经济、私营经济、港澳台投资经济、外商投资经济**以及混合所有制经济中的非国有成分和非集体成分。
- "六个重要"定位：稳定经济的重要基础、国家税收的重要来源、就业创业的重要领域、技术创新的重要主体、金融发展的重要依托、经济持续健康发展的重要力量。
- 习近平"**三个没有变**"⭐：非公有制经济在我国经济社会发展中的**地位和作用**没有变，毫不动摇鼓励、支持、引导非公有制经济发展的**方针政策**没有变，致力于为非公有制经济发展营造良好环境和提供更多机会的**方针政策**没有变。
- **民营经济**是非公有制经济的**主要经济组织形式**，是推进中国式现代化的**生力军**、高质量发展的重要基础；迈上新征程，民营经济**只能壮大，不能弱化**。要营造市场化、法治化、国际化一流营商环境，全面构建**亲清政商关系**，促进民营经济做大做优做强。

**4. 两者关系**

- 公有制经济与非公有制经济功能优势不同、作用不可替代，是**相辅相成、相得益彰**的；任何想把公有制经济或者非公有制经济**否定掉**的观点，都是不符合最广大人民根本利益的，都是**错误的**。
- 要适应我国现阶段生产力发展的多层次性和不平衡性，坚持**两点论和重点论的统一**，推进国有资本、集体资本、非公有资本等交叉持股、相互融合的**混合所有制经济**发展，把公有制经济发展和非公有制经济发展**统一于社会主义基本经济制度之中**。

### 三、坚持按劳分配为主体、多种分配方式并存

- 决定因素⭐⭐：基本分配制度是由我国**社会主义性质和基本国情**决定的；在社会主义初级阶段，**公有制为主体的所有制决定了按劳分配为主体的分配**（"参与生产的一定方式决定着参与分配的形式"）。
- 分配**决定于生产，又反作用于生产**；**劳动是财富创造的活的源泉**，劳动者是生产力发展最活跃的因素，要坚持多劳多得、鼓励勤劳致富；**资本、土地、知识、技术、管理、数据**等生产要素也发挥重要作用，允许和鼓励其**参与分配**。
- 政策要求：推动**居民收入增长和经济增长同步、劳动报酬提高和劳动生产率提高同步**两个"同步"；增加劳动者特别是一线劳动者劳动报酬，提高劳动报酬在**初次分配**中的比重；健全生产要素由**市场评价贡献、按贡献决定报酬**的机制，让一切创造社会财富的源泉充分涌流。

### 四、构建高水平社会主义市场经济体制

**1. 关键是处理好政府和市场的关系**⭐⭐⭐

- 党的二十大作出构建**高水平社会主义市场经济体制**的战略部署；关键在于：**使市场在资源配置中起决定性作用，更好发挥政府作用**——这是我们党在理论和实践上的重大推进，是对中国特色社会主义建设规律认识的一个新突破。
- 市场起决定性作用 = 把市场机制能有效调节的经济活动交给市场，推动资源配置实现**效益最大化和效率最优化**；更好发挥政府作用 = 在保证市场发挥决定性作用的前提下，**管好那些市场管不了或管不好的事情**。
- 二者是**有机统一**的，不是相互否定的，不能割裂开来、对立起来；要用好"**看不见的手**"和"**看得见的手**"，推动**有效市场和有为政府**更好结合。

**2. 三项部署**

- **加快建设高标准市场体系**：当今世界**最稀缺的资源是市场**，市场资源是我国的巨大优势；要建设**统一开放、竞争有序、制度完备、治理完善**的高标准市场体系，为构建新发展格局提供有力支撑。
- **推进宏观经济治理体系和治理能力现代化**：宏观调控的主要任务是**保持经济总量平衡，促进重大经济结构协调和生产力布局优化，减缓经济周期波动影响，防范区域性、系统性风险，稳定市场预期**，实现经济持续健康发展；健全以国家发展规划为战略导向、以财政政策和货币政策为主要手段，就业、产业、投资、消费、环保、区域等政策紧密配合的宏观经济治理体系。
- **依法规范和引导资本健康发展**：资本是带动各类生产要素集聚配置的重要**纽带**，同时具有**逐利本性**；要正确认识资本的特性和行为规律，为资本设立"**红绿灯**"，健全事前引导、事中防范、事后监管相衔接的**全链条资本治理体系**，使资本始终服从和服务于人民和国家利益。

## 第三节 加快构建新发展格局

### 一、把握未来发展主动权的战略部署

- 定位⭐⭐：构建以**国内大循环为主体、国内国际双循环相互促进**的新发展格局，是根据我国发展阶段、发展环境、条件变化，特别是基于我国**比较优势变化**审时度势作出的重大决策，是推动高质量发展的**战略基点**，是关系我国发展全局的重大战略任务。
- 背景：改革开放以来特别是加入世界贸易组织后，我国深度参与国际分工，形成市场和资源"**两头在外**"的发展格局；**2008 年国际金融危机**是我国发展格局演变的一个重要**分水岭**，面对危机冲击我国把扩大内需作为重要措施，推动经济发展向内需主导转变；近年逆全球化趋势加剧、有的国家大搞单边主义保护主义，"两头在外"的国际大循环**动能明显减弱**，而**国内大循环活力日益强劲**——必须进一步把发展立足点放在国内。

**三个"不是"（辨析必背）**⭐⭐⭐

| 构建新发展格局是…… | 不是…… |
| --- | --- |
| 把握未来发展主动权的**先手棋** | 被迫之举和权宜之计 |
| **开放的国内国际双循环** | 封闭的国内单循环 |
| 以**全国统一大市场**基础上的国内大循环为主体 | 各地都搞自我小循环 |

- 依据与要求：大国经济的特征都是**内需为主导、内部可循环**（我国是世界第二大经济体和制造业第一大国，立足国内有利于化解外部冲击、在极端情况下保证经济基本正常运行和社会大局总体稳定）；我国经济已深度融入世界经济，内外需市场相互依存、相互促进；以国内大循环为主体是针对**全国**而言的，各地区要找准自己在国内大循环和国内国际双循环中的**位置和比较优势**。

### 二、以国内大循环为主体、国内国际双循环相互促进

1. 必须具备**强大的国内经济循环体系和稳固的基本盘**，加强国内大循环在双循环中的**主导作用**，国内经济运行越稳定、循环越顺畅，越能形成对全球资源要素的**引力场**；确保增长、就业、物价不出现大的波动，金融不出现区域性系统性风险；
2. 必须发挥**比较优势**，以国内大循环**吸引全球资源要素**，充分利用国内国际**两个市场、两种资源**，促进内需和外需、进口和出口、引进外资和对外投资协调发展，实施更大范围、更宽领域、更深层次的对外开放；
3. 必须**保证经济循环的畅通无阻**，实现**生产、分配、流通、消费**各环节有机衔接——循环受阻在宏观上表现为增长速度下降、失业增加、风险积累、国际收支失衡，在微观上表现为产能过剩、企业效益下降、居民收入下降；要建设现代流通体系，增强供给体系韧性。

### 三、大力推动构建新发展格局

四个"着力"⭐⭐：

1. 着力推动实施**扩大内需战略同深化供给侧结构性改革有机结合**——供给和需求是市场经济内在关系的两个基本方面，相互依存、互为条件；坚持深化供给侧结构性改革这条主线，以满足国内需求为基本立足点，形成"**需求牵引供给、供给创造需求**"的更高水平供需良性循环和动态平衡；
2. 着力发展**实体经济**——实体经济是一国经济的**立身之本、财富之源**，是构筑未来发展战略优势的重要支撑；坚持金融为实体经济服务，**防止脱实向虚**，完善中国特色现代企业制度，加快建设世界一流企业；
3. 着力加快**科技自立自强**——⭐⭐⭐构建新发展格局**最本质的特征是实现高水平的自立自强**；发挥社会主义市场经济条件下**新型举国体制**优势，打好关键核心技术攻坚战，加快攻克重要领域"**卡脖子**"技术，加强基础研究、注重原始创新；
4. 着力推动**产业链供应链优化升级**——建立稳定的产业链供应链是稳固国内大循环主体地位的迫切需要；把增强产业链韧性和竞争力放在更加重要的位置，推动短板产业**补链**、优势产业**延链**、传统产业**升链**、新兴产业**建链**，引导产业链关键环节留在国内，实现自主可控、安全高效。

## 第四节 建设现代化经济体系

**总定位**⭐⭐：建设现代化经济体系是我国发展的**战略目标**，是推动高质量发展、全面提高经济整体竞争力的**必然要求**。内容：建设创新引领、协同发展的**产业体系**，统一开放、竞争有序的**市场体系**，体现效率、促进公平的**收入分配体系**，彰显优势、协调联动的**城乡区域发展体系**，资源节约、环境友好的**绿色发展体系**，多元平衡、安全高效的**全面开放体系**，以及充分发挥市场作用、更好发挥政府作用的**经济体制**。

## 04考点闪卡 · 先回忆再翻面

## 05易错点辨析

1. **"首要任务"与"基础和关键"不是同一句话**——高质量发展是全面建设社会主义现代化国家的**首要任务**；而"发展是解决我国一切问题的基础和关键"说的是**发展**本身的地位，两个定位不能互换。
2. **新常态"没有改变 / 改变"的对象**——没有改变重要战略机遇期的**判断**和总体向好的**基本面**，改变的是机遇期的**内涵和条件**、经济发展**方式和经济结构**。
3. **新发展阶段 ≠ 超越初级阶段**——它是我国**社会主义初级阶段历史进程中的一个重要阶段**，不是对初级阶段的否定或终结。
4. **五大理念与"解决的问题"一一对应**——创新→动力、协调→不平衡、绿色→人与自然和谐共生、开放→内外联动、共享→社会公平正义，选择题最爱交叉设错。
5. **高质量发展"五个成为"的配语与五大理念"地位"配语不同**——"第一动力 / 内生特点 / 普遍形态 / 必由之路 / 根本目的"是高质量发展语境下的表述；"第一动力 / 内在要求 / 必要条件 / 必由之路 / 本质要求"是五大理念各自的地位定位，答题勿串。
6. **基本经济制度新概括是"三方面"而非只有所有制**——把"按劳分配为主体、多种分配方式并存"和"社会主义市场经济体制"**上升为**基本经济制度是新概括的亮点；其中**所有制结构是基础**，决定分配方式和资源配置方式。
7. **"两个毫不动摇"动词方向不能换**——对公有制是"**巩固和发展**"，对非公有制是"**鼓励、支持、引导**"。
8. **市场起"决定性作用" ≠ 市场决定一切**——政府要在保证市场决定性作用的前提下管好市场**管不了或管不好**的事情；"两只手"**有机统一**，不能割裂开来、对立起来。
9. **新发展格局三个"不是"**——不是被迫之举和权宜之计（是先手棋）；不是封闭的国内单循环（是开放的双循环）；不是各地自我小循环（以**全国统一大市场**为基础，且"以国内大循环为主体"是针对**全国**而言）。
10. **最本质特征答"扩大内需"就错了**——构建新发展格局最本质的特征是实现**高水平的自立自强**；扩大内需只是四个"着力"之一。
11. **乡村振兴"总"字辈不能错位**——总目标 = 农业农村现代化（不是"乡村振兴"本身）；总方针 = 农业农村优先发展；总要求 = 二十字方针；制度保障 = 城乡融合发展体制机制和政策体系。
12. **区域协调 ≠ 同一水平**——不能简单要求各地区在经济发展上达到同一水平，要走**合理分工、优化发展**的路子。
