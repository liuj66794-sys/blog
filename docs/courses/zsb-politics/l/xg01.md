## 03正文精讲

## 第一节 中国特色社会主义是历史和人民的选择

::: info 本节指引 · 第一节 中国特色社会主义是历史和人民的选择

- **目标**：为什么说中国特色社会主义是历史和人民的选择？它是怎样接续发展起来的？为什么说它是社会主义而不是其他什么主义？四个自信的内容与底气在哪里？
- **建议用时**：15 分钟
- **知识点**：`中国特色社会主义是历史和人民的选择` `中国特色社会主义是社会主义而不是其他什么主义` `四个自信`

:::

::: info 中国特色社会主义

- **白话**：一条既有"社会主义底色"又带"中国特色"的路：底色是不丢科学社会主义基本原则，特色是这条路是在中国大地上走出来的，不是照抄别人，也不是另起炉灶。
- **教材表述**：中国特色社会主义是科学社会主义理论逻辑和中国社会发展历史逻辑的辩证统一，既坚持了科学社会主义基本原则，又根据时代条件赋予其鲜明的中国特色（课1 p11）；道路问题是关系党的事业兴衰成败第一位的问题，中国特色社会主义是中国共产党领导中国人民长期探索、始终坚持、接续发展的结果（课1 p5）。
- **情境**：用它分析"为什么照搬别国经验不行"：当代中国的伟大社会变革，不是简单延续我国历史文化的母版，不是简单套用马克思主义经典作家设想的模板，不是其他国家社会主义实践的再版，也不是国外现代化发展的翻版——只有把科学社会主义基本原则同我国具体实际、历史文化传统、时代要求紧密结合起来，才能更好地坚持和发展中国特色社会主义（课1 p13）。
- **易混区别**："中国特色社会主义是社会主义而不是其他什么主义"的关键在"坚持科学社会主义基本原则"：党的领导、人民代表大会制度这一根本政治制度，多党合作和政治协商、民族区域自治、基层群众自治等基本政治制度，公有制为主体多种所有制经济共同发展等基本经济制度——"如果丢掉了这些，那就不成其为社会主义了"；同时不能把"中国特色"理解成可以脱离基本原则任意发挥。
- **答题关键词**：科学社会主义理论逻辑和中国社会发展历史逻辑的辩证统一、第一位的问题、三个"只有"、科学社会主义基本原则、四个"版"（母版/模板/再版/翻版）

:::

::: info 接续发展历程：五段接力（时期 → 代表人物 → 标志性贡献）

1. **1921 年以后（革命时期）** 以毛泽东同志为主要代表的中国共产党人把马克思列宁主义基本原理同中国具体实际相结合，提出经过新民主主义革命走向社会主义的正确理论，完成新民主主义革命、建立中华人民共和国、确立社会主义基本制度 → 使中国走上社会主义康庄大道
2. **改革开放新时期·邓小平同志为主要代表** 作出把党和国家工作中心转移到经济建设上来、实行改革开放的历史性决策，提出走自己的路、建设中国特色社会主义 → 成功开创了中国特色社会主义
3. **改革开放新时期·江泽民同志为主要代表** 加深了对"什么是社会主义、怎样建设社会主义"和"建设什么样的党、怎样建设党"的认识 → 成功把中国特色社会主义推向 21 世纪
4. **改革开放新时期·胡锦涛同志为主要代表** 深刻认识和回答了新形势下"实现什么样的发展、怎样发展"等重大问题 → 成功在新形势下坚持和发展了中国特色社会主义
5. **中国特色社会主义新时代·习近平同志为主要代表** 科学回答新时代坚持和发展中国特色社会主义的一系列重大理论和实践问题，明确基本方略，作出战略安排，统揽"四个伟大" → 开创新时代，取得历史性成就、发生历史性变革

:::

::: info "六个得来"：六个时间尺度（背下来就是一条答案链）

1. **改革开放 40 多年** 在改革开放的伟大实践中得来
2. **新中国成立 70 多年** 在新中国的持续探索中得来
3. **伟大社会革命 100 多年** 在中国共产党领导人民进行伟大社会革命的实践中得来
4. **由衰到盛 180 多年** 在近代以来中华民族由衰到盛的历史进程中得来
5. **世界社会主义 500 多年** 在世界社会主义波澜壮阔的发展历程中得来
6. **中华文明 5000 多年** 在对中华文明的传承发展中得来——这是历史的结论、人民的选择

:::

::: info 四个自信

- **白话**：对脚下的路（道路）、手里的方案（理论）、办事的规矩（制度）、精神上的底气（文化）都有信心；其中文化自信最基础、最深厚，是"根"上的自信。
- **教材表述**：改革开放以来取得一切成绩和进步的根本原因：开辟了中国特色社会主义道路（实现途径）、形成了中国特色社会主义理论体系（行动指南）、确立了中国特色社会主义制度（根本保障）、发展了中国特色社会主义文化（精神力量），四者统一于中国特色社会主义伟大实践（课1 p14）；四个自信来源于实践、来源于人民、来源于真理；"说到底是要坚定文化自信，文化自信是更基础、更广泛、更深厚的自信"（课1 p16-17）。
- **情境**：用它解释"底气从哪里来"：党的坚强领导（最本质特征、最大优势）、新中国成立以来特别是党的十八大以来形成的更为完善的制度保证、更为坚实的物质基础、更为主动的精神力量、5000 多年连绵不绝的文明、960 多万平方公里土地和 14 亿多人民聚合的磅礴之力（课1 p16）。
- **易混区别**：四者定位不能互换：道路＝实现途径、理论体系＝行动指南、制度＝根本保障、文化＝精神力量；"说到底是文化自信"不等于只讲文化自信，道路、理论、制度自信同时缺一不可。另外"四梁八柱"在制度自信语境下指根本制度、基本制度、重要制度。
- **答题关键词**：根本原因、实现途径/行动指南/根本保障/精神力量、来源于实践、来源于人民、来源于真理、更基础、更广泛、更深厚、文化根脉

:::

::: tip 四个自信：像一支队伍出征要有的四样东西

| 本概念 | 类比为 |
| --- | --- |
| 道路自信 | 认准要走的那条路：知道往哪走、怎么走（实现途径） |
| 理论自信 | 手里的地图与作战方案：靠它判断方向（行动指南） |
| 制度自信 | 队伍的章程和纪律：保证不出乱子、能持续运转（根本保障） |
| 文化自信 | 士气和共同记忆：这支队伍为什么值得拼（精神力量，最深沉持久） |

**局限**：类比只帮你记住四者"途径—指南—保障—力量"的分工；考试必须写出四个定位词，并说明四者统一于中国特色社会主义伟大实践。

:::

### 一、道路问题是第一位的问题

- ⭐ 道路问题是关系党的事业兴衰成败**第一位的问题**。中国特色社会主义是中国共产党领导中国人民长期探索、始终坚持、接续发展的结果，是根植于中国大地、反映中国人民意愿、适应中国和时代发展进步要求的**科学社会主义**。
- ⭐⭐ 三个"只有"：**只有社会主义才能救中国，只有社会主义才能发展中国，只有坚持和发展中国特色社会主义才能实现中华民族伟大复兴**。

### 二、历史渊源：两大历史任务与道路求索

- 1840 年鸦片战争以后，中国逐步成为半殖民地半封建社会，**争取民族独立、人民解放**和**实现国家富强、人民幸福**成为中国人民的历史任务；无数仁人志士前仆后继、苦苦求索，但都没能找到解决中国问题的正确道路。
- **十月革命一声炮响**，使中国先进分子看到了一条崭新的道路；在历史的大潮中，中国人民和中华民族实现了伟大觉醒，**中国共产党应运而生**，担负起民族复兴的历史大任。
- 以毛泽东同志为主要代表的中国共产党人把马克思列宁主义基本原理同中国具体实际相结合，提出**经过新民主主义革命走向社会主义**的正确理论；完成新民主主义革命，建立中华人民共和国，确立社会主义基本制度，对适合中国国情的社会主义道路进行初步探索，使中国走上了社会主义这条康庄大道。

| 改革开放新时期 | 以江泽民同志为主要代表 | 加深了对"什么是社会主义、怎样建设社会主义"和"建设什么样的党、怎样建设党"的认识，成功把中国特色社会主义**推向 21 世纪** |

- 新时期成就：实现了从生产力相对落后到**经济总量跃居世界第二**的历史性突破，实现了人民生活从温饱不足到总体小康、奔向全面小康的历史性跨越，中国大踏步赶上了时代。

### 四、两个历史时期不能相互否定⭐⭐

- 我们党领导人民进行社会主义建设，有**改革开放前和改革开放后两个历史时期**，二者**相互联系又有重大区别**，但**本质上都是我们党领导人民进行社会主义建设的实践探索**。
- 不能用改革开放后的历史时期否定改革开放前的历史时期，也不能用改革开放前的历史时期否定改革开放后的历史时期；前者为后者**积累了条件**，后者是对前一个时期的**坚持、改革、发展**。

### 五、"六个得来"⭐⭐⭐

- 科学社会主义扎根中国决不是偶然的：因为它**回答了近代以来中华民族面临的历史性课题、指明了实现伟大复兴的正确道路**，并且同我国传承几千年的优秀历史文化和广大人民日用而不觉的价值观念具有**高度的契合性**。
- 中国特色社会主义不是从天上掉下来的，而是在：**改革开放 40 多年**的伟大实践中、**新中国成立 70 多年**的持续探索中、**中国共产党领导人民进行伟大社会革命 100 多年**的实践中、**近代以来中华民族由衰到盛 180 多年**的历史进程中、**世界社会主义 500 多年**波澜壮阔的发展历程中、**对中华文明 5000 多年**的传承发展中得来的——这是历史的结论、人民的选择。

### 六、中国特色社会主义是社会主义而不是其他什么主义

- ⭐⭐ 定位：中国特色社会主义是**科学社会主义理论逻辑和中国社会发展历史逻辑的辩证统一**，既坚持了科学社会主义基本原则，又根据时代条件赋予其鲜明的中国特色。
- 科学社会主义基本原则：在**《共产党宣言》**中第一次得到全面阐述，在《资本论》及其手稿等著作中充分展开和深入论证，在《哥达纲领批判》《反杜林论》等著作中进一步总结和阐发；诞生 170 多年来，**资本主义的基本矛盾没有变、工人阶级的历史使命没有变、科学社会主义的真理性没有变**，"《共产党宣言》……阐述的基本原理没有过时，也不会过时"。
- 坚持基本原则的体现⭐：中国共产党领导下立足基本国情，以经济建设为中心，坚持四项基本原则，坚持改革开放；坚持人民代表大会制度这一**根本政治制度**，多党合作和政治协商、民族区域自治、基层群众自治等**基本政治制度**；坚持公有制为主体多种所有制经济共同发展、按劳分配为主体多种分配方式并存、社会主义市场经济体制等**基本经济制度**——"**如果丢掉了这些，那就不成其为社会主义了**"。
- ⭐⭐ "新版本"论（背诵）：当代中国的伟大社会变革，**不是简单延续我国历史文化的母版，不是简单套用马克思主义经典作家设想的模板，不是其他国家社会主义实践的再版，也不是国外现代化发展的翻版**；社会主义并没有定于一尊、一成不变的套路，只有把科学社会主义基本原则同我国具体实际、历史文化传统、时代要求紧密结合起来，才能更好地坚持和发展中国特色社会主义。

### 七、坚定道路自信、理论自信、制度自信、文化自信

**1. 根本原因与四者定位**⭐⭐⭐

- 改革开放以来我们取得一切成绩和进步的**根本原因**：①开辟了中国特色社会主义**道路**；②形成了中国特色社会主义**理论体系**；③确立了中国特色社会主义**制度**；④发展了中国特色社会主义**文化**。

| 内容 | 定位 |
| --- | --- |
| 中国特色社会主义道路 | **实现途径** |
| 中国特色社会主义理论体系 | **行动指南** |
| 中国特色社会主义制度 | **根本保障** |
| 中国特色社会主义文化 | **精神力量** |

- 四者**统一于中国特色社会主义伟大实践**。

**2. 四个自信的含义**⭐

::: info 中国特色社会主义新时代

::: info 新时代社会主要矛盾

- **白话**：以前是"东西不够"（落后的社会生产），现在是"发展还不平衡不充分"：不再主要缺"有没有"，而是要求"好不好"。
- **教材表述**：新时代我国社会主要矛盾是人民日益增长的美好生活需要和不平衡不充分的发展之间的矛盾（课2 p8）；转化依据：需要侧从"有没有"转向"好不好"，在民主、法治、公平、正义、安全、环境等方面要求日益增长；生产侧社会生产力水平总体上显著提高，"落后的社会生产"已不符合实际；发展不平衡不充分成为满足人民美好生活需要的主要制约因素（课2 p8-9）。
- **情境**：用它解释"为什么还要坚持基本路线"：主要矛盾变化是关系全局的历史性变化，但两个"没有变"——我国仍处于并将长期处于社会主义初级阶段的基本国情没有变，我国是世界最大发展中国家的国际地位没有变，因此必须毫不动摇贯彻党在社会主义初级阶段的基本路线，既不能落后于时代，也不能脱离实际、超越阶段（课2 p10）。
- **易混区别**：新旧表述不能混搭：旧＝"物质文化需要同落后的社会生产之间的矛盾"；新＝"美好生活需要和不平衡不充分的发展之间的矛盾"，写成"美好生活需要同落后的社会生产"即为错项；"不平衡不充分"是主要制约因素，不是"不发达"。
- **答题关键词**：美好生活需要、不平衡不充分的发展、有没有→好不好、主要制约因素、两个没有变、社会主义初级阶段

:::

## 05易错点辨析

1. **中国特色社会主义 ≠ 其他什么主义**——判断标准在于是否坚持科学社会主义基本原则并根据时代条件赋予中国特色；"如果丢掉了这些，那就不成其为社会主义了"。
2. **"说到底是文化自信"≠ 只讲文化自信**——文化自信是更基础、更广泛、更深厚，最基本、最深沉、最持久的力量，但道路、理论、制度自信同样缺一不可，四者统一于伟大实践。
3. **两个历史时期不能相互否定**——改革开放前后两个时期"相互联系又有重大区别"，本质上都是党领导人民进行社会主义建设的实践探索。
4. **主要矛盾变化 ≠ 改变初级阶段判断**——矛盾转化是"关系全局的历史性变化"，但初级阶段的基本国情、世界最大发展中国家的国际地位两个"没有变"。
5. **新旧主要矛盾表述不能混搭**——旧论断是"人民日益增长的物质文化需要同落后的社会生产之间的矛盾"；新时代是"人民日益增长的美好生活需要和**不平衡不充分的发展**之间的矛盾"，不能写成"美好生活需要同落后的社会生产之间的矛盾"。
6. **三个"意味着" vs 三个"反映"**——"意味着"讲**意义**（飞跃/旗帜/贡献），"反映"讲**判断依据**（矛盾/任务/中国与世界关系），审题先分清问的是哪个。
7. **"四个全面"的当前表述**——决胜全面建成小康社会后，战略目标是"**全面建设**社会主义现代化国家"（居于引领地位）；三大战略举措是全面深化改革、全面依法治国、全面从严治党，不要仍把"全面建成小康社会"当战略目标。
8. **布局与动词的固定搭配**——"五位一体"是**总体布局**（统筹推进），"四个全面"是**战略布局**（协调推进），搭配不能颠倒。
9. **"十四个坚持"是基本方略，不是基本路线**——基本路线是"以经济建设为中心，坚持四项基本原则，坚持改革开放"的完整表述（国家的生命线、人民的幸福线）；基本方略是十九大概括的"十四个坚持"。
10. **"归根到底"必须答完整**——"归根到底是马克思主义行，是**中国化时代化的马克思主义行**"，只答前半句不得分。
11. **里程碑意义的"五史"**——党史、新中国史、改革开放史、社会主义发展史、**中华民族发展史**，五史一个不能漏。

- 协调推进"四个全面"战略布局：全面建设社会主义现代化国家是战略目标、居于引领地位，全面深化改革、全面依法治国、全面从严治党是三大战略举措；决胜全面建成小康社会后，战略目标已更新为全面建设社会主义现代化国家。
- 接续奋斗：社会主义是不断发展和完善的实践过程，需要一代又一代人接续奋斗——"坚持和发展中国特色社会主义是一篇大文章"，我们这一代共产党人的任务就是继续把这篇大文章写下去；既要看到规律把握达到新高度，也要看到我国社会主义还处在初级阶段。
- 顽强斗争：对五个"凡是危害"（党的领导与我国社会主义制度／主权安全发展利益／核心利益和重大原则／人民根本利益／第二个百年奋斗目标与民族复兴）的风险挑战必须坚决斗争，发扬斗争精神、增强斗争本领。
- 实干兴邦：牢记空谈误国、实干兴邦，埋头苦干、踔厉奋发；历史只会眷顾坚定者、奋进者、搏击者，不会等待犹豫者、懈怠者、畏难者。

**推导**：先写总论句（成果＋继续＋必须一以贯之），中段按"三个基本（理论·路线·方略）＋两个布局（统筹推进五位一体、协调推进四个全面）"展开，最后落到接续奋斗、顽强斗争、实干兴邦三条要求。两个提示：一是基本路线要原文默写；二是布局与动词的固定搭配不能颠倒（总体布局＝统筹推进，战略布局＝协调推进）。

**自评标准**

- [ ] 总论句写出"伟大社会革命的成果"与"伟大社会革命的继续"两句；
- [ ] 三个基本与两个布局齐全，基本路线原文无误，布局与动词搭配正确；
- [ ] 三条要求（接续奋斗、顽强斗争、实干兴邦）齐全，能各补一个固定表述（大文章／五个凡是危害／空谈误国、实干兴邦）。
