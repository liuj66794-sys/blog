## 03正文精讲

## 第一节 江山就是人民，人民就是江山

章首总论⭐⭐：人民性是马克思主义的**本质属性和鲜明品格**。坚持以人民为中心，是新时代坚持和发展中国特色社会主义的**根本立场**，是贯穿党治国理政全部活动的**一条红线**。必须坚持人民至上，**站稳人民立场、把握人民愿望、尊重人民创造、集中人民智慧**，不断实现人民对美好生活的向往，推动人的全面发展、全体人民共同富裕取得更为明显的实质性进展。

习近平指出："江山就是人民，人民就是江山。中国共产党领导人民打江山、守江山，**守的是人民的心**。"要坚持以人民为中心的执政理念，始终保持同人民群众的血肉联系，始终接受人民批评和监督，始终同人民同呼吸、共命运、心连心。

### 一、人民是历史的创造者，是真正的英雄（社会历史观）

**1. 人民是创造历史的真正动力**⭐⭐

- 如何认识人民群众在历史上的作用，是**社会历史观的重大问题**。历史唯物主义群众史观认为，人民是历史的创造者，在创造历史中起**决定性作用**，**第一次彻底解决**了这个重大问题。
- 马克思、恩格斯指出："整个所谓世界历史不外是人通过人的劳动而诞生的过程""历史活动是群众的活动"。

| 三个体现 | 具体内容 |
| --- | --- |
| 社会物质财富的创造者 | 既创造吃穿住行等**生活资料**，也创造生产和再生产活动的**生产资料** |
| 社会精神财富的创造者 | 一切精神财富的**最终源泉**植根于人民群众的实践活动；离开人民的实践，任何精神创造都是无源之水、无本之木 |
| 社会变革的决定力量 | 历史上一切生产关系的深刻变革、社会制度的兴亡更替，都是人民群众推动的，**最终决定于人民群众的力量** |

**2. 尊重人民历史地位，充分发挥人民主体作用——党的百年奋斗历史经验的重要结论**

| 时期 | 人民的作用 |
| --- | --- |
| 红军时期 | 人民群众是党和人民军队的**铜墙铁壁** |
| 抗日战争时期 | 广泛发动群众，使日本侵略者陷入**人民战争的汪洋大海** |
| 解放战争 | 淮海战役胜利是老百姓用**小车**推出来的，渡江战役胜利是老百姓用**小船**划出来的 |
| 社会主义革命和建设 | 成就是人民群众**干**出来的 |
| 改革开放 | 历史伟剧是亿万人民群众**主演**的 |
| 新时代 | 伟大变革离不开人民群众的**不懈奋斗** |

- 习近平：从建党的开天辟地，到新中国成立的改天换地，到改革开放的翻天覆地，再到党的十八大以来党和国家事业取得历史性成就、发生历史性变革，**根本原因就在于我们党始终坚守了为中国人民谋幸福、为中华民族谋复兴的初心和使命**。
- 结论：始终同人民在一起，为人民利益而奋斗，紧紧依靠人民创造历史伟业，是党立于不败之地、从胜利走向胜利的**根本原因**。

### 二、打江山、守江山，守的是人民的心（党性宗旨）

- **民心是最大的政治**，决定事业兴衰成败。中国共产党是人民的党，**为人民而生，因人民而兴**，既为人民夺取政权打江山，又为人民巩固政权守江山。

**1. 人民在一个国家的地位是由这个国家的政权性质决定的**⭐

- 在存在阶级压迫和剥削的社会中，政权维护少数统治阶级利益；社会主义国家由无产阶级建立和领导，**第一次真正实现了人民当家作主**。恩格斯：工人阶级一旦取得统治权，必须"以新的真正民主的国家政权来代替"。
- 国家机关必须由**社会主人变为社会公仆**，接受人民监督。
- 我国是**工人阶级领导的、以工农联盟为基础的人民民主专政**的社会主义国家，**国家一切权力属于人民**；各级国家机关和重要机构都冠以"人民"的称号，反映了我国政权的基本定位。

**2. 江山就是人民，人民就是江山，是由我们党的性质、宗旨决定的**⭐⭐

- 《共产党宣言》："无产阶级的运动是绝大多数人的、为绝大多数人谋利益的独立的运动。"
- **不谋私利才能谋根本、谋大利**：党除了国家、民族、人民的利益，**没有自己特殊的利益**，从来不代表任何利益集团、任何权势团体、任何特权阶层的利益。
- 党必须始终坚持**全心全意为人民服务**的宗旨——"我们讲宗旨，说到底还是为人民服务这句话"。人民是党执政的**最大底气**，也是党执政**最深厚的根基**。
- 党的执政地位**不是一劳永逸、一成不变的**，现在拥有不等于永远拥有；要做到长期执政，就必须牢记党的**根基在人民、血脉在人民、力量在人民**，始终同人民群众想在一起、干在一起，风雨同舟、同甘共苦。

### 三、人民立场是中国共产党的根本政治立场⭐⭐

- 政治立场是一个政党观察、认识、处理政治问题的立足点。**人民立场是中国共产党的根本政治立场，是我们党区别于其他政党的显著标志**。坚持这一根本立场，就要坚持以人民为中心的执政理念，将其贯穿于党和国家事业发展各方面。

| 三条要求 | 要点 |
| --- | --- |
| 1. 始终牢记党的初心和使命 | 为中国人民谋幸福、为中华民族谋复兴，是激励一代代共产党人前仆后继、英勇奋斗的根本动力；忘记初心使命，党就会改变性质、改变颜色，就会失去人民、失去未来 |
| 2. 始终保持党同人民群众的血肉联系 | 党的**最大政治优势**是密切联系群众，党执政后的**最大危险**是脱离群众；立党为公、执政为民是衡量党的先进性的**根本标尺** |
| 3. 热爱人民、尊重人民、敬畏人民 | "人民"二字在共产党人心中**位置最高、分量最重**；老百姓是我们的衣食父母，要像爱自己的父母那样爱老百姓，诚心诚意做人民的小学生 |

- 守初心三个方法：以**坚定的理想信念**坚守初心、以**真挚的人民情怀**滋养初心、以**牢固的公仆意识**践行初心。

## 第二节 坚持人民至上

总起⭐⭐：坚持人民至上，是我们党**百年奋斗的宝贵历史经验**，也是新时代党治国理政的**根本价值取向**。要把人民对美好生活的向往作为党的奋斗目标，把人民作为党的工作的最高裁决者和最终评判者，充分调动和激发全体人民的**积极性、主动性、创造性**，紧紧依靠人民创造新的历史伟业。

### 一、人民对美好生活的向往就是党的奋斗目标⭐⭐

- "民之所忧，我必念之；民之所盼，我必行之。"为人民谋幸福是党始终坚守的初心，让人民过上好日子是党一贯的追求。

| 奋斗阶段 | 为了让人民过上好日子 |
| --- | --- |
| 革命时期 | 实现民族独立、人民解放，建立了新中国 |
| 建设时期 | 建立社会主义制度、改变一穷二白的国家面貌 |
| 改革开放 | 解放和发展社会生产力，解决温饱、实现总体小康、全面建设小康社会 |
| 新时代 | 决胜全面建成小康社会、打赢脱贫攻坚战，迈上全面建设社会主义现代化国家新征程 |

- ⭐ 体现了**我国社会主要矛盾转化**对党和国家工作的新要求：进入新时代，人民的美好生活需要呈现**多样化、多层次、多方面**的特点：
  - 更加关心食品安全、暖气、环境、精神文化生活、就业机会、收入等具体问题；
  - 对**幼有所育、学有所教、劳有所得、病有所医、老有所养、住有所居、弱有所扶**有了更高期盼；
  - 对**民主、法治、公平、正义、安全、环境**等提出了更高要求。
- 必须牢牢把握社会主要矛盾的新变化，顺应人民对高品质生活的新期待，**在高质量发展中**努力为人民创造更美好、更幸福的生活。

### 二、依靠人民创造历史伟业

- 人民是我们党的**生命之根、执政之基、力量之源**。

**1. 必须尊重人民主体地位**⭐

- "坚持人民主体地位，充分调动人民积极性，始终是我们党**立于不败之地的强大根基**。"
- 改革开放在认识和实践上的每一次突破和发展、每一个新生事物的产生和发展、每一个方面经验的创造和积累，**无不来自亿万人民的实践和智慧**；必须自觉**拜人民为师**，亲身征询于田野，虚心问计于百姓，凝聚民心民智民力。

**2. 必须尊重人民首创精神**⭐

1. 尊重实践、尊重创造，坚持**顶层设计和基层探索相统一**，大胆探索、勇于开拓，鼓励创新、宽容失败；
2. 激发人民群众的**创新创造活力**，营造激励干事创业的浓厚氛围，健全创新激励机制，打破阻碍创新的壁垒，焕发蕴藏于人民群众中的无穷创造力；
3. 及时发现、总结、概括人民群众实践中形成的**新鲜经验**，使之**上升为理论和政策**，更好指导中国特色社会主义实践。

### 三、人民是党的工作的最高裁决者和最终评判者⭐⭐

- "时代是出卷人，我们是答卷人，**人民是阅卷人**。"党的执政水平和执政成效不是由自己说了算，必须而且只能由人民来评判。

**1. 让群众满意是党做好一切工作的价值取向和根本标准**

- 检验一切工作的成效，最终都要看：人民**是否真正得到了实惠**、人民生活**是否真正得到了改善**、人民权益**是否真正得到了保障**。
- 人民群众的意见是**最好的尺子**，生活过得好不好人民最有发言权；群众赞成什么、期盼什么，就坚持和推动什么；群众反对什么、痛恨什么，就防范和纠正什么；对群众呼声要**件件有着落、事事有回音**。

**2. 必须牢固树立和践行正确的政绩观**⭐

- 回答"政绩为谁而树、树什么样的政绩、靠什么树政绩"：把**为民办事、为民造福**作为最重要的政绩，把为老百姓办了多少好事实事作为检验政绩的重要标准。
- 评价干部不能只看纸面指标：**不能简单以国内生产总值增长率论英雄**，不搞脱离实际的盲目攀比，不搞劳民伤财的**形象工程和政绩工程**。
- 以**"功成不必在我"**的精神境界和**"功成必定有我"**的历史担当，多做为后人作铺垫、打基础、利长远的好事，追求人民群众的好口碑、历史沉淀之后的真评价。

## 第三节 全面落实以人民为中心的发展思想

总起：坚持以人民为中心的发展思想是**具体的、现实的**，而不是抽象的、空泛的，必须体现在经济社会发展各个环节，体现在更好满足人民美好生活需要的实践当中。

### 一、坚持和贯彻党的群众路线⭐⭐

- "群众路线是我们党的**生命线和根本工作路线**，是我们党永葆青春活力和战斗力的重要**传家宝**。"坚持**一切为了群众、一切依靠群众，从群众中来到群众中去**，把党的正确主张变为群众的自觉行动。

| 要点 | 内容 |
| --- | --- |
| 1. 根本工作方法 | 领导工作的正确方法：把群众意见集中起来形成正确决策 → 到群众中宣传解释、化为群众行动 → 在群众实践中检验决策是否正确；"**知**"是基础、是前提，"**行**"是重点、是关键，必须知行合一；把党的优良传统和新技术新手段结合起来，**走好网上群众路线** |
| 2. 调查研究 | "开展调查研究就是走群众路线，**没有调查就没有发言权，就没有决策权**"；要扑下身子、沉到一线、深入基层，坚持问题导向，到困难较多、情况复杂、矛盾尖锐的地方把脉问诊，把群众面临的问题发现出来、意见反映上来、经验总结出来 |

- 案例：打赢脱贫攻坚战中，习近平先后 **7 次**主持召开中央扶贫工作座谈会，**50 多次**调研扶贫工作，走遍 **14 个集中连片特困地区**，提出**精准扶贫、精准脱贫**的基本方略，为全党大兴调查研究、走好新时代群众路线作出表率。

### 二、把为人民造福的事情真正办好办实

**1. 落实到新时代中国特色社会主义的各项事业、全部工作之中**⭐

| 领域 | 为民造福的要求 |
| --- | --- |
| 经济高质量发展 | 破解发展不平衡、不协调、不可持续问题，满足个性化、多样化、不断升级的需求 |
| 全面深化改革 | 确保改革发展成果更多更公平惠及全体人民 |
| 民主政治建设 | 发展**全过程人民民主**，各环节各方面体现人民意愿、听到人民声音 |
| 全面依法治国 | 让人民群众在每一个司法案件中感受到**公平正义** |
| 文化建设 | 满足人民日益增长的精神文化需求，使人民精神生活更加充盈 |
| 民生建设 | 时刻把人民安危冷暖放在心上，关心困难群众疾苦、帮助排忧解难 |
| 社会治理 | 人人有责、人人尽责、人人享有，建设人民更满意的**平安中国** |
| 生态文明建设 | 解决群众身边突出生态环境问题，天更蓝、山更绿、水更清 |
| 维护国家安全 | 坚持以**人民安全**为宗旨 |
| 外交工作 | 坚持**外交为民**的理念 |

**2. 着力解决好人民群众最关心最直接最现实的利益问题**

- 用心用情用力解决群众关心的**就业、教育、社保、医疗、住房、养老、食品安全、社会治安**等实际问题；想群众之所想、急群众之所急、解群众之所难，把群众的小事当作大事来办。
- **从最困难的群体入手**：多做雪中送炭的事情，健全困难群众帮扶工作机制，让人民感受到社会主义大家庭的温暖；
- **从最突出的问题着眼**：聚焦看病难、上学难、就业难、住房难等操心事、烦心事、揪心事和民生历史遗留问题，出实招、办实事、求实效。

**3. 一件事情接着一件事情办，一年接着一年干**

- 为民造福的事情面广量大，具有**稳定性、连续性、累积性**等特点，要发扬**钉钉子精神**，一锤一锤接着敲，合力攻坚、久久为功、一抓到底。
- **制度建设是持续为群众办实事的有力保障**：健全为人民执政靠人民执政各项制度、社会公平正义法治保障制度、人民文化权益保障制度、统筹城乡的民生保障制度、共建共治共享的社会治理制度、最严格的生态环境保护制度等，把以人民为中心的发展思想通过制度落到实处。

### 三、推动全体人民共同富裕取得更为明显的实质性进展⭐⭐⭐

- 共同富裕是**中国特色社会主义的本质要求**，是**中国式现代化的重要特征**。

**1. 实现共同富裕不仅是经济问题，而且是关系党的执政基础的重大政治问题**⭐⭐

- 我们追求的发展是造福人民的发展，追求的富裕是全体人民共同富裕，**决不能允许贫富差距越来越大**。
- 路径：首先通过全国人民共同奋斗把"蛋糕"**做大做好**，然后通过合理的制度安排正确处理**增长和分配**关系，把"蛋糕"**切好分好**。
- 习近平："我们不能等实现了现代化再来解决共同富裕问题"，而要始终把满足人民对美好生活的新期待作为发展的出发点和落脚点，在实现现代化过程中不断地、逐步地解决好。

**2. 要从全局角度来把握共同富裕**⭐⭐

- 是**全体人民**共同富裕，是人民群众**物质生活和精神生活都富裕**；**不是**少数人的富裕，**不是**整齐划一的平均主义，**不是**所有人同时富裕，**也不是**所有地区同时达到一个富裕水准。
- 处理好**先富和共富**的关系：允许一部分人先富起来，同时积极推动**先富带后富**。
- 实现共同富裕是一个**长期的历史过程**，不可能一蹴而就，必须保持历史耐心、不懈努力，积小胜为大胜。

**3. 扎实推进共同富裕必须坚持正确的原则和科学的思路**⭐⭐

- 四条原则：**鼓励勤劳创新致富、坚持基本经济制度、尽力而为量力而行、坚持循序渐进**。
- 总思路：坚持以人民为中心的发展思想，**在高质量发展中促进共同富裕**，正确处理效率和公平的关系，构建**初次分配、再分配、三次分配**协调配套的基础性制度安排，加大**税收、社保、转移支付**等调节力度并提高精准性——**扩大中等收入群体比重、增加低收入群体收入、合理调节高收入、取缔非法收入**，形成**中间大、两头小的橄榄型分配结构**，促进社会公平正义、促进人的全面发展。

**4. 推动共同富裕与促进人的全面发展高度统一**⭐

- 《共产党宣言》确立了马克思主义政党的最高目标是实现**共产主义**，并把实现**人的自由而全面发展**作为共产主义的本质特征。
- "现代化的最终目标是实现人自由而全面的发展。"推动共同富裕的过程，必须是人民物质生活不断提升、精神世界不断丰富的过程；要更加主动解决地区差距、城乡差距、收入差距等问题，提高人民思想道德素质、科学文化素质、身心健康素质，促进**物的全面丰富和人的全面发展**达到新的更高境界。

## 05易错点辨析

1. **"守江山"守的不是疆土政权本身，而是"人民的心"**——民心是最大的政治；党的执政地位不是一劳永逸、一成不变的，现在拥有不等于永远拥有。
2. **最大政治优势 ≠ 最大危险**——党的最大政治优势是**密切联系群众**，党执政后的最大危险是**脱离群众**，两者不能互换。
3. **人民立场**是党的**根本政治立场**，同时是党**区别于其他政党的显著标志**；"坚持以人民为中心"是**根本立场**（贯穿治国理政全部活动的红线），不是一般性工作方法。
4. **三个"创造者"对应不能混**：物质财富（生活资料+生产资料）、精神财富（最终源泉在人民实践）、社会变革（决定力量）；"决定力量"指向人民群众整体，不能换成个别人物。
5. **人民在一个国家的地位由政权性质决定**——不是由经济发展水平或人口数量决定。
6. **国家机关的角色转换方向**：必须由"社会主人"变为"**社会公仆**"，别记反。
7. **贯彻群众路线中"知""行"的地位**："知"是基础、是前提，"行"是重点、是关键——顺序不能颠倒。
8. **共同富裕 ≠ 同步富裕、平均主义**——不是所有人同时富裕、不是所有地区同时达到一个富裕水准、不是整齐划一的平均主义；允许一部分人先富起来，但要积极推动**先富带后富**。
9. **共同富裕 ≠ 纯经济问题**——它同时是**关系党的执政基础的重大政治问题**。
10. **不以 GDP 增长率论英雄 ≠ 不要发展**——是不搞脱离实际的盲目攀比、不搞形象工程政绩工程，仍要在**高质量发展中**促进共同富裕。
11. **"阅卷人"是人民**——"时代是出卷人，我们是答卷人，人民是阅卷人"：党是答卷人，评判权在人民，"党的执政水平和执政成效不是由自己说了算"。
12. **以人民为中心的发展思想是具体的、现实的**——不是空洞口号，不能停留在口头、止步于思想环节，必须转化为发展实践并通过**制度**落到实处。
