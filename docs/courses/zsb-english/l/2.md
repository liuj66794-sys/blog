语法专题 · 第二课

对应教材上册 P15–P18 · 冠词是戴在名词头上的"帽子"，专升本考 a/an/the/零冠词的选择题。

::: info 考点地图

1. **不定冠词 a/an**（泛指）—— 区别看发音、5 种基本用法、固定搭配
2. **定冠词 the**（特指）—— 必加 the 口诀、基本用法、固定搭配
3. **零冠词** —— 巧记口诀、有 the 无 the 大不同

:::

## 一、不定冠词 a / an（表泛指）

### 1. a 和 an 的区别：看发音，不看字母

| 开头音素 | 用 | 例 |
| --- | --- | --- |
| **元音音素** | an | an interesting book；an hour；an honest man；an honored man |
| **辅音音素** | a | a book；a useful book；a university；a uniform；a European；a unique idea |

::: danger 易错

高频易错**元音字母 ≠ 元音音素**：university 发 /ju:/ 是辅音音素开头，用 a university；hour 的 h 不发音，用 an hour。

:::

### 2. 五种基本用法

1. **泛指**某一个人或物：There is **a** cat lying on the sofa.
2. 序数词前表"再一、又一"：She thanked him **a** second time.
3. 动词转化的名词前表"一次、一番"（配 have / take / make / give）：We've already had **a** try. / take **a** swim
4. 表**某类**人或物：**A** cat is much smaller than **a** tiger.
5. 抽象名词具体化：He was **a** success in business. / It's **a** pleasure to talk with you.

固定搭配：catch a cold 感冒 · in a hurry 匆忙 · in a word 总之 · take a look 看一眼 · take a break 休息一下

## 二、定冠词 the（表特指）

::: info

必加 the 口诀**"那个地球第一最酷的老人带着一家人弹着钢琴走南闯北欢度春节。"**

:::

| 口诀 | 用法 | 例 |
| --- | --- | --- |
| 那个 | 上文提过、双方都了解 | the cat |
| 地球 | 独一无二的事物 | the sun |
| 第一 | 序数词前 | the first |
| 最酷的 | 最高级前 | the happiest |
| 老人 | 一类人 | the old |
| 一家人 | 姓氏复数前 | The Smiths |
| 钢琴 | 乐器前 | play the piano |
| 走南闯北 | 方向前 | the north |
| 欢度春节 | 中国传统节假日前 | the Spring Festival |

"the + 比较级，the + 比较级"：**The** more you learn, **the** more you gain.

固定搭配：on the left/right · by the way · at the same time · in the end · in the morning/afternoon/evening

## 三、零冠词

::: info

零冠词口诀**0 球 12 月 3 餐 4 季，56 颜色 7 星期；x 学科 y 语言，z 专有名词记心里**

:::

| 情形 | 例句 |
| --- | --- |
| 球类棋类 | play chess / play basketball |
| 月份 | in June |
| 三餐 | eat dinner / have lunch |
| 四季 | in summer |
| 颜色 | The door is red. |
| 星期 | from Monday to Friday |
| 学科 / 语言 / 专有名词 | I love English best. / Can you speak Chinese? / Lu Xun is a great writer. |

::: danger 易错

有 the 无 the 大不同（考试高频）

| 无 the（表动作） | 有 the（表地点） |
| --- | --- |
| in hospital **住院** | in the hospital **在医院** |
| in bed **睡觉** | in the bed **在床上** |
| in class **在上课** | in the class **在班里** |
| by sea **乘船** | by the sea **在海边** |

:::

## 易错清单

::: danger 易错

高频易错
1. a/an **看音标不看字母**：a university ✔ / an hour ✔

2. 演奏乐器加 the，球类棋类不加：play the violin / play chess

3. watch TV 零冠词

4. 三餐、月份、星期、季节、学科、语言、颜色零冠词

5. in hospital / in the hospital 类短语有无 the 意思不同

:::

## 课堂练习

**—Do you know ____ man standing under the tree?
—He’s ____ university teacher.**

- A. a; the
- B. the; an
- C. a; an
- D. the; a

::: details 点开核对答案

**答案：D（the; a）** —— 特指"站在树下的那个男人"用 the；university 发 /ju:/ 辅音音素，用 a。

:::

**After watching ____ TV, she played ____ violin for an hour.**

- A. /; /
- B. the; the
- C. the; /
- D. /; the

::: details 点开核对答案

**答案：D（/; the）** —— watch TV（看电视）零冠词；play the violin 乐器前加 the。

:::

**____ Browns were having dinner when the telephone rang.**

- A. A
- B. An
- C. /
- D. The

::: details 点开核对答案

**答案：D（The）** —— the + 姓氏复数，表示"布朗一家人"。

:::

**To some degree, being ____ honest person all one’s life isn’t easy.**

- A. /
- B. an
- C. a
- D. the

::: details 点开核对答案

**答案：B（an）** —— honest 的 h 不发音，以元音音素开头，用 an。

:::

**People like to walk by ____ sea in ____ June and July.**

- A. the; /
- B. /; /
- C. the; the
- D. /; the

::: details 点开核对答案

**答案：A（the; /）** —— by the sea 在海边（地点）；月份前零冠词。

:::

**We have ____ lunch at school.**

- A. a
- B. an
- C. the
- D. /

::: details 点开核对答案

**答案：D（/）** —— 三餐前零冠词。

:::

**I play ____ piano very well.**

- A. a
- B. an
- C. the
- D. /

::: details 点开核对答案

**答案：C（the）** —— 乐器前加 the（口诀：钢琴）。

:::
