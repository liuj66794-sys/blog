语法专题 · 第一课

对应教材上册 P7–P14 · 名词是句子的"材料"，也是主谓一致、冠词等专题的地基。

::: info 考点地图

1. **分类** —— 专有名词 vs 普通名词（可数 / 不可数）
2. **功能** —— 主语、宾语、表语、定语、同位语、补语（6 种）
3. **单复数** —— 规则 / 不规则 / 复合名词 / 不可数量化 / 抽象名词具体化
4. **所有格** —— 's 所有格、of 所有格、双重所有格

:::

## 一、名词的分类

| 大类 | 子类 | 例词 | 含义 |
| --- | --- | --- | --- |
| 专有名词 | Beijing、WTO、the Spring Festival | 特定的人、地方、机构、事件 |   |
| 可数名词 | 个体名词 | book、pen、apple、teacher | 表示个体 |
| 集体名词 | family、class、team、police、crowd | 人或事物的集合体 |   |
| 不可数名词 | 物质名词 | water、milk、bread、rice、wood | 无法分为个体的事物 |
| 抽象名词 | love、happiness、knowledge、progress | 抽象概念，无法触摸 |   |

::: info

TIP专有名词第一个字母要**大写**。

:::

## 二、名词的六大功能

| 功能 | 例句 | 说明 |
| --- | --- | --- |
| 主语 | The **dog** runs fast.　**Honesty** is the best policy. | 动作的发出者 |
| 宾语 | I like **apples**. / She is in the **room**. | 分别是动词宾语、介词宾语 |
| 表语 | He is a **doctor**. / The room is a **mess**. | 说明主语的身份、特征、状态 |
| 定语 | a **book** cover（所属）/ **banana** trees（分类）/ **coffee** cup（用途） | 名词直接修饰名词 |
| 同位语 | My friend **Tom** is very kind. | 对前面的名词解释说明 |
| 补语 | We made the room **clean**.（宾补） She was elected **monitor**.（主补） | 对主语或宾语补充说明 |

::: info

写作补充"...is the best policy" 意为"……是上策 / 最佳原则"。

:::

## 三、名词的单复数

### 1. 规则变化

| 规则 | 例词 |
| --- | --- |
| 一般加 **-s** | map → maps |
| 以 s / x / ch / sh 结尾加 **-es** | box → boxes；bus → buses；wish → wishes；beach → beaches |
| 辅音 + y：去 y 变 i 加 -es；元音 + y：直接加 -s | story → stories；boy → boys；key → keys |
| 元音 + o / oo 结尾加 -s | bamboo → bamboos；radio → radios；zoo → zoos |
| 辅音 + o：三个词加 -es，其余加 -s | hero / tomato / potato → -es；piano → pianos |
| -f / -fe 结尾：少数直接加 -s，多数变 v 加 -es | roof → roofs、chief → chiefs、belief → beliefs；leaf → leaves、wife → wives、knife → knives |

::: info

口诀
**三线城市后加 es**（三=s，线=x，城=ch，市=sh）· **英雄爱吃西红柿和土豆**（hero / tomato / potato 加 -es）

**海湾屋顶首领信，证据悬崖直接 s**（gulf / roof / chief / belief / proof / cliff）

**树叶半数自己黄，妻子拿刀去割粮，架后窜出一只狼，就像小偷逃命忙**（leaf / half / wife / knife / shelf / wolf / thief / life 变 v 加 -es）

:::

::: danger 易错

例外stomach 虽以 ch 结尾，却是 **stomachs**（ch 发 /k/ 音）。

:::

### 2. 不规则变化

| 类型 | 例词 |
| --- | --- |
| 变元音字母 | man → men；woman → women；foot → feet；tooth → teeth；goose → geese |
| 单复数同形 | deer 鹿；sheep 羊；means 方法；species 物种 |
| 只有复数形式 | glasses 眼镜；trousers 裤子；shorts 短裤；scissors 剪刀；gloves 手套 |
| 特殊形式 | child → children；ox → oxen；mouse → mice；phenomenon → phenomena |
| "某国人" | Chinese / Japanese 不变；Englishman → Englishmen、Frenchman → Frenchmen；American → Americans、German → Germans |

::: info

口诀**男人女人 a 变 e；鹅、足、牙齿 oo 变 ee** · **中日不变，英法变 a-e，其余 s 加后面**

:::

### 3. 复合名词的复数

| 规则 | 例词 |
| --- | --- |
| 含 man / woman 的：**前后都变** | woman doctor → women doctors；man writer → men writers |
| 有连字符 / 分开的：**主要名词变** | father-in-law → fathers-in-law；passer-by → passers-by |
| 无主要名词：**最后一个词变** | grown-up → grown-ups；go-between → go-betweens |

::: info

口诀**男人女人若出现，前者后者都要变**

:::

### 4. 单复数意思不同的词

| 单数 | 复数 | 单数 | 复数 |
| --- | --- | --- | --- |
| paper 纸张 | papers 文件 | time 时间 | times 次数、时代 |
| wood 木材 | woods 树林 | custom 风俗 | customs 海关 |
| value 价值 | values 价值观 | work 工作 | works 作品；工厂 |
| damage 赔偿 | damages 损害赔偿金 |   |   |

### 5. 不可数名词的量化

三种量化方式，**谓语动词跟着"量"走**：

| 方式 | 例 | 谓语 |
| --- | --- | --- |
| some / much / a little 等 | much water；a little milk | 用**单数**：A lot of juice **is** in the bottle. |
| 容器：a cup of / ten bags of | ten bags of rice | 跟**容器数**：Ten bottles of water **are** not enough. |
| 计量单位：a piece of / a slice of | a piece of paper | 跟**单位数**：Three pieces of paper **are** on the table. |

::: info

两栖修饰词some、any、a lot of、plenty of、enough、most、half、all、quantities of、the rest of 等既可修饰可数也可修饰不可数名词。

:::

### 6. 抽象名词具体化

抽象名词表示具体的人或事时变为可数，可加 a/an：

| 表达 | 含义 | 例句 |
| --- | --- | --- |
| a beauty / a youth | 一个美女 / 年轻人 | This book tells the story of a youth growing up. |
| a success / a failure | 一个成功（失败）的人或事 | The project was a failure due to poor planning. |
| an honor | 一件引以为荣的事 | It is an honor to have such a privilege. |
| a walk | 一次散步 | take a walk = go for a walk |

## 四、名词的所有格

### 1. 's 所有格：A's B ＝ "A 的 B"

构成：单数或非 s 结尾复数加 **-'s**（the boy's bag / the children's rooms）；s 结尾复数只加 **'**（the workers' job）。

::: danger 易错

共有 vs 各有
Tom **and Lisa's** house is very big.（共有一间房 → 只在最后一个名词后加 's）

Tom**'s and Lisa's** houses are very big.（各有各的房 → 分别加 's）

:::

's 还可用于：时间（ten days' holiday）、城市国家（China's policy）、机构（the station's waiting-room）、度量衡（a kilo's weight）、天体（the moon's light）；表"家、店铺"时名词省略：the doctor's（诊所）、the barber's（理发店）。

### 2. of 所有格与双重所有格

of 所有格：A of B 译为"B 的 A"。双重所有格 = **of + 's / 名词性物主代词**，表示"谁的（其中）一个/几个"：

Some friends **of my brother's**. —— 我哥哥的一些朋友（只是其中一部分）

A friend **of mine**. —— 我的一个朋友（众多朋友之一）

::: danger 易错

辨析
a photo **of Nina** —— 照片**内容**是 Nina（归属不明）

a photo **of Nina's** —— 照片归 **Nina 所有**（内容不明）

:::

::: info

用 to 表示"的"the key **to**（……的钥匙/关键）· the answer **to** · the solution **to** · the way **to**

:::

## 易错清单

::: danger 易错

高频易错
1. **advice 不可数**：不说 some advices / an advice。

2. **stomachs** 不加 -es。

3. man/woman 作修饰语**前后都变复数**：women teachers ✔。

4. 物质名词表材料不可数：Tables are made of **wood**（wooden 是形容词）。

5. 共有加一个 's，各有分别加。

6. 容器量化**谓语跟容器**：Ten bottles of water **are**...

7. in hospital 住院 / in the hospital 在医院——有 the 无 the 意思不同（见下一课冠词）。

:::

## 课堂练习

**He gave us ____ on how to keep fit.**

- A. some advices
- B. some advice
- C. an advice
- D. a advice

::: details 点开核对答案

**答案：B（some advice）** —— advice 是不可数名词，无复数形式，也不加冠词。

:::

**I would like to have ____.**

- A. two glasses of milk
- B. two glass of milk
- C. two glasses of milks
- D. two glass of milks

::: details 点开核对答案

**答案：A（two glasses of milk）** —— 不可数名词用"容器 of"量化：glass 可数需复数，milk 不变。

:::

**Some ____ came to our school for a visit that day.**

- A. Germans
- B. Germen
- C. Germany
- D. Germanies

::: details 点开核对答案

**答案：A（Germans）** —— "某国人"复数口诀：其余 s 加后面——German → Germans。

:::

**Tables are made of ____.**

- A. wood
- B. some woods
- C. wooden
- D. woods

::: details 点开核对答案

**答案：A（wood）** —— 物质名词表材料用原形 wood；woods 意为"树林"；wooden 是形容词。

:::

**There are sixty-seven ____ in our school.**

- A. women’s teacher
- B. women teachers
- C. woman teachers
- D. women teacher

::: details 点开核对答案

**答案：B（women teachers）** —— man/woman 修饰名词时前后两个词都要变复数：women teachers。

:::

**—Is the broom under ____ desk?
—No, it’s under ____.**

- A. the teacher’s; my
- B. teacher’s; mine
- C. teacher’s; me
- D. the teacher’s; mine

::: details 点开核对答案

**答案：D（the teacher’s; mine）** —— 特指"老师的桌子"用所有格 the teacher’s；"我的（桌子）"用名词性物主代词 mine。

:::

**He is reading a history book. —— 句中加粗的名词充当什么成分？**

- A. 主语
- B. 宾语
- C. 定语
- D. 同位语

::: details 点开核对答案

**答案：C（定语）** —— history 修饰 book，表分类，作定语。

:::

**The city, Beijing, is the capital of China. —— 句中加粗的名词充当什么成分？**

- A. 同位语
- B. 主语
- C. 表语
- D. 宾语补足语

::: details 点开核对答案

**答案：A（同位语）** —— Beijing 对 the city 解释说明，作同位语。

:::
