语法专题 · 第十五课

对应教材上册 P175–P187 · 三大形式：(should) be 型、were 型、if 条件句及主句虚拟，外加 It is (high/about) time 特殊结构。

::: info 考点地图

1. **(should) be 型虚拟**："一二四四"标志词、词形变化、主观看法、lest/in case/for fear that、祝愿
2. **were 型虚拟**：wish、if only、as if/as though、would rather 等
3. **if 条件句及主句虚拟**：同一时空、错综时间、虚实混用、倒装、含蓄虚拟、情态动词 + have done
4. **特殊虚拟结构**：It is (high/about) time...

:::

## 什么是虚拟语气

英语语气可分为三类：

| 语气 | 作用 | 例句 |
| --- | --- | --- |
| **陈述语气** | 陈述事实或可能发生的事情 | You guys are so smart.（你们真聪明。） |
| **祈使语气** | 表示请求、命令、警告等 | Be careful, please!（请小心！） |
| **虚拟语气** | 表达假设、愿望、建议等不真实或未实现的情况 | If I were you...（如果我是你……） |

虚拟语气用**动词的不同形式**表示不能实现或与事实相反的假设。课件用"想得美""后悔药""做梦"帮助理解：例如"如果我是皇上""真希望华妃失宠""我建议皇上听我的"。其形式大体分为 **(should) be 型、were 型、if 条件句及主句虚拟**三类。

## 第一部分 · (should) be 型虚拟

### 1. “一二四四"标志词

| 类别 | 标志词 |
| --- | --- |
| **一个主张** | insist |
| **两个命令** | order、command |
| **四个建议** | suggest、advise、propose、recommend |
| **四个要求** | ask、require、request、demand |

这些动词引导宾语从句时，从句谓语用：**动词 + (that) + 从句主语 + (should) do / (should) be done**。should 一般可以省略；被动结构为 **(should) be + 过去分词**。

We demand that the meeting (should) **be postponed**.（我们要求会议延期。）

::: info

口诀**一坚持、二命令、四建议、四要求。**

:::

### 2. 变形词引导其他名词性从句

上述词变成**名词、形容词**等形式后，引导的主语从句、表语从句或同位语从句同样用 **(should) + 动词原形**。

It is required that the students (should) **learn** a foreign language.（要求学生学习一门外语。）
The requirement is that all the equipment in the meeting room (should) **be checked** twice before.（要求是会议室里的所有设备事先检查两遍。）
We didn't stand for his proposal that the meeting (should) **be postponed**.（我们不支持他提出的会议延期举行的建议。）

### 3. suggest 与 insist 的特例

::: danger 易错

看词义，不只看词形
**suggest** 表示"**建议**"时用虚拟；表示"**暗示、表明、说明**"时陈述客观事实，不用虚拟。

**insist** 表示"**坚持要求**"时用虚拟；表示"**坚持说**"时陈述事实，不用虚拟。

:::

We all suggest that a lab (should) **be built**.（我们都建议建一个实验室。）
Her expression **suggests that she is** angry.（她的表情表明她生气了。）
She **insisted that we should find** the source of the river.（她坚持要求我们找到河流的源头。）
She **insisted that she had done** nothing wrong.（她坚持说她没有做错任何事。）

### 4. It is + 名词/形容词 + that 从句

表示必要性、重要性、强制性、合适性、义务性或主观反应时，that 从句用 **(should) + 动词原形**。常见形容词：advisable（可取的）、desirable（可取的）、essential（必要的）、vital（至关重要的）、important（重要的）、necessary（必要的）、unnecessary（不必要的）、proper（适当的）、possible（可能的）、impossible（不可能的）、natural（自然的）、surprising（令人惊讶的）、compulsory（强制的）。

It is important that students graduating from universities (should) **have** not only theory but also practice.（大学毕业生不仅应掌握理论，还应具备实践能力，这很重要。）
It is of great importance that smoking (should) **be banned** in public.（在公共场所应该禁止吸烟，这非常重要。）

### 5. lest / in case / for fear that 与祝愿

**lest、in case、for fear that** 表示"恐怕、担心、以免、万一"时，从句用 **(should) + 动词原形**。

He took his raincoat with him **in case it (should) rain**.（他带上雨衣，以防下雨。）
He took his raincoat with him **for fear that he (should) be caught** in the rain.（他带上雨衣，唯恐淋雨。）

表示祝愿可用：**May + 主语 + 动词原形**。

**May you be happy.**（愿你幸福。）

## 第二部分 · were 型虚拟

were 型虚拟表达与事实相反、未曾实现的主观愿望：

| 愿望与事实的关系 | 从句谓语形式 |
| --- | --- |
| 与现在事实相反 | 一般过去时；be 一律用 **were** |
| 与过去事实相反 | 过去完成时 **had done** |
| 与将来事实相反 | 过去将来时 **would/could + do** |

### 1. wish 引导宾语从句

I wish I **were** a bird.（我希望自己是一只鸟。——与现在事实相反）
I wish that I **had passed** the final exam.（我真希望自己已经通过了期末考试。——与过去事实相反，实际未通过）
I wish he **would/could come** to help me with my paper, but he will go on business next week.（我希望他能来帮我写论文，但他下周要出差。——与将来事实相反）

### 2. if only 感叹句

if only 表示"要是……就好了"。

If only she **were** here at this moment.（要是她此刻在这里就好了。——与现在事实相反）
If only I **hadn't made** this mistake.（要是我没有犯这个错误就好了。——与过去事实相反）
If only you **would/could attend** my wedding.（要是你能参加我的婚礼就好了。——与将来事实相反）

::: danger 易错

易错：if only 与 only if**if only** = 要是……就好了；**only if** = 只有……才。**Only if 位于句首时，主句采用部分倒装**：**Only if** the government takes some measures **will this problem be solved**.（只有政府采取一些措施，这个问题才能得到解决。）

:::

### 3. as if / as though

as if / as though 引导状语从句，表示"似乎、好像"，所述情况与事实相反或极不可能发生。

He talked about the film **as if he had seen** it before.（他谈起那部电影，好像以前看过似的。）
It seems **as if the meeting would/could/might never end**.（会议似乎怎么也不会结束。）

### 4. would rather 等引导宾语从句

**would rather、would sooner、would prefer、had rather** 表示"宁愿、但愿"。从句用**一般过去时**表示现在或将来的愿望，用**过去完成时**表示对过去的愿望。

I would rather you **came** here now.（我宁愿你现在来这里。——现在的愿望）
I would rather he **hadn't told** me the truth.（我宁愿他当时没有告诉我真相。——对过去的愿望）

## 第三部分 · if 条件句虚拟及主句虚拟

### 1. 同一时空虚拟

| 与事实相反的时间 | if 从句 | 主句 |
| --- | --- | --- |
| **现在** | did / were | would/should/could/might + do |
| **过去** | had done | would/should/could/might + have done |
| **将来** | did / were to do / should do | would/should/could/might + do |

**与现在事实相反：**

If I **had** more money, I **would buy** a new car.（如果我有更多的钱，我会买一辆新车。）
If I **were** you, I **would consider** their advice.（如果我是你，我会考虑他们的建议。）

**与过去事实相反：**

If I **had had** more money, I **would have bought** a new car.（如果我当时有更多的钱，我就会买一辆新车了。）
You **would not have caught** a cold if you **had put on** more clothes.（如果你当时多穿点衣服，就不会感冒了。）

**与将来事实相反：**

If I **had** more money in the future, I **would buy** a new car, but it's unlikely.（如果将来我有更多的钱，我会买一辆新车，但这不太可能。）

### 2. 错综时间虚拟

从句和主句分别对应不同时间，就**分别按各自所反事实的时间**选择动词形式。

If you **had left** earlier, you **would be** at the concert now.（如果你早点出发，你现在就在演唱会上了。——过去条件 + 现在结果）
If you **had worked** hard before, you **would be** very tired now.（如果你以前努力工作，你现在会很累。——过去条件 + 现在结果）
If you **followed** my advice now, you **would succeed** in the final exam next month.（如果你现在听从我的建议，你下个月的期末考试就会成功。——现在条件 + 将来结果）

::: info

做题方法句子各部分是什么时间，就判断其与哪个时间的事实相反，再分别套用该时间的动词形式，**不要整句只套一列**。

:::

### 3. 虚实混用

有的部分是真实事实，有的部分是虚拟情况。**非真实部分才虚拟，真实部分使用正常时态**。

If I **had been** at the concert yesterday evening, I **should have met** the famous singer. But I failed to get a ticket.（如果我昨晚在音乐会上，就会见到那位著名歌手了。但我没能买到票。——前句是过去虚拟；"没买到票"是真实发生的事实）

### 4. 省略 if 的倒装

if 从句含 **were、should、had** 时，可以省略 if，并把 were、should、had 移到主语之前：

| 原句 | 倒装 |
| --- | --- |
| If I **were** you... | **Were I you**... |
| If you **had** taken... | **Had you taken**... |
| If it **should** rain... | **Should it rain**... |

If I were you, I would apply for the job. = **Were I you, I would apply for the job.**（如果我是你，我会申请这份工作。）
If you had taken my advice, you wouldn't have failed in the examination. = **Had you taken my advice, you wouldn't have failed in the examination.**（如果你当时听了我的建议，就不会考试不及格了。）

**were it not for / had it not been for** 表示"要不是因为……"：

If it were not for peace, we could not live a happy life. = **Were it not for peace, we could not live a happy life.**（如果不是因为和平，我们就不能过上幸福生活。）
If it had not been for your help, I would have gone bankrupt. = **Had it not been for your help, I would have gone bankrupt.**（如果当时不是因为你的帮助，我就破产了。）

### 5. 含蓄虚拟

假设条件不一定写成 if 从句，也可由介词或介词短语 **without、but for**，副词 **otherwise**，连词 **or、but** 等表达；此时可看成 if 条件句的主句虚拟结构。

**Without air**, there wouldn't be living things in the world.（没有空气，世界上就不会有生物。）
**But for your advice**, I would have failed.（要不是你的建议，我就失败了。）
He came to town yesterday; **otherwise/or I would not have met him**.（他昨天进城了，否则我就见不到他了。）

### 6. 情态动词 + have done

| 形式 | 含义 | 例句 |
| --- | --- | --- |
| should have done | 过去本应该做，实际没做 | You **should have told** me the truth earlier.（你本应该早点告诉我真相。） |
| shouldn't have done | 过去本不应该做，实际做了 | You **shouldn't have stayed up** so late last night.（你昨晚本不应该熬夜到这么晚。） |
| could have done | 过去本有能力或机会做，实际没做 | He **could have won** the race if he had tried harder.（如果他更努力些，本可以赢得比赛。） |
| couldn't have done | 对过去事情的否定推测：不可能做过 | He **couldn't have finished** the work in such a short time.（他不可能在这么短的时间内完成这项工作。） |
| would have done | 与过去事实相反：某条件下本会做 | I **would have gone** to the party if I had been invited.（如果我被邀请了，本来会去参加派对。） |
| wouldn't have done | 某条件下本不会做 | She **wouldn't have bought** that dress if she hadn't seen the discount.（如果没看到折扣，她本来不会买那条裙子。） |
| might have done | 过去可能做了，是否做过不确定 | He **might have forgotten** about our appointment.（他也许忘了我们的约会。） |
| might not have done | 过去可能没做 | They **might not have received** our email yet.（他们也许还没收到我们的邮件。） |
| need have done | 过去本有必要做，实际没有做 | You **need have come** here earlier. There was a lot of preparation work.（你本有必要早点来，这里有很多准备工作。） |
| needn't have done | 过去本没必要做，实际做了 | You **needn't have watered** the flowers. It's going to rain.（你本没必要浇花，马上要下雨了。） |
| would rather have done | 宁愿过去做了，实际没做；或后悔没做 | I **would rather have stayed** at home last night. The party was boring.（我昨晚宁愿待在家里；那个派对太无聊了。） |
| would rather not have done | 宁愿过去没做，实际做了 | She **would rather not have said** those words.（她宁愿自己当时没说那些话。） |
| would like/love to have done | 过去本想做，实际没做 | I **would like to have visited** the museum last week.（我上周本想去参观博物馆。） |

::: danger 易错

课件提示**must、can、may 本身不用于表达这种"本来……却……"的虚拟结构；但 could/might have done 可表达未实现的可能性或推测。**

:::

## 第四部分 · 特殊虚拟结构

在 **It is (high/about) time + 从句** 中，从句谓语用**一般过去时**，或用 **should + 动词原形**（此处 should 不可省略），表示"该做某事的时候到了"。

It is high time we **went** to bed. = It is high time we **should go** to bed.（我们该睡觉了。）

## 易错清单

::: danger 易错

高频易错
1. suggest/insist 要先看词义：建议、要求才虚拟；"表明""坚持说"不用虚拟

2. (should) be 型里的 should 通常可省，但 **It is time... should do 中的 should 不可省**

3. 与现在事实相反时，be 不随人称变化，统一用 **were**

4. wish/if only/would rather 后的"过去式"表示与事实的距离，不等于句子一定发生在过去

5. 错综时间题必须分别找从句和主句的时间标志，如 before/yesterday 与 now/next month

6. 省略 if 倒装只提前 **were、should、had**，不能把普通实义动词直接提前

7. **were it not for** 对现在虚拟；**had it not been for** 对过去虚拟

8. should have done = 本应做而未做；needn't have done = 本不必做却做了

:::

## 课堂练习

**The job would require that ____ at 7 o’clock every morning.**

- A. he will be at the factory
- B. he be at the factory
- C. he was at the factory
- D. he has been at the factory

::: details 点开核对答案

**答案：B（he be at the factory）** —— require 后的 that 从句用 (should) be，should 可省略。（(should) be 型随堂练习）

:::

**Your advice that she ____ till next week is reasonable.**

- A. will wait
- B. is going to wait
- C. waits
- D. wait

::: details 点开核对答案

**答案：D（wait）** —— advice 后的同位语从句用 (should) wait。

:::

**It is necessary that a worker ____ his work on time.**

- A. accomplishes
- B. can accomplish
- C. accomplish
- D. has accomplished

::: details 点开核对答案

**答案：C（accomplish）** —— It is necessary that... 后用 (should) accomplish。

:::

**The government suggests people ____ the Spring Festival at their working place this year.**

- A. to spend
- B. spend
- C. spending
- D. will spend

::: details 点开核对答案

**答案：B（spend）** —— suggest 表“建议”，从句用 (should) spend。

:::

**The physicists propose that our attention ____ the use of special methods of thinking and acting.**

- A. would be directed towards
- B. be directed towards
- C. is directed towards
- D. direct towards

::: details 点开核对答案

**答案：B（be directed towards）** —— propose 表“建议”，attention 与 direct 是被动关系，用 (should) be directed。

:::

**The boy insisted that he ____ old enough, and ____ the right to make his own choice.**

- A. was; be given
- B. was; was given
- C. be; give
- D. is; given

::: details 点开核对答案

**答案：A（was; be given）** —— 第一个 insist 表“坚持说”，陈述事实用 was；第二个表“坚持要求”，用 (should) be given。

:::

**You are overweight. You’d better ____ any junk food. I suggest you ____ more vegetables.**

- A. not to eat; to have
- B. not eat; have
- C. not eat; to have
- D. not to eat; have

::: details 点开核对答案

**答案：B（not eat; have）** —— had better 后接动词原形，否定为 had better not do；suggest 从句用 (should) have。

:::

**I enjoyed the movie very much. I wish I ____ the book from which it was made.**

- A. have read
- B. had read
- C. should have read
- D. are reading

::: details 点开核对答案

**答案：B（had read）** —— wish 针对过去未发生之事，使用 had done。（were 型随堂练习）

:::

**The two students talked as if they ____ friends for years.**

- A. should be
- B. would be
- C. have been
- D. had been

::: details 点开核对答案

**答案：D（had been）** —— “做了多年朋友”先于 talked，用 had been。

:::

**If only he ____ quietly as the doctor instructed, he would not suffer so much now.**

- A. lies
- B. lay
- C. had lain
- D. should lie

::: details 点开核对答案

**答案：C（had lain）** —— 从句与过去事实相反，主句结果落在现在，是错综时间虚拟。

:::

**“He will come tomorrow.” “But I’d rather he ____ the day after tomorrow.”**

- A. will come
- B. is coming
- C. came
- D. had come

::: details 点开核对答案

**答案：C（came）** —— would rather 后对将来愿望用一般过去时。

:::

**The sun rises in the east and sets in the west, so it seems as if the sun ____ round the earth.**

- A. were circling
- B. circles
- C. is circling
- D. be circling

::: details 点开核对答案

**答案：A（were circling）** —— as if 描述与事实相反的表象，be 用 were，动作表进行。

:::

**If I ____ where he lived now, I ____ a note to him.**

- A. knew; would send
- B. had known; would have sent
- C. know; would send
- D. knew; would have sent

::: details 点开核对答案

**答案：A（knew; would send）** —— now 指向现在：if 从句用 knew，主句用 would send。（同一时空随堂练习）

:::

**If we ____ more time, we could do it better.**

- A. were given
- B. are given
- C. is given
- D. is giving

::: details 点开核对答案

**答案：A（were given）** —— 与现在事实相反，we 与 give 是被动关系，用 were given。

:::

**If I ____ a boss, I would manage a big factory.**

- A. are
- B. was
- C. were
- D. be

::: details 点开核对答案

**答案：C（were）** —— 与现在事实相反，be 一律用 were。

:::

**If I ____ not so busy, I ____ with you.**

- A. was; would go
- B. were; would go
- C. was; should go
- D. were; will go

::: details 点开核对答案

**答案：B（were; would go）** —— 从句 were，主句 would go。

:::

**— If he ____, he ____ that food. — Luckily he was sent to the hospital immediately.**

- A. was warned; would not take
- B. had been warned; would not have taken
- C. would be warned; had not taken
- D. would have been warned; had not taken

::: details 点开核对答案

**答案：B（had been warned; would not have taken）** —— 对过去虚拟：had been warned / would not have taken。

:::

**If I ____ harder when I was young, I ____ a university and lived a different life.**

- A. worked; would entered
- B. had worked; would have entered
- C. would worked; had entered
- D. have worked; will have entered

::: details 点开核对答案

**答案：B（had worked; would have entered）** —— when I was young 指过去：had worked / would have entered。

:::

**Without the air to hold some of the sun’s heat, the earth at night ____ for us to live.**

- A. would be freezing cold
- B. will be freezing coldly
- C. would be frozen cold
- D. can freeze coldly

::: details 点开核对答案

**答案：A（would be freezing cold）** —— without 引出与现在事实相反的含蓄条件，主句用 would + do；freezing cold 表“极冷”。（综合练习）

:::

**Without electronic computers, much of today’s advanced technology ____.**

- A. will not have been achieved
- B. have not been achieved
- C. would not have been achieved
- D. had not been achieved

::: details 点开核对答案

**答案：C（would not have been achieved）** —— 技术已经实现，假设与过去事实相反，用 would not have been achieved。

:::

**Yesterday, the storm delayed us. ____ the storm, we would have been here in time.**

- A. But for
- B. If it were not for
- C. If it is not for
- D. Unless

::: details 点开核对答案

**答案：A（But for）** —— yesterday 和 would have been 表过去虚拟，But for = If it had not been for。

:::

**Luckily, he wasn’t driving fast at the time of the accident; otherwise, I am sure, it ____ a more serious accident.**

- A. would be
- B. were
- C. would have been
- D. had been

::: details 点开核对答案

**答案：C（would have been）** —— otherwise 指过去相反结果，用 would have been。

:::

**He did not regret saying what he did but felt that he ____ it differently.**

- A. could express
- B. would express
- C. could have expressed
- D. must have expressed

::: details 点开核对答案

**答案：C（could have expressed）** —— 表示过去本可以换一种方式表达却没有，用 could have expressed。

:::

**I told your friend how to get to the hotel, but perhaps I ____ her there.**

- A. would have driven
- B. must have driven
- C. might have driven
- D. should have driven

::: details 点开核对答案

**答案：D（should have driven）** —— 表示过去本应该开车送她却没有，用 should have driven。

:::

**【25 湖南】If I were you, I ____ for her opinion.**

- A. asked
- B. would ask
- C. ask
- D. will ask

::: details 点开核对答案

**答案：B（would ask）** —— If I were you 表现在虚拟，主句用 would ask。（真题在线）

:::

**【22 重庆】An order came that all the army supply ____ to the front before daybreak.**

- A. be sent
- B. should send
- C. were went
- D. have sent

::: details 点开核对答案

**答案：A（be sent）** —— order 后同位语从句用 (should) do；supply 与 send 为被动关系，用 (should) be sent。

:::

**【24 重庆】If you had done your homework yesterday, you ____ how to answer the question now.**

- A. know
- B. knew
- C. will know
- D. would know

::: details 点开核对答案

**答案：D（would know）** —— 过去条件造成现在结果：had done / would know。

:::

**【24 湖南】If you ____ him about the rainy weather, he ____ his umbrella.**

- A. warn; would bring
- B. had warned; would bring
- C. warned; would have brought
- D. had warned; would have brought

::: details 点开核对答案

**答案：D（had warned; would have brought）** —— 与过去事实相反：had warned / would have brought。

:::

## 口诀卡

::: info

本课全部口诀
should 型标志词：**一坚持、二命令、四建议、四要求。**

were 型时间后退：**现在过去式，过去 had done，将来 would/could do。**

if 三时空：**现过将来分别看，从句 did/had done/did-were to-should，主句 would do/have done。**

if 倒装：**were、should、had 才能提，省 if 后放句首。**

错综时间：**各看各的时间，各用各的虚拟。**
