Everything else is mechanical.」 如果你有一个 tight feedback loop（紧反馈回路）——一个能在这个 bug 上变红、修好后变绿的 pass/fail 信号—— 你迟早能找到原因：bisect、假设验证、插桩都只是消耗这个信号。 反之， 没有回路，盯着代码看多久都没用 …
