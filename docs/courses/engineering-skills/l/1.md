Skill 是什么？ 一个 skill 就是一份给 AI 的“工作说明书”：它定义了面对某类任务时，AI 应该遵循的流程、使用的词汇、输出的格式。 安装后，skill 会出现在多个 AI 客户端能识别的地方（Kimi Code CLI、Claude Code、Cursor、Codex 等）。 有些 skill 是 model-invoked（模型可自动调用） ， 有些是 user-invoked（用户手动触发） 。 作为学习者，你暂时只需要关心后者：看到合适的场景，喊出它的名字。 2. 主流程：idea → ship Matt 把大部分工程工作抽象成一条主流程。记住这条线，你就记住了 half of the skills： 1 打磨想法 ：用 /grill-with-docs （有代码库）或 /grill-me （无代码库）进行 relentless interview（追问式访谈）。 2 生成 spec ：想法清楚后，用 /to-spec 把它写成 PRD/spec，发布到 issue tracker（问题追踪系统）。 3 拆 ticket ：用 /to-tickets 把 spec 拆成…
