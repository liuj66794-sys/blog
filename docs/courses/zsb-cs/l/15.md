## 一、线性表的本质：逻辑结构

**线性表**是相同数据类型的 n(n≥0) 个数据元素的**有限序列**，记作 L=(a₁, a₂, …, aₙ)。除第一个元素外，每个元素**有且仅有一个直接前驱**；除最后一个元素外，每个元素**有且仅有一个直接后继**。

::: danger 易错

概念分层

⚠️ **线性表是逻辑结构**，描述的是元素之间一对一的相邻关系；**顺序表和链表才是存储结构**。考题如果说「线性表是顺序存储结构」就是错的。

:::

## 二、顺序表：随机存取快，插删要搬家

顺序表用一组**地址连续**的存储单元依次存放元素，逻辑相邻 ⟺ 物理相邻。三大特点：① 随机访问 O(1)；② 存储密度高；③ 插入删除要移动元素。

| 操作 | 最好 | 最坏 | 第 i 个位置 | 平均移动次数 | 复杂度 |
| --- | --- | --- | --- | --- | --- |
| 插入 | 0（表尾） | n（表头） | **n-i+1** 个元素后移 | **n/2** | O(n) |
| 删除 | 0（表尾） | n-1（表头） | **n-i** 个元素前移 | **(n-1)/2** | O(n) |
| 按值查找 | 1 次 | n 次 | — | **(n+1)/2** 次 | O(n) |

::: info

记忆诀窍

插入要腾位置，所以比删除多移 1 个：插入 n-i+1，删除 n-i。插入有 n+1 个可插位置，所以平均 n/2；删除只有 n 个元素可删，所以平均 (n-1)/2。按值查找平均比较 (n+1)/2 次，三者都答 O(n)。

:::

## 三、单链表：指针接力，先接后断

链表用一组**任意的存储单元**存放元素，靠指针建立逻辑关系。结点 = 数据域 + 指针域。它**不能随机存取**，查找必须从表头遍历；但插入删除只需改指针。

### 3.1 判空条件

| 链表类型 | 判空条件 |
| --- | --- |
| 不带头结点 | `L == NULL` |
| 带头结点 | `L->next == NULL` |
| 循环单链表 | `L->next == L` |

### 3.2 核心代码

**单链表插入**：把 s 插到 p 之后，口诀「先接后断」。

```
<code class="language-c">s->next = p->next;    /* 先接：s 接管 p 的后继 */
p->next = s;          /* 后断：p 指向 s；两句顺序不能反 */</code>
```

**单链表删除**：删除 p 的后继结点。

```
<code class="language-c">q = p->next;          /* q 指向被删结点 */
p->next = q->next;    /* 绕过被删结点 */
free(q);              /* 释放空间 */</code>
```

## 四、双链表：插入四句，先解决后继再解决前驱

双链表结点有 prev 和 next 两个指针，找前驱不用从头遍历。把 s 插入 p 之后：

```
<code class="language-c">s->next = p->next;      /* ① s 接管后继 */
p->next->prev = s;      /* ② 后继回指 s */
s->prev = p;            /* ③ s 回指 p */
p->next = s;            /* ④ p 指向 s */</code>
```

::: danger 易错

教材勘误

⚠️ 课件原稿此处印作 `p->next-prev`，漏写了 `->prev` 中的箭头，实际应为 `p->next->prev = s`，请以教材为准。

:::

## 五、按场景选存储结构

| 对比项 | 顺序表 | 链表 |
| --- | --- | --- |
| 存取方式 | 可顺序、可随机存取 | 只能顺序存取 |
| 插入删除 | 移动元素，O(n) | 只改指针，O(1)（定位后） |
| 空间 | 静态分配，易溢出/浪费 | 动态分配，按需申请 |
| 适用场景 | 频繁按位访问、取前驱 | 频繁插入删除、长度变化大 |

## 六、先回忆，再自测

::: details 合上笔记默写：顺序表插入、删除的移动次数公式，以及平均移动次数和按值查找平均比较次数

插入第 i 个位置：n-i+1 个元素后移；删除第 i 个元素：n-i 个元素前移。插入平均移动 n/2，删除平均移动 (n-1)/2，按值查找平均比较 (n+1)/2 次，三者时间复杂度均为 O(n)。

:::

::: details 合上笔记默写：单链表插入、删除的两行/三行代码；双链表插入的四行顺序

单链表插入：s-&gt;next=p-&gt;next; p-&gt;next=s;（顺序不能反）。单链表删除：q=p-&gt;next; p-&gt;next=q-&gt;next; free(q)。双链表插入：s-&gt;next=p-&gt;next; p-&gt;next-&gt;prev=s; s-&gt;prev=p; p-&gt;next=s。

:::

::: details 三种链表判空条件分别是什么？频繁插入删除该选顺序表还是链表？

不带头结点：L==NULL；带头结点：L-&gt;next==NULL；循环单链表：L-&gt;next==L。频繁插入删除选链表；频繁按位访问或取前驱选顺序表。

:::

## 七、测验（点击选项作答）

**1. 长度为 20 的顺序表，在第 5 个位置插入新元素，需要移动的元素个数为**

- A. 14 个元素后移
- B. 16 个元素后移
- C. 15 个元素后移
- D. 17 个元素后移

::: details 点开核对答案

**答案：B（16 个元素后移）** —— 顺序表插入第 i 个位置需移动 n-i+1 个元素：20-5+1=16。注意是「后移」为第 i 个位置腾出空间，不要与删除的 n-i 混淆。

:::

**2. 关于顺序表的平均移动次数，下列说法正确的是**

- A. 插入 n/2 次，删除 n/2 次
- B. 插入 (n-1)/2 次，删除 n/2 次
- C. 插入 n/2 次，删除 (n-1)/2 次
- D. 插入 (n+1)/2 次，删除 n/2 次

::: details 点开核对答案

**答案：C（插入 n/2 次，删除 (n-1)/2 次）** —— 插入有 n+1 个可插入位置，平均 n/2；删除有 n 个元素可删，平均 (n-1)/2。按值查找平均比较 (n+1)/2 次，不要套用到移动次数上。

:::

**3. 单链表中，将结点 s 插入到 p 之后，正确的两句代码是**

- A. p-&gt;next=s; s-&gt;next=p-&gt;next;
- B. s-&gt;next=p-&gt;next; p-&gt;next=s;
- C. s-&gt;next=p; p-&gt;next=s-&gt;next;
- D. p-&gt;next=s-&gt;next; s-&gt;next=p;

::: details 点开核对答案

**答案：B（s-&gt;next=p-&gt;next; p-&gt;next=s;）** —— 口诀「先接后断」：先把 s 的 next 指向 p 原来的后继，再让 p 指向 s。若先执行 p-&gt;next=s，则第二句 s-&gt;next 会指向 s 自己，造成断链。

:::

**4. 双链表中，将结点 s 插入到 p 之后，四句的正确顺序是**

- A. s-&gt;next=p-&gt;next; s-&gt;prev=p; p-&gt;next-&gt;prev=s; p-&gt;next=s;
- B. s-&gt;next=p-&gt;next; p-&gt;next-&gt;prev=s; s-&gt;prev=p; p-&gt;next=s;
- C. p-&gt;next=s; s-&gt;prev=p; s-&gt;next=p-&gt;next; p-&gt;next-&gt;prev=s;
- D. s-&gt;prev=p; p-&gt;next=s; s-&gt;next=p-&gt;next; p-&gt;next-&gt;prev=s;

::: details 点开核对答案

**答案：B（s-&gt;next=p-&gt;next; p-&gt;next-&gt;prev=s; s-&gt;prev=p; p-&gt;next=s;）** —— 口诀「先解决后继结点，再解决前驱结点」：s 接管后继 → 后继回指 s → s 回指 p → p 指向 s。若先改 p-&gt;next，后面再用 p-&gt;next-&gt;prev 就会访问到 s 而非原后继。

:::

**5. 下列关于链表判空条件的说法，正确的是**

- A. 带头结点的链表判空为 L==NULL
- B. 循环单链表判空为 L-&gt;next==NULL
- C. 不带头结点的链表判空为 L-&gt;next==NULL
- D. 循环单链表判空为 L-&gt;next==L

::: details 点开核对答案

**答案：D（循环单链表判空为 L-&gt;next==L）** —— 不带头结点：L==NULL；带头结点：L-&gt;next==NULL；循环单链表：L-&gt;next==L（尾结点 next 回指头结点，形成环）。

:::

**6. 某应用需要频繁对线性表进行插入和删除，且表长变化较大，宜采用的存储结构是**

- A. 顺序表，因其可随机存取
- B. 链表，因其插删只改指针
- C. 顺序表，因其存储密度较高
- D. 链表，因其支持随机存取

::: details 点开核对答案

**答案：B（链表，因其插删只改指针）** —— 频繁插入删除选链表，定位后修改指针即可 O(1)；顺序表插删需移动大量元素。链表不能随机存取，必须顺序遍历，因此 D 错。

:::
