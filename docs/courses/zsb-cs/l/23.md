::: details 温故 · 第 22 课「赫夫曼树与编码」：n 个叶子的赫夫曼树，总结点数是多少？树中有没有度为 1 的结点？

总结点数为 2n−1；不存在度为 1 的结点——每次合并都新增一个度为 2 的内部结点，共新增 n−1 个。

::: details 温故 · 第 21 课「树、森林与二叉树的转换和存储」：树转二叉树的规则是什么？转换后根结点的右子树有何特征？

:::

::: info

为什么现在复习图

图是数据结构「最重」的一章：基本概念、存储、遍历是选择题的常客，而下一课的最小生成树、最短路径、拓扑排序、关键路径全靠这节课的地基。广东专升本卷子里，完全图边数、连通分量、邻接矩阵读度、DFS/BFS 序列都是大题高频区的送分点——先把这节课的「数字」和「口诀」焊死。

:::

## 一、图的基本概念：G=(V, E)

**图 G = (V, E)**：顶点的**有穷非空**集合 V，加上边的集合 E。

- 图中数据元素叫**顶点**，**不允许没有顶点（有穷非空性）**——这一点区别于空表、空树；但**边集可以为空**；
- 线性表元素是一对一，树是层次（一对多）关系，图是**多对多**关系，用**边**表示。

| 概念 | 定义 |
| --- | --- |
| 无向图 / 有向图 | 边都无向 / 边都有向（有向边称**弧** &lt;Vi,Vj&gt;，箭头端为弧头） |
| **无向完全图** | 任意两顶点都有边：**n(n−1)/2 条边** |
| **有向完全图** | 任意两顶点都有方向相反的两条弧：**n(n−1) 条弧** |
| 顶点的度 | 与该顶点相关联的边数；有向图：**度 = 入度 + 出度** |
| 邻接 | 无向边 (V1,V2) 两顶点互为邻接点；**无向边用小括号、有向边用尖括号** |
| 路径 / 回路 | 顶点序列 / 首尾相同的路径 |
| **连通图、连通分量** | 无向图任意两点有路径 = 连通图；**连通分量 = 极大连通子图**（连通图的连通分量是其本身） |
| **强连通图、强连通分量** | 有向图每一对顶点 Vi↔Vj 都有路径；**强连通分量 = 极大强连通子图** |
| 权与网 | 边/弧上的数字叫**权**；**带权图 = 网** |
| **生成树** | 连通图包含全部顶点、任意两点仅一条通路：**边数 = 顶点数 − 1，无环** |
| 生成森林 | 非连通图各连通分量的生成树组成的森林 |

::: info

判断小抄

n 个顶点，边数 **&lt; n−1 → 一定不连通**；**&gt; n−1 → 必有环**。生成树的边数恰好等于顶点数 − 1。

:::

::: info

高频推论

有向图所有顶点出度之和为 s，则所有顶点度数之和为 **2s**（度数和 = 出度和 + 入度和 = s + s）。

:::

## 二、图的存储：邻接矩阵与邻接表

### 2.1 邻接矩阵法

一维数组存顶点信息 + **二维数组（邻接矩阵）存边信息**。

- **无向图**：矩阵**一定对称**；**第 i 行（或第 i 列）的非零元素个数 = 第 i 个顶点的度**；
- **有向图**：**第 i 行非零元 = 出度；第 i 列非零元 = 入度**；
- **网**：无边处用 **∞**（无权图用 0）；
- 空间复杂度 **O(n²)**（与顶点数有关）；n 个顶点 e 条边的无向图占 n² 个存储，有效元 **2e** 个，无效 n²−2e 个。

### 2.2 邻接表法

边数相对较少时邻接矩阵浪费空间 → 对每个顶点建一个**单链表**：表头结点存顶点信息并指向第一个边结点，边结点存邻接顶点序号。

- **无向图**：每条边存两遍；顶点 Vi 的**度 = 该顶点邻接表中边结点个数**；
- **有向图**：边结点个数 = 该顶点的**出度**（求入度需遍历全表或用逆邻接表）。

::: danger 易错

⚠️ 真实缺口提醒

**邻接多重表**出现在考点列表中，但课件未展开讲解；**逆邻接表**也只在「有向图求入度」处一笔带过。这两块本课不展开，记住名字与用途即可，考前以笔记 数据结构/16-图 为准。

:::

## 三、图的遍历：DFS 与 BFS

### 3.1 深度优先遍历 DFS

1. 访问出发点 v，标记已访问；
2. 访问与 v 邻接且未访问的顶点 w；
3. 再选与 w 邻接且未访问的顶点 q……**当某顶点的邻接点全被访问过，依次回退**到最近被访问的顶点，若其还有未访问邻接点则继续。

口诀：**「不撞南墙不回头」**；**借助栈实现**。

### 3.2 广度优先遍历 BFS

1. 访问出发点 v，标记已访问；
2. 访问 v 的所有未访问邻接点，**按序入队列**；
3. 依次出队，访问出队结点的未访问邻接点并入队……直到队空（按层扩展）。

**借助队列**实现。

| 遍历 | 辅助结构 | 过程要点 | 序列唯一性 |
| --- | --- | --- | --- |
| DFS 深度优先 | **栈** | 一路向下，「不撞南墙不回头」，走不动依次回退 | 都**可能不唯一** |
| BFS 广度优先 | **队列** | 按层扩展，出队一个、把它未访问的邻接点按序入队 |   |

::: info

为什么序列不唯一

DFS/BFS 序列都取决于**邻接点的访问次序**，所以同一图的遍历序列可能不唯一；遍历经过的边保留、删去其余边，得到的深度/广度优先生成树也有多种。

:::

## 先回忆，再自测

::: details 无向完全图和有向完全图的边（弧）数各是多少？

无向完全图 n(n−1)/2 条边；有向完全图 n(n−1) 条弧。口诀：有向翻倍——每对顶点要方向相反的两条弧。

:::

::: details 连通分量、强连通分量怎么定义？题眼是哪两个字？

连通分量 = 无向图的**极大**连通子图；强连通分量 = 有向图的**极大**强连通子图。漏掉「极大」两个字就是易错写法。

:::

::: details 邻接矩阵里怎么读度？空间开销多大？

无向图矩阵一定对称，第 i 行（或列）非零元个数 = 度；有向图第 i 行非零元 = 出度、第 i 列非零元 = 入度；空间 O(n²)，n 顶点 e 边的无向图有效元 2e 个。

:::

::: details DFS 与 BFS 分别借助什么结构？口诀是什么？序列唯一吗？

DFS 借助**栈**，口诀「不撞南墙不回头」；BFS 借助**队列**，按层扩展。两种遍历序列都可能不唯一（取决于邻接点访问次序）。

:::

## 测验（点击选项作答）

**1. n 个顶点的有向图，所有顶点出度之和为 s，则所有顶点度数之和为**

- A. s
- B. 2s
- C. 2n
- D. 2e

::: details 点开核对答案

**答案：B（2s）** —— 度数和 = 出度和 + 入度和 = s + s = 2s。别和邻接矩阵的 2e 记混：那是有向图之外、无向图矩阵有效元的结论。

:::

**2. n 个顶点的无向完全图的边数为**

- A. n(n−1)
- B. n(n+1)
- C. n(n−1)/2
- D. n(n+1)/2

::: details 点开核对答案

**答案：C（n(n−1)/2）** —— 无向完全图任意两顶点都有边，共 n(n−1)/2 条；有向完全图才是 n(n−1) 条弧。这是本章最高频的送分公式。

:::

**3. n 个顶点的无向连通图，其连通分量个数为**

- A. 1
- B. 0
- C. n−1
- D. n

::: details 点开核对答案

**答案：A（1）** —— 连通图任意两点间都有路径，其极大连通子图就是整个图本身，所以连通分量个数是 1。

:::

**4. 把 n 个顶点连成一个连通图，至少需要多少条边**

- A. n
- B. n+1
- C. n−1
- D. 2n

::: details 点开核对答案

**答案：C（n−1）** —— 至少 n−1 条，恰好是生成树的边数。判断小抄：边数 &lt; n−1 一定不连通，&gt; n−1 必有环。

:::

**5. n 个顶点 e 条边的无向图，其邻接矩阵中有效元素个数为**

- A. e
- B. n²
- C. n²−2e
- D. 2e

::: details 点开核对答案

**答案：D（2e）** —— 无向图矩阵对称，每条边对应两个有效元素，共 2e 个；无效元是 n²−2e 个，矩阵总占 n² 个存储单元。

:::

**6. n 个顶点 e 条边的有向图，其邻接矩阵中有效元素个数为**

- A. 2e
- B. e
- C. n²−e
- D. n²

::: details 点开核对答案

**答案：B（e）** —— 有向图每条弧只对应矩阵中一个元素，有效元素共 e 个；无向图才是 2e 个。

:::
