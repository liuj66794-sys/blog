::: details 温故 · 第 21 课「树、森林与二叉树的转换和存储」：树的后序遍历等价于转换后二叉树的哪种遍历？树本身有中序遍历吗？

树的后序 ↔ 二叉树的中序。树只有先序和后序两种遍历，没有中序——「树的中序遍历等价于二叉树的什么」这类题干本身就在挖坑。

:::

::: details 温故 · 第 20 课「二叉树的遍历与还原」：用遍历序列还原二叉树的规则是什么？哪些序列组合能唯一还原？

先序/后序定根，中序分左右子树。先序+中序、后序+中序可唯一还原；只给先序+后序不能——必须有中序才能分左右。

:::

::: info

为什么重点讲这个

赫夫曼树是数据结构大题常客，考点非常集中：构造过程、2n−1 个结点、无度为 1 的结点、WPL 计算、前缀编码。巩固阶段不需要面面俱到，但要确保每一步都「手能生巧」。

:::

## 一、赫夫曼树的构造：每次取最小的两棵合并

给定 n 个带权叶子，反复执行：**从当前森林中选出根权值最小的两棵树，合并成一棵新树，新树根的权 = 左右子树根权之和**，直到只剩一棵树。

以笔记中的权 `{1,2,3,4,5}` 为例：

| 步骤 | 选出的两棵 | 合并后新权 | 剩余序列 |
| --- | --- | --- | --- |
| 1 | 1、2 | 3 | {3,3,4,5} |
| 2 | 3、3 | 6 | {4,5,6} |
| 3 | 4、5 | 9 | {6,9} |
| 4 | 6、9 | 15 | {15}（根） |

::: info

构造时的两条纪律

1. 每次只合并**最小的两个**，不是任意两个；2. 合并后要把新权放回序列重新排序，再进入下一轮。很多手算错误都是第二步漏掉「重新参与比较」造成的。

:::

## 二、赫夫曼树的三个特点

| 特点 | 含义 | 考试用法 |
| --- | --- | --- |
| 初始结点全为叶子 | 给定的权值最终都落在叶子层 | WPL 只算叶子，不算内部结点 |
| 权值越小离根越远 | 小权值被压在深层，大权值靠近根 | 频繁字符编码短、少见字符编码长 |
| 无度为 1 的结点 | 每次合并产生一个度为 2 的内部结点 | n 个叶子 ⇒ 总结点数 2n−1 |

::: danger 易错

最高频陷阱

赫夫曼树**不存在度为 1 的结点**；n 个叶子时总结点数是 **2n−1**，不是 2n 或 n+1。反过来，若一棵二叉树有 n 个叶子且无度为 1 的结点，它不一定是赫夫曼树，但赫夫曼树一定满足这两个条件。

:::

## 三、WPL 的计算与验算

**WPL（带权路径长度）** = Σ 权ᵢ × 路径长度ᵢ，其中路径长度是根到该叶子的**边数**。

仍用 `{1,2,3,4,5}`：1、2 的深度为 3；3、4、5 的深度为 2。

```
<code>WPL = 1×3 + 2×3 + 3×2 + 4×2 + 5×2 = 33</code>
```

::: info

快速验算技巧

赫夫曼树的 WPL 也等于**所有内部结点权值之和**：3 + 6 + 9 + 15 = 33。大题算出 WPL 后，用这个办法复核一遍，能避免手算漏项。

:::

## 四、赫夫曼编码：左 0 右 1，从根到叶

赫夫曼编码是一种**前缀编码**：任何字符的编码都不是另一个编码的前缀，所以解码没有歧义。生成规则：

1. 把字符出现频率作为权值构造赫夫曼树；
2. 从根出发，**左分支标 0，右分支标 1**（也可反过来，但题目通常约定左 0 右 1）；
3. 从根到叶子的路径上的 0/1 序列就是该字符的编码。

笔记中的经典例子（a,b,c,d,e,f 频度 45,13,12,16,9,5）：

| 字符 | 频度 | 赫夫曼编码 |
| --- | --- | --- |
| a | 45 | 0 |
| c | 12 | 100 |
| b | 13 | 101 |
| f | 5 | 1100 |
| e | 9 | 1101 |
| d | 16 | 111 |

::: danger 易错

⚠️ 编码易错点

同一个构造过程，如果某次合并时两个子树的左右位置交换，得到的 0/1 编码会不同，但仍然是正确的赫夫曼编码（WPL 不变）。考试画图时只要** consistently 左 0 右 1 **即可，不要死记某一个编码表。

:::

## 五、先回忆，再自测

::: details 合上笔记默写：n 个叶子的赫夫曼树，总结点数是多少？有没有度为 1 的结点？

总结点数为 2n−1；不存在度为 1 的结点。因为每次合并都新增一个度为 2 的内部结点，共新增 n−1 个。

:::

::: details WPL 的两种算法分别是什么？

算法一：Σ 每个叶子的权值 × 根到该叶子的路径长度（边数）。算法二：所有内部结点权值之和。两个结果应相等，可互相验算。

:::

::: details 什么叫前缀编码？赫夫曼编码为什么一定是前缀编码？

前缀编码指任意编码都不是另一编码的前缀。赫夫曼编码中所有字符都在叶子，而叶子路径不可能互相成为前缀，所以天然满足前缀编码。

:::

## 六、测验（点击选项作答）

**1. n 个叶子的赫夫曼树，其结点总数为**

- A. 共有 n+1 个结点
- B. 共有 2n−1 个结点
- C. 共有 2n 个结点
- D. 共有 2n+1 个结点

::: details 点开核对答案

**答案：B（共有 2n−1 个结点）** —— n 个叶子 + (n−1) 个合并产生的内部结点 = 2n−1；且每次合并都产生度为 2 的结点，故无度为 1 的结点。

:::

**2. 以权 {2,3,5,7,8} 构造赫夫曼树，其 WPL 为**

- A. 45
- B. 50
- C. 55
- D. 60

::: details 点开核对答案

**答案：C（55）** —— 构造过程：2+3=5，5+5=10，7+8=15，10+15=25。WPL = 2×3+3×3+5×2+7×2+8×2 = 55，也等于内部结点和 5+10+15+25=55。

:::

**3. 关于赫夫曼树的性质，下列说法正确的是**

- A. 树中一定存在度为 1 的结点
- B. 权值较小的叶子离根较近
- C. 叶子结点数等于初始权值个数
- D. 总结点数恒为 2n 个

::: details 点开核对答案

**答案：C（叶子结点数等于初始权值个数）** —— 初始给定的权值最终都成为叶子，所以叶子数等于初始权值个数；权值越小离根越远；总结点数为 2n−1 且无度为 1 的结点。

:::

**4. 下列编码组中，属于前缀编码的是**

- A. {0, 1, 01, 10}
- B. {0, 10, 110, 111}
- C. {0, 01, 011, 0111}
- D. {10, 110, 101, 1001}

::: details 点开核对答案

**答案：B（{0, 10, 110, 111}）** —— 前缀编码要求任一编码不是另一编码的前缀。B 中 0、10、110、111 互不前缀；其余选项中均存在前缀关系（如 A 中 0/1 是 01/10 的前缀）。

:::

**5. 笔记中 a,b,c,d,e,f 频度分别为 45,13,12,16,9,5，字符 c 的赫夫曼编码是**

- A. 0
- B. 101
- C. 100
- D. 111

::: details 点开核对答案

**答案：C（100）** —— 按笔记给出的编码表：a:0，c:100，b:101，f:1100，e:1101，d:111。注意同一构造过程若左右子树交换，编码会不同，但 WPL 不变。

:::

**6. 关于 WPL 的计算，下列说法正确的是**

- A. WPL 是所有结点的带权路径长度之和
- B. 路径长度按结点个数而不是边数计算
- C. 赫夫曼树的 WPL 不一定最小
- D. WPL 可用内部结点权值之和验证

::: details 点开核对答案

**答案：D（WPL 可用内部结点权值之和验证）** —— WPL 只算叶子；路径长度是边数；赫夫曼树就是 WPL 最小的二叉树。内部结点权值之和等于 WPL，是常用的验算方法。

:::
