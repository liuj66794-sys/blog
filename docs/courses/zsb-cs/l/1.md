## 一、四步骤与三个扩展名

C 程序的实现经过 **编辑 → 编译 → 连接 → 运行** 四步（注意：是四步，不是五步——题干把「执行」拆开数就是错的）：

| 步骤 | 产物 | 文件性质 | 这一步做什么 |
| --- | --- | --- | --- |
| 编辑 | `.c` 源程序 | 文本文件 | 把源程序输入计算机存盘 |
| 编译 | `.obj` 目标程序 | 二进制 | 词法分析 + 语法分析，报错定位 |
| 连接 | `.exe` 可执行程序 | 二进制 | 把目标程序与库文件连接 |
| 运行 | 运行结果 | — | 运行 .exe 得到结果 |

::: danger 易错

最高频陷阱

源程序（.c）和目标程序（.obj）都**不能**被计算机直接执行，**只有 .exe 能**。同理：能被计算机直接执行的**语言**只有机器语言；C 是高级语言，必须先编译。

:::

## 二、配套的三组判断

**C 的诞生**：由 Denis M. Ritchie（丹尼斯·里奇）于 **1972—1973 年**在美国**贝尔实验室**设计（常考判断/选择）。

**语言三代**：机器语言 → 汇编语言 → 高级语言；机器 + 汇编统称**低级语言**（都依赖具体机器）。高级语言分两种翻译方式：**解释**（边翻译边执行，不产生目标程序）和**编译**（整体翻译成目标程序，再连接成可执行文件）——C 属于编译方式。

**main 函数**：有且**只有一个**，是程序的入口和出口；程序总是从 main 开始执行，与 main 写在什么位置无关。每个函数由**函数头 + 函数体**两部分组成，函数之间是**平行**关系，不能嵌套定义。

**注释**：`//` 到换行符结束、不能跨行；`/* */` 可跨行。注释**不参与编译**，编译器不会发现注释里的任何错误。另外记住：C 本身**没有输入/输出语句**，I/O 靠 scanf/printf 库函数完成。

## 四、测验（点击选项作答）

**1. 下列文件中，能被计算机直接执行的是**

- A. 扩展名为 .c 的源程序文件
- B. 扩展名为 .obj 的目标文件
- C. 扩展名为 .exe 的可执行文件
- D. 扩展名为 .h 的头文件

::: details 点开核对答案

**答案：C（扩展名为 .exe 的可执行文件）** —— 只有可执行文件能直接运行；.c 是文本、.obj 是二进制目标文件，都要先经过后续步骤。

:::

**2. C 源程序经过「编译」这一步后得到的产物是**

- A. 可直接运行的可执行文件
- B. 需再连接的目标程序
- C. 逐句翻译的解释结果
- D. 包含库函数的可执行程序

::: details 点开核对答案

**答案：B（需再连接的目标程序）** —— 编译产生 .obj 目标程序，它不能单独执行，必须由连接程序与库文件连接成 .exe。

:::

**3. 关于 C 程序的执行起点，正确的是**

- A. 总是从 main 函数开始执行
- B. 从最前面的函数开始执行
- C. 从最后面的函数开始执行
- D. 从预处理命令开始执行

::: details 点开核对答案

**答案：A（总是从 main 函数开始执行）** —— 与 main 的位置无关，程序永远从 main 开始；main 有且只有一个，是入口也是出口。

:::

**4. 关于注释，下列说法正确的是**

- A. 单行注释可以跨越多行书写
- B. 编译器能发现注释中的错误
- C. 注释中的语句会被编译执行
- D. 块注释可以跨越多行书写

::: details 点开核对答案

**答案：D（块注释可以跨越多行书写）** —— &lt;code&gt;//&lt;/code&gt; 到换行符止，不能跨行；&lt;code&gt;/* */&lt;/code&gt; 可跨行。注释不参与编译。

:::

**5. 机器语言和汇编语言统称为**

- A. 高级语言，不依赖具体机器
- B. 低级语言，依赖具体机器
- C. 符号语言，可移植性很好
- D. 自然语言，易学易读易修改

::: details 点开核对答案

**答案：B（低级语言，依赖具体机器）** —— 机器 + 汇编 = 低级语言，都依赖具体计算机，难学难用；汇编又称符号语言，但它仍属低级语言。

:::

**6. C 语言的输入/输出功能是依靠什么实现的**

- A. 属于 C 语言关键字的输入输出命令
- B. 编译器自带的输入输出语句
- C. scanf 和 printf 等库函数
- D. 预处理命令提供的输入输出

::: details 点开核对答案

**答案：C（scanf 和 printf 等库函数）** —— C 本身没有 I/O 语句，靠库函数完成——这正是它移植性好的原因之一。

:::
