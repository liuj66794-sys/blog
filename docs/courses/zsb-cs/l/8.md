## 一、一维数组：定义、初始化与数组名

定义格式：`类型 数组名[常量表达式];`，例如 `int a[8];`。元素为 `a[0] ~ a[7]`，**下标从 0 开始**。

| 要点 | 正确 | 错误 |
| --- | --- | --- |
| 数组大小 | 必须是常量或常量表达式，如 `8`、`2+6` | `int a[n];`（n 变量）、`int a[2.3];` |
| 初始化 | `int a[5]={1,2,3};` 剩余自动补 0 | 列表个数超过长度会警告；不指定长度又不初始化会报错 |
| 引用 | `a[0]`、`a[i]`、`a[1+1]` | `a[2.3]`、`a[-1]`（越界不报错） |

::: info

记忆口诀

「初始化则值确定，部分赋值补成零；省略长度要数列，不初不省编译停。」

:::

**数组名 = 首元素地址 = &a[0]**，因此数组名是**地址常量**：`a++`、`a=a+1` 非法；但 `a+i` ≡ `&a[i]` 合法，且 `a+1` 实际加的是 `sizeof(元素类型)` 字节，不是 1 字节。

## 二、二维数组：可省行不可省列

定义：`int a[3][3];` 逻辑上是 3 行 3 列，内存中仍是连续线性存储。可以把 `a` 看成由 3 个「行数组」组成的一维数组，`a[0]` 又是第一行 3 个元素的数组名。

| 初始化写法 | 结果 |
| --- | --- |
| `int a[2][3]={{1,2,3},{4,5,6}};` | 分行初始化，最直观 |
| `int a[2][3]={1,2,3,4,5,6};` | 平铺填充（易漏，不推荐） |
| `int a[2][3]={{1},{2,3}};` | 第 1 行 1,0,0；第 2 行 2,3,0 |
| `int a[][3]={1,2,3,4,5,6,7};` | ⌈7/3⌉=3 行，第三行 7,0,0 |
| `int a[][3]={{1,2},{},{1,2,3}};` | 行数 = 内层花括号个数 = 3 |

::: danger 易错

高频陷阱

二维数组**第一维（行数）可以省略，第二维（列数）不可省**。`int a[3][]` 是错的。元素 `a[i][j]` 之前有 **i×N+j** 个元素，主对角线 `i==j`，副对角线 `i+j==N-1`。

:::

## 三、冒泡排序的精确计数

升序冒泡：相邻两元素比较，前面大于后面就交换，每一趟把当前最大数沉到末尾。

```
<code>for(i = 0; i < n-1; i++)          /* 趟数：n-1        */
    for(j = 0; j < n-1-i; j++)    /* 每趟：n-1-i 次   */
        if(a[j] > a[j+1])
        { t = a[j]; a[j] = a[j+1]; a[j+1] = t; }
</code>
```

::: info

课件修订版公式

n 个数比较 **n-1 趟，第 x 趟比较 n-x-1 次**。例如 4 个数：第 0 趟比 3 次，第 1 趟比 2 次，第 2 趟比 1 次。注意「第 x 趟」从 0 开始计数。

:::

## 四、字符数组与字符串

C 没有字符串类型，用字符数组或指针存放字符串。**只有用字符串初始化时才自动追加 '\0'**。

| 写法 | 长度 | 内容 |
| --- | --- | --- |
| `char c[] = "abc";` | 4 | a b c '\0' |
| `char c[5] = {'a','b','c'};` | 5 | a b c '\0' '\0'（部分初始化补 '\0'） |
| `char c[5] = {'a','b','c','d','e'};` | 5 | 逐字符初始化，**无 '\0'** |

::: danger 易错

strlen 与 sizeof 的本质区别

`strlen` 统计字符个数，**不含 '\0'**，遇到 '\0' 就停止；`sizeof` 求变量占用的总字节数，**含 '\0'**。例如 `char c[]="abc";`：strlen(c)=3，sizeof(c)=4。

:::

## 五、六大字符串处理函数

| 函数 | 头文件 | 核心考点 |
| --- | --- | --- |
| `puts` | stdio.h | 输出字符串并**自动换行**，只能一个参数 |
| `gets` | stdio.h | 输入字符串，**空格也收入**，只能一个参数 |
| `strcat` | string.h | 把串 2 接到串 1 后，**数组 1 必须足够大** |
| `strcpy` | string.h | 复制串 2 到数组 1，解决数组名不能整体赋值的问题 |
| `strcmp` | string.h | 按 ASCII 逐字符比较，返回正/0/负；字符串**不能用关系运算符**比较 |
| `strlen` | string.h | 测长度不含 '\0'；涉及字节/内存空间用 sizeof |

::: info

输入细节

`scanf("%s", c);` 中 `c` 本身就是地址，不能写成 `&c`；`scanf` 遇空格停止，`gets` 可收空格。

:::

## 六、先回忆，再自测

::: details 合上笔记默写：数组名是什么？a++ 为什么非法？a+1 实际加多少字节？

数组名是首元素地址（&a[0]），属于地址常量，因此 a++、a=a+1 都会改变常量，非法。a+1 实际加 sizeof(元素类型) 字节，对 int 数组就是 4 字节。

:::

::: details 默写二维数组的「可省」规则和 a[i][j] 位置公式

二维数组初始化时，第一维（行数）可以省略，第二维（列数）不可省。a[i][j] 之前有 i×N+j 个元素，它是第 i×N+j+1 个元素。主对角线 i==j，副对角线 i+j==N-1。

:::

::: details 对比 strlen 与 sizeof；字符串比较为什么不能直接用 >、==？

strlen 测长度不含 '\0'，sizeof 求占用字节数含 '\0'。数组名是地址常量，用关系运算符比较字符串实际上是在比较两个地址，不是比较字符内容，必须用 strcmp。

:::

## 四、测验（点击选项作答）

**1. 下列数组定义或初始化中，合法的是**

- A. int a[n];（n 为变量）
- B. int a[2.3];
- C. int a[5] = {0};
- D. int a[];

::: details 点开核对答案

**答案：C（int a[5] = {0};）** —— 数组大小必须是常量表达式且为整型；不指定长度又不初始化会报错。int a[5]={0} 是标准全零写法。

:::

**2. 关于数组名的说法，正确的是**

- A. 数组名是变量，a++ 合法
- B. a+i 等价于 &a[i]
- C. a+1 实际只加 1 个字节
- D. a = a+1 可以改变数组位置

::: details 点开核对答案

**答案：B（a+i 等价于 &a[i]）** —— 数组名是地址常量，a++、a=a+1 均非法；a+1 实际加 sizeof(元素类型) 字节；a+i 与 &a[i] 等价。

:::

**3. n 个数进行冒泡排序，比较趟数与第 x 趟次数为**

- A. n 趟，第 x 趟 n-x 次
- B. n-1 趟，第 x 趟 n-x-1 次
- C. n 趟，第 x 趟 n-x-1 次
- D. n-1 趟，第 x 趟 n-x 次

::: details 点开核对答案

**答案：B（n-1 趟，第 x 趟 n-x-1 次）** —— 课件修订版公式：n 个数比较 n-1 趟，第 x 趟比较 n-x-1 次。注意 x 从 0 开始。

:::

**4. 对于 int a[][3]={1,2,3,4,5,6,7}，第一维与第三行分别是**

- A. 2 行，第三行 7,0,0
- B. 3 行，第三行 7,0,0
- C. 3 行，第三行 0,0,7
- D. 2 行，第三行 0,0,7

::: details 点开核对答案

**答案：B（3 行，第三行 7,0,0）** —— 省略第一维时按 ⌈元素总数/列数⌉ 计算：⌈7/3⌉=3 行。按行优先填充，第三行只有 7，其余补 0。

:::

**5. char c[]="abc"; 与 char d[5]={'a','b','c'}; 的长度和内容区别是**

- A. c 长 3，d 长 3，都无 '\0'
- B. c 长 4，d 长 3，都含 '\0'
- C. c 长 3，d 长 5，都含 '\0'
- D. c 长 4，d 长 5，都含 '\0'

::: details 点开核对答案

**答案：D（c 长 4，d 长 5，都含 '\0'）** —— 字符串初始化自动加 '\0'，故 c 为 4 字节；d 指定长度 5 且部分初始化，剩余补 '\0'，长度 5。

:::

**6. 执行 strcmp("abc", "Abc") 的返回值是**

- A. 负数
- B. 正数
- C. 0
- D. 无法确定

::: details 点开核对答案

**答案：B（正数）** —— strcmp 按 ASCII 逐字符比较，'a'(97) &gt; 'A'(65)，所以第一个字符已分出大小，返回正数。

:::
