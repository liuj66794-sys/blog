## 一、关系与逻辑表达式：值只有 0 或 1

关系运算符有 6 个，**左结合**，分两个优先级：

| 档次 | 运算符 | 优先级 | 记忆 |
| --- | --- | --- | --- |
| 高 | `> >= < <=` | 6 | 先算大小 |
| 低 | `== !=` | 7 | 再算相等 |

完整优先级链（高 → 低）：

```
<code>!  →  算术(* / % + -)  →  关系(> >= < <= == !=)  →  &&  →  ||  →  赋值(=)</code>
```

::: danger 易错

最高频陷阱

关系/逻辑表达式的值**只有 0 或 1**，不是 true/false；C 语言里非 0 即真。数学式 `10 < a < 15` 在 C 中是 `(10 < a) < 15`，结果恒为 1；判断范围必须写 `a > 10 && a < 15`。

:::

例（a=10, b=20, c=30）：

- `a < b < c` → `(a < b) < c` → `1 < 30` → **1**
- `a + b >= c` → `30 >= 30` → **1**
- `'a' == 'b'` → `97 == 98` → **0**

## 二、短路规则：右侧可能「白写」

| 运算符 | 短路条件 | 结果 |
| --- | --- | --- |
| `&&` | 左侧为 0（假） | 右侧**不执行**，整体为 0 |
| `\|\|` | 左侧非 0（真） | 右侧**不执行**，整体为 1 |

::: info

判断口诀

`&&`「一假俱假」；`||`「一真皆真」。只要左边已经能决定结果，右边就直接跳过——所以右边的自增、赋值、函数调用可能根本不发生。

:::

例：

- `b && a++`（b=0）：值为 0，`a++` 不执行。
- `a || b++`（a=10）：值为 1，`b++` 不执行。
- `!a + 0 && b || c++`（a=0, b=1, c=0）：`((!a + 0) && b) || c++` → `(1 && 1) || c++` → `1 || …` → 值 **1**，`c++` 被短路，**c 仍为 0**。

::: danger 易错

⚠️ 勘误提醒

部分旧版题库对含短路的答案有误。例如 `(m=a==b)||(n=c==d)` 在全零变量下，`m=1`、`||` 左真短路，`n` 保持 0，答案为 `1,0`。遇到与笔记结论冲突的旧答案，以源笔记为准。

:::

## 三、if 单分支、双分支与多分支

```
<code>// 单分支
if (表达式) 语句;

// 双分支
if (表达式) 语句1;
else       语句2;

// 多分支（分段函数常用）
if (表达式1) 语句1;
else if (表达式2) 语句2;
else if (表达式3) 语句3;
else              语句4;</code>
```

注意：

- if 的「内嵌语句」只能有**一条**；多条必须用 `{ }` 包成复合语句。
- else 前面**必须紧邻同一条 if**，中间不能隔别的语句，否则报错 `else without a previous if`。
- 多分支从上到下匹配，**只执行其中一条**。

分段函数示例（符号函数）：

```
<code>if (x > 0)      y = 1;
else if (x == 0) y = 0;
else            y = -1;</code>
```

## 四、条件等价与 else 配对

| 写法 | 等价形式 | 含义 |
| --- | --- | --- |
| `if (x)` | `if (x != 0)` | x 非零则执行 |
| `if (!x)` | `if (x == 0)` | x 为零则执行 |

「零值」陷阱表：

| 表达式 | 逻辑值 | 说明 |
| --- | --- | --- |
| `0`、`0.0`、`NULL`、`'\0'` | 0 | 真正的「零」 |
| `'0'`、`"0"` | 1 | 字符 '0' 的 ASCII 是 48 |

::: danger 易错

两个致命混淆

`if (a = 0)` 是赋值，结果恒为 0，条件恒不成立；`if (a = b)` 把 b 赋给 a，条件值是 b 的逻辑值。比较必须用 `==`。

:::

**else 配对规则**：C 规定 else 总是与它**前面最近的、尚未配对的 if** 配对，**与缩进无关**。花括号可以把内层 if-else 包起来，让外层 else 与更外层的 if 配对。

## 五、先回忆，再自测

::: details 合上笔记默写：优先级链（从 ! 到赋值）和短路规则

优先级：! &gt; 算术 &gt; 关系 &gt; && &gt; || &gt; 赋值。短路：&& 左假右不算；|| 左真右不算。右侧的自增/自减/赋值可能不执行。

:::

::: details if(x) 与 if(!x) 分别等价于什么？写错会发生什么？

`if(x)` ≡ `if(x!=0)`；`if(!x)` ≡ `if(x==0)`。把 `==` 写成 `=` 会变成赋值，导致条件恒真或恒假。

:::

::: details else 配对看缩进还是看语法？如何用花括号改变配对？

else 与前面最近的未配对 if 配对，和缩进无关。用 `{ }` 把内层 if-else 包住，可让外层 else 只能与更外层的 if 配对。

:::

## 六、测验（点击选项作答）

**1. 下列运算符中优先级最低的是**

- A. 逻辑与 &&
- B. 等于 ==
- C. 不等于 !=
- D. 逻辑或 ||

::: details 点开核对答案

**答案：D（逻辑或 ||）** —— 优先级：关系（6/7 级）&gt; &&（11 级）&gt; ||（12 级），四者中 || 最低。赋值比 || 还低，但不在选项中。

:::

**2. 执行 `int a=1,b=2; (a=0)&&(b++);` 后，a、b 的值分别是**

- A. a=0, b=2
- B. a=0, b=3
- C. a=1, b=2
- D. a=1, b=3

::: details 点开核对答案

**答案：A（a=0, b=2）** —— &lt;code&gt;a=0&lt;/code&gt; 使 && 左侧为 0，发生短路，右侧 &lt;code&gt;b++&lt;/code&gt; 不执行，故 b 仍为 2。

:::

**3. 已知 a=0,b=1,c=0，表达式 `!a+0 && b || c++` 的值及 c 的最终值为**

- A. 0，c=0
- B. 1，c=0
- C. 1，c=1
- D. 0，c=1

::: details 点开核对答案

**答案：B（1，c=0）** —— 按优先级加括号：&lt;code&gt;((!a+0) && b) || c++&lt;/code&gt; → &lt;code&gt;(1 && 1) || c++&lt;/code&gt; → &lt;code&gt;1 || …&lt;/code&gt;，|| 左真短路，c++ 不执行，表达式值为 1。

:::

**4. 下列写法中，与 `if(x)` 功能不同的是**

- A. if(x!=0)
- B. if(!x==0)
- C. if(x==0)
- D. if(x&gt;0||x&lt;0)

::: details 点开核对答案

**答案：C（if(x==0)）** —— &lt;code&gt;if(x)&lt;/code&gt; 等价于 &lt;code&gt;if(x!=0)&lt;/code&gt;；B 中 &lt;code&gt;!x==0&lt;/code&gt; 即 x 非零；D 对整数也等价。C 在 x 为零时才执行，与原式相反。

:::

**5. 当 a=1,b=3,c=5,d=4 时，执行下面程序段后 x 的值是**

- A. 1
- B. 2
- C. 3
- D. 7

::: details 点开核对答案

**答案：B（2）** —— a&lt;b 成立 → c&lt;d（5&lt;4）不成立 → 进入 else → a&lt;c（1&lt;5）成立 → b&lt;d（3&lt;4）成立 → x=2。

:::

**6. 阅读下列代码，输出结果是**

- A. 输出 A
- B. 输出 B
- C. 输出 AB
- D. 编译错误

::: details 点开核对答案

**答案：A（输出 A）** —— else 与最近的未配对 if（即 &lt;code&gt;if(x==3)&lt;/code&gt;）配对。x&gt;y 成立且 x==3 成立，执行 printf("A")，else 分支不执行。

:::
