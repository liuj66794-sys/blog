## 01 / 变量、地址与指针

这一节只解决一件事：分清 `a`、`&a`、`p` 和 `*p`。

::: details 基础补充：变量、赋值和声明分别是什么？

`int a = 10;` 声明一个名叫 a 的整数变量，并把初值设为 10。之后的 `a = 20;` 是修改已经存在的变量。赋值号 `=` 表示把右边的值存到左边指定的位置，不是数学里的“相等”。

:::

### 先把内存想成有编号的储物格

变量 a 像一个储物格，里面放着整数 10；地址像格子的编号。另一张放在格子 p 里的纸条，写着 a 的编号。根据纸条找到 a，就是“通过指针访问变量”。

正式地说，**指针变量保存指针值，可以指向某个对象**。本课先讨论指向 int 变量的指针。地址示意图只画对象之间的关系，不假定你的电脑使用某个固定地址。

```
int a = 10;
int *p = &a;
```

1. `int a = 10;`：创建变量 a，值为 10。
2. `&a`：取出 a 的地址；此处 `&` 读作“取地址”。
3. `int *p`：声明 p 是指向 int 的指针。这里的星号是声明的一部分，并没有读取某个变量。
4. `= &a`：把 a 的地址保存到 p 中。现在 p 指向 a。

| 表达式 | 读法 | 当前含义 |
| --- | --- | --- |
| `a` | a 中的值 | 10 |
| `&a` | a 的地址 | 找到 a 所需的位置 |
| `p` | p 中保存的指针值 | 与 &a 相同，指向 a |
| `*p` | 沿着 p 访问它指向的变量 | 访问 a；读取时得到 10 |

**解引用（dereference）**就是沿指针访问目标。在表达式 `*p` 中，星号才是解引用运算符。`p` 与 `*p` 不能互换：一个是指针值，一个用于访问它指向的对象。

::: details 核对：为什么 *p 与 a 都能读到 10？

因为 p 保存的是 a 的地址。两种写法访问的是同一个变量，并没有把 10 再复制成一个独立的 int 变量。

:::

::: details 深入一点：&p 是什么？

p 自己也是一个变量，也有存储位置。`&p` 是 p 自身的地址，`p` 中保存的则是 a 的地址。先记住这两者不是一回事；二级指针留待后续学习。

:::

## 02 / 改值，还是改指向

读赋值语句时，先看左边：是 `p`，还是 `*p`？

```
int a = 10;
int b = 30;
int *p = &a;
*p = 20;
p = &b;
*p = 40;
```

`*p = 20;` 的左边是“p 指向的变量”。此时它是 a，所以把 a 改成 20。随后 `p = &b;` 的左边是 p 自己，改的是指向，a 和 b 的值都不因此改变。最后再执行 `*p = 40;`，被修改的便是 b。

| 执行完的语句 | a | b | p 指向 |
| --- | --- | --- | --- |
| `int *p = &a;` | 10 | 30 | a |
| `*p = 20;` | 20 | 30 | a |
| `p = &b;` | 20 | 30 | b |
| `*p = 40;` | 20 | 40 | b |

::: details 安全边界：还不知道指向哪里时怎么办？

`int *p;` 定义的自动局部指针没有被初始化，不能直接用 `*p = 10;` 写入。可以先让它指向一个仍然存在、类型合适的变量。

也可以在包含 `<stddef.h>` 等提供 NULL 的头文件后写 `int *p = NULL;`，表示暂不指向对象。**空指针不代表一个可以读写的“零号储物格”**；它也不能被解引用。`int *p = 0;` 同样初始化为空指针。

本课直接用 `int *` 指向 int 变量。不要把 `float *` 直接初始化为 int 变量的地址，再按 float 读写。

:::

## 03 / 指针怎样走过数组

把“算地址”和“访问元素”分成两步。

```
int a[3] = {10, 20, 30};
int *p = a;
int value = *(p + 1);
```

数组的三个元素连续存放，下标从 0 开始。在 `int *p = a;` 这种表达式中，a 转换为指向首元素的指针，与 `&a[0]` 对应。因此 p 最初指向 a[0]。

1. `p + 1`：从当前元素算出下一个元素的地址。**这个表达式没有修改 p**。
2. `*(p + 1)`：访问该地址对应的元素 a[1]，读取时得到 20。
3. 把 20 存入 value。此时 p 仍然指向 a[0]。

| 地址写法 | 访问值的写法 | 结果（p 仍指向 a[0]） |
| --- | --- | --- |
| `p` / `&a[0]` | `*p` / `a[0]` | 10 |
| `p + 1` / `&a[1]` | `*(p + 1)` / `p[1]` | 20 |
| `p + 2` / `&a[2]` | `*(p + 2)` / `p[2]` | 30 |

指针加 1 按一个目标元素前进。若本题约定 `sizeof(int) == 4`，相邻 int 元素相隔 4 字节；不要把“int 永远占 4 字节”当成 C 语言的保证。

### 再看一个完整循环

```
for (int i = 0; i < 3; i++) {
    printf("%d ", *(p + i));
}
```

在 p 指向 a[0] 的前提下，i 依次是 0、1、2，于是依次输出 10、20、30。每轮变化的是 i，p 没有被赋新值。

::: details 边界与易混点：a 是指针变量吗？

a 是数组，不是可以随意改指向的指针变量，所以不能写 `a++`。数组名在许多表达式中会转换为指向首元素的指针，但 `sizeof a` 得到整个数组的大小，`&a` 则是指向整个数组的指针。

可以形成尾后指针 `a + 3` 用于比较，但本数组没有 a[3]，不能解引用它。同数组内指针相减得到相隔的元素个数；不要拿两个无关数组的指针做这种减法。

:::

## 04 / 看懂三个自增表达式

先补括号，再检查自增作用于指针还是元素，最后记录语句执行后的状态。

下面每一行都是**独立实验**：重新从 `int a[3] = {10,20,30}; int *p = a;` 开始，使用 `int result = 表达式;` 接住结果。

| 表达式 | 补括号 | result | 语句结束后 |
| --- | --- | --- | --- |
| `*p++` | `*(p++)` | 10 | p 指向 a[1]；元素不变 |
| `*++p` | `*(++p)` | 20 | p 指向 a[1]；元素不变 |
| `(*p)++` | `(*p)++` | 10 | a[0] 变成 11；p 不变 |
| `++(*p)` | `++(*p)` | 11 | a[0] 变成 11；p 不变 |

`*(p++)` 使用自增前的指针值找到元素，同时让 p 在本完整表达式结束前前进；`*(++p)` 使用自增后的指针值。`(*p)++` 的括号把被自增的对象明确成了数组元素。

::: details 遇到这类题，按哪三问检查？

1. 自增的是 p，还是 *p？
2. 表达式取自增前的值，还是自增后的值？
3. 语句结束时，p 的指向和数组内容各是什么？

不要在同一个复杂表达式里对同一变量进行多次未排序的读写。初学时拆成单独语句更容易判断，也避免把未定义行为当作固定输出。

:::

## 05 / 为什么 swap 要用指针

理解“传入地址的副本”为什么仍能修改外面的变量。

::: details 基础补充：形参是实参值的副本

C 的函数参数按值传递。调用 `f(a)` 时，形参拿到 a 的值；只改形参，不会改 a。调用 `f(&a)` 时，形参拿到 a 地址的副本；沿这个地址仍能访问外面的 a。

:::

```
void swap(int *x, int *y) {
    int t = *x;
    *x = *y;
    *y = t;
}

/* 在 main 中 */
int a = 10, b = 20;
swap(&a, &b);
```

1. 调用时把 a、b 的地址分别复制给 x、y。于是 x 指向 a，y 指向 b。
2. `int t = *x;`：先把 a 原来的值 10 备份到 t，防止下一步覆盖后丢失。
3. `*x = *y;`：读取 b 的值 20，写入 a。此时 a、b 都是 20。
4. `*y = t;`：把备份的 10 写入 b。交换完成，a 为 20、b 为 10。

### 为什么另外两种写法不行？

| 函数内部做的事 | 实际改变 | 调用者中的 a、b |
| --- | --- | --- |
| `int t=x; x=y; y=t;`（x、y 是 int） | 两个整数形参副本 | 不变 |
| `int *t=x; x=y; y=t;`（x、y 是 int*） | 两个指针形参的指向 | 不变 |
| `int t=*x; *x=*y; *y=t;` | 指针指向的外部变量 | 交换 |

::: details 迁移到数组参数：为什么函数内改 arr[i] 会生效？

数组实参在这里转换为首元素指针，函数形参得到这个指针值的副本。`arr[i]` 沿它访问原数组元素，所以赋值会改变原数组。形参得到的不是整个数组副本，也不会自动携带数组长度；长度通常另传。

:::

## 06 / 换一道题自己做

先独立预测。卡住时只展开一条提示，再继续尝试。

```
int a[3] = {2, 4, 6};
int *p = a;
int x = *p++;
*p = x + 5;
int y = *(p + 1);
```

执行后，x、y、数组 a 的内容分别是什么？p 指向哪个元素？

::: details 提示 1：先补括号

`*p++` 是 `*(p++)`。x 取原来 p 指向的元素，语句结束时 p 前进一个元素。

:::

::: details 提示 2：写出第三行结束时的状态

x 为 2，p 指向 a[1]，数组仍是 {2,4,6}。接下来 `*p = x + 5;` 修改哪一格？

:::

::: details 完整推演：做完后再核对

| 执行完 | x | y | a | p 指向 |
| --- | --- | --- | --- | --- |
| `int *p = a;` | 尚未声明 | 尚未声明 | {2,4,6} | a[0] |
| `int x = *p++;` | 2 | 尚未声明 | {2,4,6} | a[1] |
| `*p = x + 5;` | 2 | 尚未声明 | {2,7,6} | a[1] |
| `int y = *(p + 1);` | 2 | 6 | {2,7,6} | a[1] |

最后一步的 p+1 只是计算地址，没有修改 p。这里的下标以 p 的当前位置为起点，不是重新从 a[0] 开始。

:::

### 把它变成能运行的程序

```
#include <stdio.h>
int main(void) {
    int a[3] = {2, 4, 6};
    int *p = a;
    int x = *p++;
    *p = x + 5;
    int y = *(p + 1);
    printf("x=%d y=%d a={%d,%d,%d}\n", x, y, a[0], a[1], a[2]);
    return 0;
}
```

预期输出：`x=2 y=6 a={2,7,6}`。先手算，再在你现有的 C 环境中运行核对。

::: details 再练一题：把 *p = x + 5 改成 p = a + 2，会怎样？

只看替换后的这一句：p 改为指向 a[2]，数组保持 {2,4,6}。但若继续执行原来的 `int y = *(p + 1);`，就会解引用尾后指针，产生未定义行为，不能预测一个固定输出。应先检查访问边界。

:::

复习时，尝试用自己的话解释：p 与 *p 有什么区别；p+1 是否改变 p；为什么交换函数需要访问 *x 与 *y。

::: details 内容依据与本课范围

本教学版以原课指针基础与一维数组为范围，补充示例和分步练习。关于地址与解引用、数组和指针、指针运算，可对照 [Microsoft C 语言文档](https://learn.microsoft.com/en-us/cpp/c-language/indirection-and-address-of-operators?view=msvc-170)、[GNU C：指针与数组](https://www.gnu.org/software/c-intro-and-ref/manual/html_node/Pointers-and-Arrays.html)及[指针运算](https://www.gnu.org/software/c-intro-and-ref/manual/html_node/Pointer-Arithmetic.html)。示例限定在有效对象和数组边界内，不依赖 GNU 的额外扩展。

:::

## 07 / 原课测验与复习

**1. 下列指针定义或初始化中，正确的是**

- A. int a; float \*p = &a;
- B. int \*p = 200;
- C. int a; int \*p = &a;
- D. int \*p; \*p = 10;

::: details 点开核对答案

**答案：C（int a; int \*p = &a;）** —— A 基类型不一致；B 把普通整数赋给指针；D 中 p 未指向具体地址就解引用赋值。C 基类型一致且用 & 取地址。

:::

**2. 已知 int a[5], \*p = a; 下列代表 a[2] 地址的是**

- A. p + 2
- B. \*(p + 2)
- C. a[2]
- D. p[2]

::: details 点开核对答案

**答案：A（p + 2）** —— p + 2 ≡ &a[2] 是地址；\*(p+2)、a[2]、p[2] 都是元素的值。

:::

**3. 能真正交换 main 函数中两个 int 变量值的 swap 是**

- A. void swap(int x,int y){int t=x;x=y;y=t;}
- B. void swap(int \*x,int \*y){int \*t=x;x=y;y=t;}
- C. void swap(int \*x,int \*y){int t=\*x;\*x=\*y;\*y=t;}
- D. void swap(int x,int y){int \*t=&x;\*t=y;t=&y;\*t=x;}

::: details 点开核对答案

**答案：C（void swap(int \*x,int \*y){int t=\*x;\*x=\*y;\*y=t;}）** —— A 是传值，只改副本；B 只交换形参指针的指向；D 仍是对形参副本操作。C 用 \*x、\*y 修改了实参地址里的值。

:::

**4. 执行 int a[3]={1,3,5},\*p=a; printf("%d",\*p++); 输出为**

- A. 1
- B. 3
- C. 5
- D. 不确定

::: details 点开核对答案

**答案：A（1）** —— \*p++ 是后置形式：先取当前 \*p（即 a[0]=1）输出，然后再把 p 后移一位。

:::

**5. 对同一数组内的两个 int\* 指针 p1、p2，p2 - p1 的值表示**

- A. 两地址的字节差
- B. 两元素的下标差
- C. 两指针占用的字节数
- D. 数组元素的总字节数

::: details 点开核对答案

**答案：B（两元素的下标差）** —— 指针相减按基类型步长折算，结果是两指针之间相隔的元素个数，不是字节数。

:::

**6. 关于数组名作函数参数，下列说法正确的是**

- A. 数组名传递的是整个数组的副本
- B. 形参数组名完全等价于同长度数组
- C. 在函数中改 arr[i] 即改 a[i]
- D. 实参只能写数组名不能写指针

::: details 点开核对答案

**答案：C（在函数中改 arr[i] 即改 a[i]）** —— 数组名作实参传的是首元素地址，形参本质是指针；因此 arr[i] 与 a[i] 是同一单元。实参可以是数组名或指针，四组组合均合法。

:::
