① 脱口背出四种遍历口诀：先序**根左右**、中序**左根右**、后序**左右根**、层次**从上到下、从左至右**；② 对任意二叉树手写先序、中序、后序序列，并用文字描述「借助队列」的层次遍历步骤；③ 用「先序/后序定根、中序分左右」完整还原一棵二叉树并写出第三种遍历序列；④ 判断哪些序列组合能唯一还原——先序+中序、后序+中序可以，**只有先序+后序不行**。

:::

::: details 温故 · 第 19 课「树与二叉树基础」：二叉树的叶子数 n₀ 与度为 2 的结点数 n₂ 有什么关系？

n₀ = n₂ + 1，即叶子数等于度为 2 的结点数加 1；例如有 10 个度为 2 的结点，叶子就有 11 个。

:::

::: details 温故 · 第 18 课「串」：空串和空格串是一回事吗？

不是。空串长度为 0，一个字符都没有；空格串由一个或多个空格组成，长度等于空格的个数。

:::

::: info

为什么现在复习遍历

遍历是二叉树大题的「发动机」：给两个序列求第三个序列、还原二叉树、画树形图，卷面上反复出现。这节课专注 §2.3 遍历与还原这一块，把口诀、示例树、两道完整推演一次讲透。

:::

## 一、四种遍历的口诀

| 遍历 | 口诀 | 次序 |
| --- | --- | --- |
| 先（前）序 | **根左右** | 先访问根，再递归左子树，最后右子树 |
| 中序 | **左根右** | 最左叶子起：左子树→根→右子树 |
| 后序 | **左右根** | 左→右→根 |
| 层次 | **从上到下、从左至右** | 借助队列，逐层访问 |

::: info

中序小技巧

中序不好下手时，可用**「补齐法」**把缺的孩子补成空、补成满二叉树辅助，再按「左根右」走一遍，不容易漏结点。

:::

## 二、层次遍历：借助队列的四个步骤

1. **根结点入队**；
2. 队头结点**出队并访问**；
3. 把出队结点的**左、右孩子依次入队**（存在才入）；
4. 重复 2–3，**循环至队空**。

记住辅助结构是**队列**——先进先出才能保证「从上到下、从左至右」的次序。

## 三、课件示例树：三种序列各走一遍

用文字把这棵树搭出来：**根为 1**；1 的左孩子是 **2**、右孩子是 **3**；2 没有左孩子，右孩子是 **4**；4 的左孩子是 **7**、右孩子是 **8**；3 的左孩子是 **5**、右孩子是 **6**。

```
<code>        1
      /   \
     2     3
      \   / \
       4 5   6
      / \
     7   8</code>
```

按「整棵树 = 根 + 左子树序列 + 右子树序列」的递归思路拆：

- **先序（根左右）**：1 + (2,4,7,8) + (3,5,6) = **1,2,4,7,8,3,5,6**
- **中序（左根右）**：(2,7,4,8) + 1 + (5,3,6) = **2,7,4,8,1,5,3,6**
- **后序（左右根）**：(7,8,4,2) + (5,6,3) + 1 = **7,8,4,2,5,6,3,1**

::: danger 易错

课件勘误（以树形为准）

① 课件中序印作「2,7,4,8,1,3,6」——**漏了结点 5**，按树形更正为 2,7,4,8,1,5,3,6；② 课件后序那一页的前缀误写为「中序遍历」，内容实为后序序列 7,8,4,2,5,6,3,1。背序列时认树形，别认印刷。

:::

## 四、还原二叉树：定根 + 分左右

还原规则一句话：**先序/后序定根，中序分左右**。

- **先序**序列的**第一个**字符是根；**后序**序列的**最后一个**字符是根；
- 到**中序**序列里找到这个根：它**左边全是左子树**的结点，**右边全是右子树**的结点；
- 对左、右子树各取对应的先序/中序片段，**递归**做下去，整棵树就画出来了。

因此：**先序+中序** 或 **后序+中序** 可以唯一还原一棵二叉树。

::: danger 易错

易错点

**只给先序+后序不能唯一还原**——两个序列都只负责「报根」，没有中序就没人负责「分左右」，子树边界划不开。必须有中序。

:::

## 五、完整还原推演两例

### 5.1 例一（随堂练习 4）：先序 EFHIGJK、中序 HFIEJGK，求根的右子树的根

1. 先序第一个字符 **E** = 整棵树的根；
2. 在中序 HFIEJGK 中找到 E：左边 **HFI** 是左子树，右边 **JGK** 是右子树；
3. 右子树的先序片段是 **GJK**，第一个字符 **G** = 右子树的根。答案 **C. G**。

顺手把左子树也定掉：左子树先序 FHI、中序 HFI → 左子树根是 **F**。

### 5.2 例二（随堂练习 11）：先序 ABCDEF、中序 CBAEDF，求后序

1. 先序第一个 **A** = 根；中序 CBAEDF 中 A 左边 **C B** 是左子树、右边 **E D F** 是右子树；
2. 左子树：先序 B C、中序 C B → 根 **B**，C 在 B 左边 → C 是 B 的左孩子；左子树后序 = **C B**；
3. 右子树：先序 D E F、中序 E D F → 根 **D**，E 在左、F 在右；右子树后序 = **E F D**；
4. 整树后序 = 左后序 + 右后序 + 根 = C B + E F D + A = **CBEFDA**。答案 **A**。

## 六、先回忆，再自测

::: details 四种遍历的口诀分别是什么？层次遍历借助什么结构？

先序根左右、中序左根右、后序左右根；层次遍历从上到下、从左至右，借助**队列**（根入队→出队访问→左右孩子依次入队→循环至队空）。

:::

::: details 还原二叉树的规则？哪两种组合可以唯一还原？

先序/后序定根，中序分左右子树。先序+中序、后序+中序可唯一还原；只给先序+后序不能——必须有中序才能分左右。

:::

::: details 为什么只给先序+后序不能唯一还原二叉树？

先序和后序只能确定根（先序第一个、后序最后一个），分左右必须靠中序中根的位置；没有中序，子树边界划不开，答案不唯一。

:::

::: details 课件示例树的三种遍历序列分别是什么？两处勘误还记得吗？

先序 1,2,4,7,8,3,5,6；中序 2,7,4,8,1,5,3,6（课件漏印结点 5）；后序 7,8,4,2,5,6,3,1（课件该页前缀误写「中序遍历」）。

:::

## 七、测验（点击选项作答）

**1. 中序遍历的口诀是**

- A. 根左右
- B. 左根右
- C. 左右根
- D. 从上到下从左至右

::: details 点开核对答案

**答案：B（左根右）** —— 中序左根右；根左右是先序，左右根是后序，从上到下从左至右是层次遍历。四个口诀要能对应无误。

:::

**2. 层次遍历二叉树需要借助的辅助结构是**

- A. 栈
- B. 队列
- C. 散列表
- D. 二维数组

::: details 点开核对答案

**答案：B（队列）** —— 层次遍历借助&lt;strong&gt;队列&lt;/strong&gt;：根入队→出队访问→左右孩子依次入队→循环至队空，先进先出保证逐层次序。

:::

**3. 课件示例树（根 1，2 的右孩子 4，4 的孩子 7、8，3 的孩子 5、6）的后序序列为**

- A. 1,2,4,7,8,3,5,6
- B. 2,7,4,8,1,5,3,6
- C. 7,8,4,2,5,6,3,1
- D. 7,4,8,2,6,5,3,1

::: details 点开核对答案

**答案：C（7,8,4,2,5,6,3,1）** —— 后序左右根：(7,8,4,2)+(5,6,3)+1 = 7,8,4,2,5,6,3,1。A 是先序、B 是中序；注意课件该页前缀误写「中序遍历」，内容实为后序。

:::

**4.（随堂练习 4）先序 EFHIGJK、中序 HFIEJGK，根的右子树的根是**

- A. E
- B. F
- C. G
- D. K

::: details 点开核对答案

**答案：C（G）** —— 先序定根 E；中序中 E 右边的 JGK 是右子树，右子树先序片段 GJK 的第一个字符 G 即右子树的根。左子树根为 F。

:::

**5.（随堂练习 11）先序 ABCDEF、中序 CBAEDF，后序序列为**

- A. CBEFDA
- B. CBAEDF
- C. ABCDEF
- D. FEDCBA

::: details 点开核对答案

**答案：A（CBEFDA）** —— 根 A，左子树 {B,C}（B 根、C 左孩子）后序 CB，右子树 {D,E,F}（D 根，E 左 F 右）后序 EFD，整树后序 CB+EFD+A = CBEFDA。B 是中序、C 是先序本身。

:::

**6. 只给先序和后序两个遍历序列，能否唯一还原一棵二叉树？**

- A. 能，先序定根后序定尾就够了
- B. 能，两个序列本身已含全部信息
- C. 不能，必须有中序才能分左右子树
- D. 不能，必须有层次遍历序列

::: details 点开核对答案

**答案：C（不能，必须有中序才能分左右子树）** —— 先序+后序只能「定根」，分左右必须靠中序中根的位置，所以不能唯一还原。可唯一还原的组合是先序+中序、后序+中序。

:::
