::: details 温故 · 第 12 课「指针进阶」：int(*p)[4] 与 int *p[4] 的本质区别是什么？

有括号时 (*p) 先与 * 结合，p 是指针，即数组指针，指向含 4 个 int 的一行数组；无括号时 [] 优先级高，p 先与 [4] 结合，p 是数组，即含 4 个 int* 指针的指针数组。

:::

::: details 温故 · 第 11 课「指针基础与一维数组」：三种 swap 写法中，哪种能真正交换 main 里的变量？核心代码是什么？

传址并通过 *x、*y 直接修改实参值的版本：void swap(int *x, int *y){ int t=*x; *x=*y; *y=t; }。只传值的版本改的是副本，只交换形参指向的版本没改目标值，都不行。

:::

## 一、结构体：声明、定义与初始化

声明结构体就是定义一种新类型，**类型本身不占内存**，只有定义变量后才开辟空间。

```
<code>struct Student
{
    int num;
    char name[20];
    float score;
};              /* ← 末尾分号不能少 */</code>
```

| 要点 | 正确做法 | 常见错误 |
| --- | --- | --- |
| 成员规则 | 成员只能定义变量 | 在成员处直接赋初值或写常量 |
| 整体初始化 | 只能在**定义变量时**整体初始化 | 先定义再整体赋值：`lisi = {2,"lisi",80};` 非法 |
| 字符数组成员 | 用 `strcpy(lisi.name, "lisi");` | `lisi.name = "lisi";` 非法（数组名是地址常量） |
| 相互赋值 | 同类结构体变量可直接赋值：`zhangsan = lisi;` | 把类型名当变量用 |
| 变量大小 | 考试选理论值：各成员大小之和 | 无说明时选对齐后的实际值 |

::: info

scanf 取地址口诀

数值成员前加 `&`，字符数组名本身就是地址，**不加 &**：`scanf("%d%s%f", &lisi.num, lisi.name, &lisi.score);`

:::

成员也可以是另一个结构体类型：嵌套成员**一级级往下找**，如 `lisi.dahuang.age = 2;`。

## 二、结构体数组与选择排序

```
<code>struct Student stu[3] = {
    {1, "a", 80},
    {2, "b", 90},
    {3, "c", 70}
};</code>
```

选择排序的核心：n 个数据执行 **n-1 轮**；每轮从**未排序区**找出**最小值**放到未排序区最前面；用变量 **p 记录最小值的位置**。

```
<code>for (i = 0; i < n - 1; i++)
{
    p = i;
    for (j = i + 1; j < n; j++)
        if (stu[j].score < stu[p].score) p = j;
    if (p != i) { t = stu[i]; stu[i] = stu[p]; stu[p] = t; }
}</code>
```

交换时用临时结构体变量**整体交换**，不要只交换某一个成员。

## 三、结构体指针：三种成员引用

```
<code>struct Student lisi;
struct Student *p = &lisi;   /* 普通指针不能指向结构体变量 */</code>
```

因为 `.` 和 `->` 的优先级高于 `*`，所以 `*p.num` 会被理解为 `*(p.num)`，而 `p.num` 对指针非法。必须加括号或使用指向运算符。

| 写法 | 含义 | 是否等价于 lisi.num |
| --- | --- | --- |
| `lisi.num` | 结构体变量名.成员 | 是 |
| `(*p).num` | 先解引用，再用点号 | 是 |
| `p->num` | 指向运算符，最简形式 | 是 |
| `*p.num` | 等价 `*(p.num)`，非法 | 否 |

指针也可指向结构体数组：`p = stu;` 后 `*p` 即 `stu[0]`，`*(p+1)` 与 `stu[1]` 等价，可 `p++` 逐个遍历。

## 四、文件：fopen / fgetc / fputc

```
<code>FILE *fp;
fp = fopen("data.txt", "r");
if (fp == NULL) { /* 打开失败处理 */ }</code>
```

| 打开方式 | 含义 | 打开失败时 |
| --- | --- | --- |
| `r` | 只读，从文件读数据 | 返回 **NULL** |
| `w` | 只写，向文件写数据 | **新建文件** |
| `a` | 追加，向文件末尾添加数据 | 文件不存在则**新建**（不因此失败） |

| 函数 | 调用方式 | 功能 | 失败/结束 |
| --- | --- | --- | --- |
| `fgetc` | `fgetc(fp);` | 从文件读一个字符 | 返回 **EOF** |
| `fputc` | `fputc(ch, fp);` | 向文件写一个字符 | 返回 **EOF** |

::: danger 易错

课件范围提醒

本课文件部分只覆盖 `fopen / fgetc / fputc`。`fread / fwrite / fseek / ftell` 等函数课件未讲，但教材（谭浩强《C程序设计》P339 以后）有完整内容，建议按教材补齐，避免考纲缺口。

:::

## 五、先回忆，再自测

::: details 合上笔记默写：访问结构体成员的三种正确写法，以及 *p.num 为何是错的

三种写法：lisi.num、(*p).num、p-&gt;num。因为 . 和 -&gt; 优先级高于 *，*p.num 会被解析为 *(p.num)，而 p.num 对指针不合法，所以必须写成 (*p).num 或 p-&gt;num。

:::

::: details 结构体变量初始化的两条硬规则是什么？字符数组成员为什么不能直接赋值？

只能在定义变量的同时整体初始化，且常量顺序与成员顺序一致；先定义再整体赋值不合法。字符数组成员是数组名，属于地址常量，不能出现在赋值号左边，必须用 strcpy。

:::

::: details 选择排序的轮数、p 变量的作用，以及 fopen 的 r/w/a 打开失败时分别怎样？

n 个数据执行 n-1 轮；p 记录未排序区最小值的位置。r 方式文件不存在时失败返回 NULL；w、a 方式文件不存在时都会新建文件。

:::

## 六、测验（点击选项作答）

**1. 已知 `struct Student p = &lisi;`，下列成员引用写法错误的是**

- A. lisi.num（变量点成员）
- B. (*p).num（解引用括号）
- C. p-&gt;num（指向运算符）
- D. *p.num（缺少括号）

::: details 点开核对答案

**答案：D（p.num（缺少括号））** —— . 和 -&gt; 优先级高于 *，*p.num 等价于 *(p.num)，对指针 p 来说 p.num 非法；正确写法是 (*p).num 或 p-&gt;num。

:::

**2. 关于结构体变量的初始化，说法正确的是**

- A. 定义后再用{}整体赋值
- B. 只能在定义变量时初始化
- C. 结构体成员处直接赋初值
- D. 对结构体类型名整体初始化

::: details 点开核对答案

**答案：B（只能在定义变量时初始化）** —— 结构体变量只能在定义的同时整体初始化，常量顺序与成员一致；先定义后整体赋值、对类型名赋值、在成员处初始化都不合法。

:::

**3. 对结构体中的 `char name[20]` 成员，正确赋值方式是**

- A. s.name = "Tom"（直接赋值）
- B. strcpy(s.name,"Tom")（字符串拷贝）
- C. s.name == "Tom"（关系比较）
- D. name = "Tom"（缺结构体变量）

::: details 点开核对答案

**答案：B（strcpy(s.name,"Tom")（字符串拷贝））** —— name 是数组名，属于地址常量，不能出现在赋值号左边；必须用 strcpy 把字符串拷贝到数组中。

:::

**4. 结构体数组按成绩升序进行选择排序，内层循环结束后 p 保存的是**

- A. 未排序区域中的最大值位置
- B. 未排序区域中的最小值位置
- C. 已排序区域中的首元素位置
- D. 当前轮起始位置 i 的值

::: details 点开核对答案

**答案：B（未排序区域中的最小值位置）** —— 选择排序每轮从未排序区找最小值放到未排序区最前面，p 记录的就是这个最小值的位置。

:::

**5. `fopen("data.txt", "r")` 打开一个不存在的文件，结果是**

- A. 自动新建空白文件
- B. 打开失败返回 NULL
- C. 返回文件结束标志 EOF
- D. 程序异常终止报错

::: details 点开核对答案

**答案：B（打开失败返回 NULL）** —— r 方式只读，文件不存在时返回 NULL；w、a 方式文件不存在时都会新建文件并成功打开（w 清空重写、a 保留后追加）。

:::

**6. 关于 `fgetc` 与 `fputc`，说法正确的是**

- A. 均以字符串为单位读写
- B. 失败或结束时返回 NULL
- C. 均以单个字符为单位读写
- D. 只能用于二进制文件读写

::: details 点开核对答案

**答案：C（均以单个字符为单位读写）** —— fgetc 从文件读一个字符，fputc 向文件写一个字符；失败或文件结束返回 EOF，不是 NULL。

:::
