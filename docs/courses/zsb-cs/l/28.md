对应题库 题库/真题-2025年广东省 · 约 150 分钟（120 分钟模拟 + 30 分钟复盘）

::: tip 学习目标

学完这节课，你能做到：

① 限时 120 分钟独立完成 2025 年全卷，并把答案手写在纸上；② 按卷面结构表逐块检查是否漏题漏页；③ 用错题归章表把每道错题定位到笔记章节并标 ⭐️；④ 复盘结束后能说出自己的三类失分模式（知识没记住 / 会但不熟 / 时间不够）。

:::

::: info

为什么现在做全真模拟

前 27 课解决「学没学过」，这套真题回答「考场能不能拿出来用」。全真模拟检验两件事：**存储强度**——平时看笔记都懂，闭卷手写还能不能提取出来；**时间分配**——会做但做不完，等于不会。这节课不再讲新知识，它是一本考试执行手册：怎么考、怎么对答案、怎么复盘。真题不提前拆讲，含金量才留在模拟里。

:::

## 一、考试须知

::: danger 易错

模拟纪律（缺一条就不算全真）

**闭卷**：不翻笔记、不查题库、不问 AI 助手；**断资料**：关掉所有文档和网页，只留题库卷面；**手机计时**：倒计时 120 分钟，开着勿扰模式，除此之外不碰手机；**手写答案**：全部写在白纸上——考场是手写，打字练不出卷面手感。时间一到立即停笔，超时做出的题不计分。

:::

## 二、卷面结构与分值

| 题型 | 题量 × 分值 | 小计 |
| --- | --- | --- |
| 单项选择题 | 20 × 3 分 | 60 分 |
| 判断题 | 5 × 4 分 | 20 分 |
| 填空题 | 5 × 4 分 | 20 分 |
| 简答题 | 3 题 | 题库未标分值，按卷面估计 |
| 计算题 | 3 题 | 题库未标分值，按卷面估计 |
| 应用题 | 3 题 | 题库未标分值，按卷面估计 |

注：题库分节标题写作「判断 5 题、简答 3 题」，但正文实际收录判断题编号 21–30（共 10 题）、简答题编号 36–39（共 4 题）。模拟时以正文实际题量为准——下面的时间分配表已按偏满题量给出，多出的题量占用不了多少时间。

## 三、120 分钟时间分配

| 环节 | 建议用时 | 执行要点 |
| --- | --- | --- |
| 单项选择 | 35 分钟 | 单题超过 2 分钟先标记、猜一个，往下走 |
| 判断 | 10 分钟 | 凭第一判断作答，不反复改 |
| 填空 | 15 分钟 | 按步骤算，写清题目要求的形式 |
| 简答 | 15 分钟 | 分点写关键词，不写长段落 |
| 计算 | 20 分钟 | 读程序逐行列表跟踪变量，不整段心算 |
| 应用 | 20 分钟 | 先立骨架，再填逻辑 |
| 检查 | 5 分钟 | 核对题号与页码，回填标记题 |

::: info

用法

把这张表抄在手边，每做完一块看一次表。超时 5 分钟以内属于正常波动；超时 10 分钟以上，说明该板块要进二轮专题突破的优先清单。

:::

## 四、作答策略

- **先客观后主观**：单选＋判断＋填空共 100 分上下，且题干短、见分快，先把客观分稳稳拿住，再进主观题。
- **简答按关键词给分的逻辑写**：阅卷找的是定义词、特征词、区别词。先写「是什么」，再分点补特点或对比，宁多写要点，不堆长句。
- **应用题代码按「输入→处理→输出」三段写**：头文件与 main 框架、变量定义与输入、核心循环与输出。即使算法写不全，也要把骨架和循环边界写出来——应用题按步骤给分，骨架就是步骤分。
- **计算题读程序**：在草稿上画一张「变量值随行变化」的表，逐行更新，循环题按轮次列表，别指望心算一遍过。

## 五、本卷特别提醒

::: danger 易错

来自题库的勘误标注

本卷**第 4 题、第 17 题原卷选项疑有误**：按题面计算的结果不在四个选项之中。遇到时圈出题号、按最合理的理解先作答，**对答案时以题库「参考答案（整理判定）」为准**，不要在考场上死磕选项。另外，本卷客观题答案为整理判定（讲解课件为图片版），存疑的题可回看讲解 PDF 核对。

:::

## 六、复盘：对答案与错题归章

停笔后按四步走，约 30 分钟：

- **第一步 · 对答案**：展开题库中的答案 callout，先统计各题型得分与总分，再逐题看错在哪；第 4、17 题按整理判定答案核对。
- **第二步 · 错题归章**：每道错题填进归章表，定位到笔记章节——

| C 语言部分（归笔记 01–09） | 数据结构部分（归笔记 10–18） |
| --- | --- |
| 程序设计与数据类型 → 01、02 | 绪论与复杂度 → 10 |
| 顺序、选择、循环 → 03、04、05 | 线性表、栈和队列 → 11、12 |
| 数组与字符串 → 06 | 数组矩阵广义表、串 → 13、14 |
| 函数 → 07　指针 → 08 | 树与二叉树 → 15 |
| 结构体与文件 → 09 | 图 → 16　查找、排序 → 17、18 |

- **第三步 · 回笔记重学**：每道错题回到对应笔记，把该考点重学一遍，错题本上标 ⭐️。
- **第四步 · 摘星重做**：第二天遮住答案只重做标 ⭐️ 的题，做对才摘星。

::: info

简答题失分怎么办

若简答考到背诵范围却答不到点，回[第 27 课](/courses/zsb-cs/l/27/)的打卡表找到对应组，按关键词重新背诵该组——不是背孤立的这道题，而是补上整组考点。

:::

## 七、先回忆，再自测

::: details 临场自检 1：循环队列怎么判满、怎么判空？

牺牲一个存储单元的约定下：队满 front==(rear+1)%M，队空 front==rear。两个条件别混，取模别忘写。客观题高频。

:::

::: details 临场自检 2：else 和谁配对？continue 与 break 差在哪？

else 与它前面最近的、尚未配对的 if 配对，与书写缩进无关。continue 结束「本次」进入下一次循环判定，break 直接跳出整层循环。读程序计算题就爱考这两处。

:::

::: details 临场自检 3：fopen 三种基本打开方式是什么？fclose 成功返回什么？

"r" 只读、"w" 只写（清空重建）、"a" 追加；fclose 成功返回 0。填空与判断题的常客。

:::

::: details 临场自检 4：二叉树结点数与深度的两条性质公式？

度为 0 结点数 n₀ = 度为 2 结点数 n₂ + 1；深度为 k 的二叉树结点最多 2k−1 个。31 个结点的满二叉树即 2⁵−1。

:::

## 八、测验（点击选项作答）

**1. 模拟中遇到题面或选项疑似有误的选择题，正确做法是**

- A. 当场翻资料求证，弄懂后接着做
- B. 圈出题号先作答继续推进，对答案时以题库整理判定为准
- C. 直接跳过不写，留到复盘再补
- D. 反复重读题目，直到确定选项为止

::: details 点开核对答案

**答案：B（圈出题号先作答继续推进，对答案时以题库整理判定为准）** —— 本卷第 4、17 题即属题库标注「原卷选项疑有误」的题。考场同理：先写一个答案保证不空，把疑问留到对答案环节，不在单题上耗时间。

:::

**2. 停笔对答案时，第一步应该做的是**

- A. 先看讲解 PDF 把全卷听一遍
- B. 把做错的题立刻原题重做
- C. 统计各题型得分与总分，量化失分分布
- D. 先把简答题库背一遍再对主观题

::: details 点开核对答案

**答案：C（统计各题型得分与总分，量化失分分布）** —— 复盘从量化开始：先知道客观、主观各丢多少分，才能判断失分属于知识缺口、熟练度不足还是时间失控，后面的动作才有靶子。

:::

**3. 应用题没有完整思路时，最优先写下的内容是**

- A. 输入→处理→输出的骨架：头文件、main、变量与循环边界
- B. 标注「不会」两字，整题留白
- C. 回头再想，把时间全给前面的题
- D. 把题目文字抄写一遍，表示作答过

::: details 点开核对答案

**答案：A（输入→处理→输出的骨架：头文件、main、变量与循环边界）** —— 应用题按步骤给分：框架、变量定义、循环结构写对就有分。先立骨架再填逻辑，能拿几步是几步，留白才是零分。

:::

**4. 「错题归章表」的直接作用是**

- A. 累计错题数量，用作学习打卡记录
- B. 替代笔记本，之后只看归章表
- C. 记录每道题的作答用时
- D. 把每道错题定位到笔记章节，回对应章重学考点

::: details 点开核对答案

**答案：D（把每道错题定位到笔记章节，回对应章重学考点）** —— C 语言错题归笔记 01–09，数据结构错题归笔记 10–18。归章之后「重学」才有落点，否则对答案只是看一遍正确写法。

:::

**5. 简答题答不到给分点，复盘时正确的补救是**

- A. 把参考答案工整抄写三遍
- B. 回第 27 课打卡表对应组，按关键词背整组考点
- C. 先跳过，简答题分值占比不高
- D. 只背自己做错的这一道题

::: details 点开核对答案

**答案：B（回第 27 课打卡表对应组，按关键词背整组考点）** —— 简答按关键词给分。第 27 课打卡表把简答题库分成了组，背对应组才能覆盖同一考点的各种问法，孤立背题效率最低。

:::

::: warning 动手环节

课后任务：执行这场模拟（约 150 分钟）

① 打开 题库/真题-2025年广东省，保持答案 callout 折叠，备好白纸和笔。② 手机倒计时 120 分钟，闭卷、断资料，按时间分配表作答，答案全部手写。③ 到点立即停笔：展开答案对分、统计各题型得分、填错题归章表。④ 每道错题回对应笔记重学该考点并标 ⭐️；简答缺口回第 27 课打卡表对应组背诵。⑤ 第二天重做标 ⭐️ 的题；完成复盘后，写出自己的三类失分模式各一条——这条写不出来，说明复盘还没做透。

:::
