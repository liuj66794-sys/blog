::: details 温故 · 第 15 课「线性表」：顺序表在第 i 个位置插入、删除第 i 个元素分别要移动多少个元素？平均移动次数呢？

插入第 i 个位置要 n-i+1 个元素后移，删除第 i 个元素要 n-i 个元素前移；插入平均移动 n/2 次，删除平均移动 (n-1)/2 次，时间复杂度均为 O(n)。

:::

::: details 温故 · 第 14 课「数据结构绪论与时间复杂度」：算法的五个特性是什么？「可读性」算算法特性吗？

有穷性、确定性、可行性、输入、输出，五个特性缺一不可；可读性是好算法的目标，不是算法本身的特性，判断题说「可读性是算法的重要特性」要判错。

:::

::: info

为什么现在要巩固这个

栈和队列是数据结构里「操作受限的线性表」，广东专升本年年考：循环队列四公式、出栈序列合法性、中缀转后缀。你一节课把它们焊死，后面图和排序会轻松很多。

:::

## 一、栈与队列的核心对比

|   | 栈 Stack | 队列 Queue |
| --- | --- | --- |
| 原则 | 后进先出 LIFO | 先进先出 FIFO |
| 插入位置 | 栈顶 | 队尾 rear |
| 删除位置 | 栈顶 | 队头 front |
| 逻辑结构 | 都是线性表（运算与存储实现可不同） |   |

::: danger 易错

最高频陷阱

栈**只**在栈顶插删，队列**只**在队尾入、队头出。出现「删除栈底元素」「在队头插入」的选项直接判错。

:::

## 二、顺序栈：top 指向栈顶元素的下一个单元

| 状态 / 操作 | 条件或公式 |
| --- | --- |
| 栈空 | `top == base` |
| 栈满 | `top - base >= size` |
| 入栈 Push | 先判满，值送入 `*top`，再 `top++` |
| 出栈 Pop | 先判空，`top--`，再取 `*top` |

链栈用单链表头部作栈顶，最大优点：**不存在栈满上溢**，空间按需增长。

## 三、循环队列：四公式与牺牲一个单元

普通顺序队列会出现「假溢出」——rear 走到数组尾，但前面已出队的位置空着。把数组首尾相连成环就是循环队列。

| 含义 | 公式 |
| --- | --- |
| 队满 | `(rear + 1) % MaxSize == front` |
| 队空 | `front == rear` |
| 队首指针进 1 | `front = (front + 1) % MaxSize` |
| 队尾指针进 1 | `rear = (rear + 1) % MaxSize` |
| 元素个数 | `(rear - front + MaxSize) % MaxSize` |

::: info

为什么要牺牲一个单元

空队和满队都满足 `front == rear`，无法区分。所以约定「牺牲一个存储单元」：rear 再往前走一步等于 front 时视为满。因此大小为 N 的数组，循环队列最多存 **N - 1** 个元素。

:::

## 四、中缀 → 后缀（逆波兰式）

| 表达式形式 | 运算符位置 | 示例 a + b |
| --- | --- | --- |
| 中缀 | 操作数中间 | `a + b` |
| 前缀（波兰式） | 操作数之前 | `+ a b` |
| 后缀（逆波兰式） | 操作数之后 | `a b +` |

转换/求值借助栈。例如 `a * (b + c) - d` 的后缀式为 `abc+*d-`：先算括号内 `bc+`，再与 a 相乘 `abc+*`，最后减 d 得 `abc+*d-`。

## 五、链队列

链队列是带 `front` 和 `rear` 两个指针的单链表。注意：

- 判空：**`front == NULL`**（课件原文「Q-&gt;front==NULL 且 Q-&gt;front==NULL」后半应为 rear，系笔误）。
- 不存在队满溢出问题，适合数据元素变动较大的情形。

## 六、先回忆，再自测

::: details 合上笔记默写：循环队列四公式与最大容量

队满 `(rear+1)%MaxSize==front`；队空 `front==rear`；指针进 1 用 `(x+1)%MaxSize`；元素个数 `(rear-front+MaxSize)%MaxSize`。大小为 N 的数组最多存 N-1 个元素（牺牲一格区分空满）。

:::

::: details 入栈序列 a,b,c,d，判断出栈序列 c,b,d,a 是否合法，并写出推理

合法。模拟：a 入、b 入、c 入，c 出；栈顶为 b，b 出；d 入，d 出；a 出。每一步栈顶都等于目标序列当前元素，所以合法。

:::

::: details 中缀式 a*(b+c)-d 转成后缀式的步骤是什么

先处理括号内 b+c 得 bc+；再与 a 相乘得 abc+*；最后减 d 得 abc+*d-。

:::

## 七、测验（点击选项作答）

**1. 下列关于栈的描述，正确的是**

- A. 栈底元素最先进栈也最先出栈
- B. 栈顶元素最后进栈却最先出栈
- C. 栈允许在栈底进行删除操作
- D. 栈的插入和删除可在任意端进行

::: details 点开核对答案

**答案：B（栈顶元素最后进栈却最先出栈）** —— 栈按后进先出 LIFO 原则，只在栈顶插删。栈顶元素最后进、最先出；栈底最先进、最后出。

:::

**2. 入栈序列 1,2,3,4，下列不可能是出栈序列的是**

- A. 1 2 3 4
- B. 4 3 2 1
- C. 1 3 2 4
- D. 4 1 2 3

::: details 点开核对答案

**答案：D（4 1 2 3）** —— 若 4 第一个出栈，说明 1–4 已全部入栈，此时栈顶是 3，下一位只能是 3 而非 1。模拟法可知 D 不合法。

:::

**3. 大小为 6 的循环队列，初始 rear=0、front=3，删除 1 个元素再加入 2 个元素后，rear 和 front 分别是**

- A. rear=0，front=4
- B. rear=1，front=4
- C. rear=2，front=4
- D. rear=4，front=2

::: details 点开核对答案

**答案：C（rear=2，front=4）** —— 删除 1 个：front=(3+1)%6=4；加入 2 个：rear 从 0 依次变为 (0+1)%6=1、(1+1)%6=2。注意 rear 指向队尾元素的下一个位置。

:::

**4. 用大小为 N 的数组实现循环队列，采用牺牲一个单元区分空满，该队列最多可存储的元素个数是**

- A. N - 1
- B. N
- C. N + 1
- D. 2N

::: details 点开核对答案

**答案：A（N - 1）** —— 牺牲一个单元后，队满条件为 (rear+1)%MaxSize==front，因此实际可用空间为 N-1。

:::

**5. 中缀表达式 a(b+c)-d 对应的后缀表达式是**

- A. a b c + * d
- B. a b c + * d -
- C. * a + b c - d
- D. a * b + c - d

::: details 点开核对答案

**答案：B（a b c +  d -）** —— 后缀式中运算符在操作数之后。先算 b+c 得 bc+，再乘 a 得 abc+*，最后减 d 得 abc+*d-。

:::

**6. 关于链队列，下列说法正确的是**

- A. 判空条件是 rear == NULL
- B. 存在队满溢出问题
- C. rear 指向队尾元素的下一个位置
- D. 适合数据元素变动较大的情形

::: details 点开核对答案

**答案：D（适合数据元素变动较大的情形）** —— 链队列判空看 front==NULL；不存在队满；rear 指向最后一个结点本身；正因动态分配，适合元素变动大的场景。

:::

**7. 容量 70 的循环队列，front=20、rear=11，当前元素个数为**

- A. 11
- B. 20
- C. 61
- D. 70

::: details 点开核对答案

**答案：C（61）** —— 元素个数公式为 (rear-front+MaxSize)%MaxSize。代入 (11-20+70)%70 = 61。

:::
