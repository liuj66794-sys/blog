## 一、串的定义与三个基本概念

**串（string）**：由**零个或多个字符**组成的**有限序列**，记作 S = 'a₁,a₂,…,aₙ'（n≥0）。

- S 是**串名**；单引号括起的字符序列是**串的值**；
- **n = 串长**；**n = 0 时为空串**。

| 概念 | 定义 |
| --- | --- |
| 子串 | 串中**任意多个连续的字符**组成的子序列（**串自身和空串也是串的子串**） |
| 串相等 | 长度相等且每个对应位置的字符都相等 |
| 空格串 | 由一个或多个空格组成的串——**不是空串**，长度 = 空格个数 |

::: info

空串 ≠ 空格串

空串长度为 0，里面**一个字符都没有**；空格串里装的是空格，长度 = 空格的个数。两者的唯一共同点是「都算串」，考试就爱在这里挖坑。

:::

## 二、子串个数公式

以 S='software'（n=8）归纳：

| 类型 | 公式 | 说明 |
| --- | --- | --- |
| 子串总数（含空串） | **n(n+1)/2 + 1** | 加 1 表示空串 |
| 非空子串 | n(n+1)/2 | 不含空串 |
| 真子串 | n(n+1)/2 | 不含自身（若含空串再讨论） |

对 n=8：子串总数 = 8×9/2 + 1 = **37**；非空子串 = 36。

::: danger 易错

易错点

① 子串计数**别忘 +1**（空串也是子串）；② **串自身也是子串**——别把它排除掉；③ 真子串、非空子串的口径要在读题时先分清「含不含空串、含不含自身」。

:::

::: info

真题印证（2025 年第 8 题）

串 'studio' 中以 t 为首的子串个数为（　）A.2　B.5　C.6　D.7，答案 **B**。'studio' 长 6，t 是第 2 个字符，以它开头的连续子串一路延伸到串尾：**t、tu、tud、tudi、tudio**，共 5 个。这正是「连续字符子序列」定义的直接应用。来源：题库/真题-2025年广东省 第 8 题。

:::

## 三、串的两种存储结构

| 结构 | 说明 |
| --- | --- |
| 定长顺序存储 | 类似线性表顺序存储——一组地址连续的存储单元存放字符序列 |
| 变长（堆）分配存储 | 仍用地址连续的存储单元，但空间在**程序执行过程中动态分配** |

## 四、串与线性表的区别

- **逻辑结构**极为相似，区别仅在：**串的数据对象限定为字符集**；
- **操作层面**差别大：**线性表以单个元素为操作对象**（查/插/删某元素），**串通常以子串为操作对象**（查找、插入、删除一个子串）——单个字符也属于子串。

| 易错点 | 正确认识 |
| --- | --- |
| 空串 = 空格串 | 不同——空格串长度 = 空格个数；空串长度 0 |
| 子串计数忘了空串 | 总数 = n(n+1)/2 + **1** |
| 串的基本操作按单个字符 | 串操作通常以**子串**为单位 |
| 串自身不算子串 | 串自身**和空串都**是它的子串 |

## 五、先回忆，再自测

::: details 串、子串、空串、空格串分别怎么定义？

串：零个或多个字符组成的有限序列，n=0 时为空串；子串：串中任意多个连续字符组成的子序列（串自身和空串也是子串）；空格串：由一个或多个空格组成的串，长度 = 空格个数——它不是空串。

:::

::: details 长度为 n 的串有多少个子串？非空子串、真子串的口径呢？

子串总数（含空串）n(n+1)/2 + 1；非空子串 n(n+1)/2；真子串 n(n+1)/2，不含自身（若含空串再讨论）。别忘了那个 +1。

:::

::: details 串与线性表的区别是什么？

两点：① 数据对象限定为字符集；② 线性表以单个元素为操作对象，串通常以子串为操作对象。

:::

::: details 串的两种存储结构？

定长顺序存储；变长（堆）分配存储——空间在程序执行过程中动态分配。

:::

## 六、测验（点击选项作答）

**1. 长度为 8 的串（如 'software'），它的子串总数（含空串）为**

- A. 36
- B. 37
- C. 28
- D. 64

::: details 点开核对答案

**答案：B（37）** —— 子串总数 = n(n+1)/2 + 1 = 8×9/2 + 1 = 37。选 36 是忘了空串那个 +1；64 是 2ⁿ 的干扰项。

:::

**2.（2025 真题第 8 题）串 'studio' 中以 t 为首的子串个数为**

- A. 2
- B. 5
- C. 6
- D. 7

::: details 点开核对答案

**答案：B（5）** —— 以 t 为首的连续子串：t、tu、tud、tudi、tudio，共 5 个，选 B。t 是第 2 个字符，从它到串尾共 6−2+1 = 5 个字符，每个结尾对应一个子串。

:::

**3. 关于空串与空格串，下列说法正确的是**

- A. 空串就是空格串，两者长度都为 0，可互换使用
- B. 空格串的长度规定为 0，不含任何字符
- C. 空格串由一个或多个空格组成，长度等于空格个数
- D. 空串由一个空格组成，长度为 1，也称空白串

::: details 点开核对答案

**答案：C（空格串由一个或多个空格组成，长度等于空格个数）** —— 空格串不是空串：空格串由一个或多个空格组成，长度 = 空格个数；空串长度为 0，不含任何字符。

:::

**4. 串与线性表相比，下列说法正确的是**

- A. 串的逻辑结构与线性表完全不同，属于非线性结构
- B. 线性表的操作通常以子串为单位进行插入删除
- C. 串的操作对象只能是单个字符，不能是子串
- D. 串的数据对象限定为字符集，操作通常以子串为单位

::: details 点开核对答案

**答案：D（串的数据对象限定为字符集，操作通常以子串为单位）** —— 两者逻辑结构极为相似，区别仅在于串的数据对象限定为字符集；操作层面线性表按单个元素、串按子串（单个字符也属于子串）。

:::

**5. 串的两种存储结构是**

- A. 定长顺序与堆分配存储
- B. 顺序存储与索引存储
- C. 链式存储与散列存储
- D. 定长链式存储与堆链式存储

::: details 点开核对答案

**答案：A（定长顺序与堆分配存储）** —— 串采用定长顺序存储（类似线性表顺序存储）与变长（堆）分配存储——后者空间在程序执行过程中动态分配。

:::

**6. 关于子串，下列说法正确的是**

- A. 串自身和空串都是串的子串
- B. 空串不是串的子串
- C. 子串的字符允许不连续
- D. 子串的长度必须小于原串

::: details 点开核对答案

**答案：A（串自身和空串都是串的子串）** —— 子串是串中任意多个连续字符组成的子序列，串自身和空串也都算子串；字符必须连续，长度也可以等于原串。

:::
