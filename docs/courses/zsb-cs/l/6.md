## 一、嵌套 if-else 与 else 配对

**核心规则**：C 语言规定，else 总是与它**前面最近的、尚未配对的 if** 配对，**与代码缩进无关**。出题人常用缩进把 else「推远」，不能上当。

::: danger 易错

两个高频编译错误

- 内嵌语句若有多条却不用 `{ }`，第二条语句会把 if 和 else 隔开，导致 `else without a previous if`。
- 同一 if 后出现两个 else，编译器会报 else 过多（配对冲突）。

:::

**用花括号改变配对**：把内层的 if-else 用 `{ }` 包起来，外层 else 就只能与外层的 if 配对。

```
<code>if (a < b)
    if (c < d) x = 1;
    else       x = 6;      /* else 与内层 if(c<d) 配对 */
else x = 7;                  /* else 与外层 if(a<b) 配对 */
</code>
```

若把内层改成：

```
<code>if (a < b) {
    if (c < d) x = 1;
    else       x = 6;
} else x = 7;                /* else 现在与外层 if(a<b) 配对 */
</code>
```

::: info

快速验证技巧

对等价判断题，用特殊值代入：0、1、-1、2。例如判断 `if(a)` 与 `if(a!=0)` 是否等价，分别代入 0 和非 0 即可。

:::

## 二、switch 与 case 穿透

| 规则 | 要点 |
| --- | --- |
| switch 表达式 | 只能是**整型或字符型**，不能是实型 |
| case 后 | 必须是**整型/字符型常量或常量表达式**，不能是变量 |
| case 值 | 必须唯一；`'a'` 与 `97` 重复会报错 |
| default | 同一 switch 只能有一个；位置不影响匹配顺序 |
| 入口 / 出口 | **case 是入口，break 是出口**；无 break 就继续执行下一个 case |

::: danger 易错

case 穿透怎么读

匹配到某个 case 后，从这个 case 开始**顺序往下执行**，直到遇见 break 或 switch 结束。default 写在最前面也不会先执行——先全部 case 匹配一遍，都不中才走 default。

:::

**嵌套 switch**：内层 break 只结束所在（最近）的内层 switch；外层 case 若无 break，仍会穿透到外层下一个 case。

## 三、位运算（对补码运算）

| 运算符 | 优先级 | 规则 | 示例 |
| --- | --- | --- | --- |
| `~` | 2 | 按位取反，**符号位也变** | `~3 = -4`，`~-3 = 2` |
| `<<` | 5 | 左移，右侧补 0 | `6<<2 = 24`，等价 `m×2ⁿ` |
| `>>` | 5 | 右移，**正数左补 0，负数左补 1** | `-16>>2 = -4`，等价 `m÷2ⁿ` |
| `&` | 8 | 按位与：一 0 则 0 | `3&6 = 2` |
| `^` | 9 | 异或：相同 0，不同 1 | `3^6 = 5` |
| `\|` | 10 | 按位或：一 1 则 1 | `3\|6 = 7` |

::: info

速算口诀

所有位运算都对**补码**进行；负数右移左侧补 1；取反有规律 `~x = -x - 1`。笔算时先把数写成 8 位或 32 位补码，再逐位运算，最后转回真值。

:::

## 四、顺带巩固：条件表达式 `?:`

`?:` 是 C 语言唯一的三目运算符，优先级高于赋值、低于关系和算术，**从右至左**结合。

```
<code>max = a > b ? a : b;           /* 等价于 if-else */

a > b ? a : c > d ? c : d     /* 右结合：a>b?a:(c>d?c:d) */
</code>
```

## 五、先回忆，再自测

::: details 合上笔记：else 到底跟谁配对？缩进有没有影响？

else 与前面最近的、尚未配对的 if 配对；与缩进无关。花括号可以把内层 if-else 包起来，从而改变外层 else 的归属。

:::

::: details switch 中 case 和 break 各是什么角色？default 写在最前面会先执行吗？

case 是入口，break 是出口；无 break 就继续执行下一个 case，称为穿透。default 位置不影响匹配，先匹配所有 case 都不中时才走 default。

:::

::: details 位运算对什么编码进行？负数右移补什么？~x 有什么快捷公式？

对补码运算；负数右移左侧补 1；快捷公式 `~x = -x - 1`。左移相当于乘 2ⁿ，右移相当于除以 2ⁿ。

:::

## 六、测验（点击选项作答）

**1. 执行下面程序段后，x 的值是（a=1, b=3, c=5, d=4）**

- A. 1
- B. 2
- C. 3
- D. 6

::: details 点开核对答案

**答案：B（2）** —— a&lt;b 为真，进入内层；c&lt;d（5&lt;4）为假，走 else；a&lt;c（1&lt;5）为真，再判断 b&lt;d（3&lt;4）为真，故 x=2。else 始终按「最近未配对 if」配对，与缩进无关。

:::

**2. 执行下列程序后，变量 i 的值为**

- A. 10
- B. 11
- C. 12
- D. 13

::: details 点开核对答案

**答案：D（13）** —— 匹配 case 10，i 变为 11；后面没有 break，依次穿透 case 11（12）、default（13），最后退出 switch。

:::

**3. 以下程序输出结果是**

- A. a=1, b=0
- B. a=2, b=1
- C. a=1, b=1
- D. a=2, b=2

::: details 点开核对答案

**答案：B（a=2, b=1）** —— 外层匹配 case 1；内层 switch(y) 匹配 case 0，a 自增 1，内层 break 只退出内层 switch；外层 case 1 没有 break，继续穿透到 case 2，a、b 各加 1，遇 break 退出。

:::

**4. 下列 switch 用法中，不会导致编译错误的是**

- A. switch('A') 后接字符常量
- B. case 1.5: 后接实型常量
- C. switch(3.5) 使用实型表达式
- D. case 'a': 与 case 97: 同时出现

::: details 点开核对答案

**答案：A（switch('A') 后接字符常量）** —— switch 表达式只能是整型或字符型；case 后也只能是整型/字符型常量；'a' 的 ASCII 码就是 97，与 case 97 重复会报错。只有 A 合法。

:::

**5. 表达式 `-16 >> 2` 的值是**

- A. -4
- B. -8
- C. -2
- D. 4

::: details 点开核对答案

**答案：A（-4）** —— 右移对负数左侧补 1，等价于除以 2ⁿ，所以 -16/4 = -4。正数才是右移补 0。

:::

**6. 已知 `int a=5, b=7`，表达式 `(a ^ b) & ~(-2)` 的值是**

- A. 0
- B. 2
- C. 5
- D. 7

::: details 点开核对答案

**答案：A（0）** —— 5 ^ 7 = 2（0101 ^ 0111 = 0010）；~(-2) 按公式 -x-1 得 1；2 & 1 = 0。

:::
