::: details 温故 · 第 25 课「查找」：折半查找的判定树怎么画？树高是多少？

根 = (low+high)/2 向下取整，左右子树递归同样画法；树高 = ⌊log₂n⌋+1。某元素的比较次数 = 该结点在判定树上的深度。

:::

::: details 温故 · 第 24 课「图的应用」：拓扑排序每一步怎么做？什么样的图才有拓扑序列？

每轮选一个没有前驱（入度为 0）的顶点输出，并删除它及其所有出边，循环到网空。只有有向无环图才有拓扑序列；若输出不完所有顶点，说明图中有环。

:::

## 一、基本概念与稳定性

- **排序**：将无序的记录序列调整为有序的记录序列。
- **内部排序**：整个过程不需访问外存；**外部排序**：记录太多，内存中无法一次完成。
- **稳定性**：相等元素排序后**相对顺序不变**，则该算法稳定。

| 类别 | 算法 |
| --- | --- |
| **稳定** | 冒泡排序、插入排序（含折半插入）、基数排序、归并排序 |
| **不稳定** | 选择排序、堆排序、快速排序、希尔排序 |

::: info

口诀（必背）

**「冒插基归稳，选堆快希不稳」**——冒泡、插入、基数、归并是稳定的；选择、堆、快速、希尔是不稳定的。易错：很多人以为快速排序稳定，其实**快速不稳定，冒泡才稳定**。

:::

## 二、插入排序：直接插入、折半插入、希尔

### 2.1 直接插入排序

思想：每步把一个待排对象**按关键码大小插入到前面已排好序的子序列的适当位置**（边插入边排序）。

逐趟示例（13, 6, 3, 31, 9, 27, 5, 11 升序，共 n−1=7 趟）：

```
<code>(13)→(6,13)→(3,6,13)→(3,6,13,31)→(3,6,9,13,31)
   →(3,6,9,13,27,31)→(3,5,6,9,13,27,31)→(3,5,6,9,11,13,27,31)</code>
```

| 情形 | 复杂度 |
| --- | --- |
| 最好（已有序） | **O(n)**——每插比较 1 次、0 移动 |
| 最坏（逆序） | **O(n²)**——第 i 趟比较 i−1 次：Σ(i−1) = n(n−1)/2 |
| 空间 | O(1)（常数个辅助单元） |

::: danger 易错

考点

**直接插入的时间复杂度与待排序表的初始状态有关**【考】。已有序 → 最好 O(n)；逆序 → 最坏 O(n²)。判断题常拿这一点设陷阱。

:::

### 2.2 折半插入排序（了解）

- 用折半查找定位插入点：时间仍 **O(n²)**，空间 O(1)；
- **比较次数与初始状态无关**；**稳定**；
- **只能用于顺序结构（不能链式）**——折半查找要求随机存取；
- 它只减少**比较**次数，**移动次数不变**。

### 2.3 希尔排序（缩小增量排序）

思想：把序列按增量 d 划分为若干子序列分别做插入排序；**逐趟缩小增量**（如 d=5→d=2→d=1）；前面各趟使序列「基本有序」，最后 d=1 时整体做一次直接插入排序——恰好用上插入排序最好情形的高效率，大幅降低耗时。

| 复杂度 | 值 |
| --- | --- |
| 最好 | O(n) |
| 最坏 | O(n²) |
| 平均 | **O(n^1.3)**（数学上尚未精确解决） |
| 空间 | O(1) |

## 三、交换排序：冒泡与快速

交换排序的总思想：**两两比较，逆序则交换**，直到全部有序。

### 3.1 冒泡排序

每趟两两比较、按**「前小后大」**交换。课件例：T = (21, 25, 49, 25*, 16, 08) 递增：

| 趟 | 结果 |
| --- | --- |
| 初态 | 21 25 49 25* 16 08 |
| 第1趟 | 21 25 25* 16 08 **49** |
| 第2趟 | 21 25 16 08 **25*** 49 |
| 第3趟 | 21 16 08 **25** 25* 49 |
| 第4趟 | 16 08 **21** 25 25* 49 |
| 第5趟 | **08** 16 21 25 25* 49 |

| 情形 | 规则 |
| --- | --- |
| 最好（已有序） | **1 趟，比较 n−1 次，不移动 → O(n)**【记忆】 |
| 最坏（逆序/无序） | **n−1 趟，第 i 趟比较 n−i 次 → O(n²)**【记忆】 |
| 空间 / 稳定性 | O(1)；**稳定** |

::: danger 易错

考点

冒泡排序**必须会写每一趟排序的结果**——上面这张表要能自己从初态一行行推出来，而不是背下来。最好情况不是「n−1 趟」，而是**只需 1 趟**（比较 n−1 次、无交换即停）。

:::

### 3.2 快速排序

1. **任取一个元素作枢轴**（第一个/最后一个/中间/随机均可）；
2. 划分：**比它小的一律前放，比它大的一律后放**——左 ≤ 枢轴 ≤ 右；
3. 对左右子表**递归**重复，直到子表只剩一个元素。

课件例：(49, 38, 65, 97, 76, 13, 27, 49*) 以 49 为枢轴，一趟划分后：

```
<code>(27, 38, 13 | 49 | 76, 97, 65, 49*)   再对左右两侧递归</code>
```

## 四、选择排序：堆与堆排序

### 4.1 堆的定义

- **堆 = 完全二叉树**，用顺序存储（**下标从 1 开始**，方便找左右孩子 2i、2i+1）；
- **大顶堆：任意结点 ≥ 其左右子树，堆顶是最大值**；小顶堆相反（≤，堆顶最小）；
- 判断一个序列是不是堆：按下标画成完全二叉树，逐个核对每个结点与左右孩子的大小关系（例如 94,23,31,72,16,53 是大顶堆）。

### 4.2 堆排序两步（以大顶堆升序为例）

1. **建堆**——**倒着**（从最后一个非叶结点 ⌊n/2⌋ 开始到根）把每个结点为根的子树调整成堆：大者上浮，不合规则则与较大的孩子交换下沉；
2. **排序**——堆顶（最大值）与**堆尾**交换 → 最大值到位；堆规模减 1，重新调整成堆；「后面以此类推」直到全部有序。

::: danger 易错

易错点

**升序用大顶堆**（堆顶最大，交换后沉到尾部）——不是小顶堆。建堆是**倒着**从 ⌊n/2⌋ 开始，不是从根正着调。堆是完全二叉树，用**顺序存储**，不用链式。

:::

## 五、算法对比总表（必背）

| 算法 | 最好 | 最坏/平均 | 空间 | 稳定性 | 初始状态敏感 |
| --- | --- | --- | --- | --- | --- |
| 直接插入 | O(n) | O(n²) | O(1) | 稳定 | 是 |
| 折半插入 | — | O(n²)（比较次数与初态无关） | O(1) | 稳定 | 仅比较无关 |
| 希尔 | O(n) | 平均 O(n^1.3) | O(1) | **不稳定** | 是 |
| 冒泡 | O(n) | O(n²) | O(1) | 稳定 | 是 |
| 快速 | — | 平均 O(nlog₂n) | O(log₂n) 递归栈 | **不稳定** | 是（有序时最坏） |
| 简单选择 | — | O(n²) | O(1) | **不稳定** | 比较次数无关 |
| 堆排序 | — | O(nlog₂n) | O(1) | **不稳定** | 否 |
| 归并 | — | O(nlog₂n) | O(n) | 稳定 | 否 |
| 基数 | — | O(d(n+r)) | O(r) | 稳定 | 否 |

::: danger 易错

真实缺口：归并排序与基数排序

归并排序、基数排序在考点列表中，但两讲课件**未展开讲解**——这是真实缺口。上表已收录两者的结论（归并 O(nlog₂n)/O(n)/稳定，基数 O(d(n+r))/O(r)/稳定），复习时请**按教材补充**这两块的原理与手算过程。

:::

## 六、先回忆，再自测

::: details 稳定/不稳定的排序各有哪些？

口诀「冒插基归稳，选堆快希不稳」：稳定——冒泡、插入（直接/折半）、归并、基数；不稳定——选择、希尔、快速、堆。

:::

::: details 冒泡排序最好/最坏的趟数与比较次数？

最好：已有序，1 趟比较 n−1 次、无交换即停 → O(n)；最坏：n−1 趟，第 i 趟比较 n−i 次 → O(n²)。

:::

::: details 快速排序的一趟划分做什么？

以枢轴为界，小者前放、大者后放（左 ≤ 枢轴 ≤ 右），再对左右子表递归。

:::

::: details 堆排序的两步？怎么判断一个序列是不是堆？

① 倒着从最后一个非叶结点 ⌊n/2⌋ 建堆；② 堆顶与堆尾交换、规模减 1、再调整，循环。判断：按下标画成完全二叉树，检查每个结点与其左右孩子的大小关系（大顶堆双亲 ≥ 孩子）。

:::

## 七、测验（点击选项作答）

**1. 下列排序算法中，稳定的是**

- A. 快速排序
- B. 希尔排序
- C. 冒泡排序
- D. 简单选择排序

::: details 点开核对答案

**答案：C（冒泡排序）** —— 口诀「冒插基归稳，选堆快希不稳」。稳定的只有冒泡、插入、基数、归并；快速、希尔、选择、堆都不稳定。

:::

**2. 待排序列已经有序时，直接插入排序的情况是**

- A. 每插比较 1 次、0 移动，总时间 O(n)
- B. 每趟比较 i−1 次，总时间 O(n²)
- C. 比较次数与初始状态无关
- D. 必须移动 n(n−1)/2 次

::: details 点开核对答案

**答案：A（每插比较 1 次、0 移动，总时间 O(n)）** —— 已有序是最好情形：每插比较 1 次不移动 → O(n)；逆序才是最坏 O(n²)。直接插入的复杂度与初始状态有关【考】；「比较次数与初态无关」说的是折半插入。

:::

**3. 关于折半插入排序，下列说法正确的是**

- A. 它减少了元素的移动次数
- B. 比较次数与初始状态无关，且稳定
- C. 可以用于链式存储结构
- D. 时间复杂度为 O(nlog₂n)

::: details 点开核对答案

**答案：B（比较次数与初始状态无关，且稳定）** —— 折半插入只减少比较次数（与初态无关），移动次数不变；时间仍 O(n²)；因折半查找需要随机存取，只能用于顺序结构；它是稳定的。

:::

**4. 希尔排序的平均时间复杂度是**

- A. O(n)
- B. O(n²)
- C. O(n^1.3)
- D. O(nlog₂n)

::: details 点开核对答案

**答案：C（O(n^1.3)）** —— 希尔排序的平均复杂度 O(n^1.3)（数学上尚未精确解决）；最好 O(n)、最坏 O(n²)、空间 O(1)。

:::

**5. 序列已经有序时，冒泡排序**

- A. 仍需 n−1 趟才能结束
- B. 1 趟比较 n−1 次后即停，时间 O(n)
- C. 1 趟只比较 1 次
- D. 无法提前判断有序

::: details 点开核对答案

**答案：B（1 趟比较 n−1 次后即停，时间 O(n)）** —— 最好情形只需 1 趟：比较 n−1 次、无交换即停 → O(n)。最坏才是 n−1 趟、第 i 趟比较 n−i 次。冒泡的每趟结果必须会写。

:::

**6. 关于堆排序，下列说法正确的是**

- A. 升序排序应使用小顶堆
- B. 建堆应从根结点开始逐个向下调整
- C. 建堆从最后一个非叶结点 ⌊n/2⌋ 倒着调整；排序时堆顶与堆尾交换、规模减 1 再调整
- D. 堆必须用链式存储

::: details 点开核对答案

**答案：C（建堆从最后一个非叶结点 ⌊n/2⌋ 倒着调整；排序时堆顶与堆尾交换、规模减 1 再调整）** —— 升序用大顶堆（堆顶最大沉到尾部）；建堆是倒着从 ⌊n/2⌋ 开始；堆是完全二叉树，用顺序存储（下标从 1 便于找 2i、2i+1）。

:::
