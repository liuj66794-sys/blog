::: details 温故 · 第 11 课「指针基础与一维数组」：& 和 * 的运算对象各有什么限制？指针初始化的两条硬性规则是什么？

& 后面只能跟变量；* 后面只能跟地址或指针。规则：① 基类型必须一致；② 指针变量只能赋地址（0 或 NULL 除外）。

::: details 温故 · 第 10 课「函数进阶」：数组名作实参时，形参的改变会影响实参数组吗？为什么？

会。数组名传的是首元素地址，形参数组与实参数组共用同一片内存单元，所以形参元素变化实参跟着变化。

## 一、二维数组：降维寻址

把二维数组看成「元素是行」的一维数组。`int a[3][3]` 里，`a` 的元素是 `a[0]`、`a[1]`、`a[2]` 三行；`a[0]` 本身又是该行一维数组的数组名。

| 表达式 | 含义 |
| --- | --- |
| `a` | 二维数组名，即首行地址 `&a[0]` |
| `a+i` / `&a[i]` | 第 i **行**的地址 |
| `*(a+i)` / `a[i]` | 第 i 行首元素地址 `&a[i][0]` |
| `*(a+i)+j` / `a[i]+j` | i 行 j 列元素的**地址** `&a[i][j]` |
| `*(*(a+i)+j)` / `*(a[i]+j)` | i 行 j 列元素的**值** `a[i][j]` |
| `*a` / `a[0]` | 0 行 0 列元素地址 `&a[0][0]` |

::: danger 易错

数值相同 ≠ 类型相同

`a` 与 `&a[0][0]` 数值相同，但类型不同：`a` 是「指向一行数组的指针」`int(*)[n]`，`a[0]` 与 `&a[0][0]` 是「指向 int 的指针」`int *`。这就是 `a+1` 跳一行、`a[0]+1` 跳一个 int 的原因。

:::

**数组指针**指向一整行：

```
<code>int (*p)[3];   /* p 指向"含 3 个 int 的一行数组" */
p = a;         /* p+1 跳一整行 */
/* 访问 a[i][j] 可写 p[i][j] 或 *(*(p+i)+j) */</code>
```

## 二、字符串与字符指针

字符串是常量，存放在常量区，`"abcd"` 本身表示第一个字符的地址，末尾自动含 `'\0'`。

| 写法 | 合法性 | 原因 |
| --- | --- | --- |
| `char *s = "hello";` | 合法 | 声明时初始化，s 接收字符串首地址 |
| `char *s; *s = "hello";` | 非法 | `*s` 是字符，不是指针变量，不能接收地址 |
| `char *s; s = {"abcd"};` | 非法 | 花括号初始化列表只能用于声明初始化，不能用于赋值语句 |
| `char s[10]; s = "abcd";` | 非法 | 数组名是地址常量，不能整体赋值，应使用 `strcpy(s, "abcd")` |

::: info

手写字符串复制函数

```
<code>void Mystrcpy(char *dest, char *src) {
    while ((*dest++ = *src++) != '\0');
}</code>
```

循环把 `*src` 赋给 `*dest`，然后两者同时后移，直到把 `'\0'` 也复制过去。如果逐字符循环手动复制，记得**手动补 `'\0'`**，否则输出会越界乱码。

同时记住：笔记 08 §4.2 明确 **Mystrcat**（先把指针走到 dest 末尾，再逐位复制 src）与 **Mystrcmp**（逐位比较字符、返回差值）也考手写，一并练熟。

:::

## 三、五种带 * 的声明辨析

判断规则：**看 `*p` 先与谁结合**。与 `[]` 结合是数组，与 `()` 结合是函数，先与 `*` 结合才是指针变量。

| 声明 | 本质 | 读法 |
| --- | --- | --- |
| `int (*p)[4]` | 指针变量 | 数组指针：指向含 4 个 int 的一行数组 |
| `int *p[4]` | 数组 | 指针数组：4 个元素，每个都是 int* 指针 |
| `int (*p)()` | 指针变量 | 函数指针：指向返回 int 的函数 |
| `int *p()` | 函数 | 返回 int* 指针的函数 |
| `int **p` | 指针变量 | 二级指针：指向 int* 指针的指针 |

二级指针的双重取值：以 `int a, *p=&a, **q=&p;` 为例，q 存的是**指针 p 的地址**，`*q` 是 p（即 a 的地址），`**q` 才是 a 的值——链路 q→p→a，两次取值才到底。

::: danger 易错

两个常见陷阱

① `int *p[4]` 是数组不是指针，`int(*p)[4]` 才是指向一行的指针；② 函数指针不能做算术运算，`p+1` 无意义。

:::

::: danger 易错

课件范围提醒

指针章部分课件（指针【三】【五】）缺失，本课已覆盖二维数组指针、字符串指针等高频考点；其余未讲到的更细内容按谭浩强《C程序设计》教材补齐，避免考纲缺口。

:::

## 四、先回忆，再自测

::: details 合上笔记，写出 a[i][j] 的地址形式和值形式（至少各两种）

地址：`&a[i][j]`、`a[i]+j`、`*(a+i)+j`；值：`a[i][j]`、`*(a[i]+j)`、`*(*(a+i)+j)`。写错一个就回到表格再默一次。

:::

::: details char *s = "hello"; 合法，为什么 char *s; *s = "hello"; 与 char s[10]; s = "hello"; 都非法？

第一句是声明时初始化，`s` 是指针变量可接收地址。第二句 `*s` 是字符不能接收地址。第三句 `s` 是数组名（地址常量），不能出现在赋值号左边，需用 `strcpy`。

:::

::: details 快速判断：int(*p)[4] 与 int *p[4] 的本质区别是什么？

括号改变结合顺序。`(*p)` 先与 `*` 结合 → `p` 是指针 → 数组指针；无括号时 `[]` 优先级高 → `p` 先与 `[4]` 结合 → `p` 是数组 → 指针数组。

:::

## 五、测验（点击选项作答）

**1. 设有 `int a[3][3];`，下列表达式中代表 `a[1][2]` 值的是**

- A. `a+1+2`
- B. `*(a+1)+2`
- C. `*(*(a+1)+2)`
- D. `**(a+1+2)`

::: details 点开核对答案

**答案：C（((a+1)+2)）** —— &lt;code&gt;a+1&lt;/code&gt; 是第 1 行地址；&lt;code&gt;*(a+1)&lt;/code&gt; 即 &lt;code&gt;a[1]&lt;/code&gt;，是第 1 行首地址；+2 到 &lt;code&gt;&a[1][2]&lt;/code&gt;；再取 * 才是值。A 是行地址运算，B 是元素地址，D 越界到第 3 行。

:::

**2. 关于字符串指针，下列说法正确的是**

- A. `char *s; *s = "abc";` 合法
- B. `char *s = "abc";` 合法
- C. `char s[10]; s = "abc";` 合法
- D. `char *s; s = {"abc"};` 合法

::: details 点开核对答案

**答案：B（char s = "abc"; 合法）** —— 只有声明时直接初始化合法。&lt;code&gt;*s&lt;/code&gt; 是字符不能收地址；数组名是常量不能赋值；花括号列表只能用于初始化不能用于赋值语句。

:::

**3. 对于 `int a[3][3];`，`a` 与 `&a[0][0]` 的关系是**

- A. 地址值与类型均相同
- B. 地址值不同但类型相同
- C. 地址值不同且类型不同
- D. 地址值相同但类型不同

::: details 点开核对答案

**答案：D（地址值相同但类型不同）** —— 数值上都指向数组开头，但 &lt;code&gt;a&lt;/code&gt; 是 &lt;code&gt;int(*)[3]&lt;/code&gt;（指向一行），&lt;code&gt;&a[0][0]&lt;/code&gt; 是 &lt;code&gt;int *&lt;/code&gt;。因此 &lt;code&gt;a+1&lt;/code&gt; 跳一行，&lt;code&gt;&a[0][0]+1&lt;/code&gt; 跳一个 int。

:::

**4. `int (p)[4];` 中，`p` 的本质是**

- A. 指向含 4 个 int 的一维数组
- B. 含 4 个 int 指针的数组
- C. 返回 int 指针的函数
- D. 指向返回 int 函数的指针

::: details 点开核对答案

**答案：A（指向含 4 个 int 的一维数组）** —— 括号使 &lt;code&gt;*p&lt;/code&gt; 先结合，&lt;code&gt;p&lt;/code&gt; 是指针；&lt;code&gt;[4]&lt;/code&gt; 修饰指向的对象是一维数组。B 是 &lt;code&gt;int *p[4]&lt;/code&gt;，C 是 &lt;code&gt;int *p()&lt;/code&gt;，D 是 &lt;code&gt;int (*p)()&lt;/code&gt;。

:::

**5. 下列定义中，`p` 是数组而不是指针的是**

- A. `int **p;`
- B. `int *p[4];`
- C. `int (*p)[4];`
- D. `int (*p)();`

::: details 点开核对答案

**答案：B（int p[4];）** —— &lt;code&gt;[]&lt;/code&gt; 优先级高于 &lt;code&gt;*&lt;/code&gt;，&lt;code&gt;p&lt;/code&gt; 先与 &lt;code&gt;[4]&lt;/code&gt; 结合，所以 &lt;code&gt;int *p[4]&lt;/code&gt; 是指针数组（数组），其余三项中 &lt;code&gt;p&lt;/code&gt; 都是指针变量。

:::

**6. 手写 `Mystrcpy(dest, src)` 时，循环结束的条件是**

- A. `*src == '0'`
- B. `*dest == '\0'`
- C. `(*dest++ = *src++) == '\0'`
- D. `(*dest = *src) != 0`

::: details 点开核对答案

**答案：C（(dest++ = src++) == '\0'）** —— C 在赋值的同时把 &lt;code&gt;'\0'&lt;/code&gt; 也复制到 &lt;code&gt;dest&lt;/code&gt;，并移动两个指针，循环自然终止。A 判断字符 '0' 错误；B 未复制结束符；D 只复制一次不移动指针。

:::

**7. 已知 `int x=5, p=&x, q=&p;`，则 `q` 的值是**

- A. x 的地址
- B. p 的地址
- C. 5
- D. q 的地址

::: details 点开核对答案

**答案：C（5）** —— q 存 p 的地址；*q 即 p，是 x 的地址；再取一次 **q 才是 x 的值 5。二级指针要解两次引用才到达数据。

:::
