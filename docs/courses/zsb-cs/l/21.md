::: details 温故 · 第 20 课「二叉树的遍历与还原」：先序、中序、后序遍历的口诀分别是什么？层次遍历借助什么结构？

先序根左右、中序左根右、后序左右根；层次遍历从上到下、从左至右，借助队列（根入队→出队访问→左右孩子依次入队→循环至队空）。

:::

::: details 温故 · 第 19 课「树与二叉树基础」：n 个结点的二叉链表有多少个空链域？为什么？

n+1 个。二叉链表共 2n 个指针域，n 个结点的二叉树有 n-1 条分支，2n-(n-1)=n+1，注意不是 n-1 也不是 2n。

:::

::: info

为什么这节课重要

转换与存储是数据结构大题的常客：给一棵树让你画二叉树、给遍历序列让你还原森林、给存储结构让你写指针含义。你已经学过一轮，这节课把「转换规则 + 遍历对应 + 存储选择」三根桩一次打牢。

:::

## 一、树 → 二叉树：左孩子、右兄弟

转换规则只有一句话：**左孩子 = 原来的孩子，右孩子 = 原来的兄弟**。操作上分三步：

1. 把每个结点的相邻兄弟用线连起来（兄弟连线）。
2. 每个结点只保留与第一个孩子的连线，其余孩子沿兄弟线串起来。
3. 以根为轴顺时针转 45°，原来的孩子连线变为左分支，兄弟连线变为右分支。

::: info

转换后的两个铁律

① **形态唯一**——同样的树只能得到同一棵二叉树；② **根的右子树必为空**，因为根没有兄弟。凡是说「树转二叉树后根可能有右子树」的选项都是错的。

:::

## 二、森林 → 二叉树：根根串成右链

森林是 m 棵互不相交的树的集合。转换分两步：

1. 把森林中的每棵树各自按「左孩子、右兄弟」转成二叉树。
2. 第一棵二叉树的根作为总根；第二棵树的根作为第一棵根的**右孩子**，第三棵树的根作为第二棵根的右孩子……依次向右串下去。

## 三、遍历对应关系【易错】

| 对象 | 自身遍历 | 对应二叉树遍历 | 记忆要点 |
| --- | --- | --- | --- |
| 树 | 先序遍历 | 先序遍历 | 根 → 子树，与二叉树根左右一致 |
| 树 | 后序遍历 | **中序遍历** | 最易错：树没有中序，但二叉树中序等价于树后序 |
| 森林 | 先序遍历 | 先序遍历 | 按树顺序，每棵内部先序 |
| 森林 | 中序遍历 | 中序遍历 | 森林有中序，对应二叉树中序 |

::: danger 易错

高频陷阱

**树只有先序和后序两种遍历**，没有中序。一旦题目问「树的中序遍历等价于二叉树的什么」，要先判断题干本身就在挖坑——树的合法遍历里没有中序。正确对应是：树的后序 ↔ 二叉树的中序。

:::

## 四、存储结构：二叉链表与三种树表示

### 二叉树的存储

- **顺序存储**：按完全二叉树编号 1..n 放进一维数组。适合完全二叉树，一般二叉树会浪费空间。
- **二叉链表**：每个结点含 lchild、data、rchild。n 个结点的二叉链表共有 **n+1 个空链域**（总指针域 2n，减去 n−1 条分支）。

### 线索二叉树

利用这 n+1 个空链域存放**某种遍历次序下的前驱或后继指针**，这些指针叫**线索**，加线索的过程叫**线索化**。为了区分指针含义，引入标志位：

- ltag = 0：lchild 指向左孩子；ltag = 1：lchild 指向遍历前驱。
- rtag = 0：rchild 指向右孩子；rtag = 1：rchild 指向遍历后继。

### 树的三种存储表示

| 表示法 | 结点结构 | 适用场景 |
| --- | --- | --- |
| 双亲表示法 | data + parent（根为 −1） | 频繁找双亲 |
| 孩子表示法 | data + 孩子单链表头指针 | 频繁找孩子 |
| 孩子兄弟表示法 | data + 第一个孩子指针 + 下一个兄弟指针 | 把普通树转为二叉树，又称二叉树表示法 |

## 五、先回忆，再自测

::: details 合上笔记默写：树转二叉树的三步口诀，以及转换后根结点的特征。

兄弟连线 → 只留第一孩子 → 顺时针转 45°。结果是：左孩子 = 原来的孩子，右孩子 = 原来的兄弟；转换唯一，且根的右子树必为空。

:::

::: details 树的后序遍历，等价于转换后二叉树的哪种遍历？森林的中序遍历呢？

树的后序 ↔ 二叉树的中序；森林的中序 ↔ 二叉树的中序。注意：树本身没有「中序遍历」这一说法，不要被题干带偏。

:::

::: details 线索二叉树用空指针域存什么？标志位 1 和 0 分别代表什么？

空指针域存放该遍历次序下的前驱或后继线索。标志位 0 表示指针指向孩子，1 表示指针指向线索（前驱或后继）。

:::

## 六、测验（点击选项作答）

**1. 一棵树转换为二叉树后，其根结点的右子树**

- A. 一定为空
- B. 存放第一子树
- C. 保存森林总根
- D. 由树高决定

::: details 点开核对答案

**答案：A（一定为空）** —— 根结点没有兄弟，所以右孩子必为空。右子树放的是兄弟，不是孩子，也不是森林总根。

:::

**2. 森林转换为二叉树时，第二棵树的根应作为**

- A. 第一棵根的左孩子
- B. 第一棵根的右孩子
- C. 森林总根的左孩子
- D. 森林总根的右孩子

::: details 点开核对答案

**答案：B（第一棵根的右孩子）** —— 森林转二叉树后，各树的根通过右指针依次串接：第二棵树的根是第一棵树根的右孩子，第三棵是第二棵的右孩子，依此类推。

:::

**3. 对一棵树进行后序遍历，等价于对其二叉树表示进行**

- A. 先序遍历
- B. 中序遍历
- C. 后序遍历
- D. 层次遍历

::: details 点开核对答案

**答案：B（中序遍历）** —— 易错点：树的先序对应二叉树先序；树的后序对应二叉树中序。树本身没有中序遍历，不要混淆。

:::

**4. 用二叉链表存储 n 个结点的二叉树，空指针域的个数为**

- A. n−1 个
- B. n 个
- C. n+1 个
- D. 2n 个

::: details 点开核对答案

**答案：C（n+1 个）** —— 二叉链表共有 2n 个指针域；n 个结点的二叉树有 n−1 条分支，每条分支占用一个指针，故空指针域 = 2n − (n−1) = n+1。

:::

**5. 下列关于线索二叉树的说法，正确的是**

- A. 线索只存于左指针
- B. 标志位为 0 表示线索
- C. 空指针可存前驱后继
- D. 线索化后空链域增多

::: details 点开核对答案

**答案：C（空指针可存前驱后继）** —— 线索可以放在左空指针（前驱）或右空指针（后继）；标志位 0 表示指向孩子，1 表示指向线索；线索化正是利用空链域，不会增多。

:::

**6. 孩子兄弟表示法中，结点的右指针指向的是**

- A. 下一个兄弟
- B. 第一个孩子
- C. 双亲结点
- D. 最左兄弟

::: details 点开核对答案

**答案：A（下一个兄弟）** —— 孩子兄弟表示法 = 左指针指第一个孩子，右指针指下一个兄弟。它是普通树转成二叉树的存储基础。

:::
