## 一、树的术语：先对齐名词

树是 **n 个结点的有限集**，有一个根，其余结点分成若干互不相交的子树。核心逻辑：根没有前驱，其他结点有且只有一个前驱，叶子没有后继。

| 术语 | 含义 | 易错提醒 |
| --- | --- | --- |
| 结点的度 | 该结点拥有的子树个数 | 不是「孩子个数」的口语说法，就是子树数 |
| 树的度 | 各结点度的最大值 | 不是所有度之和 |
| 叶子/终端结点 | 度为 0 的结点 | — |
| 深度 | 从根往下数到该结点的层数，根为第 1 层 | 不是从 0 开始 |
| 高度 | 从该结点往下到叶子的最长路径层数 | 深度从根往下，高度从叶子往上 |
| 森林 | m 棵互不相交的树的集合 | m≥0，空森林也是森林 |
| 有序树/无序树 | 子树从左到右能否互换 | 二叉树一定是「左右有序」 |

## 二、二叉树定义与六条性质

### 2.1 定义

二叉树不是「度为 2 的树」。它的定义只有两点：

1. 每个结点最多有两棵子树（度 ≤ 2）；
2. **左右子树有顺序**——即使只有一个孩子，也要说清楚是左还是右。

**满二叉树**：所有分支结点都有左右孩子，且所有叶子都在同一层。

**完全二叉树**：满二叉树从下往上、从右到左逐个删除结点得到，**满二叉树是完全二叉树的特例**。

::: danger 易错

最高频陷阱

「二叉树是度为 2 的有序树」是错的。二叉树可以是空树、可以只有左/右孩子、可以没有度为 2 的结点；但它的左右子树永远有区别。

:::

### 2.2 六条性质（必背）

| 编号 | 内容 | 常见用途 |
| --- | --- | --- |
| 1 | 第 i 层至多有 `2^(i-1)` 个结点（i≥1） | 层数与结点数上限 |
| 2 | 深度为 k 的二叉树至多有 `2^k − 1` 个结点 | 最大结点数/高度下限 |
| 3 | **n₀ = n₂ + 1**（叶子数 = 度 2 结点数 + 1） | 已知 n₂ 求叶子，或已知 n₀、n₁ 求总结点 |
| 4 | 完全二叉树按 1..n 编号：双亲 `⌊i/2⌋`；左孩子 `2i`（若 ≤n）；右孩子 `2i+1`（若 ≤n） | 由编号推父子 |
| 5 | n 个结点的完全二叉树深度为 `⌊log₂n⌋+1` | 完全二叉树高度 |
| 6 | n 个结点的完全二叉树：n 为奇数时叶子 `(n+1)/2` 个；n 为偶数时叶子 `n/2` 个 | 快速口算叶子数 |

性质 2 的另一半（随堂练习 10 的题型）：反过来由结点数定高度——**n 个结点的二叉树高度范围为 `⌈log₂(n+1)⌉ ~ n`**，最矮是完全形态 ⌈log₂(n+1)⌉ 层，最高是每层一个结点的单支树 n 层。

::: info

性质 3 的快速记忆

总分支数 = n−1（树的基本事实，n 个结点的树有 n−1 条边）。另一方面，总分支数 = n₁ + 2n₂。两式联立：n−1 = n₁ + 2n₂，且 n = n₀ + n₁ + n₂，消去 n₁ 即得 **n₀ = n₂ + 1**。

:::

::: danger 易错

完全二叉树的 n₁ 只有 0 或 1

n 为奇数时，n₁ = 0；n 为偶数时，n₁ = 1。做题时若算出 n₁≥2，一定哪里错了。

:::

### 2.3 三道口算示范

- 1001 个结点的完全二叉树，叶子数 = **501**（奇数 → (1001+1)/2）。
- 100 个结点的完全二叉树，度 2 结点数 = **49**（n₀=50，n₁=1，n₂=n₀−1=49）。
- 完全二叉树有 500 个叶子，总结点数最少 = **999**（n₂=499，完全二叉树 n₁ 取最小 0，n=500+0+499）。

## 三、二叉链表：为什么是 n+1 个空链域

二叉链表每个结点有 `lchild` 和 `rchild` 两个指针，共 `2n` 个指针域。n 个结点的二叉树有 `n−1` 条分支，每条分支占用一个指针。所以空指针数 = `2n − (n−1) = n+1`。

这些空链域在线索二叉树中会被用来存放遍历次序下的前驱/后继指针，称为**线索**。但本节课只需要记住数字：**n 个结点的二叉链表有 n+1 个空链域**。

## 四、先回忆，再自测

::: details 合上笔记默写：二叉树六条性质中涉及数值的三组公式

- 第 i 层最多：2^(i−1)；深度 k 最多：2^k−1。
- n₀ = n₂ + 1。
- 完全二叉树深度：⌊log₂n⌋+1；编号 i 的双亲 ⌊i/2⌋，左孩子 2i，右孩子 2i+1（≤n 才存在）。

写不全就再看一遍表格，然后重默一次。

:::

::: details 为什么 n 个结点的二叉链表恰好有 n+1 个空链域？

2n 个指针域 − (n−1) 条分支 = n+1 个空指针。注意不是 n−1，也不是 2n。

:::

::: details 完全二叉树 100 个结点，编号 60 的结点的度是多少？

度为 0。60 的左右孩子编号为 120、121，均大于 100，不存在，所以 60 是叶子。

:::

::: details 1025 个结点的二叉树，高度范围是多少？

11~1025。最矮为 ⌈log₂(1025+1)⌉ = ⌈log₂1026⌉ = 11 层，最高是单支树 1025 层——正是「n 个结点高度范围 ⌈log₂(n+1)⌉ ~ n」的具体应用。

:::

## 五、测验（点击选项作答）

**1. 某二叉树有 10 个度为 2 的结点，则叶子结点数为**

- A. 9 个
- B. 10 个
- C. 11 个
- D. 12 个

::: details 点开核对答案

**答案：C（11 个）** —— 由性质 3，n₀ = n₂ + 1 = 10 + 1 = 11。注意不是 n₀ = n₂。

:::

**2. 100 个结点的完全二叉树，编号 49 的左孩子编号为**

- A. 96
- B. 97
- C. 98
- D. 99

::: details 点开核对答案

**答案：C（98）** —— 左孩子编号 = 2i = 98，且 98 ≤ 100，所以存在。

:::

**3. 10 个结点的二叉链表共有多少个空链域**

- A. 9 个
- B. 10 个
- C. 11 个
- D. 12 个

::: details 点开核对答案

**答案：C（11 个）** —— n 个结点的二叉链表空链域数为 n+1 = 11。来源：2n 个指针域减去 n−1 条分支。

:::

**4. 深度为 4 的二叉树，结点数最多为**

- A. 7 个
- B. 8 个
- C. 15 个
- D. 16 个

::: details 点开核对答案

**答案：C（15 个）** —— 性质 2：深度 k 的二叉树最多 2^k − 1 个结点。2^4 − 1 = 15。

:::

**5. 关于完全二叉树，下列说法正确的是**

- A. 满二叉树不是完全二叉树
- B. 叶子只可能出现在最后一层
- C. 编号 i 的双亲编号为 i/2
- D. 总结点 n 为偶数时 n₁=1

::: details 点开核对答案

**答案：D（总结点 n 为偶数时 n₁=1）** —— A 错：满二叉树是完全二叉树的特例；B 错：叶子可在倒数第二层；C 错：双亲应为 ⌊i/2⌋；D 对：完全二叉树 n 为奇数时 n₁=0，偶数时 n₁=1。

:::

**6. 下列关于二叉树的说法正确的是**

- A. 二叉树等同于度为 2 的树
- B. 二叉树每个结点度为 2
- C. 二叉树的子树有左右之分
- D. 二叉树一定不允许为空树

::: details 点开核对答案

**答案：C（二叉树的子树有左右之分）** —— 二叉树允许为空、度可为 0/1，核心特征只是「最多两棵子树且左右有序」。A、B、D 都是常见错误表述。

:::
