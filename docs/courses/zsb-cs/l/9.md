::: details 温故 · 第 8 课「数组与字符串」：数组名代表什么？为什么 a++ 非法？a+1 实际加几个字节？

数组名是首元素地址（&a[0]），属于地址常量，所以 a++、a=a+1 都非法。a+1 实际加 sizeof(元素类型) 字节，对 int 数组就是 4 字节。

:::

::: details 温故 · 第 7 课「循环结构」：while 与 do-while 最少各执行几次？for 的三个表达式分别在什么时候执行？

while 先判断，条件一开始不成立就 0 次；do-while 先执行，至少 1 次。for：表达式 1 只执行一次；表达式 2 在循环体前判断；表达式 3 在循环体后执行。

:::

为什么先学基础

函数是 C 程序的基本单位，「先定义后使用」「传值单向」「return 只返一个值」是历年选择、填空、判断的高频雷区。高级内容（递归、数组名作参数、static）放在下一课。

## 一、定义与调用

函数必须先定义后使用。一个完整的函数定义包括**类型、函数名、参数列表、函数体**：

```
<code>int add(int a, int b) {      /* 有参函数：类型 int，参数 int a, int b */
    return a + b;
}

void hello(void) {           /* 无参函数，无返回值 */
    printf("hello\n");
}</code>
```

调用时把实参的值传给形参：

```
<code>int s = add(3, 5);           /* 实参 3、5 → 形参 a、b */
hello();                     /* 无参调用不能省略 () */</code>
```

::: danger 易错

先定义后使用

如果被调函数写在主调函数**后面**，调用前必须**声明**。声明只告诉编译器函数的「类型 + 名字 + 参数类型」，不写函数体。

:::

## 二、声明的两种写法

两种声明都合法，编译器只看类型、数量和顺序，不看形参名：

```
<code>int add(int a, int b);       /* 写法一：带形参名 */
int add(int, int);           /* 写法二：只写参数类型 */</code>
```

若多个函数都要调用同一个函数，可把声明放在所有函数之外，形成**外部声明（全局声明）**，一处声明处处可用。

## 三、形参 vs 实参：传值单向

| 对比项 | 实参 | 形参 |
| --- | --- | --- |
| 出现位置 | 调用处的括号内 | 定义处的括号内 |
| 允许形式 | 常量、变量、表达式、有返回值的函数 | 只能是变量 |
| 存储空间 | 自己的独立空间 | 自己的独立空间 |
| 类型要求 | 数量、类型一致（"虚实结合"） |   |

**传值调用 = 单向赋值**：实参把值复制给形参，被调函数里修改形参不会影响实参。例如：

```
<code>void swap(int a, int b) { int t = a; a = b; b = t; }
int main() {
    int x = 3, y = 5;
    swap(x, y);              /* x、y 仍然是 3、5 */
}</code>
```

::: info

巩固期辨析

「形参变了实参也变」是经典错法，只有在数组名作参数（传址）时才成立，本课先记住：普通变量传值单向，实参不变。

:::

## 四、return 的三条规则

1. **只能返回一个值**：`return a, b;` 返回的是逗号表达式的值，即 `b`，不是两个值。
2. **执行到 return 函数即结束**，其后的代码不再执行。
3. **返回值自动转换为函数类型**；void 函数不能写 `return 值;`，调用结果也不能赋值或输出。

## 五、先回忆，再自测

::: details 合上笔记默写：函数定义的四个组成部分、两种声明写法

类型、函数名、参数列表、函数体。声明：int fun(int x, int y); 或 int fun(int, int);（形参名可省）。

:::

::: details 调用 swap(x, y) 后，普通变量 x、y 会交换吗？为什么？

不会。普通变量传值是单向的，形参 a、b 各自占独立空间，修改形参不影响实参。

:::

::: details return (a, b); 到底返回几个值？值是什么？

返回一个值。括号内是逗号表达式，值等于最右操作数 b。

:::

## 六、测验（点击选项作答）

**1. 下列关于函数声明的说法，正确的是**

- A. 声明必须写出函数体以便编译
- B. 声明可省略形参名只写类型
- C. 声明能替代函数定义使用
- D. 被调函数在前时也必须声明

::: details 点开核对答案

**答案：B（声明可省略形参名只写类型）** —— 声明只说明类型、名字、参数类型，不写函数体；被调函数定义在主调函数之前时不需要声明。

:::

**2. 有参函数调用时，实参允许的形式是**

- A. 只能是未赋值的变量
- B. 只能是常量不能是变量
- C. 常量、变量或表达式均可
- D. 必须与被调函数同名

::: details 点开核对答案

**答案：C（常量、变量或表达式均可）** —— 实参可以是常量、变量、表达式或有返回值的函数；形参只能是变量，用于接收实参值。

:::

**3. 函数 f 中将形参 a 加 1，调用 f(x) 后 x 的值**

- A. 保持不变，因为传值单向
- B. 也加 1，因为形参实参同步
- C. 变成随机值，不可确定
- D. 取决于 return 是否写 a

::: details 点开核对答案

**答案：A（保持不变，因为传值单向）** —— 普通变量作实参是单向值传递，形参变化不影响实参；数组名作实参才传址。

:::

**4. 对于函数 int fun(double x) { return x; }，返回值类型是**

- A. double，与参数类型一致
- B. void，因为会发生截断
- C. 自动提升为 long double
- D. int，按函数类型自动转换

::: details 点开核对答案

**答案：D（int，按函数类型自动转换）** —— 返回值类型由函数类型决定，与参数类型无关；不一致时自动转换为函数类型，int fun 返回 int。

:::

**5. 函数 void print(int n) 的调用方式，正确的是**

- A. int a = print(5); printf("%d", a);
- B. print(5);
- C. printf("%d", print(5));
- D. return print(5);

::: details 点开核对答案

**答案：B（print(5);）** —— void 函数调用无返回值，不能赋值、不能输出、不能作为 return 的表达式。

:::

**6. 执行 return (3, 5); 时，函数实际返回的值是**

- A. 3
- B. 8
- C. 5
- D. 语法错误，不能返回

::: details 点开核对答案

**答案：C（5）** —— return 只能返回一个值；(3, 5) 是逗号表达式，值为最后一个操作数 5。

:::
