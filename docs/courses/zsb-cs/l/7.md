## 一、while 与 do-while：先判还是先执行

| 循环 | 语法 | 执行顺序 | 最少次数 |
| --- | --- | --- | --- |
| while | `while(表达式) 语句;` | 先判断表达式，为真再执行 | **≥0 次** |
| do-while | `do 语句; while(表达式);` | 先执行一次，再判断表达式 | **≥1 次** |

::: info

高频对比

条件一开始就不成立时，while 的循环体一次都不执行；do-while 已经执行完那一次。do-while 的 `while(表达式)` 后面**必须加分号**，且 `do` 不能单独出现。

:::

累加 `1+2+…+100` 的 while 写法：

```
<code>#include <stdio.h>
int main()
{
    int i = 1, sum = 0;   /* 累加器必须置 0，否则脏数据影响结果 */
    while (i <= 100)
    {
        sum = sum + i;
        i++;
    }
    printf("sum=%d i=%d\n", sum, i);
    return 0;
}
</code>
```

循环结束后 **i = 101**：i=100 时进入循环，i++ 后变成 101 才退出。累乘 `1×2×…×10` 时，存放乘积的变量必须**置 1**，否则乘 0 会全部归零。

## 二、for：三表达式的“固定走位”

```
<code>for(表达式1; 表达式2; 表达式3) 语句;</code>
```

| 表达式 | 执行时机 | 省略或写错会怎样 |
| --- | --- | --- |
| 表达式 1 | 只执行一次，用于设初值 | 可在 for 之前定义 |
| 表达式 2 | 循环体**前**判断 | 省略默认恒真 → **死循环** |
| 表达式 3 | 循环体**后**执行 | 需在循环体内手动改变控制变量 |

标准顺序：表达式 1 → 表达式 2（真）→ 循环体 → 表达式 3 → 回到表达式 2 → …

::: danger 易错

赋值当条件最坑

`for(i=0; i=5; i++)` 中表达式 2 是赋值，结果恒真，死循环；`for(; i=0; )` 中表达式 2 是赋值 0，恒假，一次都不执行。不要把 `==` 和 `=` 混用。

:::

最简死循环：`for(;;)` 等价 `while(1)`。用 `getchar` 控制循环时，`for(; (ch=getchar())!='\n'; )` 里 `(ch=getchar())` 的括号**不可省**，因为 `!=` 优先级高于 `=`，去掉就变成把比较结果 0/1 赋给 ch。

## 三、break 与 continue：范围与去向

|   | break | continue |
| --- | --- | --- |
| 作用范围 | 结束整个所属循环；嵌套时只结束所属层 | 只结束本次循环，循环不终止；嵌套时也只作用于所属层 |
| 在 for 中的去向 | 直接到循环**之后**的语句，**不经过表达式 3** | 先执行表达式 3，再判表达式 2 |
| 在 while/do-while 中的去向 | 直接到循环之后的语句 | 回到 while/do-while 的表达式 |
| 可用位置 | switch 和循环 | 仅循环 |

::: info

嵌套就近原则

外层执行一次，内层执行一轮；break/continue 都只影响自己所在的那一层循环。switch 里的 break 只跳出 switch，**不会**跳出外层循环。

:::

## 四、典型代码：九九乘法表

```
<code>#include <stdio.h>
int main()
{
    int i, j;
    for (i = 1; i <= 9; i++)        /* 外层控制行 */
    {
        for (j = 1; j <= i; j++)    /* 内层控制列 */
            printf("%d*%d=%-2d ", j, i, i * j);
        printf("\n");
    }
    return 0;
}
</code>
```

核心记忆点：外层一次，内层一轮；内层循环变量要在外层循环体内部重新初始化或按行控制，否则行与行之间会乱。当前版本内层 j 从 1 到 i，输出的是**下三角**。

## 五、先回忆，再自测

::: details 合上笔记：while 与 do-while 最少执行几次？for 的三个表达式分别在什么时候执行？

while 先判断，条件一开始不成立就 0 次；do-while 先执行，至少 1 次。for：表达式 1 只执行一次；表达式 2 在循环体前判断；表达式 3 在循环体后执行。

:::

::: details break 与 continue 在 for 循环中分别“跳到哪里”？嵌套时作用范围如何？

break 直接跳到循环后面的语句，不会执行表达式 3；continue 跳到表达式 3，再判断表达式 2。嵌套时两者都遵循就近原则，只作用于自己所在的那一层。

:::

::: details 写累加、累乘程序时，累加变量和累乘变量分别要置多少？

累加变量置 0，累乘变量置 1。否则累加会带入脏数据，累乘遇到 0 会全部归零。

:::

## 六、测验（点击选项作答）

**1. 关于 while 与 do-while 的执行次数，正确的是**

- A. while 至少执行 1 次，do-while 至少 0 次
- B. while 至少执行 0 次，do-while 至少 1 次
- C. 两者都至少执行 1 次，两种循环没有区别
- D. 两者都至少执行 0 次，两种循环没有区别

::: details 点开核对答案

**答案：B（while 至少执行 0 次，do-while 至少 1 次）** —— while 先判断后执行，条件一开始不成立就一次都不执行；do-while 先执行后判断，即使条件一开始不成立也已执行一次。

:::

**2. 下列 for 循环中，循环体一次都不会执行的是**

- A. 条件为关系表达式 i&lt;10，正常执行
- B. 条件为赋值 i=1，导致死循环
- C. 条件为赋值 i=0，循环体不执行
- D. 三个表达式全部省略，无限循环

::: details 点开核对答案

**答案：C（条件为赋值 i=0，循环体不执行）** —— 表达式 2 是赋值 &lt;code&gt;i=0&lt;/code&gt;，值为 0 即恒假，循环体一次不执行；&lt;code&gt;i=1&lt;/code&gt; 恒真会死循环；&lt;code&gt;for(;;)&lt;/code&gt; 表达式 2 省略默认恒真，也是死循环。

:::

**3. 在 for 循环中遇到 continue 后，程序下一步会**

- A. 直接结束整个循环，不再继续执行
- B. 跳到循环后面的语句继续执行
- C. 跳过本次后直接判断表达式 2
- D. 先执行表达式 3 再判断表达式 2

::: details 点开核对答案

**答案：D（先执行表达式 3 再判断表达式 2）** —— continue 只结束本次循环。在 for 中它会先执行表达式 3，再去判断表达式 2；在 while/do-while 中则直接回到表达式。

:::

**4. 嵌套循环中，内层循环里的 break 会**

- A. 只结束 break 所属的内层循环
- B. 同时结束内层循环与外层循环
- C. 跳到外层循环的下一次继续
- D. 跳到内层循环的表达式 3 执行

::: details 点开核对答案

**答案：A（只结束 break 所属的内层循环）** —— break 与 continue 都遵循就近原则，只作用于它们所在的那一层循环；内层 break 结束后，外层继续执行下一轮。

:::

**5. 写程序计算 `1×2×…×10` 时，累乘变量 result 的初值应设为**

- A. 0，防止累乘结果超出范围
- B. 1，作为乘法单位元起始
- C. 10，从循环上限开始递减
- D. -1，用于判断最终乘积符号

::: details 点开核对答案

**答案：B（1，作为乘法单位元起始）** —— 累乘必须置 1，因为 1 是乘法单位元；若置 0，所有乘积都会变成 0。累加则必须置 0。

:::

**6. `for(;;)` 与下列哪个循环等价**

- A. `while(0)`，条件恒假不执行
- B. `do {} while(0);` 条件恒假
- C. `while(1)`，条件恒真无限循环
- D. `for(;0;)`，条件恒假不执行

::: details 点开核对答案

**答案：C（while(1)，条件恒真无限循环）** —— for 的三个表达式全部省略时，表达式 2 默认恒真，等价 &lt;code&gt;while(1)&lt;/code&gt;，都是无限循环。其他三个选项条件为假，不会等价。

:::

**7. 执行下面程序段后，输出结果是**

- A. 12
- B. 123
- C. 12345
- D. 3

::: details 点开核对答案

**答案：A（12）** —— i=1、2 时输出 1、2；i=3 时遇 break，直接结束整个循环（不经过表达式 3），后面的 3、4、5 都不再输出。

:::

**8. 执行下面程序段后，输出结果是**

- A. 135
- B. 12345
- C. 24
- D. 13

::: details 点开核对答案

**答案：A（135）** —— i=2、4 时 i%2==0 成立，continue 跳过本次的 printf，先执行表达式 3（i++）再判 i&lt;=5，循环不终止；只有奇数 1、3、5 被输出。

:::
