::: details 温故 · 第 26 课「排序算法对比与选择」：默写口诀——哪些排序算法稳定？哪些不稳定？

「冒插基归稳，选堆快希不稳」：稳定——冒泡、插入（含折半插入）、基数、归并；不稳定——选择、堆、快速、希尔。

:::

::: details 温故 · 第 25 课「查找」：默写 AVL 树 LL、RR、LR、RL 四种失衡的旋转方式。

LL 右旋，RR 左旋；LR 先左旋再右旋，RL 先右旋再左旋——本质是把「折线」先扭成「直线」，再旋一次。

## 三、从复习题归纳的应用题代码模板

复习题一二三的应用题反复出现三类骨架：**链表插删**、**排序**、**遍历**。下面给出可直接默写的模板，代码细节与 数组、指针、结构体 笔记一致。

### 3.1 链表插入与删除

```
<code>struct Node {
    int data;
    struct Node *next;
};

/* 在 p 所指结点之后插入新结点 s（s 已创建好） */
s->next = p->next;
p->next = s;

/* 删除 p 之后的结点 q */
struct Node *q = p->next;
p->next = q->next;   /* 让 p 直接指向 q 的后继 */
</code>
```

::: info

易错点

插入时必须先让 `s->next` 指向 `p->next`，再改 `p->next`，否则原后继会丢失。删除时若题目要求释放空间，再补 `free(q);`，但先保证指针连接正确。

:::

### 3.2 排序模板

**冒泡排序**（来自数组笔记）：

```
<code>for (i = 0; i < n - 1; i++)
    for (j = 0; j < n - 1 - i; j++)
        if (a[j] > a[j + 1]) {
            t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
        }
</code>
```

**选择排序**（来自结构体笔记，整型数组同样适用）：

```
<code>for (i = 0; i < n - 1; i++) {
    p = i;                       /* p 记录未排序区最小值位置 */
    for (j = i + 1; j < n; j++)
        if (a[j] < a[p]) p = j;
    if (p != i) { t = a[i]; a[i] = a[p]; a[p] = t; }
}
</code>
```

### 3.3 遍历模板

**数组遍历**：复习题一应用题 3（求大于平均值个数）的核心骨架。

```
<code>for (i = 0; i < n; i++) {
    /* 对 a[i] 进行操作：累加、计数、判断等 */
}
</code>
```

**链表遍历**：

```
<code>for (p = head; p != NULL; p = p->next) {
    /* 访问 p->data */
}
</code>
```

**字符流遍历**：复习题二应用题 2（统计字符类型）的核心骨架。

```
<code>while ((ch = getchar()) != '\n') {
    /* 用 if-else 分类计数 */
}
</code>
```

::: danger 易错

模板不是照抄，是识别套路

拿到应用题先拆三段：**输入**（scanf / getchar / 初始化数组）→ **处理**（遍历 + 判断/累加/交换）→ **输出**（printf）。把这三段写出来，代码主体结构就不会丢分。

:::

## 四、先回忆，再自测

::: details 合上笔记：什么是数据结构？涉及哪几个方面？

按一定逻辑结构组成的一批数据，按某种存储结构存储于计算机中，并在其上定义了一个运算的集合。涉及三方面：逻辑结构、存储结构、运算（算法）。

:::

::: details 合上笔记：算法有哪些特性？评价优劣的标准是什么？

五特性：有穷性、确定性、可行性、输入（0 个或有限个）、输出（1 个或有限个）。评价标准：正确性、可读性、健壮性、高效性（时间复杂度 + 空间复杂度）。

:::

::: details 合上笔记：栈和队列的相同点和不同点是什么？

相同点：都是操作受限的线性表。不同点：栈只能在一端（栈顶）插入和删除，先进后出；队列在一端（队尾）插入、另一端（队头）删除，先进先出。

:::

## 五、测验（点击选项作答）

**1. 按照 14 天打卡表，第 4 天需要对哪些组进行回忆？**

- A. 仅 A 组需要回忆
- B. A 组与 B 组均需回忆
- C. B 组与 C 组均需回忆
- D. 全部六组均需回忆

::: details 点开核对答案

**答案：B（A 组与 B 组均需回忆）** —— A 组第 1 天学，第 2、4、7、11 天回忆；B 组第 3 天学，第 4、6、9、13 天回忆。因此第 4 天是 A、B 两组同时回忆。

:::

**2. 复习题三中「顺序表和链表的区别」官方答案强调的核心差异是**

- A. 顺序表物理相邻可随机存取，链表插删较方便
- B. 顺序表只能顺序存取，链表可以随机存取
- C. 链表比顺序表更节省存储空间
- D. 顺序表插入删除不需要移动元素

::: details 点开核对答案

**答案：A（顺序表物理相邻可随机存取，链表插删较方便）** —— 复习题三官方答案：顺序表逻辑相邻的元素物理存储位置必须相邻，优点是节省空间、可以随机存取；链表物理位置不要求相邻，插入删除方便。

:::

**3. 复习题二应用题「统计字符类型」中，while 循环的结束条件是**

- A. 读到空格符即结束
- B. 读到文件结束符 EOF
- C. 读到数字字符即结束
- D. 读到换行符即结束

::: details 点开核对答案

**答案：D（读到换行符即结束）** —— 参考代码使用 &lt;code&gt;while ((ch = getchar()) != '\n')&lt;/code&gt;，即从键盘读到回车换行符为止。

:::

**4. 在链表删除模板中，要删除 p 后面的结点 q，正确操作是**

- A. p-&gt;next = q-&gt;next
- B. p-&gt;next = q
- C. q-&gt;next = p-&gt;next
- D. p = q-&gt;next

::: details 点开核对答案

**答案：A（p-&gt;next = q-&gt;next）** —— 删除 q 时，应让 p 直接指向 q 的后继，即 &lt;code&gt;p-&gt;next = q-&gt;next&lt;/code&gt;。选项 A 会把 p 指向 q 本身，B 改的是 q 的指针，D 改的是 p 的指向。

:::

**5. 关于冒泡排序的趟数，n 个数需要比较**

- A. n 趟，每趟比较 n 次
- B. n−1 趟，第 x 趟比 n−x−1 次
- C. n/2 趟，两两交换一次
- D. n+1 趟，保证全部有序

::: details 点开核对答案

**答案：B（n−1 趟，第 x 趟比 n−x−1 次）** —— 数组笔记明确：n 个数比较 n−1 趟，第 x 趟比较 n−x−1 次（x 从 0 开始计数，对应代码中 &lt;code&gt;j &lt; n - 1 - i&lt;/code&gt;）。

:::

**6. 下列操作中，全部属于「加工型操作」的一组是**

- A. 插入、删除、查找
- B. 查找、遍历、更新
- C. 更新、排序、引用
- D. 插入、删除、排序

::: details 点开核对答案

**答案：D（插入、删除、排序）** —— 数据结构绪论笔记：加工型操作改变结构的值，如插入、删除、更新、排序；引用型操作只查询，如查找、遍历。因此只有 B 组全部属于加工型。

:::
